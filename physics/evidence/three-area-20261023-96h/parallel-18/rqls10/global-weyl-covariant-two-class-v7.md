## 0. Result in one paragraph

Consider every 1-RQLS(10) whose 100 cells carry the Weyl orbit `D(g)psi` (`g` in `Z10^2`), with row, column and designated-transversal partitions all invariant under translation of `Z10^2`. This family is **exactly equivalent** to one vector problem: find `psi` in `C^10` unbiased to three Weyl-Heisenberg eigenbases `(Z, X, XZ^k)` with `k` a unit mod 10 (Theorems A and C). **Any** solution automatically has all 100 rays pairwise nonparallel (Theorem B), so it IS a maximal-cardinality 1-RQLS(10). Up to Clifford symmetry there are exactly **two** classes:

- class B: `k = +/-1`. This is the triple that Grassl-McNulty-Mista-Paterek report as strongly unextendible in `d = 10`, by computer-aided algebra (named import I1).
- class A: `k = +/-3`. As far as the sources read here show, it is not covered by any published statement.

The two classes are **Galois conjugate** through `zeta20 -> zeta20^7` (Theorem D). If the import's certificate shows emptiness over C, class A is empty as well. If it shows only real emptiness, every class-A solution still needs coordinates outside every abelian number field containing `zeta20`. A complete C^5 reduction (Theorem E) excludes every fully `Dic3`-symmetric candidate in both classes, and every plane spanned by vectors unbiased to the three C^5 bases. **The single remaining question is whether class A has a real solution.** It is a finite, exactly stated algebraic system (Section 9). A yes gives an explicit maximal 1-RQLS(10). A no closes the whole translation-covariant Weyl route.

## 1. Notation

`omega = exp(2 pi i/10)`; on `C^10` with basis `|t>`, `t` in `Z10`: `X|t> = |t+1>`, `Z|t> = omega^t |t>`, `D(p,q) = X^p Z^q`. Then `ZX = omega XZ`, and the 100 operators `D(g)` are orthogonal: `tr(D(g)^dagger D(h)) = 10 delta_{gh}`. For a unit vector `psi`, the ambiguity function is `A(g) = <psi, D(g) psi>`. Moyal: `sum_g |A(g)|^2 = 10`, `A(0) = 1`, and `|A(g)| <= 1` with equality iff `psi` is an eigenvector of `D(g)`.

CRT: `t <-> (t mod 2, t mod 5)` identifies `C^10 = C^2 (x) C^5`. Since `t/10 = t/2 + 3t/5 (mod 1)` holds for every `t` (check at `t = 1`: `1/2 + 3/5 = 11/10`),

    X10 = X2 (x) X5,     Z10 = Z2 (x) Z5^3,     D10(p,q) ~ D2(p,q) (x) D5(p,3q)     (up to phase).   (1.1)

`Z10^2 = Z2^2 x Z5^2` correspondingly, via `(p,q) -> ((p,q) mod 2, (p,3q) mod 5)`.

## 2. The family and its exact reduction

**Definition.** `F_W` is the set of 1-RQLS(10) arrays of this form. A bijection `cells <-> Z10^2` puts `D(g)psi` on cell `g`. The 10 rows, 10 columns and 10 designated transversals each form a partition of `Z10^2` that is invariant under all translations `h -> h+g`. Each block must carry an orthonormal basis.

**Lemma 1 (invariant partitions are coset partitions).** Let a partition of a group `G` be invariant under all translations, and let `H` be the block containing 0. For `h` in `H`, `H+h` is a block containing `h`, so it equals `H`. Thus `H` is closed under addition, and finite, so it is a subgroup. Every block `B` containing `g` equals `H+g`. QED.

**Lemma 2 (orthonormality).** For a coset `C = H+g`, `<D(g+h)psi, D(g+h')psi> = (phase) A(h'-h)`. Thus `{D(c)psi : c in C}` is orthonormal iff `A` vanishes on `H\{0}`. If `H` is cyclic of order 10, generated by `g0`, the operators `D(m g0)` commute and are linearly independent, so they span a 10-dimensional commutative algebra (a MASA). `D(g0)` then has simple spectrum with eigenbasis `B_H`. Fourier inversion on the character group shows that `A = 0` on `H\{0}` iff `|<e,psi>|^2 = 1/10` for every `e` in `B_H`. QED.

**Lemma 3 (the admissible subgroup triples).** A subgroup of order 10 of `Z2^2 x Z5^2` is `l x lambda`, with `l` one of the three lines of `Z2^2` and `lambda` one of the six lines of `Z5^2`. All 18 are cyclic. Rows and columns need `A1 + A2 = Z10^2` and `A1 ∩ A2 = 0`, i.e. an exact factorization. A transversal class meets every row and every column in exactly one cell iff `A3 ∩ A1 = A3 ∩ A2 = 0`. Pairwise trivial intersection holds iff the `l_k` are distinct (so they are all three lines `z, x, y` of `Z2^2`) and the `lambda_k` are distinct. QED.

**Theorem A (equivalence).** `F_W` is nonempty iff, for some admissible triple `(A1,A2,A3)`, some `psi` is unbiased to `B_{A1}`, `B_{A2}` and `B_{A3}`. Given such `psi`, the array with `D(g)psi` on cell `g`, rows `A1+g`, columns `A2+g` and classes `A3+g` lies in `F_W`. Conversely, Lemmas 1-3 put every member in this form. QED.

Under (1.1), `B_{A_k}` is the product basis `l_k-basis (x) lambda_k-basis`. This holds because `D2 (x) D5` has simple joint spectrum and the joint eigenbasis is unique.

## 3. Theorem B - every solution is automatically maximal

**Step 1 (maximally mixed qubit).** Let `psi` be unbiased to the three product bases `{|j_a>(x)|K_a>}` (`a = z,x,y`). Summing over `K` gives `<j_a|rho_A|j_a> = 5/10 = 1/2` for all six qubit stabilizer states, so the Bloch vector of `rho_A` vanishes and `rho_A = I/2`. Hence `psi = (|0>(x)b0 + |1>(x)b1)/sqrt2` with `b0, b1` orthonormal in `C^5`, and `psi` is entangled.

**Step 2 (no Weyl eigenvector).** Suppose `D(g)psi` is proportional to `psi` with `g = (g2,g5) != 0`. Then `|A(mg)| = 1` for all `m`. But `A` vanishes on every `A_k \ {0}`, so `<g> ∩ A_k = 0` for each `k`.

- If `g2 != 0`, then `5g = (5g2, 5g5) = (g2, 0)`, which is nonzero. Since the three `l_k` cover `Z2^2\{0}`, `g2` lies in some `l_k`, so `5g` lies in `A_k`. Contradiction.
- If `g2 = 0`, then `D(g) ~ I (x) D5(g5')` with `g5' != 0`. Every `C^5`-component of `psi` lies in one eigenspace of `D5(g5')`. These eigenspaces are 1-dimensional because `5` is prime and the spectrum is simple. So `psi` is a product state, contradicting Step 1.

Therefore `|A(g)| < 1` for all `g != 0`, and the 100 rays `D(g)psi` are pairwise nonparallel. QED.

**Corollary B1.** Every member of `F_W` has the maximal cardinality 100.

## 4. Theorem C - exactly two Clifford classes

The Clifford group acts on `F_W` and preserves unbiasedness; `Sp(2,Z10) = SL(2,Z2) x SL(2,Z5)` acts on the triple data. `SL(2,2) ~ S3` permutes the three lines of `Z2^2` simply transitively. On `Z5^2`, `SL(2,5)` acts on the six lines through `PSL(2,5)`, which acts on `P^1(F5)`. That action is free on ordered triples of distinct points, since only the identity of `PGL` fixes three points. `120/60 = 2`, so there are two orbits on ordered triples. The antiunitary complex conjugation acts by `diag(1,-1)`, with determinant `-1 = 2^2` (a square mod 5). It therefore acts through `PSL`, which merges nothing.

Each `PSL(2,5)` orbit on unordered 3-subsets has stabilizer `S3`, which realizes every permutation of the three points, so the matching between Z2-lines and Z5-lines is immaterial. **Hence exactly two classes.**

**Invariant.** Put two of the Z5 lines at `Z5` (slope inf) and `X5` (slope 0). The third is `X5 Z5^c`, whose eigenbasis is the chirp basis `g_M(K) = omega5^{alpha K^2 + M K}/sqrt5` with `alpha = c/2 (mod 5)`. The stabilizer of `{inf, 0}` in `PSL(2,5)` is `z -> 4z`, `z -> 1/z`, `z -> 4/z`. It preserves the Legendre symbol `(alpha/5)`, and the two values give the two classes. Equivalently, take the centre vectors `e0 = delta_0`, `f0 = (1,...,1)/sqrt5` and `g0 = (omega5^{alpha K^2})/sqrt5`. Their Gram matrix is real, with `<e0,f0> = <e0,g0> = 1/sqrt5` and `<f0,g0> = (alpha/5)/sqrt5`, the last by the Gauss sum `sum omega5^{alpha K^2} = (alpha/5) sqrt5`.

Representatives, by (1.1):

- **class B**: `(Z,X,XZ)`. `X10 Z10 = X2Z2 (x) X5 Z5^3`, so `c = 3` and `alpha = 4`, a square. This is the icosahedral "face" type.
- **class A**: `(Z,X,XZ^3)`. `X10 Z10^3 = X2Z2 (x) X5 Z5^4`, so `c = 4` and `alpha = 2`, a nonsquare. This is the "nonface" type.

Conversely, `k` in `{1,9}` gives class B and `k` in `{3,7}` gives class A. The dilations `diag(u,u^{-1})` send `k -> u^{-2} k` with `u^2` in `{1,9}`, and the Fourier element sends `k -> -k^{-1}`. Both preserve these two sets.

## 6. Theorem D - classes A and B are Galois conjugate

All three eigenbases of each class have entries in `Q(zeta20)`: `XZ^k` satisfies `(XZ^k)^10 = -I`, so its eigenvalues are 20th roots of unity. Let `sigma = sigma_7: zeta20 -> zeta20^7`. Then `sigma(Z) = Z^7`, `sigma(X) = X`, `sigma(XZ^3) = X Z^21 = XZ`, and `sigma(i) = -i`. Since `sigma` maps eigenvectors to eigenvectors, it maps:

- the Z-basis to itself (rational);
- the Fourier basis to itself as a set;
- the `XZ^3` eigenbasis onto the `XZ` eigenbasis.

Write `psi = u + i v` and complexify `(u,v)`. Equivalently, take independent `z = u + iv` and `w = u - iv`. The unbiasedness equations become the polynomial system

    (sum_t conj(beta_t) z_t)(sum_s beta_s w_s) = 1/10   (every basis vector beta),     sum_t z_t w_t = 1,

with coefficients in `Q(zeta20)`. This field is abelian, so `sigma` commutes with complex conjugation on it. Applying `sigma` to the coefficients therefore gives exactly the class-B system for the bases `sigma(beta)`. Extend `sigma` to an automorphism of `C`. It maps the complex solution variety `V_A(C)` bijectively onto `V_B(C)`. QED.

**Corollary D1 (conditional on I1's certificate type).** If I1 certifies `V_B(C) = empty` (a unit ideal in the real-imaginary variables), then `V_A(C) = empty`. Class A then has no real solution, and `F_W` is empty in both classes.

**Corollary D2 (needs only real emptiness of class B).** Suppose a class-A solution `psi` has all coordinates in a field `K` that is Galois and abelian over `Q`, with `zeta20` in `K`. Some lift of `sigma` lies in `Gal(K/Q)` and commutes with complex conjugation `c`, because the group is abelian and `c` acts on `K`. Then `sigma(psi)` is a REAL class-B solution, contradicting I1. More generally, a class-A solution needs a Galois closure in which no lift of `sigma_7` centralizes complex conjugation. In particular, every cyclotomic or otherwise abelian guess fails automatically.

## 7. Theorem E - exact C^5 plane reduction and exclusions

By Step 1 (Section 3), `psi = (|0>(x)b0 + |1>(x)b1)/sqrt2`. Unbiasedness to `z(x)E`, `x(x)F` and `y(x)G` (`E` the Z5-basis, `F` the Fourier basis, `G` the chirp basis of the class) is equivalent to the following:

    b0 _|_ b1 unit;  b0, b1 E-flat;  (b0 +/- b1)/sqrt2 F-flat;  (b0 +/- i b1)/sqrt2 G-flat     (7.1)

Here B-flat means `|<e,v>|^2 = 1/5` for all `e` in `B`. Proof: `<j,K|psi> = b_j(K)/sqrt2`, `<+/-x, L|psi> = <L|b0 +/- b1>/2` and `<+/-y, M|psi> = <M|b0 -/+ i b1>/2`.

**Bloch form.** Define the isometry `V|j> = b_j`, put `u_e = V^dagger e` in `C^2` for every basis vector `e`, and let `r_e` be its Bloch vector, so `|r_e| = |u_e|^2`. Then `|<e, V n>|^2 = (|u_e|^2 + n.r_e)/2` for the qubit direction `n`. Condition (7.1) holds iff, for every `e` in `E ∪ F ∪ G`, `|u_e|^2 = 2/5`, and

- `r_e` is perpendicular to `z` for `e` in `E`;
- `r_e` is perpendicular to `x` for `e` in `F`;
- `r_e` is perpendicular to `y` for `e` in `G`.

In every basis, `sum_e u_e u_e^dagger = I2`, so `sum r_e = 0`.

**Lemma E1 (odd sum).** Five vectors of equal nonzero length summing to 0 are not collinear: collinear ones would be `+/-v` with an odd number of terms. So the E-Bloch vectors span exactly the plane perpendicular to `z`, and similarly for `F` (`x`) and `G` (`y`). The same holds for every odd prime replacing 5.

**Lemma E2 (no H-pair plane).** Let `H` be one of the three remaining Weyl MUBs. If `span(b0,b1) = span(h,h')` with `h, h'` orthonormal in `H`, then `|<h,e>| = |<h',e>|` for every `e` in `E ∪ F ∪ G`. Thus all fifteen `r_e` are perpendicular to the h-frame axis `n_h`. By E1, `n_h = +/-z` and also `n_h = +/-x`. Contradiction.

**Lemma E3 (no mixed-pair plane, any odd prime p).** Let `h, h'` be unit vectors unbiased to `E` with `|<h,h'>|^2 = 1/p`, for instance from two different further MUBs. Then `span(h,h')` does not have flat E-diagonal `2/p`. Proof: with `c = <h,h'>`, `<K|P|K> = (p/(p-1))(2/p - 2 Re(c h_K conj(h'_K)))`, so flatness forces `Re(c h_K conj h'_K) = 1/p^2` for every `K`. The modulus is `p^{-3/2}`, so `Im = +/- p^{-2} sqrt(p-1)` with a common magnitude. Meanwhile `sum_K c h_K conj(h'_K) = |c|^2` is real, so the imaginary parts must sum to 0. An odd number of equal-magnitude `+/-` terms cannot sum to 0.

**Theorem E4 (all Dic3-symmetric candidates fail, both classes).** In `PSL(2,5)`, the stabilizer of the three lines is `S3`. Its preimage in `SL(2,5)` acting on `C^5` is `Dic3` (order 12), containing the parity `Pi5 = -I`. The C^5 Weil representation splits as even `W+` (dim 3) plus odd `W-` (dim 2).

- The centre vectors `e0, f0, g0` span `W+` with REAL Gram matrix of determinant `(2/5)(1 + epsilon/sqrt5) > 0`, where `epsilon = (alpha/5)`.
- Gram preservation forces the three-cycle to act as `e0 -> c f0 -> c^2 epsilon g0 -> c^3 epsilon e0`, up to the stated phases. Its eigen-equation `mu^3 = epsilon` has three distinct roots, so `W+|S3 = sigma + (one line)`. The line is the real direction `w = e0 + f0 + g0` (class B) or `w = -e0 + f0 + g0` (class A).
- With the qubit `S3` (`sigma`, axis permutations): `C^2 (x) C^5 = (1 + 1' + sigma) + sigma + (sigma (x) W-)`. Every one-dimensional `Dic3` component lies either in `C^2 (x) Sigma`, with `Sigma = W+ ⊖ w`, or in `C^2 (x) W-`.

In the odd case, `b0(0) = b1(0) = 0`, so `E`-flatness fails. In the even case `span(b0,b1) = Sigma`, which needs `<e0|P_Sigma|e0> = 1 - |<e0,w>|^2/|w|^2 = 2/5`. But `|<e0,w>|^2/|w|^2` is `(1 + 2/sqrt5)/3 = (5 + 2 sqrt5)/15` (class B) or `(1 - 2/sqrt5)/3 = (5 - 2 sqrt5)/15` (class A), and neither equals `3/5`, because `sqrt5 != +/-2`. QED.

## 9. Exact remaining question (class A)

Find unimodular `a, b: Z5 -> T` with `sum_K conj(a_K) b_K = 0` and, for all `L, M` in `Z5` and both signs,

    | sum_K omega5^{-K L} (a_K +/- b_K) |^2 = 10,      | sum_K omega5^{-2K^2 - M K} (a_K +/- i b_K) |^2 = 10.     (9.1)
