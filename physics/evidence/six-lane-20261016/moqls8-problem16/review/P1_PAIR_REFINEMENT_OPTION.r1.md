## Proposed statement

Take C ∈ {P1-B3, P1-B5}. Any genuine normalised configuration in template C can be moved, by the same (σ, ρ, τ) moves, to one in the same template whose two permutation squares carry a representative pair {a, b} from the table. These are the moves of `review/GB_NF_GENUINE_BRIDGE.r1.md`, SHA256 `1a352d364a2e2c68a344735537db7e6f10861e01d520cf75dcbef7a61fbf504b`, Lemma 2, as corrected by `review/GB_REVIEW_ERRATUM.r2.md`, SHA256 `a2d3b9b3cd7bfe1cb4ffe20bbfbaf80856051ab6a4e743ffa86591513fbe407d`. In the Boolean setting, the same claim would extend NF §4. In that representative configuration both M_{a−2} and M_{b−2} hold.

Hence UNSAT of every B_C ∧ M_{a−2} ∧ M_{b−2} over the representative pairs would exclude template C:
- P1-B3: two formulas, B3∧M2∧M3 and B3∧M2∧M4. They would replace P1-B3.M2.
- P1-B5: four formulas. They would replace P1-B5.M2 and P1-B5.M3.

Each pair formula contains all clauses of the corresponding single-M_s input. It has 252 tail binaries, so 5740268 + 252 = 5740520 GA clauses. The option is useful only if the single input proves hard; refuting the single input already refutes every pair formula built on it.
