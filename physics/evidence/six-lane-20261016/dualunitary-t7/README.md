### 0.1 Primary source and conventions (read from the pinned PDF; text in `sources/`)

Source: Rajchel-Mieldzioć, Bistroń, Rico, Lakshminarayan, Życzkowski, arXiv:2508.04777v3 (PDF SHA-256
bc8ee8fc…5e760b, identical to the parent's pin). Layout text `sources/2508.04777v3.layout.txt`.

- Reshuffling (realignment) R: `⟨ij|U^R|αβ⟩ = ⟨iα|U|jβ⟩` (layout line 239).
- Partial transpose Γ: `⟨iβ|U^Γ|jα⟩ = ⟨iα|U|jβ⟩` (line 241).
- Dual unitary: U and U^R unitary; T-dual: U and U^Γ unitary; 2-unitary: U, U^R, U^Γ unitary (lines 245–257).
- Entangling power (11a): `e_p(U) = [E(U) + E(US) − E(S)]/E(S)`, `E(U) = 1 − Tr(U^R U^R†)²/d⁴`,
  `E(US) = 1 − Tr(U^Γ U^Γ†)²/d⁴` (eq. 10), `E(S) = 1 − 1/d²` (lines 375–409).
- Basis/index convention used everywhere here: `|ij⟩ ↔ 3i + j` (first tensor factor = most significant), so
  `(A⊗B)[(i,α),(j,β)] = A[i,j] B[α,β]`; a permutation matrix has `P[row][col] = 1` iff `P|col⟩ = |row⟩`.
- **P9 := the matrix (C7)** (Appendix C, PDF page 27). Its nine ones, extracted from PDF word coordinates
  (`sources/c7page.bbox.html`), sit at (row, col) = (0,0),(1,8),(2,4),(3,5),(4,1),(5,6),(6,7),(7,3),(8,2), i.e.
  `P9|ij⟩ = |2i+j, i+j⟩ (mod 3)`. The source also gives two other descriptions — state (14), `|ij⟩ ↦ |i+j, 2i+j⟩`,
  and the verbal permutation of Sec. III A, `|ij⟩ ↦ |2i+j, 2i+2j⟩` — and ref. [44] (A14) uses a fourth labelling.
  These differ from (C7) by local relabellings; this is checked exactly (local permutation matrices found by
  exhaustive search) rather than assumed.
- Four-party picture (eq. C8): `|Ψ_U⟩ ∝ Σ_ij |ij⟩ ⊗ U|ij⟩`, i.e. `ψ(a,b,c,d) = U[(c,d),(a,b)]`, parties 1..4 = (a,b,c,d).

- **Corollary target** (only with source ref. [44], Rather–Ramadas–Kodiyalam–Lakshminarayan, arXiv:2212.06737v2,

  `sup{e_p(U): U ∈ D (resp. T), U not 2-unitary} < 1`. Qualitative only; no gap value claimed.

## 1. Result (status: CANDIDATE — written proof + two exact implementations; parent re-derivation, Claude hostile
## review and priority audit pending)

- **Theorem (both readings recorded in `review/PROOF.md` §0):** O9 is relatively open (indeed a connected component) in
  the dual-unitary set D and in the T-dual set T; i.e. there is ε > 0 such that every dual (resp. T-dual) unitary within
  ε of O9 lies in O9. Literal T7: trivially yes; non-trivial T7 (non-2-unitary dual/T-dual gates near P9): no.
- **Corollary (uses [44] Thm 1):** sup e_p < 1 over non-2-unitary dual (resp. T-dual) gates; no value claimed.
- **Mechanism:** at P9 both linearized systems have kernel 33 = dim of the LU orbit (exact). Hand proof: the code of P9
  is the perfect [4,2,3]_3 tetracode; the cut involutions generate S3 acting freely on the 72 off-code points
  (12 orbits), kernel 9 + 2·12 = 33; LU tangent 9 + 24 = 33.
- **Certificates:** implementation A (python-flint, matrix picture) and B (pure Python, state picture) agree exactly
  (`evidence/implA.json`, `evidence/implB.json`, `evidence/SHA256SUMS.txt`).
- **Controls:** variants of P9, wrong reshuffle (kernel 81), equivalent reshaping (33), d = 4 P16 (kernel 136 > tangent 61;
  enphasing curve proves O16 non-isolated), dual-not-T-dual permutation (45 vs 29) — all as expected.
