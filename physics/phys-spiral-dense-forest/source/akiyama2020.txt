                                                   Abstract. We show that a constant angle progression on the Fermat
                                                   spiral forms a Delone set if and only if its angle is badly approximable.

direction, the first return map gives another irrational rotation x 7→ x +
(−1)k+1 ηk+1 . As the number of points nα (mod 1) increases, we inductively
observe the induced irrational rotations. Three distance theorem can be
easily understood as a consequence of this structure.

constant R, that for any N ∈ N, the ratios of three distances generated by
the N + 1 points are bounded by R.
