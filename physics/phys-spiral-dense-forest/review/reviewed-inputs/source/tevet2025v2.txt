                                                                                  Abstract
                                                                                                     √
                                                    A Fermat spiral is a set of points of the form ne2πiαn for α ∈ R.
                                                 In this paper we prove that the Chabauty limits of Fermat spirals are
                                                 always closed subgroups of R2 , and conclude that no Fermat spirals are
                                                 dense forests. Furthermore, we show that if α is badly approximable the
                                                 Chabauty limits are always lattices, for which we give a characterisation.

                                           A spiral set is a set of the form { nun | n ∈ N} such that un ∈ S1 . A
                                           spiral set is called a Fermat spiral if un = e2πiαn for some α ∈ R. Fermat
                                           spirals, and, in particular, √
                                                                        the sunflower spiral (the Fermat spiral with constant
                                           angle difference φ = (1 + 5)/2, the golden ratio), have long been studied. In
                                           [Vog79], Vogel studied a close relative of the sunflower spiral that is found in
                                                                                          2

                                           spiral sets where the angle is of the form α n.

                                           approximable if
                                                                      0 < cα := lim inf qj |qj α − pj |.

                                           tion, such that for every ε > 0, every ε×V (ε) rectangle intersects X. In [Aki20],
                                           Akiyama showed that the Fermat spirals with constant angle difference are De-

Theorem 1. The non-empty Chabauty limits of a Fermat spiral are translations
of closed subgroups of R2 .

in a big neighbourhood around the origin. The Chabauty limits can likewise
be thought of as how the set X looks as we go farther from the origin. It is
easy to show that the only Chabauty limits of a Fermat spiral with a rational
α are the empty set and lines. In the case that α is not rational and not badly-
approximable little is known, however, the following theorem states that in the
case where α is badly-approximable the Chabauty limits can be well understood.

Throughout the paper we use the following characterisation of the Chabauty
limit:
Proposition 3. Let X ⊆ Rd be a closed set and Tn be translations such that
Tn X converges to X̃ in the Chabauty topology. For a point x ∈ Rd we have that
x ∈ X̃ if and only if there is a sequence of points xn ∈ Tn X that converges to x.
Proof. Assume that x ∈ X̃, then for any n denote by xn the point closest to x
in Tn X (there must be such a point since Tn X is closed). For every 0 < ε < 1
and ∥x∥ < 1/ε, for some N and every N ≤ n, we have that d(X, Tn X) < ε,
therefore x ∈ Nε (Tn X) and so ∥xn − x∥ < ε.
    In the other direction, we have a sequence xn ∈ Tn X that converges to x,
and denote by x̃n ∈ X̃ the point closest to xn . For every 0 < ε < 1 there is
N1 such that for every N1 ≤ n we have ∥x − xn ∥ < ε; similarly, there is N2
such that for every N2 ≤ n we have xn ∈ Nε (X̃), therefore ∥x̃n − xn ∥ < ε. For
N = max{N1 , N2 } and N ≤ n we have

                    ∥x̃n − x∥ ≤ ∥x̃n − xn ∥ + ∥xn − x∥ < 2ε

and so we have x̃n → x and since X̃ is closed x ∈ X̃.
Definition. A discrete set X ⊆ Rd is called relatively dense if there is some
r > 0 such that for any x ∈ Rd we have Br (x) ∩ X ̸= ∅; it is called uniformly
discrete if there is some s > 0 such that for any x ∈ Rd we have |Bs (x) ∩ X| ≤ 1;
it is called Delone if it is both relatively dense and uniformly discrete.
Proposition 4. If X is Delone, then every Chabauty limit of it is Delone.
Proof. Let X be a Delone set and Tn be translations such that Tn X converges
to X̃. There is some r such that X is r-relatively dense, therefore for any x ∈ Rd
and any translation Tn we have yn ∈ Br (x) ∩ Tn X, so the sequence yn has a
converging subsequence in Br (x), and the limit of it must be in X̃, therefore
X̃ ∩ Br+1 (x) ̸= ∅.
    Similarly, there is some s such that X is s-uniformly discrete, therefore for
any x ∈ Rd and any translation Tn we have |Bs (x) ∩ Tn X| ≤ 1, so it is clear
that |Bs (x) ∩ X̃| ≤ 1.
    As a consequence of Theorem 1 we obtain:
Corollary 5. The Chabauty limits of a Fermat spiral with badly-approximable
angle difference are translations of lattices.
Proof. There are exactly six closed subgroups of R2 (up to isomorphism): 0, Z,
R, Z2 , Z × R, R2 . In [Aki20], Akiyama showed that for a badly-approximable
angle difference, the Fermat spiral is Delone, therefore the limits must be Delone
as well, and the only Delone closed subgroups of R2 are the lattices.
Proposition 6. For a set X ⊆ Rd , the following are equivalent:


                                        3
    1. X is not a dense forest;
    2. X has a Chabauty limit with an infinite strip with no points (i.e. there is
       an ε and there is a line such that there are no points ε-close to it);
    3. X has a Chabauty limit with a half-infinite strip with no points (i.e. there
       is an ε and there is a ray such that there are no points ε-close to it).
Proof. For (1 =⇒ 2), if X is not a dense forest, there is some ε > 0 such that
for every V > 0 there is ε × V rectangle that does not intersect with X. Let Tn
be the transformation that translates the centre of such a rectangle for V = n
to the origin. Let θn be the angle the long side of the rectangle makes with
the horizontal direction, then we may assume that θn converges by passing to a
subsequence. We now may pass to a converging subsequence of Tn X since the
Chabauty topology is compact, and the limit must have an infinite strip with
no points.
    The implication (2 =⇒ 3) is trivial.
    For (3 =⇒ 1), assume there is such a Chabauty limit X̃ with a half-infinite
strip with no points of width ε, achieved by the translations Tn . For every
V > 0 there is n such that d(X̃, Tn X) < min{ε/2, 1/(2V )}, this means there
is a V × (ε/2) rectangle that does not intersect Tn X, so there must be such
rectangle that does not intersect X.
Corollary 7. No Fermat spiral is a dense forest.

Proof. Let α be the angle difference. If α ∈ Q the points lie on a finite number
of rays from the origin, and so for some ε > 0 we can look at the half-infinite
strip [a, ∞) × [ε/2, ε] and for large enough a it will not intersect any point. If
α∈ / Q is not badly-approximable, Akiyama showed in [Aki20] that the Fermat
spiral is not relatively dense, and if α ∈
                                         / Q is badly-approximable, it follows from
Corollary 5 and Proposition 6.

Remark. The author conjectures that for α that is not badly-approximable
the only non-empty Chabauty limits are isomorphic to R, Z2 , and Z × R, and
in particular the limit cannot be R2 . If this is indeed the case, then we need
not split the preceding proof into cases.

4    Properties of the Limit
We now turn to studying the non-empty Chabauty limits of Fermat spirals
as given by Theorem 1 in the badly-approximable case. Let X be a Fermat
spiral with a badly-approximable angle difference α and let Tj be a sequence of
translations such that Tj X converges in the Chabauty topology. Without loss
of generality, we may assume that the limit has a point at the origin, so Tj X
converges to a lattice Λ. Let nj be a sequence of indices such that Tj xnj → 0.
    Let pn /qn be the continued fraction convergents of α. We can write qn+1 =
an qn + qn−1 for some positive natural numbers an , which are the continued
fraction expansion of α = [a1 , a2 , . . .]. The number α is badly-approximable if
and only if the sequence an is bounded, therefore it is equivalent to the sequence
qn+1 /qn = an + qn−1 /qn being bounded. Note we also have cα ≤ qn |qn α − pn | ≤
1, and so we can always pass to a converging subsequence. Two facts which will
prove useful are (qn α − pn )(qn+1 α − pn+1 ) < 0 and

                    qn |qn+1 α − pn+1 | + qn+1 |qn α − pn | = 1.

For a reference, see [Cas57].

Further Questions
The author conjectures that there is a spiral set that is a dense forest, this is
in contrast to a conjecture of Adiceam and Tsokanos in [AT22]. A possible
avenue to consider is noting that if all of the Chabauty limits of a set are dense
forests, the set is also a dense forest (by Proposition 6), and then constructing a
spiral set whose limits are similar to the construction given by Bishop in [Bis11]
using the lattice limits given by Fermat spirals. If there are indeed spiral sets
that are dense forests, one might ask what is the best visibility function, and in
particular whether there is a Danzer spiral set.
    We saw a classification of all of the lattices that can be achieved, however,
this classification is quite difficult to use. In particular, the question whether
every lattice with co-volume π is achieved as a Chabauty limit of some Fermat
spiral with badly-approximable angle difference remains.
    A third question is what are the Chabauty limits of Fermat spirals with
irrational angle difference that is not badly-approximable. As noted above,
the author conjectures that the limits are isomorphic to ∅, R, Z2 , and Z × R.
Computational evidence suggests they are all achieved, but a full classification
could be interesting, and in particular do the lattices also have co-volume π.
