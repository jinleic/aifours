Chapter heading: 一些代数的 Gröbner–Shirshov 基

Dendriform dialgebra 是一个具有两个二元运算 ≺ 和 ≻ 的 k- 线性空间 D, 满足: 对于任意的 x, y, z ∈ D, (x ≺ y) ≺ z = x ≺ (y ≺ z + y ≻ z), (x ≻ y) ≺ z = x ≻ (y ≺ z), (x ≺ y + x ≻ y) ≻ z = x ≻ (y ≻ z).

Dendriform trialgebra 是一个具有三个二元运算 ≺, ≻ 和 · 的 k- 线性空间 T, 满足: 对于任意的 x, y, z ∈ T, (x ≺ y) ≺ z = x ≺ (y ⋆ z), (x ≻ y) ≺ z = x ≻ (y ≺ z), (x ⋆ y) ≻ z = x ≻ (y ≻ z), (x ≻ y) · z = x ≻ (y · z), (x ≺ y) · z = x · (y ≻ z), (x · y) ≺ z = x · (y ≺ z), (x · y) · z = x · (y · z), 其中 x ⋆ y = x ≺ y + x ≻ y + x · y.

问题 3 分别找出自由 dendriform dialgebra 和 trialgebra 的 Gröbner–Shirshov 基.
