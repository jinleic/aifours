# A seven-rule Gröbner–Shirshov basis for the free noncommutative dendriform trialgebra

Date: 2026-10-14 PT. Status: **reproduction/certification of published prior work**, not a new solution. The decisive source is Bagherzadeh–Bremner–Madariaga, *Journal of Algebra* **486** (2017), 360–395, §6.1, Lemma 6.1, p. 388, DOI [10.1016/j.jalgebra.2017.04.022](https://doi.org/10.1016/j.jalgebra.2017.04.022). The [saved page image](sources/lemma-29.png) shows the exact seven polynomials. Their middle operation `curlywedge` is the book's dot.

The finite symbolic calculations below have been checked over the integers twice in different representations: a replayable Python reduction certificate and a Lean kernel-evaluated theorem. The admissible-order proof, exhaustive-overlap argument, and all-arity composition–diamond bridge are written mathematics, **not** fully formalized in Lean.

## 1. Exact scope and seven rules

Let `k` be any field and `X` any set (possibly infinite or empty). No operation is assumed commutative, and no multiplicative unit is imposed. Let `M(X)` be the planar binary trees with internal vertices labelled by `P = prec`, `D = dot`, or `S = succ`, and leaves labelled by `X`. Let `k M(X)` be their finite linear span, with the three bilinear grafting operations. The ideal `I` is generated by every monomial substitution into the seven identities printed in the book; multilinearity makes this equivalent to allowing arbitrary vector substitutions.

Here are the oriented rules. Letters `a,b,c` stand for arbitrary trees, not necessarily generators, and every operation is extended bilinearly:

```text
PP: (a P b) P c  ->  a P (b P c) + a P (b S c) + a P (b D c)
PS: (a S b) P c  ->  a S (b P c)
PD: (a D b) P c  ->  a D (b P c)
DP: (a P b) D c  ->  a D (b S c)
DS: (a S b) D c  ->  a S (b D c)
DD: (a D b) D c  ->  a D (b D c)
SS: (a S b) S c  ->  a S (b S c) - (a P b) S c - (a D b) S c.
```

Rule names give the outer operation first. Each defining polynomial is its displayed left-hand side minus the right-hand side. In particular, the last rule is exactly the book's `(a * b) S c = a S (b S c)` with `a*b = a P b + a S b + a D b`; it is not an extra axiom or a different variety.

**Theorem.** These seven polynomial schemas, instantiated at all `a,b,c in M(X)`, are a Gröbner–Shirshov basis of `I` for the order in §2. Its irreducible labelled trees form a `k`-basis of the free dendriform trialgebra on `X`, in every arity and in every characteristic.

The seven schemas are a reduced quadratic basis in the nonsymmetric operad. The infinite set of all their algebra substitutions is a GS basis of the algebra ideal, but is not asserted to be reduced as an infinite set: substituting a reducible tree can make a tail reducible.

## 2. An explicit admissible well-order

Order operations `D < P < S`. For a tree `t` with `n` leaves in planar order, let

```text
Path(t) = (w_1(t), ..., w_n(t))
```

where `w_i(t)` records the internal-operation labels from root to its `i`th leaf, with the root label first. Order operation words by **degree–lexicographic order**: length first, then lexicographically using `D<P<S`. Order tree shapes first by `n`, then lexicographically by these path words. If leaf labels matter, choose a well-order of `X` and break a path-sequence tie lexicographically by the leaf-label sequence. The basis statement itself does not depend on this auxiliary choice. For an arbitrary set this is the usual classical well-ordering convention for GS theory.

This is the standard graded path-lex order, not an unsupported declaration that all left combs outrank all right combs. See Dotsenko–Khoroshkin [arXiv:0812.4069](https://arxiv.org/abs/0812.4069), §3.2.1, Propositions 4–5; and Bremner–Dotsenko, *Algebraic Operads: An Algorithmic Companion*, Lemma 3.4.1.4 and Proposition 3.4.1.6. Here is a direct justification in the binary nonsymmetric case.

1. **Injectivity.** The ordered sequence of leaf depths uniquely determines an ordered full binary tree: parse its first subtree recursively until the subtree's dyadic leaf weights sum to one, then parse the second. Equivalently, the left block has total Kraft weight `1/2` in the whole tree, determining its unique boundary. The first symbol of every nonempty path gives the root label; deleting it on each of the two recursively determined blocks recovers both decorated subtrees. Leaf labels then recover the labelled tree.
2. **Well-foundedness.** Arity is compared first. At each fixed arity there are finitely many decorated binary skeletons. At each fixed skeleton the lexicographic order on a fixed finite power of the well-ordered set `X` is a well-order. Thus the whole order is a well-order.
3. **Operadic substitution in a leaf.** In this item the trees are unlabelled input skeletons, with the same ordered input slots. Grafting `u` into slot `i` replaces the single path `w_i` by the block `w_i v_1,...,w_i v_m`, where `Path(u)=(v_1,...,v_m)`. Degree–lex word order is strictly increasing under concatenation on either side. If the first differing old path occurs before or after `i`, it remains the first differing path, with the appropriate index shift; if it is `i`, the first element of the replacing block preserves the inequality. If instead the inserted skeleton is varied, equal path prefixes are added to its first differing path. Different arities remain different in the same direction. This proves operadic admissibility; it does not assert that replacing a differing generator label by a common tree preserves strict order.
4. **Labelled-algebra contexts.** For any one-hole labelled tree context `C`, different arities in `u<v` remain different in `C[u],C[v]`. At equal arities, the first differing path within the hole has the same prefix added on both sides, and all paths outside the hole agree. If skeletons agree, the leaf-label sequences outside the hole agree and the first differing label inside the hole remains. Thus `u<v` implies `C[u]<C[v]`. This is the monomial-order property needed for the free nonassociative algebra's products.

For each of the first six rules, the first leaf has a path of length two on the left and one on every right-comb term on the right. The SS right-comb also has this property. The other two SS terms have first paths `SP` and `SD`, strictly less than `SS`. Thus every RHS term is smaller than the LHS. After substituting arbitrary trees `a,b,c`, the paths to the first leaf of `a` have the same suffix appended to these displayed prefixes, so the inequalities persist directly; every term has the same total arity and ordered leaf labels. Context monotonicity then proves strict decrease in any surrounding tree.

Reduction of a polynomial is terminating: a step removes one supported monomial and introduces finitely many smaller ones. The well-founded multiset extension of the monomial order decreases. No division is used; all leading coefficients are one.

## 3. Exhaustive classification of ambiguities

A reducible occurrence consists of a node and its left child. Write `B(o,i)` for the condition that outer operation `o` and left-child operation `i` form a leading term. Explicitly,

```text
B(P,i) = B(D,i) = true for all i in {D,P,S};
B(S,i) = true exactly when i=S.
```

Two chosen reductions on a tree have four possibilities:

- **Same occurrence:** there is exactly one matching rule, so the results agree.
- **Disjoint occurrences:** performing both in either order gives the same polynomial by bilinearity.
- **One occurrence lies wholly inside a variable-subtree of the other rule:** each variable occurs exactly once in every term of each rule. Reducing that subtree before the outer rule or in each copy after the outer rule gives the identical expanded polynomial. Collecting or cancelling coefficients does not change this equality.
- **A genuine shared-vertex overlap:** the two left edges form one consecutive three-vertex left chain. It has the form
  `W(o,m,i) = (((a i b) m c) o d)`
  with `B(o,m)` and `B(m,i)`. There are seven such pairs `(m,i)` for each `o=D,P`, and one for `o=S`, hence exactly **15**.

No proper inclusion of one quadratic skeleton in another is possible. No balanced-tree or right-edge critical shape is omitted. In an arbitrary larger tree every shared-vertex overlap is a context and monomial substitution of exactly one of these fifteen four-variable skeletons. This is why checking these finite **symbolic** overlaps, unlike checking a finite list of dimensions, is sufficient for every arity.

## 4. All fifteen symbolic reductions

The notation below is prefix notation: `D(a,b)=a D b`, and similarly for `P,S`. All sums distribute linearly. Define only the following abbreviation for compactness:

```text
E_q(a,b,c,d) = S(a,S(b,q(c,d))) - S(P(a,b),q(c,d)) - S(D(a,b),q(c,d)).
```

For a row `omi`, reduce `W(o,m,i)` first at the root, or first at its left child. Both branches reduce to the listed common polynomial:

| `omi` | Common polynomial |
|---|---|
| DDD | `D(a,D(b,D(c,d)))` |
| DDP | `D(a,S(b,D(c,d)))` |
| DDS | `S(a,D(b,D(c,d)))` |
| DPD | `D(a,D(b,S(c,d)))` |
| DPP | `D(a,S(b,S(c,d)))` |
| DPS | `S(a,D(b,S(c,d)))` |
| DSS | `E_D(a,b,c,d)` |
| PDD | `D(a,D(b,P(c,d)))` |
| PDP | `D(a,S(b,P(c,d)))` |
| PDS | `S(a,D(b,P(c,d)))` |
| PPD | `sum_{q in {D,P,S}} D(a,P(b,q(c,d)))` |
| PPP | `sum_{r,q in {D,P,S}} P(a,r(b,q(c,d)))` |
| PPS | `sum_{q in {D,P,S}} S(a,P(b,q(c,d)))` |
| PSS | `E_P(a,b,c,d)` |
| SSS | The nine-term polynomial immediately below. |

```text
 S(P(a,P(b,c)),d) + S(P(a,D(b,c)),d)
+S(D(a,P(b,c)),d) + S(D(a,D(b,c)),d)
-S(P(a,b),S(c,d)) - S(D(a,b),S(c,d))
-S(a,S(P(b,c),d)) - S(a,S(D(b,c),d))
+S(a,S(b,S(c,d))).
```

These are genuine symbolic reductions, not numerical evaluations of the variables. Full term-by-term traces for both branches of **every** row are in [critical-pairs.json](evidence/critical-pairs.json), with a readable [expanded table](evidence/critical-pairs.tsv). The JSON stores each initial branch, the term/coefficient/context path selected at every later step, and the final polynomial. Paths `1` and `2` select the left and right child. There are 75 traced steps after the 30 first branch steps.

For illustration, DPP is the useful nontrivial cancellation case. Its outer-first branch is

```text
((a P b) P c) D d
 -> (a P b) D (c S d)
 -> a D (b S (c S d)).
```

The inner-first branch expands to `sum_q (a P (b q c)) D d`, then to `sum_q a D ((b q c) S d)`. Applying SS to its `q=S` summand cancels precisely the `q=P,D` summands, leaving the same answer. This uses neither a new identity nor characteristic-zero division.

[TrialgebraCritical.lean](work/TrialgebraCritical.lean) independently represents polynomials by lists of integer-weighted trees. Its `rootRule` lists the seven rules explicitly; `step` contracts one actual contextual redex; `reduce` iterates this operation with fuel. The theorem `TrialgebraCritical.all_critical_pairs_join` proves that the filtered complete list of operation triples has length 15 and that both branches in every triple have equal integer coefficients and irreducible outputs. Requiring irreducibility excludes mistaking fuel exhaustion for a successful normal form. Equality checks the union of both finite supports, so no coefficient can be silently omitted. The accepted theorem uses only `propext`.

Negative controls: corrupting a trace coefficient is rejected; replacing dot associativity by `(a D b) D c -> -a D (b D c)` gives nonjoining DDD, PPP, SSS peaks. The corresponding Lean mutation is rejected with `Tactic decide proved that the proposition ... is false`, not a synthesis failure. The [failed source](../../scratch/ai4s-math-more-20261014/trialgebra/TrialgebraCriticalFalse.lean) is preserved in the owned scratch directory, and its [stdout](evidence/lean-negative-stdout.txt) and [stderr](evidence/lean-negative-stderr.txt) are retained here; these were outside the referee's restricted snapshot. ## 5. All-arity composition–diamond bridge

We give the linear diamond argument rather than inferring confluence from Schröder counts.

Induct in the well-order of §2. For an irreducible monomial `t`, set `NF(t)=t`. For a reducible `t`, choose any one-step result `r(t)` and set `NF(t)` equal to the sum of the already defined normal forms of its smaller terms. Extend linearly to polynomials. To see that the choice is independent, compare two first reductions. The four cases in §3 give an identical common polynomial after the specified local operations: in the last case use the traces of §4 substituted into the arbitrary variable subtrees and outer context. Every term after the first reduction is smaller than `t`, and all later contextual rules decrease the order. The induction hypothesis therefore gives identical normal forms for both branches. This proves independence at `t` and hence in every arity.

Let `N(X)` denote the irreducible monomials. Every reduction subtracts a contextual, substituted defining polynomial, so `f-NF(f)` belongs to `I`. Conversely, `NF` annihilates every contextual substituted relation by the just-proved choice independence, hence it annihilates their linear span, which is exactly `I`. Thus

```text
ker NF = I,
NF restricted to k N(X) = identity,
k M(X) / I  is naturally isomorphic, as a vector space, to  k N(X).
```

There is also the explicit leading-term formulation of GS completeness. If a nonzero `f in I` had an irreducible leading monomial `m`, reductions of all its other monomials stay strictly below `m` and cannot remove its nonzero coefficient. This contradicts `NF(f)=0`. Therefore the leading monomial of every nonzero element of `I` contains a leading occurrence of one of the seven schemas. This is precisely the nonassociative multioperator GS property, with the operadic small-common-multiple argument translated to the free algebra.

Finally, the quotient satisfies all seven identities because they are multilinear and their monomial instances generate `I`. For any trialgebra `A` and any function `X -> A`, the unique graft-evaluation map `k M(X) -> A` annihilates `I`, so descends uniquely to the quotient. This proves the required universal property for **any generator set**, not only for the one-generator algebra or only for the multilinear component.

All displayed reductions are integral and monic. The argument works verbatim after mapping integer coefficients into any field, including characteristics 2 and 3. No symmetric-group semisimplicity or polarization is used. This explicitly removes the characteristic-zero convention of the 2017 source without claiming that this routine monic base-change observation is novel.

## 6. Explicit normal forms and all-arity enumeration

A tree is normal exactly when every internal node labelled `P` or `D` has a leaf as its left child, and a node labelled `S` has either a leaf left child or a left child labelled `P` or `D` that is itself normal. Thus the following grammar is unambiguous:

```text
N = X
  | P(X,N) | D(X,N) | S(X,N)
  | S(P(X,N),N) | S(D(X,N),N).
```

Choose any trees in this grammar and label their leaves freely by `X`, in order. They are the requested linear basis. Multiplication is: graft with the chosen operation and apply the seven rules until normal. Termination and independence were proved above, so this is an explicit well-defined algebra presentation and normal-form algorithm.

For one generator let `F(z)=sum_{n>=1} a_n z^n`. The unambiguous grammar proves, in formal power series over the integers,

```text
F = z + 3 z F + 2 z F^2,
a_1 = 1,
a_n = 3 a_(n-1) + 2 sum_{i+j=n-1, i,j>=1} a_i a_j  (n>=2).
```

This is an all-coefficient recurrence, not a guess from a prefix. It gives `1,3,11,45,197,903,...`, the shifted little Schröder numbers. If `X` has `q` elements, degree `n` has dimension `a_n q^n`; if `X` is empty the free nonunital algebra is zero.

As an independent classical comparison, Loday–Ronco's Theorem 2.6 and Corollary 2.9 in [math/0205043](https://arxiv.org/abs/math/0205043), published in 2004, identify the free trialgebra on `V` with `direct_sum_{n>=1} k[T_n] tensor V^(tensor n)`, where `T_n` consists of planar reduced rooted trees with **n+1** leaves, not n leaves. Their operations and inverse map are in §§2.6–2.8, over a field `K`, with no commutativity restriction. The indexing shift is essential. If `H=z+sum_{n>=1}|T_n| z^(n+1)`, root decomposition gives `H=z+H^2/(1-H)`. Substituting `H=z(1+F)` yields exactly `F=z+3zF+2zF^2`, proving agreement in every degree. This comparison is corroborative here; it is not a hidden hypothesis of our critical-pair proof.

## 7. The dialgebra half and complete Question 3 scope

The other half is already solved by Chen–Wang (2010), [1009.0185](https://arxiv.org/abs/1009.0185), and Madariaga, [1304.5184](https://arxiv.org/abs/1304.5184), Theorem 1. With `P<S` and the same graded path-lex order, the three schemas are

```text
(a P b) P c -> a P (b P c) + a P (b S c)
(a S b) P c -> a S (b P c)
(a S b) S c -> a S (b S c) - (a P b) S c.
```

Normal forms are `N = X | P(X,N) | S(X,N) | S(P(X,N),N)`, giving the Catalan dimensions `1,2,5,14,...`. This presentation is the dot-zero quotient, but merely deleting a rule from an arbitrary GS basis would not be a valid proof. Here the dot-zero specialization is justified: reduction never decreases the number of dot-labelled vertices in any summand (PP and SS can increase it). Thus the span of trees containing a dot is stable under reduction, and projecting away those trees yields exactly the displayed dialgebra rules. The four no-dot critical peaks are PPP, PPS, PSS, SSS. Projecting their established integer reduction traces kills every positive-dot summand; remaining steps are precisely the three dialgebra rules. Their common results are normal, so the same diamond argument proves the displayed normal basis over every field. Madariaga explicitly gives the same three-rule result in characteristic zero; Chen–Wang supplies the earlier algebra formulation over a field `k`.

Consequently the exact independent book **Question 3**, asking separately for the free dialgebra and free trialgebra GS bases, is fully answered by existing mathematics. This does not solve the chapter's other questions, and this dossier does not claim an original discovery.
