## 0. Lemma INC (zero-sum-free odd sequences of length 2p-1-e, e <= 3)

Let p >= 5 and Y a zero-sum-free sequence of odd elements of Z_(2p) of length L = 2p-1-e, 0 <= e <= 3.  Then Y = g^L
with g a generator, or e >= 2 and Y = g^(L-1)(3g).
Proof.  For an ordering y_1..y_L put A_0 = {0}, A_t = A_(t-1) u (A_(t-1) + y_t), delta_t = |A_t| - |A_(t-1)|.
(a) delta_t >= 1: otherwise A_(t-1) + y_t is inside A_(t-1), so A_(t-1) contains 0, y_t, 2y_t, ..., hence -y_t; then
    -y_t is 0 or a subsequence sum of y_1..y_(t-1) and Y has a zero-sum.  As A_L lies in Z_(2p), sum delta_t <= 2p-1
    = L + e, so the "extras" sum (delta_t - 1) are at most e <= 3.
(b) At most two distinct values: if a, b, c are distinct values, order them first.  A_2 = {0, a, b, a+b} has 4
    elements (a+b is even and nonzero, a, b odd).  A_2 + c = {c, a+c, b+c, a+b+c} meets A_2 in nothing: c is not a or
    b; a+b+c = a or b would give a zero-sum pair; a+c, b+c are even and nonzero and a+c = a+b iff c = b.  So
    delta = 1, 2, 4 and the extras are already 4 > 3.
(c) Y = a^m b^n, m >= n.  As L >= 2p-4 >= 6, m >= 3; a = (1,0) would give the zero-sum a a, so a is a generator and
    b = d a with d odd in [3, 2p-1].  Order a^m first (A = {0, a, ..., m a}, delta = 1 each; m < 2p).  For the first b:
    if d <= m, A + b = {d a, ..., (m+d) a}; m+d >= 2p would make b a^(2p-d) a zero-sum, so delta = d and the extras
    are d-1; d >= 5 is excluded, so d = 3.  If 2p-d <= m, b a^(2p-d) is a zero-sum.  Otherwise A + b is disjoint
    from A (b + i a = j a forces d = j-i in [-m, m]) and delta = m+1, extras m >= ceil(L/2) >= p-2; this exceeds 3
    unless p = 5, m = n = 3, e = 3 (L = 6); in that case order b a a a b b: the deltas are 1,2,2,2 and then the fifth
    letter adds the four elements 2b + i a (i = 0..3), none in A (2b + i a = j a forces 2d = j-i in [-3, 3] mod 10,
    so d in {1, 9, 5}: b = a, b = -a or b = (1,0), all impossible), extras >= 6.  So b = 3a.
    If n >= 2, A = {0, ..., (m+3) a} after the first 3a (m+3 < 2p, else a zero-sum); the second 3a adds (m+4)a,
    (m+5)a, (m+6)a; m+4, m+5 or m+6 = 2p would be a zero-sum; m+6 = 2p+1 forces n = 4-e <= 1 (as m = L-n), a
    contradiction; otherwise these 3 elements are new, extras >= 2 + 2 > 3.  So n = 1 and Y = a^(L-1)(3a) with
    extras 2 <= e.  []
Special cases: e = 2 gives (Z3) of v1 (g^(2p-3) or g^(2p-4)(3g)); e = 3 gives g^(2p-4) or g^(2p-5)(3g).
(In Z_(2p), (1,0) = p g for every generator g, which is neither g nor 3g since p != 1, 3.)

## 1. Lemma DEL (unchanged from v1)

If w (length 4p-2) avoids and has exactly three odd blocks, deleting one reflection from one odd block and applying
Lemma PM* across every even block gives an avoider w2 of length 4p-3 with the same rotation multiset and a
representation X_1 S_1 X_2 S_2, l_1, l_2 odd.  (Subwords of avoiders avoid; GRX and PM* hold for every
representation, including empty runs.)

## 3. Theorem ROT-o3

For every prime p >= 5, every avoider of length 4p-2 over D_(2p) with exactly three odd maximal constant reflection
blocks has all rotation letters in one {rho_c, rho_-c}, c != 0.  Proof: Lemma DEL, then Proposition K2'.  []
Together with Corollary ROT-o2: ROT holds for every avoider with at most three odd blocks.
