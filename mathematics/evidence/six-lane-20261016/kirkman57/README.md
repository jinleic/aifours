## 4. New representation (this lane)

1. **Automorphism lemmas for any LSTS(v), v odd** (written proofs in
   `sources/automorphism-lemmas.md`): an involution of the large set has exactly
   one fixed point and exactly one invariant constituent; a prime-order element
   with f≥3 fixed points has exactly f−2 invariant constituents carrying an
   LSTS(f) on its fixed set; order-3 elements with f=0 have n≡1 (mod 3)
   invariant constituents, each with ≡1 (mod 3) of its 3-cycles (v=57).
   These rule out most large symmetry groups, including the affine ones the
   prior dossier treated case by case.
2. **Group G513** = `(Z19 ⋊ Z9) × Z3` on `Z19×Z3`, generated by
   `τ:(x,i)↦(x+1,i)`, `ν:(x,i)↦(4x,i+1)`, `ρ:(x,i)↦(x,i+1)`; point `(x,i)↦19i+x`.
   Transitive, order 513, point stabilizer Z9. The lemmas force the
   constituent orbit structure `19 + 9+9 + 9+9`: one orbit with stabilizer the
   Sylow-3 `P27=<ν,ρ>` and four orbits with stabilizers `F57=<τ,ωρ>` (two) and
   `F57'=<τ,ω²ρ>` (two), ω=7. G has 62 orbits on triples (55 regular).
3. Kramer–Mesner exact cover over the 62 G-orbits with five bases, followed by
   independent per-base *symmetric resolution* SAT problems
   (base S0: ν-invariant, 1 fixed class + 3 orbits of 9; F57 bases:
   μ-invariant, 1 fixed class + 9 orbits of 3), then development by G and
   independent verification.

## 5. Frozen attack protocol

* Stage A (STS level): exact cover of the G513 Kramer–Mesner system. Solver:
  own Algorithm X and/or kissat/cadical CNF. Enumerate solutions in bounded
  chunks (≤30 min uncheckpointed). Record counts and every candidate.
* Stage B (resolution): for each Stage-A candidate, per-base SAT with the
  stated class symmetry; fall back to weaker symmetry only as a recorded,
  separate experiment.
* Stage C: expand to 55 labelled KTS(57) and check with the lane's own
  standard-library checker `code/check_lkts57.py`; mutation controls required.
* Positive controls through the same pipeline: LKTS(9) and LKTS(15)
  (and LKTS(21) if time allows) under known-feasible group actions.
* Resources: ≤4 CPU workers, ≤8 GiB RSS, chunks ≤3 h, checkpoint ≤30 min.
* Stop/redirect: an exhaustive Stage-A infeasibility is a *restricted-model
  exclusion* only; then move to the next ranked structure (recorded in
  `evidence/`). UNKNOWN is never UNSAT.
