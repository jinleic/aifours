## 1. Frozen target (written 2026-10-17 after 08:07:47 PDT host clock, before any run)

X = {(g, a) : g ∈ {0,1,2,3}, a ∈ {0,…,31}} (label 32g + a), groups G_g = {(g, a)}; empty stem.
Find a set A of 4-subsets such that

1. (CQS(32⁴ : 0), Tan–Zhou lines 256–266) every 3-subset of X not contained in one group lies in
   exactly one block and no 3-subset of a group lies in any block; hence |A| =
   (C(128,3) − 4·C(32,3))/4 = 80384, block group-multiplicities 2+2, 2+1+1 or 1+1+1+1;
2. (good colourable derived designs, lines 211–220, 281–288) for **every** x ∈ G, the derived
   design D_x = {B∖{x} : x ∈ B ∈ A}, an incomplete STS(127, 31) with hole H = G∖{x}
   (2512 triples; every pair not inside H covered once, no pair inside H covered), is
   partitioned into r = χ′(127) = 64 nonempty partial parallel classes of which exactly
   s = 64 − (127 − 31)/2 = 16 avoid H. (Source (1.1): v ≡ 1 (mod 6), v ≠ 7, 13 gives
   (r, s) = ((v+1)/2, (h+1)/2) = (64, 16).)

Counting facts (sanity checks only): a hole point lies in 48 triples (so it lies in every
non-avoiding class exactly once), a non-hole point in 63 (missed by exactly one class); a
non-avoiding class has exactly 31 hole triples and m ≤ 11 hole-free triples and misses
34 − 3m ≡ 1 (mod 3) non-hole points; a hole-avoiding class has k ≤ 32 triples and misses
96 − 3k ≡ 0 (mod 3); the misses sum to 96; total slack 48·42 + 16·32 − 2512 = 16.
**No class-size profile, symmetry, cyclic or orbit condition is part of the target.**

Success = one explicit certificate listing the groups, all 80384 blocks and all 128 labelled
colourings, accepted by definition-first checkers that assume no symmetry. A restricted-group
UNSAT, a heuristic miss or a timeout leaves the unrestricted question UNKNOWN.

**Groups (search choices only).** Generators act on (g, a); π₁ = (1 2 3), π₂ = (0 1)(2 3) on the
group index (⟨π₁, π₂⟩ = A4 = AGL(1, 4) on F4 labels).
* G_C = A4 × C32 (τ: a ↦ a + 1 mod 32), order 384, Stab(x) = ⟨π₁⟩ — the copied pipeline
  ("A4xC").
* G_E = A4 × (F₂⁵ ⋊ ⟨A⟩): a ∈ F₂⁵ as 5-bit integers, translations a ↦ a ⊕ e
  (e = 1, 2, 4, 8, 16) in every group, and A: (b₀, b₁, b₂, b₃, b₄) ↦ (b₀, b₁, b₂, b₄, b₃ ⊕ b₄)
  applied to the coordinate in every group (order 3, Fix(A) = {0,…,7}). Order 1152, transitive,
  Stab((0,0)) = ⟨π₁⟩ × ⟨A⟩ ≅ C3 × C3. Colouring symmetry R = ⟨π₁, A⟩, anchor h = (0, 1)
  (fixed by R). Lane note (`sources/symmetry-notes.md`, to be written before E3): by Lemma F
  of the gcdcqs20 lane (order-3 ρ = A, fixed set Fix(A) × F4 = a sub-CQS(8⁴ : 0)), every
  R-invariant good colouring has exactly 16 A-invariant classes (12 non-avoiding, 4 avoiding)
  whose restrictions colour the fixed sub-design well; non-avoiding class orbits are forced
  (4 of size 3 with stabilizer ⟨A⟩, 4 of size 9); the hole-avoiding orbit structure is a
  recorded option per run. Elements π₁Aʲ (j = 1, 2) fix only hole points.
* Order-3 coordinate automorphisms do not exist for C32, and an order-3 coordinate map with a
  one-dimensional fixed space (Fano fixed set) is excluded from R by Corollary F1 — hence the
  choice of A. The Boolean CQS (planes of AG(7, 2) not inside a coset of a 5-space) is not used:
  by a parity count (`sources/symmetry-notes.md`, Lemma P) it has no good colouring.
