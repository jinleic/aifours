the 27 non-avoiding classes each contain every hole point exactly once. A non-avoiding class has 19 hole

## 3. Representation, certificate formats, checkers, controls

**Format S (gcDCQS with stem; `.txt`, `#` starts a comment, blank lines ignored, strict order):**
`GCDCQS v n g s` / `COLOURS r` / `HOLEFREE t` / `GROUPS` + n lines of g points / `STEM` + one line of s points
(no line if s = 0) / `BLOCKS` + lines of 4 points / then for every group point x a section `POINT x` with
`CLASS j` (j = 0,…,r−1 in order) followed by triples / then for every stem point α a section `STEMPOINT α` with
classes `FRAME k` (k = index of the missed group in GROUPS order) followed by triples. Points are 0,…,v−1.
Checks: v = gn + s; v−1 ≡ 1, 3 (mod 6); r = χ′(v−1) by (1.1) and t = r − (v − g − s)/2 recomputed and equal to the
header; groups and stem partition X; blocks are 4 distinct points, none repeated; **every 3-subset of X not inside
any S ∪ G lies in exactly one block and none inside S ∪ G lies in a block**; every group point x has exactly r
nonempty classes of pairwise disjoint triples T with T ∪ {x} a block, no triple twice, all derived triples listed,
and exactly t classes avoid (G_x ∪ S)∖{x}; every stem point α has classes whose triples T have T ∪ {α} a block,
each class covering exactly X∖(S ∪ G_k) once, the classes partitioning the derived design at α.

**Format D (FDGDD / RDGDD):** `GDD34 KIND k m` (KIND ∈ {FDGDD, RDGDD}) / `GROUPS` + k lines of m points / `BLOCKS`
+ lines of 4 points / for every point x a section `POINT x` with classes `FRAME j` (FDGDD; j = index of the
missed group, ≠ group of x) or `PC j` (RDGDD; j = 0,1,… in order) followed by triples. Checks: groups partition
X = {0,…,km−1}; blocks transverse (4 distinct groups), none repeated; every 3-subset meeting three groups in
exactly one block (and no other triple in a block); at every x the classes partition {B∖{x} : x ∈ B} and each
class is a parallel class of X∖(G_x ∪ G_j) (FDGDD) or of X∖G_x (RDGDD).

(`code/check_gcdcqs_s.py`, `code/check_gdd34.py`, written by this worker); route 2 C (`code/check_gcdcqs_s.c`,
