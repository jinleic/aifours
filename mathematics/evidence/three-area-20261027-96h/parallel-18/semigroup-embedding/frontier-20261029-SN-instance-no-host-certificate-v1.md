# A label-consistent SN-instance certificate for nonembedding, and bounded searches for it

**Status: NEW AUTHOR WRITTEN sufficient-obstruction theorem (self-contained) + BOUNDED EXPLORATORY searches that found NO instance; UNREVIEWED / UNADOPTED.** No counterexample to originalQ1 is claimed. The searches are evidence about where an obstruction is NOT, not a proof that none exists.

## 1. Certificate theorem (any actor, any action)

Let S be ANY semigroup and let ν' be the congruence generated by all comparable idempotent pairs `e≤f` (`ef=fe=e`). Suppose a,b,c,d∈S satisfy

1. `abc` and `abcd` are idempotents;
2. `abc ν' ac`.

If S embeds in a physical host `P(B,D)` with B seminormal (`xyzwx=xyzxzwx`), D completely simple and any action, then `abcda=abcacda`. Consequently, if such a,b,c,d exist with `abcda≠abcacda`, then S has NO faithful SN-band-by-CS host for ANY CS actor or action.

**Proof.** Let φ be the embedding and t its actor coordinate. Distinct idempotents of a CS semigroup are incomparable, so ker t contains every comparable idempotent pair and hence ν'. Thus `t(abc)=t(ac)` is an idempotent of the row of t(a), and so is `t(abcd)`; for an idempotent ε in that row, `εt(a)=t(a)`. Write `φ(x)=(β_x,(i_x,g_x,λ_x))`. The physical product gives the band coordinate of a word as `β_(x₁)α_(w₁)(β_(x₂))…α_(w_(n−1))(β_(x_n))`, with cumulative weights `w_k=g_(x₁)P_(λ_(x₁),i_(x₂))⋯g_(x_k)P_(λ_(x_k),i_(x_(k+1)))`. In the word abcacda, the weight before the second a is trivial because `t(abc)t(a)=t(a)`; the weight before the second c equals the weight before the first c because `t(abca)=t(a)` and `t(abc)=t(ac)` give `P_(λ_a,i_b)g_bP_(λ_b,i_c)=P_(λ_a,i_c)`; consequently the weights before d agree, and the weight before the last a is trivial in BOTH words because `t(abcd)t(a)=t(a)`. Setting `A=β_a`, `B=α_(w₁)(β_b)`, `C=α_(w₂)(β_c)`, `D'=α_(w₃)(β_d)`, the two band coordinates are `ABCD'A` and `ABCACD'A`, equal by SN. The actors agree because `t(abca)=t(a)` and `t(abc)=t(ac)`. Injectivity forces `abcda=abcacda`. □

The derivation only uses one SN instance with label-consistent letters; analogous certificates exist for any SN identity instance whose prefix actors coincide modulo ν'. No regularity, local-r or actual-q transport is used.

## 2. Intrinsic consequences inside any source

If t is any pure homomorphism onto a CS semigroup, the hypotheses make `m=abc`, `n=ac`, `P=abcd`, `Q=acd` idempotents, with m,n in one actor fibre and P,Q in one fibre, all in the actor ROW of a. With `e=aa'` (a'∈V(a)), `abcda=abcacda` is equivalent to `Pe=mQe`, and all of `e,m,n,P,Q,Pe,mQe` lie in the principal right ideal eR of the row band R. In ANY original source R is an SN band (purity makes row unions of idempotent fibres closed; local-r makes them locally regular), so eR is GLOBALREG. These facts did NOT yield a proof that original sources exclude the certificate: the needed relation passes through d, which is not in R.

## 3. Bounded searches (exploration only; programs pinned)

All sources below are regular subsemigroups of physical hosts over the non-SN band B5^1 (its only SN failures use the adjoined identity in the third slot), so WEU is automatic and local-r is checked as SN of every idempotent actor fibre (exact fibre formula).

- `frontier-20261029-SN-pattern-counterexample-search-v1.py`: ALL4096 actor quadruples over D8 for seeds `(u0,x,1,u1)`, trivial and swap actions: no hit. A separate replay found all512 D8-loop-consistent seeded sources regular but with a NON-SN fibre.
- `…-search-v2.py` (seed7, 420s): 26870 distinct randomly generated sources in four B5^1/dual/action configurations; 10312 regular, SN-fibred and nonorthodox; zero certificates.
- `…-search-v3.py` (seed11, 480s): 153376 seeded sources over `M[Z_k;I,L;P]`, k≤4, up to 3×3; NONE regular with SN fibres. A failure census of 245 cases showed every failure is a non-SN fibre containing ALL six B5^1 coordinates: the identity-coordinate letter generates a subgroup whose identity's corner absorbs u0,x,u1 after group-label correction by its powers.

The last mechanism explains these negatives but depends on completely regular identity-coordinate letters; it is not a theorem for arbitrary sources. A twisted non-completely-regular extension (`…-search-v4.py`) is being explored separately. Original Q1 remains OPEN.
