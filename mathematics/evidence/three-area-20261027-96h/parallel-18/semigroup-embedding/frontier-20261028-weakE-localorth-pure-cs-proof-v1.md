# A complete weak-E / locally-orthodox / pure-CS actor bridge

**Status: NEW SELF-CONTAINED AUTHOR WRITTEN RECONSTRUCTION; UNREVIEWED / UNADOPTED.** This supplies the source-class bridge without importing the historical SQ-E packet as an unexpanded premise. It uses the newly written least-CS congruence theorem and ordinary Rees–Suschkewitsch; it does not settle canonical band separation or original Q1. No novelty is claimed.

## 1. Exact theorem

Let S be a nonempty regular **locally orthodox** semigroup: for every idempotent f, the idempotents of fSf form a subsemigroup. Let ν be its least CS congruence and τ the syntactic idempotence-context congruence. The following are equivalent:

1. S is weakly E-unitary in the printed natural order: if an idempotent d satisfies `d=u a=a v` for possibly different idempotents u,v, then a is idempotent.
2. The least CS quotient map `S→S/ν` is idempotent-pure.
3. The actual syntactic quotient `S/τ` is completely simple (and its map is automatically pure).
4. There is an onto idempotent-pure homomorphism from S to some completely simple semigroup.

The theorem requires local **orthodoxy**, not the additional regular-band identity in the original locally-r subclass. This is a source-class assertion only, not a host existence theorem.

## 2. Consequences of the full weak-E condition

Assume 1. If `b³=b²`, put d=b². Then `d²=b⁴=b²=d` and `db=bd=d`, giving d≤b with the genuine idempotent witnesses d,d. Weak E-unitarity makes b idempotent.

Thus for arbitrary a,b∈S,

`ab∈E(S)  ⇔  ba∈E(S)`: if ab is idempotent, `(ba)³=b(ab)²a=b(ab)a=(ba)²`, and the preceding implication applies; interchange a,b for the reverse. This cyclic idempotence rule also applies when one factor is a formal absent identity, since then the two products coincide.

If f is idempotent and `fv=v`, cyclicity gives the support equivalence

`v∈E(S)  ⇔  vf∈E(S)`,                                 (2)

by applying the rule to f,v and using fv=v. This does not assume natural-order compatibility or cancellation.

In any local monoid fSf, its idempotents are left and right unitary. Indeed, if e∈E(fSf), a∈fSf and ea is idempotent, then ae is idempotent by cyclicity. Local orthodoxy makes `z=(ae)(ea)=aea` idempotent. Moreover `z=(ae)a=a(ea)`, so z≤a with the actual idempotent witnesses ae,ea. Weak E-unitarity makes a idempotent. The dual implication from ae∈E is the same argument. Only local orthodoxy, not global closure of E(S), is used.

## 3. Comparable idempotents have identical contexts

Let e,f∈E(S) satisfy `ef=fe=e`. For every z∈S¹ we prove

`ez∈E(S)  ⇔  fz∈E(S)`.                                 (3)

For the forward direction, suppose ez is idempotent. We have `f(ez)=ez`, so (2) gives ezf idempotent. Set `u=fzf∈fSf`; since e∈fSf and `eu=ezf` is idempotent, the local unitary-idempotent property from §2 gives u idempotent. Now v=fz satisfies fv=v and vf=u; (2) makes fz idempotent.

Conversely, suppose fz is idempotent. By (2), u=fzf is idempotent. Both e,u are idempotents of the orthodox local monoid fSf, so `eu=ezf` is idempotent. Put v=ez; it satisfies fv=v and vf=ezf. Again (2) makes ez idempotent. All equations remain valid for z=1.

For arbitrary x,y∈S¹, cyclicity gives `xey∈E iff eyx∈E`, and similarly for f. Apply (3) with z=yx to obtain `xey∈E iff xfy∈E`. Hence **e τ f for every comparable idempotent pair**.

## 4. Pure-CS conclusion and converses

By the independently unreviewed general proof in `frontier-20261028-least-cs-comparable-generators-v1.md`, SHA `627b0d397f9db81ede71b2eefdcd6b7e63772717e9c111576034a9aeef89857e`, ν is generated by those comparable-idempotent pairs. Section3 therefore gives `ν⊆τ`. A quotient of a regular semigroup by an idempotence-saturating congruence is pure: if [s]_ν is idempotent, take z inverse to s², so p=szs is idempotent in the same ν-class; s τ p and the empty context force s idempotent. Thus 1⇒2.

2⇒4 is immediate. If r:S→D is onto pure and D is CS, equal r-values have equal contextual idempotence truth values, so τ contains ker r. The quotient S/τ is a homomorphic image of D, hence CS, proving 4⇒3. The automatic purity of τ on regular sources is the same szs argument and is also written in `frontier-20261028-syntactic-purity-all-regular-v1.md`, SHA `20b839e181bc4fff3655cc22cf07675357c0e4ddedb2998fdd1949642d1c1714`; hence 3⇒4.

Finally 4⇒1 holds for EVERY regular S, without local orthodoxy: a natural-order witness d=u a=a v maps to `r(d)≤r(a)` in D. The natural order on a CS semigroup is equality (compare rows in `r(d)=r(u)r(a)` and use the cell idempotent identity), so r(a)=r(d) is idempotent and purity makes a idempotent. This completes all implications. □
