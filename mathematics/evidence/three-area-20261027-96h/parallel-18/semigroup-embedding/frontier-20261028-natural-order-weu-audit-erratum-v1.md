# Erratum: weak-E tests must use two idempotent witnesses

**MANDATORY ADDENDUM for the cited records; source conclusions below remain unreviewed.** I incorrectly treated `e≤s` for an idempotent e and arbitrary s as equivalent to `es=se=e`. In a regular semigroup the printed natural order is `a≤b` iff `a=eb=bf` for possibly DIFFERENT idempotents e,f; see <https://arxiv.org/pdf/1207.4296>, p.2. The simultaneous condition is sufficient but NOT necessary. This mistake caused my earlier live alert to Main about a supposed four-element SQ-E counterexample; that alert was immediately withdrawn and MUST NOT be used.

## 1. The false-alert control

For the multiplication table

```text
0 0 0 0
0 1 2 3
3 2 1 0
3 3 3 3
```

idempotents are {0,1,3}, and `0=0·2=2·3` exhibits 0≤2 while 2²=1≠2. Yet no idempotent e satisfies simultaneously e·2=2·e=e. Thus this semigroup is **not** weakly E-unitary; it is NOT a Q1/SQ-E counterexample. The first, erroneous run of `frontier-20261028-weakE-qCS-transformation-attack-v1.py` stopped at that false alarm. I repaired that unpinned script to test all two-idempotent witnesses and reran it: among 687 distinct transformation semigroups generated by at most3 maps on 3 points, 321 were regular and145 were weakly E-unitary; none of those145 had non-CS actual q. This finite check is not a universal proof. The corrected script SHA is `e110a7a60c4a9f0c9fe363858231dbb06158ef262632be6bd85686fa37151f32`.

Their actual checks of pure maps to the CS D8 actor, together with the preceding general argument, establish full WEU for those examples, but do NOT describe the direct assertion as an exhaustive printed-order check. Their Horn results are not affected.
* In `frontier-20261028-q1-finite-product-subsemigroup-v1.md`, SHA `8ee60ebf10ee69b6390b5b5e3299afaa2af2702f101bd62aa95a2bc809b2c790`, §3, the displayed proof that an idempotent below an arbitrary element in D satisfies `ex=xe=e` is invalid. Replace it with: in a CS Rees semigroup, if `a=e b=b f` for idempotents e,f, comparing rows forces e and b to have the same row, and then the Rees formula gives `eb=b`; hence a=b. Therefore the natural order on D is equality and D is weakly E-unitary. The class conclusion and its source A×D witness remain unchanged.
* The upper-cone result in `frontier-20261028-q2-upper-cone-weu-boundary-v1.md`, SHA `fb0f8f8ecaec11f3789c145a54b4e7cb1a2ea43291e96ced83017ff4a7eebc70`, uses `z(ef)=(ef)z=z` only as a SUFFICIENT witness for `z≤ef`, so the argument is unaffected. The non-WEU examples with explicit `ex=xe=e` witnesses remain valid for the same reason.
* Earlier exhaustive weak-E scripts using `({e s:e∈E} ∩ {s f:f∈E} ∩ E)` or an explicit `e=us=sv` with separate u,v are the correct full-order test; they are not implicated by the four scripts above.
