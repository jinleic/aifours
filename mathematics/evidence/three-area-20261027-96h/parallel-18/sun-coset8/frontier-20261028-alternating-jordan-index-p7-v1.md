# A Jordan-theorem conditional subgroup-index family

**Status: WRITTEN candidate, conditional on the named classical Jordan theorem; not independently reviewed, formally verified or accepted.** Let r>7 be prime, let 3≤t<r, put n=r+t and
\[D=\frac{n}{\gcd(n,t!)}.\]
If D>7, then A_n has no **three** proper subgroups with all pairwise index gcds at most 7. Consequently it has no direct P7 configuration; it also satisfies Sun8 for actual disjoint cosets at this restricted scope. ## 2. Every r-free proper subgroup is intransitive

Because r<n<2r, the r-part of |A_n| is r. If H<A_n has r-free index, H contains a Sylow r-subgroup generated by an r-cycle R; this cycle fixes exactly t≥3 points.

Suppose H is transitive. It is primitive: if it preserved a nontrivial block system with k≥2 blocks of size b≥2, then k≤n/2<r. The order-r element R acts on the k blocks, but no nontrivial permutation of fewer than r objects has order r, so R fixes each block setwise. Its r moved points lie in a single block; hence b≥r and n=kb≥2r, contradiction.

Jordan's theorem now gives H≥A_n because R is a prime cycle fixing t≥3 points. But H≤A_n, so H=A_n, contradicting properness. Therefore H is intransitive.

## 3. A common divisor of all r-free indices

Let U be the H-orbit containing the r moved points. It has size r+s for some 0≤s<t; its complement has size u=t−s with 1≤u≤t. The setwise stabilizer B=(S_U×S_(U^c))∩A_n has index C(n,u): S_U contains an odd permutation, so B has half the product order. Since H≤B, C(n,u) divides [A_n:H].

The identity u C(n,u)=n C(n−1,u−1) implies n/gcd(n,u) divides C(n,u). As u divides t!, gcd(n,u) divides gcd(n,t!), so
\[D=\frac n{\gcd(n,t!)}\mid\binom nu\mid[A_n:H].\]
Under the stated D>7 hypothesis, any two r-free proper-subgroup indices have gcd at least D>7. In a three-index pattern with pairwise gcd≤7, at most one index is divisible by r>7, leaving two r-free, contradiction.

For actual Sun8, a family of eight pairwise disjoint cosets cannot contain a coset of the whole group, so every underlying subgroup is proper. Any three of their indices already have a pair with gcd>7. The result is conditional only on the named Jordan theorem, not on an assumed Sun7 conclusion.
