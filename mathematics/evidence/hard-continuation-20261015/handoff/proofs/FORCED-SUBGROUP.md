## Setting

Under the imported premises (Kantor/CFSG, Thas–Zagier reduction, Feit's valid conditions), a
non-Desarguesian flag-transitive plane of order n > 8 gives a prime p = n²+n+1 such that
D = μ_(n+1) ⊂ F_p^* is a planar difference set. Planarity forces some elements into D:
2 (base-two lemma), every divisor of n (Feit), μ_3 (3 | n+1), and all products and inverses.
Call the subgroup they generate the **forced subgroup** K. The closure lemma of attack-e2 and its
S-unit generalizations are exactly arguments that find a coincidence x−y = z−w (x ≠ y,
(x,y) ≠ (z,w)) inside K. Such a coincidence contradicts planarity, so a collision inside K excludes
n even when K is not actually inside D.

Notation: a ≥ 1, N = 2^a, P = N²+N+1 (prime or not), ω = e^(2πi/3), R = Z[ω],
Nm(x+yω) = x²−xy+y² = |x+yω|², and T_a = {2^s ω^k : 0 ≤ s < a, k = 0,1,2}.

## Lemma 1 (reduction map)

φ : R → Z/PZ, ω ↦ N, is a surjective ring homomorphism with kernel πR, π = N−ω.

*Proof.* N²+N+1 ≡ 0 makes φ well defined, φ(π) = 0, φ(Z) = Z/PZ. The index [R : πR] equals
Nm(π) = P = |Z/PZ|, so πR = ker φ. Hence every nonzero element of ker φ has norm ≥ P. ∎

## Lemma 2 (the subgroup generated by 2)

φ maps T_a bijectively onto {2^i mod P : 0 ≤ i < 3a}, and 2 has order exactly 3a modulo P.

*Proof.* φ(2^s ω^k) = 2^(s+ka). For X ≠ X' in T_a, |X−X'| ≤ 2·2^(a−1) = N, so
0 < Nm(X−X') ≤ N² < P and X−X' ∉ ker φ. Finally 2^(3a) = N³ ≡ 1 since N³−1 = (N−1)P. ∎

## Theorem 3 (Sidon property)

For a ≥ 3, S_a = {2^i mod P : 0 ≤ i < 3a} is a Sidon set in Z/PZ: x+y ≡ z+w (mod P) with
x,y,z,w ∈ S_a implies {x,y} = {z,w}. For a = 2 it fails (P = 21: 2^0+2^5 ≡ 2^2+2^3).

*Proof.* Lift to X,Y,Z,W ∈ T_a and put E = X+Y−Z−W ∈ ker φ, so E = πE' with E' ∈ R.

**(a) Size.** |E| ≤ 4·2^(a−1) = 2N, so P·Nm(E') = Nm(E) ≤ 4N² < 4P. The values of Nm are
0, 1, 3, 4, 7, …, hence Nm(E') ∈ {0, 1, 3}.

**(b) Symmetry.** Call F representable if F = X+Y−Z−W with X,Y,Z,W ∈ T_a. Because ωT_a = T_a and
−(X+Y−Z−W) = Z+W−X−Y, the representable set is invariant under the six units μ_6.

**(c) Coordinates.** Writing A+Bω, the elements of T_a are 2^s(1,0), 2^s(0,1),
2^s(−1,−1) with 2^s ≤ N/2. Every representable F therefore has |A|, |B| ≤ 2N.

**(d) Nm(E') = 3.** Then E' is a unit times 1−ω, so by (b) π·ω(1−ω) is representable. But
π·ω(1−ω) = (N−ω)(1+2ω) = (N+2) + (2N+1)ω has B = 2N+1 > 2N, contradicting (c).

**(e) Nm(E') = 1.** By (b), π = N−ω itself is representable. Apply the real-linear map
L(z) = (2 Re z, (2/√3) Im z). On unit directions L(1) = (2,0), L(−ω²) = (1,1), L(ω) = (−1,1),
L(−1) = (−2,0), L(ω²) = (−1,−1), L(−ω) = (1,−1), and L(N−ω) = (2N+1, −1). The positive terms
X, Y point along 1, ω or ω²; the negative terms −Z, −W along −1, −ω or −ω²; all magnitudes are
powers of two at most N/2.

* First coordinate. A negative term contributes m (along −ω, −ω²) or −2m (along −1), so at most
  N in total. If at most one of X, Y points along 1, the positive terms contribute at most N−m < N
  and the total is below 2N+1. Hence X = m1 and Y = m2 are positive reals.
* Second coordinate (X, Y contribute 0). If both negative terms point along −1, it is 0 ≠ −1.
  If exactly one does, the other contributes ±m = −1, so m = 1 along −ω, and the first coordinate
  gives 2(m1+m2) + 1 − 2m' = 2N+1, i.e. m1+m2 = N+m' > N, impossible. If neither does,
  ±m3 ± m4 = −1 forces {m3,m4} = {1,2} (2 along −ω, 1 along −ω²), and the first coordinate gives
  m1+m2 = 2^a − 1. A sum of two powers of two has at most two binary ones, while 2^a−1 has a.
  So a ≤ 2.

**(f) Nm(E') = 0,** i.e. X+Y = Z+W in R. Let X = 2^(s1)ω^(k1), Y = 2^(s2)ω^(k2), s1 ≤ s2.

* X, Y parallel: X+Y is a positive multiple of a cube root of unity. If Z, W are parallel, the
  directions agree and 2^(s1)+2^(s2) = 2^(s3)+2^(s4) forces {s1,s2} = {s3,s4}. If Z, W are not
  parallel and s3 = s4, then Z+W = −2^(s3)·(third cube root) points along −μ_3, never along μ_3.
  If s3 < s4 (d = s4−s3), Nm(Z+W) = 4^(s3)(4^d−2^d+1) has odd part ≥ 3. Nm(X+Y) is 4^(s1+1) when
  s1 = s2 (odd part 1), or 4^(s1)(1+2^e)² with e = s2−s1 ≥ 1. Equality would need
  2^d(2^d−1) = 2^(e+1)(2^(e−1)+1): for e = 1 the right side is 8, impossible; for e ≥ 2 the
  2-adic valuations give d = e+1 and then 3·2^(e−1) = 2, impossible.
* Both pairs non-parallel: Nm(X+Y) = 4^(s1) if s1 = s2, else 4^(s1)(4^d−2^d+1); likewise for
  Z+W. Odd parts and powers of 4 must agree, and t ↦ 4^t−2^t+1 is strictly increasing, so
  |X| = |Z| and |Y| = |W| (after ordering). If s1 = s2, X+Y = Z+W = −2^(s1)·(third root)
  determines the pair of directions, so {X,Y} = {Z,W}. If s1 < s2, X−Z = W−Y with
  |X−Z| ∈ {0, √3·2^(s1)} and |W−Y| ∈ {0, √3·2^(s2)}, so both vanish.

Thus E ≠ 0 is impossible for a ≥ 3, and E = 0 forces {x,y} = {z,w}. ∎

## Corollary 4 (the obstruction)

Let n = 2^a with a ≥ 3, p = P prime, D = μ_(n+1). The divisors of n are powers of 2, and
μ_3 = {1, 2^a, 2^(2a)} because 2^a = n is a primitive cube root of unity mod p. So the forced
subgroup is K = ⟨2⟩, of order 3a, and by Theorem 3 it contains no nontrivial difference
coincidence. Consequently the closure lemma, its S-unit generalizations, and every collision test
confined to forced elements can never exclude an order n = 2^a, a ≥ 3.

For a = 3^t (the only exponents with p prime) the attack-e2 power-of-two lemma adds: base-two
and every divisor condition hold, n ≡ 8 (mod 24), and every prime factor of p is ≡ 1 (mod 6a).
So for each fixed sieve bound B, all t with 6·3^t+1 > B survive every one of the standard filters
(congruences, fixed sieve, base-two, divisor-multiplier conditions, forced-subgroup collisions).
Theorem 3 rules out exclusion certificates consisting of repeated nonzero differences inside the
specified forced subgroup. Further exclusions require additional information; the theorem does not
prescribe its form. Information of this kind that has excluded members so far:

* an explicit proper factor of p (attack-e2: t = 3,…,9);
* a Fermat compositeness witness for p (this lane: t = 10, `evidence/fermat-t10.json`);
* a collision involving **non-forced** elements of D, as for n = 512:
  89785 − 1 = 89788 − 4 with 89785, 89788 ∉ ⟨2⟩ (`code/certify.py` re-derives it).

Criteria that use all of D, such as the Thas–Zagier Gaussian-period criterion |ω_n|² = n, the
moment criterion of attack-e2, or Xia's characteristic-3 systems, are not affected by Theorem 3.

Note also that 2 is a Fermat liar for every p_t = Φ_(3^(t+1))(2): ord(2) = 3a divides n+1, which
divides p−1. Base-2 probable-prime tests cannot detect composite p_t; another base can.

## Remark 5 (the Desarguesian shadow)

For q = 2^a and θ primitive in F_(q³) with Tr_(F_(q³)/F_q)(θ) = 0, Singer's set
D_S = {i mod P : Tr(θ^i) = 0} is a planar difference set of PG(2,q) in Z/PZ. As Tr(x²) = Tr(x)²,
2D_S = D_S and 1 ∈ D_S, so ⟨2⟩ ⊂ D_S. Every consequence of "planar, contains ⟨2⟩, fixed by
multiplication by 2" therefore holds for an actual plane. What distinguishes the putative D is
multiplicative closure: D = μ_(n+1) is fixed by multiplication by each of its n+1 elements. For
a = 9, D_S is not: a multiplicatively closed (n+1)-subset of the cyclic group F_P^* containing 1 is
its unique subgroup of order n+1, but |D_S ∩ μ_513| = 27. (Classically the full multiplier group
of the Desarguesian Singer set is ⟨2⟩, of order 3a; not re-read here.) `code/structure.py` checks
a = 3 (D_S = μ_9 = ⟨2⟩, the classical PG(2,8)) and a = 9 (D_S planar, ⟨2⟩ ⊂ D_S,
|D_S ∩ μ_513| = 27, while μ_513 is not planar).

For general a ≥ 3 the existence of θ follows from Cohen's 1990 theorem on primitive elements with
prescribed trace: for extension degree 3 every trace value, including 0, is attained by a primitive
element except for F_64 over F_4 with trace 0, which is exactly the case a = 2. Read scope: the
parent read the statement as given in the official abstract of Cohen–Prešern (2005), *Primitive
finite field elements with prescribed trace*, Southeast Asian Bull. Math. 29(2), 283–300
(https://eprints.gla.ac.uk/13012/), and in the introduction of Cohen–Gupta, arXiv:1904.00443v1. No
proof was audited. Theorem 3 does not depend on this citation.

## Lemma 6 (minor elementary non-membership tests)

If D = μ_(n+1) is planar (so 2 ∈ D), then u−1 ∉ D ∪ (−D) for every u ∈ D \ {1, 2, 1/2}. In
particular −3 ∉ D.

*Proof.* If u−1 = d ∈ D, the pairs (u,1) and (2d,d) of D both have difference d, so u = 2d and
1 = d, i.e. u = 2. If u−1 = −d, the pairs (1,u) and (2d,d) give 1 = 2d and u = d = 1/2. For
−3: ω = n mod p lies in D and (1−ω)² = −3ω. As |D| is odd, x² ∈ D implies x ∈ ±D, and
1−ω ∉ ±D by the first part (ω ∉ {1, 2, 1/2} for p > 7). ∎

These tests involve non-forced elements (u−1), but each fails with heuristic probability about
2/n, and none excludes n = 512 (computed). They are recorded for completeness, not as progress.

## What a resolution needs

Theorem 3 rules out exclusion certificates consisting of repeated nonzero differences inside the
specified forced subgroup. Further exclusions require additional information; the theorem does not
prescribe its form. In particular it does not rule out a uniform arithmetic obstruction for the
whole family p_t = Φ_(3^(t+1))(2). A finite scan never covers all orders. [INFERENCE] A
random model with Pr(2 ∈ D) ≈ 2/n and Bateman–Horn density predicts about (c/24)·ln(ln Y / ln X)
base-two survivors with prime p in X < n < Y, c ≈ 3.4 (2.24 for n²+n+1, times 3/2 for the class):
about 0.013 for 2×10^11 < n < 2.6×10^12,
but unbounded as Y → ∞, so each survivor would still need its own exact elimination. Falsifier:
a proof that only finitely many n have 2^(n+1) ≡ 1 (mod n²+n+1) with n²+n+1 prime.
