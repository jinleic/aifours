56|## 3. Lemma SPLIT (proved here)
57|
58|Let M be a minimal zero-sum sequence over C_n and M' := M x^(-1) y z with y + z = x, y, z != 0, M' a minimal zero-sum
59|sequence.  Then ||M||_g <= ||M'||_g for every generator g; hence ||M'||_g = 1 implies ||M||_g = 1.
60|Proof.  |y|_g + |z|_g is a positive integer congruent to |x|_g modulo n, and |x|_g is the least positive integer in its
61|class, so |x|_g <= |y|_g + |z|_g; summing, n ||M||_g <= n ||M'||_g.  If n ||M'||_g = n, then n ||M||_g is a positive multiple
62|of n (M is a zero-sum of nonzero terms) that is <= n, so it equals n.  []

64|## 4. Parity check of both Xia-Yuan families at n = 2p (the only property of (I2) used)
65|
66|Claim P.  Every unsplittable minimal zero-sum sequence S of length p + 1 over C_(2p) that consists of odd elements is
67|g^p (pg) for a generator g, and has index 1.
68|Proof.  By (I2) (n = 2p even, floor(n/2) + 1 = p + 1), S belongs to one of the two families.
69|- Family A, (2g)^(p-1) (x_1 g) ((2p + 2 - x_1) g): the term 2g lies in 2C_(2p) for EVERY g (generator or not) and occurs
70|  p - 1 >= 4 times; so S contains an even element: excluded.
71|- Family B, g^t (pg) ((p + 1) g)^(2l) with t + 2l = p: (p + 1) g = 2 ((p + 1)/2) g lies in 2C_(2p) for every g; if l >= 1, S
72|  contains an even element: excluded.  If l = 0 (whether or not the elided conditions exclude it), S = g^p (pg).  All terms
73|  odd forces g odd; g = p would give S = p^(p+1), which contains the proper zero-sum p p: not minimal.  So g is a generator,
74|  and sum |.|_g = p * 1 + p = 2p: index 1.  []
