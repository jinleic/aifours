## 2. Lemma D-ROW (LFC at d)

Let P = {c in C : alpha_dc = 2} and p_alpha = |P|. Then 3 <= p_alpha <= 5. The same holds for alpha*.

*Proof.* At d, lambda_c = n_c alpha_dc / 3 = 2 * 5^(h_c) w_c alpha_dc and the weights are alpha_dc / 3. Since at most one
c has h_c >= 1, gcd(lambda_c, lambda_c') = 2 gcd(alpha_dc, alpha_dc') in {2, 4}. Hence allowed sets are: singletons,
pairs, and sets of size 3 or 4 with at most one element outside P (three or four elements need a pair of gcd >= 3,
i.e. two elements of P); no 5-set (gcds <= 4). In units of 1/3, LFC (d) at d says sum y_c alpha_dc < 3.
- p_alpha = 0: y = 1/2 (pairs only): 6 * 1/2 = 3. p_alpha = 1: still pairs only; y = 1/2: 5/2 + 1 = 7/2.
- p_alpha = 2: y = 1/2 outside P, 1/4 on P (3-sets {x, P, P} sum 1; no allowed 4-set): 4/2 + 2 * 2/4 = 3.
- p_alpha = 6: y = 1/4 (sets have size <= 4): 6 * 2/4 = 3.
Each contradicts LFC (d). QED
By INV (b) (alpha_dc + alpha*_dc <= 3), P and P* := {c : alpha*_dc = 2} are disjoint, so **|P| = |P*| = 3**; put
A := C \ P = {c : alpha_dc = 1} (|A| = 3).

## 3. Lemma C-ROW (LFC at v in C)

Let v in C.
- **(a)** If alpha_vd = 1, then k3 >= 3, or h_d >= 1 and alpha_vc = 5 for all five C-neighbours.
- **(b)** If alpha_vd = 2, then k3 = 0.

*Proof.* Weights not mentioned are 0; the R-classes of ROW-U are formed by the C-neighbours by the value of alpha_vc
(p, if present, behaves for gcds like an unmarked element of the same alpha except that it also shares 5 with fives;
it receives weight 0 unless stated). "Standard weights" means ROW-U's standard partial weights; any allowed set
through a weight-0 element has the same sum as without it.
- (a), k3 in {1, 2}: y = 1/k3 on the threes (value 3), y_d = 0. The >= 3 other C-neighbours: if an unmarked five exists,
  y = 1/k5 on unmarked fives adds 5; otherwise the unmarked others lie in R1 cup R24 (>= 2 of them). If p is not among
  them, standard weights add >= min(3, 4) = 3. If p is among them: alpha_vp = 1 or 5 makes lambda_p coprime to every
  other label (y_p = 1, adds >= 1, plus >= 2); alpha_vp in {2, 4} makes p gcd-equivalent to an unmarked element of R24
  (the 5-part meets no five), and standard weights on R1 cup R24 cup {p} add >= min(3, 4) = 3. Total >= 6.
- (a), k3 = 0: if h_d = 0, lambda_d = 3^(F_d) w_d alpha_vd is coprime to every C-label (no three, no 5 in it): y_d = 1
  gives 2 units, and the >= 4 unmarked C-neighbours give >= 4 (an unmarked five gives 5; otherwise min(N, 4)). If h_d >= 1
  (no p), the fives are compatible with d: 1 <= k5 <= 4 gives y = 1/k5 on fives (5) plus >= 1 from the rest; k5 = 0 makes d
  coprime to all (2 units + >= 4); leaving k5 = 5.
- (b), k3 in {1, 2}: as in (a) with y_d = 0: 3 + 3.
- (b), k3 >= 3: lambda_d = 2 * 3^(F_d) 5^(h_d) w_d. Put y = 1/3 on the threes and on d: an allowed set containing threes
  and d has all pairwise gcds 3 except possibly gcd(d, p) when p is a three... (p is a three only if alpha_vp = 3, and then

## 4. Proof of Theorem K63-E

Let v in A (alpha_vd = 1; alpha*_vd = 2 by INV (b)). If the second alternative of C-ROW (a) held, then alpha*_vc = 1 for
all five C-neighbours; in the inverted configuration their labels w_c (or 5^(h_c) w_c) are coprime to every other label,
and lambda*_d = 3^(F_d) 5^(h_d) w_d * 2 is coprime to them too: y = 1 on all six gives 5 + 4 = 9 units, contradicting LFC (d)
for the inverted configuration. Hence k3(v) >= 3: v has at least three C-neighbours u with alpha_vu = 3. For such u,
alpha_uv = 3, so u's C-row contains a three; by C-ROW (b), alpha_ud != 2, i.e. u in A. Thus every v in A has at least
three neighbours in A, so |A| >= 4, contradicting |A| = 3 (Lemma D-ROW). QED
