## 0. Setting and notation

Class K7: n_i = 6 r_i with r_i pairwise coprime; r_i = m_i w_i, m_i the {2,3,5}-part of r_i, gcd(w_i, 30) = 1. Vertex i
is unmarked iff m_i = 1. Hypothesis **U1**: exactly one vertex z is marked, with **m_z = 2^E 3^A 5^B, E, A, B >= 0
not all 0 (actual, unbounded exponents)**; W := V \ {z} (six unmarked vertices, n_u = 6 w_u). In K7 every g_ij = 6,
so every alpha_ij and alpha*_ij lies in {1,...,5} (E1) and alpha + alpha* <= 6 (INV (b), E7).

At an apex v the LFC label of a neighbour j is lambda_j = n_j alpha_vj / 6 = m_j w_j alpha_vj (LFC (a)); LFC (d) says
that every y >= 0 that sums to <= 1 on every lambda-allowed set satisfies sum_j y_j alpha_vj <= 6 (1 - 1/n_v) < 6.
"Allowed" is hereditary (every subset of an allowed set is allowed), and every pair inside an allowed set has
gcd >= 2.

**Gcd facts (G).** w_u is coprime to w_j (j != u) and to 30, and every alpha <= 5 has prime factors in {2,3,5}. Hence:
(G1) for unmarked j, j' != v: gcd(lambda_j, lambda_j') = gcd(alpha_vj, alpha_vj');
(G2) for v in W and u in W \ {v}: gcd(lambda_z, lambda_u) = gcd(m_z alpha_vz, alpha_vu), which **divides alpha_vu**;
(G3) at the apex z every neighbour is unmarked, so (G1) holds for all six neighbours of z.
m_z enters this file only through (G2) and through ell_z in section 3; no step depends on the size of E, A or B.

## 1. Lemma ROW-1* (LFC at an unmarked apex whose only marked neighbour z has an arbitrary marker product) [NEW]

Let v in W, and let k5, k3 be the numbers of u in W \ {v} with alpha_vu = 5, resp. 3. Then
- **(a)** k5 in {0, 5};
- **(b)** if k3 >= 1 then k3 >= 3, no alpha_vu (u in W \ {v}) equals 4 or 5, and alpha_vz in {1, 2}.

*Proof.* Split W \ {v} into R1, R24, R3, R5 by the value of alpha_vu (sizes k1, a + b with a twos and b fours, k3, k5).
By (G1) cross-class gcds are 1, so an allowed subset of W \ {v} of size >= 2 lies inside one class; ROW-U's class
analysis (accepted) gives the standard partial weights (R1: 1; R3: 1/min(3,k3); R5: 1/min(5,k5); R24: 1/2 on twos and
1/4 on fours if b <= 2, 0 on twos and 1/3 on fours if b = 3, 1/4 on all if b >= 4), each class-feasible, each nonempty
class contributing >= 1 to sum y alpha, R3 contributing 3 if 1 <= k3 <= 3 and k3 if k3 >= 3, R5 contributing 5 if
1 <= k5 <= 5, and N elements of R1 cup R24 contributing >= min(N, 4) (E8).

*Weights with y_z = 0 are feasible.* If y_z = 0 and y restricted to W \ {v} sums to <= 1 on every allowed subset of
W \ {v}, then for an allowed T, T \ {z} is allowed (hereditary) and sum_T y = sum_(T \ z) y <= 1. This does not
look at lambda_z, so it holds for every m_z.

(a) Suppose 1 <= k5 <= 4: y = 1/k5 on R5 (value 5), standard weights on the other 5 - k5 >= 1 elements (value >= 1),
y_z = 0. Total >= 6, contradicting LFC (d).

(b) Let k3 >= 1. Then k5 <= 4, so k5 = 0 by (a).
- k3 in {1, 2}: R3 contributes 3 (y = 1/k3); the >= 3 remaining elements lie in R1 cup R24 and contribute >= 3
  (E8); y_z = 0. Total >= 6. So k3 >= 3.
- Some alpha_vu = 4 with k3 = 3: the two remaining elements are {4, x}, x in {1, 2, 4}; standard weights give 4 + 1
  (x = 1), (4 + 2)/2 = 3 (x = 2), (4 + 4)/2 = 4 (x = 4); R3 contributes 3; y_z = 0. Total >= 6.
  With k3 = 4 the remaining element is the 4 (y = 1, contribution 4) and R3 (y = 1/3) contributes 4: total 8.
  With k3 = 5 there is no remaining element. So no entry 4 occurs (and no 5, as k5 = 0); the elements of W \ {v}
  outside R3 are ones and twos, at most two of them.
- Suppose alpha_vz in {3, 4, 5}. Weights: y = 1/3 on R3, y = 1 on R1, y = 1/2 on the twos, y_z = 1/3. Feasibility
  for an allowed T: if z not in T, T lies in one class: inside R3 |T| <= 3 (four pieces of pairwise gcd 3 are not
  allowed), R1 elements are singletons, at most two twos (three twos have pairwise gcd 2 < 3); sum <= 1. If z in T:
  by (G2) gcd(lambda_z, lambda_u) = 1 for u in R1, so T contains no R1 element; T \ {z} lies in one class; if it
  contains a two u, any further element u' is a two and {z, u, u'} has all gcds dividing 2 (G2), not allowed; so
  T = {z, u}, sum 1/3 + 1/2. If T \ {z} lies in R3, then |T \ {z}| <= 2, since {z, u1, u2, u3} has all gcds
  dividing 3 (G2) and is not allowed; sum <= 1/3 + 2/3 = 1. So y is feasible. Every element of W \ {v} contributes
  exactly 1 (1/3 * 3, 1 * 1, 1/2 * 2), so sum y alpha = 5 + alpha_vz / 3 >= 6, contradicting LFC (d).
  Hence alpha_vz in {1, 2}. QED

*Remark (scope).* ROW-1 (c) of K7-M1 is NOT claimed here for even m_z: with 2 | m_z and alpha_vu = 2, the pair
{z, u} is compatible even when alpha_vz is odd, so ROW-U-deg fails. Only (a) and (b) are used below.

## 2. Steps 0-2: the rows of z and the W-pairs

**Step 2 (no 3 on a W-pair, both orientations).** Let W3 := {v in W : alpha_vu = 3 for some u in W}. If v in W3 then

## 3. Lemma CROSS* (triangle facts for a in F*, b in F) [NEW in this scope]

For a in F*, b in F put x := alpha_ab and x* := alpha*_ab (both in {1, 2, 4} by section 2). Then:
- **(C1)** x in {2, 4} and x* in {2, 4}, and not x = x* = 4;
- **(C2)** if s_a = 1 then x = 4; if s*_b = 1 then x* = 4;
- **(C3)** X_a subset X_b (X_v := U_zU_v after normalising g_z = 1) whenever x s_a <= 4; for the inverted
  configuration, X*_b subset X*_a whenever x* s*_b <= 4.

*Proof.* Triangle {z, a, b} (L1): every g = 6 and gamma = lcm(6, 6) = 6 at each apex; ell_z = n_z / 6 = m_z w_z,
ell_a = w_a, ell_b = w_b. tau_min is the lcm of alpha_za / gcd(alpha_za, ell_b) = s_a, alpha_zb / gcd(4, w_a) = 4 and
x / gcd(x, m_z w_z), which divides x and hence divides 4 for x in {1, 2, 4}. So **tau_min = lcm(s_a, 4, .) = 4**
(s_a in {1, 2}), whatever E, A, B are. tau_max = min over apexes of gamma * (opposite alpha) * min(adjacent alphas) / 6:
apex z: x * min(s_a, 4) = x s_a; apex a: 4 * min(s_a, x); apex b: s_a * min(4, x).

| s_a | x = 1 | x = 2 | x = 4 |
|---|---|---|---|
| 1 | tau_max = 1 < 4: killed | tau_max = 2 < 4: killed | tau_max = 4: survives |
| 2 | tau_max = 2 < 4: killed | tau_max = 4: survives | tau_max = 8: survives |

Hence x in {2, 4}, and x = 4 when s_a = 1. The inverted configuration has the same indices (INV (a)), hence the same
ell's; its triangle {z, a, b} has alpha*_za = 4, alpha*_zb = s*_b, alpha*_ab = x*, i.e. the same table with the roles
of a and b exchanged (tau_min = lcm(4, s*_b, x*/gcd(x*, m_z w_z)) = 4; tau_max = min(x* s*_b, 4 min(s*_b, x*),
s*_b min(4, x*))). Hence x* in {2, 4} and x* = 4 when s*_b = 1. x = x* = 4 contradicts alpha + alpha* <= 6. This
gives (C1), (C2). (C3): (F7) at apex z with g_za = 6 = gamma_z reads tau_min * 6 >= 6 * x * s_a, i.e. x s_a <= 4, and
then X_a subset X_b; (F7) for the inverted configuration at apex z with the pair (b, a) reads 4 >= x* s*_b. QED

## 5. Theorem K7-U1 [NEW]

**No K7 configuration (in any group with finite-index subgroups, by R0) has exactly one marked vertex.**

*Proof.* Assume U1. Sections 2-4 apply. Four exhaustive types by the existence of a0 (s_a0 = 1) and b0 (s*_b0 = 1):

- **T4 (a0 and b0 exist).** (C2) gives alpha_a0b0 = 4 and alpha*_a0b0 = 4; contradiction with (C1).
- **T3 (b0 exists, s_a = 2 for all a in F*).** Take any a in F*. (C2) gives alpha*_ab0 = 4, so by (C1) alpha_ab0 = 2;
  x s_a = 4, so (C3) gives X_a subset X_b0, i.e. Y_b0 subset Y_a. The edge za is tight (2 + 4), so Y_a = D_a, and
  D_b0 subset Y_b0 subset D_a. D_b0 has measure 1/6 > 0 and is a union of right cosets; any right coset R inside it has
  {a, b0} subset S_R, contradicting (L2) (alpha*_zb0 = 1).
- **T2 (a0 exists, s*_b = 2 for all b in F).** Take any b in F. (C2) gives alpha_a0b = 4, so alpha*_a0b = 2 by (C1);
  x* s*_b = 4, so (C3) for the inverted configuration gives X*_b subset X*_a0, i.e. Y*_a0 subset Y*_b; zb is tight
  (4 + 2), so in the inverted configuration D*_b = Y*_b and D*_a0 subset Y*_a0 subset D*_b. D*_a0 has measure
  alpha_za0 / 6 = 1/6 > 0; a right coset of U*_z inside it has {a0, b} in its S-set, contradicting (L2*).
- **T1 (no a0, no b0).** All six edges at z are tight. Call b in F *in* if alpha_ab = 2 for some a in F*. Then (C3)
  (2 * 2 <= 4) gives X_a subset X_b, so D_b = Y_b subset Y_a = D_a; if D_b met D_b' (b' in F \ {b}) the
  intersection would contain a right coset R subset D_a with {a, b, b'} subset S_R, contradicting (L1). So D_b is
  disjoint from every other D_b'. If at most one b in F were not in, every pair from F would contain an in vertex and
  the three D_b (b in F), each of measure s*_b / 6 = 1/3, would be pairwise disjoint, giving measure 1 for their union,
  contrary to (L3). Hence at least two b in F are *out*: alpha_ab != 2, so alpha_ab = 4 by (C1), for every a in F*.
  The same argument in the inverted configuration (with (C3)*, (L1*), (L3*); its tight edges are the same) gives at
  least two a in F* with alpha*_ab = 4 for every b in F. For such a and such b, alpha_ab = alpha*_ab = 4, contradicting
  (C1).

Every type is impossible. QED
