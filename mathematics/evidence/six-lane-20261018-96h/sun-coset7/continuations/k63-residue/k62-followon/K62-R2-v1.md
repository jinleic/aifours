## 0. Statement
**Theorem K62-R2 [NEW].** No K6.2* configuration has e_d = 2, the 3-marker on a vertex t of O, and e* <= 3 (any
5-marker position, any other exponents; any group by R0). With the accepted K62-A, every K6.2* configuration with
e_d = 2 and e* <= 3 is excluded.

*Proof.* By Lemma D, (alpha_(d i*), alpha*_(d i*)) is (1,1), (1,3) or (3,1). (1,1) is excluded by Theorem R2-11
(`K62-FG-v1.md` section 4). If it is (1,3), pass to the inverted configuration (INV (a) with E6: same indices and
markers, alpha and alpha* exchanged), for which it is (3,1). So it suffices to exclude **alpha_(d i*) = 3,
alpha*_(d i*) = 1**; this is done in sections 1-3. QED

Throughout, f* = 1 (t carries the 3-marker), n_d = 4 * 5^(h_d) w_d, and "type" is the {2,3,5}-part of a label.
At i*, g = 6 to O and g = 4 to d; values are in units of 1/6 (d's weight x/4 is 3x/2 units).

## 1. Step A (LFC at i*, alpha-orientation): at least three vertices of O minus {t} carry alpha_(i* c) = 3, or 5 with h_d >= 1
At i* the labels are lambda_d = n_d * 3/4 = 3 * 5^(h_d) w_d (weight 3/4: 9/2 units) and, for c in O minus {t},
lambda_c = n_c alpha_(i* c) / 6 = 5^(h_c) w_c alpha_(i* c) (f_c = 1). Such a c is incompatible with d iff
alpha_(i* c) != 3 and not (h_d >= 1 and alpha_(i* c) = 5) (a common 5 needs h_d >= 1, which forces h_c = 0).
Suppose two such c, c' exist. Put y_d = 1; if c, c' are incompatible put y_c = y_c' = 1, otherwise (they share 2 or
5, so the larger of their two values is >= 2) put y = 1 on the larger and 0 on the other; all else 0. Every allowed
set meets {d} or {c, c'} only (Sun(2)), so y is feasible, and val >= 9/2 + 2 > 6, contradicting LFC (d) at i*.
Hence the set S := {c in O minus {t} : alpha_(i* c) = 3, or h_d >= 1 and alpha_(i* c) = 5} has **|S| >= 3**. For c in S,
INV (b) gives **alpha*_(i* c) <= 3**, and alpha*_(i* c) = 1 when alpha_(i* c) = 5.

## 2. Step B (VFC at i*, alpha*-orientation, with an improved bound when e* <= 3)
Normalise g_(i*) = 1 and let W = intersection of U_j over j in O cup {d}, T = [G : W]. Add the vertices in the order d, t,
p (if p in O, p != t), then the rest of O. With T_m the running index, T_(m+1) = lcm(n_e, T_m) k, and by L0.1 with
Lagrange k <= gcd(n_e, T_m) * mu(U_eU_d) = gcd(n_e, T_m)/2 (alpha_ed = 1, g_ed = 2):
- t: gcd(n_t, n_d) = 2 (one 5-marker), so k = 1;
- p: gcd(n_p, lcm(n_d, n_t)) = 6 (no 5 in n_d, n_t when p is marked), so k <= 3;
- an unmarked e: gcd(6 w_e, T_m) divides 6 (w_e is coprime to T_m by induction), so k <= 3.
Hence the prime-to-30 part of T is the product of the w_j (j != i*), and 5 does not divide T when i* is 5-marked.
So gcd(n_(i*), T) = 2^(min(e*, v2(T))) * 3 <= 2^(e*) * 3 <= 24 for e* <= 3, and by L0.1 with Lagrange
mu(U_(i*) W) >= 1/24. U_(i*) W lies in every U_(i*)U_j, hence is disjoint from every D_j = U_(i*) g_j U_j (V1), and the
VFC count with INV (b) (mu(D_j) = alpha*_(i* j)/g_(i* j), labels lambda*_j = n_j alpha*_(i* j)/g_(i* j)) gives, for every
lambda*-feasible y,

  val*(y) := sum over c in O of y_c alpha*_(i* c) + (3/2) y_d  <=  6 (1 - 1/24) = 23/4.        (B)

## 3. Step C: some lambda*-feasible y has val*(y) >= 35/6 > 23/4
Write z_c = alpha*_(i* c). Types at i*: c in O minus {t}: 5^(h_c) z_c; t: 3^(F_t) 5^(h_t) z_t (F_t = f_t - 1 >= 1);
d: 5^(h_d) (alpha*_(d i*) = 1, e_d = 2), load 3/2. Facts: (G1) d is compatible with c in O iff h_d >= 1 and z_c = 5;
(G2) two vertices of O minus {t} share 2 iff both z are even, 3 iff both z = 3, 5 iff 5 divides both types (z = 5, or
the vertex is p); (G3) t shares 3 with c iff z_c = 3, 2 iff z_c and z_t are even, 5 iff 5 divides both types. By Step A,
|S| >= 3 and z_c <= 3 on S. Let T3 = {c in O minus {t} : z_c = 3}, k3 = |T3|.

**Case I: k3 = 0** (so z_c in {1, 2} on S).
- I.1 (no z_c = 5, including c = t): no type shares a 5 with another (a marker is shared only with a five), so d is
  isolated: y_d = 1 (3/2). If z_t = 3, t shares nothing with O minus {t}: y_t = 1 (3), and standard weights on S give
  >= 3: val* >= 15/2. Otherwise all z lie in {1, 2, 4}, at most two equal 4 (t and the vertex outside S), and the label
  gcds equal the z-gcds (t's 3 and p's 5 meet nothing): standard weights give 5, so val* >= 13/2.
- I.2 (some five; only t or the vertex r outside S can be one): pick s in S minus {p} (|S| >= 3); type(s) = z_s in
  {1, 2} shares nothing with a five. y = 1/|F5| on the fives, y_s = 1: val* >= 5 + 1.

**Case II: k3 >= 1.** K := T3 cup {t}.
- **II.1 (generic: not [p in T3 and z_t = 5]).** All pairwise gcds inside K equal 3 (a three's type is 3 * 5^(h);

  - k3 = 4: y = 1/3 on K (value 4 + z_t/3). d meets only t, and only if h_d >= 1 and z_t = 5; put y_d = 1 otherwise and
    y_d = 2/3 then (sets through d: {d}, {d, t}). val* >= 4 + 1/3 + 3/2 = 35/6, resp. 4 + 5/3 + 1.
  - k3 = 3, O minus K = {r}: if r meets nothing of K cup {d}: y = 1/3 on K, y_r = 1, y_d as before:
    val* >= 3 + 1/3 + 1 + 3/2 = 35/6. If r meets t (both even, or both 5-divisible) but no three: if d is isolated,
    y = 1/3 on K, y_r = 2/3 (sets through r: {r}, {r, t}), y_d = 1: val* >= 3 + 1/3 + 2/3 * 2 + 3/2 > 35/6 when r and t
    share 2 (z_r >= 2), and if they share 5 with z_r = 1 (r = p, z_t = 5) then 3 + 5/3 + 2/3 + 3/2 > 35/6; if d is not

    three, y = 1 on that five, y_d = 1: val* >= 3 + 5 + 3/2.
  - k3 = 1: y = 1 on the three (3), y_t = 0, standard weights on the three vertices outside K (>= 3; a five gives 5):

  - k3 = 4: val* = 3 + 5/3 + 3/2 > 35/6. k3 = 3: r (outside K) has an unmarked type z_r; if z_r != 5 it meets nothing
