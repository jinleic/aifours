## 0. Notation and feasibility discipline
For a family x in {alpha, alpha*}, work with its configuration (the original if x = alpha, inverted if x = alpha*).
At i* put
- a_c := x_(i* c) for c in O, b_c := n_c / 6 = 3^(f_c - 1) 5^(h_c) w_c;
- K_x := {c in O : a_c in {1,2}};
- lambda_c := b_c a_c (c in O), lambda_d := n_d x_(i* d) / 4 (LFC (a));
- L_x(y) := sum over c in O of y_c a_c / 6 + y_d x_(i* d) / 4, so LFC (d) says L_x(y) < 1 for feasible y.
The b_c are odd and pairwise coprime (only t has a factor 3, at most one O-vertex has a factor 5, the w's are pairwise
coprime and prime to 30). Allowed sets are hereditary: if T is lambda-allowed then every subset of T is lambda-allowed.
Thus it is enough to check the positive-weight part of each allowed set. A label coprime to every other positive-weight
label is isolated on positive support (Sun(2)); half-weights on labels with pairwise gcd 2 are feasible because no allowed
set contains three of them (Sun(3)). A zero-weight label, in particular d, need not be coprime to the others.

## 1. Lemma B1 (four small entries are impossible; accepted imports only)
**For either family x in the setting above, |K_x| != 4.**

*Proof.* Suppose |K_x| = 4; write c_0 for the fifth O-vertex and k := a_(c_0) in {3,4,5} (E1). All certificates below
have y_d = 0, so no gcd with lambda_d is used.
- **k = 4.** Give y_c = 1 to the entries a_c = 1, y_c = 1/2 to the entries a_c = 2, and y_(c_0) = 1/2.
  - Each positive 1-label b_c is coprime to every other positive label: b's are pairwise coprime and the entries are
    powers of 2.
  - The other positive labels are 2 b_c and the single 4 b_(c_0); every pair has gcd 2, so there is no positive allowed
    triple. The certificate is feasible.
  - L_x(y) = 4/6 + (1/2)(4/6) = 1, contradicting LFC (d).
- **k = 3 or 5.** Among K_x, at most one vertex r can have a label with a common prime with lambda_(c_0): for k = 3 it
  can only be t (if t != c_0), and for k = 5 it can only be the 5-marked O-vertex p (if p != c_0). Pick r to be that
  vertex if it exists, and otherwise pick any r in K_x. Set y_(c_0) = 1, y_r = 0, y_c = 1/a_c for c in K_x minus {r}.
  - The c_0-label is coprime to every other positive label (k is odd; its only possible new shared odd prime was on r).
  - Of the other positive labels, the 1-labels are isolated and the 2-labels have pairwise gcd 2, so the certificate is
    feasible by the discipline above.
  - L_x(y) = k/6 + 3/6 >= 1, again contradicting LFC (d). QED

The proof uses only the O-labels at i*. It does not borrow any of the G-only row facts from DT-B.

## 2. Lemma B2 (the high distinguished-entry family has a gap; accepted imports only)
**In (1,3), |K_alpha*| != 5, hence |K_alpha*| <= 3 by B1.**

*Proof.* If K_alpha* = O, SH (ii) excludes a_c = 1 for c != t, so a_c = 2 for all four c in O minus {t}. In the inverted
configuration at i*, set y_d = 1/2, y_c = 1/2 for c in O minus {t}, y_t = 0. The five positive labels are
- lambda_d = 3 n_d / 4 = 2^(e_d - 2) * 3 * 5^(h_d) w_d;
- lambda_c = 2 b_c = 2 * 5^(h_c) w_c for c != t (f_c = 1).
Every pair has gcd exactly 2: the 2-parts are >= 4 at d and 2 at the other four; 3 occurs only at d; at most one vertex
carries 5; the w's are coprime. No positive allowed triple exists (Sun(3)), so the half-weights are feasible. Their value
is L_alpha*(y) = 4(1/2)(2/6) + (1/2)(3/4) = 2/3 + 3/8 = 25/24 > 1, contrary to LFC (d). QED

## 3. Lemma B3 (the low distinguished-entry family has a gap) [CONDITIONAL ON CAP/DT VERDICT]
**In (1,3), |K_alpha| != 5, hence |K_alpha| <= 3 by B1.**

*Proof.* Suppose K_alpha = O. In the original configuration at i*, set y_c = 1/a_c for c in O (1 for entries 1,
1/2 for entries 2), and y_d = 1/2. Here lambda_d = n_d/4 = 2^(e_d - 2) 5^(h_d) w_d has no factor 3.
- A positive 1-label b_c is coprime to every other positive label, including lambda_d: the b's are pairwise coprime,
  lambda_d has no factor 3, and c and d cannot both be 5-marked.
- The positive half-weight labels are the O-2-labels 2 b_c and lambda_d, with pairwise gcd exactly 2. So they admit no
  positive allowed triple (Sun(3)). The certificate is feasible.
- L_alpha(y) = 5/6 + (1/2)(1/4) = 23/24 > 11/12. This contradicts **(RC-i*)**, available for the alpha-row with the
  granularity of alpha* because f* = 1. No strict slack and no absolute index is used. QED

## 4. Consequences in the two orientations [CONDITIONAL ON CAP/DT VERDICT]
In (1,3), **|K_alpha| <= 3 and |K_alpha*| <= 3**. Consequently each i*-row has at least two O-entries >= 3. In particular,
- there are at least two vertices c in O with alpha_(i* c) >= 3, and for each such c, alpha*_(i* c) <= 3 (INV (b));
- for every v in O there is c_0 in O minus {v} with **alpha*_(i* c_0) <= 3**.
The analogous statement in (3,1) follows after exchanging alpha and alpha*.
