## 0. Setting
K6.2*: V = C disjoint-union {d}, C = {i*} disjoint-union O, |O| = 5; n_d = 2^(e_d) 5^(h_d) w_d (f_d = 0, e_d >= 2);
n_(i*) = 2^(e*) 3^(f*) 5^(h*) w_* (e* >= 2, f* >= 1); n_c = 2 * 3^(f_c) 5^(h_c) w_c (c in O, f_c >= 1); min(e_d, e*) = 2;
at most one vertex with f >= 2 (call it t if it lies in O), at most one with h >= 1 (call it p if it lies in O);
w's pairwise coprime and coprime to 30. gcds: 6 inside C, 4 for d-i*, 2 for d-c (c in O); so alpha_dc = alpha*_dc = 1
(c in O). For a vertex v and x in {alpha, alpha*}, LFC labels are lambda^x_j = n_j x_vj / g_vj.

**Theorem K62-E3 [NEW].** Every K6.2* configuration has **e_d >= 4** (hence e* = 2). Equivalently, no K6.2*
configuration has e_d in {2, 3}, in any group (R0).

## 1. Lemma 1 (the d-i* entry)
For x in {alpha, alpha*}, x_(d i*) != 2; and x_(d i*) = 3 only if t exists. Since alpha_(d i*) + alpha*_(d i*) <= 4
(INV (b)), **at least one of alpha_(d i*), alpha*_(d i*) equals 1.**

*Proof.* At d, lambda_c = n_c / 2 = 3^(f_c) 5^(h_c) w_c (c in O; odd) and lambda_(i*) = n_(i*) x / 4 =
2^(e* - 2) 3^(f*) 5^(h*) w_* x with x = x_(d i*) in {1, 2, 3}. Pairwise gcds: (c, c') gives 3^(min f) 5^(min h) = 3;
(c, i*) gives 3^(min(f_c, f* + v3 x)) * 5^(min(h_c, h* + v5 x)) = 3, except 9 when c = t and x = 3 (then f* = 1).
If all six labels have pairwise gcd 3, no fibre holds four pieces (LFC (c), Sun(4)), y = 1/3 on all six is
feasible, and LFC (d) gives 5/6 + x/12 < 1, i.e. x = 1. For alpha* apply this to the inverted configuration
(INV (a) with E6). QED

## 2. Lemma 2 (O-O entries at an O-vertex; plain LFC)
Let v in O, x in {alpha, alpha*}, u in O minus {v}. Then x_vu != 3; at most two u have x_vu = 1; and **if h_d >= 1,
x_vu != 5.**

*Proof* (orientation alpha; for alpha* use the inverted configuration). At v: lambda_u = 3^(f_u - 1) 5^(h_u) w_u x_vu,
lambda_(i*) = 2^(e* - 1) 3^(f* - 1) 5^(h*) w_* x_(v i*), lambda_d = n_d / 2 = 2^(e_d - 1) 5^(h_d) w_d with weight
x_vd / g_vd = 1/2. In units of 1/6, LFC (d) at v reads val(y) := sum_j y_j x_vj (6 / g_vj) < 6, d contributing 3 y_d.
- x_vu = 3: lambda_u is odd and shares no 5 with lambda_d (that would need h_u >= 1 and h_d >= 1). So u and d never
  share a fibre (Sun(2)); y_u = y_d = 1 (all else 0) is feasible and val = 3 + 3 = 6.
- Three entries 1: their labels 3^(f_u - 1) 5^(h_u) w_u are pairwise coprime (one 3-marker, one 5-marker) and coprime
  to lambda_d (odd parts share no 5 unless h_u, h_d >= 1). y = 1 on them and on d: val = 3 + 3 = 6.
- h_d >= 1 (so every C-vertex has h = 0) and F5 := {u : x_vu = 5} non-empty. (i) If some u' in O minus {v} is not
  in F5, then x_vu' is 1, 2 or 4 (not 3, above), and lambda_u' shares no prime with a five f: no 2 (lambda_f is odd),
  no 5, and a 3 would need f_u' >= 2 and f_f >= 2. So y = 1/|F5| on F5 and y_u' = 1 is feasible (sets of fives have
  sum <= 1 since |F5| <= 4): val >= 5 + 1. (ii) If F5 = O minus {v} and 5 does not divide x_(v i*): lambda_(i*) shares
  with a five f no 5 and no 2, and a 3 only if f = t and x_(v i*) = 3. Put y = 1/4 on F5 and y_(i*) = 1 if i* meets no
  five (val >= 5 + 1), y_(i*) = 3/4 if it meets t (val = 5 + 9/4); y_d = 0. Every allowed set has sum <= 1.
  (iii) If F5 = O minus {v} and x_(v i*) = 5: INV (b) gives x*_vu = 1 on the four fives, four entries 1 in the other
  orientation, excluded by the second item applied to it.
Each case contradicts val < 6. QED

## 3. Lemma 3 (the O-intersection index)
Normalise g_d = 1 and put U*_j = g_jU_jg_j^-1, W*_O = intersection of the U*_c (c in O), T*_O = [G : W*_O]. Then the
prime-to-30 part of T*_O is the product of the w_c (c in O); and if h_d >= 1 then 5 does not divide T*_O.
Consequently **gcd(n_d, T*_O) = 2^(min(e_d, v2(T*_O)))**.

*Proof.* beta_jk := [G : U*_j cap U*_k] / lcm(n_j, n_k) = alpha*_jk (INV), and 1 <= alpha* <= g - 1. Order O as: t,
then p (if p exists and p != t), then the remaining vertices, which have n_e = 6 w_e. With T_m the index of the
intersection of the first m groups: T_1 = n_(c_1); if two marked vertices start the order, T_2 = lcm(n_t, n_p)
alpha*_(tp). For each later e: T_(m+1) = lcm(n_e, T_m) k with k a positive integer (Lagrange), and by L0.1
k / gcd(n_e, T_m) = mu(U*_e W*_m) <= mu(U*_e U*_j) = alpha*_ej / 6 for any earlier j. By induction the prime-to-30
part of T_m is the product of the earlier w's, so gcd(n_e, T_m) = gcd(6 w_e, T_m) divides 6 and k <= alpha*_ej <= 5;
no prime > 5 enters. If h_d >= 1, no O-vertex is 5-marked and Lemma 2 gives alpha*_cc' in {1, 2, 4} on O, so the pair
factor alpha*_(c_1 c_2) and every k <= alpha*_ej <= 4 are prime to 5. Finally n_d = 2^(e_d) 5^(h_d) w_d has no 3, w_d is
prime to every w_c, and the 5-part of the gcd is trivial (h_d = 0, or 5 does not divide T*_O). QED

## 4. Proof of Theorem K62-E3
By Lemma 1 and INV (a) with E6 (the inverted configuration is again K6.2* with the same indices and markers, and its
alpha is our alpha*), we may assume **alpha_(d i*) = 1**. Normalise g_d = 1. Fibres are the n_d left cosets of U_d;
for a fibre F let S_F be the set of j != d with g_jU_j cap F non-empty.
1. *Counts.* By LFC (a)-(b), g_jU_j meets exactly t_j = n_d alpha_dj / g_dj fibres, none of them U_d:
   t_c = n_d / 2 (c in O), t_(i*) = n_d / 4. So the sum over fibres of |S_F| is 5 n_d / 2 + n_d / 4 = 11 n_d / 4.
2. *At most three pieces per fibre.* The labels lambda_c = n_c / 2 and lambda_(i*) = n_(i*) / 4 have pairwise gcd 3
   (computation of Lemma 1 with x = 1), so by LFC (c) and Sun(4), |S_F| <= 3.
3. *Light fibres.* The set W*_O U_d is a union of left U_d-cosets, contains U_d, and meets no
   L_c := g_cU_cU_d (c in O): if w u lies in L_c with w in W*_O, u in U_d, then w = g_c a g_c^-1 (a in U_c) lies in
   g_cU_cU_d, so a g_c^-1 lies in U_cU_d, so g_c^-1 lies in U_cU_d, i.e. g_c lies in U_dU_c, i.e. g_cU_c meets
   U_d = g_dU_d, contradicting disjointness. Hence every fibre F inside W*_O U_d has S_F contained in {i*}, and
   S_(U_d) is empty. Let M be the number of fibres inside W*_O U_d (M >= 1). Then
   11 n_d / 4 <= 3 (n_d - M) + (M - 1), i.e. **M < n_d / 8**.
4. *Granularity.* By L0.1 and Lagrange, M = n_d mu(W*_O U_d) = n_d mu(U_d W*_O) =
   [G : U_d cap W*_O] / T*_O >= n_d / gcd(n_d, T*_O). With Lemma 3: 2^(min(e_d, v2(T*_O))) = gcd(n_d, T*_O) > 8, so
   min(e_d, v2(T*_O)) >= 4. In particular **e_d >= 4**, and v2(T*_O) >= 4.
This holds in every finite group; R0 lifts it to arbitrary groups. QED

whenever F lies in W*_Q U_d (W*_Q = intersection of U*_c, c in Q; step 3 for Q in place of O). Writing

beta_4 + 2 beta_5 <= 1/4 - 1/n_d (the n_d/4 fibres met by g_(i*)U_(i*) have |B| >= 3, and U_d is another fibre

  (beta_4 + beta_5) n_d < n_d / 4; granularity as in step 4; the chain of Lemma 3 applies to Q).
