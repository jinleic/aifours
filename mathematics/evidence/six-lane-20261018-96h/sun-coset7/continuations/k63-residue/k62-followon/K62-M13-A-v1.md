## 1. Lemma A1 (fibre structure of Gamma* at d)
- **(a) Counts.** P*_c meets exactly n_d/2 fibres (c in O); P*_(i*) meets exactly 3 n_d / 4 fibres; none of them is U_d.
- **(b) Size.** |S*_F cap O| <= 3 for every F. Moreover |S*_F| <= 4, and |S*_F| = 4 only if {t, i*} is contained in
  S*_F.
- **(c) Complements.** For c in O: c is not in S*_F iff F lies in U_cU_d, a union of n_d/2 fibres. Likewise i* is not
  in S*_F iff F lies in U_(i*)U_d, a union of n_d/4 fibres.
- **(d) Counting facts.** sum over F of (|B*(F)| - 2) = n_d/2, every term is >= 0, and #{F : |B*(F)| >= 3} >= n_d/4 + 1.
- **(e) Four-piece fibres.** At least n_d/4 + 3 fibres have |S*_F| = 4; each of them contains t and i*.

*Proof.*
- **(a)** LFC (a)-(b) for Gamma* at d: t*_j = n_d alpha*_dj / g_dj, which is n_d/2 for c in O (alpha*_dc = 1, g = 2) and
  3 n_d / 4 for i* (g = 4).
- **(b)** By LFC (c) for Gamma*, S*_F is lambda*-allowed, with lambda*_c = n_c / 2 and lambda*_(i*) = 3 n_(i*) / 4. The
  gcd computation of accepted K62-E3 Lemma 1, with x = 3, gives:
  - all pairwise gcds of the six labels are 3, except gcd(lambda*_t, lambda*_(i*)) = 9 (f* = 1, f_t >= 2).
  A 4-subset T of S*_F must contain a pair with gcd >= 4 (Sun(4)), so T contains both t and i*. Hence S*_F cap O has at
  most 3 elements. If |S*_F| >= 5, some 4-subset omits t, which is impossible.
- **(c)** Let L*_j := P*_jU_d = U_jg_j^-1U_d. It is the union of the fibres meeting P*_j, of measure t*_j / n_d (LFC (b)).
  The set U_jU_d has measure [G : U_j cap U_d]/(n_j n_d) = alpha_dj / g_dj (L0.1). The two are disjoint (the argument of
  K62-E3 step 3, written out for Gamma* as in SH-DG erratum S2): if w u lies in L*_j with w in U_j and u in U_d, then
  w = a g_j^-1 b with a in U_j and b in U_d, so g_j^-1 = a^-1 w b^-1 lies in U_jU_d. Then g_j lies in U_dU_j, and g_jU_j
  meets U_d = g_dU_d, contradicting disjointness. The measures add to 1:
  - for c in O, 1/2 + 1/2;
  - for i*, 3/4 + 1/4, since alpha_(d i*) = 1.
  So U_jU_d = G minus L*_j, and U_jU_d is right U_d-invariant, i.e. a union of fibres (n_d/2 of them for c, n_d/4 for i*).
- **(d)** sum_F |B*(F)| = 5 (n_d - n_d/2) = 5 n_d / 2 by (a), so sum_F (|B*(F)| - 2) = n_d/2. Every term is >= 0 by (b).
  Put A := {F : i* in S*_F} (3 n_d / 4 fibres) and A_t := {F in A : t in S*_F}; then |A_t| <= n_d/2 by (a).
  - For F in A minus A_t, (b) gives |S*_F| <= 3, hence |S*_F cap O| <= 2 and |B*(F)| >= 3.
  - |A minus A_t| >= 3 n_d / 4 - n_d / 2 = n_d / 4.
  - U_d is not in A (S*_(U_d) is empty, LFC (b)) and |B*(U_d)| = 5.
- **(e)** Bound sum_F |S*_F cap O| = 5 n_d / 2 from above:
  - by 2 on A minus A_t;
  - by 2 + [|S*_F| = 4] on A_t;
  - by 3 off A, with U_d contributing 0.
  This gives 5 n_d / 2 <= 2 (3 n_d / 4) + N_4 + 3 (n_d / 4 - 1), where N_4 := #{F : |S*_F| = 4}, i.e.
  N_4 >= n_d / 4 + 3. QED

## 2. DG and C2 for the alpha-family in (1,3)
- **(DG-1\*)** For non-empty Q contained in O, N*(Q) is a positive multiple of n_d / 2^(min(e_d, v2 T_alpha(Q))).
  *Proof.* Apply DG-1 to Gamma*: DG-1 does not require alpha_(d i*) = 1 (parent verdict). The conjugated family of
  Gamma* is (U_j), so its intersection index for Q is T_alpha(Q), and its count N(Q) is N*(Q). QED
- **(DG-2\*)** Put A*_4 := #{F : |B*(F)| >= 4}. Then:
  - (i) N*(O) + A*_4 <= n_d/4 - 1;
  - (ii) the sum over 3-subsets R of O of N*(R) is <= n_d - 2 + 3 N*(O);
  - (iii) the sum over 4-subsets Q of O of N*(Q) is <= n_d/4 - 1 + 3 N*(O);
  - in particular N*(O) <= n_d/8 - 1/2.
  *Proof.* This is the proof of DG-2, with Lemma A1 (d) supplying its three counting facts. Write b_k := #{F : |B*(F)| = k}
  (k = 2, ..., 5). Then:
  - b_3 + 2 b_4 + 3 b_5 = n_d/2, b_5 = N*(O) and b_4 = A*_4 - N*(O);
  - b_3 + b_4 + b_5 >= n_d/4 + 1, so A*_4 + N*(O) = b_4 + 2 b_5 <= n_d/4 - 1, which is (i);
  - the sum in (ii) is b_3 + 4 b_4 + 10 b_5 = n_d/2 + 2 A*_4 + 5 N*(O), and the sum in (iii) is b_4 + 5 b_5 =
    A*_4 + 4 N*(O); insert (i);
  - the last claim is (i) with A*_4 >= N*(O). QED
- **(Theorem DG\*)** In (1,3), for the alpha-family, write r_S := min(e_d, v2 T_alpha(S)).
  - **(a)** If r_Q <= 4 for all five 4-subsets Q of O, then N*(O) <= n_d/16 and **the sum over the ten 3-subsets R of O of
    2^(-r_R) is <= 19/16 - 2/n_d**.
  - **(b)** Under the hypothesis of (a), at least two 3-subsets R have r_R >= 4, or exactly one does and it has r_R = 5.
    In the second case its alpha-values are (4,4,4), tau_alpha(R) = 16 and e_d >= 5. By DG-3 (G3 form, applied to
    Gamma*), every R with r_R >= 4 has alpha-values (2,4,4) or (4,4,4) and tau_alpha(R) in {8, 16}.
  *Proof.* This is the proof of Theorem DG with the G5/G6 corrections, with DG-1\* and DG-2\* in place of DG-1 and DG-2.
  - (a) Suppose N*(O) > n_d/16. Every 4-subset Q has N*(Q) >= N*(O) > n_d/16, and N*(Q) is a multiple of n_d/16
    (DG-1\* and the hypothesis; n_d/16 is an integer as e_d >= 4). So N*(Q) >= n_d/8, and DG-2\* (iii) gives
    5 n_d / 8 <= n_d/4 - 1 + 3 N*(O), i.e. N*(O) >= n_d/8 + 1/3, contradicting DG-2\*. Hence N*(O) <= n_d/16. Then
    DG-2\* (ii) together with N*(R) >= n_d 2^(-r_R) (DG-1\*) gives the sum bound.
  - (b) If no R has r_R >= 4, the sum is >= 10/8. If exactly one has it and r_R = 4, the sum is >= 9/8 + 1/16 = 19/16.
    Both exceed 19/16 - 2/n_d. Finally r_R <= 5 by DG-3. QED
- **(C2\*)** In (1,3), write n_k(alpha) := #{O-pairs with alpha = k}. Then **n_4(alpha) >= 2 n_1(alpha) + 2**.
  *Proof.* As in K62-E3 (C2). First,
  sum over O-pairs of N*({c, c'}) = sum_F C(|B*(F)|, 2) = b_2 + 3 b_3 + 6 b_4 + 10 b_5 = 2 n_d + b_4 + 3 b_5
    <= 2 n_d + (3/2)(A*_4 + N*(O)) <= 19 n_d / 8 - 3/2 (DG-2\* (i)).
  Second, N*({c, c'}) >= n_d / 2^(1 + v2 alpha_cc') by DG-1\*, since 1 + v2 alpha_cc' <= 3 < e_d, and alpha_cc' lies in
  {1, 2, 4} (accepted Lemma 2 and Z11 (a), for alpha). So 4 n_1 + 2 n_2 + n_4 < 19, i.e. <= 18; with
  n_1 + n_2 + n_4 = 10 this is n_4 >= 2 n_1 + 2. QED
- **(C1\*)** In (1,3): v2 T_alpha(Q) >= 3 for every 4-subset Q of O, and v2 T_alpha(O) >= 4.
  *Proof.* N*(Q) <= A*_4 <= n_d/4 - 1 < n_d/4 and N*(O) <= n_d/8 - 1/2 < n_d/8 (DG-2\*), while N*(Q) >= n_d / 2^(r_Q)
  (DG-1\*). So r_Q >= 3, and r_O >= 4. QED
