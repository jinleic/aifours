## 1. Setting

Class K6.3: V = C disjoint-union {d}, |C| = 6; for c in C, n_c = 6 r_c with r_c = m_c w_c, m_c = 2^(e_c - 1) 3^(f_c - 1)
5^(h_c); n_d = 3 r_d with r_d = 3^(f_d - 1) 5^(h_d) w_d odd (e_d = 0); all w's pairwise coprime and coprime to 30; g = 6
inside C and g_cd = 3. At most one vertex has e >= 2 (it lies in C; call it i*), at most one has f >= 2, at most one
has h >= 1. Since g_cd = 3, alpha_cd and alpha*_cd lie in {1, 2} and alpha_cd + alpha*_cd <= 3 (INV (b)); hence
**for every c in C, alpha_cd = 1 or alpha*_cd = 1.**
At a vertex v in C, LFC (a) gives the labels lambda_c = m_c w_c alpha_vc (c in C \ {v}, weight alpha_vc / 6) and
lambda_d = m_d w_d alpha_vd with m_d = 3^(f_d - 1) 5^(h_d) (weight alpha_vd / 3). In units of 1/6, LFC (d) reads
sum_c y_c alpha_vc + 2 y_d alpha_vd < 6. Write M_C for the set of marked vertices of C.

**Theorem K63-D [NEW].** There is no K6.3 configuration with f_d = 1 (d carries no 3-marker), in any group (R0).

*Strategy.* We exhibit one vertex v in C at which LFC excludes alpha_vd = 1. The inverted configuration has the same
labelled indices (INV (a), E6), so the same argument at the same v excludes alpha*_vd = 1, contradicting the bold line
above.

## 2. Case D0: d unmarked (f_d = 1, h_d = 0)

Then n_d = 3 w_d and every marker sits in C. If alpha_vd = 1, lambda_d = w_d is coprime to every other label, so d lies
only in {d} and y_d = 1 contributes 2 units; it suffices to show the C-part has value >= 4.

*Choice of v.* If |M_C| <= 1 take any v; if |M_C| = 2 take v in M_C; then v has at most one marked C-neighbour and at
least four unmarked ones. If |M_C| = 3, the three markers sit on three distinct vertices i* (2^E, E = e* - 1 >= 1),
t (3^F, F >= 1), p (5-marker only); take v = p.

*(a) v has at least four unmarked C-neighbours.* Put y = 0 on the marked C-neighbour (allowed sets through it have the
same sum as without it, by heredity) and ROW-U standard weights on the N >= 4 unmarked ones (their labels have
alpha-gcds). Their value is >= 5 if some alpha = 5; >= 3 + 1 if 1 <= k3 <= 3 (some other class is nonempty); >= k3 >= 4
if k3 >= 4; and >= min(N, 4) = 4 on R1 cup R24 (E8). Total >= 4 + 2 = 6.

*(b) v = p, neighbours i* (label 2^E w alpha_pi*), t (label 3^F w alpha_pt) and three unmarked u's.* All weights not
mentioned are 0; feasibility is checked on allowed sets through the positive-weight elements.
- (b1) some alpha_pu = 5: y = 1/k5 on the unmarked fives; value 5.
- (b2) no 5, 1 <= k3 <= 2: R3 value 3 plus >= 1 from the other unmarked (standard weights).
- (b3) k3 = 3 (all three u's are 3s, y = 1/3 each, value 3). If alpha_pt >= 3 put y_t = 1/3 (no allowed set contains t
  and three u's: {t,u,u',u''} would need a gcd >= 4, but all its gcds are 3): +alpha_pt/3 >= 1. If alpha_pt in {1,2}:
  * 3 does not divide alpha_pi* and alpha_pt = 1: i* is coprime to every other label; y_i* = 1 adds alpha_pi* >= 1.
  * 3 does not divide alpha_pi* and alpha_pt = 2: i* is compatible only with t; y_t = 1/3, y_i* = 2/3 (sets {t,u,u'}: 1,
    {t,i*}: 1; {t,i*,u} is not allowed since gcd(i*,u) = 1): +2/3 + (2/3) alpha_pi* >= 4/3.
  * alpha_pi* = 3, alpha_pt = 1: gcd(i*,t) = 3, so allowed sets through i* or t have size <= 3; y_t = y_i* = 1/3:
    +1/3 + 1 = 4/3.
  * alpha_pi* = 3, alpha_pt = 2: gcd(i*,t) = 6; {i*,t,u,u'} is allowed but no 5-set is ({i*,u,u',u''} has gcds 3 < 4);
    y_i* = 1/3, y_t = 0: +1.
- (b4) all three u's in R1 cup R24. If they contain three fours, standard weights give 4. Otherwise their standard value
  is 3 (each contributes 1) and we add >= 1:
  * (k1, a, b) = (2,1,0): y = 1 on the two, 0 on the marked: value 2 + 2 = 4. (2,0,1): y = 1 on the four: 6.
    (1,1,1): y = 1/2 on the two and on the four (only pairs are allowed among them): 1 + 1 + 2 = 4. (1,0,2): y = 1/2 on
    both fours: 5. (0,2,1): y = 1/2 on all three (pairs only): 4. (0,1,2): y = 1/2 on the fours, 0 on the two: 4.
  * (3,0,0): the u's are isolated (value 3); if i* and t are compatible (pair), y_i* = y_t = 1/2 adds
    (alpha_pi* + alpha_pt)/2 >= 1; otherwise both are isolated and add alpha_pi* + alpha_pt >= 2.
  * (1,2,0) and (0,3,0): twos with y = 1/2 (value 3). If t is coprime to every other label, y_t = 1 adds >= 1. If
    alpha_pt is even, y_t = 1/2 and y_i* = 0 (sets {two, t}: 1; {two, two', t} needs a gcd >= 3 and is not allowed;
    {two, i*, t}: 1/2 + 0 + 1/2): adds alpha_pt / 2 >= 1. If alpha_pt is odd and t is compatible with i* (3 | alpha_pi*):
    y_t = y_i* = 1/2 ({two, i*}: 1; {i*, t}: 1; {two, i*, t} is not allowed since gcd(two, t) = 1): adds
    (alpha_pi* + alpha_pt)/2 >= 2.
In every case the C-part value is >= 4, so with d's 2 units LFC (d) fails. QED (case D0)

## 3. Case D5: d carries the 5-marker but not the 3-marker (f_d = 1, h_d >= 1)

Then no C-vertex has h >= 1, M_C is contained in {i*, t}, and we choose v in C with at most one marked C-neighbour (any
v if |M_C| <= 1, v in M_C if |M_C| = 2). Let K5 = {c in C \ {v} : alpha_vc = 5}, k5 = |K5|.

**Step 1: alpha_vd = 1 forces k5 = 5.** With alpha_vd = 1, lambda_d = 5^(h_d) w_d, and a C-label is divisible by 5 iff
alpha_vc = 5 (no C-vertex carries 5). Let k5u be the number of unmarked elements of K5.
- k5 = 0: d is coprime to every other label; y_d = 1 (2 units) plus >= 4 from the >= 4 unmarked C-neighbours (as in
  section 2 (a)): 6.
- 1 <= k5 <= 4 and k5u >= 1: y = 1/k5u on the unmarked fives (value 5), 0 on d and on the marked neighbour, standard
  weights on the other unmarked neighbours; an unmarked five is compatible only with fives, d and a marked five, all
  of weight <= 1/k5u or 0, so feasibility holds. If some unmarked non-five exists it adds >= 1: total 6. Otherwise all
  unmarked C-neighbours are fives and the marked neighbour x has alpha_vx != 5 (else k5 = 5); its label m_x w_x alpha_vx
  (m_x a power of 2 or of 3) is coprime to every other label (fives, and lambda_d = 5^(h_d) w_d), so y_x = 1 adds >= 1.
- k5 = 1 and k5u = 0 (the marked neighbour is the only five): standard weights on the four unmarked (value >= 4),
  y_d = 1, y = 0 on the marked five (the only set through d besides {d} is {d, marked five}): 4 + 2 = 6.

**Step 2: k5 = 5 is impossible.** Then alpha*_vc = 1 for all c in C \ {v} (INV (b)). In the inverted configuration the
labels at v are w_c (unmarked c), m_c w_c (the marked neighbour, if any) and 5^(h_d) w_d alpha*_vd. Every unmarked c is
coprime to every other label (y = 1, 1 unit each). The marked neighbour c is compatible only with d, and only when
m_c is a power of 2 and alpha*_vd = 2: then y_c = y_d = 1/2 gives 1/2 + 2 units; otherwise y_c = 1 and y_d = 1 give
1 + 2 alpha*_vd >= 3 units. With at least four unmarked units the total is >= 4 + 1/2 + 2 > 6 (and >= 5 + 2 if v has no
marked neighbour), contradicting LFC (d) for the inverted configuration.

Hence alpha_vd = 2; the same argument for the inverted configuration (same v, same markers) gives alpha*_vd = 2,
contradicting alpha_vd + alpha*_vd <= 3. QED (case D5)
