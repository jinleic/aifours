## 1. Setting of the theorem

Exactly one vertex z is marked, and m_z = 3^a 5^b with a, b in {0, 1} after capping (a = 1 iff f_z >= 2, b = 1 iff
h_z >= 1; e_z = 1), not both 0. U := V \ {z} (six unmarked vertices). Only the {3,5}-part of m_z can enter a gcd, and
only through a label of a U-neighbour divisible by 3 or 5.

## 2. Lemma ROW-1 (LFC at an unmarked vertex whose only marked neighbour carries markers 3/5 only) [NEW]

Let v in U. Its neighbours are the five vertices of U \ {v} (labels w_u alpha_vu) and z (label m_z w_z alpha_vz). Write
k5, k3 for the numbers of u in U \ {v} with alpha_vu = 5, resp. 3. Then:
- **(a)** k5 in {0, 5};
- **(b)** if k3 >= 1, then k3 >= 3, no alpha_vu (u in U \ {v}) equals 4 or 5, and alpha_vz in {1, 2};
- **(c)** if alpha_vu in {1, 2, 4} for every u in U \ {v}, then the conclusions (i)-(iii) of ROW-U hold for the full
  row of v (z included): every entry lies in {1,2,4}, at most one entry is 1, and at least three entries equal 4.

*Proof.* Throughout, y is a weight vector; by LFC (d) every feasible y has sum_j y_j alpha_vj < 6 (units of 1/6). Classes
R1, R24, R3, R5 of U-neighbours are as in ROW-U; cross-class gcds are 1, so allowed sets of size >= 2 among
U-neighbours lie in one class. Whenever y_z = 0, a set T containing z satisfies sum_T y = sum_{T \ z} y and T \ z is
allowed, so the standard partial weights of ROW-U on the U-neighbours remain feasible.
- (a) Suppose 1 <= k5 <= 4. Put y = 1/k5 on R5 and y_z = 0: any allowed set meets R5 in at most k5 elements, so this
  is feasible, with value 5. The 5 - k5 >= 1 other U-neighbours carry standard weights, each nonempty class
  contributing >= 1. Total >= 6, contradiction.
- (b) Let k3 >= 1; then k5 <= 4, so k5 = 0 by (a). If k3 in {1, 2}: R3 has value 3 (y = 1/k3... = 1/min(3,k3)), and the
  >= 3 remaining U-neighbours lie in R1 cup R24 with value >= min(N, 4) >= 3 (erratum E8); total >= 6. So k3 >= 3.
  If moreover some alpha_vu = 4: for k3 = 3 the two remaining U-neighbours {4, x} have value 5 (x = 1: both alone),
  3 (x = 2: the pair, y = 1/2) or 4 (x = 4: the pair, y = 1/2); with R3's value 3 the total is >= 6. For k3 = 4 the
  remaining 4 is alone (y = 1, value 4); total 8. So no entry 4 (and none 5) occurs. Finally suppose alpha_vz not in
  {1,2}, i.e. alpha_vz in {3,4,5}. Put y = 1/3 on R3, y = 1 on remaining ones, y = 1/2 on remaining twos (at most two
  remain), y_z = 1/3. Feasibility: an allowed set containing z and two other elements needs a pair of gcd >= 3; z's
  label is m_z alpha_vz w_z, so with twos (label 2) the only pairs have gcd <= 2 and with 3-elements the gcd is 3, while
  any 4-set {z,3,3,3} would need a pair of gcd >= 4 (gcd(m_z alpha_vz, 3) <= 3); hence sets containing z are {z},
  {z, x} (sum <= 1/3 + 1/2), or {z, 3, 3} (sum 1); sets without z are as in ROW-U. Every U-neighbour contributes
  exactly 1 (3s: 3 * 1/3; ones: 1; twos: 2 * 1/2), so the value is 5 + alpha_vz / 3 >= 6. Contradiction.
- (c) All U-neighbour entries lie in {1,2,4}, so no U-label is divisible by 3 or 5 and
  gcd(lambda_z, lambda_u) = gcd(m_z alpha_vz, alpha_vu) = gcd(alpha_vz, alpha_vu) for every U-neighbour u. Hence every
  gcd among the six labels equals the gcd of the corresponding alphas, which is the only property of the labels that
  the proof of ROW-U uses (with alpha_vz <= 5). ROW-U's conclusions follow for the full row. QED

## 3. Theorem K7-M1 [NEW]

There is no K7 configuration (in any group with finite-index subgroups, by R0) with exactly one marked vertex z whose
markers lie in {3, 5} (e_z = 1).

*Proof.* (0) Every neighbour of z is unmarked, so ROW-U applies at z to alpha and, by INV (a) (the inverted
configuration has the same indices, hence the same unique marked vertex z), to alpha*. As alpha + alpha* <= 6 (INV (b)),
F := {u : alpha_zu = 4} and F* := {u : alpha*_zu = 4} are disjoint subsets of U of size >= 3, so |F| = |F*| = 3 and
U = F disjoint-union F*. For u in F*, alpha_zu in {1, 2} (ROW-U (i) at z).
(1) No alpha = 5 inside U. If alpha_vu = 5 for some v != u in U, ROW-1 (a) at v gives alpha_vu' = 5 for all u' in U \ {v},
and then at every u' the same; so alpha = 5 on all 15 pairs of U. By INV (b), alpha* = 1 on all pairs of U. Apply ROW-1
(c) to alpha* at any v in U (the U-entries 1 lie in {1,2,4}): the alpha*-row of v must contain at least three entries 4,
but only alpha*_vz can differ from 1. Contradiction.
(2) No alpha = 3 inside U. Let U3 := {v in U : alpha_vu = 3 for some u in U}. If v in U3 and alpha_vu = 3 then u in U3;
by ROW-1 (b) each v in U3 has at least three such u, so |U3| >= 4. Also by ROW-1 (b), alpha_vz in {1,2} for v in U3,
so U3 is disjoint from F (where alpha_zv = 4), i.e. U3 subset F*, |F*| = 3. Contradiction unless U3 is empty.
(3) Hence alpha_vu in {1,2,4} for all v != u in U, and ROW-1 (c) gives |A4(v)| >= 3 for every v in U, where
A4(v) := {j : alpha_vj = 4}; also |A4(z)| = 3 by (0). Steps (1)-(3) apply verbatim to the inverted configuration (same
z, same markers), giving |A4*(v)| >= 3 for all v. By INV (b), A4(v) and A4*(v) are disjoint subsets of the six
neighbours of v, so |A4(v)| = 3 for all seven vertices. The graph {ij : alpha_ij = 4} is then 3-regular on 7 vertices,
impossible (odd degree sum 21). QED

## 4. Scope and what remains

  K7-M0 this settles every K7 configuration in which at most one vertex is marked and no vertex has e >= 2.
