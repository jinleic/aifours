## 1. Setting and statement

Class K7: n_i = 6 r_i, r_i = m_i w_i (m_i the {2,3,5}-part, gcd(w_i, 30) = 1, r_i pairwise coprime). Hypothesis H:
some vertex z has e_z >= 2 (so m_z = 2^eps 5^(h_z), eps = e_z - 1 >= 1, h_z >= 0) and **no vertex has f >= 2**. Then at
most one further vertex p != z is marked, and m_p = 5^(h_p) (h_p >= 1), in which case h_z = 0.

**Theorem K7-Z2 [NEW].** No K7 configuration satisfies H. (By R0, in any group with finite-index subgroups.)

## 2. Lemma Z-ROW: the rows of z

The alpha-row and the alpha*-row of z satisfy the conclusions (i)-(iii) of ROW-U: entries in {1,2,4}, at most one
entry 1, at least three entries 4.

*Proof.* LFC at z uses only the labels of z's neighbours, lambda_j = m_j w_j alpha_zj. If no p != z exists, every
neighbour of z is unmarked and ROW-U applies; the inverted configuration has the same indices (INV (a)), so ROW-U
applies to alpha* too. If p != z exists, its only marker is 5. Apply ROW-1 at z (its proof uses only the neighbours'
labels, not z's own index): (a) the number k5 of unmarked neighbours u with alpha_zu = 5 is 0 or 5; (b) if some
unmarked alpha_zu = 3, then k3 >= 3, no unmarked entry is 4 or 5, and alpha_zp in {1,2}; here p is not 3-compatible
(lambda_p = 5^(h_p) w_p alpha_zp with alpha_zp in {1,2}), and the certificate of ROW-1 (b) improves to a kill: if
alpha_zp = 1, lambda_p is coprime to every other label, y_p = 1 adds 1 to the U-part value 5; if alpha_zp = 2, p lies
only in allowed sets inside R24 cup {p}, which here consists of p and the remaining twos (all labels with 2-part
exactly 2), so only pairs are allowed and y = 1/2 on R24 cup {p} adds alpha_zp / 2 = 1; either way the value is 6. So
k3 = 0. If k5 = 5, then alpha*_zu = 1 on those five neighbours (INV (b)); in the alpha*-row of z the five labels w_u are
coprime to every other label, as is lambda*_p = 5^(h_p) w_p alpha*_zp unless it shares a prime with another label,
which it cannot (the others are w_u); y = 1 on all six gives value 5 + alpha*_zp >= 6, contradicting LFC for alpha*.
So k5 = 0, the unmarked entries lie in {1,2,4}, and ROW-1 (c) gives the claim for alpha. The same argument applied to
the inverted configuration (same markers) gives it for alpha*. QED

## 3. The two sides F, F* and the four row types

Put N = V \ {z}, F = {v in N : alpha_zv = 4}, F* = {v in N : alpha*_zv = 4}. By Lemma Z-ROW and alpha + alpha* <= 6,
F and F* are disjoint of size >= 3, so |F| = |F*| = 3 and N = F disjoint-union F*. For a in F*: alpha*_za = 4 and
alpha_za =: s_a in {1,2}, with s_a = 1 for at most one a (call it a0). For b in F: alpha_zb = 4 and alpha*_zb =: s*_b in
{1,2}, with s*_b = 1 for at most one b (call it b0). An edge zv is *tight* if alpha_zv + alpha*_zv = 6.

## 4. Lemma CROSS (triangle facts for a in F*, b in F)

In the triangle {z, a, b} (rules-k7-v1 L1; g = gamma = 6 everywhere, ell_z = n_z / 6 = 2^eps 5^(h_z) w_z,
ell_a = m_a w_a, ell_b = m_b w_b with m_a, m_b in {1, 5^h}):
- (C1) alpha_ab in {2, 4} and alpha*_ab in {2, 4}; not both equal 4.
- (C2) if s_a = 1 then alpha_ab = 4; if s*_b = 1 then alpha*_ab = 4.
- (C3) tau_min(z, a, b) = 4 for the alpha-triangle, hence (F7) X_a subset X_b (X_v := U_zU_v after g_z = 1) whenever
  alpha_ab * s_a <= 4. The same holds for the alpha*-triangle of the inverted configuration with roles swapped:
  X*_b subset X*_a whenever alpha*_ab * s*_b <= 4.

*Proof.* alpha-triangle labels (alpha_za, alpha_zb, alpha_ab) = (s, 4, x). The tau_min terms are s / gcd(s, ell_b) = s,
4 / gcd(4, ell_a) = 4 (ell_a, ell_b odd), and x / gcd(x, ell_z) with gcd(x, ell_z) = 2^min(v2 x, eps) * 5^min(v5 x, h_z).
So tau_min = lcm(s, 4, x / gcd(x, ell_z)). tau_max = min(x * min(s,4), 4 * min(s,x), s * min(4,x)).
- s = 2: x = 1 gives tau_max = 2 < 4 <= tau_min; x = 3 gives tau_min = 12 > tau_max = 6; x = 2 gives tau_min = 4 =
  tau_max; x = 4 gives tau_min = 4 <= 8; x = 5 gives tau_min = 20 > 8 unless h_z >= 1, when tau_min = 4 <= 8.
- s = 1: tau_max = min(x, 4) and tau_min >= 4, so x >= 4; x = 5 needs h_z >= 1 (else tau_min = 20).
The same computation applies to the alpha*-triangle (4, s*, x*) (the inverted configuration has the same ell's).
If alpha_ab = 5 (possible only if h_z >= 1), then alpha*_ab <= 1, so alpha*_ab = 1, which the alpha*-computation forbids
(x* = 1 never survives). Symmetrically alpha*_ab != 5. Hence (C1) up to the last clause, which is alpha + alpha* <= 6
(INV (b)); (C2) is the s = 1 line. (C3): for x in {2, 4}, x / gcd(x, ell_z) divides 4, so tau_min = lcm(s, 4, .) = 4,
and (F7) at apex z (g_za = 6 = gamma) reads tau_min * 6 >= 6 * alpha_ab * alpha_za. QED

## 5. Lemma LIGHT (VFC at z) [NEW]

Normalise g_z = 1, put D_v = U_z g_v U_v, Y_v = G \ X_v. By (V1)/INV (b), D_v subset Y_v, mu(D_v) = alpha*_zv / 6,
mu(Y_v) = 1 - alpha_zv / 6; for a tight edge zv, D_v = Y_v (finite sets of equal measure). By (V3) with
q = alpha*, every right coset R of U_z has an allowed index set S_R = {v : R subset D_v} for the local indices
lambda*_v = alpha*_zv m_v w_v; since alpha* in {1,2,4} at z, gcd(lambda*_v, lambda*_v') = gcd(alpha*_zv, alpha*_zv').
Hence: (L1) for b != b' in F and a in F*, no allowed set contains {a, b, b'} (all three gcds are <= 2: Sun(3)); (L2) a
label with alpha*_zv = 1 is coprime to every other label (Sun(2)), so such v lies only in S_R = {v}.
The symmetric statements hold for the inverted configuration (q* = alpha, F and F* exchanged). By (V4), the union of
all D_v avoids U_z, so it has measure < 1.

## 6. Proof of Theorem K7-Z2

**Type T4 (a0 and b0 both exist).** By (C2), alpha_{a0 b0} = 4 and alpha*_{a0 b0} = 4, contradicting (C1).

**Type T3 (b0 exists, every s_a = 2).** Pick any a in F*. By (C2), alpha*_{a b0} = 4, so by (C1) alpha_{a b0} = 2.
By (C3) (s_a = 2, alpha_{a b0} = 2), X_a subset X_b0, hence Y_b0 subset Y_a. The edge za is tight (2 + 4), so
Y_a = D_a, and D_b0 subset Y_b0 subset D_a. Every right coset R subset D_b0 (D_b0 is non-empty: measure 1/6) has
{a, b0} subset S_R, contradicting (L2).

**Type T2 (a0 exists, every s*_b = 2).** The inverted configuration is of type T3 (INV (a), (b); F and F* exchange).

**Type T1 (all edges at z tight).** Call b in F *in* if alpha_ab = 2 for some a in F*. Then by (C3) X_a subset X_b,
so D_b = Y_b subset Y_a = D_a (both tight), and by (L1) D_b is disjoint from D_b' for every b' != b in F. If at most
one b is not in, the three sets D_b (b in F) are pairwise disjoint of measure 2/6 each, so the union of the D's has
measure >= 1, contradicting (V4). Hence at least two b in F are *out*: alpha_ab = 4 for all a in F* (by (C1)). Apply
the same argument to the inverted configuration (its F is our F*, its q is our alpha): at least two a in F* satisfy
alpha*_ab = 4 for all b in F. Take such an a and such a b: alpha_ab = alpha*_ab = 4, contradicting (C1). QED
