Proposed all-m extension (author derivation, 2026-10-14; to be independently reviewed).

For every rank-three GCM A=[[2,-p,-q],[-r,2,-s],[-t,-u,2]] with p,q,r,s,t,u positive integers, I_(m,1,1)=K_(m,1,1) for ALL integers m>=0. No novelty claim; this is still only an infinite root-degree subfamily, not all root degrees or the full conjecture.

Let E=ad a, a=e1,b=e2,c=e3, and v_i^(m)=[E^i b,E^(m-i)c], 0<=i<=m. These m+1 elements span L_(m,1,1): any bracket tree either splits the unique b and c between its branches (each one-special-letter branch is an a-string), or brackets a with a smaller mixed component; use E[v,w]=[Ev,w]+[v,Ew]. The multigraded Witt dimension equals m+1 (gcd(m,1,1)=1), so they form a basis.

The Serre ideal in this degree has basis precisely those v_i with i>p or m-i>q. Every such vector is in I because E^(p+1)b or E^(q+1)c is a Serre generator. Conversely, no other Serre generator can have multidegree <=(m,1,1): all other relations repeat b or c at least twice. Descendants of the two possible generators are formed using a and exactly one occurrence of the other special letter; their mixed basis indices remain in the forbidden ranges under E. Therefore quotient basis is i in [a_m,b_m]=[max(0,m-q),min(m,p)]. It is zero for m>p+q.

In this quotient D1 v_i^(m)=i(p-i+1)v_(i-1)^(m-1)+(m-i)(q-m+i+1)v_i^(m-1), with any forbidden/absent target basis vector zero. Also D2(v0)=(mr+s)E^m c, D2(v1)=-r E^m c, D2(vi)=0 for i>=2; D3(vm)=-(mt+u)E^m b, D3(v_(m-1))=t E^m b, and other D3 images zero.

Induct on m, using already-known rank-two Gabber–Kac equality for D2,D3 targets and previous m for D1. m=0 is rank two.

If m>q but m<=p+q, a_m=m-q>=1. D1 has independent columns: use target rows i-1 for source indices i=a_m,...,b_m; this is triangular with diagonal i(p-i+1)>0. The chosen rows lie in the allowed target interval [max(0,m-1-q),min(m-1,p)]. Hence D1 is injective.
If m<=q but m>p, then a_m=0,b_m=p<m. Use target rows i for source i=0,...,p. This is triangular with diagonal (m-i)(q-m+i+1)>0. Thus D1 injective.
The remaining range is 1<=m<=min(p,q). Domain i=0,...,m, target i=0,...,m-1. Bidiagonal positive coefficients give rank m and one-dimensional kernel. In a kernel vector z=sum z_i vi, z0 cannot be zero (successive equations force all coefficients zero). First target equation yields p*z1+m(q-m+1)*z0=0. Hence D2 z=[mr+s+r*m(q-m+1)/p]*z0 E^m c, nonzero because all parameters positive, z0 nonzero, and E^m c survives the rank-two quotient since m<=q. Thus joint kernel is zero in all cases; K/I=0.

Dimension conclusion: dim g(A)_(m,1,1)=max(0,min(m,p)-max(0,m-q)+1), and permutations. This includes the previous (1,1,1)/(2,1,1) formulas. Any additional positive relation for a fully connected rank3 GCM must therefore have at least two coefficients >=2 (support<=2 is already symmetrizable), so first unexcluded full-support patterns begin at height5, permutations of (2,2,1).

Potential gaps to challenge: ideal-descendant span characterization; circularity in using quotient D maps while assuming induction; triangular target intervals at endpoints; m=0 and p=q=1 boundaries; arbitrary brackets not just E descendants; reliance on rank-two theorem vs formula-derived nonvanishing. No computation has been used to assert this lemma.
