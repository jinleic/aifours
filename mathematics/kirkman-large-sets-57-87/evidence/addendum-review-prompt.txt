Claim A. If an involution g preserves both the block set and a chosen resolution of a KTS(v), and has f>=1 fixed points, then f divides v. Proof: its fixed points carry STS(f): the completing third point of any fixed pair is fixed. There are f(f-1)/6 blocks wholly fixed pointwise (zero if f1). Each transposition {x,gx} completes with a fixed point, so exactly(v-f)/2 further setwise fixed blocks have one fixed point and a transposed pair. These are all fixed blocks. Any fixed block belongs to a g-fixed parallel class, by uniqueness of its class in the resolution. In any fixed parallel class, the block through any fixed point is fixed. Counting fixed-point incidences over fixed blocks two ways, if c classes are fixed, gives cf = f(f-1)/2 + (v-f)/2. Thus 2cf=f^2-2f+v, and f|v. No conclusion without an invariant chosen resolution.
