称 X 上一码 C 是完备的，如果

∀w ∈ X*，X*wX* ∩ C* ≠ Φ.

称 X 上一有限码 C 具有有限完备化，如果它能被嵌入一有限完备码.

事实[1] 正则码（特别地，有限码）是完备的当且仅当它是极大的.

推翻“码交换等价于前缀码”猜测的那个非极大有限码的反例是 {a,b} 上的有限码[3,5]

C = b{1,a,a^7,a^13,a^14} ∪ {a^3,a^8}b{1,a^2,a^4,a^6} ∪ a^11b{1,a,a^2}.

问题 1[3] 上面的有限码 C 具有有限完备化（据事实 1，即有限极大化）吗？

这一问题与“有限极大码交换等价于有限极大前缀码”的猜测的联系在于，如果问题 1 的回答是正面的，那么“有限极大码交换等价于有限极大前缀码”的猜测就是错的.
