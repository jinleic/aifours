令 S 是一半群, T ⊆ S. 则 S 上下述二元关系 P(T)(R(T)) 是 S 上一同余 (右同余), 称为 S 上由 T 确定的主同余 (主右同余)：关于任意 x, y ∈ S,

xP(T)y ↔ F_T(x,y) = S¹ × S¹    (xR(T)y ↔ G_T(x,y) = S¹),

其中,
F_T(x,y) = {(u,v) ∈ S¹ × S¹ | uxv ∈ T ↔ uyv ∈ T}
(G_T(x,y) = {u ∈ S¹ | xu ∈ T ↔ yu ∈ T}).

称 T 是正则的, 如果 R(T) 在 S 上指数有限. 称 S¹ 的子集族 L 为 S¹ 上一左除性滤子 (左除性半滤子), 如果它们满足下面的左四条 (右三条)：

(i), S¹ ∈ L,                                  (i′), S¹ ∈ L,
(ii), A,B ∈ L → A ∩ B ∈ L,                    (ii′), A,B ∈ L → A * B ∈ L,
(iii), A ∈ L, A ⊆ B → B ∈ L,                  (iii′), A ∈ L, z ∈ S¹ → D_z A ∈ L.
(iv), A ∈ L, z ∈ S¹ → D_z A ∈ L.

其中, D_z A = {x ∈ S¹ | zx ∈ A}, A * B 是 A 与 B 的对称差的补, 即

A * B = [(A ∩ B^c) ∪ (A^c ∩ B)]^c.

显然, 左除性滤子是左除性半滤子.
定义 1[1] 令 S 是一半群, T ⊆ S, L 是 S¹ 上一左除性半滤子. 定义 R(T,L) 是 S 上下述二元关系：关于任意 x,y ∈ S,

xR(T,L)y ↔ G_T(x,y) ∈ L.

我们有下面的几个显然的事实：
(1) R(T,L) 是 S 上一右同余；
(2) {S¹} 是一左除性滤子, R(T) = R(T,{S¹}). 因此, 关于任意左除性半滤子 L, R(T,L) 是 R(T) 的加粗；
(3) C_{S¹} = {A ⊆ S¹ | A^c 有限} 是 S¹ 上一个滤子, 称为“余有限”滤子.
一般情况下, C_{S¹} = {A ∈ S¹ | A^c 有限} 不一定是一左除性滤子. 例如, 当 S 是一含零元 0 的无限半群时, A = S¹\{0} 是“余有限”的, 但 D₀A = {x ∈ S¹ | 0x ∈ A} 是空集, 当然不“余有限”.

记号 1 令 S 是一半群. 记 S¹ 上的左除性滤子 (半滤子) 的全体为 LDF_{S¹} (LDSF_{S¹}), 关于任意 L ∈ LDSF_{S¹}, 记 R_L = {T ⊆ S¹ | R(T,L) 的指数有限}.
问题 1[1] 令 X 是一有限集, X* 是 X 生成的自由幺半群 (称 X* 的子集为 X 上的语言), 则 C_{X*} ∈ LDF_{X*}. 问 R_{ {X*} } = R_{C_{X*}}? (等号左边是正则语言类).
下面的事实 1 从正面回答了问题 1, 它的证明使用的是由自由群 (见文献 [2]) 里移植过来的所谓 Schreier 方法.
事实 1[3] R_{ {X*} } = R_{C_{X*}}.
事实 1 实际上是用“余有限”左除性半滤子 C_{X*} 给出了正则语言类的一个新刻画. 于是下面的问题是自然的.

问题 2 寻找另外的 L ∈ LDF_{X*} (LDSF_{X*}), 使得 R_{ {X*} } = R_L.

更一般的, 我们有
问题 3 令 L₁,L₂ ∈ LDF_{X*} (LDSF_{X*}). 给出 R_{L₁} = R_{L₂} 的一个充分必要条件.

问题 4 在一般半群 S 中开展问题 1,2,3 的研究.
