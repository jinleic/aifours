## 1. Exact column-permutation orbit reduction

Write each n-by-m binary matrix as an ordered list of m n-bit columns. Apply an independent uniform permutation of all m column positions to every encoding, for either secret. This preserves every stacking weight and preserves equality of each forbidden ordered-matrix distribution. Hence existence implies existence of a scheme invariant under column permutations.

An orbit is represented uniquely by its nondecreasing column list `c`. For a forbidden F define `sigma_F(c)=sort(t & F for t in c)`. Under a uniform global column permutation, the ordered projected matrix is uniform on all distinct orderings of this projected multiset: each ordering has the same number of preimages in the permutation group. Different projected multisets have disjoint supports. Therefore equality of **distributions of the complete sigma_F(c)**, not merely their expected counts, is equivalent to equality of the full ordered F-row matrix distributions. It suffices to check maximal forbidden sets, since any smaller row restriction is a deterministic projection.

For fixed integer thresholds `t_Q in {1,...,m}`, one could give each orbit of each color a nonnegative probability, impose total mass1 for each color and equality of every projected-multiset probability, and retain only white orbits with `W_Q<t_Q` and black orbits with `W_Q>=t_Q` for every qualified Q. This finite rational feasibility system is complete. We do not claim that this restatement resolves the book problem; the actual result below is the concrete infeasibility certification of its six missing cases.

## 2. Necessary support filters, valid for arbitrary collections

All five instances have all participants essential and all singletons forbidden. The following filters discard no positive-probability encoding of a gap-at-least1 scheme:

1. Every white matrix has an all-zero column. The full participant set is qualified; otherwise its white stacking weight m cannot be separated from a black weight at most m.
2. Every maximal forbidden restriction of either color has an all-zero column. This is immediate for white; security transfers the entire restriction support to black.
3. Every row of either color has at least one black subpixel. For an essential participant i there are forbidden F and qualified F union {i}. Security supplies for each black B a white matrix agreeing on F, and contrast forces a column of B that is zero on F and one on i. Singleton security transfers nonzero row weight to white.
4. Every black B satisfies `W_Q(B)-W_F(B)>=1` whenever F is forbidden and F subset Q is qualified. The white matching B on F has Q-weight at least `W_F(B)`, and contrast separates that white matrix from B. This is the classical unavoidable-pattern argument of Ateniese et al. (1996), Lemmas5.7--5.11; those primary proofs were read. For gap1 this amounts to requiring at least one column from `{T: T intersects Q, T disjoint F}`. Keeping only inclusion-minimal such column-type sets is logically equivalent, since hitting a smaller set hits each containing set.

These filters are only necessary. No surviving orbit or SAT answer is treated as a construction.

## 8. General structural consequence: an indispensable participant

Let Gamma be any nonconstant strong access structure on n participants with the empty set forbidden. Its **cone** Gamma+ adds a new participant a and declares a set qualified exactly when it contains a and its old-participant part is qualified in Gamma. In particular the entire old participant set is forbidden in Gamma+. Write G_basis for the optimal integer gap at a fixed expansion, allowing gap0, and put G_basis(0)=0.

For every integer m>=0,

    G_basis,Gamma+(m) = G_basis,Gamma(floor(m/2)).

Also the globally maximum relative contrast, in either the basis or arbitrary-collection model, satisfies

    alpha*(Gamma+) = alpha*(Gamma)/2.

Proof. In a cone basis pair let d_(b,T) be the white-minus-black column multiplicity difference, with new row b in {0,1} and old black rows T. Security for the entire old participant set gives equality of every old projected column pattern, hence `d_(0,T)+d_(1,T)=0` for every T. Put delta_T=d_(0,T). The singleton {a} is forbidden, so sum_T delta_T=0. For any old subset S, the cone moment on {a} union S is exactly `sum_(T disjoint S) delta_T`. Thus delta is an admissible old difference vector with the same forbidden equalities and qualified gaps. Its minimum realization length is `L=sum max(delta_T,0)`. The minimum realization length of the cone difference vector `(delta,-delta)` is `sum |delta_T|=2L`; any common-column padding only increases actual length. Consequently a cone basis at m yields an old basis at L<=floor(m/2), and padding gives the upper inequality for G.

Conversely, given old basis column-count vectors x,y of length L, use cone white counts `(x,y)` in new-row blocks0,1, and cone black counts `(y,x)`. Old-only projections agree, and each projection containing a and an old forbidden set agrees separately in its new-row0/1 blocks. A qualified cone weight difference equals the old difference. This gives length2L and the same guaranteed gap; pad identically if m is odd. The stated G identity follows, including gap0.

The identity implies the basis contrast law: any cone ratio g/m is at most `(1/2) alpha*(Gamma)`, and doubling an attaining old scheme attains equality. The already proved concatenate-collections argument identifies the global alpha optimum in the collection and basis models separately for Gamma and Gamma+, so the same contrast law holds for arbitrary collections. This does **not** identify the fixed-length collection G functions: the extraction used the per-basis equality `d_(0,T)+d_(1,T)=0`, which arbitrary collections supply only in expectation. The last five-participant case is the cone of 2-out-of-4. Our full-distribution obstruction at7 is precisely what was needed beyond this general basis identity. The lemma is an independently derived structural observation, not a novelty-cleared theorem.

#!/usr/bin/env python3
"""Six full-distribution impossibility checks; standard library, no solver.

The original certificate package is input-only. See collection-continuation.md
for coverage and support-pruning proofs. Every arithmetic certificate is exact.
"""
import argparse
from collections import defaultdict
from copy import deepcopy
from fractions import Fraction as F
import hashlib
from itertools import combinations_with_replacement
import json
from pathlib import Path
import sys
import time


OBLIGATIONS = [
    ('n5-3-5-6-9-10-28', 5, True),
    ('n5-3-5-9-22-26-28', 6, True),
    ('n5-3-5-10-12-22-25', 5, True),
    ('n5-3-5-10-22-25-28', 6, True),
    ('n5-7-11-13-19-21-25', 6, True),
    ('n5-7-11-13-19-21-25', 7, False),
]


def partition(record):
    n = record['n']
    qualified = [s for s in range(1 << n)
                 if any(s & a == a for a in record['minimal_qualified'])]
    forbidden = [s for s in range(1 << n) if s not in qualified]
    maximal = [s for s in forbidden if not any(s != t and s & t == s for t in forbidden)]
    assert 0 in forbidden and (1 << n)-1 in qualified
    assert all((1 << i) in forbidden for i in range(n))
    assert all(any(f | (1 << i) in qualified for f in forbidden) for i in range(n))
    return qualified, forbidden, maximal


def signature(columns, forbidden):
    # The complete multiset is the orbit of an entire projected matrix.
    return tuple(sorted(t & forbidden for t in columns))


def weights(columns, n):
    return tuple(sum(bool(t & s) for t in columns) for s in range(1 << n))


def check_lp(record):
    q, forbidden, _ = partition(record)
    k = 1 << record['n']
    cert = record['lp']
    primal = list(map(F, cert['primal']))
    u = list(map(F, cert['dual_inequality']))
    v = list(map(F, cert['dual_equality']))
    alpha = F(cert['alpha'])
    assert len(primal) == 2*k+1 and len(u) == len(q) and len(v) == len(forbidden)+1
    assert all(x >= 0 for x in primal) and all(x <= 0 for x in u)
    assert sum(primal[:k]) == sum(primal[k:2*k]) == 1
    assert primal[-1] == alpha > 0
    for s in range(k):
        gap = sum((primal[t]-primal[k+t]) for t in range(k) if not t & s)
        assert gap == 0 if s in forbidden else gap >= alpha
    assert sum(u) <= -1
    assert v[0]+v[1] == -alpha
    slack = [[], []]
    for color in range(2):
        for t in range(k):
            lhs = v[color]
            lhs += sum(value * (1 if color else -1) for s, value in zip(q, u) if not t & s)
            lhs += sum(value * (-1 if color else 1)
                       for s, value in zip(forbidden[1:], v[2:]) if not t & s)
            assert lhs <= 0, 'Invalid exact dual column inequality'
            slack[color].append(-lhs)
    allowed = [[t for t in range(k) if slack[color][t] == 0] for color in range(2)]
    tight = [s for s, value in zip(q, u) if value < 0]
    return alpha, allowed, tight


def check_basis(record, witness):
    q, forbidden, _ = partition(record)
    columns = [tuple(t for t, count in enumerate(witness[color]) for _ in range(count))
               for color in ('white', 'black')]
    assert len(columns[0]) == len(columns[1]) == witness['m']
    assert all(signature(columns[0], f) == signature(columns[1], f) for f in forbidden)
    w, b = [weights(c, record['n']) for c in columns]
    assert min(b[s]-w[s] for s in q) == witness['gap'] >= 1


def enumerate_supports(record, m, allowed, use_face):
    n = record['n']
    q, forbidden, maximal = partition(record)
    k = 1 << n
    requirements = set()
    for s in q:
        for f in forbidden:
            if f & s == f:
                requirements.add(frozenset(t for t in range(k) if t & s and not t & f))
    minimal_requirements = sorted((x for x in requirements if not any(y < x for y in requirements)),
                                  key=lambda x: (len(x), tuple(sorted(x))))
    black = []
    for columns in combinations_with_replacement(allowed[1], m):
        present = set(columns)
        if any(not present.intersection(r) for r in minimal_requirements):
            continue
        if any(all(t & f for t in columns) for f in maximal):
            continue
        black.append((columns, weights(columns, n)))
    black_keys = [{signature(c, f) for c, _ in black} for f in maximal]
    white = []
    assert 0 in allowed[0]
    for tail in combinations_with_replacement(allowed[0], m-1):
        columns = (0,)+tail
        if use_face:
            if any(all(t & f for t in columns) for f in maximal):
                continue
            if any(all(not t & (1 << i) for t in columns) for i in range(n)):
                continue
        elif not all(signature(columns, f) in keys for f, keys in zip(maximal, black_keys)):
            continue
        white.append((columns, weights(columns, n)))
    return white, black, minimal_requirements


def prune_lists(white, black, qualified, maximal, tight):
    rounds = []
    while white and black:
        wg = [defaultdict(list) for _ in maximal]
        bg = [defaultdict(list) for _ in maximal]
        for group, support in ((wg, white), (bg, black)):
            for index, (columns, _) in enumerate(support):
                for d, f in zip(group, maximal):
                    d[signature(columns, f)].append(index)

        def compatible(w, b):
            return all(b[q] > w[q] for q in qualified) and all(b[q] == w[q]+1 for q in tight)

        nw = [(c, w) for c, w in white if all(
            any(compatible(w, black[j][1]) for j in d[signature(c, f)])
            for d, f in zip(bg, maximal))]
        nb = [(c, b) for c, b in black if all(
            any(compatible(white[i][1], b) for i in d[signature(c, f)])
            for d, f in zip(wg, maximal))]
        rounds.append([len(nw), len(nb)])
        if len(nw) == len(white) and len(nb) == len(black):
            return nw, nb, rounds
        white, black = nw, nb
    return white, black, rounds


def bits(mask):
    while mask:
        bit = mask & -mask
        yield bit.bit_length()-1
        mask -= bit


def check_separator(white, black, forbidden, m, separator):
    terms = separator['terms']
    for term in terms:
        assert term['forbidden'] in forbidden
        assert isinstance(term['coefficient'], int)
        pattern = term['signature']
        assert len(pattern) == m and pattern == sorted(pattern)
        assert all(t & term['forbidden'] == t for t in pattern)
    scores = [[sum(term['coefficient'] for term in terms
                   if signature(c, term['forbidden']) == tuple(term['signature']))
               for c, _ in support] for support in (white, black)]
    assert min(scores[0]) >= separator['white_score_lower']
    assert max(scores[1]) <= separator['black_score_upper']
    assert separator['white_score_lower'] > separator['black_score_upper']
    return scores


def threshold_tree(white, black, q, forbidden, maximal, m, separator):
    # Each edge records a full forbidden projected-matrix orbit, plus ALL Q.
    wedges = [[0]*len(white) for _ in maximal]
    bedges = [[0]*len(black) for _ in maximal]
    for index, f in enumerate(maximal):
        groups = defaultdict(list)
        for j, (c, _) in enumerate(black):
            groups[signature(c, f)].append(j)
        for i, (c, w) in enumerate(white):
            for j in groups[signature(c, f)]:
                b = black[j][1]
                if all(b[s] > w[s] for s in q):
                    wedges[index][i] |= 1 << j
                    bedges[index][j] |= 1 << i
    wcut = {s: {t: sum(1 << i for i, (_, w) in enumerate(white) if w[s] < t)
                for t in range(1, m+1)} for s in q}
    bcut = {s: {t: sum(1 << j for j, (_, b) in enumerate(black) if b[s] >= t)
                for t in range(1, m+1)} for s in q}
    stats = {'nodes': 0, 'empty_leaves': 0, 'separated_leaves': 0, 'max_depth': 0}
    leaves = []

    def visit(wmask, bmask, depth):
        stats['nodes'] += 1
        stats['max_depth'] = max(depth, stats['max_depth'])
        while wmask and bmask:
            nw = sum(1 << i for i in bits(wmask) if all(row[i] & bmask for row in wedges))
            nb = sum(1 << j for j in bits(bmask) if all(row[j] & wmask for row in bedges))
            if (nw, nb) == (wmask, bmask):
                break
            wmask, bmask = nw, nb
        node = {'white': wmask.bit_count(), 'black': bmask.bit_count()}
        if not wmask or not bmask:
            stats['empty_leaves'] += 1
            node['result'] = 'empty'
            return node
        ws, bs = list(bits(wmask)), list(bits(bmask))
        choices = []
        for s in q:
            if max(white[i][1][s] for i in ws) >= min(black[j][1][s] for j in bs):
                children = [(t, wmask & wcut[s][t], bmask & bcut[s][t]) for t in range(1, m+1)]
                viable = [(t, w, b) for t, w, b in children if w and b]
                score = max((w.bit_count()+b.bit_count() for _, w, b in viable), default=0)
                choices.append((score, len(viable), s, children))
        if not choices:
            lw = [white[i] for i in ws]
            lb = [black[j] for j in bs]
            scores = check_separator(lw, lb, forbidden, m, separator)
            leaf = {'white': [list(c) for c, _ in lw], 'black': [list(c) for c, _ in lb],
                    'scores': scores, 'thresholds': {str(s): max(w[s] for _, w in lw)+1 for s in q}}
            node.update(result='integer_separator', leaf=len(leaves))
            leaves.append(leaf)
            stats['separated_leaves'] += 1
            return node
        _, _, s, children = min(choices)
        node['qualified'] = s
        node['children'] = []
        for t, w, b in children:
            if w and b:
                assert (w, b) != (wmask, bmask), 'Threshold branch did not shrink support'
                child = visit(w, b, depth+1)
            else:
                # Still explicitly retain all thresholds, including immediately empty ones.
                child = {'white': w.bit_count(), 'black': b.bit_count(), 'result': 'empty_before_pruning'}
            node['children'].append({'threshold': t, 'node': child})
        return node

    tree = visit((1 << len(white))-1, (1 << len(black))-1, 0)
    assert stats['separated_leaves'] == 1
    return stats, tree, leaves


def controls(leaf, forbidden, m, separator):
    # Equal aggregate projected column counts are NOT equal matrix distributions.
    first = {(0, 0): F(1, 2), (1, 1): F(1, 2)}
    second = {(0, 1): F(1)}
    assert sum(sum(c)*p for c, p in first.items()) == sum(sum(c)*p for c, p in second.items())
    assert first != second
    bad = deepcopy(separator)
    for term in bad['terms']:
        term['coefficient'] = 0
    white = [(tuple(c), ()) for c in leaf['white']]
    black = [(tuple(c), ()) for c in leaf['black']]
    try:
        check_separator(white, black, forbidden, m, bad)
    except AssertionError:
        pass
    else:
        raise AssertionError('Zeroed separating functional was accepted')
    return ['first-moment-only security rejected', 'zeroed separator rejected']


def main():
