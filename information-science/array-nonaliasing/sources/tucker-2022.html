Abstract

Nonuniform array geometries provide freedom for increased aperture and reduced mutual coupling. A necessary and sufficient condition is given for an array of isotropic sensor elements to be unambiguous for any specified set of directions of arrival. The set of unambiguous spatial frequencies is shown to be a parallelepiped, admitting simple geometrical interpretation. Results are used in design of linear, planar, and 3D arrays.

Index Terms—: phase unwrapping, direction of arrival, planar array, nonuniform linear array, array design

I. Introduction

A necessary and sufficient condition is presented for an arbitrary sensor array to be alias-free. An array is said to be alias-free on some set ℬ of directions of arrival (DoAs) if array steering vectors are distinct for all DoAs in ℬ. Results apply to linear, planar, and 3D arrays and hold for any predefined subset of DoAs for which the array must be unambiguous. The results extend existing literature to provide simple geometrical interpretation for use in array design.

Four decades ago, Godara and Cantoni [1] presented a linear algebraic test for alias-free arrays in one, two, or three dimensions requiring, for L sensors, a combinatorial search over L-tuples of integers. For planar and 3D arrays, [1] also provides easily tested but restrictive sufficient conditions, requiring a smallest inter-sensor spacing not exceeding λ/2, where λ is the wavelength of the signal. The sufficient conditions have been widely used in design [2]–[4]. A slightly less restrictive sufficient condition for planar arrays is given in [5, Thm. 2].

Motivated by array design, alternative sufficient conditions have been devised for linear arrays. To avoid aliasing over the full range of azimuth angles, uniform linear arrays require an inter-sensor spacing that is no more than λ/2 [6]. It may be prohibitive to have two sensors within λ/2, due either to physical size limitations or mutual coupling. Nonuniform linear arrays allow for alias-free operation despite a minimum inter-sensor spacing that exceeds λ/2 [7]–[10]. A difference co-array is a virtual array with positions given by the pairwise differences of the physical sensor locations. Particular attention has been given to array geometries for which the co-array has uniform sampling and is fully filled, such as minimum redundancy arrays [11], nested arrays [12], and co-prime arrays [13]. Thinned arrays refer to the special case of a uniform array from which some elements have been removed. For a thinned linear array of L sensors with λ/2 spacing, a necessary and sufficient condition for no aliasing is given in [14]: for reference sensor at 0 and positions niλ/2, the integers {n2, …, nL} must have a greatest common divisor (gcd) of 1. Specialized to a nonuniform linear array of L = 3 sensors at positions {0 < x2 < x3}, [15] posits the sufficient condition that x3/x2 = m/n for co-prime integers m, n, with ∣n∣ > ⌊2x2/λ⌋ or ∣m∣ > ⌊2x3/λ⌋. Likewise for L = 3, [16], [17] establish the sufficient condition that the co-array contains a pair of positions not more than λ/2 apart.

A task very similar to array design arises in phase-contrast magnetic resonance imaging [18]–[22]. There, the velocity of spins at a voxel is encoded into image phase differences. Encoded images are acquired by adopting a time-varying gradient field, and the first moments of these waveforms are analogous to sensor positions. For velocity in one or several dimensions, unambiguous performance is required up to some maximum speed, such as 300 cm/s.

II. Signal Model

Consider data collected from an array with L sensors receiving a narrow-band signal from a single emitter located in the far field. The demodulated complex-valued L × 1 array output vector is given by

y(t)=a(ω)s(t)+ϵ(t),    t=1,…,T, (1)

where s(t)∈ℂ is the baseband complex amplitude of the impinging wavefront, T is the number of snapshots, a(ω)∈ℂL×1 is the array steering vector, ϵ(t)∈ℂL×1 is circularly symmetric Gaussian noise with zero mean and covariance ˙σ2I, and ϵ(t) is uncorrelated across snapshots.

For an array of isotropic sensors in d dimensions, the array steering vector is given by

a(ω)=[eiπp1⊤ωeiπp2⊤ω⋯eiπpL⊤ω]⊤, (2)

where i=−1, (·)⊺ denotes transpose, and the vector ω∈ℝd corresponds to the DoA of the impinging signal. The position vectors {p1, …, pL} describe the array geometry in units of one-half wavelength. For linear arrays, d = 1 and ω = sin θ, where θ is the azimuth angle of the source. For planar arrays, d = 2 and ω = [cos θ cos ϕ, sin θ cos ϕ]⊺, with ϕ denoting the elevation angle to the source. For general arrays, d = 3 and ω = [cos θ cos ϕ, sin θ cos ϕ, sin ϕ]⊺.

III. Periodic Lattice

A. Congruences and a lattice

For an array to be alias-free, the steering vectors in (2) must be distinct for distinct DoAs. Using the first sensor as a phase reference, the (L − 1) phase differences are π [pk − p1]⊺ ω, k = 2, …, L. So, we define the (L − 1)-by-d geometry matrix

P=π[(p2−p1),…,(pL−p1)]⊤, (3)

and assume rank(P) = d [1, Thm. 4]. Next, define ℬ as the set of arrival directions. For d = 1, the set ℬ1={ω∣θ∈[−π2,π2]} is the unit ball in ℝ, ‖ω‖ ≤ 1. For a planar array, d = 2 and the set ℬ2={ω∣θ∈[0,2π),ϕ∈[0,π2]} of all DoAs is the unit ball in ℝ2, ‖ω‖ ≤ 1. These DoAs correspond to source directions on source directions on the upper hemisphere. If, for the planar array, the source is constrained to lie in the plane of the sensors, then ℬ2′ is the unit circle in the plane. For a 3D array, d = 3 and the set ℬ3={ω∣θ∈[0,2π),ϕ∈[−π2,π2]} of all is DoAs is a sphere in ℝ3, {ω ∣ ‖ω‖ = 1}. These DoAs correspond source directions on the sphere. Note that ℬ may alternatively be defined as some subset of ℬd in d dimensions, for example, with prior knowledge restricting the range of possible DoAs [23].

Definition 1 (Alias-free on ℬ). An array with geometry matrix P is alias-free on ℬ if, for any ω1 ≠ ω2 ∈ ℬ,

P(ω1−ω2)≡0    mod 2π.

When considering the set of all directions of arrival, ℬ = ℬd and the array is simply said to be “alias-free.”

Thus, for aliases we consider the congruence equations

Pω≡0    mod 2π, (4)

which can be reformulated as

Pω=2πk, (5)

where k∈ℤL−1 is called a vector of wrapping integers. If (4) admits any nonzero solution, then all solutions make a periodic lattice Λ⊂ℝd [24]–[26],

Λ={ω∣Pω≡0    mod 2π}. (6)

A lattice is said to be nontrivial if there exist d linearly independent ωi, W = [ω1, …, ωd], such that PW ≡ 0 mod 2π.

Proposition 2. For array geometry P, there exists a nontrivial lattice of solutions to (4) if and only if P admits the factorization P = 2πZW−1 for invertible W and rank-d integer-valued (L − 1)-by-d matrix Z.

Proof. From (6), PW ≡ 0 mod 2π⇔12πPW=Z for some integer-valued Z∈ℤp×q⇔P=2πZW−1 by the invertibility of W. ⬜

Thus, a sufficient condition for a nontrivial lattice is that the sensor positions be placed on a Cartesian grid, such as might naturally happen in fabrication. For linear arrays, W becomes a scalar, w∈ℝ, so a 1D array has a nontrivial lattice if and only if the sensor displacements in (3) are all integer multiples of a common real-valued factor, 2/w. Note that if ω = 0 is the only solution to (4), then the lattice is trivial and the array is alias-free on all ℝd.

B. Parallelepiped

Given any solution ω⋆ to (4), the solution set of (4) is {ω⋆} + Λ, where + is Minkowski addition between sets of vectors. Suppose a nontrivial lattice exists. There exist d vectors v1, …, vd such that all lattice points ω ∈ Λ admit a unique representation [25]

ω=∑i=1dnivi,    ni∈ℤ. (7)

Let V=[v1,…,vd]∈ℝd×d, then V is called a basis for the lattice Λ. Following [25], for basis V we define the set

Ω={Vλ∣0⪯λ≺1}, (8)

as a fundamental parallelepiped of the lattice Λ, where ⪯, ≺ are elementwise ≤ and <. Ω contains no lattice points of Λ except for its vertices. This implies the partition:

∪ω∈Λ(Ω+{ω})=ℝd,    ∩ω∈Λ(Ω+{ω})=∅. (9)

Thus, the parallelepiped Ω is an unambiguous set for the congruence equations (4) specified by the array geometry P. For arrays with rational displacements between sensors, fundamental parallelepipeds may be readily constructed1 by searching a small range of integer-valued vectors in ℤ(L−1); the search is bounded by construction from Proposition 2.

For a given DoA ω0, let ϕ0 = Pω0 mod 2π = Pω0 − 2πk0 = ∠a(ω0) be the phases of the steering vector; k0 is the associated vector of wrapping integers. Let † denote matrix pseudo-inverse. The least-squares solution ω^=P†(ϕ0+2πk^) wrapped into Ω for k^≠k0 corresponds to a beampattern side-lobe.

IV. Necessary and Sufficient Condition

The displacements between sensor positions define P, which in turn defines a lattice Λ. From Definition 1, we immediately have:

Proposition 3. An array is alias-free on ℬ if and only if translations ℬ + ui and ℬ + uj are disjoint for all lattice points ui ≠ uj.

Specializing to the case of the full range of DoAs defined as ℬd above yields the following two corollaries.

Corollary 4. An array is alias-free if and only if the smallest norm of a non-zero lattice point is greater than 2.

Proof. Recall ℬd as defined in III-A: unit balls in ℝ and ℝ2 or the sphere in ℝ3. Let u1 = 0 by translation of the lattice, and let u2 ≠ u1 be a lattice point. Then, ℬ + u1 and ℬ + u2 have empty intersection if and only if ∥u1 − u2∥ > 2. ⬜

Corollary 5. An array with lattice basis V is alias-free if and only if the vertices of the parallelepiped defined by V are separated by more than 2.

Proof. Necessity: by Corollary 4, because vertices are lattice points. Sufficiency: the union of all 2d parallelepipeds of the shape Ω and having one vertex at the origin will guarantee cover of the nonzero lattice point with the smallest norm. By hypothesis, all non-zero vertices in this union have norm greater than 2; thus, by Corollary 4 the array is alias-free. ⬜

Godara and Cantoni [1, Thm. 6] provide an alternative necessary and sufficient test for alias-free on the full set of DoAs: the image of the unit ball under 12πP contains no integer point other than the origin. The test is applied by combinatorial search over k∈ℤL−1, with ‖k‖<12π‖P‖2. In contrast, construction of the lattice basis, V, provides for an easily tested necessary and sufficient condition for arbitrary ℬ. Specialization to the set of all possible directions of arrival in one or several dimensions is considered below.

A. Linear arrays

For d = 1, the fundamental parallelepiped, Ω, reduces to an interval and is unique. By the Chinese remainder theorem and Corollary 4, a linear array is alias-free if and only if

LCM(2(p2−p1),…,2(pL−p1))>2, (10)

where LCM(…) denotes the least common multiple, which is the smallest positive real number that is an integer multiple of all input numbers. For example, LCM(π3,π2,2π3)=2π. Equation (10) is an equivalent and alternative test to [1, Thm. 11]: there exists sensor separation less than or equal to λ/2, or for minimum spacing nα > λ/2 with integer n, there exists a third element such that its distance from any one of the two elements is not an integer multiple of α. The simplicity of (10) aids in design.

B. Nonlinear arrays

For planar or 3D arrays, the fundamental parallelepiped and basis are not unique. For any basis V, let C∈ℤd×(2d−1) with each column given by a d-digit binary representation from 1 to 2d − 1. Corollary 4 is equivalent to

mindiag(C⊤V⊤VC)>2. (11)

Equation (11) provides a simple necessary and sufficient test, in contrast to the widely used sufficient condition [1, Thm. 8].

C. Invariances and scaling

From (6), we see that the fundamental parallelepiped is invariant to translations, rotations, permutations, and reflections of the point set {p1, …, pL}. Further, a dilation or contraction of a point set by a scaling constant γ > 0 merely scales the lattice basis V by γ −1.

V. Examples

A. Linear array

In [8] a four-element linear array is proposed for meteor trajectory estimation with element positions given, in units of one-half wavelength, by {0, 4, 9, 40}. The array, an extension of an interferometric system in [7], is alias-free for the full range of azimuth angles. The application requires a minimum inter-sensor spacing much larger than λ/2 to limit the effects of mutual coupling. As an example, we design an alternative array configuration to minimize the Cramér-Rao lower bound (CRB) on estimation error variance subject to the constraints that the minimum inter-sensor spacing and peak side-lobe level meet those of the array in [8].

The source signal {s(t)} follows a zero-mean circularly symmetric Gaussian distribution with power ρ2 and is independently and identically distributed across snapshots, indexed by t [6], [27]. Under this model with T snapshots and L sensors, the CRB is given by (e.g., [28], [29])

CRB=L⋅snr+12π2TL2M snr2 (12)

where snr denotes the signal-to-noise ratio ρ2/σ2 and

M=1L∑k=1L(pk−1L∑n=1Lpn)2 (13)

is the moment of inertia.

For a 20 dB signal-to-noise ratio as in [7], the array in [8] has a CRB of 5.09 × 10−7 and a peak side-lobe level of 0.369 dB. Assuming that ∣θ∣ < 80° [8], we follow a design procedure similar to that in [21] to obtain the element locations 0.986 · {0, 5, 41, 78}. This new array configuration has a peak side-lobe level of 0.369 dB, a reduced CRB of 1.25 × 10−7, and from (10), an unambiguous interval for sin θ of 1.97.

Next, we interpret (10) for an arbitrary three-element linear array with rational positions. Without loss of generality, let p1 = 0 and (p2 − p1) ≤ (p3 − p2). Select co-prime integers m and n such that p3−p1p3−p2=mn∈(1,2]. Then, from (10) with ℬ = (−1, 1), the array is alias-free on ℬ if and only if

m−n(p2−p1)≥1. (14)

In [16], [17], [30], the co-array is constrained to have a pair of positions not more than λ/2 apart; from (14), this sufficient condition is not necessary, allowing additional design flexibility. If [−1, 1] is a strict subset of the unambiguous interval Ω, then the two end-fire DoAs, ± sin(π/2), are disambiguated.

B. Planar arrays

Consider a uniform circular array with L = 6 and one-wavelength spacing [31]–[33]. The lattice has basis V=diag({2,23/3}). Corollary 5 is violated, because vertex [0,233]⊤ has norm 233≈1.1547<2. This is evident in Fig. 1a, where the boundary of ℬ2 is shown translated to each of the several lattice points displayed, and the translated unit balls overlap. For a regular hexagonal array, the largest spacing at which the unit balls become tangent is 33λ≈0.5774 wavelength. The minimum spacing 33λ>12λ violates the widely used sufficient condition [1, Thm. 9].

Fig. 1b depicts the lattice and shifted unit balls for a four-element array with positions [0, 0]⊺, [±1.71, 0]⊺, and [0.26, 2.11]⊺. The array is alias-free on ℬ2, although no fundamental parallelogram contains a unit ball and the smallest inter-sensor spacing is 0.855λ.

Fig. 1c shows the lattice and shifted ℬ for a four-element array with a reduced set of DoAs given by ℬ = {ω ∣ θ ∈ [−π/3, π/3], ϕ ∈ [0, π/2]} Note that the array is not alias-free for the full set of DoAs ℬ2; the minimum separation between the parallelogram vertices is 1.335, and the condition of Corollary 5 is not satisfied. However, for the subset ℬ, the condition in Proposition 3 is satisfied, and the array is alias-free on ℬ. The lack of aliasing is illustrated by the disjointedness of the hourglass-shaped translations of ℬ in Fig. 1c. The array is designed from the desired parallelogram via P = 2πZV−1 with integer matrix Z yielding positions [0, 0]⊺, [2.67, 0.42]⊺, [1.78, 2.48]⊺, and [0.89, 4.54]⊺; the minimum separation between sensors is 1.122λ. This example shows how Proposition 3 may be used to design arrays that avoid aliasing over a subset of DoAs, as is sought in [8].

C. 3D array

A bi-tetrahedron of five sensors [34]–[36] is shown in Fig. 2a with positions [0, 0, ±1]⊺, [2, 0, 0,]⊺, and [−1, ±1, 0,]⊺ in units of one-half wavelength. The positions correspond to the vertices of an irregular polyhedron and are chosen so that there exists a cubic fundamental parallelepiped circumscribing a sphere of diameter 2. The minimum distance between sensors is 3λ/2, in violation of the widely used sufficient condition [1, Thm. 8]. The tangent points on each face correspond to the three pairs (az, el) of ambiguous DoAs, (0, ±90°), (±90°, 0), and (90°±90°, 0); any small contraction of the array geometry removes these points of tangency. The array is not isotropic: the CRB for ω1 is three times smaller than for ω2 and ω3. The unambiguous set for 3D arrays is underestimated in some prior literature, e.g., [35], [37].

VI. Summary

Results in [1] have been extended to provide a simply tested necessary and sufficient condition characterizing array geometries that provide unambiguous steering vectors. First, Proposition 3 considers an arbitrary set, ℬ, of candidate DoAs, with application illustrated in Fig. 1(c). In contrast, [1] only considers the case in which ℬ corresponds to all possible DoAs. Second, the test in (11) provides a simple necessary and sufficient condition for alias-free array geometries in 2D and 3D, offering a less restrictive alternative to a widely used sufficient condition [1, Thms. 8, 9]. The test in (11) is easily applied, yet it offers increased flexibility for array geometry design over the sufficient condition in [1]. Third, the direct test for 1D arrays in (10) is simpler than [1, Thm. 11] and therefore advantageous in a design procedure. The new results facilitate the design of nonuniform arrays for widely separated sensors or increased aperture without an increase in the number of sensors.

The unambiguous set of spatial frequencies was shown to be a parallelepiped, admitting both intuitive geometric interpretation and application of the test for any subset, ℬ, of DoAs. The parallelepiped, with edge vectors given by columns of the basis V, allows for array design to begin, as in Proposition 2 and Fig. 1(c), with a desired unambiguous parallelepiped, then proceed by selection of an integer array Z∈ℤ(L−1)×d.

Alias-free is a noiseless property; optimized design must also consider outliers due to beampattern side lobes [21], [28], [38]. The signal model in (2) adopted the traditional assumption of isotropic sensor elements; ambiguity analysis with arbitrary complex-valued gain functions per sensor was considered in [39].
