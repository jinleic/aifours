# Odd-order T1 arrays cannot be isomorphic to their reversals

Native `/bin/date` observed before writing: **Wed Oct 28 17:56:32 PDT 2026**. **WRITTEN universal theorem:** for every odd integer n>1, no T1(n) array can be mapped to its global left–right row reversal by any common permutation of its symbols and any reordering of its rows. Thus this holds for every possible T2(11) witness without imposing a Latin-column, cyclic-row or additional symmetry assumption. It is a genuine all-array structural obstruction, not an unrestricted T2 nonexistence result, construction, formal/kernel proof, or novelty claim.

## Proof

A T1(n) array consists of n permutation rows over n symbols, with all directed linear adjacencies distinct. Its n(n−1) events exhaust all ordered pairs of distinct symbols. Its row strings are distinct. Let G be the group of symbol permutations that preserve the row set up to row order. If an element fixes one row string, it fixes every symbol, so the action of G on the n rows is free. Every orbit has |G| rows; therefore `|G|` divides n and is odd.

Suppose for contradiction that a symbol permutation g composed with global row reversal R preserves the row set. Symbol relabeling commutes with R, and `(gR)^2=g²∈G`. Let m be the order of g². By Lagrange's theorem m is odd, so the odd power `(gR)^m=hR` also preserves the row set, where `h=g^m` and `h²=1`.

If h is the identity, then global reversal alone preserves an odd set of n row strings. As an involution of an odd finite set it must fix a row, but a permutation row of length n>1 cannot equal its reverse because its first and last symbols differ. Contradiction.

Otherwise h swaps some two distinct symbols a and b. The directed adjacency `a→b` occurs in exactly one row, at exactly one position. Under h followed by global reversal, this event maps to `h(b)→h(a)=a→b`. Since hR preserves the row set, the row containing that unique event must be fixed by hR. If its event is at zero-based position i (between i and i+1), global reversal maps that occurrence to position `n−2−i`. Because n is odd, n−2 is odd, and these two positions cannot coincide. Thus the same directed event would occur twice, contradicting T1. Both cases are impossible.

The restriction n odd is essential to the argument: at n=2 the T1 table with rows `01,10` is globally reversal-invariant. The theorem concerns ONE common symbol permutation and ONE common reversal of every row; it does not forbid arbitrary column permutations or individually reversing a chosen subset of rows.
