# Exact linear-rank bound and a nonlinear Ingleton-defect gate

**Status: WRITTEN with a separately implemented exact rational certificate check.** The upper bound `20/3` below is for representable rank profiles and uniform finite-field affine/linear-subspace supports, not arbitrary nonlinear guessing laws. The exact identity and the necessary Ingleton-defect conclusion apply to arbitrary finite FD laws. No formal proof, cross-model review or novelty clearance has been performed.

## Main results

For the original ten-vertex R-minus graph, every representable rank function `h` satisfying the ten original-neighbour FDs obeys

\[
h(V)\le \frac23\sum_{v=1}^{10}h(v)
\le \frac{20}{3}\max_v h(v).
\]

Consequently, the supremum guessing number achievable by finite-field vector-linear or affine-linear full-neighbour strategies is **exactly `20/3`**. The lower bound is attained by the explicit binary triangle code: on the 10 triangles listed below, each vertex holds three bits, each triangle has XOR zero, and a vertex reconstructs each component from the other two triangle vertices. There are `2^20` fixed words with alphabet size `q=8`, so `log_8(2^20)=20/3`. The upper bound also applies to any uniform law on a finite-field affine subspace whose support satisfies the graph FDs, even if the given decoders are nonlinear.

For arbitrary entropy laws with the graph FDs, define the conditional Ingleton expression

\[
J(A,B;C,D\mid Z)=I(A;B\mid C,Z)+I(A;B\mid D,Z)
+I(C;D\mid Z)-I(A;B\mid Z).
\]

The certificate gives an exact graph-specific identity involving 83 listed singleton-instance conditional Ingleton expressions and 64 conditional mutual informations. It implies the following **necessary condition for a nonlinear strict gain**. Set

\[
M=\max_v H(X_v),\qquad
\varepsilon=H(X_V)-\frac{20}{3}M,\qquad
T=\frac{1856350733}{320150190}.
\]

If `epsilon>0`, at least one of the 83 certificate Ingleton instances, after some graph automorphism, satisfies

\[
J(A,B;C,D\mid Z)\le -\frac{\varepsilon}{T}
=-\frac{320150190}{1856350733}\,\varepsilon.
\]

Thus any strictly improving FD law must violate a **specific conditional Ingleton inequality**; quantitative violation is at least the displayed amount. This is only a necessary condition. Entropic Ingleton expressions can be negative, so the certificate does **not** give an unrestricted `20/3` upper bound or close the original interval.

## Why conditional Ingleton is valid for ranks

For subspaces `A,B,C,D` in a common finite-dimensional vector space, let `S=A intersect B`. Dimension arithmetic gives

\[
I(A;B\mid C)\ge \dim S-\dim(S\cap C),
\qquad
I(A;B\mid D)\ge \dim S-\dim(S\cap D).
\]

Also `I(C;D)=dim(C intersect D)>=dim(S intersect C intersect D)` and

\[
\dim(S\cap C)+\dim(S\cap D)
\le \dim S+\dim(S\cap C\cap D).
\]

Combining them proves `J(A,B;C,D)>=0`. For conditioning `Z`, quotient all subspaces by the span of `Z`; the corresponding conditional rank expressions become the unconditional expressions in that quotient. For uniform finite-field linear or affine-subspace laws, subset entropies divided by the log field size are such ranks. Averaging graph-automorphic rank profiles preserves the linear inequalities and the FDs; representability of the average itself is not required.

The ten lower-bound triangles, in order, are `123,145,167,239,(2,7,10),389,(4,5,10),(4,8,10),569,678`. Each vertex occurs three times, each listed pair is an original edge, and the ten disjoint occurrence-coordinate XOR checks have rank ten. Each neighbour decoder outputs the XOR of the other two component bits and is defined on the full alphabet domain.
