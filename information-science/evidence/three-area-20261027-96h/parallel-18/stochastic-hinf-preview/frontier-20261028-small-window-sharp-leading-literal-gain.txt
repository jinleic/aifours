1. Actual plant and precise assertion

Fix T>0 and arbitrary finite original matrices. For each 0<=h<T let S=T-h, input w be progressive on [0,S], and choose the actual zero control u=0 in

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u,                x0=0.

Let gamma1(S),gamma2(S) be the ACTUAL given-law E1/E2 supremal gains, respectively, both using E||z||_L2[0,T]/E||w||_L2[0,S]. Set

 alpha(S)=||A||op S+8||A0||op sqrt(S).

Whenever alpha(S)<=1/2,

 |gamma_i(S)-(2S/pi)||D0 C||op|
    <=2||D0||op||C||op S alpha(S),      i=1,2.            (1)

Hence, as S downarrow 0,

 gamma_i(S)=(2/pi)||D0 C||op S+O(S^(3/2)).                (2)

The statement remains an absolute O(S^(3/2)) estimate when D0C=0; it does not claim a relative asymptotic or identify the next nonzero term. It is for this ONE actual u=0 law, not the optimum over controls.

2. Shift to the physical last window and bound the state

Before h the zero-start homogeneous state is identically zero. On [h,T], use t in [0,S], input v_t=w_t and the shifted Brownian `Wtilde_t=W_(h+t)-W_h`. The filtration F_(h+t) contains F_t, so v is adapted and Wtilde is Brownian with respect to it. The actual shifted state is

 dx_t=A x_t dt+C v_t dt+A0 x_t dWtilde_t,   x0=0.

Write Z=sup_(0<=t<=S)||x_t||. With the named dimension-independent L1 martingale maximal constant 8 and pathwise Cauchy–Schwarz, localized if needed,

 E Z <= alpha(S) E Z+||C||op sqrt(S) E||w||_2.

When alpha<=1/2,

 E Z <=2||C||op sqrt(S) E||w||_2.                          (3)

This remains valid for E1-only w; no square root of E||w||² is introduced.

3. Compare the actual output with a deterministic Volterra operator

Let V_S be the scalar Volterra integration operator on [0,S], and define the deterministic vector output y=(V_S tensor D0C)w. Pathwise,

 z_t-y_t=D0 [ integral_0^t A x_s ds+integral_0^t A0 x_s dWtilde_s ].

Applying the same L1 maximal inequality, then (3), gives for EVERY progressive E1 input

 E||z-y||_L2[0,S]
 <=||D0||op sqrt(S) alpha(S) E Z
 <=2||D0||op||C||op S alpha(S) E||w||.                   (4)

The exact deterministic Hilbert-space norm is

 ||V_S tensor D0 C||op=(2S/pi)||D0 C||op.                (5)

The scalar Volterra norm is attained by `cos(pi t/(2S))`; multiplying it by a top right singular vector of D0C gives a deterministic admissible E2 input. Formula (4) gives the upper gain bound for all E1 inputs, while its reverse triangle inequality applied to that same deterministic input gives the lower gain bound for BOTH gain classes. This proves (1) and (2). No stochastic output has been replaced by a deterministic operator without the explicit error bound.

4. Exact coefficient check and limits

For the illustrative scalar magnitudes ||A||=1/5,||A0||=3/10,||C||=||D0||=1 and S=1/100, Python Fraction arithmetic checked alpha=121/500<1/2 and the explicit error term in (1) is 121/25000. The leading value 2/(100pi) is exact; no float, Monte Carlo, controller optimization or actual sharp-gain equality was inferred from the arithmetic check.

The leading rate changes if the domain does not shrink with h, if direct disturbance output or input-driven diffusion remains under u=0, or for an infinite horizon. The result does not identify strict feasibility at the true gain, the unrestricted optimal gamma, source-book equivalence or novelty.
