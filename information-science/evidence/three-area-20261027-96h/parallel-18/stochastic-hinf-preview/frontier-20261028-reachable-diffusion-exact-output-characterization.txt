1. Original model, all matrices and exact theorem

Fix any finite T>0 and any compatible real matrices in the original plant. Use h=0, zero initial state/history, canonical Brownian filtration, and ONE fixed deterministic stationary linear law `u=Kx+Lw`, where L combines the two h=0 endpoint taps. Inputs are progressive E2 or E1 as in the parent-supported actual-output domain theorem; E1 uses local pathwise-L2 nonexplosive control, and both literal denominators are E||w||>0.

Write the ACTUAL closed loop

 dx=(P x+F w)dt+(Q x+G w)dW,  z=O x+J w,
 P=A+BK, F=BL+C, Q=A0+B0K, G=B0L,
 O=D0+D1K, J=D1L.                                                (1)

Let n be the physical state dimension and define finite subspaces

 R_d=span{P^k F e: e in input space, 0<=k<n},
 D_0=range(G)+Q R_d,
 D=smallest subspace containing D_0 and invariant under BOTH P and Q,
 N=intersection_(0<=j<n) ker(O P^j).

D is computed algebraically by D_(k+1)=D_k+P D_k+Q D_k; the dimension can increase at most n times, so D_n=D. No rank, stability, invertibility, positivity or nonzero coupling is assumed.

THEOREM A. The following are equivalent:

 (i) For EVERY deterministic L2 input v, the ACTUAL original output Z(v) is a deterministic L2-time function almost surely.
 (ii) D is contained in N.
 (iii) There exists ONE deterministic bounded real linear time operator S such that Z(w)(omega)=S(w(omega)) for EVERY progressive E2 input and, via actual localization, every E1 input.

Under these equivalent conditions, both literal gains equal ||S||, and for every gamma>0 the given law is pointwise-strict for every nonzero E2 input iff it is pointwise-strict for every nonzero E1 input. At gamma=||S||>0, strictness on both domains holds exactly when S has no nonzero deterministic norm-attaining vector; uniform strictness still fails. The same controller and original output are retained in BOTH callers.

2. SUFFICIENCY for all actual random inputs

For a given progressive input w define the deterministic time-operator state x^d by the ACTUAL input path:

 (x^d)'=P x^d+F w, x^d(0)=0.

It is progressive and finite pathwise, and lies in the P-invariant deterministic reachable space R_d. Set eta=x-x^d for the actual SDE solution. Then

 d eta=P eta dt+[Q eta+Q x^d+G w]dW, eta(0)=0.                 (2)

If D⊂N, the forcing Q x^d+G w lies in D_0⊂D, and D is invariant under P and Q. The SDE restricted to D has a solution there; original strong uniqueness identifies it with eta. Thus O eta=0 for the ACTUAL input/Brownian pair. This is true for all E2 inputs and then all E1 local solutions by causal energy localization; no product-a.e. deterministic-input version is substituted.

The ORIGINAL output is consequently the bounded deterministic path operator

 (S v)(t)=O integral_0^t exp(P(t-s))F v(s)ds + J v(t).          (3)

The finite-horizon exponential kernel and finite J bound S on L2. This proves (ii)->(iii)->(i).

3. NECESSITY: no Wiener-chaos completeness or selected test needed

Assume (i). Fix an arbitrary smooth deterministic input v. The actual mean x^d=E x solves the deterministic ODE in section 2, by finite-horizon E2 Itô integrability. Since z=Ox+Jv is deterministic as a random L2 function and Ox has continuous paths, O eta=0 as a process almost surely. Let

 B_v(t)=Q x^d(t)+G v(t),

which is continuous and deterministic. The deviation solves `d eta=P eta dt+[Q eta+B_v(t)]dW` and E eta=0.

First show eta(t) lies in N. From O eta=0, the continuous semimartingale decomposition has zero drift and zero diffusion coefficient separately: a continuous local martingale of finite variation is constant, or equivalently its quadratic variation is zero. Hence OP eta=0 and O(Q eta+B_v)=0 dt x P-a.e.; continuity upgrades OP eta=0 to all times. Repeat this argument for O P eta, O P^2 eta, and so on. It yields O P^j eta=0 for j<n, i.e. eta∈N on the entire finite horizon.

Now let Pi project onto N-perp and let W be ANY finite word in P,Q. Claim: W eta(t)∈N and W B_v(t)∈N for all t, for each such v. Proceed by induction on word length. The base W=I has eta∈N. If W eta∈N, its projected SDE is identically zero:

 0=Pi W P eta dt+Pi W(Q eta+B_v)dW.

Uniqueness of the finite-variation/local-martingale decomposition gives Pi W P eta=0 and Pi W(Q eta+B_v)=0 dt x P-a.e. Taking expectations and using E eta=0 gives Pi W B_v(t)=0; continuity makes this true for every t. Subtracting it then gives Pi WQ eta=0. Continuity makes both W P eta and W Q eta N-valued for all t, completing the word induction. Each finite word/input uses its own probability-one event; no uncountable null-set intersection is assumed.

4. Every generator is actually paid by deterministic inputs

The preceding statement holds for EVERY smooth deterministic input and each t. Let v(t) be constant near zero. Then x^d(t)->0 as t decreases to zero, so B_v(t)->G v(0). By closedness of N, W range(G)⊂N for every word W.

For the remaining generator, choose smooth inputs supported strictly before a given t, so v(t)=0. Their x^d(t) values span R_d. To see this, approximate a Dirac input at any s<t: the resulting vectors approach exp(P(t-s))F e. The span of exp(Pr)F e over an open time interval equals R_d: inclusion follows from Cayley-Hamilton, and any functional annihilating that span annihilates its analytic derivatives P^k F e at r=0. Therefore W Q R_d⊂N for EVERY word W.

It follows that every P/Q word applied to D_0=range(G)+Q R_d lies in N. Their span is exactly D, so D⊂N. This proves (i)->(ii), including G=0, F=0, repeated/singular matrices and n=1. We did not assume the lower-order conditions O P^jG=0 and O P^jQ P^k F=0 were by themselves sufficient.

5. Exact literal endpoint consequence

When (i)–(iii) hold, the physical output is S applied pathwise to the random input. Therefore both expected-path-norm gains equal the deterministic real Hilbert-space operator norm ||S||: the pathwise bound gives the upper inequality, and deterministic E2 inputs approximate that norm from below.

For gamma=||S||>0, if S attains its norm at a nonzero v, that deterministic E2 input violates strictness at the endpoint. If S does not, the pathwise nonnegative gap gamma||w||-||S w|| is strictly positive on each nonzero input path; an E1 input with positive denominator has such paths with positive probability, and the gap is integrable. Hence EVERY E1/E2 input is strictly below gamma. Above gamma a uniform margin holds; below it an actual deterministic approximating input violates. This is the SAME fixed physical law and the source's literal expected norm, not an RMS substitution.

The theorem gives NO conclusion about endpoint transfer when (ii) fails. Output-visible noise can still have strict transfer or fail it; neither follows merely from this algebraic test. For h>0 the input-delay/kernel word problem is NOT covered by the iff in this file, although the earlier sufficient hidden-noise theorem covers its separate conditions.

6. Two exact original physical systems distinguish the conditions

A. Hidden-noise system with a>0 and nonzero sigma,kappa:

 dx1=(-a x1+w)dt+kappa x3 dW,
 dx2=(sigma x2+w)dW,  dx3=0,  z=w-a x1,

zero initial state and u=w. It has P=diag(-a,0,0), Q e2=sigma e2, Q e3=kappa e1, F=e1, G=e2, O=-a e1^T. Here R_d=span(e1), D=span(e2)⊂N, yet OQ e3=-a kappa!=0. Thus the earlier stronger condition OQ=0 fails while the new necessary-and-sufficient reachable-diffusion test succeeds. The Brownian x2 coordinate is genuinely active. The exact pathwise identity

 ||w||^2-||z||^2=a x1(T)^2+a^2 integral_0^T x1^2dt

is strictly positive for every nonzero input; high-frequency deterministic inputs show the common gain is exactly1, so strict endpoint transfer is nonvacuous.

B. Three-stage visible-noise cascade with deterministic w=1:

 dx3=w dW,  dx2=x3 dW,  dx1=x2 dW,  z=x1,

zero initial state. P=F=0, G=e3, Qe3=e2, Qe2=e1, O=e1^T. The low-order necessary tests OG=0 and O Q P^k F=0 all hold, but D grows `span(e3)` -> `span(e3,e2)` -> `span(e3,e2,e1)` and is NOT contained in N. Itô's formula gives actual

Thus stochastic output is genuine; a first-order-only observable-noise test would be false. This tests the original physical equation rather than a relaxed random operator.
