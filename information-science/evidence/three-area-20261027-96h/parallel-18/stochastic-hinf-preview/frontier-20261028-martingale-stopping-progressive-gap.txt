This is a general all-T all-h result for a different actual law and an ALL stopping-time input class; it does not read, reconstruct, optimize or calibrate any held deterministic-reference controller or prior selected diagnostic. It is a fixed-law E2 progressive-vs-deterministic comparison in the original expected-path norm, NOT existential synthesis, E1/E2 endpoint transfer, exact gain or novelty clearance.

1. The actual original stochastic SDE

For every T>h>=0,S=T-h>0, scalar Brownian W and zero x0, use the legitimate original controller u_t=w_t and plant

 dx_t=u_t dW_t=w_t dW_t,      z_t=x_t.

All other drift/disturbance/output-feedthrough coefficients are zero. Disturbances w are supported on [0,S]; u=w is an actual current-preview law in the registered class. Define gamma_prog,2 as the supremum of the ORIGINAL E||z||_L2[0,T]/E||w||_L2[0,S] over progressive E2 inputs, and gamma_det over nonzero deterministic L2 inputs, with the identical ratio.

Let tau=inf{s>=0:|B_s|=1} for standard Brownian B, and set m=E sqrt(tau). Then

 gamma_prog,2 >= sqrt(T)/m  > sqrt(T) >= gamma_det.          (A)

Therefore this actual fixed law has a STRICT progressive-vs-deterministic gain gap for EVERY finite T>h, proved already on E2 inputs. It also lower-bounds the E1 gain, but does not prove any E1/E2 pointwise strictness transfer or identify either gain exactly.

2. Deterministic input upper bound

For deterministic w, Itô isometry, Fubini and Jensen give

 E||x||_L2 <= (E||x||_L2²)^(1/2)
   =[integral_0^S (T-s)|w_s|²ds]^(1/2) <= sqrt(T)||w||_L2.

The RHS equals sqrt(T) E||w|| because w is deterministic. This is ONLY a deterministic-input upper bound for the literal ratio; it is not substituted for the progressive expected-path gain. No input maximizer or reference controller is assumed.

3. m is strictly less than one

The exit time tau is finite a.s. and nonconstant. Optional stopping of B_(t wedge tau)^2-(t wedge tau), with the stopped Brownian bounded by 1, gives E tau=1. Strict concavity of square root therefore gives

 0<m=E sqrt(tau)<sqrt(E tau)=1.                            (1)

An exact representation, obtained from E exp(-lambda tau)=sech(sqrt(2lambda)) and the standard square-root Laplace identity, is

 m=sqrt(2/pi) integral_0^infinity (1-sech u)/u² du.        (2)

Both tails converge; (1), not numerical integration, proves the strict gap.

4. An entire progressive E2 stopping family

For any finite integer N and 0<delta<min(S,T), define the time-rescaled Brownian motion

 Btilde_s=sqrt(N/delta) W_(delta s/N),     0<=s<=N,
 tautilde_N= min[N, inf{s in [0,N]:|Btilde_s|=1}],
 w_t=sqrt(N/delta) 1_(0<=t<=delta) 1_(tautilde_N>Nt/delta).

The convention for an empty hitting set is infinity; (Btilde,tautilde_N) has the same law on [0,N] as (B,tau wedge N). The input is progressively measurable in the ORIGINAL Brownian filtration, supported on [0,delta], and belongs to E2 since

 ||w||_L2[0,S]^2=tautilde_N<=N.

Its actual state satisfies x_t=Btilde_(min(Nt/delta,tautilde_N)) on [0,delta], and x_t=Btilde_tautilde_N for t>=delta. Writing tau_N=tau wedge N for the standard B of section 1, equality in distribution gives

 E||w||=E sqrt(tau_N),
 E||x|| >= sqrt(T-delta) E|B_tau_N|.                       (3)

As N->infinity, |B_tau_N|<=1 and B_tau_N->B_tau with |B_tau|=1, so E|B_tau_N|->1 by bounded convergence; E sqrt(tau_N)->m by monotone convergence. First take N arbitrarily large and then delta down to 0; the supremum over the actual progressive E2 inputs is at least sqrt(T)/m. Together with (1)–(3), this proves (A). Some FINITE N and positive delta already make the ratio strictly exceed sqrt(T); neither a limiting input nor E1-only pathology is needed.
