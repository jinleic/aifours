1. Original plant and theorem

Fix T>0, real a, nonzero sigma, nonzero real c,d. Use the actual h=0 original plant, zero state/history, no control, canonical Brownian filtration:

 dx=(a x+c w)dt+sigma x dW,  z=d x.

Its constant-coefficient stochastic fundamental factor is

 Phi_t=exp[(a-sigma^2/2)t+sigma W_t] >0.

For every actual progressive E1 input, localization/Itô's product rule gives the pathwise linear solution

 x(t)=c (T_W w)(t),  (T_W v)(t)=Phi_t integral_0^t Phi_s^(-1)v(s)ds.

For each Brownian path, T_W is an ordinary compact real Hilbert–Schmidt operator on L2[0,T]; let G(W)=||T_W||, finite and positive pathwise. The actual samplewise inequality is

 ||z(omega)||_L2 <= |cd| G(W(omega)) ||w(omega)||_L2.          (1)

**Theorem.** If sigma!=0, NO nonzero progressive input w having finite pathwise L2 energy can make (1) an equality almost surely. In particular, neither an E2 input nor an E1-only input can be an almost-sure pathwise operator-norm maximizer. Also `ess sup G(W)=infinity`.

The latter is a property of the FUTURE-PATH operator, not a claim that the progressive literal gain is infinite. A progressive input cannot condition its time-zero direction on the whole future Brownian path; this distinction is the purpose of the theorem.

2. The pathwise top eigenvector is nonzero from the start

Fix any continuous Brownian sample. Compactness makes G attained on that sample. The positive-kernel operator T^*T has continuous kernel

 K(s,u)=Phi_s^(-1)Phi_u^(-1) integral_(max(s,u))^T Phi_t^2dt.

For s,u<T this is strictly positive. If a top eigenvector changed sign on two positive-measure subsets, replacing it by its absolute value would strictly increase its Rayleigh quotient: the positive off-diagonal kernel adds strictly positive cross terms. Thus every norm-attaining top eigenvector has a constant sign. Its eigen-equation then makes it strictly one-signed at every s<T in its continuous representative, because K is strictly positive and the input is not zero. This handles possible sign reversal and needs no assumption that an arbitrarily selected top eigenvector is unique.

If equality (1) held for an adapted w, on the active path event E={||w||>0} its time path would satisfy the eigen-equation T_W^*T_W w=G^2w and hence be one-signed/nonzero on every interval (0,t), t>0. The event E therefore equals `{integral_0^t |w_s|^2ds>0}` almost surely for each rational t>0. Those latter events are F_t-measurable, so E is in F_(0+)=F0 and has probability0 or1. A nonzero input means P(E)>0, hence P(E)=1.

3. The actual adapted singular equation would reveal G at time zero

Define the causal state coordinate

 y_t=integral_0^t Phi_s^(-1)w_s ds,

and the whole-output path functional

 v_t=integral_t^T Phi_r^2 y_r dr.

The pathwise eigen-equation is equivalent, in L2 time, to

 G^2 Phi_t w_t=v_t.                                              (2)

Since Phi and y are continuous, v is continuously differentiable with v'_t=−Phi_t² y_t. Equation (2) gives a continuous version `u_t=Phi_t w_t=v_t/G²`. Although its formula contains a future integral, this version is ACTUALLY adapted: it equals the progressive process Phi w dt x P-a.e.; for each t>0, its value is the limit of left-time averages of that progressive process, hence is F_t-measurable. Its derivative u'_t is also F_t-measurable as a limit of backward differences. The state coordinate y_t is F_t-measurable from its actual causal integral.

By the sign/nonzero conclusion, y_t and u'_t are nonzero for EVERY t in (0,T). Thus on the now probability-one active set,

 **G²=−Phi_t² y_t/u'_t is F_t-measurable for every t>0.**      (3)

For a deterministic sequence t↓0, Brownian F_(0+) is trivial; therefore G² would have to be deterministic. This follows from actual progressiveness, not from treating an anticipative singular vector as an admissible input.

4. The physical samplewise norm is nonconstant and unbounded

As a function of the continuous driving path W, the kernel Phi_t/Phi_s on 0<=s<=t<=T depends continuously in the uniform topology; the Hilbert–Schmidt bound gives continuity of its operator norm G.

For a deterministic driving path W_t=k t the kernel is `exp(beta(t-s))1_(s<t)`, `beta=a−sigma²/2+sigma k`. If beta2>beta1, the first kernel is strictly larger at every 0<=s<t<=T. Apply both to a nonzero nonnegative norm-attaining vector for beta1: its output is strictly larger on a positive-measure interval, hence its operator norm is strictly larger. Because sigma!=0, choose two slopes producing distinct beta values. Brownian full support of continuous paths gives positive probability to disjoint small neighborhoods of those two paths; norm continuity makes G nonconstant. This contradicts (3).

As beta tends to +infinity, the image of deterministic input 1 is `(exp(beta t)-1)/beta`, whose L2 norm grows without bound. For each M, choose a finite slope with norm>M and a small full-support neighborhood. Hence P(G>M)>0 and ess sup G=infinity.

No sampled path or numerical fit is used in this proof. The full-support input is the standard Brownian path-space support fact; it is not a novelty claim or an external theorem about the control optimum.

5. What this rules out, and what it DOES NOT rule out

Any attempt to settle the actual literal E1/E2 endpoint by declaring an adapted input to be a samplewise top singular vector of the scalar stochastic Volterra kernel fails: none exists except the zero input. The physical noise makes the pathwise norm random and unbounded, whereas admissibility reveals noise progressively.

This is distinct from the earlier final-time Cauchy saturation result. Its adapted input Phi^(-1) saturates an inner time Cauchy inequality at each t, but that is NOT the top singular direction for the full time-output norm. The result also DOES NOT show strict inequality at the actual deterministic common literal gain gamma, does not give a physical E1-only attainer, and does not assert that the literal progressive gain is infinite. The pathwise bound (1) has a random coefficient G, so taking an essential supremum would be an unjustified replacement of the original expected-path-norm problem.
