1. Universal deterministic lower formula

For any actual original full-preview law with arbitrary finite matrices, scalar W, progressive vector E1 input and T>h>=0, use the named impulse source's all-variable coefficient vector a, direct norm d(a), and artificial impulse process X^a. Define

 Y=integral_0^T ||O X_t^a||²dt,  I2=E Y,
 U4=T integral_0^T E||O X_t^a||^4dt.

These are deterministic and finite; if I2>0 then U4>0. BOTH actual E1 and E2 expected-path gains satisfy

 gamma1,gamma2 >= sqrt[d(a)²+(2/pi) I2(a)^3/U4(a)] / ||a||. (1)

If I2=0 interpret the correction as zero. I2,U4 are computed by the second/fourth tensor ODEs and Gaussian jump updates in the named moment-gap source. This is a necessary lower bound for a GIVEN original law, not an exact gain or general controller-design decision.

2. Conditional Gaussian geometry and proof

The finite impulse normals xi_j are independent of the entire auxiliary Brownian path Wbar. Conditional on that path, the output `O X^a` is a centered finite-rank Gaussian element of L2 time, so

 Y=xi^T M xi

for a finite positive-semidefinite Gram matrix M=M(Wbar). Put J=tr M=E_xi Y and diagonalize M with eigenvalues lambda_i>=0. Conditional on Wbar and J>0, writing p_i=lambda_i/J, pointwise concavity of square root gives

 sqrt[d²+sum_i lambda_i xi_i²]
 >= sum_i p_i sqrt[d²+J xi_i²].

Each xi_i is standard normal, so the conditional expected norm is at least E_xi sqrt[d²+J xi²]. Since the Euclidean norm is convex and E|xi|=sqrt(2/pi),

 E_xi sqrt[d²+Y] >= sqrt[d²+(2/pi) J].                    (2)

Apply the same convex-norm inequality over Wbar to get

 L(a) >= sqrt[d²+(2/pi)(E_W sqrt(J))²].                     (3)

Hölder gives E_W sqrt(J)>=(E J)^(3/2)/(E J²)^(1/2). Also E J=E Y=I2 and E J²<=E Y²<=U4: the first inequality is conditional Jensen over xi, the second is time Cauchy–Schwarz. Substitute into (3), and then use the pinned impulse theorem gamma_i>=L(a)/||a||, proving (1). Every expectation/square root is in the correct order for the original E1 objective.

3. Stronger finite Gramian matrix when Q=0

Suppose the ACTUAL closed state-multiplicative noise Q=A0+B0K is zero; additive control-noise impulses G0,Gh may remain nonzero. The vectors O exp[P(t-tj)] gj are then deterministic, so J=I2 is deterministic and (3) sharpens to

 gamma1,gamma2 >= sqrt[d(a)²+(2/pi) I2(a)] / ||a||.       (4)

For h>0 let B_n be the direct-atom chain of the pinned source and let linear maps G_j act on the stacked coefficient a by G_j a=G0 aj+Gh a_(j-1). Define

 W(v)=integral_0^v exp(P^T t) O^T O exp(Pt)dt,
 R=sum_(j=0)^n G_j^T W(T-jh) G_j.

Then d(a)²=a^T B_n^T B_n a and I2(a)=a^T R a, so optimizing this NECESSARY bound over the finite chain gives the explicit matrix inequality

 gamma1,gamma2 >= sqrt[lambda_max(B_n^T B_n+(2/pi)R)].     (5)

At h=0 combine atoms E=E0+Eh,G=G0+Gh and use the single matrix E^T E+(2/pi)G^T W(T)G. Formula (5) uses only deterministic matrix exponentials/integrals and an eigenvalue; it does NOT state the actual gain is equal to this lower bound.
