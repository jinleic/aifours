0. Exact theorem

Fix arbitrary finite real matrices P in R^(n x n), B in R^(n x m), C in R^(p x n), finite T>0, and ONE scalar Brownian driver W. Consider the actual GIVEN linear law
 dx_t=P x_t dt+B w_t dW_t, z_t=C x_t, x_0=0, 0<=t<=T.   (0.1)
Here B denotes the input-DIFFUSION matrix, not the book's drift-input matrix. The input w is R^m-valued, progressive in the canonical Brownian filtration, and belongs to E1 or E2 as defined by its L2 path norm. No controller is selected or constructed.

Define the finite Gramian
 G(u)=B^T integral_0^u exp(P^T t) C^T C exp(P t)dt B,
 c_T=sqrt(lambda_max G(T)).                           (0.2)
There is no stability, rank, invertibility or commutativity hypothesis. Let r be the unique positive zero of
 g(y)=exp(y^2/2)-y integral_0^y exp(s^2/2)ds,
so 1.30692<r<1.30693 as certified in the source packet.

The candidate theorem is:

 (A) Both actual literal gains of (0.1) equal r c_T. The RMS gain is c_T.
 (B) For every actual E1 input,
     E||z|| <= r E sqrt(integral_0^T w_t^T G(T-t) w_t dt).   (0.3)
 (C) If c_T>0, every nonzero actual E1/E2 input has E||z||<r c_T E||w||. Hence the original pointwise strict criterion for this GIVEN LAW holds exactly for gamma>=r c_T, including equality. No E1/E2 maximizer exists. Uniform-margin feasibility needs gamma>r c_T.
 (D) If c_T=0, the actual output vanishes for every input; both gains are zero. The strict criterion is true for gamma>0 and false at gamma=0. This branch is NOT silently included in the closed-threshold wording of (C).

The conclusion covers arbitrary state/input/output dimensions with one Brownian driver, not merely a rank-one input/output matrix. The exact formula involves only a finite deterministic Gramian and the universal constant r. It is a fixed-law value/strict-feasibility theorem, not the original existential controller synthesis criterion.

1. Actual state and deterministic kernels

For E2 inputs, deterministic variation of constants gives
 z_t=integral_0^t C exp(P(t-s))B w_s dW_s.              (1.1)
All matrices and deterministic exponentials are bounded on the finite horizon. Standard finite-dimensional linear-SDE existence/uniqueness applies. The same formula defines the actual local solution for E1 inputs because their pathwise input energy is finite almost surely. No global E2 state estimate is inserted into the E1 definition.

It is convenient to name the deterministic output-shape operator
 K_s a : t -> 1(t>=s) C exp(P(t-s))B a, t in [0,T].
This is only notation for a deterministic L2[0,T;R^p] function, not an additional controller or state. Its squared norm is
 ||K_s a||^2=a^T G(T-s)a.                            (1.2)

2. Radial inequality for arbitrary progressive vector integrands

The source packet section 2 explicitly defines the radial function
 F(m,a)=sqrt(a) f(||m||/sqrt(a)),
 f(rho)=-g(rho)/alpha for rho<=r, f(rho)=rho-r for rho>=r,
 alpha=integral_0^r exp(s^2/2)ds.
It reconstructs, in EVERY finite dimension,
 F(m,a)>=||m||-r sqrt(a), ||grad_mF||<=1,
 2F_a+lambda_max(D_m^2F)<=0,                          (2.1)
with a positive-semidefinite Hessian, a>0. The derivatives match at the joining sphere; f'(0)=0 handles the origin.

Here the vector integrand need NOT be a fixed deterministic q times a scalar v. Let q_t be any progressive R^d-valued E2 integrand, M=integral q dW, A=integral||q||^2 dt. The same finite-vector Ito argument gives
 drift F(M,A+epsilon)
 =F_a||q||^2+(1/2)q^T D_m^2F q
 <=(1/2)||q||^2[2F_a+lambda_max(D_m^2F)]<=0.
The martingale integrand has norm at most ||q||. Initial value is -sqrt(epsilon)/alpha. Taking expectations and passing epsilon down to zero gives
 E||integral_0^T q_t dW_t|| <= r E sqrt(integral_0^T||q_t||^2dt).   (2.2)
Thus this extension does not import any unproved independence or deterministic-direction property.

Joining-sphere precision. One can use the generalized Ito formula as in the source. Alternatively, F is C1, locally has bounded piecewise second derivatives for a bounded away from zero, and its continuous first derivatives create no distributional surface delta. For every constant unit vector e, the linear distributional inequality F_a+(1/2)e^T D_m^2F e<=0 follows from (2.1). Positive mollification in (m,a) on a>0 preserves every such inequality, as well as the gradient bound. Apply ordinary C2 Ito to the mollifications after localization and pass to the locally uniform limit. This supplies the same supermartingale inequality without taking a side-dependent second derivative at a path on the sphere. F has linear growth in ||m|| and sqrt(a), and E2 plus ||grad F||<=1 makes the martingale integrable; the usual expectation/localization limits are legitimate.

3. Weighted upper bound without Hilbert-space Ito

For N>=1 put t_j=jT/N and define the R^(pN)-valued terminal vector
 Z^N=sqrt(T/N)(z_(t_1),...,z_(t_N)).
It is the terminal value of the actual vector martingale with progressive integrand blocks
 q^N_j(s)=sqrt(T/N)1(s<t_j) C exp(P(t_j-s))B w_s.
Its quadratic clock is
 A^N=integral_0^T w_s^T G_N(s)w_s ds,
 G_N(s)=(T/N)sum_(j:s<t_j) B^T exp(P^T(t_j-s)) C^T C exp(P(t_j-s))B.

For almost every s, deterministic Riemann sums give G_N(s)->G(T-s). Their operator norms have one finite bound depending only on P,B,C,T, uniformly in s,N. Hence pathwise dominated convergence and then expected dominated convergence yield
 E sqrt(A^N)->E sqrt(integral_0^T w_s^TG(T-s)w_s ds).
Domination is by a constant times ||w||, integrable for E2 (and later E1). Apply (2.2) to each q^N. The continuous actual output paths imply ||Z^N||->||z|| almost surely. Fatou proves (0.3) for E2 inputs. There is no assertion that z_t itself is a martingale when P is nonzero; it is the finite sampled-output vector represented above that is a TERMINAL martingale value.

Since G(T-s)<=G(T)<=c_T^2 I in Loewner order, this gives E||z||<=r c_T E||w||.

For E1, use w_n=w 1(||w||<=n). Apply the just-proved E2 inequality to differences w_n-w_m. Their outputs converge in L1(Omega;L2[0,T]). Input bracket convergence and the bounded deterministic variation-of-constants kernels identify the local/uniform-in-probability state limit with the actual state (1.1). Passing to the limit gives (0.3) for E1. This also proves E1/E2 equality of gains once the lower bound below is included; no global expected state/control energy is assumed for E1.

4. Strictness for every nonzero actual input when c_T>0

For every s in (0,T) and nonzero vector a,
 a^T G(T-s)a<c_T^2||a||^2.                           (4.1)
Indeed equality would force both a^TG(T)a=c_T^2||a||^2 and
 integral_(T-s)^T ||C exp(Pt)B a||^2dt=0.
The real-analytic vector function C exp(Pt)B a would then vanish on a nonempty interval, hence identically. This gives a^TG(T)a=0, contradicting c_T>0 and a!=0. Degenerate/invisible input directions cause no exception: their Gramian value is zero, strictly below c_T^2||a||^2.

For any nonzero finite-energy input path, the integral of the positive difference in (4.1) is positive: a nonzero L2 function has support of positive measure in (0,T). Therefore
 sqrt(integral w_t^T G(T-t)w_tdt)<c_T||w||
on every nonzero input path. Both sides are integrable for E1, and a nonzero input has such paths with positive probability. Expected strictness and (0.3) prove (C).

If c_T=0, the same analyticity/Gramian argument shows C exp(Pt)B=0 for all t, so (1.1) has identically zero output for every admissible input. This proves (D).

For a fixed integer N and epsilon in (0,T), run the physical scalar Brownian motion at rate R=N/epsilon inside [0,epsilon]. Define beta_u=sqrt(R)W_(u/R) on [0,N], sigma_N=tau_b wedge N, and
 v_s=sqrt(R)1(s<epsilon)1(Rs<tau_b), w_s=a0 v_s.
This is bounded, progressive and E2, ||w||^2=sigma_N, and integral_0^epsilon v_s dW_s=beta_sigma_N. The actual output z_epsilon has the kernel representation (1.1).

Compare its whole output path to the reference deterministic shape times a scalar:
 Z_ref(t)=C exp(Pt)B a0 beta_sigma_N=K_0 a0(t) beta_sigma_N.
This reference is only a random L2 function for estimating the error; it need not be a causal output at t<epsilon. No anticipative process is substituted for the actual state.

By ordinary Ito isometry for each fixed output time and Tonelli,
 E||z_epsilon-Z_ref||^2
 =E integral_0^epsilon ||K_s a0-K_0 a0||_L2^2 v_s^2ds
 <=omega(epsilon)^2 N,
where omega(epsilon)=sup_(0<=s<=epsilon)||K_s a0-K_0 a0||_L2 ->0. The latter continuity follows directly: on [0,s] the missing initial shape has O(s) squared norm; on [s,T] the difference of deterministic matrix exponentials is uniformly O(s). All integrands in the displayed stochastic integrals are adapted: for each fixed output time the kernels are deterministic, including the reference term.

Thus E||z_epsilon||>=c_T E|beta_sigma_N|-omega(epsilon)sqrt(N). Divide by E sqrt(sigma_N)>0 and let epsilon down to zero for fixed N. Then let N grow using the source's dominated/monotone convergence argument. The gain is at least
 c_T b E sqrt(1+tau_b)/E sqrt(tau_b)>c_T b.
Finally let b increase to r. This proves the matching lower bound r c_T with actual bounded E2 inputs, including every quantifier and order of limits. No infinite-energy input or numerical optimizer is asserted to be admissible.

6. Exact RMS gain and feasibility topology

Ito isometry and Tonelli give
 E||z||^2=E integral_0^T w_s^T G(T-s)w_s ds<=c_T^2 E||w||^2.
Deterministic normalized pulses w_s=epsilon^(-1/2)a0 1_[0,epsilon] have squared RMS ratio
 (1/epsilon)integral_0^epsilon a0^T G(T-s)a0 ds ->c_T^2.
Hence the same law's RMS gain is c_T. This computation is a comparison, not a substituted definition of the literal gain. The proof of literal gain r c_T comes from the separately reconstructed martingale inequality and progressive stopping inputs, not an assumed RMS-to-literal theorem.

For c_T>0 the per-input strict literal criterion holds at gamma=r c_T because the true gain is not attained; it fails for gamma<r c_T by the bounded lower witnesses/supremum. A common uniform strict margin needs gamma>r c_T. These are fixed-law quantifiers, not existential-controller claims.
