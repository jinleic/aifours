1. Original law and deterministic-output condition

Use arbitrary finite matrices, scalar W, T>h>=0,S=T-h, vector progressive E1 input and the actual full original deterministic linear preview law. Put P=A+BK,Q=A0+B0K,O=D0+D1K and define its drift/diffusion/output time taps F0,Fh,F(r),G0,Gh,G(r),E0=D1L0,Eh=D1Lh,E(r)=D1H(r) exactly as in the named source.

Assume ONLY its stochastic hiding condition: there is a common P,Q-invariant N subset ker O such that every G tap maps into N and Q Rd subset N, where Rd is the P-invariant span of the deterministic drift forcing. Do NOT require E0=Eh=0. At h=0 combine coincident taps as usual. Then the actual output is pathwise the deterministic operator

 T=A+K,                                                     (1)

where `(A w)(t)=E0 w_t+Eh w_(t-h)` and K is a Hilbert–Schmidt regular time-kernel operator containing all state response and distributed output. Hence true gamma1=gamma2=||T||op for the SAME expected-path ratio, even if that norm is not attained. This is an exact same-law statement, not a general output-visible stochastic result.

2. Exact finite delay-chain threshold

For h>0 define n=ceil(S/h) and the finite block matrix B_n:R^(n m)->R^((n+1)p) by

 y0=E0 a0,
 yj=E0 aj+Eh a_(j-1)  (1<=j<n),
 yn=Eh a_(n-1).

Define delta=||B_n||op. At h=0 define delta=||E0+Eh||op. Then

 ||A||op = ||A||essential = delta.                          (2)

For h>0, partition time into residues r in [0,h): the input values w(r+jh) form a finite chain of length n(r), and output values form B_(n(r)) times that chain. As r varies, n(r) is either floor(S/h) or ceil(S/h), with the longer value n on a set of positive measure; for integral S/h the length is constantly n except endpoints. Embedding a shorter chain in a longer chain with zero entries shows ||B_j|| is nondecreasing in j. Hence ||A||=||B_n||.

Choose infinitely many orthonormal residue functions on the positive-measure n-chain set, each multiplied by a fixed unit top singular vector of B_n. The resulting deterministic input sequence is weakly null and has ||A w_j||=delta. Every compact operator sends it strongly to zero, so ||A+K0||>=delta for every compact K0; since ||A||=delta, its essential norm is delta. For h=0 use orthonormal time functions times a top singular vector of E0+Eh.

As K in (1) is compact, (2) immediately implies the actual hidden-noise literal gain satisfies ||T||>=delta. This is generally stronger than the separate-window stack ||[E0;Eh]||: the delay chains can combine multiple atoms coherently.

3. Endpoint dichotomy above the essential threshold

If ||T||>delta, then T's norm is attained by a deterministic input. A direct proof: take a unit maximizing sequence w_j and a weakly convergent subsequence w_j ⇀ w. Compactness gives K(w_j-w)->0. If w=0 then limsup ||T w_j||<=||A||=delta, a contradiction. More generally Hilbert orthogonality gives

 ||T||² <= ||T w||²+delta²(1-||w||²)
          <= ||T||²||w||²+delta²(1-||w||²).

Since ||T||>delta, ||w||=1 and ||T w||=||T||. The deterministic w is progressive E2/E1, so strictness FAILS at gamma=||T||.

If ||T||=delta>0, either outcome is possible: strictness at the literal gain holds iff T has NO norm-attaining input, because then every nonzero path has strictly smaller output norm and its expected deficit is strictly positive; if a maximizing vector exists it is a deterministic E2 equality witness. The case delta=0 reduces to the compact-output source: nonzero T has ||T||>0=delta and attains its norm; gamma=0 is never strictly feasible. Thus a strict-at-gain hidden-noise law can occur ONLY at the direct-atom essential threshold, but equality there alone does not decide strictness.

4. Exact examples on both sides of the threshold

First, take h=1,S=2,T=3, scalar E0=Eh=1 and no regular/state output. Then n=2 and

 B_2=[[1,0],[1,1],[0,1]],  B_2^T B_2=[[2,1],[1,2]].

Python Fraction arithmetic checked this Gram matrix; delta=sqrt(3), strictly above the separate-window bound sqrt(2). The atom operator itself attains delta on a top chain vector, so equality at gamma=delta is NOT strict.

Second, take h=0,a>0, deterministic dx=(-a x+w)dt, z=w-a x, realized by u=w,D0=-a,D1=1 with other noise zero. For x0=0 one has w=x'+a x,z=x' and the exact path identity

 ||w||²-||z||²=a x(T)²+a² integral_0^T x(t)²dt.

Thus every nonzero input has ||z||<||w||, while T=I+K with compact K and delta=1 implies ||T||=1. Hence gamma=delta=1 IS pointwise strict for every nonzero progressive E1/E2 input even though the gain supremum is 1. This is an actual deterministic-output law, not an output-visible stochastic endpoint or a selected reference calibration.
