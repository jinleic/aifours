1. Actual original class and exact necessary bound

For arbitrary finite matrices, T>h>=0,S=T-h, scalar Brownian W, zero x0, and progressive vector E1 input w supported on [0,S], take the actual original plant and registered full deterministic linear preview law

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u,
 u=Kx+L0w_t+Lh w_(t-h)+integral_0^h H(r)w_(t-r)dr,

with H in L2[0,h]. Let gamma_1 and gamma_2 be the actual supremal expected-path-L2 ratios separately over nonzero E1 and E2 disturbances. Define E0=D1L0, Eh=D1Lh. Then

 h>0:  gamma_1,gamma_2 >= || [E0; Eh] ||op,
 h=0:  gamma_1,gamma_2 >= || E0+Eh ||op.                    (1)

The stack is vertical. Thus for THIS law every gamma strictly below the right side is impossible for the original strict literal criterion. Equality is NOT ruled out: a supremum can fail to be attained. The result is independent of plant stability, rank, stochastic control diffusion, hidden state, and signs/directions of matrix taps. It does not optimize K,L or state anything about existential controller synthesis.

2. Uniform state bound available for the entire pulse family

The imported full-preview source proves, by localized L1 martingale control, a finite constant C_state depending only on this fixed law and T,h such that

 E sup_(0<=t<=T)||x_t|| <= C_state E||w||_L2[0,S]           (2)

for ALL progressive E1 inputs. This is an actual physical state bound, not an RMS or deterministic-reference bound. We use it only to show the continuous state response has negligible L2 mass on shrinking time windows; no detailed state distribution or chosen reference plant is introduced.

3. Universal time-localized test family, h>0

For every vector a in the disturbance space and every 0<epsilon<min(h,S)/2, consider the deterministic progressive input

 w_epsilon(t)=epsilon^(-1/2) a 1_[0,epsilon](t).

It is E2 as well as E1, has ||w_epsilon||_2=||a||, and w_epsilon(t-h) is supported on the disjoint interval [h,h+epsilon]. These are a proof family for ALL directions a and all sufficiently small epsilon, not a selected candidate optimizer or calibrated reference law.

On the union I_epsilon=[0,epsilon] union [h,h+epsilon], the direct atom output

 E0 w_epsilon(t)+Eh w_epsilon(t-h)

has exact L2 norm sqrt(||E0 a||²+||Eh a||²). On I_epsilon the state contribution satisfies, by (2),

 E||1_I O x||_2 <= ||O|| sqrt(2epsilon) C_state ||a|| ->0,

where O=D0+D1K. This includes stochastic and deterministic state responses and needs no E2-based estimate.

For the regular distributed output operator let E(r)=D1 H(r). At the first window, only r in [0,epsilon] can contribute; at the delayed window, only r in [h-epsilon,h] can contribute. Young's inequality gives

 ||1_I integral_0^h E(r)w_epsilon(.-r)dr||_2
 <= [integral_0^epsilon ||E(r)||dr
     +integral_(h-epsilon)^h ||E(r)||dr] ||a|| ->0,

since H is L2 on the finite interval and hence L1. No other direct atom overlaps the opposite window for epsilon<h/2.

The reverse triangle inequality for the WHOLE actual z, restricted to I_epsilon, gives

 liminf_(epsilon->0) E||z(w_epsilon)||_2 / ||a||
 >= sqrt(||E0 a||²+||Eh a||²)/||a||.

Every w_epsilon is admitted to BOTH gain classes. Taking the supremum over ALL a!=0 proves the h>0 inequality in (1), without assuming a norm-attaining input.

4. The coincident h=0 case

When h=0, the two direct atoms coincide and the distributed term has empty support. The same first-window family yields

 liminf E||z(w_epsilon)||/||a|| >= ||(E0+Eh)a||/||a||,

because (2) makes the continuous state contribution o(1). Taking all directions proves the second line of (1). It would be wrong to stack E0 and Eh when h=0.
