1. Actual finite-horizon setup and statement

Fix finite T>0 and arbitrary real original plant matrices, one Brownian W, x0=0, and the registered input domain w supported on [0,T-h]. The actual plant is

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u.

For each h in [0,T), choose the admissible zero controller u=0. Then for every progressive E1 input,

 E||z||_L2[0,T] <= H(T-h) E||w||_L2[0,T-h],              (1)

where H(S) is the deterministic covariance expression below and H(S)->0 as S downarrow 0. In fact, with alpha=2||A||op+||A0||op²,

 H(S) <= ||D0||op ||C||F [integral_0^S(S-t)e^(alpha t)dt]^(1/2)
      <= ||D0||op ||C||F (S/sqrt(2))e^(alpha S/2).         (2)

Therefore, if h is genuinely FREE to approach T, every gamma>0 is strictly feasible for some h<T with u=0, and the infimum of the actual finite-horizon E1/E2 gains over h and laws is 0. This is a shrinking-disturbance-window effect, not evidence of an improved preview controller. Gamma=0 is never pointwise strict for nonzero w. The infimum need not be attained by any allowed h<T.

2. Exact E1 covariance upper and correct information order

Let S=T-h and shift time to the last interval [h,T]. Before h the zero-start state remains zero. The actual homogeneous flow Phi(s,r) for matrices A,A0 depends only on Brownian increments after r. For 0<=s<=S, define the output-time column

 (K_s v)(t)=1_(t>=s)D0 Phi(h+t,h+s) C v,  0<=t<=S.

The original disturbance w_s is F_s measurable, hence F_(h+s) measurable, while K_s depends only on increments after h+s and is independent of F_(h+s). Variation of constants and Bochner–Minkowski therefore give in the ORIGINAL unsquared E1 criterion

 E||z|| <= integral_0^S E|w_s| E||K_s||op ds
         <= [integral_0^S (E||K_s||op)^2ds]^(1/2) E||w||.

Jensen and the Frobenius bound define the deterministic majorant

 H(S)^2=integral_0^S (S-t) E||D0 Phi(t,0) C||F²dt.        (3)

No RMS input ratio, deterministic-reference optimizer, anticipative kernel or E2 input condition is used. The displayed factorization respects the physical injection time h+s and holds even when w is adapted to all earlier noise.

3. Explicit small-window estimate

For X_t=Phi(t,0)C, Itô's formula and the matrix norm inequality give

 d/dt E||X_t||F² <= [2||A||op+||A0||op²] E||X_t||F².

Thus E||D0 X_t||F²<=||D0||op²||C||F²e^(alpha t). Inserting this into (3) proves (2). In particular H(S)=O(S), with an explicit bound for every S>0. Given gamma>0, choose any S in (0,T) making the right side of (2) strictly less than gamma and set h=T-S; no optimization or numerical solver is needed.

The conclusion DEPENDS on the input domain [0,T-h]. If inputs remain allowed through time T, if h is prescribed, if there is direct disturbance output or input-driven noise not removed by u=0, or if the horizon is infinite, this argument does not apply as stated.
