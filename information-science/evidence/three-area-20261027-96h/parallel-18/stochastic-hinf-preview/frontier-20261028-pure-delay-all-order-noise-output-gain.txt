1. Actual original pure-delayed law

Fix finite T>0 and fixed arbitrary original matrices and fixed K,Lh. For S=T-h>0 with S<=h, use the actual original plant and pure delayed law

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u,       u=Kx+Lh w_(t-h),   x0=0.

w is progressive vector E1/E2 supported [0,S]. L0=H=0, but B0Lh and D1Lh may be NONZERO. Set

 P=A+BK, Q=A0+B0K, F=BLh+C, G=B0Lh,
 O=D0+D1K, E=D1Lh, a=||P||op, q=||Q||op.

Before h the state and output vanish. The entire input is F_h-measurable before independent post-h noise, so the named revelation theorem applies. The same fixed K,Lh are used as S varies; h and hence the input domain may vary. This is not a fixed-h claim.

2. Exact weighted unit-window coefficient operators

On the unit interval, for deterministic v in L2[0,1], define

 X_G(v)(t)=integral_0^t G v_s dB_s,
 X_F(v)(t)=integral_0^t F v_s ds,
 (D x)(t)=integral_0^t P x_s ds,
 (N x)(t)=integral_0^t Q x_s dB_s.

D has weight2 and N weight1; both stochastic integrals use the SAME B. Define T_0 v=E v, and for k>=1

 T_k v=O [ sum_(W:2#D+#N=k-1) W X_G(v)
             + sum_(W:2#D+#N=k-2) W X_F(v) ].            (1)

A negative weight sum is empty; the empty word is included at weight0. Put c_k=||T_k||_(L2_input -> L1(Omega;L2_time)). Thus T1 v=O integral Gv dB, while T2 has the drift term O integral Fv dt and the double-noise term O integral Q integral Gv dB dB. These are original expected-path norms; c_k need not be attained.

3. All-order leading gain and an explicit remainder

If T_0,...,T_(k-1) are the zero OPERATORS, then BOTH actual E1/E2 given-law gains satisfy

 gamma_i(S)=c_k S^(k/2)+O(S^((k+1)/2)),      i=1,2.        (2)

More explicitly, for 0<S<=1 and alpha=aS+8q sqrt(S)<=1/2, use the finite C_j constants from the named all-order source:

 C_j=sum_(l=0)^j sum_(i=0)^l 1_(l+i>=j+1)
       binom(l,i)a^i(8q)^(l-i)+2(a+8q)^(j+1).

For k>=1,

 |gamma_i-c_k S^(k/2)|
 <=||O||[8||G|| C_(k-1)+||F|| D_k] S^((k+1)/2),
 D_1=2, D_k=C_(k-2) for k>=2.                             (3)

For k=0, c0=||E||op and

 |gamma_i-c0|<=2||O||[8||G||+||F||] sqrt(S).              (4)

These are absolute estimates; if c_k=0 the inequality does not identify a next order. No claim about a first nonzero coefficient or word independence is made.

4. E1 derivation and why the output atom is different

On the post-h window, x=X_G+X_F+(D_S+N_S)x. In E sup norm, ||D_S||<=aS,||N_S||<=8q sqrt(S), while the L1 maximal inequality and Cauchy give

 E sup||X_G||<=8||G|| E||w||,
 E sup||X_F||<=||F||sqrt(S) E||w||.

The Neumann series converges for alpha<=1/2. With r=sqrt(S)<=1, a word of weight j contributes r^j to either state base; the output-path norm adds one factor r. The G base therefore has output order r^(j+1), the F base r^(j+2), yielding (1). Summing word weights above k exactly as in the named all-order source yields (3); for k=1 the entire F series is bounded by2||F||r². For k=0, the entire state response has expected path norm at most `2||O||[8||G||+||F||]r E||w||`, while the direct atom Ev contributes c0 without a vanishing window factor.

Because the entire input path is revealed at h and future Brownian noise is independent, each scaled leading operator's actual E1/E2 gain equals c_k S^(k/2) by the named revelation/energy-weighting argument. Uniform E1 error plus deterministic near-maximizers gives (2)–(4). This does not say the leading Banach operator attains its norm: with additive input diffusion it can be noncompact, as shown in `frontier-20261028-revealed-additive-noise-noncompactness-obstruction.txt` SHA256 `97b3c3b6d031967d7e54a6ae6fa1b616683b2edd9fd7618464c1c0d26d8cab0b`.

5. Three concrete leading regimes

* If E!=0, gamma_i(S)=||E||op+O(sqrt(S)); shrinking the input window DOES NOT erase this given law's direct feedthrough.
* If E=0 and O G!=0, T1 is nonzero and gamma_i(S)=c1 sqrt(S)+O(S), c1>0. For example dx=w_(t-h)dW,z=x has exactly this sqrt(S) scaling under revealed timing; its numerical c1 is not asserted.
* If E=G=0 and O F!=0, T0=T1=0 and T2 is deterministic Volterra, so c2=(2/pi)||OF||op and the leading term is `(2/pi)||OF|| S`, agreeing with the u=0 source.

These are finite-window given-law examples, not claims about choosing h freely or optimal feedback.
