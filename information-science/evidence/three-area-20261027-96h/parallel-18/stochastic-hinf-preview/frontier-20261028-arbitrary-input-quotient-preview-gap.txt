1. Exact physical model and complete input-matrix scope

For arbitrary finite n,m,p,r, T>h>=0, S=T-h, real constant A,A0,B,B0,C,D0,D1,K,L, scalar W and vector w in R^m, use the actual original law

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u,                  u=Kx+Lw_t,

x0=0, w supported in [0,S], canonical Brownian filtration and every progressive E1 input E||w||<infinity. The ONLY algebraic restrictions are

 B0 L=0,       D1 L=0.                                     (R)

Define P=A+BK, Q=A0+B0K, b=BL, c=C, D=D0+D1K. P,Q need not commute; b,c may have any ranks, mutual cancellations and unobservable directions; p may be less than m. The closed law is dx=(Px+bw_t+c w_(t-h))dt+Qx dW, z=Dx.

Let Phi(t,s) be its actual linear Itô fundamental flow, and define the physical operator-valued column

 (K_s a)(t)=1_(t>=s)D Phi(t,s)b a +1_(t>=s+h)D Phi(t,s+h)c a.

Let Cbar(s)=E||K_s||_(R^m -> L2([0,T];R^p)) and Gamma=(integral_0^S Cbar(s)^2ds)^(1/2). Let H be the deterministic Hilbert–Schmidt covariance bound from the first named source. Both concern the ORIGINAL expected path norms; no RMS substitution is made.

2. Exact zero and gain-gap theorem, without extra rank hypotheses

In every nonzero-output case of this actual given-law physical system, there exists a deterministic model-dependent epsilon>0 such that for EVERY progressive E1 w,

 E||z|| <= (1-epsilon)Gamma E||w|| <= (1-epsilon)H E||w||. (A)

The true fixed-law literal progressive gain is strictly positive and strictly smaller than Gamma; gamma=Gamma is uniformly strictly feasible. Gamma is NOT claimed equal to the actual gain, and this does not resolve strict endpoint transfer at that gain or general preview synthesis. epsilon is guaranteed by the explicitly defined positive-probability event in the named sources; no numerical value is asserted.

Zero-output is characterized exactly by the finite-dimensional subspace in section 3. In a zero case z=0 for every input, actual gain Gamma=H=0, and gamma>0 (not gamma=0) is strictly feasible.

3. Deterministic maximal invisible input subspace

Let N be the largest common P,Q-invariant subspace in ker D, equivalently the intersection of ker[D word(P,Q)] over all finite words. Compute it by N0=ker D and N_(k+1)=Nk intersect P^(-1)Nk intersect Q^(-1)Nk, until stable. For a matrix v define N_in(v)={a:v a in N}. Now let

 Nstar = N_in(b) intersect N_in(c)       if h>0,
 Nstar = N_in(b+c)                      if h=0.              (1)

For any a in Nstar, the pathwise Itô flow preserves N, so K_s a=0 for all relevant s,t almost surely. Conversely, the quotient argument below and named sources show that if Nstar is a proper subspace, the actual output operator has positive gain. Therefore zero-output is equivalent to Nstar=R^m.

4. Exact isometric quotient of inputs, columns and literal gain

If r=dim(Nstar^perp)>0, choose any deterministic orthonormal basis U in R^(m x r) of Nstar^perp and set

 b'=bU,   c'=cU,   what=U^T w,   K'_s=K_s U.

For h>0, `N_in(b') intersect N_in(c')={0}`; for h=0, `N_in(b'+c')={0}`. Indeed U what is in Nstar only when what=0. These reduced input matrices satisfy precisely the hypotheses of the appropriate named source, regardless of the original ranks. The new disturbance what is progressively measurable, E1 (or E2 whenever w is E2), has the same support and obeys pathwise ||what||<=||w||.

Moreover K_s vanishes on Nstar, so the actual output satisfies

 z(w)=z'(what) pathwise,
 ||K_s||op = ||K_s U||op,      ||K_s||HS = ||K_s U||HS.     (2)

The norm equalities are exact: decompose R^m orthogonally into Nstar^perp and Nstar; the column operator annihilates the latter. Thus Gamma'=Gamma and H'=H. There is no factor depending on r or m and no estimate replacing the original physical column.

For each disturbance class i=1 or i=2 SEPARATELY, the supremal literal gains are EXACTLY equal between the original and the quotient: every full w projects to a quotient input with no larger denominator and the same numerator; every quotient what lifts to w=U what with identical numerator and denominator.
