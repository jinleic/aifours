1. Exact original law and new joint condition

For arbitrary finite dimensions, consider the same original closed-loop vector-input model and actual preview law

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u,                   u=Kx+Lw_t,

scalar W, progressive vector E1 w in R^m supported on [0,S], x0=0, S=T-h>0, and B0L=D1L=0. Put P=A+BK,Q=A0+B0K,b=BL,c=C,D=D0+D1K. Let N be the largest common (P,Q)-invariant subspace in ker D, and N_in(v)={a:v a in N}. All are finite-computable as in the dynamic-visibility source.

Assume the NEW joint condition

 h>0,      T>2h,       N_in(b) intersect N_in(c)={0}.      (J)

Neither tap separately need have an injective observable-input map, full matrix rank, a sign condition, or p>=m. Under (J), the same expected-path-L2 statement holds for ALL progressive E1 (and E2) inputs:

 E||z|| <= (1-epsilon)Gamma E||w|| <= (1-epsilon)H E||w||,

where Gamma is the actual expected operator-column bound, H is the deterministic HS moment bound from the vector-input source, and epsilon>0 is given by its weighted-future-event formula using the event constructed in sections 3–4. Thus the actual fixed-law literal gain is >0 and gamma=Gamma is uniformly strictly feasible. Gamma is NOT claimed to be the true gain or its endpoint.

Condition T>2h is used only to create two disjoint output prefixes that each include both taps. This candidate makes NO claim for the complementary-tap case T<=2h; it does not alter the wider-horizon applicability of the previous single-tap cases.

2. Recovering complementary input directions in one short prefix

The physical column for input direction a is

 K_s(t)a=1_(t>=s)D Phi(t,s)b a+1_(t>=s+h)D Phi(t,s+h)c a.

Let Nb=N_in(b). Since N is invariant under P,Q, for a in Nb the first term is identically unobservable for every future time. The intersection in (J) means c a is outside N for EVERY nonzero a in Nb.

The dynamic-visibility source proves the following generic finite-dimensional fact: for any initial state outside N, an arbitrarily short piecewise-linear scalar driver produces a nonzero observed output; iterating such drivers strictly decreases a finite-dimensional input Gramian kernel. Apply it on [0,h) to the b-column, stopping when the input kernel is precisely Nb. This is possible within h: Nb is always in the early kernel; whenever the kernel has an a outside Nb, b a is outside N and controlled flow (and its inverse) preserve N, so another arbitrarily short driver removes that a. The kernel loses at least one dimension each time and at most m removals are needed. Extend the resulting driver until time h.

For remaining a in Nb, the early state Phi(h,0)b a lies in N. After the delay, its output is zero under every future flow, so the only visible contribution is D Phi(t,h)c a. As c maps Nb injectively modulo N by (J), the same dimension-drop construction on any strictly positive post-h interval observes all remaining directions. Consequently, for EVERY Lprefix>h there exists a piecewise-linear driver beta on [0,Lprefix] for which the full two-tap prefix input Gramian

 integral_0^Lprefix [K_0(t)]^T K_0(t)dt

is positive definite. This is a statement about all input directions simultaneously; it does not construct or optimize a disturbance.

3. Two disjoint observable prefixes, with the exact horizon geometry

Let epsilon_time=(S-h)/10>0, delta=epsilon_time, s0=2epsilon_time, u0=S-2epsilon_time, and Lprefix=h+epsilon_time. Then

 delta<s0<u0<S,    s0+Lprefix<u0,    u0+Lprefix<T.

For the actual Itô flow, the dynamic-visibility source's one-Brownian Doss–Sussmann transformation makes the column prefix Gramian continuous in uniform driving-path norm; Brownian full support around the driver from section 2 gives positive probability of a positive-definite prefix Gramian. The Brownian windows [s0,s0+Lprefix] and [u0,u0+Lprefix] are disjoint, so both prefix Gramians are simultaneously positive definite with positive probability.

Continuous two-parameter flow and a countable selection then give deterministic positive-length intervals I,J around s0,u0, rational lambda_I,lambda_J>0 and finite rational M0 such that sup I+Lprefix<inf J and the following event E0 has probability p0>0:

 inf_(s in I, |a|=1) ||1_[s,s+Lprefix] K_s a||>=lambda_I,
 inf_(u in J, |a|=1) ||1_[u,u+Lprefix] K_u a||>=lambda_J,
 sup_(v in I union J)||K_v||op<=M0.

Both I,J lie after delta; E0 uses only Brownian increments after delta and is independent of F_delta. For arbitrary actual input directions w_s,w_u, the earlier prefix lies before every possible support of K_u w_u. Hence with xi=1-sqrt[1-(lambda_I/M0)²]>0,

 |<K_s w_s,K_u w_u>| <= (1-xi)||K_s w_s||||K_u w_u||,
 ||K_s w_s||>=lambda_I|w_s|,  ||K_u w_u||>=lambda_J|w_u|.

The prefix values and probability are model-dependent existence constants, not claimed numerically evaluated.

4. Exact E1 gain conclusion and its scope

The vector-input predecessor's covariance/fourth-moment formula gives f=Cbar/Gamma>=f0>0 on [0,S), where Cbar(s)=E||K_s||op. Positivity of its deterministic second-moment function follows from joint visibility: if b has any visible direction, the initial h interval contributes; if b is entirely invisible, (J) makes c visible on every nonzero direction and the delayed tail contributes. The predecessor's

 R=integral ||K_s w_s||ds <= Rbar=integral ||K_s||op |w_s|ds,
