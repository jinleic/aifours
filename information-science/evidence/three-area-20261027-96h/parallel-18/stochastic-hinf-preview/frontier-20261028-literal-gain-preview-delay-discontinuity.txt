1. Actual original plant and fixed controller

Fix T>0 and use the registered original plant/control

 dx_t=0,     z_t=u_t,
 u_t=w_t-w_(t-h),      x0=0,

with scalar W, any progressive scalar E1/E2 w supported on [0,S], S=T-h. This is realized by D1=1,L0=1,Lh=-1,H=0,K=0 and all state/disturbance matrices zero. The controller coefficients are FIXED as h changes and are uniformly bounded. State/noise are irrelevant; the law remains in the actual full preview class.

2. Exact gain for every h>0

For 0<h<T put n=ceil((T-h)/h). The output is the deterministic direct-atom operator A_h:w(t)->w(t)-w(t-h). Partitioning time into residues modulo h identifies its operator norm with the (n+1) x n difference-chain matrix

 B_n a=(a0,a1-a0,...,a_(n-1)-a_(n-2),-a_(n-1)).

The pathwise deterministic operator inequality gives gamma1,gamma2<=||B_n||. A deterministic top chain singular vector multiplied by an L2 residue function on the positive-measure n-chain region is an admissible E2 input attaining equality; hence BOTH true original expected-path gains are

 gamma1(h)=gamma2(h)=||B_n||=2 cos[pi/(2(n+1))].           (1)

The eigenvalue calculation is exact: B_n^T B_n has diagonal 2 and adjacent off-diagonal -1, with eigenvalues 2-2cos(k pi/(n+1)), 1<=k<=n. The last eigenvalue gives (1). At gamma=gamma_i(h)>0 the deterministic equality witness makes the original pointwise strict criterion fail.

3. Exact h=0 jump and its interpretation

At h=0 the two taps are the SAME input and cancel identically, z=0 for all w, so gamma1(0)=gamma2(0)=0. But as h downarrow 0, n->infinity and (1) gives

 lim_(h downarrow 0) gamma1(h)=lim gamma2(h)=2 !=0.        (2)

Thus even fixed bounded tap matrices can produce an O(1) jump in the TRUE literal gain when the delay changes to zero. The mechanism is that unrestricted L2 input can oscillate on the delay scale; pointwise/strong convergence of shifts is not operator-norm convergence. The example is consistent with lower semicontinuity because the limit gain at h=0 is BELOW the positive-h liminf. It does not imply that every law is discontinuous, or give a counterexample to the bounded-gain minimizer theorem.

The case n=2 was independently checked in exact Python Fraction arithmetic: `B2^T B2=[[2,-1],[-1,2]]`, eigenvalues 3,1 and gamma=sqrt(3). The full chain eigensystem is a standard finite tridiagonal calculation; no float/simulation establishes it.
