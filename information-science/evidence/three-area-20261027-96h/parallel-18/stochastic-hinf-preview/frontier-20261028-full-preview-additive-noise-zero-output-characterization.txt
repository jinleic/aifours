1. Actual original model and closed-law signals

For arbitrary finite real matrices, scalar W, vector progressive E1 disturbance w supported on [0,S], S=T-h>0, consider

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u, x0=0,
 u=Kx+L0w_t+Lh w_(t-h)+integral_0^h H(r)w_(t-r)dr.

Assume H in L2[0,h] and the given fixed K satisfies Q=A0+B0K=0. NO restriction is imposed on B0L0,B0Lh,B0H,D1L0,D1Lh or D1H. Define

 P=A+BK, O=D0+D1K,
 F0=BL0, Fh=BLh+C, F(r)=B H(r),
 G0=B0L0, Gh=B0Lh, G(r)=B0 H(r),
 E0=D1L0, Eh=D1Lh, E(r)=D1 H(r).

The closed law is dx=(Px+f)dt+g dW,z=Ox+o, where f,g,o are the respective actual deterministic causal time operators applied to w. All are bounded L2[0,S] -> L2[0,T] by Young's inequality.

Let N=intersection_(0<=j<n) ker(O P^j), the maximal P-invariant unobservable state subspace, and let Pi be the orthogonal projection onto N^perp. Define the bounded deterministic operators

 (Gop w)(t)=G0w_t+Gh w_(t-h)+integral_0^h G(r)w_(t-r)dr,
 (Top w)(t)=E0w_t+Eh w_(t-h)+integral_0^h E(r)w_(t-r)dr
           +integral_0^t O exp[P(t-s)] f_s ds.

w is extended by zero outside [0,S]. Top is the complete deterministic drift/direct-output map; Gop is the actual additive-noise coefficient map, NOT a gain surrogate.

2. Exact necessary-and-sufficient operator criterion

**Theorem.** Universal physical zero output

 z=0 in L2[0,T] a.s. for EVERY progressive E1 disturbance

holds if and only if

 Top=0  and  Pi Gop=0 as deterministic L2 operators.       (Z)

Thus the actual given-law literal gain is exactly 0 iff (Z), and the strict criterion holds for every gamma>0 (not gamma=0). For fixed K with Q=0, (Z) is an affine linear feasibility system in all the tap unknowns L0,Lh,H. It does NOT solve the general positive-gain synthesis problem, optimize K, or apply to arbitrary Q!=0.

3. Necessity from exact mean and stochastic isometry

Take every deterministic L2 input w, a subset of both E1 and E2. Variation of constants gives in output path space

 z=Top w + [t -> integral_0^t O exp(P(t-s))(Gop w)_s dW_s].

The stochastic term is centered, so universal z=0 implies Top w=0 for every deterministic w, i.e. Top=0. Itô isometry and Tonelli then imply

 0=E||z||²=integral_0^T integral_s^T
      ||O exp[P(t-s)](Gop w)_s||²dt ds.

For almost every s<T, the inner analytic function of t-s vanishes on a nontrivial interval. By its Taylor series and Cayley–Hamilton, (Gop w)_s lies in N. This holds for every deterministic w, hence Pi Gop=0 as an operator. This is an all-input necessity argument, not optimization of a selected reference disturbance.

4. Sufficiency for genuinely E1-only random inputs

For each random input path w(omega) in L2, the deterministic operator identities give Top w(omega)=0 and (Gop w)(omega) in N for almost every time. N is P-invariant and killed by O, so O exp[P(t-s)](Gop w)_s=0. Localized stochastic Fubini/Itô integration therefore gives zero stochastic output, and the deterministic output is already zero. This applies to progressive E1 inputs even when their E2 moment is infinite.

5. Exact impulse/Volterra form of the affine equations

For h>0, write the deterministic output's ordinary causal kernel on 0<tau<T as

 k(tau)=1_(tau<h) E(tau)+O exp(P tau) F0
       +1_(tau>=h) O exp[P(tau-h)] Fh
       +integral_0^min(h,tau) O exp[P(tau-r)] F(r)dr.

Then (Z) is equivalent to the explicit affine linear conditions

 E0=0, Eh=0, k(tau)=0 for a.e. tau in (0,T),
 Pi G0=0, Pi Gh=0, Pi G(r)=0 for a.e. r in (0,h).        (K)

The first line is Top=0 and the second is Pi Gop=0. To see necessity despite finite S, test arbitrarily narrow deterministic input pulses near time zero (their support lies in [0,S]); approximate-identity convergence identifies the ordinary kernel on (0,T), while short pulses straddling 0 and h identify the two distinct direct atoms. The ordinary kernels are locally L1 since H is L2 and T is finite. The converse follows immediately by convolution. The endpoint h is a Lebesgue-null set for the density and is separate from the atom at h.

For h=0 the taps coincide: H has empty integration interval, replace E0,Eh by E0+Eh and G0,Gh by G0+Gh; the ordinary deterministic kernel is O exp(P tau)(F0+Fh). Thus zero output iff E0+Eh=0, Pi(G0+Gh)=0 and O exp(P tau)(F0+Fh)=0 a.e. on (0,T). The h=0 atoms must NOT be constrained separately.
