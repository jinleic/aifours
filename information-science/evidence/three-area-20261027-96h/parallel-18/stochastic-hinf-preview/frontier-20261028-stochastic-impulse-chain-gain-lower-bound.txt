1. Actual law and the finite stochastic impulse functional

Use the exact original finite-horizon scalar-Brownian plant and ANY deterministic full linear preview law from the named chain source, T>h>=0, S=T-h>0, vector progressive E1 w, x0=0. Define the actual closed matrices

 P=A+BK, Q=A0+B0K, O=D0+D1K,
 E0=D1L0, Eh=D1Lh, G0=B0L0, Gh=B0Lh.

All matrices, direct output/noise taps and the distributed L2 kernel H are unrestricted. Let gamma1,gamma2 be the ACTUAL E1 and E2 supremal gains using the same original ratio E||z||_path/E||w||_path.

For h>0 put n=ceil(S/h), tj=jh, 0<=j<=n, and let a=(a0,...,a_(n-1)), a_-1=a_n=0. Define finite vectors

 Dj=E0 aj+Eh a_(j-1),   Gj=G0 aj+Gh a_(j-1), 0<=j<=n.

On an auxiliary probability space let xi_0,...,xi_n be independent N(0,1), independent of a Brownian Wbar. Let the cadlag impulse state X^a start at zero immediately before 0, jump by Gj xi_j at tj, and obey

 dX=P X dt+Q X dWbar

between jumps. It has finite E||X||_L2[0,T]. Define the deterministic homogeneous lower functional

 L(a)=E [ sum_(j=0)^n ||Dj||² + integral_0^T ||O X^a_t||²dt ]^(1/2).

Then the NECESSARY bound is

 gamma1,gamma2 >= sup_(a!=0) L(a)/||a||.                   (2)

At h=0 there is one impulse: D=(E0+Eh)a, G=(G0+Gh)a, X jumps by G xi at 0 and follows the same homogeneous SDE; the corresponding one-vector form of (2) holds. This bound may involve a non-elementary stochastic expectation, but it is an exact original-criterion lower bound, not an RMS proxy or an asserted sharp gain.

3. Why the impulse functional is the limit of real physical inputs

For h>0, use the entire all-variable coefficient family of the named direct-chain proof:

 w_epsilon(t)=epsilon^(-1/2) a_j on [tj,tj+epsilon], 0<=j<n,
 zero otherwise, with epsilon<h/2 and epsilon<S-(n-1)h.

These are admissible deterministic E2 (hence E1) inputs with path norm ||a||. Both current and delayed noise taps overlap on window [tj,tj+epsilon] as Gj/sqrt(epsilon). Their Brownian increments xi_j^epsilon=(W_(tj+epsilon)-W_tj)/sqrt(epsilon) are independent standard normals. The direct-output atoms on those windows have exactly sum_j||Dj||² squared path norm.

All other forcing becomes negligible in the correct norms: the total L1 norm of the pulse input is sqrt(epsilon) sum_j||aj||; for the L2 distributed kernel H, Young gives ||H*w_epsilon||_L2 <= ||H||_L2 ||w_epsilon||_L1=O(sqrt(epsilon)). Thus distributed drift/noise/output terms vanish in the needed norms, and the current/delayed DRIFT atoms have L1 norm O(sqrt(epsilon)). The Qx and Px contributions DURING each pulse window have L2 size O(sqrt(epsilon)) and O(epsilon), respectively: standard linear SDE E2 estimates give a uniform bound on E sup_t||x_epsilon||² for this fixed coefficient vector. At each pulse end, the actual state increment therefore equals Gj xi_j^epsilon plus an L2 error tending to zero. Between windows, ordinary linear SDE L2 stability shows that the state is close in L2(Omega x time) to the homogeneous impulse process with the same pulse normals. State output on the union of n+1 windows has expected path norm O(sqrt(epsilon)).

For the limiting distribution, delete the disjoint pulse-window Brownian increments. The remaining process is a Brownian motion with the deterministic paused clock `t - length([0,t] intersect union windows)`, independent of every xi_j^epsilon; its clock converges uniformly to t. The impulse times converge to tj. Standard continuity of finite-dimensional linear Itô flows, equivalently the one-Brownian Doss–Sussmann ODE transform, gives convergence of the physical outside-window state output to O X^a in L2-time distribution, with uniform second moments. The exact atom output and outside-window state output have disjoint time support; hence their combined path norm tends in distribution to the square root defining L(a). Uniform second moments give uniform integrability, so the EXPECTATION of this path norm converges. All remainder terms above vanish in expected path norm. The same reasoning with one initial window applies at h=0.

Thus each all-variable pulse family gives lim E||z(w_epsilon)||/||w_epsilon||=L(a)/||a||, proving (2). Neither a single sampled input nor an empirical limit is a proof of this all-variable result.

4. A strict gap above the direct-atom threshold

The named direct-chain bound is delta=||B_n|| with B_n a=(D0,...,Dn). Since L(a)>=||B_n a||, (2) always strengthens it. More: suppose a* is ANY unit top singular vector of B_n and for some j, O Gj(a*)!=0. All tj<T. At that impulse, conditional on the previous state, O X jumps by O Gj xi_j with an independent nondegenerate Gaussian, so it is nonzero almost surely at that instant; right continuity yields positive output energy with positive probability. Therefore

 L(a*)>delta, and hence gamma1,gamma2>delta.                (3)

Thus gamma=delta is impossible for the original strict criterion in this condition, even though the direct-atom bound alone could not decide equality. This condition is sufficient, not necessary; it does not assert that the impulse lower bound is the actual gain.

5. Actual scalar example and bounded diagnostic

For h=0,T=1, actual dx=w dW,z=w+x (realized by u=w, B0=1,D1=1,D0=1, all other plant terms zero), the one-impulse functional is

while the direct atom bound is exactly delta=1. Indeed L(1)>=1+(sqrt(2)-1)P(|xi|>=1)>1. Hence this actual full stochastic law CANNOT satisfy the literal strict inequality at gamma=1. The theorem does not say L(1) is the true gain.
