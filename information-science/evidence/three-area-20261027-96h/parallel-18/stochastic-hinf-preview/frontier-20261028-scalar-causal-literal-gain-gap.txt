Status: NEW WRITTEN CANDIDATE, UNREVIEWED AND UNADOPTED. Native prewrite observation Wed Oct 28 17:57:57 PDT 2026. Actual original expected-path-L2 criterion, not RMS. Bounded diagnostics described in section 8; no numerical value is used to establish the inequality.

1. Claim and physical scope

For all T>0, a,sigma real, nonzero scalar c,d, let the actual h=0 original plant with zero initial state, zero control and canonical Brownian information be

 dx_t=(a x_t+c w_t)dt+sigma x_t dW_t,     z_t=d x_t.

The progressively measurable input w ranges over every nonzero E1 input, E||w||_L2[0,T]<infinity (and in particular over every E2 input). We prove a strictly positive deterministic epsilon_0, explicitly defined below, such that

 E||z||_L2 <= |cd| (1-epsilon_0) Gamma E||w||_L2
             <= |cd| (1-epsilon_0) H E||w||_L2.             (A)

Here Gamma is the actual mean future-kernel Minkowski bound and H is the explicitly elementary Gaussian upper bound in section 2. Therefore gamma=|cd| Gamma is uniformly, pointwise strictly feasible for THIS original stochastic plant even when sigma!=0, with the explicit relative margin epsilon_0. More strongly, |cd|(1-epsilon_0)H is an elementary uniform upper bound on its actual literal gain. This is a fixed-law strict FEASIBILITY statement; it is NOT an exact expression for the physical gain, a proof of E1/E2 endpoint transfer at the actual gain, a preview synthesis theorem, or a source-book equivalence claim.

2. Actual future-noise kernel and exact bounds

Put alpha=a-sigma^2/2 and k_s(t)=1_(s<=t<=T) exp[alpha(t-s)+sigma(W_t-W_s)]. The exact physical solution is

 x_t=c integral_0^t k_s(t) w_s ds.

Define the deterministic functions

 C(s)=E( integral_s^T k_s(t)^2dt )^(1/2),
 ell(s)=( integral_0^(T-s) exp(2a v)dv )^(1/2),
 Gamma=( integral_0^T C(s)^2ds )^(1/2),
 H=( integral_0^T (T-v)exp((2a+sigma^2)v)dv )^(1/2).

0<Gamma<=H<infinity. By the Gaussian exponential identity and Jensen, ell(s)<=C(s)<=sqrt(integral_0^(T-s) exp((2a+sigma^2)v)dv). In particular, Gamma is exactly the L2 norm of a one-dimensional family of genuine future-increment expectations, not a substituted RMS gain. Set rho=2a+sigma². H²=(exp(rho T)-1-rho T)/rho² if rho!=0, and H²=T²/2 if rho=0.

3. Fully defined positive constants

Let delta=T/8, I=[T/4,T/3], J=[2T/3,3T/4], choose any deterministic r>0, and set

 f0(s)=ell(s)/H,
 b0=(integral_0^delta f0(s)^2ds)^(1/2),
 bI=integral_I f0(s)ds,      bJ=integral_J f0(s)ds,
 eta=min{ bI/(2 sqrt(|I|)), bJ/(2 sqrt(|J|)) },
 p=P(sup_(0<=v<=T-delta) |B_v|<=r)>0 for standard Brownian B,
 m=exp[-(|alpha|T+2|sigma|r)],     M=1/m,
 xi=1-sqrt(1-m^2/(3M^2)),
 cI=m sqrt(2T/3) bI/2,      cJ=m sqrt(T/4) bJ/2,
 epsilon_0=min{ p^2 b0^2/[128(1+p)^2], p eta^2/16,
                xi cI cJ p^2/(8 H^2) } > 0.              (B)

Every quantity is deterministic and positive. The small-ball probability p can also be evaluated as the absolutely convergent series

 p=(4/pi) sum_(j>=0) (-1)^j/(2j+1)
        exp[-(2j+1)^2 pi^2 (T-delta)/(8r^2)].

The value epsilon_0 is deliberately conservative; no optimization is claimed. It is less than 1 by its first term, so (A) has the stated direction.

4. E1 validity of the unsquared kernel bound

Write U=||w||, O=||integral k_s w_s ds|| and

 R=integral_0^T |w_s| ||k_s||_L2[0,T] ds.

Pathwise Bochner–Minkowski gives O<=R. R is integrable: for each s, ||k_s|| depends only on Brownian increments after s and is independent of F_s, whereas w_s is F_s-measurable. Tonelli and ordinary Cauchy–Schwarz give

 E R = integral_0^T C(s) E|w_s| ds
     = E integral_0^T C(s)|w_s| ds <= Gamma E U.              (1)

This is an L1 expectation of the PATH norm from the start; no E2 input requirement or square-before-expectation substitution is used. The factorization in (1) is precisely where adaptedness and future-increment independence enter. Pathwise continuity of Brownian paths and pathwise L2 input ensure the solution and the Bochner integral exist; (1) proves output integrability.

5. Near-equality forces input shape before future noise

Normalize E U=1, permissible by homogeneity. Let f=C/Gamma, so ||f||_2=1 and f>=f0. On {U>0} set v=|w|/U and e=||v-f||_2; set e=0 if U=0. The physical deficit

 q=1-E O/Gamma >=0

satisfies, exactly,

 Gamma-E R = Gamma/2 E[U e^2],      hence E[U e^2]<=2q.    (2)

Indeed, ||v||=||f||=1 and `1-<v,f>=||v-f||²/2`. Define the F_delta-measurable random variable

 Lambda=( integral_0^delta |w_s|²ds )^(1/2) / ||f 1_[0,delta]||_2.

Because ||f 1_[0,delta]||>=b0, reverse triangle plus Cauchy–Schwarz gives

 E|U-Lambda| <= sqrt(2q)/b0.                                (3)

Take H_event={sup_(delta<=t<=T)|W_t-W_delta|<=r}; it is independent of F_delta and has probability p. By (3),

 E[U 1_H_event] >= p-(1+p)sqrt(2q)/b0.                    (4)

Thus any sequence that nearly saturates the mean-kernel bound must carry essentially the same input-energy mass on a nontrivial independent future-noise event. This is the key actual nonanticipation argument.

6. Two separated input windows force output-column angular loss

On H_event, for delta<=s<=t<=T, m<=k_s(t)<=M. For s in I and u in J, column k_u vanishes on [s,u) while k_s has at least m²(u-s)>=m²T/3 squared mass there; ||k_s||²<=M²T. Thus

 <k_s,k_u> <= (1-xi) ||k_s|| ||k_u||.                     (5)

This remains valid when w has arbitrary signs: replacing w_s w_u by |w_s w_u| can only reduce the deficit below. On the event e<=eta, Cauchy–Schwarz and f>=f0 imply

 integral_I |w_s| ||k_s||ds >= cI U,
 integral_J |w_s| ||k_s||ds >= cJ U.                       (6)

All (s,u) pairs contribute nonnegatively to R²-O², and restricting to I x J and J x I gives

 R²-O² >= 2 xi cI cJ U².                                  (7)

7. Quantitative uniform gap

Set R0=4H/p and consider the good event H_event ∩ {e<=eta} ∩ {R<=R0 U}, restricted to U>0. The bad e-event has U-weight <=2q/eta² by (2). The bad R-event has U-weight <=E R/R0<=H/R0=p/4 by (1). If

 q<=p²b0²/[128(1+p)²]  and  q<=p eta²/16,

then (4) shows the good event has U-weight at least p/2. On it, R+O<=2R<=2R0 U, so (7) implies R-O >= (xi cI cJ/R0)U. Therefore

 Gamma q = Gamma-E O >= E(R-O)
         >= xi cI cJ p/(2R0)
         = xi cI cJ p²/(8H),

and since Gamma<=H, q>=xi cI cJ p²/(8H²). If either of the two preliminary small-q inequalities fails, q is already at least the corresponding first or second term in (B). Hence q>=epsilon_0 in all cases, proving (A). The argument does not assume existence of an optimizer, uniform integrability of a maximizing sequence, or any E2 moment.
