1. Actual model and universal E2 input bound

For every finite T>h>=0,S=T-h, use the original scalar law dx_t=w_t dW_t,z_t=x_t,x0=0,u=w_t, with any progressively measurable E2 input supported on [0,S]. Define the RANDOM path-energy norm

 U=||w||_L2[0,S].

For every nonzero such w,

 E||z||_L2[0,T] / E U
   <= sqrt(T) sqrt(E U²)/(E U)
   = sqrt(T) sqrt[1+Var(U)/(E U)²].                       (1)

Proof: Itô isometry and Tonelli give the exact identity

 E||z||²=integral_0^S (T-s) E|w_s|²ds <=T E U²,

and Jensen gives E||z||<=sqrt(E||z||²). This second-moment argument is used ONLY as an upper estimate for E2 inputs; the actual denominator and objective remain E U and E||z||, not RMS.

2. Necessary randomness for an actual advantage

If U is deterministic almost surely, (1) implies literal ratio<=sqrt(T), even if the time PROFILE or signs of w are arbitrarily adaptive/random. Thus an actual E2 input whose ratio exceeds sqrt(T) MUST have nonconstant total path energy. This is stronger than requiring random temporal magnitude, but is NOT a claim that every input beating the unknown exact deterministic gain must exceed sqrt(T).

More quantitatively, if a single E2 input has literal ratio at least r sqrt(T) for r>1, then

 CV(U):=sqrt(Var(U))/E U >=sqrt(r²-1).                     (2)

3. Exact stopping-family identity and limiting mechanism

For the named source's accelerated Brownian stopping input with N finite and pulse length delta<S, put tau_N=tau wedge N. Under the same probability law as the scaled Brownian path,

 U²=tau_N,
 E||z||² = T E tau_N - [delta/(2N)] E tau_N².            (3)

The second term follows by the change of variable s=N t/delta in integral t |w_t|²dt. For fixed N, as delta->0 the actual path norm ||z|| converges in L1 to sqrt(T)|B_tau_N|, since the state is constant after delta. Letting N->infinity gives |B_tau|=1 and E tau=1; thus the output norm becomes asymptotically deterministic sqrt(T), while the input norm remains the random sqrt(tau). The achieved ratio tends to sqrt(T)/E sqrt(tau)>sqrt(T). This explains exactly which Jensen inequality becomes tight and where the E1 expected-norm advantage comes from.
