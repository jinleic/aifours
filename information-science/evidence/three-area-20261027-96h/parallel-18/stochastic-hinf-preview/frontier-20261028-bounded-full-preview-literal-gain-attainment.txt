1. Original physical class and extra budget

Fix T>0 and 0<=hmax<T, arbitrary finite real original matrices and scalar Brownian W. For h in [0,hmax], use the actual original plant and full registered deterministic linear preview law

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u,                  x0=0,
 u=Kx+L0w_t+Lh w_(t-h)+integral_0^h H(r)w_(t-r)dr,

where progressive w is supported on [0,T-h]. For fixed finite nonnegative budgets MK,M0,Mh,MH, define BUDGETED laws by

 ||K||_F<=MK,  ||L0||_F<=M0,  ||Lh||_F<=Mh,
 H in L2[0,h],  ||H||_L2,F<=MH.                           (B)

The original task does NOT necessarily impose (B); every conclusion here is conditional on it. The zero law parameters make this class nonempty. The same result holds if h is prescribed rather than optimized.

For each actual law define its true literal gain

 gamma_1 = sup_(nonzero progressive E1 w) E||z||_L2[0,T] / E||w||_L2[0,T-h].

This gain is finite by the named source. E2 below always means E||w||²<infinity but retains the SAME ratio of EXPECTED PATH NORMS; it does not mean an RMS objective.

**Theorem.** There is a law in the bounded class, possibly with an optimized h in [0,hmax], attaining the minimum g_B=min gamma_1. Consequently:

 * if a prescribed gamma>g_B, this actual law satisfies the original strict inequality for every nonzero E1/E2 disturbance, with a uniform margin;
 * if gamma<g_B, NO law in the bounded class satisfies that pointwise strict inequality;
 * if gamma=g_B>0, the pointwise strict criterion is NOT decided by this theorem, because the gain supremum may fail to be attained. At gamma=0 strictness is impossible.

In particular g_B=0 iff the budgeted class actually contains a universally zero-output law. No explicit formula, rate or claim for unbounded controllers is made.

2. Same-law E1/E2 gain equality for the complete full-preview class

For a FIXED law and any E1 w define the product-progressive pointwise clipping

 w_n(t,omega)=w(t,omega) 1_(|w(t,omega)|<=n).

Each w_n is bounded on a finite time interval, hence E2; it keeps the same support. Pointwise |w_n|<=|w|, so pathwise ||w_n-w||_2->0 and dominated convergence gives E||w_n-w||_2->0. The named full-matrix E1 input-output bound applies to the SAME fixed law, hence E||z(w_n)-z(w)||_2->0. Denominators also converge and are eventually positive for w!=0. Therefore

 gamma_1 = gamma_2                                         (1)

for this same law, where gamma_2 is the supremum of the ORIGINAL expected-path ratio over E2 inputs. This is only a gain equality; it does NOT imply that strictness at the shared endpoint transfers pointwise between E1 and E2.

3. Weak compactness of bounded physical kernels

Take an arbitrary sequence of laws satisfying (B). By compactness in finite dimensions, along a subsequence

 h_j->h*, K_j->K*, L0_j->L0*, Lh_j->Lh*.

Extend each H_j by zero from [0,h_j] to [0,hmax]. The bounded sequence has a weakly convergent L2([0,hmax];matrix) subsequence H_j ⇀ H*. The limit has support in [0,h*]: every test supported strictly after h* pairs to zero for all sufficiently large j. Lower semicontinuity of the L2 norm preserves ||H*||<=MH, so the limit is an admissible bounded law. If h*=0, H*=0 almost everywhere.

4. Compact convolution and physical state convergence

Take ANY fixed progressive E2 input w supported in [0,T-h*-epsilon] for some epsilon>0. It is admissible for all large j. Extend w by zero outside [0,T]. Time translations are strongly continuous in L2(Omega x time), so w(.-h_j)->w(.-h*) there.

For this fixed w the map

 H -> [(t,omega) -> integral_0^hmax H(r) w_(t-r)(omega) dr]

is Hilbert–Schmidt from L2([0,hmax];R^(r x m)) to L2(Omega x [0,T];R^r): its kernel-square integral is bounded by r hmax E||w||². Hence weak H_j ⇀ H* implies these convolutions converge STRONGLY in L2(Omega x time). Multiplying by fixed plant matrices preserves strong convergence.

The closed drift/diffusion matrices and direct-output matrices converge because K_j does, and all current/delayed/distributed forcing terms converge in L2. Standard finite-dimensional linear Itô L2 stability then gives actual physical state convergence in L2(Omega;C[0,T]) and output convergence

 E||z_j(w)-z_*(w)||_L2 ->0.                               (2)

This uses E2 only for a fixed input to establish parameter continuity; the optimized gain remains (1)'s original E1 ratio.

5. Lower semicontinuity of the actual gain and existence

For each fixed w in section 4, the denominator E||w|| is the same for all sufficiently large j, so

 liminf_j gamma_1(law_j) >= E||z_*(w)||/E||w||.

Progressive E2 inputs supported strictly before T-h* are dense in all progressive E2 inputs at h*: truncate before T-h*, then use the SDE's E2 continuity and Cauchy–Schwarz to pass both expected path norms. Taking their supremum gives gamma_2(law*), which equals gamma_1(law*) by (1). Thus the TRUE original gain is sequentially lower semicontinuous under the mixed finite-dimensional strong/H-kernel weak topology, INCLUDING a moving horizon in [0,hmax].

Apply this to a gain-minimizing sequence. Its limit is budget-admissible by section 3 and has gain no larger than the infimum, so it ATTAINS g_B. For gamma>g_B the minimizing law has strict uniform margin. For gamma<g_B a law whose every ratio were <gamma would have supremum <=gamma<g_B, contradiction. At equality a supremum need not be attained, so no pointwise endpoint assertion is made. Gain zero is equivalent to universal zero output because all ratios are nonnegative.
