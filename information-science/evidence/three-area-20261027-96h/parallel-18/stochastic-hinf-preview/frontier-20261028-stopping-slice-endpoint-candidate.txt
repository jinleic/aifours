1. Precise model and question

For arbitrary compatible real A,B,C,A0,B0,D0,D1, one fixed deterministic stationary linear law

 u(t)=K x(t)+L0 w(t)+Lh w(t-h)+integral_0^h H(r)w(t-r)dr,

and the actual plant

 dx=[Ax+Bu+Cw(t-h)]dt+[A0x+B0u]dW,  z=D0x+D1u,

use a finite horizon T>h>=0, zero initial state/history, a canonical Brownian filtration with usual conditions, J=[0,T-h], and w zero-extended outside J. H is deterministic L2; at h=0 the endpoint taps combine. The same law is used for all inputs. Compare progressive E2 inputs (E U<infinity) and E1 inputs (E sqrt(U)<infinity), where U=integral_J |w|^2. Output is the actual original process Z(w), with local pathwise-L2 control/nonexplosion; all denominators E sqrt(U) are positive.

Let gamma>0 be the finite E2 gain. By the previously parent-supported actual output-only E1/E2 equality, the SAME gamma is an upper bound on E||Z(w)||/E||w|| for E1 inputs, and every E1 w has the actual local solution. Assume EVERY nonzero E2 input satisfies the strict ratio <gamma. Does this imply the same strict inequality for every E1 input? This report proves it for the stopping-time conditional-energy class below, and gives a necessary condition on every possible counterexample. It does NOT decide the universal implication or any controller-synthesis question.

2. New conditional-energy slice theorem

Let w be any nonzero E1 input. Let tau be any bounded stopping time with 0<=tau<=T-h such that w(t)=0 for dt x P-a.e. t<tau. Define the nonnegative extended conditional energy

 V_tau=E[U | F_tau] in [0,infinity].

No independence between the future shape and F_tau is assumed. If

 P(U>0 AND V_tau<infinity)>0,                                      (H)

then w obeys the strict literal ratio <gamma. More precisely: there is a nonzero actual E2 input v of the form 1_A w, A in F_tau, such that the zero-deficit condition for w would force the same zero deficit for v.

Proof. For each integer n>=1 let A_n={V_tau<=n}. Extended conditional expectation/Tonelli gives

 E integral_J |1_A_n w|^2 = E[1_A_n V_tau] <= n P(A_n) <= n.

Thus 1_A_n w is E2. Because w vanishes before tau and 1_A_n 1_{t>=tau} is adapted/progressive, this is an actual progressive input, not a terminal-event product anticipatively applied to nonzero past. Condition (H) implies that some A_n carries positive expected path norm, so the chosen E2 input is nonzero.

For every A in F_tau, zero input/history makes the actual state, control and output zero before tau. After tau, 1_A is a revealed scalar. Linear stochastic-integral identities and strong uniqueness for the SAME closed-loop law give

 Z(1_A w)=1_A Z(w),  Z(1_{A^c}w)=1_{A^c}Z(w).

This holds for E1 w by localizing/patching the actual solutions; it does not assert a product identity for an arbitrary unrevealed terminal factor. On disjoint probability events the whole path norms add, so for D(v)=gamma E||v||-E||Z(v)||,

 D(w)=D(1_A w)+D(1_{A^c}w).

Both terms are finite and nonnegative by the parent-supported E1 upper bound. If D(w)=0, then D(1_A_n w)=0, contradicting the given strictness for the nonzero E2 input. Therefore D(w)>0. This establishes the claim without assuming a strictly positive uniform margin.

3. A necessary condition on every unresolved physical attainer

Consequently, if an E1 input w ever attains the endpoint while every E2 input is strictly below it, then for EVERY stopping time tau<=T-h before which w is zero,

 E[U | F_tau]=infinity  on {U>0}, up to null sets.                (NEC)

Otherwise (H) would give an E2 attainer. At tau=0 this merely restates the familiar non-E2 condition in the canonical trivial initial filtration. For later revealed starts it is stronger: a counterexample cannot have even ONE positive-input event on which its remaining total energy has finite conditional expectation. This is an all-stopping-times necessary condition; it neither constructs nor rules out such an actual E1 attainer.

This theorem strictly differs from the earlier revealed-amplitude/future-shape subclass: it requires neither deterministic start time nor a factorization w=Yv with a post-tau shape independent of the revealed past. The entire future process may depend on the past. It also differs from the earlier universal progressive projection, because the event slice preserves the WHOLE path/output on each probability branch, exactly paying the endpoint face, under the explicit extra conditional-energy premise.

4. Exact original-plant E1-only family with coupled future shape

For arbitrary 0<t0<T let h=0, state/control/output scalar, x0=0, and original coefficients

 A=B=C=A0=D1=0, B0=D0=1, K=0, L0=1, Lh=0,

so u=w, dx=w dW and z=x. Put L=T-t0. Set P=1-Phi(W_t0/sqrt(t0)), where Phi is the standard normal distribution function; Brownian's continuous Gaussian law makes P uniform on (0,1). For every a with 1/2<=a<1 let

 Y=P^{-a},  alpha=Y/(1+Y),
 w(t)=0 for t<t0;  w(t)=Y[1+alpha(W_t-W_t0)] for t0<=t<=T.

The input is progressive. Conditional on F_t0, alpha,Y are fixed and the future Brownian increments remain independent. Its actual energy U has the exact conditional mean

 E[U|F_t0]=Y^2[L+alpha^2 L^2/2] < infinity almost surely.

Since E Y=1/(1-a)<infinity but E Y^2=infinity, conditional Cauchy-Schwarz yields E||w||<=E Y sqrt(L+L^2/2)<infinity, while E U>=L E Y^2=infinity. Thus this is a GENUINE E1-only input with condition (H), not a mock input.

The actual strong solution after t0 is

 x(t)=Y[B_r + alpha(B_r^2-r)/2], B_r=W_{t0+r}-W_{t0}.

Its conditional expected squared OUTPUT path norm is

 E[integral_{t0}^T |x(t)|^2dt | F_t0]
   =Y^2[L^2/2+alpha^2 L^3/6],

so E||z||<=E Y sqrt(L^2/2+L^3/6)<infinity. The normalized future shape w/Y=1+alpha(Y)B_r has conditional variance alpha(Y)^2 r, which depends nontrivially on the revealed Y: the future shape is not independent of Y. Thus this physical family lies beyond the old independent-shape factorization, while clipping A_R={Y<=R}, R>1, is revealed at t0, yields a nonzero E2 input and preserves the ORIGINAL state/output by the displayed probability-event factorization.

This family validates the extra conditional-energy premise and original actual-solution caller only. We have NOT shown that this particular plant/law has a finite common gain gamma with the premise that every E2 input is strict, nor that the displayed E1 input is an endpoint attainer. It is neither a physical counterexample nor a proof of universal endpoint transfer.
