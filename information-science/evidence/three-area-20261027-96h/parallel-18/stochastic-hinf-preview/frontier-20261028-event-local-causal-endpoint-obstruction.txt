2. A real progressive input and its moments

Fix arbitrary S>0, T>S, h=T-S, and c with

 1/(4S)<c<1/(2S).

On a canonical Brownian space set w_*(t)=exp(c W_t^2), 0<=t<=S, with zero extension outside. Put R=[integral_0^S w_*^2dt]^(1/2). Brownian paths are continuous, so R is strictly positive and finite a.s. The reflection principle and a Gaussian tail estimate give E exp(c sup_{t<=S}|W_t|^2)<infinity; hence E R<infinity. On a positive-length set of t, 4ct>=1 and the exact Gaussian integral E exp(2cW_t^2) is infinite. Tonelli gives E R^2=infinity. Thus w_* is ACTUAL progressive E1 but not E2. No distributional shape is chosen post hoc to substitute for an original disturbance class.

Define p_t(omega)=w_*(t,omega)/R(omega), 0<=t<=S. Its full time-path L2 norm equals one for each omega. The normalizer R depends on W up to S, so p_t is not claimed progressive at earlier times.

3. The PATHWISE operator and all actual adaptedness/causality callers

Let g(t)=h^(-1/2) on (S,T] and zero on [0,S]. For every progressive E1 input v, define

 (T_loc v)(t,omega)=g(t) integral_0^S p_s(omega)v_s(omega)ds.

This is linear PATHWISE in the input. The scalar integral is F_S-measurable; the output is zero through S and F_S-measurable afterwards, hence progressive. For any stopping time tau<=T, two input processes that agree up to tau yield outputs agreeing up to tau: if tau<S the outputs are zero there; if tau>=S their integrals over all of J already agree. This is genuine samplewise stopping-time causality, not an ensemble-average notion.

For any event A in F_tau and any input v supported after tau, the input 1_A v is progressive and

 T_loc(1_A v)=1_A T_loc(v)  pathwise.

In fact the identity holds for any measurable A when the product is admissible, because p is fixed independently of v. Thus the exact revealed-event locality available from a zero-start physical SDE is retained, unlike in the previous ensemble-nonlocal example.

By pathwise Cauchy-Schwarz and ||p||=||g||=1,

 ||T_loc v||_L2[0,T](omega)<=||v||_L2[0,S](omega).

The bound holds simultaneously on each path, so T_loc maps E1 to E1 and E2 to E2 with norm at most one. It does not claim a global state/control energy result for a physical plant.

4. Exact E1 attainment and strictness for EVERY E2 input

For v=w_*, the output scalar integral equals R; hence ||T_loc w_*||=||w_*|| pathwise. The literal E1 gain is exactly 1 and is attained by the E1-only w_*.

Suppose any nonzero real progressive E2 input v attained literal ratio 1. The pathwise difference ||v||-||T_loc v|| is nonnegative, so zero expectation forces pathwise equality. Equality in Cauchy-Schwarz gives

 v_t(omega)=lambda(omega) w_*(t,omega) for dt x P-a.e. (t,omega),

with finite real lambda on each path. Because w_*(t)>0 for every time, v/w_* is progressive; Fubini supplies a full-measure set of deterministic times for which it equals lambda almost surely. Choose a sequence of such times tending to zero. Canonical usual Brownian filtration has trivial F_(0+), so lambda is a deterministic constant almost surely. A nonzero constant makes E||v||^2 infinite; the zero constant makes the input zero. Thus every NONZERO E2 input has strictly smaller ratio.

Its E2 gain supremum is still 1: causal energy stops of the actual E1 input w_* are E2 and converge to it in E1, while T_loc is E1-bounded. No finite stop is claimed to attain the gain.

This operator also meets the earlier frontier necessary conditions: w_*>0 from time zero, so any stopping time before which it vanishes is zero a.s. on its active support, and its F_0-conditional squared energy is infinite. The forward normal equation holds by differentiating a pathwise Cauchy equality. Those necessary conditions therefore are NOT by themselves a universal physical endpoint proof.

5. Why this STILL cannot be the original SDE: prehistory measurability

Fix any deterministic t0 in (0,S), and the genuine deterministic input v=1_[t0,S]. For ANY allowed original finite-dimensional plant with fixed deterministic stationary linear preview law, zero history and zero initial state, input v gives state/control/output zero before t0. Its later actual output is measurable in the Brownian INCREMENTS AFTER t0 alone: the forcing/window values are deterministic, the time-homogeneous linear coefficients are deterministic, and strong uniqueness/Picard construction uses only those future increments from zero state. Thus its output after S cannot retain unrelated Brownian prehistory.

T_loc v instead contains the random scalar

 F(W) = [integral_t0^S exp(cW_s^2)ds] / [integral_0^S exp(2cW_s^2)ds]^(1/2).   (F)

We show F is NOT measurable with respect to the post-t0 Brownian-increment sigma field. Condition on any continuous future increment path q, and let B=sup|q|<infinity. For any delta>0, the past event E_low={sup_{s<=t0}|W_s|<delta} has positive probability and gives

 F >= (S-t0)/sqrt[t0 exp(2c delta^2)+(S-t0)exp(2c(B+delta)^2)] =: ell_B>0.

Choose any nonempty subinterval [a,b] inside (0,t0). For any M>0, the past event E_high={W_s>=M for all s in [a,b], |W_t0|<delta} has positive probability. This follows from the full support of Brownian paths on continuous paths starting at zero; equivalently use finite Gaussian increments and positive small-ball/bridge probabilities around a polygonal excursion and return. On E_high,

 F <= (S-t0)exp(c(B+delta)^2) / [sqrt(b-a) exp(cM^2)].

For the fixed q choose M large enough that this is <ell_B/2. Future increments are independent of the whole past, so BOTH past events retain their positive probabilities conditional on q. Thus the conditional law of F given the entire future increment path is not a point mass. Since q was arbitrary continuous, F is not future-increment measurable.

This directly contradicts the physical zero-state deterministic-input caller above. Hence T_loc is NOT representable by any member of the specified original linear SDE/controller class, even though its input/output and event-locality properties are genuine. The argument uses no selected numerical matrix/plant test; the analytic past-event construction is universal.
