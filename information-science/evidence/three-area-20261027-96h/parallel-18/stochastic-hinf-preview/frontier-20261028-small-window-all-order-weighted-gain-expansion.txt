1. Actual original law and weighted unit-window operators

Fix finite T>0 and arbitrary real original matrices A,A0,C,D0. For h=T-S choose the actual zero controller in

 dx=(Ax+Cw_(t-h))dt+A0x dW,     z=D0x,     x0=0,

with progressively measurable vector E1/E2 w supported on [0,S]. Assume S<=h and 0<S<=1. The whole input path is F_h measurable before the post-h state noise, so the scaled post-h Brownian path is independent of it.

On the unit window, for deterministic v in L2([0,1];R^m), define base process

 X_empty(t)=C integral_0^t v(s)ds.

For a continuous adapted process f define the ACTUAL Itô time operators

 (D f)(t)=integral_0^t A f(s)ds,
 (N f)(t)=integral_0^t A0 f(s)dB_s.

For each integer k>=0 define the finite weighted-word operator

 T_k v = D0 sum_(words W in {D,N}: 2 #(D)+#(N)=k) W X_empty, (1)

where a word means actual composition in its stated order; the empty word is included for k=0. Drift integration has weight2, Itô integration weight1. The SAME Brownian path is used in all words. For example

 T0 v=D0 C Vv,
 T1 v=D0 A0 C integral_0^. (Vv)(s)dB_s,
 T2 v=D0 A C V²v + D0 A0² C integral_0^. [integral_0^s(Vv)(r)dB_r]dB_s.

Each T_k maps deterministic L2 input into L1(Omega;L2 time). Let c_k=||T_k|| in that actual Banach norm.

2. Exact all-order leading-gain assertion

If for some k>=0 the operators T0,...,T_(k-1) are identically zero, then for BOTH actual E1 and E2 expected-path gains of u=0,

 |gamma_i(S)-c_k S^(1+k/2)|
       <= ||D0||||C|| C_k S^(1+(k+1)/2),    i=1,2,       (2)

whenever alpha(S)=||A||S+8||A0||sqrt(S)<=1/2. If c_k>0, the leading coefficient c_k is attained by a deterministic unit input; if c_k=0, (2) is only a remainder estimate and one may inspect the next weighted level. No claim is made that nonzero matrix words cannot cancel in (1).

A concrete finite remainder constant is obtained by putting a=||A||,q=||A0|| and

 C_k = sum_(l=0)^k sum_(i=0)^l 1_(l+i>=k+1)
           binom(l,i) a^i (8q)^(l-i)
       +2(a+8q)^(k+1),                                    (3)

with 0^0=1. It is dimension-free and deliberately conservative.

3. Why the Picard series has the stated E1 remainder

Shift the actual state to [h,T] and write x=X_empty+(D_S+N_S)x, with the same integral definitions on [0,S] and original revealed E1 input. In the Banach norm E sup_t||.||,

 ||D_S||<=a S,       ||N_S||<=8q sqrt(S),
 E sup||X_empty||<=||C|| sqrt(S) E||w||.

The N bound is the named L1 martingale maximal inequality; all processes can be localized. Since alpha<=1/2, the Neumann/Picard series converges in this norm. A word with i drifts and l-i noises has norm at most a^i(8q)^(l-i) S^((l+i)/2). For l<=k, sum the finite words of weighted degree l+i>=k+1; since S<=1, each contributes at most its coefficient times S^((k+1)/2). For l>=k+1, the whole geometric tail is at most `2(a+8q)^(k+1) S^((k+1)/2)`. This proves (3).

Output L2 path norm adds a factor ||D0||sqrt(S), so all terms of weight >k contribute at most the RHS of (2) times E||w||. Under Brownian/time/input scaling, each weight-j word's OUTPUT path norm carries exactly S^(1+j/2) and becomes T_j on [0,1]. Because w[0,S] is F_h measurable and post-h noise is independent, every random E1 leading-output ratio is an energy-weighted average of deterministic-v ratios. Therefore the leading operator has actual E1/E2 gain exactly c_k S^(1+k/2), and (2) follows from the uniform error and deterministic near-maximizers. No RMS ratio or future-conditioned input is used.

4. Compactness, attainment and exact scope of coefficients

The first step `v -> C Vv` is compact from the Hilbert input L2[0,1] to deterministic continuous paths by the 1/2-Hölder bound and Arzelà–Ascoli. Each finite Itô/drift word is a bounded linear map from such deterministic paths into L1(Omega;L2 time), using standard finite-time Itô estimates. Hence every T_k is compact and attains its norm when c_k>0. This does not assert that different words are linearly independent: condition T_j=0 is explicitly an OPERATOR condition, so a cancellation is not misclassified as a leading matrix word.

The named two preceding sources provide exact k=0,1,2 physical specializations and exact examples. For arbitrary k the result is a generic rigorous all-variable expansion conditional on the vanishing of lower operators; it does not compute c_k or claim a first nonzero level always exists.
