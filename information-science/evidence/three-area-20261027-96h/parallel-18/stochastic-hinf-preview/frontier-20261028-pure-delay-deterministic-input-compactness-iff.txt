It concerns compactness of a deterministic-input map, not a proof that a noncompact operator cannot attain its norm.

1. Actual original pure-delayed law

For arbitrary finite original matrices, scalar W, T>h>=0,S=T-h>0, x0=0 and the actual pure-delayed law `u=Kx+Lh w_(t-h)`, define

 P=A+BK, Q=A0+B0K, F=BLh+C, G=B0Lh,
 O=D0+D1K, E=D1Lh.

On the post-h S-window a deterministic input v drives

 dx=(P x+F v)dt+(Qx+Gv)dWtilde,    z=O x+Ev.

Let T map deterministic `v in L2([0,S];R^m)` to the ACTUAL output random path in `L1(Omega;L2([0,S];R^p))`. The norm is E||z||, not an RMS. T is bounded by the named E1 bound. Let N be the largest common P,Q-invariant subspace of ker O.

**Theorem.**

 T is compact  <=>  E=0 AND range(G) subset N.             (1)

There is NO condition on F, nor on output visibility of the state noise generated from F. For h>=S, the named revelation theorem converts this deterministic-input statement into an actual E1/E2 gain statement: in the compact case the positive gain is attained by a deterministic E2 input and strict feasibility is equivalent to gamma>the gain. If (1) fails, compactness is false but endpoint attainment remains undecided.

2. Sufficiency

If G maps into N, the state component driven by `G v dW` stays in N because P,Q preserve it and the initial state is zero; it has no output. When E=0 the only output is the drift-input response `v -> O integral Phi(t,s)Fv_s ds`, with random Hilbert–Schmidt kernel. The named source shows its map into L1(Omega;L2) is compact by finite-rank input projections and dominated convergence. This argument does not assume the remaining random output is deterministic.

3. Necessity when the output atom E is nonzero

Choose a unit vector a with Ea!=0 and a deterministic real orthonormal oscillating sequence

 v_n(t)=sqrt(2/S) cos(2pi n t/S) a.

It converges weakly to 0 in L2 by Riemann–Lebesgue. The mean output is `E v_n` plus the mean of the drift-input response; the latter tends strongly to zero because that random-HS map is compact. The additive stochastic response has zero mean. Hence Jensen gives

 ||T v_n||_L1(Omega;L2) >= ||E z(v_n)||_L2 -> ||Ea||>0.

A compact operator sends weakly null sequences to strongly null ones, contradiction. This covers E!=0 even if other random terms partially cancel pathwise.

4. Necessity when E=0 and G is visible

Suppose some unit a has g=G a outside N, and use the same v_n. Split x=xF+xG into drift-forced and additive-noise-forced components; the output of xF tends to zero in L1 because its map is compact. Let y_n be the output of

 dxG=P xG dt+(QxG+G v_n)dWtilde,  xG(0)=0.

Its mean is zero. The covariance Sigma_n=E[xG xG^T] obeys the deterministic ODE

 Sigma_n'=P Sigma_n+Sigma_n P^T+Q Sigma_n Q^T
              +G v_n v_n^T G^T.

The cross terms vanish because v_n is deterministic and E xG=0. Denote by M_t the homogeneous covariance semigroup and set

 A(v)=integral_0^v tr[O M_r(g g^T)O^T]dr.

Itô isometry/covariance integration yields

 E||y_n||_L2² = integral_0^S |v_n(s)|² A(S-s) ds
               -> (1/S) integral_0^S A(v)dv =: I2>0.     (2)

The limit uses `|v_n|²=(1/S)(1+cos(4pi n s/S))` and Riemann–Lebesgue. Positivity follows because g outside N implies a nonzero observed homogeneous stochastic response on every positive interval, by the common-(P,Q)-word semimartingale induction.

Standard L4 linear-SDE estimates give a finite constant U4 with sup_n E||y_n||_L2^4<=U4: the deterministic inputs have uniformly bounded L2 norms and sup amplitudes. Hölder gives

 E||y_n||_L2 >= [E||y_n||_L2²]^(3/2) / [E||y_n||_L2^4]^(1/2),

which has a strictly positive liminf by (2). The compact drift output tends to zero, so `||T v_n||_L1` does not tend to zero. This contradicts compactness and proves necessity.

5. Endpoint consequence and boundaries

When h>=S, the pinned input-revelation theorem gives actual progressive E1/E2 gains equal to the deterministic-path gain and identical pointwise strict/attainment behavior. Under (1), compactness then forces every positive gain to be attained, so strict feasibility is EXACTLY gamma>gain. If E!=0 or G is output-visible, this proof only says T is noncompact; it does NOT decide whether its norm is attained or whether pointwise strictness holds at gain.
