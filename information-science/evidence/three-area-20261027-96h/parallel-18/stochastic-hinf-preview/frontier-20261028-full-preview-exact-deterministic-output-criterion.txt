1. Full actual original law

Take arbitrary finite original matrices, scalar Brownian W, T>h>=0, S=T-h, x0=0 and progressive E1 vector input w supported in [0,S]. Use the original deterministic full-preview law

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u,
 u=Kx+L0w_t+Lh w_(t-h)+integral_0^h H(r)w_(t-r)dr,

with H in L2[0,h]. Put P=A+BK,Q=A0+B0K,O=D0+D1K and define the actual deterministic causal time operators f=Fop w,g=Gop w,o=Eop w. Define

 (J w)_t=integral_0^t exp[P(t-s)] f_s ds,
 Top=Eop+O J,   Dop=Gop+Q J,

and N=largest common P,Q-invariant subspace in ker O, Pi=orthogonal projection onto N^perp. N is computed by finite kernel closure. All time operators are bounded from L2[0,S] to the relevant L2[0,T] space.

2. Exact deterministic-output iff

The following are equivalent:

 (i) for EVERY deterministic L2 input w, the actual output z(w) is almost surely deterministic;
 (ii) Pi Dop=0 as a deterministic L2 time operator;
 (iii) for EVERY progressive E1 input w, z(w)=Top w pathwise. (1)

The deterministic output value in (i) is necessarily Top w. This iff permits nonzero visible state multiplicative noise Q and nonzero visible additive diffusion taps G so long as they cancel through Dop; separately requiring each G tap hidden would be too strong.

3. Necessity and E1 sufficiency

For deterministic E2 w, mu=Jw is deterministic and y=x-mu satisfies

 dy=P y dt+[Q y+Dop w]dW,  y0=0,  z=Top w+O y,

with Ey_t=0. If (i) holds, z=Ez=Top w and O y=0 a.s. The exact semimartingale word induction in the named zero-output source applies without requiring Top=0: for every word V(P,Q), zero O V y implies its diffusion coefficient O V Q y+O V Dop w is zero, and taking expectations gives O V Dop w=0; the drift gives O V P y=0. Inductively Dop w lies in N a.e. for every deterministic w, proving (ii).

Conversely, Pi Dop=0 as an operator means for EACH random E1 sample path Dop w lies in N a.e. The actual residual equation above has P,Q-invariant N, zero initial state and N-valued additive diffusion, so y remains in N by localized strong uniqueness; O y=0 and (iii) follows. (iii) trivially implies (i). This proves a pathwise output identity without assuming w in E2 or treating stochastic kernels as deterministic for output-visible noise.

4. Exact affine time-domain conditions

Define F0=BL0,Fh=BLh+C,F(r)=BH(r), G0=B0L0,Gh=B0Lh,G(r)=B0H(r), and for h>0 let

 V=e^(Ph) F0+Fh+integral_0^h exp[P(h-r)]F(r)dr.

Then Pi Dop=0 is equivalent to

 Pi G0=Pi Gh=0,
 Pi G(t)+Pi Q exp(Pt)F0
   +integral_0^t Pi Q exp[P(t-r)]F(r)dr=0 for a.e. 0<t<h,
 Pi Q P^j V=0 for j=0,...,n-1.                            (2)

The first line isolates the direct diffusion atoms, the second is the early residual kernel, and the third is the ENTIRE late residual kernel by analyticity/Cayley–Hamilton. Unlike the zero-output theorem, it is NOT necessary here that V lie in N, because a visible deterministic mean output is allowed. The conditions follow from exact approximate-identity testing of the causal time operator on [0,T] with inputs supported on [0,S]; direct atoms at 0 and h remain distinct. For h=0 combine F0+Fh and G0+Gh: Pi(G0+Gh)=0 and Pi Q P^j(F0+Fh)=0 for j<n.

The state/noise cancellation example in the named zero-output source has Q=sigma!=0, visible mean mu=integral_0^h w_(t-r)dr and visible G(r)=-sigma, but Dop=0 exactly. It therefore satisfies (1) while violating the earlier stronger requirement that G(r) individually lie in N.

5. Actual literal gain and endpoint for the complete deterministic-output class

Under (1), Top is a deterministic bounded operator from input path L2[0,S] to output path L2[0,T]. The pathwise identity yields

 gamma1=gamma2=||Top||op,

both using E||z||/E||w||, with deterministic inputs giving the reverse bound even if the norm is not attained. At gamma=||Top||>0 the pointwise strict criterion holds iff Top has NO norm-attaining vector: otherwise that deterministic E2 vector witnesses equality; if none exists, every nonzero input path has a strictly positive deficit whose expectation is positive. Gamma=0 is never strict.

Write Top=A+Kcompact, where A w=E0 w_t+Eh w_(t-h) and Kcompact is Hilbert–Schmidt. 6. Unbounded existential compact-output corollary
