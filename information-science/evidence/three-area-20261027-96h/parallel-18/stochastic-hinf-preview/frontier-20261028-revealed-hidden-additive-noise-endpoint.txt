1. Actual original pure-delayed law and exact result

For arbitrary finite original matrices, scalar W, zero x0 and T>h>=S=T-h>0, take the actual original law

 dx=(Ax+Bu+Cw_(t-h))dt+(A0x+B0u)dW,
 z=D0x+D1u,                  u=Kx+Lh w_(t-h),

with progressive vector E1/E2 inputs supported [0,S]. Put P=A+BK,Q=A0+B0K,F=BLh+C,G=B0Lh,O=D0+D1K,E=D1Lh. Assume

 E=0, and range(G) subset N,                               (R)

for SOME common P,Q-invariant subspace N subset ker O. G is allowed to be nonzero. Then the actual literal E1 and E2 gains are equal, and if their common gain gamma*>0 it is attained by a deterministic E2 input. For this given law the original pointwise strict inequality is satisfied for all nonzero E1/E2 inputs EXACTLY when gamma>gamma*; gamma=0 is never strict even if the gain is zero.

The condition (R) is SUFFICIENT, not claimed necessary. Q and the stochastic output driven through F may remain fully visible; neither the state nor the output is assumed deterministic.

2. Exact physical decomposition

On the post-h window, for deterministic or progressive input v, split the actual state linearly into x=xF+xG, with

 dxF=(P xF+F v)dt+Q xF dWtilde,
 dxG=P xG dt+(Q xG+Gv)dWtilde,

both zero initially. N invariance and range(G) subset N imply xG stays in N for every path-L2 input; hence O xG=0. Since E=0, the actual output is

 z(t)=O xF(t)=integral_0^S K_W(t,s)v_s ds,
 K_W(t,s)=1_(s<=t) O Phi(t,s)F,                           (1)

where Phi is the actual homogeneous Itô flow. For deterministic v this equality is pathwise, and E||K_W||_HS²<infinity by linear-flow moments.

3. Compact deterministic-path map and endpoint

Exactly as in the pinned drift-only theorem, the map v -> z(v) from deterministic L2 input into L1(Omega;L2 output) is compact: finite-rank input projections P_N satisfy

 ||T-T P_N|| <=E||K_W(I-P_N)||_HS ->0.

The unit Hilbert ball is weakly compact, so a positive norm is attained by a deterministic E2 input. Since h>=S, the entire actual random w path is F_h measurable and the future Brownian noise is independent; the revealed-input theorem gives an exact conditional ratio representation for ALL E1 inputs. Thus the actual full progressive gain equals this deterministic-path operator norm, and its deterministic maximizer witnesses equality in BOTH E1/E2 classes. Gamma strictly larger is feasible; the shared endpoint is not.

4. A genuinely stochastic example not covered by G=0

Let n=2,m=p=r=1, K=0,Lh=1,C=0,B=e1,B0=e2,D0=e1^T,D1=0, A=0 and A0=diag(sigma,0), sigma!=0. On the post-h window,

 dx1=v dt+sigma x1 dWtilde,
 dx2=v dWtilde,        z=x1.

N=span(e2) is P,Q-invariant, G=e2 is nonzero but hidden, and x1/output have genuine Brownian randomness. The theorem applies although B0Lh!=0. No numerical gain is asserted.
