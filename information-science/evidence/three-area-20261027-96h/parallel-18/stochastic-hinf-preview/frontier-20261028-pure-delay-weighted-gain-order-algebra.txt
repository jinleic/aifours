1. Actual original pure-delayed class and finite recursion

Use the named source's actual law, fixed K,Lh, T>h, S=T-h<=h, scalar W and progressive E1/E2 w supported [0,S]:

 dx=(P x+F w_(t-h))dt+(Qx+G w_(t-h))dW,
 z=O x+E w_(t-h),       x0=0,

where P=A+BK,Q=A0+B0K,F=BLh+C,G=B0Lh,O=D0+D1K,E=D1Lh, all matrices arbitrary. Define for B=F and B=G separately

 R^B_(-2)=R^B_(-1)=0,  R^B_0=range(B),
 R^B_k=P R^B_(k-2)+Q R^B_(k-1),       k>=1.

Let T_k be the exact unit-window L2 -> L1(Omega;L2) weighted operator in the named source. Then

 T0=0 iff E=0;
 for k>=1, Tk=0 iff O R^G_(k-1)=0 AND O R^F_(k-2)=0,   (1)

where negative-index spaces are zero. No assumption that F,G,Q,P commute or have signs is used.

2. Exact gain order and finite stopping bound

If E!=0, the first weight is k0=0. Otherwise let k0 be the first k>=1 at which either O R^G_(k-1) or O R^F_(k-2) is nonzero. If any output is visible, such k0 exists with k0<=2n, where n is the state dimension. The named source and (1) then give a positive c_k0=||Tk0|| and, for BOTH actual E1/E2 expected-path gains,

 gamma_i(S)=c_k0 S^(k0/2)+O(S^((k0+1)/2)),  i=1,2.

This is the given-law small-window limit as h=T-S with fixed K,Lh; no c_k0 norm-attainment is claimed. If all tests through 2n vanish, E=0 and the entire (P,Q)-reachable spaces of F,G lie in ker O, so the actual output is identically zero for EVERY progressive input at any finite horizon. This is a finite algebraic zero test, not an infinite word conjecture.

3. Wiener chaos of the two input bases

Fix k>=1, deterministic input v, output time t and total noise count j. Drift-base words start with `X_F(v)=integral Fv dr`, then have j Q-Itô integrations and iF=(k-2-j)/2 drift integrations. Additive-noise-base words start with `X_G(v)=integral Gv dB`, then have j-1 Q-Itô integrations and iG=(k-j)/2 drift integrations. Invalid negative/noninteger counts are omitted. Different j belong to orthogonal Wiener chaoses.

For j>=1, after time/Fubini rearrangement the ordered j-fold Itô kernel has the form

 K_j(t1,...,tj,t;v)
   = P_G(t1,...,tj,t) v(t1)
     + integral_0^t1 P_F(r,t1,...,tj,t) v(r)dr.           (2)

P_G is a finite sum of matrix coefficients `O P^alpha_j Q ... Q P^alpha_1 G` times independent monomials in the j positive gaps after t1. P_F is a finite sum of coefficients `O P^beta_j Q ... Q P^beta_0 F` times monomials in the j+1 positive gaps beginning at r. Degrees are respectively iG and iF=iG-1 when both occur. For j=0 only the F-base ordinary Volterra kernel remains. The integrals are nested linear Itô integrals: no product-contraction term is omitted.

4. Why ADDITIVE and DRIFT bases cannot cancel as operators

Suppose Tk is the zero operator. Orthogonality plus ordered multiple-Itô isometry makes each (2) zero in L2 over its time simplex for EVERY deterministic v. Test the complexified operator with v_omega(r)=a exp(i omega r), for arbitrary fixed vector a and omega->infinity. The P_F Volterra integral tends to zero in L2 over the time simplex by the Riemann–Lebesgue lemma and domination, whereas the L2 norm of `P_G v_omega(t1)` is independent of omega. Thus P_G a=0 for every a, so P_G vanishes. This is a universal analytic test family used to prove operator equality, not a selected reference or numerical experiment.

With P_G=0, countable dense input testing and Fubini make P_F zero almost everywhere before integration in r. In each case the gap variables range over an open positive simplex. Distinct gap monomials are polynomially independent, so EVERY corresponding matrix word coefficient must vanish. For j=0 the same ordinary Volterra argument applies. Conversely all these coefficients zero clearly make Tk zero. Grouping leftmost P/Q letters gives precisely the two subspace conditions in (1).

5. Finite reachability reasoning and first examples

For each of F and G, the common (P,Q)-reachable span stabilizes after at most n-1 strict dimension increases. A visible word of length <=n-1 has weight <=2(n-1). Including the drift-base weight2 or noise-base weight1 gives k0<=2n whenever output is not identically zero. This argument does not assume that the first visible word itself has minimum length or that individual stochastic terms can be compared pathwise.

The first conditions are concrete: T0=0 iff E=0; T1=0 iff OG=0; with E=0,OG=0, T2=0 iff OF=0 AND OQG=0. Thus direct output, input diffusion and drift/state-noise paths are distinguished exactly. These are general matrix identities, not selected examples.
