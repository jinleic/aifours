## 1. Canonical levels are weak-majorization ideals

For z∈R² put

```
r(z)=max(|z1|,|z2|),   s(z)=|z1|+|z2|.
```

A canonical level K has D4 symmetry, coordinate contractions and diagonal contractions. If (a,b)∈K with a≥b≥0, it contains

```
O(a,b)={z:r(z)<=a, s(z)<=a+b}.
```

Here is an elementary proof, without assuming K convex. In the first octant, for0≤y≤b the allowed rectangle x≤a is obtained by coordinate contractions of(a,b). For b≤y≤(a+b)/2, the point(a+b-y,y) lies on the segment joining(a,b) to(b,a), and that segment lies in K by diagonal contraction and D4. Coordinate contraction then fills all first-octant points below it. D4 gives the entire O(a,b).

Thus, if z∈K and r(z')≤r(z), s(z')≤s(z), then z'∈K. Conversely, this order-ideal property contains those coordinate/diagonal contractions and their D4 images. For a canonical density q whose closed discrete levels are such K, q is nonincreasing in the product order of(r,s).

The squared-Euclidean objective is compatible with this order on the feasible invariant wedge r≤s≤2r:

```
|z|²=r²+(s-r)²,
partial_r |z|²=4r-2s>=0,
partial_s |z|²=2(s-r)>=0.
```

This monotonicity is not by itself an optimality certificate or an appeal to SCDF Pareto minimality.

## 2. Exact full-D privacy test in the canonical class

For a nonnegative D4/weak-majorization-monotone function q, the POINTWISE full-D privacy condition is equivalent to the single-coordinate condition

```
q(x+1,y)>=b*q(x,y) for every x>=y>=0.
```

Necessity uses h=(1,0)∈D. For sufficiency, take any z and h∈D. The invariants satisfy

```
r(z+h)<=r(z)+1,   s(z+h)<=s(z)+1.
```

The sorted point z0=(r(z),s(z)-r(z)) is in the first octant and has the same q-value as z. The point z0+(1,0) has invariants(r+1,s+1). Product-order monotonicity therefore gives

```
q(z+h)>=q(z0+(1,0))>=b*q(z0)=b*q(z).
```

Applying the same argument at z+h with shift-h gives the reverse ratio. If q has finite positive mass, normalizing and integrating proves EVERY original Borel-event privacy inequality. No sampled directions or uncountable null-set intersection is used: this lemma is about the already derived pointwise canonical representative.

This reduces a feasibility test, not the full objective minimization.

## 3. Exact control: maximal unit decay does NOT force a one-core head


All sets are compact convex D4 bodies and hence have the canonical contraction properties. The first forcing inclusion holds because S_a+D⊂S_(a+1); all later inclusions are equalities. To check all cases, use the exact parallel profile of the square core. For0≤y≤a+1,
