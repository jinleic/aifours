  orbit is shifted by one step (3r+s -> 3r+(s+1 mod 3), and likewise for columns).

  orbit, and a fixed column is constant on each row orbit. In the table below, a block is written as its first row

  lists its values on the three rows of the orbit; the last four entries of each line are columns 24..27:

  ```

  R1     000 101 000 012 200 002 001 100 | 111 111 111 000
  R2     100 000 012 021 011 100 100 200 | 000 000 000 111
  R3     012 010 200 000 011 000 001 200 | 111 111 111 000
  row 12 111 000 000 000 000 222 000 111 |  0   1   0   1
  row 13 000 000 111 000 000 111 222 000 |  1   0   1   0
  ```

* Column types (ones, twos): orbits C1 and C4 are (5,1); orbits C0, C2, C3, C5, C6, C7 are (3,2); the four fixed
