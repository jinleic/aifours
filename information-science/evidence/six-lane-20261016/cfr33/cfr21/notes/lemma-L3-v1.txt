Lemma L3 (CFR21 lane, worker InfoCFR27Lift, written 2026-10-18; UNREVIEWED until an independent review is recorded)

Setting. A (Z_n,k;1) difference matrix (DM) is a k x n matrix D over Z_n such that for every pair of distinct
rows i,j the n differences D[i][c]-D[j][c] (c=0..n-1) are all distinct, i.e. a permutation of Z_n.

Statement. Let 3 | n, 9 does not divide n, and let D be a (Z_n,4;1)-DM with rows a,b,c,g. Then the columnwise
sum a+b+c is NOT constant modulo 3. Consequently, in any (Z_n,k;1)-DM with k>=4 (same n), no three rows have a
columnwise-constant sum mod 3.

Proof.
1. Normalisation. Subtracting row a from every row columnwise preserves the DM property. New rows: 0, r1=b-a,
   r2=c-a, g'=g-a. Then 0+r1+r2 = b+c-2a == a+b+c (mod 3), because -2 == 1 (mod 3). So it suffices to show that
   r1+r2 is not constant mod 3 for a DM with rows 0,r1,r2,g' (write g for g').
2. Balance. If x is a permutation of Z_n, then since 3 | n each residue class mod 3 contains exactly n/3 of its
   values. Apply this to the four permutations r1-0, g-0, g-r1 and g-r2.
3. Suppose r1+r2 == s (mod 3) for every column, for a constant s. Then r2 == s-r1 (mod 3), so g-r2 == g+r1-s.
4. For (u,v) in Z_3 x Z_3 let N(u,v) = #{columns: r1 == u, g == v (mod 3)}. Total weight sum N = n.
   From step 2 and 3:
   (i)   for each u: sum_v N(u,v) = n/3            (r1 balanced)
   (ii)  for each v: sum_u N(u,v) = n/3            (g balanced)
   (iii) for each e: sum_{v-u=e} N(u,v) = n/3      (g-r1 balanced)
   (iv)  for each e: sum_{v+u=e} N(u,v) = n/3      (g-r2 = g+r1-s balanced)
   The four families (i)-(iv) are exactly the four parallel classes of lines of the affine plane AG(2,3) on the
   9 points (u,v): directions (0,1), (1,0), (1,1), (1,-1).
5. Fix a point p. The four lines through p (one in each class) pairwise meet only in p and together cover each of
   the other 8 points exactly once (two distinct points of AG(2,3) lie on exactly one line). Summing the weights
   of these four lines: 4*(n/3) = 3*N(p) + n, hence N(p) = n/9.
6. N(p) is a non-negative integer, so 9 | n. This contradicts the hypothesis. QED.

Remarks.
* For n=21 the lemma says: no three rows of a (Z21,4;1)-DM sum to a constant mod 3 in every column.
* Linear triples {0, x, a x} with a and a-1 units mod 21 have a == 2 (mod 3), so 0 + x + a x == (1+a) x == 0
  (mod 3) is constant: no linear triple lies in any (Z21,4;1)-DM. Two independent search engines in this lane
  found the L2 neighbour list EMPTY for f1 = 2x and f1 = 5x, which is consistent with (but does not prove) the lemma.
* For n=9 or n=27 the computation gives N(p)=1 or 3, so no contradiction arises; the hypothesis 9 does not divide n
  is necessary for this argument.
No literature priority or novelty claim is made; this may be a known elementary counting argument.
