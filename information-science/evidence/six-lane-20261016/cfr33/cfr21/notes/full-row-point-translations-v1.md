# Normalised first-row point translations
Recorded 2026-10-17 20:48:20 PDT. These are exact equivalences, not target symmetry assumptions.

For an entire normalized DM with rows0,id,f_i, define T_e f_i(x)=f_i(x+e)-f_i(e). Apply the same column translation
x->x+e, then an independent constant translation to each row. Every row-pair difference is a permutation before
iff after. Zero and id remain zero and id; hence extendibility of one f-row to a specified DM size is T_e-invariant.
This does not require f_i to be odd or to have any automorphism.

Let A f(x)=f(-x)+x, I f=f^-1, C_u f(x)=u*f(u^-1*x). Then
A T_e = T_-e A, C_u T_e = T_(u*e) C_u, and I T_e f = T_(f(e)) I f.
The last identity follows by solving f(y+e)-f(e)=x. Thus the set {T_e g: e inZ_n,g inR1(f)} is closed under all these
operations and has at most n*6*phi(n) maps. For n21 the bound is1512 per starting map. Consequently a completed
search on the six existing P21 R1 representatives already settles extendibility for all their point translations
as a mathematical equivalence, even though the literal inventory file is not translation-closed. It does not settle
other orthomorphisms or unrestricted CFR6,21. At present the six negative results are one-program evidence; an
independent exact cross-check must agree before treating the restricted exclusion as independently validated.
