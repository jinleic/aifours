### 1.1 Object (contract definition)
* W is a 26 x 130 matrix over {-1, 0, 1} (rows = 26 points, columns = 130 blocks).
* Every row has exactly 25 nonzero entries; every column has exactly 5 nonzero entries.
* For every two distinct rows i, i': exactly 2 columns with W[i][j] W[i'][j] = +1, exactly 2 with -1 (126 with 0).
  Equivalently: |W| is the incidence matrix of a 2-(26,5,4) design and W W^T = 25 I.
* Repeated columns allowed; no automorphism, cyclicity, resolvability, simplicity or base-block assumption.
* Validity-preserving symmetries: row permutations, column permutations, negation of any row or any column.

### 1.3 Written facts (each used only as stated; [W] = written proof here)
* (P1) [W] Write s_j for the sum of column j. For every integer vector u, sum_j (u^T W)_j^2 = u^T W W^T u = 25 |u|^2.
  With u = all-ones: sum_j s_j^2 = 650, and each s_j is odd (five entries +-1).
* (P2) [W] If a group G of order 26 acts regularly on the rows by plain permutations (no row signs) and on the
  columns by signed permutations, with W[g i][g j] = sigma_g(j) W[i][j], then no valid W is G-invariant. Proof: the
  stabilizer K of a column acts semiregularly on rows and fixes the support (5 rows) of that column, so |K| divides
  5 and 26, |K| = 1; hence the 130 columns form 5 regular orbits. Without row signs, s_{g j} = sigma_g(j) s_j, so
  s_j^2 is constant on each orbit and (P1) gives 26 (s_1^2 + ... + s_5^2) = 650, i.e. a sum of five odd squares
  equals 25; but an odd square is 1 mod 8, so the sum is 5 mod 8 while 25 is 1 mod 8. Contradiction. This only
  removes restricted models (it is not an exclusion of the target); the plain cyclic Z_26 model is not run.
* Anything else used for pruning must be proved in `notes/` first and used only in labelled "strengthened" runs.

### 1.4 Representation and encodings
* Model = a finite group Gamma of signed permutations of the 26 rows together with a signed action on the 130
  columns, given as a disjoint union of induced monomial G-sets Gamma/K_o with characters psi_o: K_o -> {+1,-1}
  (column orbit o). Invariance: W[pi_g(i)][tau_g(j)] = rho_g(i) sigma_g(j) W[i][j] for every generator g.
  Gamma = 1 is the unrestricted problem. Each concrete model is generated by `code/brd_models.py` as a JSON spec
  (generator actions on rows and columns) whose sha256 is recorded in the run record.
* SAT encoding `code/brd_cnf.py` (one generic encoder for every model): cells are merged into Gamma-orbits with a
  relative sign (union-find with parity); an orbit containing a cell and its own negative is forced to 0. Per
  orbit: A (nonzero) and S (sign). Constraints for orbit representatives only: row exactly r nonzeros, column
  exactly k, and for every orbit of unordered row pairs exactly lambda/2 columns with equal nonzero signs (E) and
  exactly lambda/2 with opposite signs (D); E and D fully defined by Tseitin clauses; cardinalities by
  bidirectional sequential counters. Output CNF + map JSON (cell -> orbit variable and parity).
* Solver: kissat with native `--time`, no proof unless stated; driver `code/brd_run.py` writes an exclusive JSON
  record, decodes a model to the strict format (1.6) and runs both checkers.
* Unrestricted background route U0 (Gamma = 1) with symmetry breaking (S0): row 0 is nonzero exactly in columns
  0..24, all +1 there (complete by column permutation and column negation).
* Two-phase route (only after an amendment): phase 1 unsigned 2-(26,5,4) design from the same encoder (A only, pair
  co-occurrence exactly lambda), phase 2 a signing CNF for that fixed design with unrestricted signs.
