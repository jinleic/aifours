**Local verdict: HOLD.** The owned guards contain substantial repairs, but several failure paths still violate the supplied ownership, cutoff, release, or bounded-settlement contracts. Snapshot equivalence does not close these defects.

This is a text-only source review. No tools, execution, edits, delegation, or launches were used.

The remaining source findings are:

1. **FATAL — `Child.__init__`, `Helper.run`, `unresolved_inventory`: a `Popen` exception is incorrectly treated as proven no-launch.**  
   Both constructors publish `no_launch=True` for every exception from `Popen`. An exception alone does not prove that no kernel child was created: creation can succeed before subsequent parent-side constructor work fails.

   In that case, assignment to `self.proc` never completes. `settle_all()` and `unresolved_inventory()` skip the owner because `proc is None`, while `attempt_owner_manifest()` accepts the `.nolaunch.json` and suppresses the unresolved intent. The resulting record can erase an **unproved launch**, rather than retain it for independent parent resolution.

   Only a separately established no-child outcome may close an intent as no-launch. Other acquisition failures must remain unknown and retain the reservation.

2. **FATAL — `Owned.live_census`, `Owned.reap_owned`, `Child.settle`: settlement can succeed after the stop-grace deadline.**  
   Counterexample: the last reap-loop iteration begins just before `term_sent_mono + TERM_WAIT`. The final identity/RSS calls cross that deadline; `live_census()` returns `complete=True` without a final deadline check. `reap_owned()` then observes and consumes the exit without rechecking its deadline.

   `Child.settle()` subsequently restores the longer total cleanup deadline. A proof-cap producer that survives slightly beyond its permitted SIGTERM grace can therefore receive `settled=True`, provided the remaining cleanup fits the total tail. The intended C5 predicate can accept that receipt.

   Deadline checks must fence the successful observation/reap path and its completion. Entering an iteration before expiry is insufficient.

3. **FATAL — `Helper.admission_refusals`, `Helper.run`: `/bin/date` can launch after `NATIVE_LAUNCH_STOP`.**  
   Helper admission checks the run’s absolute and monotonic allowances, but never checks the frozen native-launch cutoff.

   Counterexample: the current time is just after `NATIVE_LAUNCH_STOP`, while more than `HELPER_ALLOW` remains before `STATE["abs_end"]` and the monotonic cutoffs. With stable executable pins and no latch, `Helper.run()` launches date and can return a valid clock.

   Mandatory date does not justify a cutoff exception. Scheduling must fit both requirements; otherwise the run must refuse qualification.

4. **FATAL — `release_refusals`, `disposition_refusals`: expected-versus-actual exit reconciliation is incomplete.**  
   A known-schema summary proposing exit `0`, a matching pinned closeout declaring exit `50`, and parent-observed actual exit `50` can pass without `publication_failure_disposed=True`. The guard compares actual exit with closeout, but never compares it with the summary’s proposed exit.

   That violates the supplied rule requiring an explicit failure disposition for proposed-versus-actual mismatch. Checking only the summary schema does not perform that reconciliation.

   There is a related omission for an absent launch publication: when its digest is null and the file is absent, no publication unknown is added. A new-format attempt can consequently lack that mandatory publication without this guard demanding the explicit failure disposition.

5. **FATAL — `attempt_owner_manifest`: a readable settlement’s own leader identity can be omitted.**  
   The `.settle.json` branch reads `known_identities` and `live_census`, but does not add the record’s top-level `pid` and `identity_at_start`. The quarantine branch does.

   Counterexample: launch publication is missing or unreadable, summary/closeout are unavailable, and a readable settlement contains a valid leader PID/start but empty census lists. That known leader disappears from the manifest. A disposition omitting it is consequently not rejected for missing known-identity coverage.

   The independent parent audit remains mandatory, but cannot substitute for the runner’s promised independent check of **every readable known owner**.

6. **MAJOR — `Owned.live_census`, `descendants`: census completeness and identity history are overstated.**  
   `known_identities[p] = item` overwrites earlier observations. A later unreadable identity or a reused PID with another start can erase an already known start. Deduplication by `(pid, start)` in `attempt_owner_manifest()` cannot recover evidence already discarded.

   Separately, `descendants()` seeds traversal only with the leader. Suppose the leader exits, group member `G` is reparented, and `G` has child `H` outside the original group. Group listing finds `G`, but traversal from the leader never visits `G` to discover `H`; the census can still say `complete=True`.

   Observing `G` already causes safe refusal. That protects qualification, but does not make the census complete or eliminate the parent’s unresolved ownership obligation.

7. **MAJOR — `allocation_refusals`, `ledger_refusals`, `registry_refusals`, `Owned._record_unsettled`, `write_all`: bounded work is incomplete.**  
   Namespace reads still use whole-directory `os.listdir()`/sorting before a cap—or without a cap. A large static directory can consume substantial memory and time before `walk_bounded()` gets an opportunity to refuse it. Exclusive-writer premises do not establish directory-size bounds.

   Quarantine publication also starts after the reap budget has expired, without checking a remaining publication budget. `write_all()` has a progress check but no deadline check; repeated positive short writes can cross the common deadline. Synchronous write/fsync completion is not bounded by observing time only afterward.

   The current source therefore does not establish the promised bounded quarantine return. Runtime tests alone cannot supply that missing protocol guarantee.

def walk_bounded(root, root_fd=None, deadline=None):
    """G4: bounded incremental descriptor-relative walk; no whole-directory list before checking work caps.
    No symlink following; every fd/iterator has a finally owner. Exceeding depth/entry/time caps is uncertainty."""
    end = work_deadline(deadline=deadline)
    count = [0]
    snap = {}
    fd = os.dup(root_fd) if root_fd is not None else os.open(
        root, os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW | os.O_CLOEXEC)
    def visit(dfd, base, depth):
        if depth > TREE_DEPTH_MAX:
            raise RuntimeError("census depth exceeds cap")
        with os.scandir(dfd) as entries:
            for entry in entries:
                count[0] += 1
                if count[0] > TREE_ENTRY_MAX or time.monotonic() > end:
                    raise RuntimeError("census entry/work deadline exhausted; incomplete")
                st = os.stat(entry.name, dir_fd=dfd, follow_symlinks=False)
                path = os.path.join(base, entry.name)
                snap[path] = census_entry(st)
                if stat.S_ISDIR(st.st_mode):
                    child = os.open(entry.name, os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW | os.O_CLOEXEC,
                                    dir_fd=dfd)
                    try:
                        fst = os.fstat(child)
                        if (fst.st_dev, fst.st_ino) != (st.st_dev, st.st_ino):
                            raise RuntimeError("directory replaced while walking: " + path)
                        visit(child, path, depth + 1)
                    finally:
                        os.close(child)
    try:
        visit(fd, root, 0)
    finally:
        os.close(fd)
    if time.monotonic() > end:
        raise RuntimeError("census completed beyond work deadline")
    return snap

def bounded_names(path_or_fd, deadline=None, cap=TREE_ENTRY_MAX):
    """Incrementally cap enumeration BEFORE allocating/sorting the complete namespace. No os.listdir fallback."""
    end = work_deadline(deadline=deadline)
    names = []
    with os.scandir(path_or_fd) as scan:
        for entry in scan:
            deadline_check(end, "namespace enumeration")
            if len(names) >= cap:
                raise RuntimeError("namespace entry cap exhausted; inventory incomplete")
            names.append(entry.name)
    deadline_check(end, "before bounded namespace sort")
    names.sort()
    deadline_check(end, "after bounded namespace sort")
    return names

    def observe_exit(self):
        """WNOWAIT preserves leader/group identity until census closure and the explicit owned reap."""
        if self.quarantined or self.wait_lost is not None:
            return None
        if self.reaped:
            return self.exit_status
        if signal.getsignal(signal.SIGCHLD) != signal.SIG_DFL:
            self.wait_lost = "SIGCHLD disposition changed; exclusive wait premise lost"
            latch(self.wait_lost)
            return None
        try:
            info = os.waitid(os.P_PID, self.pid, os.WEXITED | os.WNOHANG | os.WNOWAIT)
        except ChildProcessError as exc:
            self.wait_lost = "ECHILD: exclusive wait ownership lost: %r" % (exc,)
            latch(self.wait_lost)
            return None
        if info is None:
            return None
        if info.si_pid != self.pid or info.si_code not in (os.CLD_EXITED, os.CLD_KILLED, os.CLD_DUMPED):
            self.wait_lost = "unexpected waitid identity/status %r" % (info,)
            latch(self.wait_lost)
            return None

        if self.exit_observed_mono is None:

            return None
