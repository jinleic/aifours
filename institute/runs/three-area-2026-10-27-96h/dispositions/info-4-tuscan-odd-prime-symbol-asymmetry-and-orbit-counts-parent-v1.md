# Tuscan arrays of odd prime order: trivial symbol-automorphism group, free S_p×S_p action and normalized counts

**Disposition: same-harness written support for three existence-free counting statements.** Fix an odd prime `p`, the alphabet `Σ = {0,…,p−1}`, and linear (non-wrapping) directed events. A `T1(p)` array is a `p×p` array of permutation rows whose `p(p−1)` adjacent events `(x_j, x_{j+1})` are pairwise distinct; `T2(p)` is the subset whose `p(p−2)` distance-two events `(x_j, x_{j+2})` are also pairwise distinct. Symbol permutations act entrywise and rows may be reordered; no column permutation or reversal is quotiented.

1. **Theorem A (adopted).** Every `A ∈ T1(p)` has trivial symbol-automorphism group: no non-identity symbol permutation preserves its row set. Proof: the group acts freely on the `p` distinct rows, so its order divides `p`; order `p` makes it a `p`-cycle, after relabelling the translation `k ↦ k+1`, so the rows are the translates `x + k` of one base row; distinct consecutive differences are forced (a repeated difference repeats an event in another translate), hence they exhaust `Z_p ∖ {0}`, whose sum `p(p−1)/2 ≡ 0 (mod p)` for odd `p` forces `x_{p−1} = x_0`, contradicting injectivity. Oddness is used exactly at the residue sum; for `p = 2` the row set `{01, 10}` has the swap automorphism.
2. **Theorem B (adopted).** The `S_p × S_p` action (symbols × row order) on `T1(p)` and on `T2(p)` is free; every orbit has exactly `(p!)²` arrays, so `(p!)²` divides `|T1(p)|` and `|T2(p)|`, zero allowed.
3. **Theorem D (adopted).** In every `T1(p)` array each symbol begins exactly one row (it has exactly `p−1` incoming events), so every orbit contains exactly `p` normalized arrays (first row `0,1,…,p−1`, rows ordered by starting symbol); the normalized counts of `T1(p)` and `T2(p)` are divisible by `p`, and `|X| = p!·(p−1)!·#normalized(X)`. For `p = 11`: `#normalized T2(11) ≡ 0 (mod 11)` and `|T2(11)| ≡ 0 (mod (11!)²)`, whether or not `T2(11)` is empty.
