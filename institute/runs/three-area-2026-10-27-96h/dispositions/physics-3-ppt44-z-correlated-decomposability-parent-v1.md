# 4×4 phase-covariant witnesses: Z-correlated decomposability and the exact rank-two inequality

**Disposition: same-harness written support at the two stated class scopes, with Claim A conditional on the named Yang–Leung–Tang import.** Work in `C^4⊗C^4` with the computational tensor basis `|ij⟩`, Bob partial transpose `Γ`, and a Hermitian `W` that is invariant under every diagonal `U⊗Ū`. Such a `W` has an arbitrary Hermitian correlated block `H` on `span{|ii⟩}` and diagonal coefficients `d_ij ≥ 0` on the off-diagonal basis vectors `|ij⟩`, `i≠j`. `W` is 2-block positive when `⟨X|W|X⟩ ≥ 0` for every coefficient matrix `X` of rank at most two; `W` is decomposable when `W = A + B^Γ` with `A, B ≥ 0`, in which case `Tr(Wρ) ≥ 0` for every PPT `ρ`.

- **Claim A (adopted at its scope, conditional).** Suppose one local diagonal phase gauge makes the correlated block a Z-matrix pattern: diagonal `a_i`, off-diagonal entries `−k_ij` with `k_ij ≥ 0`, no further symmetry, equal-weight, product-metric or rank-one assumption. If `W` is 2-block positive, then `W` is decomposable. The written proof uses the rank-two matching lemma (`q_ij := √(d_ij d_ji)`, the test vectors `x|ii⟩ + y|jj⟩`), the Z-matrix lemma (a copositive symmetric Z-matrix is PSD), the exhaustive graph split of the low-edge graph `q_ij < k_ij` into disconnected / perfect-matching / spanning-star cases, explicit PSD pair blocks, and in the spanning-star case a Schur comparison `R − C ≥ 0` entrywise. The disconnected case with a 3-vertex component imports the 3×3 theorem: every 2-positive or 2-copositive map `M_3(C) → M_3(C)` is decomposable (Yang, Leung, Tang, arXiv:1603.03534, Theorem 3.2, read directly by the parent at the source). That import is a named conditional premise here; its proof was not re-derived.
- **Claim B (adopted at its scope, unconditional).** For any `n`, a phase-covariant Hermitian operator with arbitrary Hermitian correlated block `H` and balanced reciprocal off-diagonal weights `d_ij = q r_i / r_j` is 2-block positive if and only if `z^*Hz + q(m(|z|) − Σ_i |z_i|^2) ≥ 0` for every `z ∈ C^n`, where with `S = Σ_i x_i`, `L = max_i x_i`, `m(x) = S^2/2` when `L ≤ S/2` and `m(x) = L^2 + (S − L)^2` when `L ≥ S/2`. The minimum `m(x)` is attained for every `x` by an explicit rank-≤2 Gram construction, so the inequality is exact, not merely sufficient.
- **Section C consequence (adopted as stated).** For a general 4×4 phase-covariant witness with complex `H_ij`, the disconnected-graph argument survives with `k_ij` replaced by `|H_ij|`, so a 2-block-positive indecomposable member must have connected low-edge graph `√(d_ij d_ji) < |H_ij|`. The explicit example with phase-cancelling cross blocks is reconstructed exactly.
