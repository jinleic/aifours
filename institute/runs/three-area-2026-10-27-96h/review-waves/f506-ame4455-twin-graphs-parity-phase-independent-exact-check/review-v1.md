### 2.1 Twin graph: the complex argument precedes the finite sign diagnostic

For a distance-one pair at symbols \(a,a'\), the actual common-tensor interface defines
\[
T=V_a\cap V_{a'},\qquad
z_v=U_{a,v}\overline{U_{a',v}}\ne0.
\]

Actual block closure makes each of the other three coordinate pairings a perfect matching on \(T\). Two matching colors cannot give the same edge: then two distinct triples would agree in two coordinates, producing four extensions of a physical pair, contrary to exact multiplicity two.

The resulting graph is therefore simple and cubic. Row orthogonality gives
\[
z_v+z_{v'}=0
\]
on every edge. Around an odd cycle this yields \(z_v=-z_v\), impossible over \(\mathbb C\) for nonzero \(z_v\).

This is an arbitrary-complex argument. The source’s graph two-coloring implements its finite parity consequence; it does not replace that argument with a real-amplitude assumption.

- a degree-two varying symbol has at most four slice words and cannot support such a nonempty twin graph;
- two degree-three varying symbols have at most six common words, so their slices coincide and their twin graph is \(K_{3,3}\);
- at the regular four-symbol parties, \(M_{12}\) is a perfect matching, whose distinct rows and columns have distinct residual neighborhoods. Hence the degree-three twin conclusion contradicts \(M_{12}\).

def unique_words(words):

def pair_counters(words):

def right_axes(left):
    return tuple(i for i in range(4) if i not in left)


def split_word(word, left):
    right = right_axes(left)
    return (
        tuple(word[i] for i in left),
        tuple(word[i] for i in right),
    )


def merge_word(row, column, left):
    right = right_axes(left)
    result = [None] * 4
    for i, value in zip(left, row):
        result[i] = value
    for i, value in zip(right, column):
        result[i] = value
    need(all(value is not None for value in result), "MERGE_ARITY")
    return tuple(result)


def adjacency(words, left):
    rows = {}
    columns = {}
    for word in unique_words(words):
        row, column = split_word(word, left)
        rows.setdefault(row, set()).add(column)
        columns.setdefault(column, set()).add(row)
    return rows, columns


def close_rectangles(seed):

def graph_coloring(n, edges):
    adjacent = [set() for _ in range(n)]
    for a, b in edges:
        adjacent[a].add(b)
        adjacent[b].add(a)
    color = {}
    for start in range(n):
        if start in color:
            continue
        color[start] = 0
        stack = [start]
        while stack:
            vertex = stack.pop()
            for other in adjacent[vertex]:
                wanted = 1 - color[vertex]
                if other in color:
                    if color[other] != wanted:
                        return None
                else:
                    color[other] = wanted
                    stack.append(other)
    return color

def perfect_matchings(vertices):
    vertices = tuple(vertices)
    if not vertices:
        return ((),)
    if len(vertices) % 2:
        return ()
    first = vertices[0]

        for matching in perfect_matchings(rest):
            edge = (min(first, other), max(first, other))
            result.append(tuple(sorted((edge,) + matching)))
    return tuple(sorted(set(result)))
