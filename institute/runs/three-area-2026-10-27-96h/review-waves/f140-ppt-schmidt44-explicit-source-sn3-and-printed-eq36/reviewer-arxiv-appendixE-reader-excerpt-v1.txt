## Appendix E Schmidt number three PPT state in 4×124\times 12

The scheme described in the previous section can be slightly modified to obtain a Schmidt number 33 bound entangled state ρ4,12\rho^{4,12} in local dimensions 4×124\times 12. We start with the tensor product between the crosshatch state and the bound entangled state ρHor\rho^{\mathrm{Hor}} in 2×42\times 4, known as Horodecki state [[37](#bib.bib37)], which has the highest known relative Schmidt number SN⁡(ρHor)/dmin=1\mathrm{SN}(\rho^{\mathrm{Hor}})/d_{\min}=1.

|  | OPENρHor=110​(\|00⟩​⟨00\|+(\|01⟩+\|10⟩)​(⟨01\|+⟨10\|)+(\|03⟩+\|12⟩)​(⟨03\|+⟨12\|)CLOSECLOSE(\|02⟩+\|11⟩)(⟨02\|+⟨11\|)+(2\|13⟩+\|10⟩)(2⟨13\|+⟨10\|)).\displaystyle\begin{split}\rho^{\mathrm{Hor}}=\frac{1}{10}(\|00\rangle\langle 00\|+(\|01\rangle+\|10\rangle)(\langle 01\|+\langle 10\|)+(\|03\rangle+\|12\rangle)(\langle 03\|+\langle 12\|)\\\\ (\|02\rangle+\|11\rangle)(\langle 02\|+\langle 11\|)+(\sqrt{2}\|13\rangle+\|10\rangle)(\sqrt{2}\langle 13\|+\langle 10\|)).\end{split} | |  | (34) |

As it is evident, ρHor\rho^{\mathrm{Hor}} is not a grid state, as not all states in the convex mixture correspond to equal superpositions of grid vertices. Instead, we have one weighted edge, 2​|13⟩+|10⟩\sqrt{2}|13\rangle+|10\rangle. It is, however, still convenient to depict such a state on a grid (especially after the distillation protocol). See Fig. [4](#A5.F4 "Figure 4 ‣ Appendix E Schmidt number three PPT state in 4×12 ‣ High Schmidt number concentration in quantum bound entangled states") for our representation of ρHor\rho^{\mathrm{Hor}}. Moreover, note that we have chosen a particular representative for the family of states given in [[37](#bib.bib37)], as this allows representing ρHor\rho^{\mathrm{Hor}} similar to a grid state; other states in the family are equally suitable for constructing high Schmidt number states in the same fashion.

In order to obtain ρ4,12\rho^{4,12}, we perform a different local filtering map acting only on Alice’s side, on the tensor product with the 3×33\times 3 crosshatch state, ρHor⊗ρCH\rho^{\mathrm{Hor}}\otimes\rho^{\mathrm{CH}}:

|  | ρA,B4,12=(𝟙B⊗ΠA)​ρA1​B1Hor⊗ρA2​B2CH​(𝟙B⊗ΠA)†,\rho^{4,12}_{{A,B}}=\left(\mathbb{1}_{\mathrm{B}}\otimes\Pi_{\mathrm{A}}\right)\rho^{\mathrm{Hor}}_{\mathrm{A}_{1}\mathrm{B}_{1}}\otimes\rho^{\mathrm{CH}}_{\mathrm{A}_{2}\mathrm{B}_{2}}\left(\mathbb{1}_{\mathrm{B}\otimes\Pi_{\mathrm{A}}}\right)^{\dagger}, |  | (35) |

To ease the notation, we relabel Alice’s basis as follows {|00⟩A1​A2,|01⟩A1​A2,|11⟩A1​A2,|02⟩A1​A2}↦{|0⟩A,|1⟩A,|2⟩A,|3⟩A}\\{|00\rangle_{\mathrm{A_{1}}\mathrm{A_{2}}},|01\rangle_{\mathrm{A_{1}}\mathrm{A_{2}}},|11\rangle_{\mathrm{A_{1}}\mathrm{A_{2}}},|02\rangle_{\mathrm{A_{1}}\mathrm{A_{2}}}\\}\quad\mapsto\quad\\{|0\rangle_{\mathrm{A}},|1\rangle_{\mathrm{A}},|2\rangle_{\mathrm{A}},|3\rangle_{\mathrm{A}}\\} and Bob’s basis as |i​j⟩B1​B2↦|i+4​j⟩B|ij\rangle_{\mathrm{B}_{1}\mathrm{B}_{2}}\mapsto|i+4j\rangle_{\mathrm{B}}. Thus, if we suppose that ρ4,12\rho^{4,12} can be decomposed into Schmidt rank 22 states, at least one state |ψ⟩∈R2​(ρ)|\psi\rangle\in R_{2}(\rho) in the decomposition must have a Schmidt rank 22 projection P​|ψ⟩P|\psi\rangle.
Suppose that for all states |ψi⟩|\psi_{i}\rangle in the decomposition ρAB4,12=∑ipi​|ψi⟩​⟨ψi|\rho^{4,12}_{\mathrm{AB}}=\sum_{i}p_{i}|\psi_{i}\rangle\langle\psi_{i}|, the projections PAB​|ψi⟩P_{\mathrm{AB}}|\psi_{i}\rangle are product states, then it would follow that

|  | PAB​ρAB4,12​PAB=∑ipi​PAB​\|ψi⟩​⟨ψi\|​PAB∝ρABHor,P_{\mathrm{AB}}\rho^{4,12}_{\mathrm{AB}}P_{\mathrm{AB}}=\sum_{i}p_{i}P_{\mathrm{AB}}\|\psi_{i}\rangle\langle\psi_{i}\|P_{\mathrm{AB}}\propto\rho^{\mathrm{Hor}}_{\mathrm{AB}}, |  | (38) |

wrongly implying that ρABHor\rho^{\mathrm{Hor}}_{\mathrm{AB}} is separable. This proves the previous statement by contradiction.

This Schmidt rank 22 projection can be associated to a size 2×22\times 2 block, with i0,i1≤3i_{0},i_{1}\leq 3, with nonzero determinant:

|  | \|⟨1​i0\|ψ⟩AB⟨1​i1\|ψ⟩AB⟨2​i0\|ψ⟩AB⟨2​i1\|ψ⟩AB\|≠0.\left\|\begin{matrix}\langle{1i_{0}\|\psi}\rangle_{\mathrm{AB}}&\langle{1i_{1}\|\psi}\rangle_{\mathrm{AB}}\\\\ \langle{2i_{0}\|\psi}\rangle_{\mathrm{AB}}&\langle{2i_{1}\|\psi}\rangle_{\mathrm{AB}}\end{matrix}\right\|\neq 0. |  | (39) |

Since |ψ⟩⟂|hi⟩|\psi\rangle\perp|h_{i}\rangle, it follows that PAB​|ψ⟩∝|s~⟩P_{\mathrm{AB}}|\psi\rangle\propto|\tilde{s}\rangle, contradicting Eq. ([39](#A5.E39 "In Appendix E Schmidt number three PPT state in 4×12 ‣ High Schmidt number concentration in quantum bound entangled states")).
Thus, for every |ψ⟩∈R2​(ρAB4,12)|\psi\rangle\in R_{2}(\rho^{4,12}_{\mathrm{AB}}), PAB​|ψ⟩P_{\mathrm{AB}}|\psi\rangle is a product state, and it is not possible to find a decomposition of ρAB4,12\rho^{4,12}_{\mathrm{AB}} into pure states in 2-restricted range, as that would imply a decomposition of the Horodecki state into product states.
We can therefore conclude that ρ4,12\rho^{4,12} has Schmidt number 33.
