**L1 (T1).** ρ(u,v) := the row containing adjacency u→v is defined for **every** u≠v, and for each fixed a, ρ(a,·): S∖{a} → Rows∖{λ(a)} and ρ(·,c): S∖{c} → Rows∖{row c} are bijections. *Proof.* n rows × (n−1) adjacency slots = n(n−1) = number of ordered pairs; T1 "at most once" forces exactly once each. A row r lacks an adjacency out of a iff a is last in r; ρ(a,·) is injective (T1) with image = rows where a is not last, so #{rows: a last} = n−(n−1) = 1, i.e. λ is defined and the image is exactly Rows∖{λ(a)}; bijection by counting. **L2 (T1).** ρ(a,c) ∉ {row c, λ(a)}: c sits at position 0 of row c (no adjacency enters it there) and a is last in λ(a) (nothing after). ∎

**L3 (T1, domain dichotomy).** With b₀ = successor of a in row c and c₀ = predecessor of c in λ(a), both undefined exactly when a is last in row c, i.e. E(c)=a: (i) if E(c)≠a, ψ_{a,c} = ρ(·,c)⁻¹∘ρ(a,·) is a bijection S∖{a,b₀} → S∖{c,c₀} ((n−2)-sets); (ii) if E(c)=a (so λ(a)=row c), ψ_{a,c}: S∖{a} → S∖{c} is a bijection ((n−1)-sets).
