## Written reconstruction: all T2(11)

Write S for the 11 symbols. Each of 11 rows is a permutation, so there are 110 distinct directed adjacent events among exactly 110 nonloop ordered pairs. A symbol x has 11 appearances and is the source of one adjacent event except in each row where it is last. Since there are only ten possible directed targets, x is last at least once; there are exactly 11 last positions, so it is last exactly once. The analogous incoming count makes it first exactly once. The corresponding first-to-last map is a derangement because each row has distinct ends.

Insert ∞ between the last and first entry of each **actual** row. The eleven resulting directed 12-cycles cover every nonloop directed pair of V=S∪{∞} exactly once: the S-to-S arcs are the linear adjacency events, and the other arcs are the unique last-to-∞ and ∞-to-first arcs. Thus with actual successor matrices P_i, ΣP_i=J−I. Each P_i² is a permutation matrix and a 12-cycle has no fixed point after two steps. Therefore B=ΣP_i² has zero diagonal and row/column sums 11; W=B−(J−I) is integral, has zero diagonal and zero margins, and W_xy≥−1.

There are 99 distinct linear distance-two events, hence exactly 11 missing directed pairs M in S×S. Let C={(last R,first R)}. It has 11 distinct nonloops and exactly one source and target at each symbol. For x≠y in S the cyclic two-step events are the linear events plus the closing event x→∞→y, so W_xy=1_C(x,y)−1_M(x,y). If p_x counts penultimate occurrences and s_x second occurrences, then W_x∞=p_x−1 and W_∞x=s_x−1. These are identities for the actual cycles, not chosen row or column marginals.

There are 11 occurrences in each of the penultimate and second columns. For any 11 nonnegative integers summing to 11, total positive excess over 1 equals the number of zero entries. Consequently the total positive mass F of W is **δ+z_p+z_s**, with δ=|C\M|=|M\C|. B counts 132 cyclic events over 132 nonloop cells, and B≥0, so positive excess also equals the number of cells with B=0.

More explicitly, the number of linear distance-two events from x is 11−1−p_x=10−p_x, hence the outdegree of x in M is p_x; the indegree is s_x. If p_x=0, the one C-edge with source x lies outside M. These C-edges are distinct as x varies, proving z_p≤δ; similarly z_s≤δ. Thus δ=0 implies z_p=z_s=0 and F=0. Conversely F=0 forces δ=0. Finally F=0 iff every nonloop B-cell is 1, exactly circular 2-perfection. This proves C=M iff F=0 iff 2-perfect; in that case M=C already forces the second and penultimate columns to be permutations.

For the circulation, give every row index R_x and column index C_y its own bipartite vertex. Put −W_xy arrows R_x→C_y if W_xy<0 and W_xy arrows C_y→R_x if W_xy>0. Zero margins balance every vertex. A nonempty finite balanced directed multigraph decomposes into directed cycles; opposite signs cannot occur in the same cell, so there are no directed 2-cycles and every cycle has at least four arrows. Thus F=0 or F≥2. If F=2, the four arrows are precisely one directed four-cycle: two +1 and two −1 cells are opposite corners of a 2×2 rectangle. This necessity does not make a merely balanced rectangle realizable by 12-cycles.

If δ=1, write C\M={(a,b)} and M\C={(c,d)}. Since C has one source and one target at each symbol, the M outdegree has one zero exactly if a≠c, and its indegree has one zero exactly if b≠d. The pairs differ, so at least one inequality holds and F=1+[a≠c]+[b≠d]∈{2,3}.

## Written reconstruction: actual free q-action

Label V={(a,t): 0≤a<r, t∈Z_q}, r=12/q, with g(a,t)=(a,t+1) and ∞=(0,0). A type λ=(a,b,d), excluding (a,a,0), is the q-pair orbit (a,t)→(b,t+d). Since there are q concrete cells per type, F=qP where P=Σ max(w,0); P is also the number of absent types because the negative deviations are all −1.

The periodic step is not a selection of abstract cycle marginals. For an **actual** g-orbit of cycles, let its stabilizer have order s and put L=12/s. A stabilizer element acts as a rotation of the Hamiltonian cycle. Because it has order s, that rotation is (12/s)u positions with gcd(u,s)=1; hence shifting by L positions is some power g^t. The coordinate jumps on that cycle are L-periodic. Their two-step jump at j is the sum of the one-step jumps at j and j+1, so over a period the D2 jump sum is twice the D1 sum modulo q.

Moreover the L period positions count the **full multiplicity** of D1 or D2 types contributed by the entire cycle orbit: translating an event through g yields all q concrete pairs in its type, with the s stabilizer translates accounted for by period repetitions and the q/s cosets by distinct cycles. This remains true when different period positions give the same D2 type; their occurrences are counted separately. Across all orbits, actual D1 arcs cover each type once. Consequently

## Independent free-Z3 collision argument and boundary

Let O={∞,g∞,g²∞}. Cutting the invariant cycle family at any point o∈O gives a relabeling of the original T2 cut. Consider two distinct cyclic two-step events with the same ordered endpoints x,z and middle vertices y,y′. The two middles are distinct: otherwise the unique arc x→y puts both events in the same cycle with the same successor. All four x,y,y′,z are distinct. If any o∈O lay outside these four vertices, both events would survive linearly in the T2 cut at o, a contradiction. Therefore **O⊆{x,y,y′,z}** for every collision pair.

There cannot be a consecutive triple entirely in O. Such a triple is x→g^a x→g^(2a)x for a=1 or 2. Its g^a-translate contains the arc g^a x→g^(2a)x followed by x. The unique cycle containing that arc would have to return to x in three steps, contradicting length 12.

The collision union must contain all three O-points. Neither zero endpoints in O (only two middle slots) nor two endpoints in O (one middle is then in O, creating an all-O triple) is possible. Hence exactly one endpoint is in O and the two middles are the other O-points. A third event with the same endpoints would have a third middle; pairing it with either existing event would again require both remaining O-points among those two middles, impossible. Thus repeated types have multiplicity exactly two.

For a fixed source x∈O, two different repeated outside targets would each use both other O-points as middles. Both would then contain the unique arc x→gx, but would require different successors of that arc, impossible. Invariance under g turns a repeated O-to-outside type into one such target per O-point, so there is at most one repeated type of that orientation. Reversing predecessor/successor gives at most one repeated outside-to-O type. Therefore P≤2. Coupled with P≠1, P∈{0,2} and F=3P∈{0,6}. This derivation did not import the prior collision bound. Its use of the T2 cuts is essential: a free action and a D1 decomposition alone do not give this bound.

If F=0, the all-array identity gives δ=z_p=z_s=0 and C=M, with all p_x=s_x=1 and a 2-perfect extension. If F=6, P=2 and there is exactly one multiplicity-two type in each crossing orientation. A repeated O→outside type comprises three concrete surplus pairs: the one beginning at ∞ doubles one second-column symbol outside O; the other two have both endpoints in S and are in C\M. The reverse orientation similarly doubles one penultimate symbol outside O and contributes two more C\M pairs. Thus δ=4 and |C∩M|=7. Each column has one value with multiplicity two, one value omitted, and the remaining nine with multiplicity one. These conclusions concern any actual six-defect branch, not the existence of one.

For the remaining arrangement, denote the two positive types (0,A,d₊) and (B,0,e₊), A,B≠0. Their total positive weight is 2; exactly two distinct missing types supply negative weight −1 each. Layer balance makes their source-layer multiset {0,B} and target-layer multiset {A,0}. Consequently there are exactly the following two possible ordered-layer patterns:

1. **Crossing:** (0,A,d₋) and (B,0,e₋). Distinct signs exclude d₋=d₊ and e₋=e₊; jump conservation gives (d₋−d₊)+(e₋−e₊)=0 mod 3, so the two nonzero changes are opposite. The missing ∞→outside pair gives the omitted second symbol in the orbit of its doubled second symbol, and the missing outside→∞ pair gives the omitted penultimate symbol in the orbit of its doubled penultimate symbol. Both omissions are outside O.
2. **Switched:** (0,0,u) and (B,A,v), with u≠0 and u+v=d₊+e₊ mod 3. The ordinary nonloop type rule additionally requires v≠0 if B=A. The (0,0,u) absent type includes ∞→g^u∞ and g^(−u)∞→∞, so the omitted second and penultimate symbols are the two distinct points of O\{∞}. The other missing type has both endpoints outside O.

Thus there is no mixed inside/outside omission case. Balances and congruence are necessary only: none supplies Hamiltonian realizability of a type assignment.
