## 2. The physical reduction, re-derived

Definitions used (the candidate's text is consistent with these; if the run's internal definitions are stricter, e.g. "classical" without phases or unitary freedom, the theorem still covers them because the premise only gets narrower): a QLS of order 8 assigns a unit vector of $\mathbb{C}^8$ to each cell of an $8\times8$ array so that every row and every column is an ONB; two QLS $Q,Q'$ are orthogonal iff $\{Q(x)\otimes Q'(x)\}_x$ is an ONB of $\mathbb{C}^{64}$; $Q$ is classical iff all its entries lie, up to phase, in one ONB.

**A. Classical mates are MOLS and force line-ONBs.** If $L$ is classical with basis $\{b_s\}$ and labels $L(x)$, rows/columns ONB means $L$ is a Latin square. For two classical mates, $\langle b_{L(x)}\otimes b'_{L'(x)}, b_{L(y)}\otimes b'_{L'(y)}\rangle=\delta_{L(x)L(y)}\delta_{L'(x)L'(y)}$, so orthogonality is exactly orthogonality of the Latin squares. For arbitrary $Q$ and classical $L$: $\langle Q(x)\otimes b_{L(x)},Q(y)\otimes b_{L(y)}\rangle=\langle Q(x),Q(y)\rangle\,\delta_{L(x)L(y)}$; 64 vectors in $\mathbb{C}^{64}$ are an ONB iff orthonormal, so $Q\perp L$ **iff** $Q$ is pairwise orthogonal (hence an ONB, 8 vectors in $\mathbb{C}^8$) along every symbol line of $L$. No common rotation of the mates is needed. Hence with three classical mates, $Q$ is an ONB on every line of the 5-net $N=\{\text{rows},\text{cols},L_1,L_2,L_3\}$ — an OA$(64,5,8,2)$.

**B. Transport / orientation freedom (the "one orientation per representative" step).** If $(L_1,L_2,L_3)$ is paratopic to a catalogue triple $T$ (Egan–Wanless species = orbit of the OA under $S_8\wr S_5$: arbitrary permutation of all five OA columns plus symbol permutations inside each column — verified in the paper text, lines 184–191 and 214–223, which also identifies species of *sets* with species of *lists*), the induced cell bijection $\varphi$ maps lines of $N$ onto lines of $N_T$ (classes possibly permuted). $Q'=Q\circ\varphi^{-1}$ is an ONB on every line of $N_T$ and has the same multiset of vectors, so it is nonclassical iff $Q$ is. Everything below uses only the net $N_T$ plus a choice of anchor line, so an UNSAT certificate for $N_T$ in **any** orientation (row class $r$, column class $c$, anchor symbol $s$) excludes a nonclassical $Q$ on every net paratopic to $N_T$. This is exactly the candidate's claim, and I corroborated it computationally by refuting all 39 species in a second orientation (§3.3).

**C. Anchor frame and forbidden sets.** Pick the anchor line (the "first row"); its eight $Q$ vectors are an ONB; apply a global unitary so they are $e_0,\dots,e_7$ with $e_j$ at the anchor cell in column $j$ (global unitaries preserve all line-ONB conditions and classicality). An off-anchor cell $x$ is collinear with exactly one anchor cell per non-row class (strength 2), i.e. four anchor cells, and they are distinct (two distinct classes' lines through $x$ meet in $x$ only). So $Q(x)\perp e_j$ for the four coordinates $j$ of those cells and the support $S_x\subseteq A_x$, $|A_x|=4$. In label-normalised coordinates ($L_k(0,j)=j$) the forbidden set is $\{c(x),L_1(x),L_2(x),L_3(x)\}$; my encoder derives $A_x$ from collinearity and cross-checks it against this description (equal in all 39×56 cells, every orientation tried).

**D. Nonclassicality criterion.** If every $|S_x|=1$ then every $Q(x)$ is a phase times some $e_j$, so $Q$ is classical w.r.t. $\{e_j\}$. Contrapositive: nonclassical $\Rightarrow$ some $|S_x|\ge2$. (The converse, that a classical $Q$ must use the anchor ONB, also holds since the anchor line already contains eight orthogonal rays of the classical basis — but only the first direction is load-bearing.)

**E. Necessity of each clause family** (variables $P_{x,t}\equiv t\in S_x$ for $t\in A_x$, 224 of them):
1. $\bigvee_{t\in A_x}P_{x,t}$: unit vectors have nonempty support. 56 clauses.
2. Coverage: for a line $\ell$ and coordinate $t$, $\sum_{x\in\ell}|Q(x)_t|^2=1$ (the $t$-th diagonal entry of $\sum_x Q(x)Q(x)^\dagger=I$). If $(0,t)\notin\ell$ the anchor cell on $\ell$ (if any) has zero $t$-coordinate, so some off-anchor $x\in\ell$ has $t\in S_x\subseteq A_x$. Lines containing $(0,t)$: row 0, column $t$, the three label lines of symbol $t$ — five of 40, so $8\times35=280$ clauses per species (observed 280 in all 39). The "exactly four eligible cells" count is a true consequence of orthogonality (I derived it) but the clause is sound for any count.
3. Collinear $x\neq y$: $\langle Q(x),Q(y)\rangle=\sum_{j\in S_x\cap S_y}\overline{Q(x)_j}Q(y)_j=0$ is impossible with exactly one nonzero term, so $|S_x\cap S_y|\ne1$. With $A_x\cap A_y=\{t\}$ this is the binary clause $\neg P_{x,t}\vee\neg P_{y,t}$; with $|A_x\cap A_y|\ge2$ the file defines $B_{x,y,t}\leftrightarrow P_{x,t}\wedge P_{y,t}$ (three clauses each) and requires $B_{x,y,t}\to\bigvee_{u\ne t}B_{x,y,u}$; the physical assignment extended by the definition satisfies all of them. 868 collinear off-anchor pairs per species ($7\cdot\binom82+32\cdot\binom72$, observed 868 in all 39).
4. Two-axis triangles: for pairwise collinear $x,y,z$ with $A_x\cap A_y=A_y\cap A_z=A_x\cap A_z=\{t,u\}$, each pairwise inner product equals the inner product of the projections onto $\mathrm{span}(e_t,e_u)$; three nonzero pairwise-orthogonal vectors cannot exist in $\mathbb{C}^2$; so not all six of $P_{\cdot,t},P_{\cdot,u}$ hold. (A stronger clause — at least one projection vanishes — is also sound; the file uses the weaker 6-literal form, which is fine.) My encoder enumerates triangles by brute force over all triples of pairwise collinear cells and reproduces the author's graph-based set exactly (160 for species 0, as the species-0 note states; 0 for species 38).
5. Nonclassicality: auxiliaries $n_{x,\{t,u\}}\to P_{x,t},P_{x,u}$ and $\bigvee n$: by D, a nonclassical $Q$ supplies $x$ and $t<u$ in $S_x$; set that auxiliary true.

So every physical nonclassical fourth member yields a satisfying assignment of the exact CNF; UNSAT excludes it. The converse is not claimed and not needed (a SAT support model is not a physical witness). Note also that for the 38 maximal species a *classical* fourth member would be a fourth MOLS, so those CNFs are UNSAT even without clause family 5 — consistent with my informational control (§3.2); only species 38 (nonmaximal, AG(2,8)) depends on clause 5, and there my own classical witness shows the N-free CNF is satisfiable while the full CNF is refuted in both orientations tried.
