(c) |Y| <= 3kappa + 1 iff |U| <= p - 3e + 1 + delta0;  |Y| <= p + 2kappa iff |U| <= p - 2e + delta0.

(0 <= i <= M, W <= R identified with a sub-multiset of U); its sum is (i + A_W) g with A_W := sum of c_x = |W| + 2sigma(W),
and its length is i + |W|.  It is a zero-sum iff i + A_W = 2pk for an integer k >= 0; as 0 <= i <= M < 2p, for given W
there is at most one such i, namely i = 2pk - A_W with k = ceil(A_W/(2p)), and it exists iff 2pk - A_W <= M.  So the
zero-sums are exactly the pairs (W, k) with 2pk - M <= A_W <= 2pk, of length 2pk - A_W + |W| = 2pk - 2sigma(W).
(a) The length lies in [2p - 2e + 2, 2p] iff sigma(W) lies in [p(k - 1), p(k - 1) + e - 1] (k >= 1 then).  Write q := k - 1,
rho := sigma(W) - pq in [0, e - 1] (so rho = sigma(W) mod p, as e - 1 < p); then A_W = |W| + 2pq + 2rho and
2pk - M <= A_W <= 2pk iff delta0 <= |W| + 2rho <= 2p.  Conversely any W as in (F) gives the zero-sum (W, q + 1) of length
2p - 2rho in the window.
(b) Length 2pk - 2sigma(W) >= 2p + 2 iff sigma(W) = p(k - 1) - j with j >= 1; then A_W = |W| + 2p(k - 1) - 2j and
2pk - M <= A_W <= 2pk iff delta0 + 2j <= |W| <= 2p + 2j; the length is 2p + 2j.  Conversely such (W, j) gives k :=
(sigma(W) + j)/p + 1 >= 2.
(c) |Y| = M + |U| = 2p - delta0 + |U|, 3kappa + 1 = 3p - 3e + 1, p + 2kappa = 3p - 2e.  []
Instances (used below; direct from the definitions).  E2(k) with g = h: delta0 = 2p - (3k - p + 2), U = 1^(p-1).  E3(k)
with g := 3h (a generator, p != 3): v_g = 2p - 1, delta0 = 1, U = (mu*)^(3k-2p+2), where h = c* g with c* = 3^(-1) mod 2p and
mu* = (c* - 1)/2 satisfies 3mu* = -1 (mod p) (from 3(2mu* + 1) = 1 (mod 2p)).

## 2. Lemma XT
Let p >= 7 prime, kappa0 + 1 <= kappa <= p - 2 (kappa0 := floor(2p/3); so 2 <= e and 3e <= p - 1), h a generator, and
Z a sequence of at most three odd elements.
(i) E2(kappa - 1) Z satisfies (ZP_kappa) iff Z is one of: empty, h, -h, -3h, h^2, h(-h), h^3.
(ii) If kappa >= kappa0 + 2, E3(kappa - 1) Z satisfies (ZP_kappa) iff Z is one of the same seven sequences.
In particular the only three-term (ZP_kappa)-extensions are E2(kappa - 1) h^3 = E2(kappa) and E3(kappa - 1) h^3 = E3(kappa).
(p >= 7 because the kappa-range is empty at p = 5.)
Proof.  (ZP_kappa) passes to subsequences, so a Z of length t is admissible only if all its subsequences are; we classify
lengths 1, 2, 3 in turn and in each step only test the sub-multisets W of U that contain all added non-g terms (the others
were tested at a smaller length).  E2(kappa - 1) and E3(kappa - 1) satisfy (ZP_(kappa-1)) (Lemma TV's E2/E3 computation at
kappa - 1; re-derived for the base below), hence (ZP_kappa).
(i) Take g = h.  E2(kappa - 1) has v_h = 3(kappa - 1) - p + 2 = 2p - 3e - 1, so delta0 = 3e + 1, U = 1^(p-1).  Base: W = 1^w,
sigma = w <= p - 1; rho = w only if w <= e - 1, and then |W| + 2rho = 3w <= 3e - 3 < delta0: (F) holds.  Adding h lowers
delta0 by one and does not change U; adding x = c h with c >= 3 adds mu := (c - 1)/2 to U.
- One term x, mu in [1, p - 1].  The new sets are W = 1^w {mu}, 0 <= w <= p - 1, sigma = w + mu in [mu, mu + p - 1].  For each
  rho in [0, e - 1] there is exactly one such W with sigma = rho (mod p): w = rho - mu if rho >= mu (then |W| + 2rho =
  3rho - mu + 1 <= 3e - 3 < 3e + 1: harmless), and w = p + rho - mu if rho < mu (then |W| + 2rho = p + 1 + 3rho - mu <= 2p).
  So x is forbidden iff some rho in [0, min(e - 1, mu - 1)] has p + 1 + 3rho - mu >= 3e + 1.  For mu <= e - 1 take
  rho = mu - 1: 2mu >= 3e + 3 - p holds as 3e + 3 - p <= 2.  For mu >= e take rho = e - 1: forbidden iff mu <= p - 3.
  Hence the admissible one-term Z are h (delta0 = 3e: base check 3w <= 3e - 3 < 3e), and mu in {p - 2, p - 1}, i.e.
  c in {2p - 3, 2p - 1}: x = -3h or -h.
- Two terms from {h, -h, -3h}.  Write mu = p - 1 for -h and p - 2 for -3h.  The sets to test are W = 1^w plus the added
  non-g terms, 0 <= w <= p - 1.
  h^2: delta0 = 3e - 1, U unchanged: 3w <= 3e - 3: admissible.
  h(-h): delta0 = 3e; W = 1^w {p - 1}: sigma = p + (w - 1), rho = w - 1 <= e - 1 iff 1 <= w <= e, |W| + 2rho = 3w - 1 <= 3e - 1
  < 3e (w = 0 gives rho = p - 1 >= e): admissible.
  h(-3h): delta0 = 3e; W = 1^(e+1) {p - 2}: sigma = p + e - 1, |W| + 2rho = e + 2 + 2e - 2 = 3e: forbidden.
  (-h)^2: delta0 = 3e + 1; W = 1^(e+1) {p - 1}^2: sigma = 2p + e - 1, |W| + 2rho = e + 3 + 2e - 2 = 3e + 1: forbidden.
  (-h)(-3h): W = 1^(e+2) {p - 1, p - 2}: sigma = 2p + e - 1, |W| + 2rho = e + 4 + 2e - 2 = 3e + 2 >= 3e + 1: forbidden.
  (-3h)^2: W = 1^(e+3) {p - 2}^2: sigma = 2p + e - 1, |W| + 2rho = 3e + 3: forbidden.
  (In each forbidden case w <= e + 3 <= p - 1 and |W| + 2rho <= 2p, as 3e <= p - 1, p >= 7.)
- Three terms: every two-term subsequence must be h^2 or h(-h); so Z is h^3 or h^2(-h).  h^3: delta0 = 3e - 2, 3w <= 3e - 3:
  admissible (this is E2(kappa)).  h^2(-h): delta0 = 3e - 1; W = 1^e {p - 1}: sigma = p + e - 1, |W| + 2rho = 3e - 1: forbidden.
(ii) Take g := 3h, mu* as in Sec. 1, n := 3(kappa - 1) - 2p + 2 = p - 3e - 1; kappa >= kappa0 + 2 gives 3kappa >= 2p + 4, so n >= 3.
E3(kappa - 1) has delta0 = 1, U = (mu*)^n.  Adding g is impossible (M = 2p gives g^(2p)).  With delta0 = 1, (F) says: no
NONEMPTY W with sigma(W) mod p in [0, e - 1] (every |W| here is <= n + 3 <= p, so |W| + 2rho <= 2p).  Multiply by -3 (an
automorphism of Z_p): put nu(x) := -3 mu_x mod p, so nu = 1 for every term of U; the forbidden condition becomes
nu(W) := sum of nu over W in Phi := {0, -3, -6, ..., -3(e - 1)} (mod p), whose nonzero elements, as integers in [1, p - 1], are
p - 3, ..., p - 3e + 3 = n + 4.
- One term x with nu := nu(x) in [1, p - 1] (nu = 0 would be mu = 0, i.e. x = g).  The sets W = (mu*)^t {x}, 0 <= t <= n, have
  nu(W) = t + nu.  So x is forbidden iff nu in {phi - t : phi in Phi, 0 <= t <= n}; as n >= 2 the intervals
  [-3rho - n, -3rho] (rho = 0, ..., e - 1) overlap consecutively, and their union is [-(3e - 3 + n), 0] = [-(p - 4), 0], i.e.
  every residue except 1, 2, 3.  So x is admissible iff nu(x) in {1, 2, 3}.  Translating (h = c* g; an element with
  g-coefficient c has h-coefficient 3c mod 2p): nu = 1 is mu = mu*, x = h; nu = 3 is mu = p - 1 (as -3(p - 1) = 3), x = -g =
  -3h; nu = 2 is mu = 2mu* (mod p), c = 2c* - 1, h-coefficient 6c* - 3 = -1, x = -h.
- Two and three terms.  Adding a copies of h, b of -h, c of -3h gives the nu-multiset 1^(n+a) 2^b 3^c with n + a >= 2 ones, whose
  nonempty sub-multiset sums are exactly the integers in [1, n + a + 2b + 3c] (adding an element v <= S + 1 to a multiset whose
  sums fill [0, S] makes them fill [0, S + v]; start from 1^(n+a), S = n + a >= 2).  All of these are < 2p (n + a + 2b + 3c <=
  n + 9 < 2p), so a forbidden sum is an integer = 0 or in {p - 3, ..., n + 4} (mod p) inside [1, n + a + 2b + 3c]; the
  least such is n + 4.  Hence Z = h^a (-h)^b (-3h)^c is admissible iff a + 2b + 3c <= 3: for |Z| = 2 exactly h^2, h(-h); for
  |Z| = 3 exactly h^3 (= E3(kappa)).  []
Remark.  For kappa = kappa0 + 1 (n in {0, 1}), E3(kappa - 1) = E3(kappa0) has no long zero-sum (it has no zero-sum of length
> 2kappa0, by S1-sharp or directly), so (ii) is not needed there.  Similarly E2(kappa0) has no long zero-sum.

## 3. Consequence (conditional; nothing assumed)
TR(p, kappa) (three-occurrence transversal, OPEN): every (ZP_kappa) sequence Y of length 3kappa + 1 with a long zero-sum has
three occurrences whose deletion leaves a sequence with a long zero-sum and no zero-sum of length 2kappa.
Proposition.  Let kappa0 + 2 <= kappa <= p - 2.  STAB(p, kappa - 1) and TR(p, kappa) imply STAB(p, kappa).
Proof.  Y as in TR; delete the three occurrences: V has length 3(kappa - 1) + 1, satisfies (ZP_(kappa - 1)) (no zero-sum of
length 2kappa, and (ZP_kappa)) and has a long zero-sum (length >= 2p + 2 >= 2(kappa - 1) + 2), so by STAB(p, kappa - 1),
V = E2(kappa - 1) or E3(kappa - 1) for some generator h; Y = V Z with |Z| = 3 satisfies (ZP_kappa), so Lemma XT gives
Z = h^3 and Y = E2(kappa) or E3(kappa).  []

# Row lemma, the multiplicity lemma DGM-p, a universal (ZP_kappa) length bound, and two structural dichotomies, v1

Owner OlsonSTABSuccessor (Slice A).  Written after /bin/date 2026-10-19T04:53:25-0700.  Status: CANDIDATE, written proofs [W], UNREVIEWED.
Uses Lemma CF of proof-CF-XT-v1.md (aa602d45e154a7787ac3f0270a3c26deb5e8c6a70736cf4a82c700f5368c191f) and one classical import: the Cauchy-Davenport theorem
(|A + B| >= min(p, |A| + |B| - 1) for nonempty A, B in Z_p, p prime).  Nothing else; LS, LS+, STAB not assumed.  The
multiplicity lemma below is the prime-order special case of the DeVos-Goddyn-Mohar bound suggested by the parent's scout
(run review/olson-priority-parent-note-v2.md); it is proved here from Cauchy-Davenport, so DGM itself is NOT imported.
No novelty claim (statements of this type are standard in zero-sum theory); no Lean.

## 0. Notation
As in proof-CF-XT-v1.md: p >= 5 prime, e := p - kappa, (ZP_kappa), long, CF data (delta0, U) of a sequence Y w.r.t. an odd
generator g; r := |U|; rho(W) := sigma(W) mod p.  For a sequence S over Z_p, v_x(S) is the multiplicity of x; Sigma_n(S) is
the set of sums of n-term subsequences; Sigma_(<=K)(S) the set of sums of subsequences with at most K terms (the empty sum 0
included).  Subsequences are occurrence subsequences.

## 1. Lemma RS (rows)
Let S be a sequence over Z_p.
(a) If 1 <= n <= |S|, then |Sigma_n(S)| >= min(p, sum_x min(n, v_x(S)) - n + 1).
(b) If all terms of S are nonzero and K >= 0, then |Sigma_(<=K)(S)| >= min(p, 1 + sum_x min(K, v_x(S))).
Proof.  List the T := sum_x min(n, v_x) chosen occurrences value by value (min(n, v_x) occurrences of each value x) and put
the k-th listed occurrence into row (k mod n) + 1.  The occurrences of one value are consecutive and at most n, so each row
A_i is a SET of values; in (a) T >= min(n, |S|) = n, so every row is nonempty.  Choosing one element from each row selects n
distinct occurrences, so A_1 + ... + A_n <= Sigma_n(S), and iterated Cauchy-Davenport gives |A_1 + ... + A_n| >=
min(p, sum |A_i| - (n - 1)) = min(p, T - n + 1).  (b) Same with n := K rows (K = 0 trivial) and B_i := A_i u {0}
(possibly A_i empty): choosing at most one element per row gives a subsequence of at most K terms, so
B_1 + ... + B_K <= Sigma_(<=K)(S) and |B_1 + ... + B_K| >= min(p, sum(|A_i| + 1) - K + 1) = min(p, 1 + sum_x min(K, v_x)).
(0 is not a term, so |B_i| = |A_i| + 1.)  []

## 2. Lemma DGM-p (one dominant generator)
Let p >= 5 prime, (p - 3)/2 <= kappa <= p - 1, and let Y be an odd sequence over C_(2p) with (ZP_kappa) and |Y| >= p + 2kappa + 1.
Then exactly one element g0 of Y has multiplicity >= 2kappa + 3; g0 is a generator; and |Y| - v_(g0)(Y) <= p - 2.
Proof.  Write the odd elements as (1, a) in C_2 x C_p and let A be the sequence of C_p-coordinates.  A subsequence of exactly
2kappa + 2 <= 2p terms is a zero-sum iff its C_p-coordinates sum to 0; (ZP_kappa) excludes this, so 0 is not in
Sigma_(2kappa+2)(A) and Lemma RS(a) gives sum_x min(2kappa + 2, v_x) <= p + 2kappa < |Y| = sum_x v_x.  So some value x0 has
v_(x0) >= 2kappa + 3, and then sum_(x != x0) min(2kappa + 2, v_x) <= p - 2 < 2kappa + 2 (kappa >= (p - 3)/2); hence every other
value has v_x <= p - 2 (so min = v_x and the others total <= p - 2), and x0 is unique.  If x0 were the involution (1, 0) = p,
x0^(2kappa+2) would be a zero-sum of length 2kappa + 2.  So x0 is a generator.  []

## 3. Theorem U (universal length bound for (ZP_kappa))
Let p >= 5 prime and (p - 3)/2 <= kappa <= p - 1.  Every odd sequence Y over C_(2p) with (ZP_kappa) has |Y| <= 2p + kappa - 1.
The bound is attained by g^(2p-1) (-g)^kappa (g any odd generator), a sequence satisfying (ZP_kappa) AND (S1_kappa).
Proof.  If |Y| <= p + 2kappa we are done (kappa <= p - 1).  Otherwise take g := g0 of Lemma DGM-p and its CF data: M = v_g >= 2kappa + 3,
delta0 = 2p - M >= 1, r = |Y| - M <= p - 2.  If r < delta0 then |Y| < 2p.  Otherwise choose W0 <= U with |W0| = delta0 and
put V := U - W0.  For every V' <= V, W := W0 V' has delta0 <= |W| <= |W| + 2rho(W) <= r + 2e - 2 <= 2p (e <= (p + 3)/2), so by
CF (F) rho(W) is not in [0, e - 1]: the set Sigma_(<=|V|)(V) (all subset sums of V, 0 included) avoids the e residues
-sigma(W0) + [0, e - 1].  By Lemma RS(b) with K := |V| it has at least min(p, |V| + 1) elements; so |V| + 1 <= p - e, i.e.
r <= delta0 + p - e - 1 and |Y| = 2p - delta0 + r <= 3p - e - 1 = 2p + kappa - 1.
Example: with g, the zero-sums of g^i (-g)^j (i <= 2p - 1, j <= kappa) need i = j (mod 2p), so i = j and the length is
2j <= 2kappa.  []
(At kappa = p - 1 this is the classical s_(2p)(C_p) - 1 = 3p - 2; at kappa = 0 it is D(C_(2p)) - 1.)
Use for LS: LS(p, kappa) asks for |Y| <= p + 2kappa = (2p + kappa - 1) - (e - 1) under the extra long zero-sum; LS+ asks for
(2p + kappa - 1) - (2e - 2).  So the long zero-sum must be worth e - 1 (LS) resp. 2e - 2 (LS+) terms; a pure counting bound
that does not use the long zero-sum cannot prove either (it is attained by the (S1) example above).

## 4. Lemma ROW (the large-subset constraint) and the dichotomies
Lemma ROW.  Let Y satisfy (ZP_kappa), g an odd generator with CF data (delta0, U), r >= delta0 and r + 2e - 2 <= 2p.  Put
K := r - delta0.  Then sum_x min(K, v_x(U)) <= p - e - 1.
Proof.  Every W <= U with |W| >= delta0 has delta0 <= |W| + 2rho(W) <= 2p, so rho(W) is not in [0, e - 1] (CF (F)).  Writing
W = U - X, |X| <= K, this says: Sigma_(<=K)(U) avoids the e residues sigma(U) - [0, e - 1].  Lemma RS(b).  []
Dichotomy at the LS threshold.  Let floor(2p/3) + 1 <= kappa <= p - 2 and let Y be a counterexample to LS of length exactly
thr := p + 2kappa + 1 (accepted RED: LS fails iff such Y exists).  With g := g0 (DGM-p): M >= 2kappa + 3, so delta0 <= 2e - 3,
r = p - 2e + 1 + delta0 <= p - 2, and K = p - 2e + 1.  Then either
  (I) every value of U has multiplicity <= K, and then r <= p - e - 1, i.e. delta0 <= e - 2 (M >= p + kappa + 2); or
  (II) exactly one value mu1 has multiplicity v1 >= K + 1 = p - 2e + 2, and the other terms of U number at most e - 2.
(Two values above K would give 2K <= p - e - 1, i.e. p <= 3e - 3, false; in (II) the others then have v_x <= K, so their
total is <= p - e - 1 - K = e - 2.)
Dichotomy at length 3kappa + 2 (LS+).  Let |Y| = 3kappa + 2 with (ZP_kappa), and let g be a generator with M = v_g >= p - e
(so r + 2e - 2 <= 2p).  Then K = p - 3e + 2 and either (I+) every value of U has multiplicity <= K and delta0 <= 2e - 3
(M >= 2kappa + 3), or (II+) some value of U has multiplicity >= p - 3e + 3 (and sum_x min(K, v_x) <= p - e - 1).
No generator with M >= p - e is guaranteed at length 3kappa + 2 by the results above (DGM-p needs |Y| >= p + 2kappa + 1).

## 5. Exact status
Nothing here proves LS, LS+ or STAB.  The lemmas reduce an LS counterexample to the two structured cases (I), (II); they
are recorded because they are the first places where the long zero-sum condition (L) of CF must enter.

## 1. Lemma SH (re-derived; the unreviewed SHIFT of the partials is not used)
Assume H'(kappa); Y a LS-counterexample of length thr.  (a) Every zero-sum Z of Y with 2 <= |Z| <= 2e meets every long

kappa' <= kappa0 this contradicts S1-sharp; otherwise kappa0 < kappa' < kappa and it contradicts LS(p, kappa').  (b) T - Z is a
zero-sum of length >= 2p + 2 - 2e = 2kappa + 2, hence long by (ZP_kappa), and disjoint from Z: contradicts (a).  []

## 2. Lemma AP
Let n >= 1, 3n < p, x in Z_p nonzero, a in Z_p.  If {a + rho x : 0 <= rho <= n} lies in an arc I of size <= 2n, then x = +-1.
Proof.  The n points a + rho x (1 <= rho <= n) are distinct and lie in I n (I + x).  For an arc of size l <= 2n and the signed
representative 0 < |x| <= (p - 1)/2, |I n (I + x)| = max(0, l - |x|) + max(0, l - p + |x|).  If |x| >= 2n this is
<= 2n - (p + 1)/2 < n; if p - 2n < |x| < 2n it is <= 4n - p < n; so |x| <= p - 2n, |x| < 2n and l - |x| >= n, i.e. |x| <= n.  Lift
I to [alpha, alpha + l - 1].  For y in the lift, y + x lies in [alpha - n, alpha + 3n - 1], which meets no other translate of the
lift by a multiple of p (p > 3n - 1); so the lifted points are y_0 + rho x (integers) in an interval of length <= 2n - 1, and
n|x| <= 2n - 1 gives |x| = 1.  []

## 3. Theorem LS-II
Assume H'(kappa).  A LS-counterexample of length thr is not in case (II).
Proof.  Step 1 (mu1 = +-1).  For t in [delta0 - s, v1] (delta0 - s >= 1), W := mu1^t R' has |W| = t + s >= delta0, so W is not
forbidden only if rho(W) avoids [0, e - 1]: t mu1 + sigma(R') avoids [0, e - 1] (mod p).  With x1 := mu1^(-1) mod p, the e-term
progression {x1 (rho - sigma(R')) : 0 <= rho <= e - 1} avoids the interval [delta0 - s, v1] of size v1 - delta0 + s + 1 = K + 1 =
p - 2e + 2, so it lies in the complementary arc of size 2e - 2.  Lemma AP (n = e - 1, 3n < p): x1 = +-1, i.e. mu1 = +-1.
Step 2 (mu1 != 1).  If mu1 = 1, W := 1^(e-1) (v1 >= K + 1 >= e - 1) has rho = e - 1 and |W| + 2rho = 3e - 3 >= delta0: forbidden.
So mu1 = p - 1: the dominant non-g element is -g.
Step 3 (shape of R').  First, W = (-g)^t with p - e + 1 <= t <= v1 would have rho = p - t <= e - 1 and |W| + 2rho = 2p - t >= delta0:
forbidden; so v1 <= p - e.  Let R'' <= R', k := |R''|, phi := sigma(R'') mod p, and W := (-g)^t R'' (0 <= t <= v1), so
sigma(W) = phi - t (mod p).
- If e - 1 <= phi <= v1: t := phi - e + 1 in [0, v1] gives rho(W) = e - 1 and |W| + 2rho = k + phi + e - 1 >= 2e - 2 > delta0: forbidden.
- If v1 + 1 <= phi <= v1 + e - 1: t := phi - e + 1 in [v1 - e + 2, v1] (v1 >= e) gives rho(W) = e - 1 and |W| + 2rho >= v1 + e > delta0:
  forbidden.
- If phi <= e - 2: t := 0 gives rho(W) = phi, forbidden unless k + 2phi <= delta0 - 1.
Hence (R): for every R'' <= R', sigma(R'') mod p lies in [0, (delta0 - 1 - |R''|)/2] or in [v1 + e, p - 1].
For k = 1: every x in R' is TINY (mu_x <= (delta0 - 2)/2) or NEGATIVE (mu_x in [v1 + e, p - 2]; then nu := p - mu_x is in
[2, p - v1 - e], p - v1 - e <= e - 2, and x = -c'g with c' = 2nu - 1 in [3, 2e - 5]).
Step 4 (tiny sub-multisets).  Let R'' <= R' consist of tiny terms in any order, prefix sums S_k (integers).  If some prefix had
S_k > (delta0 - 1 - k)/2, the first such k has 0 < S_k <= (delta0 - k)/2 + (delta0 - 2)/2 < delta0 < v1 + e (and < p), contradicting
(R) for that prefix.  So |R''| + 2sigma(R'') <= delta0 - 1; in particular |R''| <= (delta0 - 1)/3.
Step 5 (the long zero-sum).  Let T be a long zero-sum.  g(-g) is a zero-sum of length 2, so by SH(a) T contains all M copies of g or
all v1 copies of -g.  If T contains both g and -g, T - g(-g) is a zero-sum of length |T| - 2: for |T| = 2p + 2 this is 2p, excluded
by (ZP_kappa); for |T| >= 2p + 4 it is long and misses a pair g, -g, contradicting SH(a).  A T without g lies in (-g)^(v1) R', of
length <= r <= p - 2: not long.  So T = g^M W', W' <= R', |W'| = |T| - M >= 2p + 2 - M = delta0 + 2.  A negative x = -c'g in W'
gives the zero-sum g^(c') x <= T of length c' + 1 <= 2e - 4, excluded by SH(b).  So W' is tiny, and Step 4 gives
|W'| <= (delta0 - 1)/3 < delta0 + 2: contradiction.  []

## 2. Proof of Lemma S1-sharp

Induction on kappa for fixed p.  For kappa <= (p+1)/2 use S1+.  Let (p+3)/2 <= kappa <= floor(2p/3), so delta := 2kappa - p
is odd with 3 <= delta and p >= 3delta - 1, and assume the Lemma at kappa - 1.  Put u := 2kappa = p + delta.  Suppose Y
satisfies (ZP_kappa) but not (S1_kappa).

Step 1 (shortest long zero-sum).  Let T be a zero-sum subsequence of Y with |T| >= u + 2 and |T| = N least.  By
(ZP_kappa), N >= 2p + 2.  If T' is a nonempty proper zero-sum subsequence of T, then |T'| <= u (a proper one of length
>= u + 2 would, by (ZP_kappa), have length >= 2p + 2 and contradict the minimality of N), and T - T' is also a nonempty
proper zero-sum, so |T'| >= l := N - u.  Put D := u - l = 2u - N.  Then D is even, and D <= 2u - 2p - 2 = 2delta - 2.
Also l >= 2p + 2 - u = p - delta + 2.

Step 2 (all proper zero-sums are minimal).  If a nonempty proper zero-sum T' of T contained a nonempty proper zero-sum
T'', then T'' and T' - T'' would be nonempty proper zero-sums of T, so 2l <= |T'| <= u, i.e. N <= 3u/2 = 3kappa.  But
3kappa <= 2p < 2p + 2 <= N.  So every nonempty proper zero-sum of T is a minimal zero-sum sequence.

Step 3 (a proper zero-sum of length exactly u).  If every nonempty proper zero-sum of T had length <= u - 2 = 2(kappa-1),
then the sequence T itself would satisfy (ZP_(kappa-1)) (its proper zero-sums are shorter than 2(kappa-1)+2 = u, and
N > 2p) while T is a zero-sum of length N > 2(kappa-1): this contradicts the Lemma at kappa - 1.  So T has a proper
zero-sum Q with |Q| = u; Q' := T - Q is a proper zero-sum with |Q'| = l.  Both are minimal (Step 2).

Step 4 (index one).  |Q| = p + delta >= p + 3 >= floor(2p/2) + 2, so the index-one theorem gives a in Z_2p with every
term of Q equal to x a, x a positive least coefficient, and the coefficients summing to ord(a).  The terms are odd, so
ord(a) is not p (multiples of an element of order p are even) and not 2 (then every term equals p and |Q| = 2); hence a
=: g is an odd generator, every coefficient lies in [1, 2p-1], is odd (x g is odd iff x is odd), and the coefficients of
Q sum to exactly 2p.  From now on every term of T is written c g with c its least positive coefficient, an odd integer
in [1, 2p-1]; for a sub-multiset W write A_W for the sum of the coefficients (an integer) and mass(W) := A_W - |W|.
Write Q = g^m S_Q, where S_Q collects the terms of Q with coefficient >= 3.  mass(S_Q) = 2p - u = p - delta.  Every
coefficient of S_Q is odd and >= 3, so |S_Q| <= (p - delta)/2 and m >= u - (p - delta)/2 = (p + 3delta)/2.  S_Q is
nonempty (otherwise the coefficients of Q would sum to u != 2p).  Let b_min := min S_Q; then b_min - 1 <= mass(S_Q),
i.e. b_min <= p - delta + 1.  Also every element b of S_Q satisfies b <= 2p - m - 3(|S_Q| - 1) = p - delta - 2|S_Q| + 3
(the other terms of Q have coefficients >= 1 and >= 3 respectively).

Step 5 (main constraint MC).  Let W be a sub-multiset of Q' and Q_1 a sub-multiset of Q with sum of coefficients of Q_1
congruent to A_W modulo 2p, excluding (Q_1, W) = (Q, empty) and (empty, Q').  Then (Q - Q_1) W is a nonempty proper
zero-sum of T (its sum is (2p - (sum of Q_1) + A_W) g = 0), of length u - |Q_1| + |W|.  By Step 1:
    (MC)   |W| <= |Q_1| <= |W| + D.
Write Q' = g^t' Y, where Y collects the terms of Q' with coefficient >= 3 (t' >= 0 copies of g).

Step 6 (no large coefficient in Q').  Every term z of Q' has coefficient c <= D + 1.
Proof.  Suppose c >= D + 2.  Take W = {z} (proper: |Q'| = l >= 2).  We exhibit Q_1 <= Q with coefficient sum c and
|Q_1| >= D + 2, contradicting (MC).  If c <= m, take Q_1 = g^c.  If c > m (note m >= (p+3delta)/2 >= D + 2), let Z_0 be
an inclusion-minimal sub-multiset of S_Q with A_(Z_0) >= c - m (it exists: A_(S_Q) = 2p - m >= c - m), and b_0 := min Z_0.
Minimality gives A_(Z_0) < c - m + b_0, and b_0 <= p - delta - 2|S_Q| + 3 <= p + delta - |S_Q| = m, so A_(Z_0) < c;
hence Q_1 := Z_0 g^(c - A_(Z_0)) is a sub-multiset of Q with coefficient sum c and |Q_1| = c - mass(Z_0).  If
|Q_1| <= D + 1, then mass(Z_0) >= c - D - 1, and mass(Z_0) = A_(Z_0) - |Z_0| < c - m + b_0 - |Z_0| gives
b_0 > m - D - 1 + |Z_0|.
- |Z_0| = 1: b_0 >= m - D + 1 = p + delta - |S_Q| - D + 1 >= p - delta - |S_Q| + 3 (as D <= 2delta - 2), while
  b_0 <= p - delta - 2|S_Q| + 3; so |S_Q| <= 0, impossible.
- |Z_0| >= 2: every element of Z_0 is >= b_0 >= m - D + 2, so mass(Z_0) >= 2(m - D + 1); as mass(Z_0) <= p - delta,
  m <= (p - delta)/2 + D - 1 <= (p + 3delta)/2 - 3 < m, impossible.
So |Q_1| >= D + 2.  []

Step 7 (index of Q' is one).  A_(Q') = 2p.
Proof.  A_(Q') is a positive multiple of 2p.  Suppose A_(Q') >= 4p.  Order Q' arbitrarily and let W be the shortest
prefix with A_W >= 2p.  By Step 6 its last term has coefficient <= D + 1, so r := A_W - 2p lies in [0, D], and W is proper
(A_W < 2p + D + 1 <= 4p).  r != 0, since Q' is minimal.  Q_1 := g^r (r <= D < m) has coefficient sum r = A_W mod 2p, so
(MC) gives |W| <= r, i.e. mass(W) = A_W - |W| >= 2p.  Let W^- be W without its last term, s := 2p - A_(W^-), so
1 <= s <= D + 1 <= m.  Q_1 := Q - g^s has coefficient sum 2p - s = A_(W^-), and (MC) gives |Q_1| <= |W^-| + D, i.e.
u - s <= |W^-| + D, i.e. |W^-| >= l - s.  Hence mass(W^-) = (2p - s) - |W^-| <= 2p - l, and mass(W) <= 2p - l + D (the
last term adds at most D).  So 2p <= 2p - l + D, i.e. l <= D, i.e. u <= 2D <= 4delta - 4, i.e. p <= 3delta - 4,
contrary to p >= 3delta - 1.  []

Step 8 (the coefficient b_min is not a sum of >= 2 terms of Q').  No sub-multiset W of Q' with |W| >= 2 has
A_W = b_min.  Indeed Q_1 := {b_min} has coefficient sum b_min, and (MC) gives |W| <= 1.  Consequences:
- (8a) t' < b_min (else W = g^(b_min) is such a sub-multiset, b_min >= 3).
- (8b) No nonempty sub-multiset Z of Y has A_Z in [b_min - t', b_min - 1] (else W = Z g^(b_min - A_Z), which uses
  between 1 and t' copies of g, is such a sub-multiset).
- (8c) Let Y_low be the terms of Y with coefficient <= t'.  Then A_(Y_low) <= b_min - t' - 1: otherwise, adding the
  terms of Y_low in any order, the first partial sum >= b_min - t' (>= 1 by (8a)) is at most (b_min - t' - 1) + t' and
  so lies in [b_min - t', b_min - 1], contradicting (8b).  As every coefficient of Y is >= 3,
  |Y_low| <= (b_min - t' - 1)/3.

Step 9 (counting).  By Step 7, A_Y = 2p - t' and |Y| = l - t'.  Put base := (3l - 2p)/2 (an integer, l even).  Then
    X := sum over Y of (c - 3)/2 = (A_Y - 3|Y|)/2 = t' - base.
Since D <= 2delta - 2 and l = u - D, base = (p + 3delta - 3D)/2 >= (p - 3delta + 6)/2 >= 5/2, so base >= 3.  Each term of
Y with coefficient >= t' + 1 contributes (c - 3)/2 >= (t' - 2)/2 to X, and every term contributes >= 0; two such terms
would give X >= t' - 2 > t' - base.  So at most one term of Y has coefficient > t', and
    l - t' = |Y| <= |Y_low| + 1 <= (b_min - t' - 1)/3 + 1.
Hence 3l <= b_min + 2t' + 2 <= b_min + 2(b_min - 1) + 2 = 3 b_min (by (8a)), i.e. l <= b_min.  But l >= p - delta + 2 >
p - delta + 1 >= b_min (Steps 1 and 4).  Contradiction.  This proves the Lemma at kappa, and by induction for every
kappa <= floor(2p/3).  []
