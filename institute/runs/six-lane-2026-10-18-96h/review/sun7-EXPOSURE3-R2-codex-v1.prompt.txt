00018|## 1. Lemma LFC (left-fibre count) [NEW]
00019|
00020|Let G be finite, let g_1U_1, ..., g_kU_k (k <= 7) be pairwise disjoint left cosets, and fix a vertex v.
00021|For j != v put
00022|
00023|  lambda_j := [U_v : U_v cap U_j],   t_j := [U_j : U_j cap U_v].
00024|
00025|**(a)** lambda_j = I_vj / n_v = n_j alpha_vj / g_vj and t_j = I_vj / n_j = n_v alpha_vj / g_vj.
00026|
00027|**(b)** g_jU_j meets exactly t_j left cosets of U_v, and none of them is g_vU_v.
00028|
00029|**(c)** For a left coset C = xU_v != g_vU_v let S_C := { j != v : g_jU_j cap C != empty }. Then S_C is
00030|*lambda-allowed*: every T subset S_C with |T| >= 2 contains j != j' with gcd(lambda_j, lambda_j') >= |T|.
00031|
00032|**(d) (count)** For every y >= 0 on V \ {v} with sum_{j in T} y_j <= 1 for every lambda-allowed T,
00033|
00034|  sum_{j != v} y_j alpha_vj / g_vj  <=  1 - 1/n_v  <  1.
00035|
00036|*Proof.* (a) |U_v cap U_j| = |G|/I_vj gives both indices; I_vj = lcm(n_v,n_j) alpha_vj.
00037|(b) The left U_v-cosets meeting g_jU_j are g_j u U_v (u in U_j), and g_j u U_v = g_j u' U_v iff u^-1 u' in U_j cap U_v;
00038|so there are [U_j : U_j cap U_v] of them. If g_j u U_v = g_vU_v then g_j u in g_jU_j cap g_vU_v = empty, impossible.
00039|(c) Let j in S_C and pick y_j in g_jU_j cap C. Then g_jU_j = y_jU_j and C = y_jU_v, so g_jU_j cap C = y_j(U_j cap U_v).
00040|Fix x in C. Then x^-1 y_j in U_v, and x^-1 (g_jU_j cap C) = (x^-1 y_j)(U_j cap U_v) is a left coset, inside the finite
00041|group U_v, of the subgroup U_j cap U_v, whose index in U_v is lambda_j. For distinct j these cosets are pairwise
00042|disjoint (the g_jU_j are). By (b), v is not in S_C, so |S_C| <= k - 1 <= 6. Apply Sun(|T|) (imports, |T| <= 6) inside
00043|U_v to the sub-family indexed by T.
00044|(d) Summing the constraint over the n_v - 1 cosets C != g_vU_v and using (b):
00045|sum_j y_j t_j = sum_C sum_{j in S_C} y_j <= n_v - 1. Divide by n_v and use t_j / n_v = alpha_vj / g_vj. QED

00061|at v (after the normalisation g_v = 1) equals alpha*_vj. In particular q is symmetric (q at v towards j equals q at j
00062|towards v), and (V1) becomes

00064|  alpha_vj + alpha*_vj <= g_vj.

00077|## 3. Lemma ROW-U (LFC on an all-unmarked neighbourhood in K7) [NEW]
