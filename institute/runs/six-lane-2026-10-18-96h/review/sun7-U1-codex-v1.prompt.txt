## 1. Lemma LFC (left-fibre count) [NEW]

Let G be finite, let g_1U_1, ..., g_kU_k (k <= 7) be pairwise disjoint left cosets, and fix a vertex v.
For j != v put

  lambda_j := [U_v : U_v cap U_j],   t_j := [U_j : U_j cap U_v].

**(a)** lambda_j = I_vj / n_v = n_j alpha_vj / g_vj and t_j = I_vj / n_j = n_v alpha_vj / g_vj.

**(b)** g_jU_j meets exactly t_j left cosets of U_v, and none of them is g_vU_v.

**(c)** For a left coset C = xU_v != g_vU_v let S_C := { j != v : g_jU_j cap C != empty }. Then S_C is
*lambda-allowed*: every T subset S_C with |T| >= 2 contains j != j' with gcd(lambda_j, lambda_j') >= |T|.

**(d) (count)** For every y >= 0 on V \ {v} with sum_{j in T} y_j <= 1 for every lambda-allowed T,

  sum_{j != v} y_j alpha_vj / g_vj  <=  1 - 1/n_v  <  1.

*Proof.* (a) |U_v cap U_j| = |G|/I_vj gives both indices; I_vj = lcm(n_v,n_j) alpha_vj.
(b) The left U_v-cosets meeting g_jU_j are g_j u U_v (u in U_j), and g_j u U_v = g_j u' U_v iff u^-1 u' in U_j cap U_v;
so there are [U_j : U_j cap U_v] of them. If g_j u U_v = g_vU_v then g_j u in g_jU_j cap g_vU_v = empty, impossible.
(c) Let j in S_C and pick y_j in g_jU_j cap C. Then g_jU_j = y_jU_j and C = y_jU_v, so g_jU_j cap C = y_j(U_j cap U_v).
Fix x in C. Then x^-1 y_j in U_v, and x^-1 (g_jU_j cap C) = (x^-1 y_j)(U_j cap U_v) is a left coset, inside the finite
group U_v, of the subgroup U_j cap U_v, whose index in U_v is lambda_j. For distinct j these cosets are pairwise
disjoint (the g_jU_j are). By (b), v is not in S_C, so |S_C| <= k - 1 <= 6. Apply Sun(|T|) (imports, |T| <= 6) inside
U_v to the sub-family indexed by T.
(d) Summing the constraint over the n_v - 1 cosets C != g_vU_v and using (b):
sum_j y_j t_j = sum_C sum_{j in S_C} y_j <= n_v - 1. Divide by n_v and use t_j / n_v = alpha_vj / g_vj. QED

## 2. Lemma INV (inversion duality) [NEW]

Let (G; U_i; g_i) be finite with pairwise disjoint g_iU_i. Put U_i* := g_i U_i g_i^-1 and g_i* := g_i^-1.

**(a)** g_i* U_i* = (g_iU_i)^-1. Hence the g_i*U_i* are pairwise disjoint left cosets and [G : U_i*] = n_i:
the *inverted configuration* has the same indices, the same profiles and the same gcd matrix, so it lies in the same
class (K7, K6.2*, K6.3, K5.2*, K5.3, KII) with the same marking. Inverting twice returns (U_i; g_i).

**(b)** Let alpha* be the alpha-matrix of the inverted configuration. For every v != j, the VFC integer q_j of (V1)
at v (after the normalisation g_v = 1) equals alpha*_vj. In particular q is symmetric (q at v towards j equals q at j
towards v), and (V1) becomes

  alpha_vj + alpha*_vj <= g_vj.

*Proof.* (a) (g_iU_i)^-1 = U_i g_i^-1 = g_i^-1 (g_i U_i g_i^-1); inversion is a bijection of G; conjugate subgroups have
equal index. (b) alpha*_vj = [G : g_vU_vg_v^-1 cap g_jU_jg_j^-1] / lcm(n_v,n_j) = [G : U_v cap hU_jh^-1] / lcm(n_v,n_j)

## 3. Lemma ROW-U (LFC on an all-unmarked neighbourhood in K7) [NEW]

Let the configuration be in class K7 and let v be a vertex (marked or not) all six of whose neighbours are unmarked.
Then:
- (i) alpha_vj in {1, 2, 4} for every j;
- (ii) alpha_vj = 1 for at most one j;
- (iii) alpha_vj = 4 for at least three j.

*Proof.* For an unmarked neighbour j, lambda_j = n_j alpha_vj / 6 = w_j alpha_vj (Lemma LFC (a), g = 6). Since the w's
are pairwise coprime, coprime to 30 and hence to every alpha <= 5, gcd(lambda_j, lambda_j') = gcd(alpha_vj, alpha_vj').
Split the neighbours into R1 = {alpha = 1}, R24 = {alpha in {2,4}}, R3 = {alpha = 3}, R5 = {alpha = 5}, with sizes
k1, a + b (a twos, b fours), k3, k5. Cross-class gcds are 1, so every allowed set of size >= 2 lies inside one class,
and R1 elements lie only in singletons. Inside R3 allowed sets have size <= 3 (four pieces of pairwise gcd 3: Sun(4));
inside R5 size <= 5 (Sun(6)); inside R24 allowed sets are the singletons, all pairs, and the sets of size 3 or 4
containing at most one two (a triple with two twos has all gcds 2: Sun(3); five pieces have gcds <= 4: Sun(5)).
By LFC (d) every feasible y satisfies sum_j y_j alpha_vj <= 6 - 6/n_v < 6. We exhibit, for every row violating
(i), (ii) or (iii), a feasible y with sum_j y_j alpha_vj >= 6. Feasibility is checked class by class, since allowed sets
do not cross classes. Standard partial weights:
- on R1: y = 1 (value k1);
- on R3 (k3 >= 1): y = 1/min(3, k3) (value 3 if k3 <= 3, else k3);
- on R5 (k5 >= 1): y = 1/min(5, k5) (value 5 if k5 <= 5, else 6);
- on R24 with b <= 2: y = 1/2 on twos, 1/4 on fours. Feasible: pairs sum <= 1; the only allowed sets of size >= 3 are
  {two, four, four} (sum 1); no allowed 4-set exists when b <= 2. Value a + b;
- on R24 with b = 3: y = 0 on twos, 1/3 on fours (allowed sets hold at most three fours). Value 4;
- on R24 with b >= 4: y = 1/4 on every element (allowed sets have size <= 4). Value a/2 + b >= 4.
Every nonempty class therefore has value >= 1, and >= 3 for R3, >= 5 for R5, >= 4 for R24 when b >= 3.
- (i) If k5 >= 1: value >= 5 + 1 when some other class is nonempty, and 6 when k5 = 6. If k5 = 0 and k3 >= 1:
  k3 >= 6 gives 6; k3 in {4,5} gives k3 + (6 - k3) >= 6 because the 6 - k3 remaining elements contribute at least
  one each (R1 elements 1 each; R24 with b <= 2 contributes a + b, with b >= 3 at least 4); k3 <= 3 gives
  3 + (value of the >= 3 remaining elements) >= 3 + 3.
- (ii), (iii) with entries in {1,2,4}: if b <= 2 the value is k1 + a + b = 6; if b >= 3 and k1 >= 2 the value is
  >= k1 + 4 >= 6.
In every case sum y alpha >= 6, contradicting LFC. QED

## §1 Pairwise, triangle, star and count rules

**L0.3 [GEN].** μ(U_iU_j) = α_ij / g_ij and 1 ≤ α_ij ≤ g_ij − 1. Per gcd: g = 2 ⇒ α = 1; g = 3 ⇒ α ∈ {1,2}; g = 4 ⇒ α ∈ {1,2,3}; g = 5 ⇒ α ∈ {1,…,4}; g = 6 ⇒ α ∈ {1,…,5}.

**L1 (T) [GEN, general form].** For a triangle {a,b,c} let L = lcm(n_a,n_b,n_c) and T = [G:U_a∩U_b∩U_c]. Then L | T; put τ = T/L. For every labelling {x,y,z} = {a,b,c}:
- **(T1)** I_xy | Lτ, equivalently α_xy | ℓ_z·τ. *Proof:* I_xy = lcm(n_x,n_y)α_xy, and L = lcm(n_x,n_y)·ℓ_z because lcm(lcm(n_x,n_y), n_z) = lcm(n_x,n_y)·n_z/gcd(n_z, lcm(n_x,n_y)).
- **(T3)** μ(U_y(U_x∩U_z)) = τ / (γ_y·α_xz). *Proof:* by L0.1 it equals Lτ/(n_y I_xz) = Lτ/(n_y lcm(n_x,n_z) α_xz), and L/lcm(n_x,n_z) = ℓ_y = n_y/γ_y.
- **(T2)** μ(U_y(U_x∩U_z)) ≤ min(μ(U_yU_x), μ(U_yU_z)), since U_y(U_x∩U_z) ⊆ U_yU_x ∩ U_yU_z.

Hence τ is a multiple of τ_min := lcm over the three edges of α_xy / gcd(α_xy, ℓ_z), and τ ≤ τ_max := min over apexes y of ⌊γ_y·α_xz·min(α_xy/g_xy, α_yz/g_yz)⌋. **T-kill:** τ_min > τ_max. (Core specialisation: when all indices are d·r_i with r_i pairwise coprime, γ = d and ℓ_z = r_z, recovering the k5/k6 forms.)

**L2/L3 (K) [GEN].** If, for every pair {i,j} ⊆ S (S ⊆ V ∖ {v}), U_vU_i ⊆ U_jU_i or U_vU_j ⊆ U_iU_j, then Σ_{i∈S} α_iv/g_iv ≤ 1 − μ(U_v) < 1. (Proof: sun-coset5 rules-v1 L3; it uses only disjointness.)
- **K1 (links, general).** The pair condition at v for {i,j} holds when μ(U_i(U_v∩U_j)) = μ(U_iU_v), i.e. (T3) at apex i equals (T2)'s bound. Since τ ≥ τ_min, this is forced whenever τ_min·g_iv ≥ γ_i·α_vj·α_iv; then τ is pinned to that value.
- **K2.** U_vU_j ⊆ U_vU_k implies α_vj/g_vj + α_kj/g_kj < 1.

**L4 (P) [GEN].** At v put X_j = U_vU_j. Then μ(X_j) = α_vj/g_vj; μ(X_j∩X_k) is a multiple of u_vjk := 1/gcd(n_v, I_jk) (double cosets of (U_v, U_j∩U_k), L0.4/L0.5); μ(X_j∩X_k) ≥ max(τ_vjk/(γ_v α_jk), μ(X_j) + μ(X_k) − 1, 0); and the Bonferroni inequality Σ_S μ(Y_j) − Σ_{pairs ⊆ S} μ(Y_j∩Y_k) < 1 holds for Y_j = G ∖ X_j. Rounding exactly as in sun-coset6 `CERT-FORMAT-k6-v3.md` (lo = u⌈Lb/u⌉, hi = u⌊min/u⌋, minus u when K2 forbids the forced containment).

Each g_lU_l meets exactly t_l left H-cosets; in each H-coset the pieces are disjoint left cosets in H of subgroups of index λ_l; every subfamily T of the vertices meeting one H-coset has a pair with gcd(λ,λ′) ≥ |T| (Sun(|T|) in H; |T| = 7 only if H < G in the minimal frame). **L6 (XE, general) [NEW].** If U_vU_a = U_vU_b (v, a, b distinct), then W := ⟨U_a, U_b⟩ satisfies U_vW = U_vU_a; W ≠ G; m := [G:W] divides g_ab; α_ab/g_ab ≤ 1/m; and [U_v : U_v∩W] = m·α_va/g_va.

## §2 VFC: the vertex fibre count (Lemma R in general form)

**Lemma VFC [GEN for (V1)–(V4); NEW for the count].** Fix v and left-translate so that g_v = 1. For j ≠ v put D_j := U_v g_j U_j. Then:
- **(V1)** D_j ∩ U_vU_j = ∅, and |D_j| = q_j·|G|/g_vj for an integer q_j with 1 ≤ q_j ≤ g_vj − α_vj.
- **(V2)** d_j := |D_j|/|U_j| = q_j·n_j/g_vj is an integer, and every right coset R = U_vy ⊆ D_j meets g_jU_j in a right coset of a subgroup of U_v of index d_j.
- **(V3)** For a right coset R put S_R := {j : R ⊆ D_j}. Every T ⊆ S_R with |T| ≥ 2 contains a pair j ≠ j′ with gcd(d_j, d_j′) ≥ |T|. (|T| ≤ k − 1 = 6, so only imports are used.)
- **(V4)** Each D_j is left U_v-invariant, and ∪_j D_j ⊆ G ∖ U_v.

*Proofs.* (V1): U_v = g_vU_v is disjoint from g_jU_j, so g_j ∉ U_vU_j (L0.2); D_j and U_vU_j are distinct (U_v,U_j)-double cosets. |D_j| = |U_v||U_j|/|U_v ∩ g_jU_jg_j⁻¹| = |G|·[G : U_v ∩ g_jU_jg_j⁻¹]/(n_v n_j), and that index is a multiple of lcm(n_v, n_j), so |D_j| is a positive multiple of |G|/g_vj; D_j ⊆ G ∖ U_vU_j gives q_j ≤ g_vj − α_vj. (V2) and (V4): sun-coset5 proof-v4 §5 (R2, R3). (V3): sun-coset6 proof-k6-lemmas-v1 §1(b): the pieces in R are pairwise disjoint; right-translating by w⁻¹ (w ∈ R) and inverting turns them into pairwise disjoint left cosets in U_v of indices d_j; apply Sun(|T|) in U_v. ∎

**Corollary VFC-count [NEW].** Call T ⊆ V ∖ {v} *allowed* if |T| ≤ 1 or every T′ ⊆ T with |T′| ≥ 2 has a pair with gcd(d,d′) ≥ |T′|. If every allowed set has size ≤ s, then Σ_j q_j/g_vj < s. More generally, for any y ≥ 0 with Σ_{j∈T} y_j ≤ 1 on every allowed T, Σ_j y_j q_j/g_vj < 1.
*Proof.* Each S_R is allowed (V3). Σ_j |D_j| = Σ_R |S_R|·|R| and Σ_j y_j|D_j| = Σ_R |R|·Σ_{j∈S_R} y_j ≤ Σ_R |R| = |∪_j D_j| ≤ |G| − |U_v| (V4). ∎

**Valuations of local indices.** v_p(d_j) = v_p(q_j) + v_p(n_j) − v_p(g_vj). Common prime factors of d_j and d_j′ (j ≠ j′) lie in {2,3,5}: q ≤ 5, and the w-parts are pairwise coprime (README P0(b)).

- v_p(gcd(n_v, I_jk)) = min(v_p(n_v), max(v_p(n_j), v_p(n_k)) + v_p(α_jk)): if v_p(n_v) is the unique large valuation, the other argument is ≤ 2 + 2 (p = 2) or ≤ 1 + 1 (p = 3, 5), within the cap; if v_p(n_j) is the large one, v_p(n_v) is small and is the min either way.
- VFC: v_p(gcd(d_j,d_j′)) = min(v_p(q_j) + v_p(n_j) − v_p(g_vj), v_p(q_j′) + v_p(n_j′) − v_p(g_vj′)). ## A1. Lemma RPLP-k7 [NEW; general-index form of sun-coset6 rules-k6-v3 L12]

This is the rule applied as "RPLP" to the 27 X1 leaf orbits (Stage A) and the 528 KII leaf orbits (Stage B). It is implemented in `core7_engine_v1.py` and `core7_engine_v2.py` (`p_bounds`, `forced`, `rplp_vertex`) and is formatted in CERT-FORMAT-k7-v1 §3. The correspondence between this text and the code is for the independent replay to check; it is not established here.

### Setting

As in rules-k7-v1 §0:
- G is finite, with U_i ≤ G and n_i = [G:U_i] for i ∈ V;
- the cosets g_iU_i are pairwise disjoint.

Fix v ∈ V and left-multiply every coset by g_v⁻¹. This keeps the cosets disjoint and changes no index or intersection index, so we may take g_v = 1. Put N = V ∖ {v}, and for j ∈ N:

  X_j := U_vU_j,  Y_j := G ∖ X_j,  D_j := U_v g_j U_j.

### Facts

**(F1)** μ(X_j) = α_vj/g_vj by L0.3. Hence μ(Y_j) = 1 − α_vj/g_vj; this value is what (E2) uses.

**(F2)** D_j ∩ X_j = ∅ and μ(D_j) = q_j/g_vj, for an integer q_j with 1 ≤ q_j ≤ g_vj − α_vj. This is VFC (V1); (E1) uses this value.

**(F3)** X_j, Y_j and D_j are left U_v-invariant. U_vX_j = X_j and U_vD_j = D_j, and complements of left-invariant sets are left-invariant. So each of them is a union of right cosets R = U_vy, and every right coset R is either contained in X_j or contained in Y_j, and either contained in D_j or disjoint from it.

**(F4) Types.** For a right coset R put A_R = {j ∈ N : R ⊆ Y_j} and S_R = {j ∈ N : R ⊆ D_j}.
- S_R ⊆ A_R, by (F2).
- S_R is *allowed* in the sense of Corollary VFC-count, with local indices d_j = q_j·n_j/g_vj. This is VFC (V3). The sets T in it have |T| ≤ |N| ≤ 6, so only Sun(t) for t ≤ 6 inside U_v is used, and these are imports.

**(F5)** A_R = ∅ exactly when R ⊆ ∩_j X_j. U_v is such a coset, since U_v ⊆ U_vU_j for every j. Hence μ(∪_j Y_j) ≤ 1 − μ(U_v) < 1.

**(F6) Pair bounds (L4, restated).** For j ≠ k in N, lo_jk ≤ μ(X_j∩X_k) ≤ hi_jk, where:
- u = 1/gcd(n_v, I_jk) and γ_v = lcm(g_vj, g_vk);
- Lb = max(τ_min(v,j,k)/(γ_v·α_jk), μX_j + μX_k − 1, 0);
- lo = u⌈Lb/u⌉;
- hi = u⌊min(μX_j, μX_k)/u⌋, reduced by u when hi = min(μX_j, μX_k) and the containment that equality needs is barred by K2. That containment is X_j ⊆ X_k if μX_j < μX_k, X_k ⊆ X_j if μX_k < μX_j, and both if the two are equal. K2: X_j ⊆ X_k ⇒ α_vj/g_vj + α_kj/g_kj < 1.

*Proof.*
1. **Grid.** X_j∩X_k is left U_v-invariant and right (U_j∩U_k)-invariant. So it is a union of (U_v, U_j∩U_k)-double cosets U_vz(U_j∩U_k), each of measure [G : U_v ∩ z(U_j∩U_k)z⁻¹]/(n_v·I_jk). That index is a common multiple of n_v and I_jk, so every double coset has measure in (1/gcd(n_v, I_jk))·ℤ = uℤ, and so does μ(X_j∩X_k).
2. **Lower bounds.** U_v(U_j∩U_k) ⊆ X_j∩X_k has measure τ_vjk/(γ_v·α_jk) by (T3) at apex v. This is ≥ τ_min/(γ_v·α_jk) because τ_vjk is a multiple of τ_min (L1). Inclusion–exclusion gives μ(X_j∩X_k) ≥ μX_j + μX_k − 1. Then round up to the grid uℤ.
3. **Upper bound.** μ(X_j∩X_k) ≤ min(μX_j, μX_k), with equality iff the needed containment holds (for finite sets, equal measure plus inclusion gives equality). If K2 bars that containment, the inequality is strict, so on the grid it is at most hi − u whenever hi equals the minimum. ∎

**(F7) Forced containments [NEW in this form].** Let a ≠ b in N and γ_v = lcm(g_va, g_vb). If

  τ_min(v,a,b)·g_va ≥ γ_v·α_ab·α_va,

then X_a ⊆ X_b, equivalently Y_b ⊆ Y_a.

*Proof.* Let τ = τ_vab be the true value, so that [G : U_v∩U_a∩U_b] = lcm(n_v,n_a,n_b)·τ.
1. (T3) at apex v (L1 with y = v and {x,z} = {a,b}) gives μ(U_v(U_a∩U_b)) = τ/(γ_v·α_ab).
2. (T2) at apex v: U_v(U_a∩U_b) ⊆ U_vU_a = X_a, so μ(U_v(U_a∩U_b)) ≤ α_va/g_va.
3. τ is a positive multiple of τ_min (L1), so by the hypothesis μ(U_v(U_a∩U_b)) ≥ τ_min/(γ_v·α_ab) ≥ α_va/g_va.
4. Steps 2 and 3 give equality of measures. The sets are finite with U_v(U_a∩U_b) ⊆ X_a, so U_v(U_a∩U_b) = X_a. (This also pins τ = γ_v·α_ab·α_va/g_va.)
5. Also U_v(U_a∩U_b) ⊆ U_vU_b = X_b. Hence X_a ⊆ X_b. ∎

*Consequence.* If (a, b) is forced and R ⊆ Y_b, then R ⊆ Y_a. So b ∈ A_R implies a ∈ A_R.

is unmarked iff m_i = 1. Hypothesis **U1**: exactly one vertex z is marked, with **m_z = 2^E 3^A 5^B, E, A, B >= 0
not all 0 (actual, unbounded exponents)**; W := V \ {z} (six unmarked vertices, n_u = 6 w_u). In K7 every g_ij = 6,
so every alpha_ij and alpha*_ij lies in {1,...,5} (E1) and alpha + alpha* <= 6 (INV (b), E7).

At an apex v the LFC label of a neighbour j is lambda_j = n_j alpha_vj / 6 = m_j w_j alpha_vj (LFC (a)); LFC (d) says
that every y >= 0 that sums to <= 1 on every lambda-allowed set satisfies sum_j y_j alpha_vj <= 6 (1 - 1/n_v) < 6.
"Allowed" is hereditary (every subset of an allowed set is allowed), and every pair inside an allowed set has
gcd >= 2.

**Gcd facts (G).** w_u is coprime to w_j (j != u) and to 30, and every alpha <= 5 has prime factors in {2,3,5}. Hence:
(G1) for unmarked j, j' != v: gcd(lambda_j, lambda_j') = gcd(alpha_vj, alpha_vj');
(G2) for v in W and u in W \ {v}: gcd(lambda_z, lambda_u) = gcd(m_z alpha_vz, alpha_vu), which **divides alpha_vu**;
(G3) at the apex z every neighbour is unmarked, so (G1) holds for all six neighbours of z.
m_z enters this file only through (G2) and through ell_z in section 3; no step depends on the size of E, A or B.

## 1. Lemma ROW-1* (LFC at an unmarked apex whose only marked neighbour z has an arbitrary marker product) [NEW]

Let v in W, and let k5, k3 be the numbers of u in W \ {v} with alpha_vu = 5, resp. 3. Then
- **(a)** k5 in {0, 5};
- **(b)** if k3 >= 1 then k3 >= 3, no alpha_vu (u in W \ {v}) equals 4 or 5, and alpha_vz in {1, 2}.

*Proof.* Split W \ {v} into R1, R24, R3, R5 by the value of alpha_vu (sizes k1, a + b with a twos and b fours, k3, k5).
By (G1) cross-class gcds are 1, so an allowed subset of W \ {v} of size >= 2 lies inside one class; ROW-U's class
analysis (accepted) gives the standard partial weights (R1: 1; R3: 1/min(3,k3); R5: 1/min(5,k5); R24: 1/2 on twos and
1/4 on fours if b <= 2, 0 on twos and 1/3 on fours if b = 3, 1/4 on all if b >= 4), each class-feasible, each nonempty
class contributing >= 1 to sum y alpha, R3 contributing 3 if 1 <= k3 <= 3 and k3 if k3 >= 3, R5 contributing 5 if
1 <= k5 <= 5, and N elements of R1 cup R24 contributing >= min(N, 4) (E8).

*Weights with y_z = 0 are feasible.* If y_z = 0 and y restricted to W \ {v} sums to <= 1 on every allowed subset of
W \ {v}, then for an allowed T, T \ {z} is allowed (hereditary) and sum_T y = sum_(T \ z) y <= 1. This does not
look at lambda_z, so it holds for every m_z.

(a) Suppose 1 <= k5 <= 4: y = 1/k5 on R5 (value 5), standard weights on the other 5 - k5 >= 1 elements (value >= 1),
y_z = 0. Total >= 6, contradicting LFC (d).

(b) Let k3 >= 1. Then k5 <= 4, so k5 = 0 by (a).
- k3 in {1, 2}: R3 contributes 3 (y = 1/k3); the >= 3 remaining elements lie in R1 cup R24 and contribute >= 3
  (E8); y_z = 0. Total >= 6. So k3 >= 3.
- Some alpha_vu = 4 with k3 = 3: the two remaining elements are {4, x}, x in {1, 2, 4}; standard weights give 4 + 1
  (x = 1), (4 + 2)/2 = 3 (x = 2), (4 + 4)/2 = 4 (x = 4); R3 contributes 3; y_z = 0. Total >= 6.
  With k3 = 4 the remaining element is the 4 (y = 1, contribution 4) and R3 (y = 1/3) contributes 4: total 8.
  With k3 = 5 there is no remaining element. So no entry 4 occurs (and no 5, as k5 = 0); the elements of W \ {v}
  outside R3 are ones and twos, at most two of them.
- Suppose alpha_vz in {3, 4, 5}. Weights: y = 1/3 on R3, y = 1 on R1, y = 1/2 on the twos, y_z = 1/3. Feasibility
  for an allowed T: if z not in T, T lies in one class: inside R3 |T| <= 3 (four pieces of pairwise gcd 3 are not
  allowed), R1 elements are singletons, at most two twos (three twos have pairwise gcd 2 < 3); sum <= 1. If z in T:
  by (G2) gcd(lambda_z, lambda_u) = 1 for u in R1, so T contains no R1 element; T \ {z} lies in one class; if it
  contains a two u, any further element u' is a two and {z, u, u'} has all gcds dividing 2 (G2), not allowed; so
  T = {z, u}, sum 1/3 + 1/2. If T \ {z} lies in R3, then |T \ {z}| <= 2, since {z, u1, u2, u3} has all gcds
  dividing 3 (G2) and is not allowed; sum <= 1/3 + 2/3 = 1. So y is feasible. Every element of W \ {v} contributes
  exactly 1 (1/3 * 3, 1 * 1, 1/2 * 2), so sum y alpha = 5 + alpha_vz / 3 >= 6, contradicting LFC (d).
  Hence alpha_vz in {1, 2}. QED

*Remark (scope).* ROW-1 (c) of K7-M1 is NOT claimed here for even m_z: with 2 | m_z and alpha_vu = 2, the pair
{z, u} is compatible even when alpha_vz is odd, so ROW-U-deg fails. Only (a) and (b) are used below.

## 2. Steps 0-2: the rows of z and the W-pairs

**Step 0 (rows of z).** All six neighbours of z are unmarked, so Lemma ROW-U (whose statement allows a marked apex)
gives: alpha_zj in {1, 2, 4} for all j in W, at most one j with alpha_zj = 1, at least three with alpha_zj = 4. By INV
(a) and E6 the inverted configuration satisfies U1 with the same z and the same m_z, so ROW-U applies to alpha* at z
as well. Put F := {u in W : alpha_zu = 4}, F* := {u in W : alpha*_zu = 4}. By alpha + alpha* <= 6 they are disjoint;
both have size >= 3; so **|F| = |F*| = 3 and W = F disjoint-union F***. For a in F* put s_a := alpha_za; s_a != 4
(else alpha + alpha* = 8), so s_a in {1, 2}, and s_a = 1 for at most one a (call it a0 if it exists). For b in F
put s*_b := alpha*_zb in {1, 2}, = 1 for at most one b (b0).

**Step 1 (no 5 on a W-pair, both orientations).** Suppose alpha_vu = 5 for some v != u in W. ROW-1* (a) at v gives
alpha_vu' = 5 for all u' in W \ {v}; then every u' in W \ {v} has an entry 5 (towards v), so by ROW-1* (a) at u'
its five W-entries are 5. Hence alpha = 5 on all 15 W-pairs and, by alpha + alpha* <= 6 and alpha* >= 1, alpha* = 1 on
all W-pairs. LFC (d) for the inverted configuration at any v in W: the labels lambda*_u = w_u (u in W \ {v}) are
coprime to each other and to lambda*_z = m_z w_z alpha*_vz, so every allowed set is a singleton (Sun(2) / the pair
condition), y = 1 everywhere is feasible, and sum y alpha* = 5 + alpha*_vz >= 6: contradiction. The same argument
for the inverted configuration (alpha** = alpha by INV (a)) shows that alpha* = 5 occurs on no W-pair either.

**Step 2 (no 3 on a W-pair, both orientations).** Let W3 := {v in W : alpha_vu = 3 for some u in W}. If v in W3 then
every u with alpha_vu = 3 is in W3, and by ROW-1* (b) v has at least three such u, so |W3| >= 4 if W3 is non-empty.
Also by ROW-1* (b), alpha_vz in {1, 2} for v in W3, so W3 is disjoint from F (where alpha_zv = 4): W3 is contained in F*,
of size 3. Hence W3 is empty. For the inverted configuration the same argument gives W3* contained in F (its "F" is
our F*) and therefore empty.

Consequently **alpha_uv and alpha*_uv lie in {1, 2, 4} for every pair u != v in W.**

## 3. Lemma CROSS* (triangle facts for a in F*, b in F) [NEW in this scope]

For a in F*, b in F put x := alpha_ab and x* := alpha*_ab (both in {1, 2, 4} by section 2). Then:
- **(C1)** x in {2, 4} and x* in {2, 4}, and not x = x* = 4;
- **(C2)** if s_a = 1 then x = 4; if s*_b = 1 then x* = 4;
- **(C3)** X_a subset X_b (X_v := U_zU_v after normalising g_z = 1) whenever x s_a <= 4; for the inverted
  configuration, X*_b subset X*_a whenever x* s*_b <= 4.

*Proof.* Triangle {z, a, b} (L1): every g = 6 and gamma = lcm(6, 6) = 6 at each apex; ell_z = n_z / 6 = m_z w_z,
ell_a = w_a, ell_b = w_b. tau_min is the lcm of alpha_za / gcd(alpha_za, ell_b) = s_a, alpha_zb / gcd(4, w_a) = 4 and
x / gcd(x, m_z w_z), which divides x and hence divides 4 for x in {1, 2, 4}. So **tau_min = lcm(s_a, 4, .) = 4**
(s_a in {1, 2}), whatever E, A, B are. tau_max = min over apexes of gamma * (opposite alpha) * min(adjacent alphas) / 6:
apex z: x * min(s_a, 4) = x s_a; apex a: 4 * min(s_a, x); apex b: s_a * min(4, x).

| s_a | x = 1 | x = 2 | x = 4 |
|---|---|---|---|
| 1 | tau_max = 1 < 4: killed | tau_max = 2 < 4: killed | tau_max = 4: survives |
| 2 | tau_max = 2 < 4: killed | tau_max = 4: survives | tau_max = 8: survives |

Hence x in {2, 4}, and x = 4 when s_a = 1. The inverted configuration has the same indices (INV (a)), hence the same
ell's; its triangle {z, a, b} has alpha*_za = 4, alpha*_zb = s*_b, alpha*_ab = x*, i.e. the same table with the roles
of a and b exchanged (tau_min = lcm(4, s*_b, x*/gcd(x*, m_z w_z)) = 4; tau_max = min(x* s*_b, 4 min(s*_b, x*),
s*_b min(4, x*))). Hence x* in {2, 4} and x* = 4 when s*_b = 1. x = x* = 4 contradicts alpha + alpha* <= 6. This
gives (C1), (C2). (C3): (F7) at apex z with g_za = 6 = gamma_z reads tau_min * 6 >= 6 * x * s_a, i.e. x s_a <= 4, and
then X_a subset X_b; (F7) for the inverted configuration at apex z with the pair (b, a) reads 4 >= x* s*_b. QED

## 4. Lemma LIGHT* (VFC at z) [NEW in this scope]

Normalise g_z = 1 (left multiplication by g_z^-1 changes no index, alpha or alpha*). For v in W put X_v = U_zU_v,
Y_v = G \ X_v, D_v = U_z g_v U_v. By (V1) and INV (b): D_v cap X_v = empty, mu(D_v) = alpha*_zv / 6,
mu(X_v) = alpha_zv / 6; if zv is **tight** (alpha_zv + alpha*_zv = 6) then D_v subset Y_v have equal finite size, so
D_v = Y_v. X_v, Y_v, D_v and their intersections are left U_z-invariant, hence unions of right cosets R = U_z y. By
(V3) with q = alpha* (INV (b)), for every right coset R the set S_R = {v : R subset D_v} is allowed for the local
indices d_v = q_v n_v / 6 = alpha*_zv w_v, and gcd(d_v, d_v') = gcd(alpha*_zv, alpha*_zv') (G-type argument; the w's
are coprime to each other and to 30). Since alpha*_zv in {1, 2, 4} (Step 0):
- **(L1)** for a in F* and b != b' in F, no allowed set contains {a, b, b'}: d_a = 4 w_a, d_b = s*_b w_b,
  d_b' = s*_b' w_b' have pairwise gcds <= 2 < 3 (Sun(3));
- **(L2)** if alpha*_zv = 1 then d_v = w_v is coprime to every other local index, so S_R containing v is {v} (Sun(2));
- **(L3)** by (V4) the union of all D_v avoids U_z and has measure <= 1 - 1/n_z < 1.
The inverted configuration (normalised g*_z = 1, X*_v = U*_zU*_v, D*_v = U*_z g*_v U*_v, q* = alpha** = alpha) satisfies
the same with alpha and alpha*, F and F* exchanged: mu(D*_v) = alpha_zv / 6, local indices alpha_zv w_v, (L1*) for
b in F and a != a' in F*, no allowed set contains {b, a, a'}, (L2*) alpha_zv = 1 forces singletons, (L3*).

## 5. Theorem K7-U1 [NEW]

**No K7 configuration (in any group with finite-index subgroups, by R0) has exactly one marked vertex.**

*Proof.* Assume U1. Sections 2-4 apply. Four exhaustive types by the existence of a0 (s_a0 = 1) and b0 (s*_b0 = 1):

- **T4 (a0 and b0 exist).** (C2) gives alpha_a0b0 = 4 and alpha*_a0b0 = 4; contradiction with (C1).
- **T3 (b0 exists, s_a = 2 for all a in F*).** Take any a in F*. (C2) gives alpha*_ab0 = 4, so by (C1) alpha_ab0 = 2;
  x s_a = 4, so (C3) gives X_a subset X_b0, i.e. Y_b0 subset Y_a. The edge za is tight (2 + 4), so Y_a = D_a, and
  D_b0 subset Y_b0 subset D_a. D_b0 has measure 1/6 > 0 and is a union of right cosets; any right coset R inside it has
  {a, b0} subset S_R, contradicting (L2) (alpha*_zb0 = 1).
- **T2 (a0 exists, s*_b = 2 for all b in F).** Take any b in F. (C2) gives alpha_a0b = 4, so alpha*_a0b = 2 by (C1);
  x* s*_b = 4, so (C3) for the inverted configuration gives X*_b subset X*_a0, i.e. Y*_a0 subset Y*_b; zb is tight
  (4 + 2), so in the inverted configuration D*_b = Y*_b and D*_a0 subset Y*_a0 subset D*_b. D*_a0 has measure
  alpha_za0 / 6 = 1/6 > 0; a right coset of U*_z inside it has {a0, b} in its S-set, contradicting (L2*).
- **T1 (no a0, no b0).** All six edges at z are tight. Call b in F *in* if alpha_ab = 2 for some a in F*. Then (C3)
  (2 * 2 <= 4) gives X_a subset X_b, so D_b = Y_b subset Y_a = D_a; if D_b met D_b' (b' in F \ {b}) the
  intersection would contain a right coset R subset D_a with {a, b, b'} subset S_R, contradicting (L1). So D_b is
  disjoint from every other D_b'. If at most one b in F were not in, every pair from F would contain an in vertex and
  the three D_b (b in F), each of measure s*_b / 6 = 1/3, would be pairwise disjoint, giving measure 1 for their union,
  contrary to (L3). Hence at least two b in F are *out*: alpha_ab != 2, so alpha_ab = 4 by (C1), for every a in F*.
  The same argument in the inverted configuration (with (C3)*, (L1*), (L3*); its tight edges are the same) gives at
  least two a in F* with alpha*_ab = 4 for every b in F. For such a and such b, alpha_ab = alpha*_ab = 4, contradicting
  (C1).

Every type is impossible. QED

## 6. Scope, exponents and what remains

- **Covered:** every K7 configuration with |M| = 1, any marker product m_z = 2^E 3^A 5^B (unbounded exponents). The
  part not covered by accepted results is E >= 1 and A >= 1 on the unique marked vertex (5-marker absent or on z).
  With accepted K7-M0, K7-M1, K7-Z2, K7-35: **K7 is open only when the 2-marker and the 3-marker sit on two
  different vertices** (5-marker absent, on one of them, or on a third vertex), if this candidate is accepted.
- **Exponent audit.** E, A, B enter only through (G2) (which only uses that gcd(lambda_z, lambda_u) divides alpha_vu)
  and through x / gcd(x, ell_z) dividing x in CROSS*; LFC labels and VFC local indices at z do not involve n_z. No
  step needs E, A, B bounded, and no capping is used.
- **Where the old hypotheses were replaced.** (i) ROW-1 (a), (b) of K7-M1 are re-proved for arbitrary m_z: their
  certificates use y_z = 0 except the final alpha_vz kill, whose sets through z are bounded using only (G2).
  (ii) K7-Z2's CROSS used "no 3-marker" only to kill x = 3 (and h_z = 0 to kill x = 5) by tau_min; here x, x* in
  {3, 5} are excluded globally on W-pairs (section 2) before CROSS*, so tau_min = 4 for every m_z.
- **Verification boundary:** written, single author, unreviewed; parent re-derivation and hostile reviews requested
  (in particular: ROW-1* (b) last case with even m_z; Step 1 inversion; the CROSS* table; T1-T4). No computation.
  No novelty, Lean or human-review claim.
