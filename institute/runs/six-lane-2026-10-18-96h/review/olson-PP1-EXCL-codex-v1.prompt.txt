68: ## 4. Lemma OM (pattern omission) and its full-coverage corollary
69: 
70: Let a in Z_p, z a pattern with Phi = 2m, m >= 1, Pi_+ / Pi_- the runs with z = +1 / -1, alpha_+ the number of letters of value a in
71: Pi_+, and K := p-3+2m. Assume alpha_+ >= K. Call FREE every rotation letter except the a-letters of Pi_+; give a free letter u in run
72: r the weight omega(u) := z_r u - a; let N_z be the multiset of weights and D := sum over all rotation letters of z_r u.
73: LEMMA OM. If D - aK - T(z) lies in Sigma_(<=K)(N_z), then w^ has an identity 2p-subword.
74: Proof. Take free letters C with |C| <= K and sum_(u in C) omega(u) = D - aK - T(z), and K - |C| <= K <= alpha_+ further a-letters of
75: Pi_+ (these are not free, so disjoint from C). Omit these K letters and select the other 3p-3-K = 2p-2m rotation letters together
76: with the 2m sign-change reflections. The selected signed sum is

78: so GRX (Sec. 2) gives an identity 2p-subword. []

84: ## 5. Lemma ER (empty runs, type H1)

101: ## 6. Proof of the theorem
102: 
103: Type H1, a = 0. By pigeonhole two of the p+1 blocks have equal values y_j = y_(j'), j != j'. For z = -1 on the runs j+1, ..., j',
104: Phi = 2, T(z) = y_(j') - y_j = 0, and 2p-2 letters of value 0 (v_0 = 2p-1) have signed sum 0: an identity 2p-subword. Impossible.
105: Type H1, a != 0.

110:   alpha_1 >= p+1 (two such runs would need 2p+2 letters a), and every other run has alpha_i <= p-2.
111: - Hence every nonempty run other than R_1 contains a letter of B (a run with a-letters contains >= alpha_i >= 1 letters -a, which lie
112:   in B since -a != a). So at most 1 + (p-2) = p-1 of the p+1 runs are nonempty: at least two runs are empty, against Lemma ER.
113: Type H2a (X = a^(2p-2) b^(p-1)). Suppose b != -a. Take any two blocks j != j' and orient the arc pattern so that Pi_+ holds at least
114: p-1 letters a (possible as the two sides hold 2p-2 in total); alpha_+ >= p-1 = K (m = 1). The free letters include all p-1 letters b,
115: with weights b - a or -b - a, both nonzero (b != a, b != -a). Corollary OM' gives a contradiction. Hence b = -a, and b != a gives
116: a != 0: X = a^(2p-2) (-a)^(p-1).
117: Type H2c (X = a^(2p-3) b^(p-1) c, c = 2a - b). For m = 1, K = p-1. Weights: b-letters b - a or -b - a; the letter c: c - a or -c - a;
118: a-letters in Pi_-: -2a. A weight -u - a vanishes iff u = -a; the others vanish only for a = 0 (the -2a weights).

120:   hold 2p-3 letters a), has at least p nonzero weights (the b-letters and c). Corollary OM': contradiction.
121: - If b = -a (so a != 0 and c = 3a): the p-1 letters b lie in at most p-1 of the p+1 runs, so at least two runs contain no b; they
122:   cannot both hold >= p-1 letters a (2p-2 > 2p-3), so some run R contains no b and alpha(R) <= p-2. With z = -1 on R:
123:   alpha_+ >= p-1 = K and every b- and c-weight is nonzero (no b in Pi_-; -c - a = -4a, c - a = 2a are nonzero): at least p nonzero
