96: Lemma M. A finite multiset S of size N with maximal multiplicity mu contains q pairwise disjoint pairs of elements with
97: different values whenever 2q <= N and q <= N - mu.
98: Proof. Cap every multiplicity at q. The capped total is >= 2q: if mu <= q it is N >= 2q; if mu > q, the top value keeps q and
99: the other values keep a capped total >= min(q, N-mu) = q (it is >= q if one of them has >= q copies, and equals their total
100: N-mu >= q otherwise). Choose a sub-multiset S' of exactly 2q elements within the
101: caps, list S' with equal values consecutive as x_1, ..., x_(2q), and pair x_i with x_(i+q) (1 <= i <= q). If x_i = x_(i+q),
102: that value fills the q+1 consecutive positions i, ..., i+q, against its cap q. []
