37: ## Theorem
38: 
39: Let G be any group. Let a_1G_1, …, a_5G_5 be pairwise disjoint left cosets of subgroups of finite index. Then gcd([G:G_i], [G:G_j]) ≥ 5 for some i < j.
40: 
41: ## 1. R0: reduction to finite groups
42: 
43: core_G(G_i) is the kernel of the action of G on G/G_i, so its index is at most [G:G_i]!. Hence N = ∩_i core_G(G_i) is a normal subgroup of finite index contained in every G_i.
44: 
45: Each coset a_iG_i is the full preimage of its image in G/N. So indices, intersection indices and disjointness all pass to the finite group G/N.
46: 
47: ## 2. R1: reduction to Core(5), and a proof of M-S Prop 4.5
48: 
49: **Core(5).** No finite group G has subgroups U_1, …, U_5 with [G:U_i] = 4r_i, the r_i pairwise coprime, and pairwise disjoint cosets g_iU_i.
50: 
51: **The Sun(5) ⇒ Core(5) direction.** A Core(5) configuration has every pairwise gcd equal to 4 < 5.
52: 
53: **The Core(5) ⇒ Sun(5) direction, group by group.** Let n_i = [G:G_i], and assume five disjoint cosets in G have all pairwise gcds ≤ 4.
54: 
55: 1. **Each gcd is 2, 3 or 4.** By L0.2 and L0.6 no gcd equals 1, so each lies in {2, 3, 4}.
56: 2. **All divisible by 3, or all even.** If some n_i is odd, every gcd with it is odd and so equals 3. Then 3 divides all five indices.
57: 3. **All divisible by 3.** Every gcd is then 3 < 4. Any four of the cosets contradict Zhu Theorem 1.1 at k = 4.
58: 4. **All even.** Write n_i = 2^{e_i}m_i with m_i odd. Then the m_i are pairwise coprime, every e_i ≥ 1, and at most one e_i ≥ 3.
59:    - **Two indices with e = 1.** With any third index they have all pairwise gcds equal to 2 < 3, contradicting Zhu Theorem 1.1 at k = 3.
60:    - **Exactly one index with e = 1.** We get (2r_1, 4r_2, 4r_3, 4r_4) with r_1 odd and the r's pairwise coprime. This is excluded by Proposition 4.5 below.
61:    - **Otherwise.** n_i = 4r_i with r_i = 2^{e_i−2}m_i pairwise coprime: a Core(5) configuration in the same group G, with the same subgroups.

18: ## 1. Lemma LFC (left-fibre count) [NEW]
19: 
20: Let G be finite, let g_1U_1, ..., g_kU_k (k <= 7) be pairwise disjoint left cosets, and fix a vertex v.
21: For j != v put
22: 
23:   lambda_j := [U_v : U_v cap U_j],   t_j := [U_j : U_j cap U_v].
24: 
25: **(a)** lambda_j = I_vj / n_v = n_j alpha_vj / g_vj and t_j = I_vj / n_j = n_v alpha_vj / g_vj.
26: 
27: **(b)** g_jU_j meets exactly t_j left cosets of U_v, and none of them is g_vU_v.
28: 
29: **(c)** For a left coset C = xU_v != g_vU_v let S_C := { j != v : g_jU_j cap C != empty }. Then S_C is
30: *lambda-allowed*: every T subset S_C with |T| >= 2 contains j != j' with gcd(lambda_j, lambda_j') >= |T|.
31: 
32: **(d) (count)** For every y >= 0 on V \ {v} with sum_{j in T} y_j <= 1 for every lambda-allowed T,
33: 
34:   sum_{j != v} y_j alpha_vj / g_vj  <=  1 - 1/n_v  <  1.
35: 
36: *Proof.* (a) |U_v cap U_j| = |G|/I_vj gives both indices; I_vj = lcm(n_v,n_j) alpha_vj.
37: (b) The left U_v-cosets meeting g_jU_j are g_j u U_v (u in U_j), and g_j u U_v = g_j u' U_v iff u^-1 u' in U_j cap U_v;
38: so there are [U_j : U_j cap U_v] of them. If g_j u U_v = g_vU_v then g_j u in g_jU_j cap g_vU_v = empty, impossible.
39: (c) Let j in S_C and pick y_j in g_jU_j cap C. Then g_jU_j = y_jU_j and C = y_jU_v, so g_jU_j cap C = y_j(U_j cap U_v).
40: Fix x in C. Then x^-1 y_j in U_v, and x^-1 (g_jU_j cap C) = (x^-1 y_j)(U_j cap U_v) is a left coset, inside the finite
41: group U_v, of the subgroup U_j cap U_v, whose index in U_v is lambda_j. For distinct j these cosets are pairwise
42: disjoint (the g_jU_j are). By (b), v is not in S_C, so |S_C| <= k - 1 <= 6. Apply Sun(|T|) (imports, |T| <= 6) inside
43: U_v to the sub-family indexed by T.
44: (d) Summing the constraint over the n_v - 1 cosets C != g_vU_v and using (b):
45: sum_j y_j t_j = sum_C sum_{j in S_C} y_j <= n_v - 1. Divide by n_v and use t_j / n_v = alpha_vj / g_vj. QED

52: ## 2. Lemma INV (inversion duality) [NEW]
53: 
54: Let (G; U_i; g_i) be finite with pairwise disjoint g_iU_i. Put U_i* := g_i U_i g_i^-1 and g_i* := g_i^-1.
55: 
56: **(a)** g_i* U_i* = (g_iU_i)^-1. Hence the g_i*U_i* are pairwise disjoint left cosets and [G : U_i*] = n_i:
57: the *inverted configuration* has the same indices, the same profiles and the same gcd matrix, so it lies in the same
58: class (K7, K6.2*, K6.3, K5.2*, K5.3, KII) with the same marking. Inverting twice returns (U_i; g_i).

60: **(b)** Let alpha* be the alpha-matrix of the inverted configuration. For every v != j, the VFC integer q_j of (V1)
61: at v (after the normalisation g_v = 1) equals alpha*_vj. In particular q is symmetric (q at v towards j equals q at j
62: towards v), and (V1) becomes

65: 
66: *Proof.* (a) (g_iU_i)^-1 = U_i g_i^-1 = g_i^-1 (g_i U_i g_i^-1); inversion is a bijection of G; conjugate subgroups have
