00002|
00003|Status: written proof (lane MathOlson, 2026-10-16), mechanism checked by brute
00004|force (`code/verify_marked.py`, `code/verify_theoremP.py`); NOT yet independently

00008|## Setting and conventions
00009|
00010|p is an odd prime. D_{2p} = {(v, e) : v in Z_p, e in {+1,-1}} with
00011|(v, e)(v', e') = (v + e v', e e')  (rotations (x,+1), reflections (y,-1)).
00012|For a word w = w_1 ... w_N and indices i_1 < ... < i_k the ordered product is
00013|w_{i_1} w_{i_2} ... w_{i_k}.  An identity k-subword is such an index set with
00014|product (0, +1).  Cyclic rotation of w preserves the existence of identity
00015|k-subwords (a product U V becomes V U = U^{-1} (U V) U).
00016|
00017|Let w contain F >= 1 reflections.  Rotate w cyclically so that it ENDS with a
00018|reflection:
00019|    w = X_1 f_1 X_2 f_2 ... X_F f_F,
00020|where f_t = (y_t, -1) are the reflections and X_t (t = 1..F) is the block of
00021|rotations strictly between f_{t-1} and f_t (X_1 = rotations before f_1); n_t =
00022||X_t|.  ("Gap t" = X_t; cyclically these are exactly the gaps between
00023|consecutive reflections.)

00025|## Theorem P
00026|
00027|If N = |w| <= 4p - 1 and  F + sum_{t=1}^{F} floor(n_t / 2) >= 3p - 1,  then w
00028|has an identity 2p-subword.

00030|## Proof
00031|
00032|**Step 1 (parametrisation).** In each gap X_t list the rotations in index order
00033|and group them into floor(n_t/2) consecutive PAIRS pi = (i, i'); if n_t is odd
00034|the last rotation of X_t is a SINGLETON.  Introduce Boolean parameters
00035|  u_2, ..., u_F  (gap colours; set u_1 := 0 and u_{F+1} := u_1 = 0),
00036|  m_pi  for each pair pi  (pair marks).
00037|Number of parameters:  M = (F - 1) + sum_t floor(n_t/2) >= 3p - 2.
00038|
00039|To a parameter point (u, m) assign the selection S(u, m):
00040|* reflection f_t is selected iff u_t != u_{t+1}  (t = 1..F);
00041|* both rotations of pair pi in gap t are selected iff m_pi XOR u_t = 1,
00042|  otherwise neither;
00043|* singletons are never selected.
00044|
00045|**Step 2 (injectivity; the empty selection).** The selection determines the
00046|parameters: going left to right, u_1 = 0 and u_{t+1} = u_t XOR [f_t selected]
00047|determine all u_t; then m_pi = [pi selected] XOR u_t.  Hence the map
00048|(u, m) -> S(u, m) is injective, and S(u, m) is EMPTY iff (u, m) = 0: an empty
00049|selection selects no reflection, so all u_t = u_1 = 0, and no pair, so all
00050|m_pi = u_t = 0.
00051|
00052|**Step 3 (size).** |S(u,m)| = #{t : u_t != u_{t+1}} + 2 #{pi : m_pi XOR u_{t(pi)} = 1}.
00053|The first term is the number of colour changes around the cycle 1..F, 1, hence
00054|even.  So |S| is always EVEN, and |S| <= N <= 4p - 1.
00055|
00056|**Step 4 (signs and the product).** Let S = S(u,m).  For an element of S lying
00057|in gap t or equal to f_t, the number of selected reflections strictly before
00058|it is #{s < t : u_s != u_{s+1}}, which has the parity of [u_t != u_1] = u_t.
00059|So in the ordered product every selected rotation x in gap t is multiplied by
00060|c_t := (-1)^{u_t}, and a selected reflection f_t contributes c_t y_t to the
00061|rotation coordinate.  The number of selected reflections is even (Step 3), so
00062|the product is (V, +1) with
00063|  V = sum_{t : u_t != u_{t+1}} c_t y_t + sum_{pairs pi selected} c_{t(pi)} x_pi,
00064|where x_pi = x_i + x_i'.  Using (c_t - c_{t+1})/2 = u_{t+1} - u_t (which is
00065|0 when u_t = u_{t+1} and c_t when they differ) and summation by parts with
00066|u_1 = u_{F+1} = 0,
00067|  sum_{t=1}^{F} (u_{t+1} - u_t) y_t = sum_{t=2}^{F} u_t (y_{t-1} - y_t).
00068|For pairs: a selected pair (m XOR u_t = 1) contributes c_t x_pi; one checks
00069|c_t x_pi [m XOR u_t] = x_pi m - x_pi u_t for both u_t = 0, 1.  Therefore, in Z_p,
00070|  V(u, m) = sum_{t=2}^{F} beta_t u_t + sum_pi x_pi m_pi,
00071|  beta_t = y_{t-1} - y_t - sum_{pi in gap t} x_pi.
00072|V is a polynomial of degree 1 in the parameters (over F_p), and S(u,m) is an
00073|identity subword iff V(u, m) = 0 in Z_p.
00074|
00075|**Step 5 (Chevalley–Warning on the Boolean box).** Write the size as the
00076|integer polynomial
00077|  Z(u, m) = sum_{t=1}^{F} (u_t + u_{t+1} - 2 u_t u_{t+1}) + 2 sum_pi (m_pi + u_{t(pi)} - 2 m_pi u_{t(pi)}),
00078|which agrees with |S(u, m)| on {0,1}^M and has degree 2.  Over F_p put
00079|  Q = (1 - V^{p-1}) (1 - Z^{p-1}),   deg Q <= 3(p - 1) < M.
00080|On {0,1}^M, Q(x) = 1 if V(x) = 0 and Z(x) = 0 in F_p, and Q(x) = 0 otherwise
00081|(Fermat).  Box lemma: for any polynomial Q over F_p of degree < M,
00082|  sum_{x in {0,1}^M} (-1)^{|x|} Q(x) = 0.
00083|(Proof: suffices for monomials; a monomial of degree < M omits some variable
00084|x_j, and the involution flipping coordinate j pairs points with opposite signs
00085|and equal values.)  Hence
00086|  sum_{x : V(x) = 0, Z(x) = 0 mod p} (-1)^{|x|} = 0 in F_p.
00087|The point x = 0 contributes +1, so there is a parameter point x != 0 with
00088|V(x) = 0 and |S(x)| = Z(x) = 0 mod p.
00089|
00090|**Step 6 (conclusion).** By Step 2, S(x) is nonempty; by Step 3 its size is
00091|even and at most 4p - 1; being divisible by p (odd), the size is a positive
00092|even multiple of p below 4p, i.e. exactly 2p.  By Step 4 its ordered product is
00093|the identity.  QED.
