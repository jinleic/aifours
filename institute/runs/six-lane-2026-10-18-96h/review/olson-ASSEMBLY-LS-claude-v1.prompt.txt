101: ## 3. Proof of Proposition ROT-LS
102: 
103: Let p >= 7 be prime, w an avoider of length 4p-2, w^ an admissible normal form of w with terminal 1 <= k <= p-1, and Y the
104: rotation sequence of w^ (equal, as a multiset, to that of w; row NF).
105: 
106: Step 1 (k = 1). w^ is an avoider of length 4p-2 consisting of one constant block (any representation; lowodd M1), so by
107: Proposition K1 its rotation letters are rho_c^(2p-1) with c != 0. They are the rotation letters of w.
108: 
109: Step 2 (k >= 2; parameters). Use 1.4. GRX on w^ with the all-plus pattern z: Phi = 0, every f_i = 0, every l_i odd, so
110: delta = k, C_max = F - k = 2H^, and T(z) = sum theta_i = 0. Hence w^ has an identity 2p-subword as soon as, for some even C with
111: 0 <= C <= 2H^ and 0 <= 2p - C <= R, some 2p - C rotation values sum to 0 (mod p).
112: (i) If H^ >= p, C = 2p and the empty rotation selection qualify; so avoidance gives H^ <= p-1, i.e. kappa^ >= 0.
113: (ii) For even m = 2p - C in [2kappa^+2, 2p] (automatically C in [0, 2H^]) and m <= R, no m rotation values sum to 0 (mod p);
114: lengths m > R are vacuous. By 1.2 this is exactly (ZP_kappa^) for Y.

116: 3p-1+kappa^-k, this is kappa^ <= k-1. With k <= p-1: kappa^ is an integer and 0 <= kappa^ <= k-1 <= p-2.
117: 
118: Step 3 ((S1) at kappa^ for k <= p-1). |Y| = R = 2p+2kappa^-k >= p+2kappa^+1 because k <= p-1. Y consists of odd elements of
119: C_(2p) (1.2), satisfies (ZP_kappa^) (Step 2), p >= 7 >= 5 is prime and kappa^ is an integer in [0, p-2]. These are exactly the
120: hypotheses of LS(p, kappa^) in its original definition (EV/LS-scope-v1.md:10-12), which Corollary LS-ALL proves on that whole

122: floor(2p/3)+1 <= kappa^ <= p-2: G-LS (p >= 7), Lev-free when kappa^ = p-2 (e = 2) and conditional on Lev 2022 Theorem 2 when

126: nonzero pair for the rotations of w. (Step 3 is not needed here; K01 obtains (S1) at kappa^ in {0,1} from S1+.)

155: ## 5. Proof of Theorem ASSEMBLY-LS (B)
156: 
157: Let p >= 7 and w a word of length 4p-1 over D_(2p) with o_F(w) <= p-1. Suppose w has no identity 2p-subword in increasing
158: index order; then every subword avoids. Apply the accepted ordered deletion ledger with B := p-1. Its class hypothesis,
159: "every avoider of length 4p-2 with o_F <= B is RGR", is (A) (INV* is RGR: rotations in one nonzero pair, constant maximal
160: cyclic reflection runs). Its only global requirement B <= 2p-3 holds (p >= 2).
161: - Case 1 (R <= 2). F >= 4p-3 and F - o_F(w) >= 4p-3-(p-1) = 3p-2 >= 2p. If R = 0 and all reflections are equal, any 2p of them
162:   multiply to 1. Otherwise read w in the cyclic frame starting at a rotation (R >= 1) or at a change of reflection value
163:   (R = 0); no block wraps, the blocks contain (F - o_F(w))/2 >= p disjoint adjacent equal pairs, p of them form an identity
164:   2p-subword of the framed word, and conjugating back gives one of w (RUNS verdict m6). Contradiction.
165: - Case 2 (some odd block has length >= 3). Deleting one of its letters gives an avoider w' of length 4p-2 with
166:   o_F(w') = o_F(w) - 1 <= p-2 (that block becomes even and stays nonempty; nothing else changes). By (A), w' is RGR; w has the
167:   same rotation letters and its reflection runs differ from those of w' by one more copy of a letter inside a constant block,
168:   so w is RGR.
169: - Case 3 (R >= 3). Delete two different rotation letters x1, x2: each w_i := w - x_i is an avoider of length 4p-2 with
170:   o_F(w_i) <= o_F(w) <= p-1 (if the run of x_i becomes empty, the two neighbouring blocks keep their identity or fuse, and
171:   odd+odd -> even, odd+even -> odd, even+even -> even never raises the odd count). By (A) both are RGR, with pairs
172:   {±c1}, {±c2}. A third rotation x3 lies in both; its value t != 0 forces {±c1} = {±t} = {±c2} (p5-lift overlay 4); every
173:   rotation of w lies in w_1 or w_2, hence in that pair. Deleting a rotation only creates new adjacencies between reflections,
174:   so two adjacent reflections of different values in w would stay adjacent in w_1; hence every maximal cyclic reflection run
175:   of w is constant, and w is RGR.
176: In Cases 2 and 3, w lies in RGR_(4p-1)(p), and RGR-LONG(p) (p >= 5) gives w an identity 2p-subword in increasing original
177: index order: contradiction. []
178: 
179: Preservation check. In (B), (A) is applied only to w' (o_F = o_F(w) - 1) and to w_1, w_2 (o_F <= o_F(w)); none exceeds p-1.
180: The normal form of Sec. 1.3 is applied only inside (A), to each of these length-(4p-2) avoiders separately. No deletion from
181: an even block occurs. Because the class has no F condition, the ledger's F - o_F bookkeeping (needed by earlier uniform
182: corollaries) plays no role.
