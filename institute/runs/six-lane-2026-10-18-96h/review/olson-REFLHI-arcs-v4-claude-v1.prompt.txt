## 3. Arc systems and Lemma ARC

Arc: nonempty set X of consecutive blocks S_j, ..., S_(j+l) whose internal runs R_(j+1), ..., R_(j+l) are all EMPTY;
nu(X) := number of distinct values y in X (>= 2 if X has an internal run).  Arc system: 2m >= 2 pairwise disjoint arcs
X_1, Y_1, ..., X_m, Y_m in cyclic order; the gap after an arc (runs and blocks up to the next arc) contains the run right
after the arc; gaps after X_i are IN, after Y_i OUT; E_in := sum of d_t over IN-gap runs; E+ := E_in + B.
**Lemma 3.1.**  For a_i in X_i, b_i in Y_i, P := union over i of the runs R_(a_i + 1), ..., R_(b_i) is proper with exactly m
intervals, E+(P) = E+ (independent of the choice), and u_P = (1/2) sum_i (y_(a_i) - y_(b_i)).
Proof.  Each interval consists of internal (empty) runs of X_i after a_i, the IN-gap runs and internal runs of Y_i up to
b_i; OUT-gaps contain a run, so the intervals are separated and P != [k]; empty runs have d = 0; theta telescopes.  []
**Lemma ARC.**  If G := gamma_m(E+), G' := gamma_m(R - E+) satisfy G + G' >= 0 and
sum over the 2m arcs of (nu - 1) + G + G' >= p - 1, then w has an identity 2p-subword.
Proof.  All patterns of Lemma 3.1 share the window [-G', G]; their u_P form the sumset of the 2m sets (1/2)V(X_i),
-(1/2)V(Y_i), which by (CD) has >= min(p, 1 + sum(nu - 1)) residues; the window has min(p, G + G' + 1).  The counts add up to
>= p + 1, so they meet; Lemma W.  []

## 4. Reflection-run labellings

Let w avoid (setting (S)).  Let N_1, ..., N_q (q >= 1) be the nonempty runs in cyclic order and M_i the maximal reflection run
between N_i and N_(i+1) (for q = 1, the single reflection run); M_i is an arc with e_i internal (empty) runs and
b_i = e_i + 1 blocks; sum_i e_i = k - q.  An **arc choice** puts c_i pairwise disjoint arcs inside M_i, sum c_i = 2m even.
It induces z in {+1, -1}^q (up to a global sign) by z_(i+1) = -z_i iff c_i is odd; T := sum_j z_j d_(N_j) (d of the run N_j).
**Lemma 4.1 (labels).**  For an arc choice, with IN = the label +1 of z or of -z, E+ = (R + T)/2 or (R - T)/2.
Proof.  The run N_j lies in a gap (arcs contain only empty runs); passing from N_i to N_(i+1) crosses the c_i arcs of M_i, so
the gap label changes iff c_i is odd.  IN runs contribute a_j to E+, OUT runs b_j; so E+ - E- = sum_j z_j d_j = T.  []
**Lemma 4.2 (kill by a balanced arc choice).**  If an arc choice has m >= 1, the two values E+- = (R +- T)/2 satisfy
ceil(E_min/2) >= kappa + 1 - m and floor(E_max/2) <= p - m, and its arcs have sum(nu - 1) >= p - ceil(R/2), then w (assumed to
avoid) has an identity 2p-subword, a contradiction.
Proof.  By Fact 2.1, G + G' = floor(E+/2) + floor(E-/2) >= ceil(R/2) - 1 >= 0 (equality cases: R odd; R even with both
E+- odd); Lemma ARC.  []
**Lemma BAL (balancing).**  Let d := max_j |d_(N_j)|.  For every arc choice with sum c_i even and every index i there is an
index i' such that, after changing the parities of c_i and c_(i') (no change if |T| <= d already), |T| <= d.
Proof.  If |T| <= d there is nothing to do; else say T > d (T < -d is symmetric).  Let S(t) := sum_(j = i+1)^(i+t) z_j d_j for
t = 0, ..., q (indices mod q), S(0) = 0, S(q) = T, steps of absolute value <= d.  Let t be minimal with S(t) >= (T - d)/2; then
t >= 1, S(t) < (T - d)/2 + d = (T + d)/2, and t <= q - 1 (S(q) = T > (T + d)/2).  Changing the parities of c_i and c_(i+t)
flips z exactly on N_(i+1), ..., N_(i+t), so T becomes T - 2 S(t), of absolute value <= d.  []
A parity change of c_j is realised by: deleting a singleton arc of M_j if there is one; else adding a singleton arc on an
unused block of M_j if there is one; else splitting one 2-block arc of M_j into two singletons.  This changes 2m by +-1 and
the number of 2-block arcs by at most 1.

## 5. A uniform exclusion for k >= 2p + 3 (new)

**Theorem K2P.**  Let p >= 5 be prime and w a word of length 4p - 2 over D_(2p) whose rotation letters lie in one pair
{rho_x, rho_-x}, x != 0, all of whose maximal constant reflection blocks have odd length.  If
   k >= 2p + 3   and   k >= 3 kappa + 3,
where k is the number of these blocks and kappa = p - 1 - H, then w has an identity 2p-subword (in increasing index order).
No hypothesis on B, on run purity, on the reflection values or on o_F (here o_F = k) is made.
Proof.  If F = 0 there is nothing... (F = 0 means k = 0, excluded by k >= 2p + 3).  If R = 0, (AR).  Normalise x = 1 and
A >= B (N keeps k, kappa); then w is in setting (S).  Suppose w avoids.  Put delta := R - p >= 0 (Fact 2.2) and
d := max_j |d_(N_j)| <= 2 delta + 1 (Fact 2.2).  From R = 2p - k + 2 kappa: k >= 3 kappa + 3 is H - delta >= 2, and
k >= 2p + 3 is 2 kappa >= R + 3.  Put
   m_lo := kappa + 1 - ceil((R - d)/4),   m_hi := p - floor((R + d)/4),   Pi* := p - ceil(R/2) + 2.
(a) m_hi - m_lo = H - (floor((R + d)/4) - ceil((R - d)/4)) >= H - floor(d/2) >= H - delta >= 2.
(b) m_lo >= 1: kappa >= (R + 3)/2 and ceil((R - d)/4) <= (R + 3)/4.
(c) Pairs.  Let a 2-block arc ("pair") be two consecutive blocks of one M_i (necessarily joined by an empty run; nu = 2).
    M_i contains floor(b_i/2) = floor((e_i + 1)/2) >= e_i/2 disjoint pairs, so at least (k - q)/2 >= (k - R)/2 in all
    (q <= R).  As R = k (mod 2), (k - R)/2 >= Pi* iff k >= 2p + 4 - [R odd], which follows from k >= 2p + 3.
(d) Initial choice.  Take Pi* disjoint pairs and N0 - Pi* singleton arcs on unused blocks, N0 := 2 m_lo + 2.  This needs
    Pi* <= N0 (true: N0 >= 2 kappa + 4 - (R - d + 3)/2 >= p - R/2 + 2 >= Pi* because 2 kappa >= R + 3 >= p + 3) and
    N0 + Pi* <= k (true: N0 + Pi* <= 2 kappa + 4 - (R - d)/2 + p - R/2 + 2 = k - p + 6 + d/2, and d <= 2 delta + 1 <=
    2H - 3 <= p - 8 as H <= (p - 5)/2 from 2 kappa >= R + 3 >= p + 3).
(e) Balance.  By Lemma BAL (any i) change at most two parities; afterwards |T| <= d, the arc count 2m lies in
    [N0 - 2, N0 + 2] = [2 m_lo, 2 m_lo + 4], within [2 m_lo, 2 m_hi] by (a), and at least Pi* - 2 = p - ceil(R/2) pairs remain.
(f) Kill.  With m_lo <= m <= m_hi and E_min >= (R - d)/2, E_max <= (R + d)/2: ceil(E_min/2) >= ceil((R - d)/4) >= kappa + 1 - m
    and floor(E_max/2) <= floor((R + d)/4) <= p - m.  sum(nu - 1) >= number of pairs >= p - ceil(R/2).  Lemma 4.2 gives a
    contradiction.  []
**Corollary K2P-num.**  For prime p >= 11 and (p + 3)/2 <= kappa <= p - 3, no word of RES_<(p) (indeed no all-odd word with
rotations in one pair) with k >= max(2p + 3, 3 kappa + 3) avoids.  Every avoider of RES_<(p) has k <= p + 2 kappa (Fact 2.2:
R >= p), so the excluded cells are kappa in [(p + 3)/2, p - 3], max(2p + 3, 3 kappa + 3) <= k <= p + 2 kappa, both B = 0 and

## 3. Arc systems (new)

An **arc** is a nonempty set X of cyclically consecutive blocks S_j, ..., S_(j+l), l >= 0, such that every run strictly
inside it (R_(j+1), ..., R_(j+l)) is EMPTY.  V(X) := {y_j, ..., y_(j+l)} and nu(X) := |V(X)|; an arc with an internal run
has nu >= 2 by genuineness.  An **arc system** is a family of 2m >= 2 pairwise disjoint arcs, listed in cyclic order
X_1, Y_1, ..., X_m, Y_m.  The **gap** after an arc is the set of runs and blocks strictly between its last block and the
first block of the next arc.  It contains the run immediately following the arc's last block, so every gap has a run.  Gaps
after X_i are IN-gaps, gaps after Y_i are OUT-gaps.  E_in := sum of d_t over the runs lying in IN-gaps.
**Lemma 3.1.**  For blocks a_i in X_i and b_i in Y_i, let J_i be the run interval R_(a_i + 1), ..., R_(b_i) and
P := J_1 u ... u J_m.  Then P is a proper nonempty pattern with exactly m maximal intervals, D_P = E_in, and
u_P = (1/2) sum_i (y_(a_i) - y_(b_i)).
Proof.  J_i consists of the internal runs of X_i after a_i, all runs of the IN-gap after X_i, and the internal runs of Y_i
up to b_i; it is a nonempty cyclic interval.  The runs of the OUT-gap after Y_i (at least one) lie in no J_j, so the J_i
are separated, m(P) = m and P != [k].  Internal runs of arcs are empty (d = 0), so D_P = E_in.  Telescoping,
sum over R_(a+1), ..., R_b of (y_(t-1) - y_t)/2 = (y_a - y_b)/2.  []
**Lemma ARC (Cauchy-Davenport arc kill).**  In setting (S) let an arc system with 2m arcs have E_in = E, and put
G := G_m(E), G' := G_m(D - E).  If  G + G' >= 0  and  sum over the 2m arcs of (nu - 1) + G + G' >= p - 1,  then w has an
identity 2p-subword.
Proof.  By Lemma 3.1 every choice (a_1, b_1, ..., a_m, b_m) in X_1 x Y_1 x ... x X_m x Y_m gives a pattern with the same m
and D_P = E, hence the same window I := [-G', G] (Lemma W), and u_P runs over the sumset
(1/2)V(X_1) + (-(1/2)V(Y_1)) + ... + (1/2)V(X_m) + (-(1/2)V(Y_m)) of 2m sets of sizes nu (2 is invertible).  By (CD) this
sumset has at least min(p, 1 + sum(nu - 1)) residues; I covers min(p, G + G' + 1) residues.  The hypothesis makes the two
counts add up to at least p + 1, so they meet, and Lemma W applies.  []
Remark.  Constant arcs (nu = 1) only change m and the gap labels.  The previous desk's lift/c-function machinery is not
used; Lemma ARC replaces a choice of one pattern by a Cauchy-Davenport count over a product family of patterns sharing one
window.

## 4. The cell R = p, every B

**Lemma 4.1 (structure).**  In setting (S) with R = p, if w avoids, then every nonempty run is a single letter (rho_1 or
rho_-1), exactly p runs are nonempty and 2 kappa are empty, k = p + 2 kappa, and w has exactly p maximal cyclic reflection
runs M_1, ..., M_p: if N_1, ..., N_p are the nonempty runs in cyclic order, M_i is the reflection run between N_i and
N_(i+1).  Each M_i is an arc; sum_i e_i = 2 kappa, where e_i is the number of (empty) runs inside M_i.
Proof.  k = 2p - R + 2 kappa = p + 2 kappa.  (P0) with e_F = 0 gives e_R <= 2 kappa, so o_R >= k - 2 kappa = p = R.  Each
odd run has at least one letter and the letters number R, so o_R = p, every odd run is a single letter and every even
run is empty.  So e_R = 2 kappa empty runs.  Between two consecutive nonempty runs the blocks are joined by empty runs, so
they form one maximal reflection run, which is an arc.  []
Put  m_0 := max(1, kappa + 1 - ceil((p - 1)/4)),  m_1 := p - floor((p + 1)/4).
**Fact 4.2.**  m_0 <= m_1, and for E in {(p - 1)/2, (p + 1)/2} and m_0 <= m <= m_1:  gamma_m(E) = floor(E/2), and
gamma_m((p - 1)/2) + gamma_m((p + 1)/2) = (p - 1)/2.
Proof.  ceil(((p - 1)/2)/2) = ceil((p - 1)/4) and floor(((p + 1)/2)/2) = floor((p + 1)/4); these are equal (q for
p = 4q + 1, q + 1 for p = 4q + 3), so m_0 <= m_1 reads kappa + 1 <= p, true, and 1 <= m_1.  For E in the two values,
ceil(E/2) >= ceil((p - 1)/4) >= kappa + 1 - m and floor(E/2) <= floor((p + 1)/4) <= p - m; Fact 2.1.  The sum:
q + q = 2q (p = 4q + 1) and q + (q + 1) = 2q + 1 (p = 4q + 3), i.e. (p - 1)/2.  []

**Theorem FP (R = p).**  Let w be in setting (S) with R = p, and suppose w avoids (so Lemma 4.1 applies; write sigma_j = +1
if N_j = rho_1 and -1 if N_j = rho_-1).  Choose pairwise disjoint arcs inside the reflection runs, c_i of them inside M_i,
with sum c_i = 2m and m_0 <= m <= m_1.  Define z in {+1, -1}^p by z_(i+1) = -z_i if c_i is odd and z_(i+1) = z_i if c_i is
even (consistent around the cycle because sum c_i is even; z is defined up to a global sign).  If
|sum_j sigma_j z_j| = 1, then the sum of (nu - 1) over the chosen arcs is at most (p - 3)/2.
Proof.  The chosen arcs, in cyclic order, form an arc system; the run N_j lies in a gap (it is not inside any arc, as arcs
contain only empty runs), and passing from N_i to N_(i+1) crosses exactly the c_i arcs in M_i, so the gap label (IN/OUT)
changes iff c_i is odd.  Hence the labels are z or -z (IN = +).  With the IN = + choice, E+(P) = A_P + B_(P^c) =
#{j : z_j = +1, sigma_j = +1} + #{j : z_j = -1, sigma_j = -1} = (p + sum_j sigma_j z_j)/2 (and the other choice gives
(p - sum_j sigma_j z_j)/2).  So {E+(P), E-(P)} = {(p - 1)/2, (p + 1)/2}, and by Fact 4.2 G + G' = (p - 1)/2 >= 0.
If the sum of (nu - 1) were >= (p - 1)/2, Lemma ARC would give an identity 2p-subword.  []
**Lemma 4.3 (a balanced one-defect labelling exists).**  For n in Z let z^(n) be the alternating labelling with its one
repeat across M_n: z^(n)_(n+1+t) = (-1)^t for t = 0, ..., p - 1 (indices of N mod p), and T(n) := sum_j sigma_j z^(n)_j.
Then |T(n)| = 1 for some n.  If B = 0, |T(n)| = 1 for every n.
Proof.  For s = 1, ..., p - 1: z^(n+1)_(n+1+s) = (-1)^(s-1) = -z^(n)_(n+1+s), and z^(n+1)_(n+1) = (-1)^(p-1) = +1 =
z^(n)_(n+1).  So T(n + 1) = -T(n) + 2 sigma_(n+1).  Put U(n) := (-1)^n T(n): U(n + 1) - U(n) = 2 (-1)^(n+1) sigma_(n+1) in
{2, -2}, and U(n + p) = -U(n) because T is p-periodic and p is odd.  T(n) is odd (a sum of p odd terms), so U moves by
steps of 2 through odd integers from U(n) to -U(n) and takes the value 1 or -1.  If B = 0, all sigma_j = +1 and
T(n) = (p + 1)/2 - (p - 1)/2 = 1.  []
The labelling z^(n) arises from Theorem FP exactly when c_i is odd for i != n and even for i = n.

## 0. Setting

D_(2p) = {(v,e)}, (v,e)(v',e') = (v + e v', e e'), rho_x = (x,+1), sigma_y = (y,-1).  A word is cyclic; an identity 2p-subword is
an increasing index set of size 2p with ordered product (0,+1); its existence is invariant under cyclic rotation
(proof-theoremP.md, Setting) and under the automorphisms rho_v -> rho_(cv), sigma_v -> sigma_(cv+d), c != 0.  An avoider has no
identity 2p-subword.

**G-words.**  A G-word is a word of length N with F >= 1 reflections, R >= 1 rotations, all rotations in {rho_1, rho_-1}
(normalised x = 1).  [r2 fix 3: R >= 1 for all maximal-decomposition statements below; a word with R = 0 is one cyclic
reflection run (for k = 1 its sole "run" is empty with theta_1 = 0), it is handled by Lemma AR, and Lemmas GR0, H0 remain valid for
every representation, R = 0 included.]  Cutting every maximal cyclic reflection run at every change of letter gives the maximal constant blocks
S_1, ..., S_k (S_i = sigma_(y_i)^(l_i), l_i >= 1) and the rotation runs R_1, ..., R_k, R_i between S_(i-1) and S_i (indices mod k,
y_0 := y_k); R_i has a_i letters rho_1 and b_i letters rho_-1, r_i = a_i + b_i >= 0, d_i = a_i - b_i, theta_i := y_(i-1) - y_i.
R_i is an EMPTY run if r_i = 0; then y_(i-1) != y_i by maximality, i.e. theta_i != 0 (a *genuine* empty run).  g := number of
empty runs.  w is RGR (in RGR_N(p) of proof-DR.md) iff g = 0.  More generally a *representation* is any cyclic alternation
R_1 S_1 ... R_k S_k of constant blocks and possibly empty runs reproducing w (adjacent blocks may then have equal values).
Parameters (of the maximal decomposition unless a representation is named): A = sum a_i, B = sum b_i, R = A + B, D = A - B,
F = sum l_i, H = sum floor(l_i/2), kappa := p - 1 - H, o_F = #{i : l_i odd}, e_F = k - o_F, o_R = #{i : r_i odd},
e_R = k - o_R (EMPTY RUNS COUNT AS EVEN ROTATION RUNS).  For N = 4p - 2:  F = 2H + o_F and R = 2p - o_F + 2 kappa.        (0.1)
Patterns: P subset of [k] (a set of rotation runs, empty runs included); m(P) = number of maximal cyclic intervals of P; the
boundary blocks of P are the S_j with exactly one of R_j, R_(j+1) in P (2m(P) of them); beta(P) = number of even boundary blocks;
D_P = sum_(i in P) d_i; R_P = sum_(i in P) r_i; u_P := 2^(-1) sum_(i in P) theta_i in Z_p (additive; u_([k]) = 0; for a cyclic
interval P = {i, ..., j}: u_P = (y_(i-1) - y_j)/2, so u_P != 0 iff its two boundary blocks have different values).
Normalisation N: rho_v -> rho_(-v), sigma_v -> sigma_(-v) maps G-words to G-words, keeps every block length and every empty run
(and its genuineness), swaps A and B; so WLOG A >= B.

## 1. Exact criteria (re-derived for representations with empty runs)

**Lemma GR0.**  For any representation (a_i, b_i, l_i, y_i) of any length, with f_i = [z_i != z_(i+1)], Phi = sum f_i,
delta = #{i : l_i != f_i mod 2}, C_max = F - delta, E+ = sum_(z_i = +1) a_i + sum_(z_i = -1) b_i, E- = R - E+, s0 = 2p - C_max,
s1 = 2p - Phi, Ach(z) = 2Z cap [max(-s1, s0 - 2E-, -E-), min(s1, 2E+ - s0, E+)] and tau(z) = -2^(-1) sum_i z_i (y_i - y_(i-1)):
w has an identity 2p-subword iff some z in {+1,-1}^k has Ach(z) cap (tau(z) + pZ) != empty.
Proof (the proof of Lemma GR, proof-GR.md Sec. 2, re-checked line by line; it never uses r_i >= 1).  Cut w at the start of R_1.
A selection with an even number of reflections has zone signs z_1 = +1, z_(i+1) = z_i (-1)^(c_i), c_i = number of letters chosen
from S_i (so c_i = f_i mod 2, z defined also at empty runs, and z_(k+1) = z_1).  Multiplying from the left, a chosen rotation
(x,+1) adds e x and a chosen reflection (y,-1) adds e y and flips e (e = current sign).  Inside S_i the chosen letters all equal
sigma_(y_i), so they add z_i y_i if c_i is odd and 0 if c_i is even; the product is rho_V with V = sum_i z_i n_i +
sum_(f_i = 1) z_i y_i (n_i = signed sum of chosen rotations of R_i, 0 for an empty run), and summation by parts gives
sum_(f_i=1) z_i y_i = sum_i z_i (y_i - y_(i-1))/2, so V = t - tau(z) with t = A+ - A- (numbers of chosen effectively positive /
negative rotations).  The realisable totals C = sum c_i are exactly the even numbers in [Phi, C_max] (each c_i independently runs
over f_i, f_i + 2, ..., l_i - [l_i != f_i mod 2] >= f_i), and for even t a pair (A+, A-) with A+ + A- = 2p - C, A+ <= E+,
A- <= E- exists for some admissible C iff t is in Ach(z) (the computation of proof-GR.md Sec. 2, unchanged).  Every admissible
data point is realised by a selection; global sign change z -> -z maps (Ach, tau) to (-Ach, -tau).  []
**Lemma H0 (half windows).**  For a representation and a proper pattern P put
  lambda(P) := min(p - m + 1, D_P + B - kappa + m - beta, floor((D_P + B)/2) + 1)   (m = m(P), beta = beta(P), kappa = p - 1 - H),
  I(P) := [1 - lambda(P^c), lambda(P) - 1]  (integers; possibly empty),
  I(empty) := [-min(p, A - kappa - 1, floor(A/2)), min(p, B - kappa - 1, floor(B/2))].
Then w avoids iff u_P notin I(P) (mod p) for every proper P and 0 notin I(empty) (mod p).
Proof.  Lemma GR0 with P = {z_i = +1}.  As sum theta_i = 0, tau(z_P) = 2^(-1) sum_i z_i theta_i = sum_(i in P) theta_i = 2 u_P,
and 2 is invertible, so the condition for z_P is u_P notin [ceil(lo/2), floor(hi/2)] (mod p).  For P proper with Phi = 2m and
beta even boundary blocks, delta = beta + (o_F - (2m - beta)), so c := C_max/2 = H + m - beta; E+ = A_P + B_(P^c) = D_P + B;
hence floor(hi/2) = min(p - m, E+ + c - p, floor(E+/2)) = lambda(P) - 1, and E+(P^c) = E-(P), same m, beta, gives
ceil(lo/2) = 1 - lambda(P^c).  P = empty (z = all -1): Phi = 0, c = H, E+ = B, E- = A gives I(empty); P = [k] gives -I(empty).
No step uses the length or r_i >= 1.  []
**Facts for G-avoiders of length 4p - 2** (F >= 1; if R = 0, Lemma AR of c2/invstar/proof-GR0-r1.md: 2p - 1 adjacent reflection

## 2. Moves

**Lemma SPEC (segment replacement).**  Spec(X) := {(|T|, ordered product of T) : T subset of the positions of the word X}.  If
w = U X V (after a cyclic rotation) and w' = U Y V with |Y| = |X| and Spec(Y) subset of Spec(X), then w avoids => w' avoids.
Proof.  An identity 2p-subword T' of w' splits as T_U, T_Y, T_V with ordered product prod(T_U) prod(T_Y) prod(T_V).  Choose
T_X in X with (|T_X|, prod T_X) = (|T_Y|, prod T_Y); T_U u T_X u T_V is an identity 2p-subword of w.  []
**Lemma FUS.**  For l >= 1, l' >= 2 even and any u, v: Spec(sigma_u^(l+l')) subset of Spec(sigma_u^l sigma_v^(l')), and
Spec(sigma_u^(l'+l)) subset of Spec(sigma_v^(l') sigma_u^l).  [r2 fix 1: r1 printed sigma_v^(l'+l) in the second inclusion, which is
false (l = 1, l' = 2, u != v: size 3 forces sigma_u, not sigma_v).]  In both forms the EVEN block sigma_v^(l') is recoloured with the
value u of its neighbour, on either side.
Proof (first form).  Spec(sigma_u^(l+l')) = {(c, sigma_u^c) : 0 <= c <= l + l'} (sigma_u^c = 1 for even c, sigma_u for odd c).
c <= l: c letters sigma_u.  c > l, c - l even: all l letters sigma_u and c - l letters sigma_v (even number): product sigma_u^l =
sigma_u^c.  c > l, c - l odd: then c - l <= l' - 1, take l - 1 letters sigma_u and c - l + 1 <= l' letters sigma_v.  Second form
[r2 fix 1]: the same counts, with the even number (c - l or c - l + 1) of letters sigma_v taken FIRST and then l or l - 1 letters
sigma_u; the product sigma_v^(even) sigma_u^(c') is sigma_u^(c') = sigma_u^c.  []
So, in a G-word (R >= 1; [r2 fix 3]), at a genuine empty run next to an EVEN block, recolouring the even block with the value of
the other block ("FUS step")
preserves avoidance, length, every rotation, B, A, R, F; it removes that empty run (and the empty run on the other side of the
even block if the new value equals the next block's value: a "double fusion").  H changes only in a double fusion of
sigma_u^a [] sigma_v^b [] sigma_u^c (b even) with a, c BOTH odd, where it rises by 1 (kappa falls by 1).
**Lemma SL (slide).**  For u != v and a, b >= 1, Spec(sigma_u^a sigma_v^b) depends only on floor(a/2) + floor(b/2), a mod 2, b mod 2.
Proof.  Its elements are (c1 + c2, sigma_u^(c1) sigma_v^(c2)), 0 <= c1 <= a, 0 <= c2 <= b; the product is 1, sigma_u, sigma_v,
rho_(u-v) for (c1, c2) = (even, even), (odd, even), (even, odd), (odd, odd) (four distinct elements), and for each parity type the
sizes form all numbers of that parity from the minimum to (max c1 of that parity) + (max c2 of that parity); with a = 2 alpha + eps,
b = 2 beta + eta these maxima are 2(alpha+beta), 2(alpha+beta) + 2 eps - 1, 2(alpha+beta) + 2 eta - 1, 2(alpha+beta) + 2 eps + 2 eta - 2.  []
Hence (a, b) -> (a - 2, b + 2) (a >= 3) is exact in both directions (Lemma SPEC twice) and keeps H, every parity, every value.
**Lemma TR (pair transfer).**  In a representation, moving one rho_1 and one rho_-1 from a run R_s (a_s, b_s >= 1) to another run
R_t (possibly empty) leaves E+(z), E-(z) unchanged for every z (the two letters are effectively of opposite signs in every zone),
and Phi, delta, F, tau are untouched; by Lemma GR0 the two words are avoiders or solvable together.  []
**Lemma PM0 (merge across an even block).**  Let k >= 2 [r2 fix 2; as in the accepted PM*] and S_j an even block of a
representation.  Merge R_j, R_(j+1) into one run
(a_j + a_(j+1), b_j + b_(j+1)) and append the l_j letters of S_j to S_(j+1) (value y_(j+1)).  If w avoids, so does the result w'.
Proof.  Patterns of w' are the patterns of w containing both or neither of j, j + 1; for them S_j is not a boundary block, m, D_P,
B and every boundary parity agree (l_(j+1) + l_j = l_(j+1) mod 2), H is unchanged (floor((l_(j+1) + l_j)/2) = floor(l_(j+1)/2) +
l_j/2), so lambda and I agree (Lemma H0); theta' of the merged run is theta_j + theta_(j+1), so u_P agrees; I(empty) agrees.  []
Used below only when R_j, R_(j+1) are both NONEMPTY: then w' has the same empty runs with the same neighbouring values, one even
block fewer, and all other block parities unchanged.

## 3. Lemma BC' (block chain with the genuineness boost)

For a proper pattern Q of an avoider put lambda'(Q) := lambda(Q) + [lambda(Q) = 0 and u_Q != 0 (mod p)].
**Lemma BC'.**  Let w be an avoider (any length; windows of Lemma H0).  Let (P_1, ..., P_s), s >= 2, be an ordered partition of
[k] into nonempty proper patterns, Q_t := P_1 u ... u P_t.  If
 (a) lambda'(P_1) + ... + lambda'(P_s) >= p + 1;
 (b) for 2 <= t <= s - 1, with X = Q_(t-1), Y = P_t, Z = Q_t^c:  lambda'(X u Y) + lambda'(Y u Z) + lambda'(Z u X) >= p + 1 and
     lambda'(X) + lambda'(Y) + lambda'(Z) >= 1;
 (c) lambda'(P_s) + lambda'(P_s^c) >= 1,
then w has an identity 2p-subword (contradiction).
Proof.  (*) For every proper Q, u_Q is congruent to no element of I'(Q) := [1 - lambda'(Q^c), lambda'(Q) - 1].  Indeed I'(Q) = I(Q)
if no boost occurs; if exactly one of lambda(Q), lambda(Q^c) is 0 and boosted, I'(Q) = I(Q) u {0} or is empty; if both are 0 and
boosted, I'(Q) = {0}; and u_Q avoids I(Q) (Lemma H0) and 0 (the boost condition; u_(Q^c) = -u_Q).  Hence |I'(Q)| <= p - 1,
i.e. lambda'(Q) + lambda'(Q^c) <= p.  From here the proof of Lemma BC (inverse-parity/proof-PAR-K0.md L67-87) is repeated
verbatim with lambda' in place of lambda; it uses only (*) and arithmetic:
Claim: if y = u_Q (mod p) and 1 - l' <= y <= p + l - 1 (l = lambda'(Q), l' = lambda'(Q^c)) then l <= y <= p - l' (the ranges
[1 - l', l - 1] and [p + 1 - l', p + l - 1] consist of integers congruent to elements of I'(Q); as l + l' <= p the three ranges
[1 - l', l - 1], [l, p - l'], [p + 1 - l', p + l - 1] tile [1 - l', p + l - 1]; if l + l' <= 1 the outer ones are empty and
[1 - l', p + l - 1] lies in [l, p - l']).  Choose v_t = u_(P_t) (mod p) in [lambda'(P_t), p - lambda'(P_t^c)] (by the claim if
l + l' >= 1, since [1 - l', p + l - 1] then has >= p integers; directly if l + l' <= 0).  V_t := v_1 + ... + v_t = u_(Q_t).
Induction: V_t in [lambda'(Q_t), p - lambda'(Q_t^c)] for t <= s - 1: V_t lies in [lambda'(X) + lambda'(Y),
2p - lambda'(Y u Z) - lambda'(Z u X)], which by (b) lies in [1 - lambda'(Z), p + lambda'(X u Y) - 1], and the claim for Q_t = X u Y
(complement Z) applies.  Finally V_s = 0 (mod p), V_s >= p + 1 by (a), V_s <= (p - lambda'(P_s)) + (p - lambda'(P_s^c)) <= 2p - 1
by (c).  []

**Lemma CH (conditions (b), (c) for a family of interval partitions, B = kappa = 0).**  Let w be an avoider of length 4p - 2 with
B = kappa = 0 and R >= p, and let P_1, ..., P_s (s >= 2) be consecutive cyclic intervals in cyclic order partitioning [k], such
that every part either has R_P >= 1 or is a single genuine empty run with beta <= 1, and at most one part has R_P = 0.  Then (b)
and (c) of Lemma BC' hold.
Proof.  For a cyclic interval Q (m = 1), B = kappa = 0 and R_Q <= R <= 2p - 1 give lambda(Q) = min(p, R_Q + 1 - beta,
floor(R_Q/2) + 1) = floor(R_Q/2) + 1 - def(Q), def(Q) := max(0, beta(Q) - ceil(R_Q/2)).  Every union U of parts that contains
>= 2 parts has R_U >= 1, so def(U) <= 1, and lambda'(U) >= lambda(U) >= 0; a single part has lambda' >= 0 too (R_P >= 1, or
R_P = 0 with beta <= 1: lambda = 1 - beta, boosted to 1 when it is 0 since the part is a genuine empty run).  (b) lower: X, Y, Z
are unions of parts with R_X + R_Y + R_Z = R >= 5, the largest has R_Q >= 2 and lambda >= 1.  (b) upper: the three unions
contain >= 2 parts each; their R-values sum to 2R, at most two are odd, so the floors sum to >= R - 1; two unions with def = 1
would both have R_U <= 2 and would cover the cycle (X u Y and Y u Z do), so R <= 4: impossible.  Hence the sum is
>= R - 1 + 3 - 1 >= p + 1.  (c): one of P_s, P_s^c has R_Q >= 3 (R >= 5), so def = 0 and lambda >= 2; the other has lambda' >= 0.  []

## 4. Theorem K0*

**Theorem K0*.**  Let p >= 5 be prime and w a word of length 4p - 2 over D_(2p) whose rotation letters all lie in one set
{rho_x, rho_-x}, x != 0.  If w is an avoider with kappa(w) = 0 (i.e. its maximal constant reflection blocks contain p - 1 disjoint
same-letter pairs), then every maximal cyclic reflection run of w is constant.  Equivalently REFL(p) holds for avoiders with
kappa = 0.  (Uses only Theorem P, Davenport-alpha, EGZ/Lemma AR and the elementary lemmas above; no RGR theorem is imported.)

Proof.  Normalise x = 1.  If F = 0 there is nothing to prove; if R = 0, Lemma AR.  So w is a G-word with F, R >= 1; suppose it has
g >= 1 genuine empty runs and avoids.  By (Z0) and kappa = 0: B = 0 (all rotations rho_1), R = 2p - o_F, 1 <= o_F.

Step 1 (FUS process).  While some genuine empty run is adjacent to an even block, apply a FUS step there.  Each step preserves
avoidance, the length, every rotation, and lowers g by >= 1.  It never performs an odd-odd double fusion: that would give an
avoider with kappa = -1, contradicting (Pairs).  So kappa stays 0 and B stays 0.  Let w_end be the final word.
Step 2 (w_end has no empty run).  Otherwise every empty run of w_end lies between two odd blocks, and no even block of w_end is
adjacent to an empty run.  Apply PM0 across every even block (both neighbouring runs are nonempty): each step preserves avoidance
and kappa = 0, keeps every empty run and the odd parity of its neighbours, and creates no even block next to an empty run.  The
resulting avoider has e_F = 0 and e_R >= g >= 1 > e_F + 2 kappa, contradicting (P0).
Step 3 (the last step).  Hence the process ends with an RGR word and its last step w' -> w_end removed every empty run of the
avoider w' (kappa(w') = 0, B = 0, g(w') >= 1).  A FUS step at an empty run R_t recolours an even neighbour, which then fuses with
the block on its other side only through a second empty run; so either
 (C1) g(w') = 1: one empty run R_t, and at least one of S_(t-1), S_t is even; or
 (C2) g(w') = 2: S_(t-1) = sigma_u^a, R_t empty, S_t = sigma_v^b with b even, R_(t+1) empty, S_(t+1) = sigma_u^c, u != v, and
      a, c not both odd (kappa = 0).
Step 4 (normalisation).  Apply PM0 across every even block of w' whose two neighbouring runs are nonempty.  This keeps
avoidance, kappa = 0, B = 0, the empty runs, their neighbouring blocks' values and parities.  Call the result w'' (still k, o_F,
e_F, e_R, R, r_i for its own decomposition).  Now every even block of w'' is adjacent to an empty run, so its even blocks lie in
{S_(t-1), S_t} (C1) or {S_(t-1), S_t, S_(t+1)} (C2).  By (P0) and (Par), e_R <= e_F and e_R = e_F (mod 2), and e_R >= g.  Also
o_F <= p: the k - g nonempty runs give k - g <= R = 2p - o_F, and k - g = o_F + e_F - g >= o_F as e_F >= e_R >= g; so R >= p >= 5.
Step 5 (cases and partitions).  For a cyclic interval Q, lambda(Q) = floor(R_Q/2) + 1 - def(Q) as in Lemma CH.  Single runs are
written {i}.
 C1a: exactly one of S_(t-1), S_t is even.  Then e_F = 1, e_R = 1: R_t is the only even run and every nonempty run is odd;
   k = o_F + 1.  Parts: all single runs in cyclic order.  {t}: beta = 1, R = 0, lambda = 0, u_t = theta_t/2 != 0, lambda' = 1.
   The other run next to the even block has beta = 1 and lambda = (r + 1)/2; every other run has beta = 0 and lambda = (r + 1)/2.
   Sum = 1 + (R + k - 1)/2 = 1 + (2p - o_F + o_F)/2 = p + 1.
 C1b: both S_(t-1), S_t even.  Then e_F = 2, e_R = 2: R_t and exactly one nonempty even run.  k = o_F + 2 >= 3, so S_(t-2) and
   S_(t+1) are odd.  Parts: {t, t+1} (boundaries S_(t-1) even, S_(t+1) odd; R = r_(t+1) >= 1) and all other single runs ({t-1} has
   beta = 1, R >= 1).  Every part has lambda = floor(R_P/2) + 1, and the sum is
   sum_(i != t) (floor(r_i/2) + 1) = (R + (k - 1) + 1)/2 = (2p - o_F + o_F + 2)/2 = p + 1.
 C2a: exactly one of a, c even, say a odd and c even (the case a even, c odd is the mirror image below).  Then e_F = 2 (S_t,
   S_(t+1)), e_R = 2 (the two empty runs), every nonempty run odd, k = o_F + 2 >= 3, S_(t+2) odd (it is S_(t-1) if k = 3).
   Parts: {t} (boundaries S_(t-1) odd, S_t even: beta = 1, lambda = 0, u_t = (u - v)/2 != 0, lambda' = 1), {t+1, t+2} (boundaries
   S_t even, S_(t+2) odd; R = r_(t+2) >= 1, lambda = (r_(t+2) + 1)/2), all other single runs (beta = 0).  Sum =
   1 + sum_(i notin {t, t+1}) (r_i + 1)/2 = 1 + (R + k - 2)/2 = p + 1.
   Mirror (a even, c odd): parts {t+1} (boundaries S_t even, S_(t+1) odd, u_(t+1) = (v - u)/2 != 0, lambda' = 1), {t-1, t}
   (boundaries S_(t-2) odd, S_t even; R = r_(t-1) >= 1), all other single runs; the same sum p + 1.
 C2b: a, c both even.  Then e_F = 3, e_R = 3 (the two empty runs and exactly one nonempty even run), k = o_F + 3 >= 4, so S_(t-2)
   and S_(t+2) are odd.  Parts: {t-1, t} (boundaries S_(t-2) odd, S_t even; R = r_(t-1) >= 1), {t+1, t+2} (boundaries S_t even,
   S_(t+2) odd; R = r_(t+2) >= 1), all other single runs (beta = 0).  Sum = sum over the nonempty runs of (floor(r_i/2) + 1) =
   (R + (k - 2) + 1)/2 = (2p - o_F + o_F + 2)/2 = p + 1.
In every case the parts are consecutive cyclic intervals in cyclic order, each has R_P >= 1 or is a single genuine empty run with

## 5. Theorem RED

Define RES_<(p): G-words of length 4p - 2 (rotations rho_1, rho_-1; normalised A >= B) with at least one (genuine) empty run,
every maximal constant block of ODD length, every rotation run pure (only rho_1 or only rho_-1) or empty, and B < kappa.
**Theorem RED.**  Assume (I1)-(I4).  If REFL(p) fails, some word of RES_<(p) with kappa >= 2 is an avoider.  Conversely every
avoider in RES_<(p) violates REFL(p).  Hence REFL(p) <=> RES_<(p) contains no avoider with kappa >= 2.
Proof.  Let w0 be an avoider violating REFL(p); normalise x = 1 and A >= B.  It is a G-word with g >= 1 (F >= 2, R >= 1 as before).
Run the following process; every move preserves avoidance, the length and rigidity of rotations; A >= B is kept (TR keeps A, B;
M0' lowers both by 1; the other moves keep them).  At every state with g >= 1, kappa >= 1 by Theorem K0*.  (A state with R = 0 would
be solvable by Lemma AR, so R >= 1 throughout and the maximal bookkeeping of proof-K0star-r2.md Sec. 0 applies.)
 P1 (FUS) at an empty run adjacent to an even block.
 P2 (PM0) across an even block whose two neighbouring runs are nonempty.
 P3 (TR-fill) if some run has a, b >= 1 and r >= 3: move one rho_1 rho_-1 pair from it into an empty run (it becomes a (1,1)-run;
    the donor stays nonempty).
 P4 (M0') if some run is a (1,1)-pair: delete its two letters (the run becomes empty) and insert sigma_y sigma_y into some block
    sigma_y^l.  Avoidance is preserved because, for the representation, every lambda(P) and I(empty) shrink (B and kappa drop by
    1, D_P, m, beta unchanged: the proof of Lemma M0, proof-RUNS.md L408-410, with Lemma H0); in the maximal decomposition the two
    neighbouring blocks may fuse (if equal-valued), which lowers kappa by one more.  No empty run is destroyed.
Apply the first applicable move.  The triple (kappa, g, k) decreases lexicographically at every move (P1: g; P2: k; P3: g; P4:
kappa), so the process stops.  Exits with g = 0 happen only through P1 or P3:
 Exit P3: the RGR avoider produced has B >= 1 and a (1,1)-run; by (I1) B = kappa; by Lemma TII every run of its OR-merge is
   pure: the (1,1)-run lies in some segment, which then contains both letters.  Contradiction.
 Exit P1: let w' be the last state with g >= 1 and w_end = FUS(w') the RGR avoider.  The step kills every empty run of w', so
   (C1) g(w') = 1 and the empty run t has an even neighbour, or (C2) g(w') = 2: sigma_u^a [] sigma_v^b [] sigma_u^c with b even.
   B(w_end) = B(w') =: B and kappa(w_end) = kappa(w') - [C2 with a, c odd].  By (I1), (I2) B = kappa(w_end).
   - kappa(w_end) = 0: then kappa(w') >= 1 forces C2 with a, c odd, and w_end contains the even block sigma_u^(a+b+c) with kappa = 0,
     contradicting (I3).
   - kappa(w_end) >= 1: Lemma TII gives A = 2p - 1.  Apply Lemma SING in w' (kappa(w') + beta <= p since an even block exists):
     C2 with a, c odd: kappa(w') - B = 1 and beta_t = beta_(t+1) = 1 force u_t = u_(t+1) = -1; but u_t + u_(t+1) = (u - v)/2 +
     (v - u)/2 = 0 and p is odd.  C2 otherwise (kappa(w') = B): an outer block odd gives an empty run with beta = 1: solvable;
     both outer blocks even give beta = 2 at both runs, u_t = u_(t+1) = -1, the same contradiction.  C1 (kappa(w') = B): beta_t = 1
     is solvable; beta_t = 2 is excluded by Lemma QQ.
 Terminal state with g >= 1: P1 and P2 do not apply, so there is no even block; P3, P4 do not apply, so every run is pure or empty.
   kappa >= 1 (K0*), B <= kappa.  B = kappa is excluded by Corollary B=K; kappa = 1 forces B = 0 and is excluded by Lemma K1*.  So
   the terminal state is an avoider in RES_<(p) with kappa >= 2.  The converse direction is trivial.  []

## 6. The residual RES_<(p), kappa >= 2: what is known and why it is open

Necessary relations for an avoider in RES_<(p) (from Z0, P0, V, Lemma SING): 2 <= kappa <= p - 1; 0 <= B <= kappa - 1;
A = R - B <= 2p - 1; R = 2p - k + 2 kappa; k >= 2 kappa - B + 1 >= kappa + 2; g + (number of even nonempty runs) <= 2 kappa;
k - g <= R, so k <= p + 2 kappa; at every empty run u_t avoids [1 - L_t, B - kappa] and 0; if A = 2p - 1 then kappa - B >= 2.
Finite status (aids): p = 5: empty (all 3,730 D10 avoiders of length 18 are RGR, olson/README.md Sec. 5.1).  p = 7: words with
k <= 9 are inside the normal form NF of c2/invstar/proof-GR0-r1.md (all blocks odd and runs pure satisfy NF (i), (ii)) and were
excluded by gwas2 (unreviewed code, c2/invstar/results.md Sec. 3); k = 10..19 are NOT computed here (contract: no blind
extension; a rough count of run data alone, before value search, is ~1.5e8 at p = 7).  For all p, nothing beyond the relations
above is proved for this class.
Why the available certificates stop here (concrete failures, not attempts merely abandoned):
(F1) Single-window boosts vanish: for kappa - B >= 2 the empty-run singleton has lambda({t}) = B - kappa + 1 <= -1, and the
     genuineness residue 0 lies outside I({t}); the single-run Lemma BC partition loses kappa - B per empty run (K1* and KB* are
     exactly the cases kappa - B <= 1 with B = 0, resp. kappa - B = 0).
(F2) The RGR proofs of the analogous RGR statements (C0-B'/S1' for B = 0, Theorem M and NMH-iii for B >= 1) use lifts and defect
     counts in which every run has r_t >= 1: e.g. S1' Step 1 needs R - r_t >= 2 kappa - 1 for every run (Kplus-r2 L181), which fails
     for a run carrying almost all rotations when g is large, and its Step 2 bound Phi(Z) >= 2 kappa + 2 uses rho_Z >= |Z|
     (Kplus-r2 L192-193), false when Z contains empty runs (whose lifted brackets bh_t = 2x_t are even and nonzero).  They cannot be
     imported by renaming (contract).
(F3) [r2 fix 5: domain and endpoint corrected]  Let w be an avoider in RES_<(p) with g = 1 and H >= 1 (a reflection pair exists).
     Filling its empty run with rho_1 rho_-1 and removing one reflection pair gives an RGR word w° (g = 1 is needed for this) with
     1 <= B + 1 < kappa + 1, which is solvable by (I1).  If A = 2p - 1, then A° = 2p and w° is certified by the empty/full pattern

* P1 (FUS; K0star-r2 L84-97).  An even block E is recoloured to the value u of a block X adjacent to it across an empty run.

  is unchanged.

  block S_j is appended to S_(j+1).

* P3 (TR-fill; K0star-r2 L104-106, RED-r2 L142-143).  One rho_1 rho_-1 pair moves from a run with r >= 3, which stays nonempty,
