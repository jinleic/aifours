## 3. Lemma SPLIT (proved here)

Let M be a minimal zero-sum sequence over C_n and M' := M x^(-1) y z with y + z = x, y, z != 0, M' a minimal zero-sum
sequence.  Then ||M||_g <= ||M'||_g for every generator g; hence ||M'||_g = 1 implies ||M||_g = 1.
Proof.  |y|_g + |z|_g is a positive integer congruent to |x|_g modulo n, and |x|_g is the least positive integer in its
class, so |x|_g <= |y|_g + |z|_g; summing, n ||M||_g <= n ||M'||_g.  If n ||M'||_g = n, then n ||M||_g is a positive multiple
of n (M is a zero-sum of nonzero terms) that is <= n, so it equals n.  []

## 4. Parity check of both Xia-Yuan families at n = 2p (the only property of (I2) used)

Claim P.  Every unsplittable minimal zero-sum sequence S of length p + 1 over C_(2p) that consists of odd elements is
g^p (pg) for a generator g, and has index 1.
Proof.  By (I2) (n = 2p even, floor(n/2) + 1 = p + 1), S belongs to one of the two families.
- Family A, (2g)^(p-1) (x_1 g) ((2p + 2 - x_1) g): the term 2g lies in 2C_(2p) for EVERY g (generator or not) and occurs
  p - 1 >= 4 times; so S contains an even element: excluded.
- Family B, g^t (pg) ((p + 1) g)^(2l) with t + 2l = p: (p + 1) g = 2 ((p + 1)/2) g lies in 2C_(2p) for every g; if l >= 1, S
  contains an even element: excluded.  If l = 0 (whether or not the elided conditions exclude it), S = g^p (pg).  All terms
  odd forces g odd; g = p would give S = p^(p+1), which contains the proper zero-sum p p: not minimal.  So g is a generator,
  and sum |.|_g = p * 1 + p = 2p: index 1.  []

## 2. Proof of Lemma FB-p

(R) Realisation at L = p.  Sort the coefficients 1 = ... = 1 < a_(1) <= ... <= a_(h) and X_i := m + sum_(j<i) a_(j).  If
a_(i) >= X_i + 1 for some i, with n := h - i + 1: W >= X_i + n(X_i + 1) and p = L <= X_i + n.  n = 1 gives W >= 2X_i + 1 >=
2p - 1, so W = 2p - 1, X_i = p - 1 and (X_i is the sum of the other p - 1 terms) Y' = g^(p-1)(pg).  For 2 <= n <= p - 1,
W >= (p - n)(n + 1) + n, a concave function of n equal to 3p - 4 at n = 2 and 2p - 1 at n = p - 1; equality W = 2p - 1 forces
n = p - 1, X_i = 1, m = 1, i = 1, and then W >= 1 + 3(p - 1) > 2p - 1; n >= p gives W >= 3p.  So outside (X) every
a_(i) <= X_i, the subset sums of the coefficients fill [0, W], and every integer in [2, W] is the coefficient sum of a
sub-multiset of Y' with at least two terms (a heavy value a_(i) is realised by the strictly smaller terms).
(Z) Shape of Z.  Let z = r g in Z, r odd in [1, 2p - 1].  If 3 <= r <= W and r is realised by a sub-multiset Q of Y' with
|Q| >= 2, then (Z - {z}) u Q is a longer zero-sum: impossible.  In case (X) (W = 2p - 1, slack = 0) every r in [3, 2p - 1]
except r = p is so realised (r <= p - 1 by units, r >= p + 1 by pg plus units), so z in {g, pg}.  Otherwise r = 1 or
r >= W + 1; then s := 2p - r <= slack, and m - slack >= 2L - 2p + 1 + h = 1 + h >= 1 gives g^s within Y', so g^s z is a
zero-sum of length s + 1 <= 2t.
(B) Balance and room (outside (X)).  S(N) = n+ (mod 2p) as sigma(Z) = 0.  Put delta := 2p - W = slack + 1 and suppose
S(N) >= delta.  Exactly as in Lemma FB (proof-FB-v1.md Sec. 2) take the r largest terms with S_r >= delta (r >= 2),
y := S_r - delta <= slack - 1 < m, y + r <= delta, and Z* := (Y' minus y terms g) u g^(n+) u (N minus those r terms), a
zero-sum of length L + 2t - (y + r) = p + 2t - (y + r).  As |Z*| and 2t are even and p is odd, y + r is odd.  If
W >= p + 2 then |Z*| >= 2t + p - delta = 2t + W - p >= 2t + 2.  If W = p (Y' = g^p, delta = p) then either y + r <= p - 2 and
|Z*| >= 2t + 2, or y + r = p = delta, which forces equality in y + r <= s_(r) + (r - 1) <=
(delta - 1)/(r - 1) + (r - 1) <= delta, i.e. r - 1 in {1, delta - 1} with all of s_(1), ..., s_(r) equal: r - 1 = 1 would
need s = delta - 1 = p - 1 even, impossible, so r = p and s_(1) = ... = s_(p) = 1; then Y contains g^p (Y' = g^p) and
(-g)^p, a zero-sum of length 2p: excluded by hypothesis.  In every case |Z*| >= 2t + 2 contradicts the maximality of Z.
So S(N) <= slack <= 2p - 1, and with 0 <= n+ <= 2t < 2p: S(N) = n+ and W + n+ <= 2p - 1.  []

the window, one of them even.
(X2) a = 2p - 1, b = 2kappa^ - p + 1 >= 2: [-U-, U+] has 2p integers and contains two representatives e1 < e2 = e1 + p.
With e* := U+ - U-, |e| + 2J = a - |e - e*| (direct check for e >= 0 and e < 0), so top(e) = R - |e - e*|, R = p + 2kappa^.

them the distance is <= (p-1)/2; otherwise both lie on one side within the 2p-window, the nearer at distance <= p - 1), so

## 2. Proof of Lemma SLZ

Every zero-sum of T - d is a proper zero-sum of T, hence not long (minimality of N), hence of length <= 2kappa: T - d
satisfies (S1_kappa).  Let Z0 be a longest zero-sum of T - d, |Z0| = 2t_d, L := N - 1 - 2t_d.  Suppose L >= p + 1.  If

Y1 := T - d: with g, W, n+, N as there, sigma(T - d) = (W + n+ - n+) g = W g, so d = -W g = (2p - W) g.  N is nonempty: if n- = 0
then n+ = 2t_d >= 2 while S(N) = 0, contradicting S(N) = n+.  Take a term -s g of N.  Since m >= slack + 3 > s, U := (T - d) minus s units g minus the
term -s g has sigma(U) = W g, so d U is a zero-sum of T of length N - s - 1, proper (s + 1 >= 2 terms omitted).  It is not
long, so N - s - 1 <= 2kappa.  With s <= slack = 2p - 1 - W <= 2p - 1 - L = 2p - N + 2t_d this gives
N - 2kappa - 1 <= 2p - N + 2t_d, i.e. N <= p + kappa + t_d (2N is even).  So L >= p + 1 implies N <= p + kappa + t_d, and
L <= p means N <= p + 1 + 2t_d.  Both bounds are <= p + 2kappa + 1 as t_d <= kappa.  []

## 3. Proof of Lemma EXT

If t0 = 0, Y1 is zero-sum-free of length >= p + 1; SC0 gives an odd generator g with W <= 2p - 1, every zero-sum of Y1 y
contains y = c g and has coefficient sum exactly 2p (c + W < 4p), so its length is 2p - (c - 1) - (mass of the other

total mass sum (a_i - 1) of C), h := number of heavy terms of C (a_i >= 3), so 2h <= e'; f(N0) := S(N0) + |N0| for N0 <= N,
so f(N) = n+ + n- = 2t0.
Step 1 (zero-sums of Y1 y).  Write y = c g with c odd in [1, 2p - 1].  Every term of Y1 y is b g with b one of a_i, 1 (the
units of Z0), -s_i, c.  For a subsequence S let sigma_g(S) be the integer sum of these b; S is a zero-sum iff
sigma_g(S) = 0 (mod 2p).  The positive b's of Y1 sum to W + n+ <= 2p - 1 and the negative ones to -n+ > -2p, so
sigma_g(S) lies in [-n+, 4p - 2] and a zero-sum has sigma_g(S) in {0, 2p}, the value 2p only if y lies in S.  Writing S_N for

length 2p + D(S), D(S) := f(S_N) - mass(S_C) - (c - 1), where S_C is the set of terms of S in C (the units of Z0 have mass
0).  (ZP_kappa) for Y1 y says: no such S has D(S) in [2kappa + 2 - 2p, 0].  (D(S) is even.)

D(S(N1)) = f(N1) - mass(H*) - (c - 1).  Remove the terms of N* one at a time (any order): D decreases by s + 1 <= 2p - 2kappa
per step (Step 2), from D(S*) >= 2 to D(S(empty)) = -mass(H*) - (c - 1) <= 0.  Let N1 be the first set reached with
D(S(N1)) <= 0; its predecessor has D >= 2, so D(S(N1)) >= 2 - (2p - 2kappa) = 2kappa + 2 - 2p.  If S(N1) is valid it is a
zero-sum of Y1 y of length 2p + D(S(N1)) in [2kappa + 2, 2p], contradicting (ZP_kappa).

f(N1) >= 2kappa + 2 - 2p + mass(H*) + c - 1 and f(N1) <= 2 S(N1) (every s >= 1), so
