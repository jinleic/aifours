27: **Lemma 1.** Fix an axis datum and unit vectors a_{s,j} := Q_s(1,j), j = 1,...,7, s = 1,...,5, with Q_s(1,0) := q_s^1. The data on R form a row-1 partial datum iff, for every s and j:

30: - (ii) j ∉ S_s(a_{s,j});
31: - (iii) for each fixed j, the sets S_1(a_{1,j}), ..., S_5(a_{5,j}) are pairwise disjoint;
32: - (iv) for each fixed j, the sets T_1(a_{1,j}), ..., T_5(a_{5,j}) are pairwise disjoint.
33: 
34: *Proof.* Condition (i) is the row-1 ONB part of (E1). Condition (ii) is equivalent to Q_s(0,j) ⊥ a_{s,j}, since Q_s(0,j) = w_{s,j} e_j. The remaining parts of (E1) are axis conditions.

36: For (E2), sort the pairs of distinct cells x, y ∈ R.
37: 
38: - **Same row or same column.** Then x and y lie together in row 0, row 1 or column 0, or form the pair {(0,j),(1,j)} with j >= 1. Every square's factor vanishes by (E1), so (E2) holds automatically.
39: - **Different row and different column, both in row 0 ∪ column 0.** Then x = (0,c), y = (r,0) with c, r >= 1. These are axis equations, which hold by assumption.
40: - **Remaining pairs.** These involve a cell (1,j) with j >= 1 and a cell outside row 1 and column j. Here (1,0) is excluded, being in row 1 and column 0. So the other cell is (0,c) with c != j, or (r,0) with r != 1. The cell (0,0) belongs to both families.
41:   - **Type I.** x = (0,c), c != j. Here <Q_s(0,c),a_{s,j}> = conj(w_{s,c}) <e_c,a_{s,j}>, which is nonzero iff c ∈ S_s(a_{s,j}). So (E2) for all s != t says no c != j lies in two of the sets S_s(a_{s,j}). Given (ii), this is (iii).

165: ## 6. Limits and the exact remaining obligation
166: 
167: **Remark L1 (reuse cannot complete any column of square 1).** Assume H1-H4 for full squares. For every j >= 1, at least one of Q_1(1,j), ..., Q_1(7,j) is not a unit multiple of any q_1^m.
168: 
169: *Proof.* Column j is an ONB containing Q_1(0,j) = w_{1,j} e_j, so Q_1(1,j), ..., Q_1(7,j) are an ONB of e_j^⊥. Suppose each were a unit multiple of some q_1^{m_i}. Orthonormality makes the m_i distinct. Let m* be the missing index; then the span of the seven vectors is (q_1^{m*})^⊥, which equals e_j^⊥ only if q_1^{m*} is a unit multiple of e_j. But supp(q_1^0) = {0}, and by H3-H4 supp(q_1^m) has at least two elements for m >= 1. So no q_1^m is a unit multiple of e_j for j >= 1. QED
