## 1. Elementary lemmas

**Prop 1 (orthogonality = disjoint non-orthogonality graphs).** For a QLS Ψ let N(Ψ) be the set of unordered pairs of
cells {c, c′} with ⟨ψ(c), ψ(c′)⟩ ≠ 0. QLS Ψ, Φ of order n are orthogonal iff N(Ψ) ∩ N(Φ) = ∅.
*Proof.* ⟨ψ(c)⊗φ(c), ψ(c′)⊗φ(c′)⟩ = ⟨ψ(c),ψ(c′)⟩⟨φ(c),φ(c′)⟩; n² orthonormal vectors in an n²-dimensional space
form a basis. ∎
(Side remark, re-derivation of the known Theorem 2: rows/columns are orthogonal, and every cell is non-orthogonal to
≥ 1 entry of each other row, so |N(Ψ)| ≥ n²(n−1)/2 with equality iff Ψ is classical; the pairs not in a common row or
column number n²(n−1)²/2; so t MOQLS(n) have t ≤ n−1, and t = n−1 forces every square classical.)

**Lemma 2 (two vectors sharing one coordinate).** If supp u ∩ supp v = {k}, then ⟨u, v⟩ = ū_k v_k ≠ 0.

**Lemma 3 (weight ≤ 2 bases).** In an ONB of C^n all of whose vectors have weight ≤ 2 (w.r.t. a fixed ONB), every
vector of weight 2 with support {a,b} has exactly one partner in the basis with the same support {a,b}, and no other
basis vector meets {a,b}.
*Proof.* Consider the bipartite support graph (vectors vs coordinates). A connected component with k vectors spans the
coordinate space of its k′ coordinates, so k = k′ (unitary). If k ≥ 2, no vector of weight 1 lies in it (a weight-1
vector e_a and a vector meeting a would share exactly one coordinate, Lemma 2), so all its vectors have weight 2 and
every coordinate has degree ≥ 2 (a degree-1 coordinate gives a column of the unitary with one nonzero entry, forcing
that vector to have weight 1); counting edges, the component is a single cycle of length 2k. For k ≥ 3 consecutive
vectors share exactly one coordinate — impossible by Lemma 2. So k = 2. ∎

**Lemma 4 (weights).** In standard form w.r.t. a row i0, at a cell c outside row i0 the supports of the four squares
are pairwise disjoint subsets of [7] \ {col(c)} (rules #2, #3). Hence every weight is ≤ 3, and a weight-3 entry forces
the other three entries at c to have weight 1, the four supports partitioning [7] \ {col(c)}.

## 2. Theorem A

Let Ψ1,…,Ψ4 be in standard form w.r.t. row 1 with all weights ≤ 2.
1. Apply Lemma 10 successively to Ψ1,…,Ψ4. The result Ψ′1,…,Ψ′4 is a set of classical MOQLS with
   (i) supp Ψ′s(c) ⊆ supp Ψs(c), (ii) weight-1 entries (in particular the first rows) unchanged up to phase
   (the procedure only rotates entries whose pattern is exactly the chosen weight-2 pattern). Their symbol arrays
   L′1,…,L′4 (L′s(c) = k iff Ψ′s(c) ∝ |k⟩) are 4 MOLS(7) with first row 1,…,7.
2. Theorem 9 (n − 3 = 4, n ≠ 4) extends them to 6 MOLS(7); with rows and columns these form an affine plane of order 7
   (Bose), which is AG(2,7) (Hall). So L′1 is isotopic to the Latin square defined by three distinct parallel classes
   of AG(2,7).
3. **Fact (C)** (impl 1: all 336 ordered class triples; impl 2: closed forms y − mx): in such a square, for every pair
   of symbols {a,b} the graph G_ab on the 14 cells carrying a or b, with edges joining cells in a common row or column,
   is connected (one 14-cycle). This is invariant under isotopy.
4. Suppose Ψ1 has an entry of weight 2, with support {a,b}; let E = {c : supp Ψ1(c) = {a,b}}. By Lemma 3 each row and

# MOQLS(7): analytic versions of affine-plane Facts C and L

Parent derivation for independent review; not a claim that Problem16 is solved. These facts concern AG(2,7). Identifying a completed order7 net with AG(2,7) still imports uniqueness of the projective plane of order7, and extension of three MOLS still imports the cited classification. They are not replaced by the arguments below.

## Fact C: the two-symbol graph is one14-cycle

Take three distinct parallel classes of AG(2,7) as rows, columns and symbols. In affine coordinates the resulting Latin square is L(i,j)=a*i+b*j with nonzero a,b in F7, up to permutations of rows, columns and symbols. For two distinct symbols s,t, every symbol-cell has exactly one row-neighbour and one column-neighbour among the other symbol's cells, so their graph is a disjoint union of even cycles.

Start from an s-cell in row i. Its row-neighbour is the t-cell with column displaced by (t-s)/b. Moving next along the column to an s-cell changes the row by (s-t)/a. This nonzero additive step has order7 in F7. The alternating walk visits all seven s-cells and all seven t-cells, so the graph is a single14-cycle. Thus no enumeration of336 coordinate triples is needed for this fact.

## Fact L: every three free directions admit exactly two linear complement directions

The directions of AG(2,7) form P1(F7). GL(2,7) induces PGL(2,7), which takes any ordered triple of distinct directions to any other: the unique fractional-linear map can be constructed by sending the triple to infinity,0,1. We may therefore take the free set F={infinity,0,1}. Its complement has five possible directions c=2,3,4,5,6.

For a fixed c, change direction coordinates by f_c(x)=1/(x-c), taking c to infinity. The free directions become the three-element subset T_c={0,-1/c,1/(1-c)} of F7. In affine coordinates with c vertical, let L0 have x=0 and L1 have x=1. The points of L0 joined to q=(1,y) in a free direction are A(q)={y-f:f in T_c}. For distinct y,y', the size of A(q) intersection A(q') equals the multiplicity of y'-y among the directed differences of T_c. Hence all intersections have size at most1 exactly when those six directed differences are distinct (then they are F7 minus{0}).

All arithmetic in the following table is modulo7.

| c | T_c | Six directed differences all distinct? |
|---|---|---|
| 2 | {0,3,6} | No: difference3 repeats |
| 3 | {0,2,3} | Yes: exactly1,2,3,4,5,6 |
| 4 | {0,2,5} | No: difference2 repeats |
| 5 | {0,4,5} | Yes: exactly1,2,3,4,5,6 |
| 6 | {0,1,4} | No: difference3 repeats |

Exactly two complement directions are linear. The geometric property is invariant under the preceding invertible coordinate changes and rescaling the separation of L0,L1, so this proves Fact L for every free triple and every pair of distinct lines of the chosen complement class.

## Consequence for the proposed Theorem B

If a quantum assignment is an ONB on every line of five parallel classes, choose one of the two linear classes c in that five-set and a reference line L0. Every vector on another c-line has support, relative to the ONB on L0, contained in its three-element A(q). Distinct q on that line are orthogonal, and their allowed supports intersect in at most1 coordinate. An actual one-coordinate intersection would give a nonzero inner product, so actual supports are disjoint. Seven nonempty disjoint supports on seven coordinates must all be singletons. Thus all entries use the same seven rays and the assignment is classical.

This last conclusion assumes the five-net really comes from five classes of AG(2,7); the imported extension/uniqueness hypotheses remain essential. It proves neither the K2/K3/K4 support exclusions nor the symmetry-breaking soundness.

Preliminaries

2.1

Latin squares

A Latin square of order n is an n × n matrix containing elements of a set of size n such that each row and
each column contains every element exactly once. Two Latin squares A = (aij )1≤i,j≤n and B = (bij )1≤i,j≤n
are orthogonal if all n2 tuples (aij , bij ) are different. A set of t mutually orthogonal Latin squares of order
n, abbreviated t MOLS(n), is a set of t Latin squares of order n that are pairwise orthogonal.

2.2

Quantum Latin squares

A quantum Latin square of order n is an n × n matrix over Cn such that each row and each column forms
an orthonormal basis of Cn . Two quantum Latin squares are isotopic if they can be obtained from one
another by
(i) multiplying each entry by a phase factor,
(ii) permuting rows and columns, and
(iii) applying a unitary transformation on all entries.
A quantum Latin square is classical or not genuinely quantum if, up to isotopy, all entries are contained
in {|1⟩ , . . . , |n⟩}, a fixed orthonormal basis. This property is independent of the chosen basis by item (iii)
in the definition of isotopy.

2.3

Two quantum Latin squares (ψij )1≤i,j≤n and (ϕij )1≤i,j≤n are orthogonal if

Conclusion and future directions

We constructed new lower and upper bounds on the largest number t for which there exist non-classical
sets of t MOQLS(n). Specific values of these new bounds for small n can be found in Table 2.
We pose two open problems for future research:
Problem 16. Is a set of n − 3 MOQLS(n), n ̸= 4, necessarily classical?
Problem 17. Are there numbers t and n for which there exist t MOQLS(n) but no t MOLS(n)?
The smallest open case for the second problem is n = 10. It is not known that 7 MOLS(10) do not exist
(combining Theorem 9 with the non-existence of a projective plane of order 10, see [4]), but it is still an
open problem whether 7 MOQLS(10) exist. It would already be interesting to find 3 MOQLS(10), because
the existence of 3 MOLS(10) is not known.

class CNF:
    def __init__(self):
        self.nv = 0
        self.clauses = []
        self.names = {}

    def var(self, name):
        if name not in self.names:
            self.nv += 1
            self.names[name] = self.nv
        return self.names[name]

    def add(self, lits):
        """lits: ints or bools; True satisfies the clause, False literals are dropped."""
        out = []
        for l in lits:
            if l is True:
                return
            if l is False:
                continue
            out.append(l)
        if not out:
            raise ValueError("empty clause generated")
        self.clauses.append(out)

    def AND(self, name, a, b):
        """returns literal equivalent to a & b (bool-folded)."""
        if a is False or b is False:
            return False
        if a is True:
            return b
        if b is True:
            return a
        v = self.var(name)
        self.add([-v, a])
        self.add([-v, b])
        self.add([v, -a, -b])
        return v


def neg(l):
    if l is True:
        return False
    if l is False:
        return True
    return -l

def decode(model_path, map_path, out_path):
    true = set()
    for line in open(model_path):
        if line.startswith("v "):
            for t in line.split()[1:]:

                if v > 0:
                    true.add(v)
    m = json.load(open(map_path))

    base = max(meta["quantum"]) + 1

    for key, v in m["vars"].items():

    TRUE = F.new("TRUE")
    F.clause(TRUE)

    def lit_L(t, r, c, x):
        if r == 0:
            return TRUE if x == c else -TRUE
        if mode == "fixed":
            return TRUE if x == (c + slopes[T.index(t)] * r) % n else -TRUE
        return one_hot[(t, r, c, x)]

    def exactly_one(lits):
        F.clause(*lits)
        for a, b in combinations(lits, 2):
            F.clause(-a, -b)

        for t in T:
            for r in range(1, n):
                for c in range(n):
                    exactly_one([lit_L(t, r, c, x) for x in range(n)])
            for x in range(n):

                for c in range(n):

        v = F.new()
        F.clause(-v, a)
        F.clause(-v, b)
        F.clause(v, -a, -b)
        return v

    def counter(lits, upto):
        """unary sequential counter; returns [ge1, ..., ge_upto] literals with full equivalence."""
        prev = [-TRUE] * upto
        for l in lits:
            cur = []
            for m in range(upto):
                v = F.new()

                # v <-> prev[m] or (carry and l)
                F.clause(-prev[m], v)
                F.clause(-carry, -l, v)
                F.clause(-v, prev[m], carry)
                F.clause(-v, prev[m], l)
                cur.append(v)

            F.clause(-e, -ge2)
            F.clause(e, -ge1, ge2)

    for c in range(n):

        for s in Q:
            for k in range(n):
                F.clause(sup[(s, 1, 0, k)] if k in alloc[s] else -sup[(s, 1, 0, k)])
    # weight >= 3 somewhere in each square
    for s in p4_labels:

                continue
