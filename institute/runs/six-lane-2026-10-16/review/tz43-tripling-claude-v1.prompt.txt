   40| ## 1. Lemma 1 (zero-sum tripling)
   41| 
   42| **Lemma 1.** Let H be a 3-regular 3-partite 3-graph with parts A, B, C, and let s ∈ Z3. Then E^s is partitioned into
   43| 9 perfect matchings of H^s. More precisely, the label classes C_P, P ∈ Z3², defined in Step 4 below, are pairwise
   44| disjoint perfect matchings of H^s whose union is E^s.
   45| 
   46| **Step 1 (sizes).**
   47| 
   48| * Every edge has exactly one vertex in A, so Σ_{a∈A} deg(a) = |E|. By 3-regularity, 3|A| = |E|.
   49| * The same argument for B and C gives |A| = |B| = |C| = |E|/3 =: n.
   50| * Hence |V| = 3n = |E|.
   51| 
   52| **Step 2 (incidence graph).**
   53| 
   54| * Let I be the bipartite graph with left nodes V and right nodes E. It has one edge (v, e) for each incidence
   55|   v ∈ e. I is simple: the three vertices of e lie in different parts, so they are distinct.
   56| * Every left node v has degree deg_H(v) = 3.
   57| * Every right node e has degree |e| = 3.
   58| * So I is 3-regular on both sides.
   59| 
   60| **Step 3 (the only import: Hall's theorem).** Hall: a bipartite graph with sides L and R has a matching saturating L
   61| iff |N(S)| ≥ |S| for every S ⊆ L.
   62| 
   63| * Let the bipartite graph be k-regular with k ≥ 1, and let S ⊆ L.
   64| * The k|S| edges leaving S all end in N(S). The set N(S) receives at most k|N(S)| edges in total. Hence
   65|   |N(S)| ≥ |S|, and a matching saturating L exists.
   66| * Since k|L| = (number of edges) = k|R|, we have |L| = |R|, so this matching is perfect.
   67| * Deleting it leaves a (k−1)-regular bipartite graph.
   68| * Induction on k therefore splits the edge set of I into three perfect matchings M_0, M_1, M_2. This is König's
   69|   edge-colouring theorem for I.
   70| 
   71| Define u(v, e) = i iff (v, e) ∈ M_i. Then:
   72| 
   73| * **(U1)** For each v ∈ V, the map e ↦ u(v, e) is a bijection from the three edges at v onto Z3. Each M_i is
   74|   perfect, so it contains exactly one incidence at v.
   75| * **(U2)** For each e ∈ E, the map v ↦ u(v, e) is a bijection from the three vertices of e onto Z3. Each M_i
   76|   contains exactly one incidence at the right node e.
   77| * **(U3)** Consequently u(a_e, e) + u(b_e, e) + u(c_e, e) = 0 + 1 + 2 ≡ 0 (mod 3) for every e.
   78| 
   79| **Step 4 (labels).**
   80| 
   81| * For L = L(e; x, y, z) ∈ E^s, put λ(L) = (x + u(a_e, e), y + u(b_e, e)) ∈ Z3².
   82| * Let C_P = {L ∈ E^s : λ(L) = P}.
   83| * λ is a function on the (indexed) family E^s. So every lift has exactly one label, the nine C_P are pairwise
   84|   disjoint, and their union is E^s.
   85| 
   86| **Step 5 (each C_P is a perfect matching).** Fix P = (p1, p2). Every vertex of H^s lies in exactly one member of
   87| C_P.
   88| 
   89| * **(i) Vertex (a, x), a ∈ A.** A lift contains (a, x) iff it is a lift of an edge e with a_e = a and has first copy
   90|   coordinate x. It lies in C_P iff, in addition:
   91|   * u(a, e) = p1 − x;
   92|   * its second coordinate is y = p2 − u(b_e, e); and
   93|   * z = s − x − y.
   94| 
   95|   By (U1) at a, exactly one edge e at a has u(a, e) = p1 − x. The coordinates y and z are then forced. The resulting
   96|   triple satisfies x + y + z = s, so it lies in E^s, and its label is (p1, p2).
   97| * **(ii) Vertex (b, y), b ∈ B.** This is symmetric.
   98|   * By (U1) at b, exactly one e at b has u(b, e) = p2 − y.
   99|   * Then x = p1 − u(a_e, e) and z = s − x − y are forced.
  100| * **(iii) Vertex (c, z), c ∈ C (third part).**
  101|   * Let e be an edge with c_e = c. A lift of e that contains (c, z) and has label P must have
  102|     x = p1 − u(a_e, e) and y = p2 − u(b_e, e). It is a member of E^s iff x + y + z = s, that is, iff
  103|     p1 + p2 − (u(a_e, e) + u(b_e, e)) + z = s.
  104|   * By (U3), u(a_e, e) + u(b_e, e) = −u(c, e). So the condition is equivalent to **u(c, e) = s − z − p1 − p2**.
  105|   * By (U1) at c, exactly one of the three edges at c satisfies it. For that edge the triple with the forced x and y
  106|     lies in E^s and has label P. No other edge at c contributes a member of C_P containing (c, z).
  107| 
  108|   So C_P covers every vertex exactly once. ∎
  109| 
  110| **Where each hypothesis is used.**
  111| 
  112| * (U1) is used at A-vertices in (i), at B-vertices in (ii) and at C-vertices in (iii).
  113| * The zero-sum identity (U3) is used **only** in (iii).
  114| * What (iii) really needs is that, for each c ∈ C, the map e ↦ −(u(a_e, e) + u(b_e, e)) is a bijection on the edges
  115|   at c. (U3) together with (U1) at c supplies this.
  116| * Suppose u were a bijection at every vertex but failed (U2) on some edges. Then (i) and (ii) still hold, but (iii)
  117|   can fail. Mutation (b) in §5 realises exactly this case.
  118| 
  119| **Counts.**

  121| * |C_P| = |V × Z3|/3 = 3n.
  122| * The total 9 · 3n = 27n = 9|E| = |E^s|.
  123| * Neither linearity nor any condition on s is used. The colouring u depends only on H, so one u serves all three
  124|   values of s.

  126| ## 2. Lemma 2 (missing-group families are (g/2)-regular)
  127| 
  128| **Lemma 2.** Let (Y, {G_1, …, G_4}, D) be a GDD(2,3,4g) of type g^4. Every triple of D meets exactly three groups,
  129| so it misses exactly one group. Let F_i = {T ∈ D : T ∩ G_i = ∅}. Then:
  130| 
  131| * F_i is a 3-partite 3-graph whose parts are the three groups G_j, j ≠ i;
  132| * every vertex of ∪_{j≠i} G_j has degree exactly g/2 in F_i; and
  133| * in particular g is even.
  134| 
  135| **Proof.**
  136| 
  137| * By D1(2), a triple has its three points in three distinct groups. So it misses exactly one of the four groups.
  138|   Every triple of F_i therefore meets each G_j, j ≠ i, in exactly one point.
  139| * Fix y ∈ G_a, and for each i ≠ a let n_i = n_i(y) be the number of triples through y that miss G_i.
  140|   * Every triple through y misses exactly one group.
  141|   * That group is not G_a, because y ∈ G_a.
  142| * Fix b ≠ a.
  143|   * A triple through y contains a point of G_b iff it misses neither G_a nor G_b. That holds iff it misses one of the
  144|     other two groups.
  145|   * Such a triple contains exactly one point of G_b.
  146|   * By D1(3), every pair {y, w} with w ∈ G_b lies in exactly one triple.
  147|   * Counting the pairs {y, w}, w ∈ G_b, therefore gives g = Σ_{i ∉ {a, b}} n_i.
  148| * Name the three groups other than G_a as G_b, G_c, G_d. Then n_c + n_d = g, n_b + n_d = g and n_b + n_c = g.
  149|   Hence n_b = n_c = n_d = g/2.
  150| * The degree of y in F_i (i ≠ a) is n_i(y) = g/2. ∎
  151| 
  152| **Case g = 6.** Each F_i is 3-regular and 3-partite, with parts of size 6 and 18 edges, and |D| = 72. Pair
  153| uniqueness also makes D linear, but nothing here uses linearity.

  155| ## 3. Theorem 3 (every zero-sum-tripled H(5,6,4,3) is an FDGDD(3,4,5{18}) with explicit frames)
  156| 
  157| **Setup.**
  158| 
  159| * Let (X0, {G0_1, …, G0_5}, A0) be a GDD(3,4,30) of type 6^5.
  160| * Put X = X0 × Z3 and G_i = G0_i × Z3, so |G_i| = 18.
  161| * Let A be the family of all {(p_0, β_0), …, (p_3, β_3)} with {p_0, …, p_3} ∈ A0 and β_0 + β_1 + β_2 + β_3 = 0 in Z3.
  162| 
  163| **(a) (X, {G_i}, A) is a GDD(3,4,90) of type 18^5.**
  164| 
  165| * A block projects onto a master block, so it has 4 points in 4 distinct groups.
  166| * Take a 3-subset {(q_1, γ_1), (q_2, γ_2), (q_3, γ_3)} from three distinct groups.
  167|   * {q_1, q_2, q_3} meets three distinct master groups. By D1(3) it lies in exactly one master block
  168|     {q_1, q_2, q_3, q_4}.
  169|   * A block of A containing the 3-subset projects onto a master block containing {q_1, q_2, q_3}, hence onto this
  170|     one.
  171|   * Its fourth point is then (q_4, γ_4) with γ_4 = −(γ_1 + γ_2 + γ_3), which is forced. That block lies in A.
  172|   * So the 3-subset lies in exactly one block.
  173| * Distinct master blocks have distinct projections, and each gives 27 distinct blocks. So |A| = 27·540 = 14580.
  174| * This is inflation by the zero-sum TD(3,4,3), {β ∈ Z3⁴ : Σβ = 0}. Any three coordinates of that design determine the
  175|   fourth.
  176| 
  177| **(b) Derived design.**
  178| 
  179| * Let x = (p, β) with p ∈ G0_a, and put s = −β.
  180| * A block contains x iff it is {(p, β), (q_1, γ_1), (q_2, γ_2), (q_3, γ_3)} with {p, q_1, q_2, q_3} ∈ A0 and
  181|   β + γ_1 + γ_2 + γ_3 = 0. Hence
  182| 
  183|   A_x = { {(q_1, γ_1), (q_2, γ_2), (q_3, γ_3)} : {q_1, q_2, q_3} ∈ D_p, γ_1 + γ_2 + γ_3 = s },
  184| 
  185|   where D_p = {B \ {p} : p ∈ B ∈ A0} is the master derived design.
  186| * D_p is a GDD(2,3,24) of type 6^4 on X0 \ G0_a.
  187|   * Its triples avoid G0_a and meet each group at most once.
  188|   * For a cross pair {q, q′}, the transverse triple {p, q, q′} lies in exactly one master block, by D1(3).
  189| * The same one-line argument applied to (a) shows that A_x is a GDD(2,3,72) of type 18^4 on X \ G_a.
  190| * Distinct pairs (T, γ) give distinct triples, because T is the projection. So |A_x| = 72 · 9 = 648.
  191| 
  192| **(c) One missed group at a time.**
  193| 
  194| * For i ≠ a, let F_i(p) be the missing-group family of D_p. By Lemma 2 with g = 6 it is 3-regular and 3-partite.
  195|   Its parts are G0_j for the three j ∉ {a, i}, taken in increasing index order as (A, B, C).
  196| * A triple of A_x misses G_i iff its projection misses G0_i. So the triples of A_x that miss G_i are exactly the
  197|   zero-sum lifts of F_i(p) with constant s.
  198| * By Lemma 1 these 162 triples split into 9 classes. Each class is a perfect matching of
  199|   ∪_{j∉{a,i}} G0_j × Z3 = (X \ G_a) \ G_i, that is, a PC of (X \ G_a) \ G_i in the sense of D2.
  200| 
  201| **(d) KF and FDGDD.**
  202| 
  203| * Every triple of A_x misses exactly one G_i with i ≠ a.
  204| * Hence the 4 × 9 = 36 classes from (c) partition A_x. Each class is a PC of (X \ G_a) \ G_i for a group G_i of the
  205|   derived design.
  206| * With (b), this is exactly D3 for the derived design at x: a KF(18⁴).
  207| * Since x was arbitrary, (X, {G_i}, A) satisfies D5: it is an FDGDD(3,4,5{18}). ∎

  162| def missing_family(groups, grp, der, p, j):
  163|     """Return (parts, vertices, oriented edges (a,b,c)) of F_{p,j}; check 3-partite and 3-regular."""

  172|         edges.append((by[parts[0]], by[parts[1]], by[parts[2]]))

  180| # ---------------------------------------------------------------- incidence colouring (Hall / Konig)

  182| def incidence_colouring(verts, edges):
  183|     """u[e][pos] in Z3 for the incidence (edges[e][pos], e); three successive perfect matchings."""
  184|     remaining = dict((q, [e for e, E in enumerate(edges) if q in E]) for q in verts)
  185|     colour = {}
  186|     for c in range(3):
  187|         match = {}
  188| 
  189|         def augment(q, seen):
  190|             for e in remaining[q]:
  191|                 if e in seen:
  192|                     continue
  193|                 seen.add(e)
  194|                 if e not in match or augment(match[e], seen):
  195|                     match[e] = q
  196|                     return True
  197|             return False
  198| 
  199|         for q in verts:
  200|             if not augment(q, set()):
  201|                 raise ConstructionError('round %d: no perfect matching (impossible for a regular bipartite graph)' % c)
  202|         if len(match) != len(edges) or len(set(match.values())) != len(verts):
  203|             raise ConstructionError('round %d: matching is not perfect on both sides' % c)
  204|         for e, q in match.items():
  205|             colour[(q, e)] = c
  206|             remaining[q].remove(e)
  207|     u = [tuple(colour[(q, e)] for q in E) for e, E in enumerate(edges)]
  208|     for e, row in enumerate(u):
  209|         if sorted(row) != [0, 1, 2]:
  210|             raise ConstructionError('colouring not proper at edge node %d' % e)
  211|     for q in verts:
  212|         if sorted(u[e][E.index(q)] for e, E in enumerate(edges) if q in E) != [0, 1, 2]:
  213|             raise ConstructionError('colouring not proper at vertex node %d' % q)
  214|     return u

  217| def lift_classes(edges, u, s):

  219|     classes = collections.OrderedDict((P, []) for P in LABELS)

  224|                 classes[((x + ua) % 3, (y + ub) % 3)].append(tuple(sorted((3 * a + x, 3 * b + y, 3 * c + z))))
  225|     return classes
