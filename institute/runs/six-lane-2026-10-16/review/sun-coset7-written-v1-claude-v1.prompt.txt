54: ## 3. Theorem R1(7): the class decomposition [NEW]
55: 
56: **Theorem R1(7).** In a CE, a ∈ {0, 1, 2}, and exactly one of the following holds.
57: - **(I)** a ≤ 1, |C| ≥ 4, and either D ⊆ A_2 ∖ A_3 ("type 2") or D ⊆ A_3 ∖ A_2 ("type 3"). (D = ∅ is allowed.)
58: - **(II)** a = 2: A_5 = {x, y} with x ∈ A_2 ∖ A_3 and y ∈ A_3 ∖ A_2, and C = V ∖ {x, y}.
59: 
60: *Proof.*
61: 1. **a ≥ 3 forces a = 7, which is impossible.** By P1(ii), at most two vertices of A_5 lie in A_2 ∪ A_3. If a ≥ 3, some x ∈ A_5 lies in neither. For every j ≠ x, P_xj ⊆ {5} and P_xj ≠ ∅ (P1(i)), so j ∈ A_5. Thus a = 7 and every pair has P = {5}, gcd 5. Any six of the seven cosets then contradict Sun(6) (k6 verdict efe1d849…). So a ≤ 2.
62: 2. **a = 2.** Let A_5 = {x, y}. There is j ∉ A_5, and P_xj ≠ ∅ with 5 ∉ P_xj, so x ∈ A_2 ∪ A_3; likewise y. By P1(ii) they cannot both lie in A_2, nor both in A_3. So after naming, x ∈ A_2 ∖ A_3 and y ∈ A_3 ∖ A_2. For every j ∉ {x,y}: P_xj ≠ ∅ and P_xj ⊆ {2} give j ∈ A_2; P_yj ⊆ {3} gives j ∈ A_3. So V ∖ {x,y} ⊆ C, and x, y ∉ C. This is (II).
63: 3. **a ≤ 1.** No pair has P = {5}. By Sun(5) (k5 verdict 2cf02436…), every 5-subset contains a pair with gcd ≥ 5, i.e. (P1) with gcd 6, i.e. (P1(iii)) a pair inside C. Hence every 5-subset of V meets C in at least two vertices, so |V ∖ C| ≤ 3, i.e. |C| ≥ 4.
64:    - A vertex d ∈ D lies in A_2 ∪ A_3: otherwise P_dj ⊆ {5} would be empty for every j ≠ d (as a ≤ 1), contradicting P1(i). Since d ∉ C, d lies in exactly one of A_2 ∖ A_3, A_3 ∖ A_2.
65:    - If d ∈ A_2 ∖ A_3 and d′ ∈ A_3 ∖ A_2, then P_dd′ = ∅, contradicting P1(i). So D lies entirely in one of them. This is (I). ∎

91: - **Entries:** for each neighbour the entry (g_vj, α_vj, b_2, b_3, b_5), unsorted, in N order.

93:   - **["R", key-string]:** the key computed from (entries, q) must equal key-string, and its dual must verify as above.
94:   - **["P", vec]:** vec has 2n + 2·C(n,2) exact rationals: a (n), b (n), u (pairs), l (pairs); u, l ≥ 0.

96: - **Forced pairs:** (a, b) is forced iff τ_min(v, N_a, N_b)·g_{vN_a} ≥ lcm(g_{vN_a}, g_{vN_b})·α_{N_aN_b}·α_{vN_a}. This is ordered: test (a, b) and (b, a) separately.
97: - **Columns:** all (A, S) with A ⊆ N non-empty, no forced (a, b) with b ∈ A and a ∉ A, and S ⊆ A with S = ∅ or S allowed.
98: - **Check (★) for every column:** Σ_{x∈S} a_x + Σ_{x∈A} b_x − Σ_{pairs ⊆ A} u + Σ_{pairs ⊆ A} l ≤ 1.

37: ## Theorem
38: 
39: Let G be any group. Let a_1G_1, …, a_5G_5 be pairwise disjoint left cosets of subgroups of finite index. Then gcd([G:G_i], [G:G_j]) ≥ 5 for some i < j.
40: 
41: ## 1. R0: reduction to finite groups
42: 
43: core_G(G_i) is the kernel of the action of G on G/G_i, so its index is at most [G:G_i]!. Hence N = ∩_i core_G(G_i) is a normal subgroup of finite index contained in every G_i.
44: 
45: Each coset a_iG_i is the full preimage of its image in G/N. So indices, intersection indices and disjointness all pass to the finite group G/N.
46: 
47: ## 2. R1: reduction to Core(5), and a proof of M-S Prop 4.5
48: 
49: **Core(5).** No finite group G has subgroups U_1, …, U_5 with [G:U_i] = 4r_i, the r_i pairwise coprime, and pairwise disjoint cosets g_iU_i.
50: 
51: **The Sun(5) ⇒ Core(5) direction.** A Core(5) configuration has every pairwise gcd equal to 4 < 5.
52: 
53: **The Core(5) ⇒ Sun(5) direction, group by group.** Let n_i = [G:G_i], and assume five disjoint cosets in G have all pairwise gcds ≤ 4.
54: 
55: 1. **Each gcd is 2, 3 or 4.** By L0.2 and L0.6 no gcd equals 1, so each lies in {2, 3, 4}.
56: 2. **All divisible by 3, or all even.** If some n_i is odd, every gcd with it is odd and so equals 3. Then 3 divides all five indices.
57: 3. **All divisible by 3.** Every gcd is then 3 < 4. Any four of the cosets contradict Zhu Theorem 1.1 at k = 4.
58: 4. **All even.** Write n_i = 2^{e_i}m_i with m_i odd. Then the m_i are pairwise coprime, every e_i ≥ 1, and at most one e_i ≥ 3.
59:    - **Two indices with e = 1.** With any third index they have all pairwise gcds equal to 2 < 3, contradicting Zhu Theorem 1.1 at k = 3.
60:    - **Exactly one index with e = 1.** We get (2r_1, 4r_2, 4r_3, 4r_4) with r_1 odd and the r's pairwise coprime. This is excluded by Proposition 4.5 below.
61:    - **Otherwise.** n_i = 4r_i with r_i = 2^{e_i−2}m_i pairwise coprime: a Core(5) configuration in the same group G, with the same subgroups.
62: 
63: **Proposition 4.5 (M-S, Beitr. Algebra Geom. 60 (2019); proof patched per F-2 and F-8).**
64: 
65: *Status of this proof.* It is self-contained modulo rules-v1 L0.3–L0.5 and L1–L3. "Harmonic" means: there exist g_i such that the cosets g_iU_i are pairwise disjoint (F-9).

170: ## 5. Lemma R: right-coset fibres over a vertex subgroup [NEW]
171: 
172: **Setting.** G is finite. U_1, …, U_5 ≤ G have indices n_i. **Assume the cosets g_1U_1, …, g_5U_5 are pairwise disjoint (F-9).** Fix a vertex v and left-translate the whole configuration so that g_v = 1; disjointness is preserved. For j ≠ v put D_j := U_v g_j U_j, a (U_v, U_j)-double coset, and d_j := |D_j|/|U_j|.
173: 
174: **Statement.**
175: - **(R1)** D_j ∩ U_vU_j = ∅.
176: - **(R2)** |D_j| is a positive multiple of |G|/gcd(n_v, n_j).
177: - **(R3)** Every right coset U_vy contained in D_j meets g_jU_j. If w ∈ g_jU_j ∩ U_vy, then g_jU_j ∩ U_vy = (U_v ∩ wU_jw⁻¹)w, and [U_v : U_v ∩ wU_jw⁻¹] = d_j.
178: - **(R5′)** If j ≠ k and D_j ∩ D_k ≠ ∅, then gcd(d_j, d_k) ≥ 2.
179: - (R4) from earlier versions is deleted, since it is unused.
180: 
181: **Proof of (R1).** Since g_vU_v = U_v and g_jU_j are disjoint, L0.2 gives g_j ∉ U_vU_j. Now U_vU_j = U_v·1·U_j is the double coset of 1, and D_j is the double coset of g_j. Distinct double cosets are disjoint, so D_j ∩ U_vU_j = ∅.
182: 
183: **Proof of (R2).** By L0.4, |U_v g_j U_j| is a multiple of |G|/gcd([G:U_v], [G:U_j]). It is positive because g_j ∈ D_j.
184: 
185: **Proof of (R3).**
186: - Let U_vy ⊆ D_j. Then y = c g_j u with c ∈ U_v and u ∈ U_j. So U_vy = U_v g_j u contains g_ju, which lies in g_jU_j.
187: - For w ∈ g_jU_j ∩ U_vy we have g_jU_j = wU_j and U_vy = U_vw. Then x ∈ wU_j ∩ U_vw ⟺ xw⁻¹ ∈ wU_jw⁻¹ and xw⁻¹ ∈ U_v. So g_jU_j ∩ U_vy = (U_v ∩ wU_jw⁻¹)w.
188: - For the index: [U_v : U_v ∩ wU_jw⁻¹] = |U_v · wU_jw⁻¹| / |wU_jw⁻¹|. Right multiplication by w preserves size, so |U_v · wU_jw⁻¹| = |U_vwU_j|. Since w ∈ D_j, U_vwU_j = D_j. Hence the index is |D_j|/|U_j| = d_j.
189: 
190: **Proof of (R5′).**
191: - D_j and D_k are both left U_v-invariant, so D_j ∩ D_k is too. Being non-empty, it contains a whole right coset C = U_vy.
192: - By (R3), choose w_j ∈ g_jU_j ∩ C and w_k ∈ g_kU_k ∩ C. The two pieces are P_j = g_jU_j ∩ C = A w_j and P_k = g_kU_k ∩ C = B w_k, where A = U_v ∩ w_jU_jw_j⁻¹ and B = U_v ∩ w_kU_kw_k⁻¹. Their indices in U_v are d_j and d_k.
193: - P_j ∩ P_k = ∅, because g_jU_j ∩ g_kU_k = ∅.
194: - **Right-translate into U_v.** Multiply both pieces on the right by w_j⁻¹. This gives A and Bc, where c = w_kw_j⁻¹ lies in U_v because w_j and w_k lie in the same right coset C. So A and Bc are disjoint subsets of U_v.
195: - **Invert.** A⁻¹ = A and (Bc)⁻¹ = c⁻¹B. These are disjoint left cosets in U_v of subgroups of indices d_j and d_k.
196: - **Apply k = 2 (L0.6) in U_v.** If gcd(d_j, d_k) = 1, then AB = U_v, so c⁻¹ ∈ AB, i.e. c⁻¹ = ab with a ∈ A and b ∈ B. Then a = c⁻¹b⁻¹ ∈ A ∩ c⁻¹B, a contradiction.
197: - Hence gcd(d_j, d_k) ≥ 2. ∎
198: 
199: **Core(5) form.** In Core(5), gcd(n_v, n_j) = 4. So |D_j| = q_j |G|/4 with q_j a positive integer. By (R1), D_j ⊆ G ∖ U_vU_j, which has size (4 − α_vj)|G|/4, so 1 ≤ q_j ≤ 4 − α_vj. Then d_j = q_j|G|/4 ÷ (|G|/(4r_j)) = q_jr_j.

201: ## 6. Refutation of the pattern S-D
202: 
203: **S-D:**
204: - α01 = α02 = 1, α03 = α04 = 2, and α12 = α13 = α14 = α23 = α24 = α34 = 3;
205: - E2 = 1, so r_1 is even and 3 ∤ r_1;
206: - E3 = 0, so 3 | r_0 and r_0 is odd;
207: - r_2, r_3, r_4 are coprime to 6.
208: 
209: Assume a Core(5) configuration with this pattern. Take v = 2, translate so that g_2 = 1, and put X_j = U_2U_j for j ∈ {0, 1, 3, 4}.
210: 
211: **Step 1: sizes, and D_j = Y_j for j ∈ {1, 3, 4}.**
212: - By L0.3, |X_0| = α_20|G|/4 = |G|/4 and |X_1| = |X_3| = |X_4| = 3|G|/4.
213: - For j ∈ {1, 3, 4} put Y_j = G ∖ X_j, so |Y_j| = |G|/4.
214: - By (R1), D_j ⊆ Y_j. By (R2), |D_j| is a positive multiple of |G|/4.
215: - Hence D_j = Y_j, q_j = 1 and d_j = r_j.
216: 
217: **Step 2: Y_1, Y_3, Y_4 are pairwise disjoint.** If Y_j ∩ Y_k ≠ ∅ for distinct j, k ∈ {1, 3, 4}, then D_j ∩ D_k ≠ ∅. By (R5′), gcd(r_j, r_k) ≥ 2, contradicting coprimality.
218: 
219: **Step 3: X_0 ⊆ X_1 ∩ X_3 ∩ X_4.** Use rules-v1 L1 in the triangles {0, 1, 2}, {0, 2, 3} and {0, 2, 4}.
220: - In {0, 1, 2}: by (T2), τ ≤ α01·α02 = 1, so τ_012 = 1.
221: - In {0, 2, 3}: (T1) gives α03 = 2 | r_2 τ, and r_2 is odd, so τ is even. (T2) gives τ ≤ α02·α03 = 2. Hence τ_023 = 2. The same argument gives τ_024 = 2.
222: - By (T3) with apex 2:
223:   - |U_2(U_0∩U_1)| = τ_012|G|/(4α01) = |G|/4;
224:   - |U_2(U_0∩U_3)| = τ_023|G|/(4α03) = 2|G|/8 = |G|/4;
225:   - |U_2(U_0∩U_4)| = |G|/4.
226: - Each of these sets lies inside X_0 = U_2U_0, which has size |G|/4. So X_0 = U_2(U_0∩U_j) ⊆ U_2U_j = X_j for j = 1, 3, 4.
227: 
228: **Step 4: G ∖ X_0 = Y_1 ⊔ Y_3 ⊔ Y_4.**
229: - By Step 3, X_0 ∩ Y_j = ∅ for j = 1, 3, 4.
230: - By Step 2, |Y_1 ⊔ Y_3 ⊔ Y_4| = 3|G|/4 = |G ∖ X_0|.
231: 
232: **Step 5: the coset g_0U_0.**
233: - **Location.** By (R1), D_0 ⊆ G ∖ X_0. By (R2), |D_0| = q_0|G|/4 with q_0 ∈ {1, 2, 3}, and d_0 = q_0r_0.
234: - **D_0 meets some Y_j.** D_0 is non-empty, so by Step 4 it meets some Y_j = D_j with j ∈ {1, 3, 4}.
235: - **Gcd condition.** (R5′) gives gcd(q_0r_0, r_j) ≥ 2. Since gcd(r_0, r_j) = 1, gcd(q_0r_0, r_j) = gcd(q_0, r_j).
236:   - For j = 3, 4 the number r_j is coprime to 6, so gcd(q_0, r_j) = 1 for q_0 ∈ {1, 2, 3}. This is impossible.
237:   - So D_0 does not meet Y_3 or Y_4, and therefore D_0 ⊆ Y_1.
238: - **Contradiction (q_0 = 1 route).** Because |Y_1| = |G|/4, D_0 ⊆ Y_1 forces q_0 = 1. Then gcd(q_0, r_1) = gcd(1, r_1) = 1, which contradicts (R5′) for the pair {0, 1}.
239: - **Equivalent route (proof-v1).** gcd(q_0, r_1) ≥ 2 with r_1 even and 3 ∤ r_1 forces q_0 = 2, and then |D_0| = |G|/2 > |Y_1|.
240: 
241: So no configuration has the pattern S-D. ∎
