Write an independent Python3 STANDARD-LIBRARY verifier for an RDSQS(v) certificate, from ONLY the definition and format below. Do not use tools. Return exactly one fenced Python code block and nothing else. No asserts (checks must survive python -O), no writes, network or subprocess. Read the input bytes exactly once; verify the expected SHA-256 before parsing. CLI: checker.py EXPECTED_V FILE EXPECTED_SHA256. Print one JSON object; exit 0 iff valid; on invalid input print a precise invariant-specific reason and exit 1.
Definitions. A Steiner quadruple system SQS(v) is a set of 4-subsets (blocks) of V={0..v-1} such that every 3-subset of V lies in exactly one block. For x in V, the derived triple system at x is {B\{x} : x in B in blocks}; it is an STS(v-1) on V\{x}. A resolution of it is a partition of its triples into parallel classes, each class a partition of V\{x} into (v-1)/3 triples; there are (v-2)/2 classes. An RDSQS(v) is an SQS(v) whose derived system at EVERY point x is resolvable; the certificate gives an explicit resolution for every x.
Format (text, LF line endings, final LF; lines starting with '#' are comments anywhere and may contain any UTF-8; all other lines ASCII): first data line 'RDSQS v'; next 'BLOCKS'; then exactly v(v-1)(v-2)/24 lines of 4 distinct canonical decimal points separated by single spaces; then for x=0..v-1 in order: a line 'POINT x', and for j=0..(v-2)/2-1 in order a line 'CLASS j' followed by exactly (v-1)/3 lines of 3 distinct canonical decimal points. No other lines; reject trailing whitespace, blank data lines, CR, leading zeros.
Check everything directly: block count, distinct blocks, every 3-subset covered exactly once (compare with the full set of C(v,3) triples), every class triple is a derived triple at x and excludes x, each class partitions V\{x}, each derived triple appears in exactly one class at x, and all v points are resolved. Report counts (blocks, triples covered, points resolved, classes per point, triples per class).
