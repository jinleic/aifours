## Fill And Validate AcroForms

Visual review alone is not a correctness check for a fillable PDF. A page `/Widget` annotation can render a value from its appearance stream while the canonical `/AcroForm/Fields` tree is missing or contains a stale value.

1. Keep the result interactive by default; set `flatten=True` only when the user explicitly requests a completed, static form. Preserve the source PDF, and do not flatten a signed PDF without an explicit workflow decision.
2. Inspect both representations before filling: enumerate fields from `reader.get_fields()` and `/Widget` annotations from every page's `/Annots`, following `/Parent` and `/Kids`. If a widget and a canonical field have the same name but are distinct objects with no `/Parent` relationship, do not call `reattach_fields()` blindly: it can create a second top-level field with the same name. Report the ambiguity or produce a static result.
3. Recover genuinely orphaned widgets, fill all pages, and write the result with `pypdf`:

```python
from pypdf import PdfReader, PdfWriter
from pypdf.generic import NameObject

reader = PdfReader(input_pdf)
writer = PdfWriter()
writer.clone_document_from_reader(reader)

# Restores widgets that are missing from /AcroForm/Fields.
writer.reattach_fields()
fields = writer.get_fields() or {}
missing = set(expected_values) - set(fields)
if missing:
    raise ValueError(f"Form fields not found after repair: {sorted(missing)}")

values_to_write = dict(expected_values)
if flatten:
    # Paint every existing value before removing every widget.
    values_to_write = {
        name: field.get("/V", "/Off" if field.get("/FT") == "/Btn" else "")
        for name, field in fields.items()
    }
    values_to_write.update(expected_values)

writer.update_page_form_field_values(
    None, values_to_write, auto_regenerate=False, flatten=flatten
)

if flatten:
    # pypdf's flatten=True paints appearances but does not remove widgets.
    writer.remove_annotations(subtypes="/Widget")
    writer.root_object.pop(NameObject("/AcroForm"), None)

with open(output_pdf, "wb") as stream:
    writer.write(stream)
```

    52	Working definitions used below (restatements of Q-D1, Q-D2, Q-D3, Q-ISO and Q-D5 with lambda = 1):
    53	
    54	* A 2-(v,k,1) design is a pair D = (V, B), |V| = v, B a collection of k-subsets ("blocks") of V such that every
    55	  2-subset of V lies in exactly one block.

    57	* An automorphism of D is a permutation of V mapping B onto B. An automorphism of the resolution R is an
    58	  automorphism of D that maps every parallel class of R onto a parallel class of R (this is the notion used in the
    59	  source's definition of isomorphic resolutions).

    62	**Theorem.** Let D = (V, B) be any 2-(88,4,1) design and R any resolution of D. There is no permutation of V that is a
    63	single 88-cycle, maps B onto B, and maps every parallel class of R onto a parallel class of R. Equivalently, no
    64	2-(88,4,1) design is cyclically resolvable in the sense of the source.
    65	
    66	Basic counts (from the definition): b = 88*87/(4*3) = 638 blocks; every point lies in r = 87/3 = 29 blocks; every
    67	parallel class has 88/4 = 22 blocks; R has 638/22 = 29 classes.

    69	## 1. Setting
    70	
    71	Suppose, for a contradiction, that D, R and an 88-cycle sigma as in the Theorem exist. Fix a point x0 and label the
    72	point sigma^i(x0) by i in Z_88 (integers mod 88). Then sigma(x) = x + 1, and sigma^d(x) = x + d. For a subset X of
    73	Z_88 write X + d = {x + d : x in X}; for a set P of blocks write P + d = {X + d : X in P}. By hypothesis:
    74	
    75	(H1) B + d = B for every d (sigma^d maps blocks to blocks);
    76	(H2) for every class P in R and every d, P + d is a class of R;
    77	(H3) two distinct blocks share at most one point (lambda = 1: two shared points would be a pair in two blocks);
    78	(H4) the blocks of one class are pairwise disjoint.
    79	
    80	The group G = Z_88 acts on Z_88, on B and on R by translation. For a block X, Stab(X) = {d : X + d = X}; for a class
    81	P, Stab(P) = {d : P + d = P}. Both are subgroups of Z_88. For every divisor h of 88, Z_88 has exactly one subgroup of
    82	order h, namely H_h = {0, 88/h, 2*88/h, ...} (the multiples of 88/h). In particular
    83	H_2 = {0,44}, H_4 = {0,22,44,66}, H_11 = {0,8,16,...,80}, H_22 = {0,4,8,...,84}.
    84	
    85	## 2. Short blocks
    86	
    87	**Lemma 1 (translation lemma).** Let X be a block, x != y points of X, and d in Z_88 with x + d and y + d in X. Then
    88	d in Stab(X).
    89	
    90	Proof. X + d is a block by (H1) and contains x + d and y + d, which are two distinct points of X. By (H3), X + d = X.
    91	
    92	**Lemma 2 (block stabilizers).** Every block X has Stab(X) = {0} or Stab(X) = H_4. The blocks with Stab(X) = H_4 are
    93	exactly the 22 cosets a + H_4 = {a, a+22, a+44, a+66} (a = 0, ..., 21); all of them are blocks.
    94	
    95	Proof. Let K = Stab(X). X is a union of K-orbits on Z_88, and the K-orbits are the cosets of K, each of size |K|.
    96	Hence |K| divides |X| = 4, so K is {0}, H_2 or H_4 (the subgroups of order 1, 2, 4).
    97	If K = H_2, then X = {a, a+44, c, c+44} with c not in {a, a+44}. Apply Lemma 1 to x = a, y = a + 44, d = c - a:
    98	x + d = c and y + d = c + 44 lie in X, so c - a in K = H_2 = {0, 44}, i.e. c in {a, a+44}: contradiction.
    99	If K = H_4, X is a union of H_4-cosets of size 4, so X is one coset.
   100	Conversely let a in Z_88. The pair {a, a+44} lies in some block X (Def. 1). Apply Lemma 1 to x = a, y = a + 44,
   101	d = 44: x + d = a + 44 and y + d = a + 88 = a lie in X, so 44 in Stab(X); hence Stab(X) != {0}, so Stab(X) = H_4 and
   102	X is the coset of H_4 containing a, namely a + H_4. So every coset of H_4 is a block.
   103	
   104	Call the 22 blocks a + H_4 *short* and write S for the set of them; every other block has trivial stabilizer and is
   105	called *full*. S is a single G-orbit (a + H_4 = H_4 + a) and S + d = S for all d. The differences y - x of points
   106	x != y of a short block all lie in H_4 \ {0} = {22, 44, 66}.
   107	
   108	(Finite control: `check88.py` E1 enumerates all C(88,4) = 2,331,890 four-subsets; stabilizer orders occur as
   109	{1: 2,330,944; 2: 924; 4: 22}; the subsets compatible with (H1)+(H3) that have a nontrivial stabilizer, and those that
   110	contain a pair {x, x+44}, are in both cases exactly the 22 cosets of H_4.)

   112	## 3. Parallel classes and their stabilizers
   113	
   114	Let P be a class, Stab(P) = H_h (h | 88), and m = m(P) = number of short blocks in P (0 <= m <= 22).
   115	
   116	**Lemma 3.** (a) The G-orbit of P consists of 88/h distinct classes, so 88/h <= 29; hence h >= 4, i.e.
   117	h in {4, 8, 11, 22, 44, 88}.
   118	(b) h divides 22 - m.
   119	(c) (88/h) * m <= 22.
   120	
   121	Proof. (a) Orbit-stabilizer; R has 29 classes. 29*h >= 88 fails for h = 1, 2 (29, 58 < 88) and holds for h = 4 (116).
   122	(b) By (H2), P + d = P for d in H_h, so H_h permutes the blocks of P. For a full block X in P the map d -> X + d is
   123	injective on H_h (Stab(X) = {0}), so the H_h-orbit of X has exactly h blocks, all in P. These orbits partition the
   124	22 - m full blocks of P; hence h | 22 - m.
   125	(c) Translation maps short blocks to short blocks and full blocks to full blocks, so every class P + d has m short
   126	blocks. The 88/h classes of the orbit are distinct classes of a partition of B, hence pairwise disjoint, and they
   127	contain (88/h)*m distinct short blocks; there are only 22 short blocks.
   128	
   129	**Definition (type T1; review item m4).** As in the source (Q-T1, Appendix A: "T1—the short block orbit is a parallel
   130	class"), say that R has type T1 if the set S of short blocks is a class of R. Only this property is used below; the
   131	source's types T2 and T3 are not used.
   132	
   133	**Corollary 4 (no mixed class; R has type T1).** m(P) is 0 or 22 for every class P. Consequently exactly one class, P0,
   134	equals S, and every other class consists of full blocks only.
   135	
   136	Proof. Suppose 1 <= m <= 21. By (c), m <= 22h/88 = h/4, so h >= 4m. Check every h of (a):
   137	* h = 4: m <= 1, so m = 1; (b) requires 4 | 21. False.
   138	* h = 8: m <= 2; (b) requires 8 | 21 or 8 | 20. False.
   139	* h = 11: m <= 2; (b) requires 11 | 21 or 11 | 20. False.
   140	* h = 22: m <= 5; (b) requires 22 | 22 - m with 17 <= 22 - m <= 21. False.
   141	* h = 44: m <= 11; (b) requires 44 | 22 - m with 11 <= 22 - m <= 21. False.
   142	* h = 88: m <= 22; (b) requires 88 | 22 - m with 1 <= 22 - m <= 21. False.
   143	So m in {0, 22}. Every short block lies in some class, and a class with m = 22 consists of 22 short blocks, i.e. it
   144	is S. Classes are disjoint, so exactly one class equals S; every other class has m = 0.
   145	(Finite control: `check88.py` E2 lists all (h, m) with h | 88, 0 <= m <= 22 satisfying (a)-(c): exactly
   146	(11, 0), (22, 0), (88, 22).)

   148	of P is a nonempty translation-invariant subset of the single orbit S; then h = 4m, and h | 22 - m fails for
   149	m = 1, 2, 11 as well. The inequality suffices.)

   151	**Lemma 5 (stabilizers of the other classes).** If P != P0, then Stab(P) = H_11 or H_22. In both cases 8 in Stab(P).
   152	
   153	Proof. P0 = S satisfies P0 + d = P0 for all d, so P + d != P0 for all d: the orbit of P lies among the 28 classes

   155	so Lemma 3(b) gives h | 22. The divisors of 22 that are >= 4 are 11 and 22. 8 is a multiple of 88/11 = 8 and of
   156	88/22 = 4, so 8 lies in H_11 and in H_22.

   158	## 4. The forbidden difference
   159	
   160	**Lemma 6.** Let P be a class, X in P, and d in Stab(P). If x and x + d both lie in X, then d in Stab(X). In
   161	particular a full block of a class P never contains two points x, x + d with d in Stab(P) \ {0}.
   162	
   163	Proof. X + d is a block of P + d = P and contains x + d; X also contains x + d. Blocks of P are disjoint (H4), so
   164	X + d = X.

   166	## 5. Proof of the Theorem
   167	
   168	The pair {0, 8} lies in a block X (Def. 1). X is not short: 8 - 0 = 8 is not in {22, 44, 66}. So X is full; X lies

   170	Lemma 6 with x = 0, d = 8, the full block X cannot contain both 0 and 8. Contradiction. Hence no such D, R, sigma

Point-Cyclic Resolutions of 2-(64, 4, 1) Designs
Svetlana Topalova 1,2                and Stela Zhelezova 1, *

                                          1   Institute of Mathematics and Informatics, Bulgarian Academy of Sciences, 1113 Sofia, Bulgaria;
                                              svetlana@math.bas.bg
                                          2   Centre of Excellence in Informatics and Information and Communication Technologies, 1113 Sofia, Bulgaria
                                          *   Correspondence: stela@math.bas.bg


                                          Abstract
                                          A point-cyclic resolution of a 2-(v, k, 1) design is invariant under a cyclic automorphism
                                          group of order v. Point-cyclic resolutions are of interest for their relations to many other
                                          combinatorial structures, and for their various applications. Resolutions of 2-(v, 4, 1)
                                          designs can exist if v ≡ 4 (mod 12). There are six point-cyclic resolutions of 2-(v, 4, 1)
                                          designs with v < 64. Before the present study, v = 64 was the smallest v for which neither
                                          theoretical nor constructive results on the existence of point-cyclic resolutions of 2-(v, 4, 1)
                                          designs were known. We establish that there are 258 point-cyclic resolutions of 2-(64, 4, 1)
                                          designs. The investigation is computer-aided.

                                          Keywords: combinatorial design; cyclically resolvable; point-cyclic resolution; Steiner
                                          system

                       The resolutions of the 2-(64,4,1) designs that we consider possess many automorphisms, too.
                       They are point-cyclic, namely invariant under the cyclic automorphism of the underlying
                       cyclic design. A design with at least one point-cyclic resolution is called cyclically resolv-
                       able [5–7]. In some papers, the term cyclically resolvable has been used for designs with
                       resolutions that are invariant under an automorphism group that maps the parallel classes
                       to one another [8–10]. This is a property that we do not consider. In the present paper, when
                       we talk about cyclically resolvable designs, we mean designs with point-cyclic resolutions.
                             An important application of cyclically resolvable 2-(v,4,1) designs is the one in low-
                       density parity-check (LDPC) codes [11]. The incidence matrix of a 2-(v,k,1) design can
                       be used as a parity-check matrix of a binary (k, r)-regular LDPC code with v parity-check
                       equations, b codeword bits, row weight r and column weight k [12], and, in particular,
                       resolvable 2-(v,4,1) designs provide an algebraic construction method for a large class of
                       regular LDPC codes with minimum distance ≥ 5 avoiding cycles of size smaller than
                       five, which is a desirable property [11]. If the Steiner 2-design is cyclic, linear-complexity
                       encoding with simple feedback shift registers is possible [13,14]. The usage of resolutions
                       of Steiner 2-designs also allows for a reduction in the row weight of the LDPC code by
                       removing some columns of the parity-check matrix in such a way that the same number of
                       ones are cut off from each row (true if one or several parallel classes are removed) to obtain
                       a lower rate code without changing the other code properties [11–13]. The resultant code
                       might have a cyclic structure if a suitable point-cyclic resolution is used.
                             Cyclically resolvable Steiner 2-designs are related to group-testing algorithms too.
                       They provide combinatorial constructions for efficient two-stage group-testing algorithms
                       with applications in fast genetic screening [15].

                       1.2. Known Results and Motivation
                             For the basic knowledge on 2-(v,k,1) designs and their resolutions, refer, for instance,
                       to [16–18]. Point-cyclic resolutions of 2-(v,k,1) designs can exist for cyclic Steiner 2-designs
                       with v ≡ k (mod k(k − 1)) [5]. In that case, under the cyclic automorphism group of
                       order v, the cyclic designs have one short block orbit of length v/k and ⌊ k(vk−−11) ⌋ full
                       block orbits of length v. Different properties and some general constructions of cyclically
                       resolvable designs are considered in [5–7]. An important necessary condition says that
                       if a 2-(v,k,1) design possesses point-cyclic resolutions and v/k is a prime number, then
                       v
                        k ≡ 1 (mod k ( k − 1)) [5].
                             A 2-(v,4,1) design exists if and only if v ≡ 1, 4 (mod 12) [19]. Cyclic 2-(v,4,1) designs
                       exist for every v ≡ 1, 4 (mod 12) except for v ∈ {16, 25, 28} [20]. A resolvable 2-(v,4,1)
                       design exists if and only if v ≡ 4 (mod 12) [21].
                             The main existence result for cyclically resolvable Steiner 2-designs with block size 4
                       is derived in [6]. It states that there exist cyclically resolvable 2-(v,4,1) designs for v = 4q,
                       where q is a product of primes of the form 12s + 1, and s is odd. This result, however, does
                       not concern v = 64.
                             The smallest cyclically resolvable 2-(v,3,1) design has 21 points, and the smallest cycli-
                       cally resolvable 2-(v,4,1) design has 52 points. The 2-(64,4,1) designs have the parameters
                       of the point-line design of the affine space AG(3, 4), but the latter is not cyclic and therefore
                       none of the 12,048 cyclic 2-(64,4,1) designs correspond to AG(3, 4).
                             Constructive classification results are important for possible applications of these
                       resolutions. Point-cyclic resolutions of 2-(v,3,1) designs (STS(v)s) have been constructively
                       classified for all v ≤ 57 [22–25]. For 2-(v,4,1) designs, a constructive classification is available
                       for v ≤ 52 [26]. The next possible parameter is v = 64, for which, before the present paper’s

                       Definition 3. An automorphism of the design D = (V, B) is a permutation of the points of V
                       preserving B .

                            Two resolutions are isomorphic if there is an automorphism of the underlying design
                       that maps each parallel class of the first resolution to a parallel class of the second one.

                       Definition 4. A 2-(v,k,λ) design is cyclic if it is invariant under a cyclic automorphism group of
                       order v.

                            The blocks of a resolvable cyclic 2-(v,k,1) design are in ⌈ k(vk−−11) ⌉ orbits under the cyclic
                       automorphism group of order v. One of these orbits is the unique short block orbit. It is of
                       length v/k. The other orbits are full block orbits of length v.

                       Definition 5. A resolution is point-cyclic if it has an automorphism permuting the points in one
                       cycle. A 2-(v,k,λ) design is cyclically resolvable if it has at least one point-cyclic resolution.

                            The design presented in Figure 1 is resolvable but is not cyclically resolvable. Only
                       cyclic designs can be cyclically resolvable. There are, however, many cyclic designs that are
                       not cyclically resolvable.

                       1.4. Content and Structure of the Paper
                            The aim of the present work is to construct all point-cyclic resolutions of 2-(64,4,1)
                       designs. That is why in Sections 2 and 3 we first study in detail the properties of the
                       cyclic designs with these parameters and of their point-cyclic resolutions. The construction
                       method is described in Section 4. We use two different software approaches implemented
                       in C + + by the two authors. For the investigations on the subgroups, we also use the com-
                       puter algebra system GAP [27]. The obtained results are described in Section 5. Approaches
                       of other authors and the correctness of the obtained results are the subject of Section 6, and
                       Section 7 contains several concluding remarks.

                       3. Parallel Class Orbits Under G
                            According to the relation between the short block orbit of a cyclic design and its
                       resolution, three types of point-cyclic resolutions are defined in [30]:
                       •         T1—the short block orbit is a parallel class;
                       •         T2—each block from the short block orbit is in a different parallel class;
                       •         T3—there are parallel classes with more than one block from the short block orbit.
                            In [7], Lemmas 4.1 and 4.2 give necessary conditions for the existence of cyclically
                       resolvable cyclic Steiner 2-designs with point-cyclic resolutions of types T2 and T3, respec-
                       tively. The parameters of cyclic 2-(64,4,1) designs do not satisfy these conditions. Thus, the
                       point-cyclic resolutions of a cyclic 2-(64,4,1) design are only of type T1, namely one of their
                       parallel classes is the short block orbit.

                            A resolution of a 2-(64,4,1) design has 21 parallel classes. We want to find out what the

                       Theorem 1. The parallel classes of a point-cyclic resolution of a cyclic 2-(64,4,1) design are in three
                       orbits under G with orbit lengths 1, 4, and 16.

                       Proof. In a point-cyclic resolution of a 2-(64,4,1) design, the short block orbit under G is a
                       parallel class that includes all short block orbits of each subgroup of G. That is why a non-
                       fixed parallel class contains only blocks from full block orbits under G and its subgroups.
                       The number of parallel classes is 21, among which there are 20 non-fixed classes, and
                       therefore the length of a class orbit is at most 20. Since the order of the automorphism group
                       G is 64 > 20, a non-fixed-under-G parallel class must be fixed under some of the subgroups
                       of G. From here to the end of the proof, parallel class will mean a non-fixed-under-G
                       parallel class.
                             Consider the biggest subgroup Gi , which fixes a parallel class. Then, the blocks of this
                       parallel class can be partitioned into full block orbits (of length i) under this subgroup (all
                       short orbits are in the fixed parallel class). There are 16 blocks in a parallel class. Therefore,
                       i ≤ 16, namely a non-fixed parallel class cannot be invariant under G32 . The subgroup G2
                       cannot be the biggest group under which the parallel class is invariant because in that case
                       its class orbit length would be 64/2 = 32 > 20. If the biggest subgroup under which the
                       parallel class is invariant is Gi , the class contains 16/i full block orbits under Gi and its class
                       orbit is of length 64/i. That is why the biggest subgroup under which a non-fixed parallel
                       class is invariant can be G4 , G8 or G16 . Then, the parallel class consists of 4, 2, or 1 full block
                       orbits under this group, and the parallel class orbits are of lengths 16, 8 or 4, respectively.
                             Consider an orbit of 64/i parallel classes invariant under Gi . Each of these classes
                       consists of 16/i block orbits of length i under Gi . Thus, the parallel classes of this orbit
                       contain altogether 64i 16i block orbits of length i under Gi . A parallel class orbit of length 16
                       contains 64 class-like block orbits under G4 . It can be seen from Table 2 that the number of
                       class-like block orbits under G4 is 80 for all the considered designs. This means that there
                       can be at most one class orbit of length 16. Class orbits of length 8 contain 16 class-like
                       orbits under G8 . The maximum number of class-like block orbits under G8 is 32 (Table 2).
                       Therefore, there can be at most two class orbits of length 8. There are four class-like block
                       orbits of length 16 under G16 in a parallel class orbit of length 4. Table 2 shows that the
                       maximum number of class-like block orbits under G16 is eight. That is why there can be at
                       most two parallel class orbits of length 4.
                             It follows that a point-cyclic resolution can have at most two parallel class orbits of
                       length 4, at most two of length 8, and at most one of length 16. There are 21 blocks. That is
                       why there are only two possibilities for the class orbit lengths, namely 1, 4, 16 and 1, 4, 8, 8.
                       Two orbits of length 8 are only possible for the 128 designs of the fourth set because they
                       have 32 class-like orbits under G8 , while the other designs have 24 (Table 2). The designs
                       of sets 1 and 4, however, have no class-like orbits under G16 , and therefore parallel class
                       orbits of length 4 are not possible for them (Table 2). Therefore, 1, 4, 8, 8 is impossible for
                       set 4. The only possibility for the lengths of the parallel class orbits is 1, 4, 16, and there can
                       be cyclically resolvable designs only in the second and third sets of cyclic 2-(64,4,1) designs
                       because parallel class orbits of length 4 are not possible for sets 1 and 4.

                       4. Construction Method
                             Only cyclic designs can be cyclically resolvable. That is why we construct point-cyclic
                       resolutions of the cyclic 2-(64,4,1) designs. We do this in two different ways in order to
                       partially test the correctness of the computer-aided results. We will briefly describe the two
                       algorithms that are used.
                             The point-cyclic resolutions are constructed by exhaustive backtrack search algorithms.
                       Backtrack search is exponential [31], so the computation time grows very fast with the
                       parameters. Backtrack search can be, however, successfully used for the construction of
                       structures with relatively small parameters if some parameter-specific restrictions are used,
                       and some of the equivalent partial solutions are rejected. To implement such a rejection,

                       6. Discussion
                             The point-cyclic resolutions of 2-(52, 4, 1) designs have been obtained in [26] by a
                       method differing from our construction approach described in Section 4. To explain its
                       main ideas, we first need the following definition.
                             Consider a design with an automorphism α of a prime order p, where the points are
                       partitioned into m, and the blocks into n orbits under α. The orbit matrix M = (mi,j ) under
                       α is of dimension m × n and its element mi,j equals the number of points from the i-th point
                       orbit, which are incident with any block from the j-th block orbit.
                             In [26], the authors derive the necessary conditions that should hold for an orbit matrix
                       of a cyclically resolvable 2-(52, 4, 1) design under an automorphism of order 13 from its
                       cyclic automorphism group of order 52. So, they first construct all the possible such orbit
                       matrices (there are three), and then the point-cyclic resolutions. They establish that only six
                       of the 206 cyclic 2-(52, 4, 1) designs admit one of these orbit matrices.
                             As a partial check of the correctness of our construction approach, we obtain once again
                       the results for 2-(52, 4, 1) designs by using the algorithms from Section 4. We apply both
                       algorithms to the 206 cyclic designs. The second algorithm uses the fact that the parallel
                       classes of a point-cyclic resolution of a design with these parameters are in two orbits of
                       lengths 4 and 13 [26], while the first algorithm considers the general case. We obtain that
                       there are six 2-(52, 4, 1) designs, each of which possesses one point-cyclic resolution, namely
                       the same result as in [26].

                       Definition 3. An automorphism of the design D = (V, B) is a permutation of the points of V
                       preserving B .

                            Two resolutions are isomorphic if there is an automorphism of the underlying design
                       that maps each parallel class of the first resolution to a parallel class of the second one.

                       Definition 4. A 2-(v,k,λ) design is cyclic if it is invariant under a cyclic automorphism group of
                       order v.

                            The blocks of a resolvable cyclic 2-(v,k,1) design are in ⌈ k(vk−−11) ⌉ orbits under the cyclic
                       automorphism group of order v. One of these orbits is the unique short block orbit. It is of
                       length v/k. The other orbits are full block orbits of length v.

                       Definition 5. A resolution is point-cyclic if it has an automorphism permuting the points in one
                       cycle. A 2-(v,k,λ) design is cyclically resolvable if it has at least one point-cyclic resolution.

                            The design presented in Figure 1 is resolvable but is not cyclically resolvable. Only
                       cyclic designs can be cyclically resolvable. There are, however, many cyclic designs that are
                       not cyclically resolvable.

                       3. Parallel Class Orbits Under G
                            According to the relation between the short block orbit of a cyclic design and its
                       resolution, three types of point-cyclic resolutions are defined in [30]:
                       •         T1—the short block orbit is a parallel class;
                       •         T2—each block from the short block orbit is in a different parallel class;
                       •         T3—there are parallel classes with more than one block from the short block orbit.
                            In [7], Lemmas 4.1 and 4.2 give necessary conditions for the existence of cyclically
                       resolvable cyclic Steiner 2-designs with point-cyclic resolutions of types T2 and T3, respec-
                       tively. The parameters of cyclic 2-(64,4,1) designs do not satisfy these conditions. Thus, the
                       point-cyclic resolutions of a cyclic 2-(64,4,1) design are only of type T1, namely one of their
                       parallel classes is the short block orbit.

                       Theorem 1. The parallel classes of a point-cyclic resolution of a cyclic 2-(64,4,1) design are in three
                       orbits under G with orbit lengths 1, 4, and 16.

                       Proof. In a point-cyclic resolution of a 2-(64,4,1) design, the short block orbit under G is a
                       parallel class that includes all short block orbits of each subgroup of G. That is why a non-
                       fixed parallel class contains only blocks from full block orbits under G and its subgroups.
                       The number of parallel classes is 21, among which there are 20 non-fixed classes, and
                       therefore the length of a class orbit is at most 20. Since the order of the automorphism group
                       G is 64 > 20, a non-fixed-under-G parallel class must be fixed under some of the subgroups
                       of G. From here to the end of the proof, parallel class will mean a non-fixed-under-G
                       parallel class.
                             Consider the biggest subgroup Gi , which fixes a parallel class. Then, the blocks of this
                       parallel class can be partitioned into full block orbits (of length i) under this subgroup (all
                       short orbits are in the fixed parallel class). There are 16 blocks in a parallel class. Therefore,
                       i ≤ 16, namely a non-fixed parallel class cannot be invariant under G32 . The subgroup G2
                       cannot be the biggest group under which the parallel class is invariant because in that case
                       its class orbit length would be 64/2 = 32 > 20. If the biggest subgroup under which the
                       parallel class is invariant is Gi , the class contains 16/i full block orbits under Gi and its class
                       orbit is of length 64/i. That is why the biggest subgroup under which a non-fixed parallel
                       class is invariant can be G4 , G8 or G16 . Then, the parallel class consists of 4, 2, or 1 full block
                       orbits under this group, and the parallel class orbits are of lengths 16, 8 or 4, respectively.
                             Consider an orbit of 64/i parallel classes invariant under Gi . Each of these classes
                       consists of 16/i block orbits of length i under Gi . Thus, the parallel classes of this orbit
                       contain altogether 64i 16i block orbits of length i under Gi . A parallel class orbit of length 16
                       contains 64 class-like block orbits under G4 . It can be seen from Table 2 that the number of
                       class-like block orbits under G4 is 80 for all the considered designs. This means that there
                       can be at most one class orbit of length 16. Class orbits of length 8 contain 16 class-like
                       orbits under G8 . The maximum number of class-like block orbits under G8 is 32 (Table 2).
                       Therefore, there can be at most two class orbits of length 8. There are four class-like block
                       orbits of length 16 under G16 in a parallel class orbit of length 4. Table 2 shows that the
                       maximum number of class-like block orbits under G16 is eight. That is why there can be at
                       most two parallel class orbits of length 4.
                             It follows that a point-cyclic resolution can have at most two parallel class orbits of
                       length 4, at most two of length 8, and at most one of length 16. There are 21 blocks. That is
                       why there are only two possibilities for the class orbit lengths, namely 1, 4, 16 and 1, 4, 8, 8.
                       Two orbits of length 8 are only possible for the 128 designs of the fourth set because they
                       have 32 class-like orbits under G8 , while the other designs have 24 (Table 2). The designs
                       of sets 1 and 4, however, have no class-like orbits under G16 , and therefore parallel class
                       orbits of length 4 are not possible for them (Table 2). Therefore, 1, 4, 8, 8 is impossible for

                       4. Construction Method
                             Only cyclic designs can be cyclically resolvable. That is why we construct point-cyclic
                       resolutions of the cyclic 2-(64,4,1) designs. We do this in two different ways in order to
                       partially test the correctness of the computer-aided results. We will briefly describe the two
                       algorithms that are used.
                             The point-cyclic resolutions are constructed by exhaustive backtrack search algorithms.
                       Backtrack search is exponential [31], so the computation time grows very fast with the
                       parameters. Backtrack search can be, however, successfully used for the construction of
                       structures with relatively small parameters if some parameter-specific restrictions are used,
                       and some of the equivalent partial solutions are rejected. To implement such a rejection,
                       both algorithms define a lexicographic order on the partial solutions. It is based on a
                       lexicographic order on the blocks and the points that they contain. The applied test for
                       equivalence of partial solutions is in fact a minimality test. Such a test rejects a partial
                       solution if there is an automorphism of the design that maps the current partial resolution
                       to a lexicographically smaller partial solution. The test checks all the automorphisms of the
                       design. For all the considered cyclic 2-(64, 4, 1) designs, these are the automorphisms from
                       the cyclic group G of order 64. In the pseudo-codes presented below, the functions per-
                       forming the minimality test are NewSolution and NewResolution. The first one performs
                       the check when all the blocks of a parallel class are chosen, and the second when a whole
                       resolution is constructed.

                                          Abstract
                                          A point-cyclic resolution of a 2-(v, k, 1) design is invariant under a cyclic automorphism
                                          group of order v. Point-cyclic resolutions are of interest for their relations to many other
                                          combinatorial structures, and for their various applications. Resolutions of 2-(v, 4, 1)
                                          designs can exist if v ≡ 4 (mod 12). There are six point-cyclic resolutions of 2-(v, 4, 1)
                                          designs with v < 64. Before the present study, v = 64 was the smallest v for which neither
                                          theoretical nor constructive results on the existence of point-cyclic resolutions of 2-(v, 4, 1)
                                          designs were known. We establish that there are 258 point-cyclic resolutions of 2-(64, 4, 1)
                                          designs. The investigation is computer-aided.
