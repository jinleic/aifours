Write an independent Python3 STANDARD-LIBRARY verifier for a gcDCQS(g^n : 0) certificate, from ONLY the definition and format below. Do not use tools. Return exactly one fenced Python code block and nothing else. No asserts (checks must survive python -O), no writes, network or subprocess. Read the input bytes exactly once; verify the expected SHA-256 before parsing. CLI: checker.py EXPECTED_V EXPECTED_N EXPECTED_G FILE EXPECTED_SHA256. Print one JSON object; exit 0 iff valid; on invalid input print a precise invariant-specific reason and exit 1.

Definitions. Points X = {0..v-1}, v = n*g, partitioned into n groups of size g (n >= 3); the stem is empty. A candelabra quadruple system CQS(g^n : 0) is a set of 4-subsets (blocks) of X such that every 3-subset of X that is NOT contained in a single group lies in exactly one block, and no 3-subset contained in a group lies in any block. For a point x with group G(x), the derived design at x is A_x = {B \ {x} : x in B}; it is a set of triples on X \ {x}, and the hole at x is H_x = G(x) \ {x}. Let w = v-1 and h = g-1. chi'(w) = (w-1)/2 if w = 3 (mod 6); chi'(w) = (w+1)/2 if w = 1 (mod 6) and w not in {7, 13}; chi'(7) = 7; chi'(13) = 8; other w are invalid. A good colouring of A_x is a partition of A_x into exactly r = chi'(w) nonempty classes, each class a set of pairwise disjoint triples, such that exactly s = r - (w-h)/2 classes contain no point of H_x. A gcDCQS(g^n : 0) is a CQS(g^n : 0) together with a good colouring of A_x for EVERY point x.

Format (text, LF line endings, final LF; lines starting with '#' are comments anywhere and may contain any UTF-8; all other lines ASCII; blank lines are not allowed): first data line 'GCDCQS v n g'; then 'COLOURS r'; then 'HOLEFREE s'; then 'GROUPS' followed by exactly n lines of g distinct canonical decimal points; then 'BLOCKS' followed by exactly (C(v,3) - n*C(g,3))/4 lines of 4 distinct canonical decimal points; then, for x = 0..v-1 in increasing order, a line 'POINT x' and, for j = 0..r-1 in order, a line 'CLASS j' followed by one or more lines of 3 distinct canonical decimal points (the triples of class j at x). Tokens are separated by single spaces. No other lines; reject trailing whitespace, CR, leading zeros, signs, wrong header values.

Check everything directly: header values equal the expected v, n, g and the derived r and s; the groups partition X; block count; distinct blocks; no block contains three points of one group; every non-group 3-subset covered exactly once (compare with the explicit set of all such 3-subsets); every listed triple at x avoids x and is a derived triple at x; each class consists of pairwise disjoint triples; each derived triple appears in exactly one class at x; all v points are coloured; exactly s hole-free classes at every x. Report counts (blocks, non-group triples covered, points coloured, classes per point, the multiset of class sizes per point, hole-free classes per point).
