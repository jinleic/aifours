167: **Theorem SEED-G.**  Let w be an NMH word with R <= 2p - 3 (p >= 5 prime; in particular any item-(iii) word) that satisfies (i) or
168: (ii+) of Lemma C0+, and suppose that for every run t of w either a quality seed is established, or seeds of t obtained by Lemma GS (a)
169: from actual configurations have empty intersection.  Then w has an identity 2p-subword.
170: Proof.  Suppose w avoids; take the canonical lifts.  If some run t has seeds from Lemma GS (a) with empty intersection, x_t would lie in
171: all of them: impossible.  Otherwise every run has a quality seed.  By Lemmas SCW-G and SL, X_Q >= lambda(Q) for every proper Q with |Q| >= 2, x_t >=
172: lambda({t}) by the choice of the lifts, and sum_t x_t = X_[k] = p.  Lemma C0+ gives a contradiction.  []

182: ## 4. Configurations, Corollaries SA and PA

184: **Lemma CF (configurations).**  Let w be an NMH word with R <= 2p - 3, t a run, n_al the number of aligned runs (n_al = k - B + e_an
185: >= k - B, where e_an := sum_anti (b_u - 1), since n_an + n_pr = B - e_an), e_t := r_t - 1 the excess of t.  Delete t and its two
186: neighbours; the remaining k - 3 runs form a path whose two ends t + 2, t - 2 are not adjacent in the cycle (their cyclic distance is
187: min(4, k - 4) >= 2, as k >= 2kappa + 3 >= 7 in the setting).
188:  (SA) If 1 <= m <= ceil((n_al - 3)/2), there are m pairwise non-adjacent aligned runs, none adjacent to t: the aligned runs of the
189:       path lie in maximal intervals of consecutive aligned runs of lengths L_i with sum L_i >= n_al - 3; take every other run of each
190:       interval, ceil(L_i/2) >= L_i/2 of them (runs from different intervals are separated by a run of the path).
191:  (PA) If 1 <= m <= ceil((n_al - B - 4)/3), there are m pairwise non-adjacent blocks {u, u + 1} of two adjacent aligned runs, none
192:       adjacent to t: the path contains at most n_an + n_pr <= B non-aligned runs, hence at most B + 1 maximal aligned intervals; an
193:       interval of length L contains floor((L + 1)/3) >= (L - 1)/3 blocks {l, l + 1}, {l + 3, l + 4}, ...
194:  In both cases Q (the union) has m blocks, Q + t has m + 1 blocks, and both are proper (2m + 2 <= k).  Its type: y := D_Q is the
195:  number of letters of the chosen runs, m <= y <= m + E - e_t (SA), resp. 2m <= y <= 2m + E - e_t (PA), since the chosen runs carry
196:  at most E - e_t excess letters; in particular y + d_t <= m + E + 1, resp. 2m + E + 1 (for an aligned t, d_t = e_t + 1; otherwise
197:  d_t <= 0).  (In a word without excess y = m, resp. 2m.)
198: **Corollary SA.**  Let (p, k, kappa, B) be the parameters of an NMH word w with R <= 2p - 3, E := R - k, b* := min(B, E + 1) (or any
199: upper bound for the lengths of the anti runs of w), and suppose some integer m satisfies
200:    (SA)  max(ceil((2kB + B + max(2, b*))/3), B + 2 - Delta0, 1) <= m <= min(floor((2p - B - E - 3)/3), Delta0 + B - b* - 2,
201:          ceil((k - B - 3)/2)).
202: Then every run of w has a quality seed (or seeds from actual configurations with empty intersection, which exclude w); if w
203: satisfies (i) or (ii+), w has an identity 2p-subword.
204: Proof.  For every run t take Q as in Lemma CF (SA) (m <= ceil((k - B - 3)/2) <= ceil((n_al - 3)/2)).  We show that Q and Q + t are
205: generic; Lemma GS (b) and Theorem SEED-G then finish.  Write d := d_t, so -b* <= d <= E + 1 and m <= y <= m + E, y + d <= m + E + 1,
206: and recall that a minimum equals its third term iff the other terms are >= it.  With floor(a/2) <= a/2:
207:  lambda(Q) = floor((y + B)/2) + 1: (a1) floor((y + B)/2) + 1 <= p - m + 1 follows from 3m + E + B <= 2p; (a2) floor((y + B)/2) + 1 <=
208:    y + m - kB: the difference RHS - LHS is non-decreasing in y, so y = m is worst, and (m + B)/2 + 1 <= 2m - kB is 3m >= 2kB + B + 2.
209:  lambda(Q + t) = floor((y + d + B)/2) + 1 (Q + t has m + 1 blocks): (b1) <= p - m follows from (y + d + B)/2 + 1 <= (m + E + 1 + B)/2 + 1
210:    <= p - m, i.e. 3m <= 2p - B - E - 3; (b2) <= y + d + m + 1 - kB: worst at the least y + d = m - b*, where (m - b* + B)/2 <=
211:    2m - b* - kB is 3m >= 2kB + B + b*.
212:  lambda(Q^c) = floor((A - y)/2) + 1: (c1) <= p - m + 1 follows from (A - y)/2 <= p - m, worst y = m: m <= 2p - A = Delta0 + B;
213:    (c2) <= A - kappa - y + m: RHS - LHS is non-increasing in y, worst y = m + E: (A - m - E)/2 + 1 <= A - kappa - E is
214:    m >= 2kappa + 2 - A + E = B + 2 - Delta0 (A - 2kappa = Delta0 + E - B).
215:  lambda((Q + t)^c) = floor((A - y - d)/2) + 1: (d1) <= p - (m + 1) + 1 = p - m: worst y + d = m - b*: (A - m + b*)/2 + 1 <= p - m is
216:    m <= Delta0 + B - b* - 2; (d2) <= A - kappa - (y + d) + m + 1: worst y + d = m + E + 1: m >= B + 1 - Delta0.
217:  (a1) and (c1) are implied by (b1) and (d1).  All hold under (SA).  []
218: **Corollary PA.**  Same setting.  Suppose Delta0 >= B + 1, b* <= Delta0 + B - 1 and some integer m satisfies
219:    (PA)  max(ceil((kB + floor(B/2) + 1)/2), ceil((kB + b* + floor((B - b*)/2))/2), 1) <= m
220:          <= min(floor((p - 1 - floor((E + B + 1)/2))/2), ceil((k - 2B - 4)/3)).
221: Then every run of w has a quality seed (or seeds from actual configurations with empty intersection, which exclude w); if w
222: satisfies (i) or (ii+), w has an identity 2p-subword.
223: Proof.  Q as in Lemma CF (PA) (m <= ceil((k - 2B - 4)/3) <= ceil((n_al - B - 4)/3)); 2m <= y <= 2m + E, y + d <= 2m + E + 1, d >= -b*.
224:  (a1) floor((y + B)/2) + 1 <= p - m + 1: worst y = 2m + E: m + floor((E + B)/2) <= p - m, implied by (b1).  (a2) floor((y + B)/2) + 1
225:  <= y + m - kB: worst y = 2m: m + floor(B/2) + 1 <= 3m - kB.  (b1) floor((y + d + B)/2) + 1 <= p - m: worst y + d = 2m + E + 1:
226:  m + floor((E + B + 1)/2) + 1 <= p - m.  (b2) floor((y + d + B)/2) + 1 <= y + d + m + 1 - kB: worst y + d = 2m - b*:
227:  m + floor((B - b*)/2) <= 3m - b* - kB.  (c1) floor((A - y)/2) + 1 <= p - m + 1: worst y = 2m: floor(A/2) <= p (A <= 2p - 1).
228:  (c2) floor((A - y)/2) + 1 <= A - kappa - y + m: worst y = 2m + E: floor((A - E)/2) + 1 <= A - kappa - E, i.e. ceil((A - E)/2) >= kappa + 1,
229:  i.e. A - E >= 2kappa + 1, i.e. Delta0 >= B + 1.  (d1) floor((A - y - d)/2) + 1 <= p - m: worst y + d = 2m - b*: floor((A + b*)/2) <= p - 1,
230:  i.e. b* <= 2p - 1 - A = Delta0 + B - 1.  (d2) floor((A - y - d)/2) + 1 <= A - kappa - (y + d) + m + 1: worst y + d = 2m + E + 1:
231:  ceil((A - E - 1)/2) >= kappa, i.e. Delta0 >= B.  (Monotonicity as in Corollary SA.)  Lemma GS (b), Theorem SEED-G.  []
232: Remark.  For E = 0 (all single letters, b* = 1) Corollary SA is the singles case of SEED-B's Lemma IS with the weaker condition
233: m >= B + 2 - Delta0 in place of delta >= 2B + 2; Corollary PA is its pairs case.  The regions are monotone in b*: a class satisfying
234: them with b* = min(B, E + 1) satisfies them for every word of the class, with the same m.
