145: **Theorem K0*.**  Let p >= 5 be prime and w a word of length 4p - 2 over D_(2p) whose rotation letters all lie in one set

151: g >= 1 genuine empty runs and avoids.  By (Z0) and kappa = 0: B = 0 (all rotations rho_1), R = 2p - o_F, 1 <= o_F.

153: Step 1 (FUS process).  While some genuine empty run is adjacent to an even block, apply a FUS step there.  Each step preserves
154: avoidance, the length, every rotation, and lowers g by >= 1.  It never performs an odd-odd double fusion: that would give an
155: avoider with kappa = -1, contradicting (Pairs).  So kappa stays 0 and B stays 0.  Let w_end be the final word.
156: Step 2 (w_end has no empty run).  Otherwise every empty run of w_end lies between two odd blocks, and no even block of w_end is
157: adjacent to an empty run.  Apply PM0 across every even block (both neighbouring runs are nonempty): each step preserves avoidance
158: and kappa = 0, keeps every empty run and the odd parity of its neighbours, and creates no even block next to an empty run.  The
159: resulting avoider has e_F = 0 and e_R >= g >= 1 > e_F + 2 kappa, contradicting (P0).

161: avoider w' (kappa(w') = 0, B = 0, g(w') >= 1).  A FUS step at an empty run R_t recolours an even neighbour, which then fuses with
162: the block on its other side only through a second empty run; so either
163:  (C1) g(w') = 1: one empty run R_t, and at least one of S_(t-1), S_t is even; or
164:  (C2) g(w') = 2: S_(t-1) = sigma_u^a, R_t empty, S_t = sigma_v^b with b even, R_(t+1) empty, S_(t+1) = sigma_u^c, u != v, and
165:       a, c not both odd (kappa = 0).

168: e_F, e_R, R, r_i for its own decomposition).  Now every even block of w'' is adjacent to an empty run, so its even blocks lie in

124: ## 5. Theorem RED
125: 
126: Define RES_<(p): G-words of length 4p - 2 (rotations rho_1, rho_-1; normalised A >= B) with at least one (genuine) empty run,
127: every maximal constant block of ODD length, every rotation run pure (only rho_1 or only rho_-1) or empty, and B < kappa.
128: **Theorem RED.**  Assume (I1)-(I4).  If REFL(p) fails, some word of RES_<(p) with kappa >= 2 is an avoider.  Conversely every
129: avoider in RES_<(p) violates REFL(p).  Hence REFL(p) <=> RES_<(p) contains no avoider with kappa >= 2.
130: Proof.  Let w0 be an avoider violating REFL(p); normalise x = 1 and A >= B.  It is a G-word with g >= 1 (F >= 2, R >= 1 as before).
131: Run the following process; every move preserves avoidance, the length and rigidity of rotations; A >= B is kept (TR keeps A, B;
132: M0' lowers both by 1; the other moves keep them).  At every state with g >= 1, kappa >= 1 by Theorem K0*.
133:  P1 (FUS) at an empty run adjacent to an even block.
134:  P2 (PM0) across an even block whose two neighbouring runs are nonempty.
135:  P3 (TR-fill) if some run has a, b >= 1 and r >= 3: move one rho_1 rho_-1 pair from it into an empty run (it becomes a (1,1)-run;
136:     the donor stays nonempty).
137:  P4 (M0') if some run is a (1,1)-pair: delete its two letters (the run becomes empty) and insert sigma_y sigma_y into some block
138:     sigma_y^l.  Avoidance is preserved because, for the representation, every lambda(P) and I(empty) shrink (B and kappa drop by
139:     1, D_P, m, beta unchanged: the proof of Lemma M0, proof-RUNS.md L408-410, with Lemma H0); in the maximal decomposition the two
140:     neighbouring blocks may fuse (if equal-valued), which lowers kappa by one more.  No empty run is destroyed.
141: Apply the first applicable move.  The triple (kappa, g, k) decreases lexicographically at every move (P1: g; P2: k; P3: g; P4:
142: kappa), so the process stops.  Exits with g = 0 happen only through P1 or P3:
143:  Exit P3: the RGR avoider produced has B >= 1 and a (1,1)-run; by (I1) B = kappa; by Lemma TII every run of its OR-merge is
144:    pure: the (1,1)-run lies in some segment, which then contains both letters.  Contradiction.
145:  Exit P1: let w' be the last state with g >= 1 and w_end = FUS(w') the RGR avoider.  The step kills every empty run of w', so
146:    (C1) g(w') = 1 and the empty run t has an even neighbour, or (C2) g(w') = 2: sigma_u^a [] sigma_v^b [] sigma_u^c with b even.
147:    B(w_end) = B(w') =: B and kappa(w_end) = kappa(w') - [C2 with a, c odd].  By (I1), (I2) B = kappa(w_end).
148:    - kappa(w_end) = 0: then kappa(w') >= 1 forces C2 with a, c odd, and w_end contains the even block sigma_u^(a+b+c) with kappa = 0,
149:      contradicting (I3).

151:      C2 with a, c odd: kappa(w') - B = 1 and beta_t = beta_(t+1) = 1 force u_t = u_(t+1) = -1; but u_t + u_(t+1) = (u - v)/2 +
152:      (v - u)/2 = 0 and p is odd.  C2 otherwise (kappa(w') = B): an outer block odd gives an empty run with beta = 1: solvable;

157:    the terminal state is an avoider in RES_<(p) with kappa >= 2.  The converse direction is trivial.  []

55: ## 2. Block-chain lemma (value-independent certificate; no winding hypothesis)

57: **Lemma BC.**  Let w be an avoider (RGR, length 4p-2, F, R >= 1).  Let (P_1, ..., P_s),
58: s >= 2, be an ordered partition of [k] into nonempty proper patterns, Q_t := P_1 u ... u P_t.

62:      lambda(X u Y) + lambda(Y u Z) + lambda(Z u X) >= p + 1   and
63:      lambda(X) + lambda(Y) + lambda(Z) >= 1;

65: Then w has an identity 2p-subword (contradiction).

67: Proof.  As w avoids, for every proper Q the residue u_Q is not that of any element of
68: I(Q); in particular |I(Q)| <= p - 1, i.e. lambda(Q) + lambda(Q^c) <= p.
69: Claim: if y is an integer, y = u_Q (mod p) and 1 - lambda(Q^c) <= y <= p + lambda(Q) - 1,
70: then lambda(Q) <= y <= p - lambda(Q^c).  Indeed, write l = lambda(Q), l' = lambda(Q^c); the
71: integers [1 - l', l - 1] and [p + 1 - l', p + l - 1] are congruent to elements of I(Q), so y
72: avoids them; as l + l' <= p, the three ranges [1 - l', l - 1], [l, p - l'],
73: [p + 1 - l', p + l - 1] tile [1 - l', p + l - 1] in this order (when l + l' <= 1 the outer
74: ranges are empty and [1 - l', p + l - 1] is contained in [l, p - l']).
75: For each t choose an integer v_t = u_{P_t} (mod p) in [lambda(P_t), p - lambda(P_t^c)]
76: (possible: if l + l' >= 1 the interval [1 - l', p + l - 1] has >= p integers and contains a
77: representative, which lies in [l, p - l'] by the claim; if l + l' <= 0 the interval
78: [l, p - l'] itself has >= p + 1 integers).  Put V_t = v_1 + ... + v_t = u_{Q_t} (mod p).

102:    (B >= 1 and D + B >= 2).

20: where f_t = (y_t, -1) are the reflections and X_t (t = 1..F) is the block of
21: rotations strictly between f_{t-1} and f_t (X_1 = rotations before f_1); n_t =
22: |X_t|.  ("Gap t" = X_t; cyclically these are exactly the gaps between
23: consecutive reflections.)
24: 
25: ## Theorem P
26: 
27: If N = |w| <= 4p - 1 and  F + sum_{t=1}^{F} floor(n_t / 2) >= 3p - 1,  then w
28: has an identity 2p-subword.
29: 
30: ## Proof
31: 
32: **Step 1 (parametrisation).** In each gap X_t list the rotations in index order
33: and group them into floor(n_t/2) consecutive PAIRS pi = (i, i'); if n_t is odd
34: the last rotation of X_t is a SINGLETON.  Introduce Boolean parameters
35:   u_2, ..., u_F  (gap colours; set u_1 := 0 and u_{F+1} := u_1 = 0),
36:   m_pi  for each pair pi  (pair marks).
37: Number of parameters:  M = (F - 1) + sum_t floor(n_t/2) >= 3p - 2.
38: 
39: To a parameter point (u, m) assign the selection S(u, m):
40: * reflection f_t is selected iff u_t != u_{t+1}  (t = 1..F);
41: * both rotations of pair pi in gap t are selected iff m_pi XOR u_t = 1,
42:   otherwise neither;
43: * singletons are never selected.
44: 
45: **Step 2 (injectivity; the empty selection).** The selection determines the
46: parameters: going left to right, u_1 = 0 and u_{t+1} = u_t XOR [f_t selected]
47: determine all u_t; then m_pi = [pi selected] XOR u_t.  Hence the map
48: (u, m) -> S(u, m) is injective, and S(u, m) is EMPTY iff (u, m) = 0: an empty
49: selection selects no reflection, so all u_t = u_1 = 0, and no pair, so all
50: m_pi = u_t = 0.
51: 
52: **Step 3 (size).** |S(u,m)| = #{t : u_t != u_{t+1}} + 2 #{pi : m_pi XOR u_{t(pi)} = 1}.
53: The first term is the number of colour changes around the cycle 1..F, 1, hence
54: even.  So |S| is always EVEN, and |S| <= N <= 4p - 1.
55: 
56: **Step 4 (signs and the product).** Let S = S(u,m).  For an element of S lying
57: in gap t or equal to f_t, the number of selected reflections strictly before
58: it is #{s < t : u_s != u_{s+1}}, which has the parity of [u_t != u_1] = u_t.
59: So in the ordered product every selected rotation x in gap t is multiplied by
60: c_t := (-1)^{u_t}, and a selected reflection f_t contributes c_t y_t to the
61: rotation coordinate.  The number of selected reflections is even (Step 3), so
62: the product is (V, +1) with
63:   V = sum_{t : u_t != u_{t+1}} c_t y_t + sum_{pairs pi selected} c_{t(pi)} x_pi,
64: where x_pi = x_i + x_i'.  Using (c_t - c_{t+1})/2 = u_{t+1} - u_t (which is
65: 0 when u_t = u_{t+1} and c_t when they differ) and summation by parts with
66: u_1 = u_{F+1} = 0,
67:   sum_{t=1}^{F} (u_{t+1} - u_t) y_t = sum_{t=2}^{F} u_t (y_{t-1} - y_t).
68: For pairs: a selected pair (m XOR u_t = 1) contributes c_t x_pi; one checks
69: c_t x_pi [m XOR u_t] = x_pi m - x_pi u_t for both u_t = 0, 1.  Therefore, in Z_p,
70:   V(u, m) = sum_{t=2}^{F} beta_t u_t + sum_pi x_pi m_pi,
71:   beta_t = y_{t-1} - y_t - sum_{pi in gap t} x_pi.
72: V is a polynomial of degree 1 in the parameters (over F_p), and S(u,m) is an
73: identity subword iff V(u, m) = 0 in Z_p.
74: 
75: **Step 5 (Chevalley–Warning on the Boolean box).** Write the size as the
76: integer polynomial
77:   Z(u, m) = sum_{t=1}^{F} (u_t + u_{t+1} - 2 u_t u_{t+1}) + 2 sum_pi (m_pi + u_{t(pi)} - 2 m_pi u_{t(pi)}),
78: which agrees with |S(u, m)| on {0,1}^M and has degree 2.  Over F_p put
79:   Q = (1 - V^{p-1}) (1 - Z^{p-1}),   deg Q <= 3(p - 1) < M.
80: On {0,1}^M, Q(x) = 1 if V(x) = 0 and Z(x) = 0 in F_p, and Q(x) = 0 otherwise
81: (Fermat).  Box lemma: for any polynomial Q over F_p of degree < M,
82:   sum_{x in {0,1}^M} (-1)^{|x|} Q(x) = 0.
83: (Proof: suffices for monomials; a monomial of degree < M omits some variable
84: x_j, and the involution flipping coordinate j pairs points with opposite signs
85: and equal values.)  Hence
86:   sum_{x : V(x) = 0, Z(x) = 0 mod p} (-1)^{|x|} = 0 in F_p.
87: The point x = 0 contributes +1, so there is a parameter point x != 0 with
88: V(x) = 0 and |S(x)| = Z(x) = 0 mod p.
89: 
90: **Step 6 (conclusion).** By Step 2, S(x) is nonempty; by Step 3 its size is
91: even and at most 4p - 1; being divisible by p (odd), the size is a positive
92: even multiple of p below 4p, i.e. exactly 2p.  By Step 4 its ordered product is
93: the identity.  QED.

99:    (m = 3..9) show 3m-1 is also the sharp threshold for composite m.
100: 2. Which words are covered depends only on the R/F type pattern.  Uncovered:

103: 3. The 2-part (size parity) is handled ONLY through pairing inside gaps.  A

106: 4. Prime powers m = p^k: the same argument with congruences mod p^k would need

108:    (Combinatorica 31 (2011) 127-130); its exact hypotheses have NOT been read
109:    from the source here, so the extension is CONDITIONAL and kept separate.
