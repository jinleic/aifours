1: # Gram-support encoding for K2 and K3 (lane moqls7-maximum): soundness
2: 
3: Status: lane draft, awaiting parent verification. The definitions are those of Ball–Simoens arXiv:2607.12933v2
4: 
5: **Pinned code (sha256 at freeze):**
6: - `code/gram_enc.py` (encoder A): b2c206d8bf4896868fb4e45cd87c633a6cfbb0d62c8fdb62b146ac84a7d38833
7: - `code/gram_encB.py` (encoder B, stdlib): c7583efe838816d39fe33456af09897cc2a1f5633d1e57e1ee63b3e5238e2b45
8: - `code/gram_certify.py` (FIFO DRAT driver): 8eba2bd38a62e43a4cd4eb28373883d4efcfd9f11cfef165ce5293e322c59778
9: - `code/ls_classes.c`: 968ad4e574ed02800ac9f391aeb67e7709d328563112c0fe4febe30596058794
10: - `code/gram_controls.py` 82d00117…240c; `code/gram_controlsB.py` a797db70…5958
11: - `code/k2_classes.py` b49099e4…b891; `code/k2_classesB.py` 1637c17f…37bc
12: 
13: Encoder correspondence with §2:
14: - Both encoders create g variables only for pairs not on a common line, so G1 holds by absence.
15: - G2: A uses AND-auxiliaries h = g(p,r)∧g(q,r) with direct 0/1-count clauses. B uses a sequential counter that
16:   gives "≥ 1" and "≥ 2".
17: - G3 over ordered pairs of lines: A uses direct clauses; B uses counters.
18: - G5 is pairwise exclusion in both.
19: - G4: A uses "every (n−2)-subset contains a true literal" guards; B uses a one-directional ≥ 3 counter.
20: - `--sym` (K3 only) is identical in both.
21: §2.2–2.4. Entries are unit vectors taken up to phase. Theorem K1 is `review/K1-THEOREM.r1.md` (still unverified by
22: the parent).
23: 
24: ## 1. Objects
25: Let S be a set of mutually orthogonal QLS(7). For a quantum square Ψ_a ∈ S and cells p ≠ q, put
26: G_a(p,q) = ⟨ψ_a,p, ψ_a,q⟩. Its support g_a(p,q) = [G_a(p,q) ≠ 0] does not depend on phases or on any global
27: unitary. The ONB lines of Ψ_a are:
28: - its 7 rows and 7 columns (QLS axioms);
29: - in K2, the 7 symbol lines of the classical square L. By (C1), Ψ_a ⊥ L iff Ψ_a is an ONB on each symbol line of L.
30: 
31: ## 2. Necessary conditions (each holds for every quantum square a)
32: - **G1.** If p ≠ q lie on a common ONB line, then g_a(p,q) = 0.
33: - **G2 (frame consistency).** Let ℓ be an ONB line and p, q ∉ ℓ. Then ψ_p = Σ_{r∈ℓ} G(r,p) ψ_r, so
34:   G(p,q) = Σ_{r∈ℓ} conj(G(r,p)) G(r,q). Hence #{r ∈ ℓ : g(p,r) ∧ g(q,r)} = 0 forces g(p,q) = 0, and = 1 forces
35:   g(p,q) = 1. When p and q are collinear, G1 then forbids the count 1.
36: - **G3 (unitary transitions).** For ONB lines ℓ1 ≠ ℓ2, the matrix U[r,q] = G(r,q) (r ∈ ℓ1, q ∈ ℓ2) is the product
37:   of two unitaries. If the lines meet in s, then U[s,s] = 1 and the 6 × 6 block on (ℓ1∖s) × (ℓ2∖s) is unitary.
38:   Hence:
39:   - every r ∈ ℓ1∖ℓ2 has a neighbour on ℓ2∖ℓ1;
40:   - if r has exactly one neighbour q there, then |U[r,q]| = 1, so q has no other neighbour on ℓ1∖ℓ2.
41: - **G5 (orthogonality, exact).**
42:   - For quantum squares a ≠ b: ⟨ψ_a,p ⊗ ψ_b,p, ψ_a,q ⊗ ψ_b,q⟩ = G_a(p,q)·G_b(p,q). So Ψ_a ⊥ Ψ_b iff
43:     g_a(p,q)·g_b(p,q) = 0 for all p ≠ q.
44:   - Orthogonality to a classical L is exactly G1 on L's symbol lines.
45: - **G4 (heavy).** In a non-classical 3-set S that minimises the number m of non-classical squares, every
46:   non-classical square Ψ is heavy in every ONB B: some entry has ≥ 3 nonzero coefficients in B.
47:   - *Proof.* Theorem K1 gives m ≥ 2. Suppose Ψ is light in B, i.e. every entry has ≤ 2 nonzero coefficients.
48:     Apply a global unitary V with V(B) = standard basis. Lemma 10 (Ball–Simoens LF178–192) then gives a classical
49:     Ψ'' that is orthogonal to every square orthogonal to VΨ. Orthogonality of Ψ to the other squares is invariant
50:     under ψ ↦ Vψ applied to all entries of Ψ alone. So V⁻¹Ψ'' is classical and orthogonal to the other two squares.
51:     The resulting 3-set has m − 1 ≥ 1 non-classical squares, which contradicts minimality. ∎
52:   - With B the ONB of an own line ℓ: the weight of p ∉ ℓ is #{r ∈ ℓ : g(p,r)}. So *every own ONB line ℓ has a
53:     point p ∉ ℓ with ≥ 3 neighbours on ℓ.*
54:   - When K1 is impossible, any K2 set already has minimal m = 2. When K1 and K2 are both impossible, any K3 set has
55:     minimal m = 3. G4 therefore applies to every K2 set and to every K3 set that survives.
56: 
57: ## 3. Symmetry and the case split
58: - **K2.** All conditions are symmetric in the three classes (rows, columns, L lines) and invariant under relabelling
59:   of each class. A K2 configuration on L therefore transports to every L′ paratopic to L. One representative per
60:   main class suffices.
61:   - The 147 main classes are in `evidence/ls7_main_classes.txt` (sha256 898065c8…8158), produced by
62:     `code/ls_classes.c` (968ad4e5…8794).
63:   - Each class was found by canonical form, a minimum over the 211680 normalisations. |Par| is the multiplicity of
64:     the minimum.
65:   - Completeness: Σ 211680/|Par| = 16942080, the number of reduced Latin squares of order 7; observed MATCH. The
66:     count of 147 classes agrees with the literature (McKay–Meynert–Myrvold). That reference is cited, not re-derived.
67: - **K3.** Row and column permutations, transposition and relabelling of the squares preserve every condition.
68:   - WLOG (`--sym`) square 1 is heavy in the frame of row 0 at point (1,0), with neighbours (0,1), (0,2), (0,3).
69:   - Justification: permute rows so that the frame row is 0 and the heavy point's row is 1. Permute columns so that
70:     the heavy point's column is 0 and three of its neighbours lie in columns 1, 2, 3. A neighbour cannot be in

1: # K1 is impossible: no set of 3 MOQLS(7) has exactly one non-classical square (lane moqls7-maximum)
2: 
3: Status: lane result, awaiting parent verification. It is a partial result for the frozen target. It excludes K1 only;
4: K2 and K3 stay open. Host-clock times are PDT 2026-10-17. Definitions are those of Ball–Simoens arXiv:2607.12933v2
5: §2.2–2.4 (pinned copy in `sources/`). Points are cells; vectors are taken up to phase.
6: 
7: ## 1. Reformulation
8: **(C1)** Let L be a classical Latin square and Ψ a QLS of order n. Then Ψ ⊥ L iff, for every symbol a, the n
9: entries of Ψ on the cells with L(i,j) = a form an ONB.
10: 
11: *Proof.* The product vectors are ψ_ij ⊗ |L(i,j)⟩. The inner product of two of them is ⟨ψ_ij, ψ_kl⟩ when
12: L(i,j) = L(k,l), and 0 otherwise. So orthogonality says exactly that entries on a common symbol line are pairwise
13: orthogonal. There are n unit vectors per line in Cⁿ, so the line is an ONB. ∎
14: 
15: **K1 ⟺ net form.** In a K1 set {Ψ, L1, L2}, L1 and L2 are orthogonal Latin squares. So rows, columns, L1 and L2 form
16: a 4-net N of order 7 (Egan–Wanless notation, k = 2). By (C1) together with the QLS axioms, Ψ is an
17: *ONB-assignment* on N: a unit vector at each of the 49 points such that each of the 28 lines carries an ONB. Ψ is
18: non-classical iff the assignment uses more than 7 rays. The condition is symmetric in the 4 parallel classes and
19: invariant under net isomorphism and global unitaries, so it suffices to treat one representative per isomorphism
20: class.
21: 
22: ## 2. Frame and the pattern families
23: Fix a line ℓ0 (in the encoders: the class-0 line with label 0). Rotate globally so that the point of ℓ0 on the
24: class-1 line with label j carries e_j.
25: 
26: **Frame lemma.** Let p ∉ ℓ0. The 3 lines through p of the other classes meet ℓ0 in 3 distinct points r. Each such r
27: is collinear with p, so ⟨e_label(r), ψ_p⟩ = 0. Hence supp ψ_p ⊆ A(p), the complement of these 3 coordinates, and
28: |A(p)| = 4.
29: 
30: **Families** (each is necessary for any ONB-assignment, in the frame):
31: - **F1** supports are nonempty, since the vectors are unit.
32: - **F2** two points on a common line never share exactly one support coordinate. Otherwise the inner product is a
33:   single nonzero product.
34: - **F3** on each line every coordinate lies in some support. A unitary has no zero column.
35: - **F4** if coordinate k lies in exactly one support on a line, that point has weight 1. Column k of the line's
36:   unitary then has a single entry of modulus 1, so the rest of that row vanishes.
37: 
38: A pattern with all supports of size 1 in the frame means every vector is a phase times a standard basis vector. Such
39: an assignment is classical.

83: 2     Preliminaries
84: 2.1    Latin squares
85: A Latin square of order n is an n × n matrix containing elements of a set of size n such that each row and
86: each column contains every element exactly once. Two Latin squares A = (aij )1≤i,j≤n and B = (bij )1≤i,j≤n
87: are orthogonal if all n2 tuples (aij , bij ) are different. A set of t mutually orthogonal Latin squares of order
88: n, abbreviated t MOLS(n), is a set of t Latin squares of order n that are pairwise orthogonal.
89: 
90: 2.2    Quantum Latin squares
91: A quantum Latin square of order n is an n × n matrix over Cn such that each row and each column forms
92: an orthonormal basis of Cn . Two quantum Latin squares are isotopic if they can be obtained from one
93: another by
94:  (i) multiplying each entry by a phase factor,
95:  (ii) permuting rows and columns, and
96: (iii) applying a unitary transformation on all entries.
97: A quantum Latin square is classical or not genuinely quantum if, up to isotopy, all entries are contained
98: in {|1⟩ , . . . , |n⟩}, a fixed orthonormal basis. This property is independent of the chosen basis by item (iii)
99: in the definition of isotopy.

101: 2.3    Mutually orthogonal quantum Latin squares (MOQLS)
102: Two quantum Latin squares (ψij )1≤i,j≤n and (ϕij )1≤i,j≤n are orthogonal if

104:                                n     n
105: is an orthonormal basis of C ⊗ C . A set of t mutually orthogonal quantum Latin squares of order n,
106: denoted t MOQLS(n), is a set of t quantum Latin squares of order n such that any two of them are
107: orthogonal. Two sets of t MOQLS(n) are isotopic if they can be obtained from one another by

112:  (ii) permuting rows and columns, simultaneously among all squares, and
113: (iii) applying, separately to each square, a unitary transformation to all of its entries.

115: are contained in {|1⟩ , . . . , |n⟩}. Again, by item (iii) above, this property does not depend on the chosen
116: orthonormal basis.

118: 2.4    Patterns of quantum Latin squares
119: The pattern of a matrix is the binary matrix that is obtained from it by replacing each nonzero entry by
120: a one. A unitary pattern is a pattern of a unitary matrix. Similarly, the pattern of a vector is the vector
121: obtained from it by replacing each nonzero entry by a one. The support of a vector is the set of coordinates
122: where it is nonzero. The weight of a vector is the size of its support, that is, the number of ones in its
123: pattern. The pattern of a quantum Latin square is the matrix that is obtained from it by replacing each
124: entry by its pattern. For example:

151: 2.5    Frobenius rings
152: Let R be a finite ring of order n with identity. We denote the set of its invertible elements by R∗ . An
153: additive character of R is a group morphism χ : (R, +) → (T, ·) where T = {z ∈ C : |z| = 1} is the complex
154: unit circle.
155: A Frobenius ring is a ring R that admits a generating character : an additive character χ such that every
156: additive character of R is uniquely of the form x 7→ χ(ax) for some a ∈ R.
157: Examples of Frobenius rings are the modular ring Z/nZ (with generating character x 7→ ω x , where ω is
158: a primitive nth root of unity) and the finite field Fq (with generating character x 7→ ω tr(x) , where ω is a
159: primitive pth root of unity and q = ph , p prime), see also [13].

392: 5    Conclusion and future directions
393: We constructed new lower and upper bounds on the largest number t for which there exist non-classical
394: sets of t MOQLS(n). Specific values of these new bounds for small n can be found in Table 2.
395: We pose two open problems for future research:
396: Problem 16. Is a set of n − 3 MOQLS(n), n ̸= 4, necessarily classical?
397: Problem 17. Are there numbers t and n for which there exist t MOQLS(n) but no t MOLS(n)?
398: The smallest open case for the second problem is n = 10. It is not known that 7 MOLS(10) do not exist
399: (combining Theorem 9 with the non-existence of a projective plane of order 10, see [4]), but it is still an
400: open problem whether 7 MOQLS(10) exist. It would already be interesting to find 3 MOQLS(10), because
401: the existence of 3 MOLS(10) is not known.
