81: ## Theorem
82: 
83: Let U ∈ U(9) be dual unitary (U^R unitary) and not 2-unitary. Then rank U^Γ ≤ 6. Hence e_p(U) ≤ 15/16, with
84: equality iff spec(U^ΓU^Γ†) = {3/2 (×6), 0 (×3)}. Both U_s(2π/3) = S·U(2π/3) and the gate H of §W attain 15/16
85: exactly.
86: 
87: **T-dual form** (§0.1, R2). If V ∈ U(9) is T-dual (V^Γ unitary) and not 2-unitary, then rank V^R ≤ 6 and
88: e_p(V) ≤ 15/16, with equality iff spec(V^RV^R†) = {3/2 (×6), 0 (×3)}. V^Γ itself is unitary, of rank 9.
89: 
90: **Corollary** (Conjecture 3.3.2 of §P). No dual and no T-dual two-qutrit gate has 15/16 < e_p < 1. For dual gates,
91: and likewise for T-dual gates, e_p = 1 iff the gate is 2-unitary.
92: 
93: **Scope.**
94: - The sharp maximum 15/16 is over the non-2-unitary part of D ∪ T. It is not a statement about all of U(9): there
95:   an unrestricted bound fails by continuity near a 2-unitary, where e_p → 1.

97:   (arXiv:2212.06737v2, Thm 1). The Theorem, its T-dual form and the Corollary do not use [44].

187: **Fact K.** Let N_0,N_1,N_2 ∈ M_2 satisfy Σ_dN_dN_d† = Σ_dN_d†N_d = I_2, and put A = span{N_d}. Then
188: A = V·span{σ_k : k ∈ S}·W for some unitaries V, W and some S ⊆ {0,1,2,3}, where σ_0 = I and σ_1,σ_2,σ_3 are the
189: Paulis. Consequently:

191:   The right multiplier W_0 := J^{-1}σ_m (J = [[0,1],[−1,0]] = iσ_2) gives span{σ_k : k ≠ m} = Sym(2)·W_0,
192:   hence A = V·Sym(2)·(W_0W). Explicitly, J^{-1}σ_m ∝ σ_2, σ_3, I, σ_1 for m = 0,1,2,3, and
193:   Sym(2) = span{σ_0,σ_1,σ_3}, so Sym·σ_2 = span{σ_1,σ_2,σ_3}, Sym·σ_3 = span{σ_0,σ_2,σ_3}, Sym·I = Sym and
194:   Sym·σ_1 = span{σ_0,σ_1,σ_2}. Equivalently, (Sym(2)·W_0)^⊥ = C·JW_0 = C·σ_m.
195: - (b) If dim A ≤ 2, then span{σ_j,σ_k} = σ_j·span{I, σ_jσ_k}, and σ_jσ_k ∝ σ_l = C_lσ_3C_l† for a unitary C_l.
196:   So span{σ_j,σ_k} = σ_jC_l·Diag·C_l†, and A ⊆ V'·Diag·W' with V', W' unitary. The case |S| = 1 is a special
197:   case.

199:   computation of Lemma S), so dim A ≤ 2.

201: *Proof.* Φ(X) := Σ_dN_dXN_d† is completely positive, trace preserving and unital.
202: 1. (Bloch form.) In the basis {I,σ_1,σ_2,σ_3}, Φ(w_0I + w·σ) = w_0I + (t + Tw)·σ with T a real 3×3 matrix, and
203:    unitality ⇔ t = 0.
204: 2. (Rotation normal form.) Write T = R_1ΛR_2 with R_1, R_2 ∈ SO(3) and Λ real diagonal. Take the real SVD and
205:    move signs into Λ: −O ∈ SO(3) whenever O ∈ O(3) has det −1. Each R_i is Ad(U_i) on the traceless part for some
206:    U_i ∈ SU(2). So Φ = Ad(U_1)∘Φ_Λ∘Ad(U_2), where Φ_Λ := Ad(U_1)^{-1}∘Φ∘Ad(U_2)^{-1} is CPTP and unital and acts
207:    by σ_k ↦ λ_kσ_k.
208: 3. (Diagonal unital maps are Pauli channels.) Ad(σ_j) acts on σ_k by a sign ε_jk ∈ {±1}: ε_j0 = +1 for all j, and
209:    for k ∈ {1,2,3}, ε_jk = +1 iff j ∈ {0,k}. The 4×4 matrix H := (ε_jk)^T is an invertible Hadamard matrix, so
210:    Φ_Λ = Σ_jp_jAd(σ_j) for a unique real p
211:    with H p = (1,λ_1,λ_2,λ_3)^T. The Choi matrix of Φ_Λ is Σ_jp_j|σ_j⟩⟩⟨⟨σ_j|, and the vectors |σ_j⟩⟩ are
212:    pairwise orthogonal. So CP ⇔ all p_j ≥ 0, in which case {√p_jσ_j : p_j > 0} is a Kraus family.
213: 4. (The Kraus span is an invariant of Φ.) For any Kraus family {K_e} of Φ, the Choi matrix is
214:    C_Φ = Σ_{i,j}E_ij⊗Φ(E_ij) = Σ_e|K_e⟩⟩⟨⟨K_e|, with |K⟩⟩ := Σ_ie_i⊗Ke_i. The range of a finite sum of positive
215:    rank-one matrices is the span of their vectors, so span{|K_e⟩⟩} = range C_Φ depends only on Φ, and K ↦ |K⟩⟩
216:    is a linear isomorphism. Applying this to {N_d} and to the family {√p_jU_1σ_jU_2} of Ad(U_1)∘Φ_Λ∘Ad(U_2)
217:    gives A = U_1·span{σ_j : p_j > 0}·U_2.

256: **Lemma N1.** If dim A = 3 and Y = (Y_0,Y_1,Y_2) satisfies Σ_dY_dN_d† = 0 = Σ_dN_d†Y_d, then all Y_d ∈ A.
257: *Proof.* By Fact K(a), gauge A = Sym; the hypotheses are covariant under Y ↦ V'†YW'†, N ↦ V'†NW'†. Then
258: N_d† = N̄_d. Transposing the second condition gives Σ_dY_d^TN̄_d = 0, and subtracting from the first gives
259: Σ_d(Y_d − Y_d^T)N̄_d = 0. Writing Y_d − Y_d^T = δ_dJ, this says J·Σ_dδ_dN̄_d = 0, and since the N̄_d are
260: independent, δ = 0. ∎ (The algebra is checked exactly in `evidence/lemma_T_exact.json`, key N1.)
261: With (α) and (γ): Q_a, Ω_ad ∈ A. By (12)(34): dim C = 3 ⇒ T_b, Ω^{(bc)} ∈ C (Lemma N1').

263: **Lemma T.** If u_1Jv_1^T + u_2Jv_2^T = 0 for 2×2 matrices u_i, v_i, then rank(u_1⊗v_1 + u_2⊗v_2) ≤ 2.
264: Equivalently, a tensor T[s,c,a,d] symmetric in (a,d) with rank_{(s,a)|(c,d)} ≤ 2 has rank_{(s,c)|(a,d)} ≤ 2.
265: *Proof* (LEMMA_R_NORMAL_FORM.v1.md §2). Both the hypothesis and F := u_1⊗v_1 + u_2⊗v_2 are invariant under
266: (u_1,u_2) ↦ (u_1,u_2)G, (v_1,v_2) ↦ (v_1,v_2)G^{-T}, and under u_k ↦ hu_k.
267: - (i) If span{u_1,u_2} contains an invertible matrix, arrange u_1 = I. Then v_1 = −v_2 adj(u) with u := u_2, and
268:   F = (I⊗v_2)L(u) with L(u) = u⊗I + I⊗u − tr(u)I. Every 3×3 minor of L(u) vanishes identically, so rank F ≤ 2.
269: - (ii) Otherwise either the span is ≤ 1-dimensional with u_1 singular, or all u_k = a_kb^T, or all
270:   u_k = ab_k^T. In each case rank F ≤ 2.
271: All of these identities are checked exactly in `evidence/lemma_T_exact.json`. ∎

273: **Lemma S.** If ‖N_0‖_op = 1 (or ‖R_0‖_op = 1, by (12)(34)), then rank U^Γ ≤ 6.
274: *Proof.* Gauge N_0 = diag(1,σ). Then (U) forces N_d = ν_dE_22 and Q_a = κ_aE_22. So X_00 = diag(1,1,σ) and
275: X_0d, X_a0 ∈ C·E_22, and the nine slices span at most 2 + #{X_ad : a,d ∈ K} = 6 dimensions. ∎

277: **Rank Lemma (R3).** Use the block form M = [[1, 0, n_0],[0, 0, P],[x, 𝐁, Ω]] of §0.2, with row and column blocks of
278: sizes 1, 4, 4, and rP = rank P, rB = rank 𝐁. Let 𝒜 be a subspace of row vectors indexed by (b,c) ∈ K×K, and 𝒞 a
279: subspace of column vectors indexed by (a,d) ∈ K×K.
280: - (i) If every column of the last row block [x, 𝐁, Ω] lies in 𝒞, then rank M ≤ 1 + rP + dim 𝒞.
281: - (ii) Suppose that:
282:   - row P ⊆ 𝒜, n_0 ∈ 𝒜, and every row of Ω lies in 𝒜;
283:   - col 𝐁 ⊆ 𝒞, x ∈ 𝒞, and every column of Ω lies in 𝒞.
284: 
285:   Put Ω' := Ω − x n_0, E_𝐁 := I − 𝐁𝐁^+ and F_P := I − P^+P, where ^+ is the Moore–Penrose inverse. E_𝐁 is the
286:   orthogonal projector onto (col 𝐁)^⊥, and F_P is the orthogonal projector onto ker P. Then
287:   rank M = 1 + rank [[0, P],[𝐁, Ω']] = 1 + rP + rB + rank(E_𝐁Ω'F_P), and
288:   rank(E_𝐁Ω'F_P) ≤ min(dim 𝒜 − rP, dim 𝒞 − rB).
289:   With dim 𝒜 = dim 𝒞 = 3 this gives rank M ≤ 1 + rP + rB + 3 − max(rP, rB) = 4 + min(rP, rB).
290: 
291: *Proof of (i).* The first two row blocks [[1, 0, n_0],[0, 0, P]] have rank exactly 1 + rP, because only the first
292: row has a nonzero entry in the first column. The last row block has rank ≤ dim 𝒞. Rank is subadditive over row
293: blocks.
294: 
295: *Proof of (ii).*
296: 1. *Pivot.* Subtract x·(first row) from the last row block, then subtract (first column)·n_0 from the last column
297:    block. Both operations are invertible, and they turn M into [[1, 0, 0],[0, 0, P],[0, 𝐁, Ω']]. Hence
298:    rank M = 1 + rank M', where M' := [[0, P],[𝐁, Ω']].
299: 2. *The constraints survive the pivot.* Row (a,d) of Ω' is (row (a,d) of Ω) − x_ad·n_0, which lies in 𝒜 because
300:    n_0 ∈ 𝒜. Column (b,c) of Ω' is (column (b,c) of Ω) − N_0[b,c]·x, which lies in 𝒞 because x = vec R_0 ∈ 𝒞.
301: 3. *Splitting.*
302:    - Subtract (first block column)·𝐁^+Ω' from the second block column. This replaces Ω' by
303:      Ω' − 𝐁𝐁^+Ω' = E_𝐁Ω' and leaves [0, P] unchanged.
304:    - Subtract (E_𝐁Ω'P^+)·(first block row) from the second block row. This replaces E_𝐁Ω' by
305:      E_𝐁Ω' − E_𝐁Ω'P^+P = Y := E_𝐁Ω'F_P and leaves 𝐁 unchanged.
306:    - col Y ⊆ range E_𝐁 = (col 𝐁)^⊥, so col Y ∩ col 𝐁 = 0.
307:    - If a row vector satisfies yP = zY, right-multiply by P^+P. Since F_PP^+P = 0 and PP^+P = P, this gives
308:      yP = 0. So row P ∩ row Y = 0.
309:    - Hence a column relation [0; 𝐁u] = −[Pv; Yv] forces Pv = 0 and 𝐁u = −Yv ∈ col 𝐁 ∩ col Y = 0. So
310:      rank [[0, P],[𝐁, Y]] = rB + rank [P; Y] = rB + rP + rank Y.
311:    This is the Marsaglia–Styan rank formula (Linear Multilinear Algebra 2 (1974) 269–292); the argument above is
312:    complete without it.
313: 4. *Bound.*
314:    - Column side: for v ∈ 𝒞, 𝐁𝐁^+v ∈ col 𝐁 ⊆ 𝒞, so E_𝐁v ∈ 𝒞; and E_𝐁𝐁 = 0. So E_𝐁𝒞 is a subspace of dimension
315:      ≤ dim 𝒞 − rB. It contains col Y, because col Y ⊆ E_𝐁(col Ω') and col Ω' ⊆ 𝒞.
316:    - Row side: for a row vector y ∈ 𝒜, yP^+P ∈ row P ⊆ 𝒜, so yF_P ∈ 𝒜; and PF_P = 0. So 𝒜F_P has dimension
317:      ≤ dim 𝒜 − rP. It contains row Y, because row Y ⊆ (row Ω')F_P and row Ω' ⊆ 𝒜.
318:    - Hence rank Y ≤ min(dim 𝒜 − rP, dim 𝒞 − rB). ∎

320: ## 2. Proposition G (dim A = 3 and dim C = 3) ⇒ rank ≤ 6
321: 
322: Gauge A = C = Sym. Rank Lemma (ii) applies with 𝒜 = vec A and 𝒞 = vec C, both 3-dimensional. The hypotheses hold:
323: - row P ⊆ vec A, since N_1, N_2 ∈ A and Q_1, Q_2 ∈ A (Lemma N1);
324: - n_0 = vec N_0 ∈ vec A;
325: - the rows vec Ω_ad of Ω lie in vec A (Lemma N1);
326: - col 𝐁 ⊆ vec C, since R_1, R_2 ∈ C and T_1, T_2 ∈ C (Lemma N1');
327: - x = vec R_0 ∈ vec C;
328: - the columns vec Ω^{(bc)} of Ω lie in vec C (Lemma N1').
329: 
330: So rank M ≤ 4 + min(rP, rB). Since ‖N_0‖ < 1, the 2×4 matrix
331: 𝐍[b,(c,d)] = N_d[b,c] (d ∈ K) has rank 2, because 𝐍𝐍† = I − N_0N_0†. With N symmetric, (O1) and (O3) put the four
332: vectors (S_c[a,d])_{(c,d)}, for S ∈ {R,T} and a ∈ K, into the 2-dimensional space ker 𝐍 (conjugated). The tensor
333: 𝔖[S,c,a,d] := S_c[a,d] is symmetric in (a,d) (C = Sym and T ∈ C), so Lemma T gives rB ≤ 2. Hence rank M ≤ 6.

335: ## 3. Proposition A\* (dim C = 3, dim A ≤ 2, ‖N_0‖ < 1) ⇒ rank ≤ 6
336: 
337: Gauge C = Sym (then T_b, Ω^{(bc)} ∈ Sym by N1') and A ⊆ Diag (Fact K(b)). So N_d = diag(p_d, q_d) with p, q ∈ C³
338: unit vectors, and p_K := (p_1,p_2) ≠ 0, q_K ≠ 0 because ‖N_0‖ < 1. Write n^{(1)} = p, n^{(2)} = q.
339: - (O1) gives R_b n̄^{(b)}_K = 0 and (O3) gives T_b n̄^{(b)}_K = 0 (b ∈ K). A symmetric 2×2 matrix with a nonzero
340:   kernel vector v is a multiple of (Jv)(Jv)^T. So R_b = ρ_bw_bw_b^T and T_b = τ_bw_bw_b^T with w_b := J n̄^{(b)}_K.
341: - dim C = 3 forces ρ_1ρ_2 ≠ 0 and w_1 ∦ w_2. (U) for C and D gives
342:   Σ_b(|ρ_b|² − |τ_b|²)‖w_b‖²w_bw_b† = 0, so |τ_b| = |ρ_b| ≠ 0.
343: - (O4) and (O2) then give Σ_{a∈K}Q_a[b,c]w̄_c[a] = 0 and Σ_aQ_a[b,c]w̄_b[a] = 0 for all b,c ∈ K.
344:   - For b ≠ c, w̄_b and w̄_c span C², so Q_a[b,c] = 0.
345:   - For b = c, (Q_a[b,b])_a ∥ n^{(b)}_K.
346:   So every Q_a (a ∈ K) is diagonal, span{N_1,N_2,Q_1,Q_2} ⊆ Diag, and rP ≤ 2.
347: - Every column of the last row block lies in vec C, which is 3-dimensional: x = vec R_0 and vec R_c by definition,
348:   vec T_b and vec Ω^{(bc)} by Lemma N1'. Rank Lemma (i) gives rank M ≤ (1 + rP) + 3 ≤ 6.
349: 
350: dim A = 1 is impossible here: then p ∥ q, contradicting w_1 ∦ w_2.

352: ## 4. Proposition B\* (all of dim A,B,C,D ≤ 2; ‖N_0‖, ‖R_0‖ < 1) ⇒ U 2-unitary or rank ≤ 5
353: 
354: Gauge A ⊆ Diag and C ⊆ Diag: N_d = diag(p_d,q_d) and R_c = diag(r_c,s_c), with all four of p_K, q_K, r_K, s_K
355: nonzero.
356: 1. (O1) reads n^{(b)}_a·conj(ρ^{(a)}_b) = 0 (ρ^{(1)} = r, ρ^{(2)} = s), i.e. p_1r_1 = p_2s_1 = q_1r_2 = q_2s_2 = 0.
357:    With all four K-parts nonzero this forces, after swapping the K-bases of parties 1 and 4 if needed,
358:    **p_2 = q_1 = r_1 = s_2 = 0**: N_1 = p_1E_11, N_2 = q_2E_22, R_1 = s_1E_22, R_2 = r_2E_11, with p_1, q_2, r_2,
359:    s_1 ≠ 0. In particular dim A = dim C = 2.
360: 2. (O4) gives Q_1e_2 = 0 and Q_2e_1 = 0, so Q_1 = αE_11 + βE_21 and Q_2 = γE_12 + δE_22. (O3) gives T_1e_1 = 0
361:    and T_2e_2 = 0, so T_1 = x_1E_12 + y_1E_22 and T_2 = x_2E_11 + y_2E_21.
362: 3. (U) for B: |α|²+|β|² = |α|²+|γ|² = |p_1|², |γ|²+|δ|² = |β|²+|δ|² = |q_2|², and αβ̄+γδ̄ = 0; so |β| = |γ|.
363:    (U) for D: |x_1|²+|x_2|² = |x_2|²+|y_2|² = |r_2|² and |y_1|²+|y_2|² = |x_1|²+|y_1|² = |s_1|².
364: 4. (O2) gives βx_2 = αx_1 = δy_2 = γy_1 = 0.
365: 5. If β = γ = 0: |α| = |p_1| and |δ| = |q_2| are nonzero, so x_1 = y_2 = 0, and all Q_a, T_b are diagonal.
366:    Entries (1,2) and (2,1) of (α) and (γ) in the diagonal gauge (using p_2 = q_1 = 0, p_1q_2 ≠ 0 and Q_a
367:    off-diagonal zero) make Ω_ad diagonal in (b,c). The mirrored argument (R, T diagonal, r_1 = s_2 = 0,
368:    r_2s_1 ≠ 0) makes Ω^{(bc)} diagonal in (a,d). So the rows of the last column block and the columns of the last
369:    row block all lie in Diag. For the columns these are x = vec R_0 (R_0 ∈ C ⊆ Diag), vec R_c, vec T_b and
370:    vec Ω^{(bc)}. Rank Lemma (i) with 𝒞 = vec Diag gives rank M ≤ (1 + rP) + 2 ≤ 1 + 2 + 2 = 5, where rP ≤ 2
371:    because N_1, N_2, Q_1, Q_2 ∈ Diag.
372: 6. If β ≠ 0 (⇔ γ ≠ 0): x_2 = y_1 = 0, so |x_1| = |r_2| ≠ 0 and |y_2| = |s_1| ≠ 0, hence α = δ = 0.
373:    - B = span{diag(p_0,q_0), E_21, E_12} has dim ≤ 2 only if N_0 = 0; likewise D forces R_0 = 0. So
374:      |p_1| = |q_2| = |r_2| = |s_1| = |β| = |γ| = |x_1| = |y_2| = 1.
375:    - With N_0 = 0, (α) and (γ) give Ω_a1 = ω_aE_22 and Ω_a2 = ω'_aE_11. Then (δ) and (β) with Q_1 = βE_21,
376:      Q_2 = γE_12 give ω = ω' = 0, so Ω = 0.
377:    - Then M = [[1,0,0],[0,0,P],[0,𝐁,0]] with P and 𝐁 monomial unitaries (distinct matrix units with unimodular
378:      coefficients). So MM† = I: **U is 2-unitary**.

45: Let N_0,N_1,N_2 ∈ M_2 satisfy (U) with dim A = 3. If Y = (Y_0,Y_1,Y_2) satisfies Σ_d Y_dN_d† = 0 and

50: complement of span{σ_k : k ∈ S} is C·σ_m (σ_m the missing Pauli), span{σ_k : k ∈ S} = Sym(2)·(J^{-1}σ_m); hence
51: A = V'·Sym(2)·W' with V', W' unitary. The hypotheses are covariant under

53: gives Σ_d Y_d^T N̄_d = 0; subtracting from the first, Σ_d (Y_d − Y_d^T) N̄_d = 0. Write Y_d − Y_d^T = δ_d J

60: ## 2. Lemma T (2×2×2×2 tensor lemma)
61: 
62: If u_1,u_2,v_1,v_2 ∈ M_2 satisfy u_1Jv_1^T + u_2Jv_2^T = 0, then rank(u_1⊗v_1 + u_2⊗v_2) ≤ 2.

64: rank ≤ 2 has (s,c)|(a,d) flattening of rank ≤ 2.
65: 
66: Proof. The hypothesis and the rank are invariant under u_k ↦ Au_kB, v_k ↦ Cv_kB (A,B,C invertible) and under
67: (u_1,u_2) ↦ (u_1,u_2)G, (v_1,v_2) ↦ (v_1,v_2)G^{-T}. (i) If span{u_1,u_2} contains an invertible matrix, arrange
68: u_1 = I; then v_1 = v_2 J u^T J = −v_2 adj(u) (u := u_2), and F := I⊗v_1 + u⊗v_2 = (I⊗v_2)(u⊗I + I⊗u − tr(u) I).
69: The last factor has eigenvalues λ_i + λ_j − λ_1 − λ_2, two of which vanish; if u is a Jordan block it equals N⊗I + I⊗N
70: (N² = 0), of rank 2. So rank F ≤ 2. (ii) Otherwise every element of span{u_1,u_2} is singular: either the span is ≤ 1-dim
71: (then F = u_1⊗w with u_1 singular) or all u_k = a_k b^T or all u_k = a b_k^T (the two rulings of {det = 0}), and
72: F = (Σ_k a_k⊗v_k)(b^T⊗I) or F = (a⊗I)(Σ_k b_k^T⊗v_k). In all cases rank F ≤ 2. ∎
