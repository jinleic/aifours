181: ## 3. Proof of Lemma S1
182: 
183: (a) This is Step 1 of proof-ROT-half-v1.md.
184: - A minimal zero-sum subsequence has length <= 2p: deleting one term leaves a zero-sum-free sequence, of length
185:   <= 2p - 1 by (D).  Its length is even, so by (ZP) it is <= 2kappa.
186: - Every zero-sum T is a product T_1 ... T_r of minimal zero-sum subsequences: take one, then induct on the rest.
187: - If |T| >= 2kappa + 2, let j be least with |T_1| + ... + |T_j| >= 2kappa + 2.  Then T_1 ... T_j is a zero-sum of
188:   length in [2kappa + 2, 4kappa], and 4kappa <= 2p - 2: contrary to (ZP).  []
189: (b) Let T be a zero-sum with |T| >= 2kappa + 2.  By (ZP), |T| >= 2p + 2.
190: - Write T = T_1 ... T_r as in (a).  Every |T_i| <= 2kappa.  Every union of some of the T_i is a zero-sum, so its length
191:   is not in [2kappa + 2, 2p].
192: - Call T_i long if |T_i| >= 2p - 2kappa + 1.  Suppose at most one T_i is long, and number it T_1 if it exists.
193:   - The lengths l_j := |T_1| + ... + |T_j| increase from l_1 <= 2kappa to l_r = |T| >= 2kappa + 2.
194:   - At the least j with l_j >= 2kappa + 2 we have j >= 2 and l_(j-1) <= 2kappa.  Also |T_j| <= 2p - 2kappa, as T_j is
195:     not long.
196:   - So l_j lies in [2kappa + 2, 2p], contrary to (ZP).
197: - Hence two pieces P, P' are long, and |P|, |P'| >= 2p - 2kappa + 2 (they have even length).
198: - Then |P| + |P'| >= 4p - 4kappa + 4 >= 2kappa + 2, as 6kappa <= 4p + 2.  P P' is a zero-sum, so |P| + |P'| >= 2p + 2.
199: - As |P|, |P'| <= 2kappa, it follows that 4kappa >= 2p + 2.  []

201: ## 4. Theorem ROT-ZX
202: 
203: **Theorem ROT-ZX.**  Let p >= 5 be prime and w an avoider of length 4p - 2 over D_(2p).  Let w^ be its normal form
204: (proof-ROT-few-E-v4.md Sec. 0, L28-43), with terminal k and kappa^ = p - 1 - (F - k)/2.  Suppose that k = 1, or that
205:   3k <= 2p + 1 and the rotation sequence of w^ satisfies (S1) with kappa = kappa^.
206: In particular the second condition holds whenever 3k <= 2p + 1 and kappa^ <= (p - 1)/2.  Then all rotation letters of
207: w lie in one set {rho_c, rho_-c}, c != 0.
208: Proof.
209: - Normal form.  By Sec. 0, w^ is an avoider with the same length, rotation multiset and F as w.  It is given by a
210:   cyclic representation with 1 <= k <= o odd blocks, and every empty run lies between blocks of different values.
211:   The ending with one even block is impossible (L39-41).
212: - k = 1.  Proposition K1 makes all rotations equal (and then F = 2p - 1 and kappa^ = 0).
213: - Let k >= 2.
214:   - kappa^ >= 0: if H >= p, GRX's all-plus pattern with m = 0 selected rotations is already an identity selection
215:     (proof-SHgen-v3.md L37).  GRX allows empty runs.
216:   - Lemma DAV gives kappa^ <= k - 1 (L42-43).  So (G') holds.
217:   - GRX with z = all + gives (ZP) for the sequence Y of the values Y(x) over the rotation letters of w^.  Y has length
218:     R = 2p + 2kappa^ - k (L42-43).
219:   - If kappa^ <= (p - 1)/2, Lemma S1 (a) gives (S1).
220:   - Lemma ZX gives a generator g = Y(c) with c != 0 (as g != (1,0)), cost_g(Y) <= k - 1, and every |b_g| <= k.
221: - Weights.  Since k <= p - 2, every rotation has |b| <= k <= p - 2.  Y(x) = b g means x = b c (mod p).  As b is odd
222:   with |b| <= p - 2, it is the SHgen weight b_x of rho_x relative to c (proof-SHgen-v3.md L39-41).  x = 0 would need
223:   b = p (b_0 := p), which is excluded.  So the lights are the rotations with b = +-1, and E and N are those of Lemma
224:   ZX, with E + N <= k - 1.
225: - If E = 0, every rotation is rho_c or rho_-c.
226: - Otherwise eta >= 1, and both hypotheses of Theorem SHgen hold:
227:   - (H): 2H = 2p - 2 - 2kappa^ >= 2p - 2k >= k - 1 >= E, by 3k <= 2p + 1.
228:   - (K): every heavy has |b| >= 3, so eta <= E/2 <= (k - 1)/2 and a_max <= E + 1 <= k.  Hence
229:     2p - eta - a_max - 1 >= 2p - (k - 1)/2 - k - 1 >= k, because 5k <= 4p - 1 (from 3k <= 2p + 1 and p >= 4).
230: - If all runs of w^ are nonempty, w^ is in the setting of proof-SHgen-v3.md Sec. 0, and Theorem SHgen gives w^ an
231:   identity 2p-subword.  Otherwise Lemma SHgen-E (proof-ROT-few-E-v4.md Sec. 1) gives one.
232:   - SHgen-E needs REFL(p) only for words with o_F <= k <= p, which Corollary REFL-few-odd supplies.
233:   - The caller obligation o_F <= k <= p holds throughout its induction (half-range verdict, overlay 3).

38:   (G) k >= 1,  3k <= 2p + 1,  0 <= kappa <= min(k - 1, p - k).

42:   cost(Y) := sum over y with b > 0 of (b - 1)  +  sum over y with b < 0 of |b|  <=  k - 1.
43: In particular every |b| <= k (so no term is (1,0) = p g), and with E := sum_y (|b| - 1) and N := the number of terms
44: with b < 0, E <= k - 1 - N.

47: ## 2. Proof of Lemma ZS
48: 
49: Consequences of (G) used below:
50: - (G1) kappa <= (p-1)/2, so 4kappa <= 2p - 2, because min(k - 1, p - k) <= ((k - 1) + (p - k))/2;
51: - (G2) 3(k - 1) + 2 <= 2p;
52: - (G3) k <= p - 2 (from 3k <= 2p + 1 if p >= 7; for p = 5, k <= 3);
53: - (G4) 3k <= 2p + 2;
54: - (G5) 2kappa <= 2p - 2k.
55: 
56: Step 1 (every zero-sum is short).  Every zero-sum subsequence T of Y has |T| <= 2kappa.
57: A minimal zero-sum subsequence has length <= 2p (deleting one term leaves a zero-sum-free sequence, of length <= 2p - 1
58: by (D)), and its length is even, so by (ZP) it is <= 2kappa.  A zero-sum T is a product T_1 ... T_r of minimal zero-sum
59: subsequences (take one minimal zero-sum subsequence, then induct on the rest).  If |T| >= 2kappa + 2, let j be least
60: with |T_1| + ... + |T_j| >= 2kappa + 2.  Then T_1 ... T_j is a zero-sum of length at least 2kappa + 2 and at most
61: 4kappa <= 2p - 2 (G1), contrary to (ZP).  []
62: 
63: Step 2 (splitting).  Let Z be a zero-sum subsequence of Y of maximal length (Z may be empty), and Y' the complementary
64: subsequence.  Y' is zero-sum-free: a nonempty zero-sum V <= Y' would make Z V a longer zero-sum.  By Step 1
65: |Z| <= 2kappa, so L := |Y'| = R - |Z| >= 2p - k, and e := 2p - 1 - L = k - 1 - 2kappa + |Z| satisfies 0 <= e <= k - 1
66: (L <= 2p - 1 by (D)).

69: multiplicity in Y', attained by g.  Then m >= max(2, e + 1), g is a generator, and Y' = g^m (d_1 g) ... (d_q g) with
70: odd d_j >= 3 and e' := sum_j (d_j - 1) <= e.  MULT (i) gives m >= L - e >= 2p - 2k + 1.  Put W' := m + sum_j d_j =
71: L + e'.

73: of some subsequence Q <= Y'.  (b) W' <= 2p - 1.  (c) Every Q <= Y' has sum w(Q) g and |Q| = w(Q) - (sum of d_j - 1 over
74: its terms d_j g) >= w(Q) - e'.
75: Proof.  (a) Every d_j <= e' + 1 <= e + 1 <= m.  The weights of subsequences of g^m are all integers in [0, m].  If all
76: integers in [0, M] are weights and d <= M + 1, then after adding d g all integers in [0, M + d] are weights (t <= M,
77: or t - d in [0, M]).  Add d_1, ..., d_q in turn.  (b) If W' >= 2p, some Q has weight 2p by (a), so sum 2p g = 0: a
78: nonempty zero-sum in Y'.  (c) Clear.  []
79: Consequences:
80: - (C1) Every d_j <= e' + 1 <= k <= p - 2 (G3), so each term of Y' is b g with b in {1} u [3, k] and b = b(y).
81: - (C2) W' >= L >= 2p - k.
82: - (C3) e' <= e.
83: - (C4) m >= 2p - 2k + 1 >= k - 1 (G4).
84:

147: ## 3. Theorem ROT-ZS and Corollary ROT-HALF
148: 
149: **Theorem ROT-ZS.**  Let p >= 5 be prime and w an avoider of length 4p - 2 over D_(2p) with o := o_F(w) such that
150: 3o <= 2p + 1 and F(w) >= 3o - 2 (equivalently kappa(w) <= p - o).  Then all rotation letters of w lie in one set
151: {rho_c, rho_-c}, c != 0.
152: Proof.  Take the normal form w^ of proof-ROT-few-E-v4.md Sec. 0 (L32-43).  It is an avoider of the same length,
153: rotation multiset and F, given by a cyclic representation with 1 <= k <= o odd blocks and every empty run between blocks
154: of different values; the ending with one even block is impossible there.  If k = 1, Proposition K1 makes all rotations
155: equal.  Let k >= 2.  Then H = (F - k)/2 and kappa := p - 1 - H = kappa(w) - (o - k)/2.  Also kappa >= 0
156: (proof-SHgen-v3.md L37), and Lemma DAV gives kappa <= k - 1.  Moreover
157: kappa <= (p - o) - (o - k)/2 <= p - k, as k <= o.  And 3k <= 3o <= 2p + 1, so (G) holds.  GRX gives (ZP) for the
158: sequence Y of the values Y(x) over the rotation letters, of length R = 2p + 2kappa - k (L42-43).  So Lemma ZS applies.
159: Write its generator as g = Y(c); then c != 0, since g != (1,0).  Y(x) = b g means x = b c (mod p), so the SHgen weight
160: of rho_x relative to c (proof-SHgen-v3.md L39-43) is b_x = b(Y(x)).  Every |b| <= k <= p - 2, so no rotation is rho_0,
161: the lights are the terms with b = +-1, and E and N are those of Lemma ZS: E <= k - 1 - N.  If E = 0, every rotation is
162: rho_c or rho_-c.  Otherwise eta >= 1, and the two hypotheses of Theorem SHgen hold.
163: - (H): 2H = 2p - 2 - 2kappa >= 2p - 2 - 2(p - k) = 2k - 2 >= k - 1 >= E.
164: - (K): every heavy has |b| >= 3, so eta <= E/2 <= (k-1)/2, and a_max <= E + 1 <= k.  Hence
165:   2p - eta - a_max - 1 >= 2p - (k-1)/2 - k - 1 >= k, because 5k <= 4p - 1 (from 3k <= 2p + 1 and p >= 4).
166: If all runs of w^ are nonempty, w^ is in the setting of proof-SHgen-v3.md Sec. 0 and Theorem SHgen gives w^ an identity
167: 2p-subword.  Otherwise Lemma SHgen-E (proof-ROT-few-E-v4.md Sec. 1) gives one; its REFL instances have
168: o_F <= k <= p, supplied by Corollary REFL-few-odd.  Either way this contradicts that w^ avoids, so E = 0.  The rotation
169: multiset of w is that of w^.  []

21: 
22: **Corollary OLSON-FEW.**  Let p >= 5 be prime and w a word of length 4p-1 over D_(2p).
23:  (a) If o_F(w) <= 3, or p >= 7 and o_F(w) <= 4, then w has an identity 2p-subword (conditional on REFL-few-odd only).
24:  (b) If 5 o_F(w) <= 2p + 4, then w has an identity 2p-subword (conditional on REFL-few-odd and SHgen).

26: ## Proof
27: 
28: Suppose w has no identity 2p-subword; every subword then avoids.  Let B denote the bound on o_F in (a) or (b); by
29: Corollary INV*-FEW every avoider of length 4p-2 with o_F <= B is RGR (rotations in one {rho_c, rho_-c}, c != 0, every
30: maximal cyclic reflection run constant).
31: Case 1: R <= 2.  Then F >= 4p - 3.  If R = 0 and all reflections are equal, any 2p of them multiply to
32: sigma_y^(2p) = 1.  Otherwise read w in the cyclic frame that starts at a rotation letter (R >= 1) or at a change of
33: reflection value (R = 0); no block wraps around this frame, so the blocks contain (F - o_F(w))/2 >= p disjoint equal
34: pairs sigma_y sigma_y adjacent in the framed word (o_F(w) <= B <= 2p - 3), and p of them form an identity 2p-subword
35: of the framed word.  A cyclic shift changes the product of a selection only by conjugation, so this selection is an
36: identity 2p-subword of w as well (conjugating back as in R/olson-runs-parent-verdict-v1.md L49): contradiction.
37: Case 2: some odd block has length >= 3.  Deleting one of its letters gives a word w' of length 4p-2 with
38: o_F(w') = o_F(w) - 1 (that block becomes even; nothing else changes).  w' is RGR.  w has the same rotations as w', and
39: its reflection runs differ from those of w' only by one more copy of a letter inside a constant block, so w is RGR.
40: Case 3: R >= 3 (the argument does not use that Case 2 fails; Case 3 alone covers every R >= 3, and Case 2 is the
41: shorter argument when it applies).  Delete two different rotation letters x1, x2: w_i := w - x_i has
42: o_F(w_i) <= o_F(w) (deleting a rotation never raises o_F: if its run becomes empty the two neighbouring blocks keep
43: their identity or fuse, and fusing never increases the number of odd blocks).  Both w_i are RGR.  A third rotation
44: lies in both, so their pairs {c_1, -c_1}, {c_2, -c_2} coincide and every rotation of w lies in it; deleting a rotation
45: only creates new adjacencies between reflections, so two adjacent reflections of different values in w would stay
46: adjacent in w_1.  Hence w is RGR.
47: In Cases 2 and 3, RGR-LONG(p) gives w an identity 2p-subword: contradiction.  []
