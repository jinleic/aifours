## §0 Monotonicity in p and the capacity statement

`D_{η1} ∘ D_{η2} = D_{η1 η2}`. For `0 ≤ η2 ≤ η1 ≤ 1`, `D_{η2} = D_{η2/η1} ∘ D_{η1}` with `D_{η2/η1}` CPTP, so by data
processing `I_c(ρ, D_{η2}^{⊗M}) ≤ I_c(ρ, D_{η1}^{⊗M})`. A certified `I_c(ρ, N_{p0}^{⊗M}) > 0` therefore gives

## §1 Sector decomposition (independent re-derivation of 2609.39747 Thm II.3/II.9)

**Lemma 1 (two-row Schur–Weyl).** `(C²)^{⊗M} ≅ ⊕_N Q_N ⊗ P_N`, `N ∈ {M, M−2, …}`, `Q_N ≅ Sym^N(C²)`,
`m_N := dim P_N = C(M,λ) − C(M,λ−1)` with `λ = (M−N)/2`, and for every `A ∈ L(C²)`:
`A^{⊗M} ≅ ⊕_N (det A)^{λ} S_N(A) ⊗ I_{P_N}`, `S_N(A) := A^{⊗N}|_{Sym^N}`. (Standard; proved from first principles in
2608.15870 App. E, Lemma E1; extends from GL(2) to all A by continuity.)

**Lemma 2.** For `X ∈ L(Sym^M)`: `D_η^{⊗M}(X) ≅ ⊕_N p_N Φ_N(X) ⊗ I_{P_N}/m_N` with
`Φ_N = Σ_{s=0}^{N} π_s C_{s→N} ∘ L_{M→s}`, where `L_{M→s} = tr_{M−s}` (restricted to Sym), the cloner
`C_{s→N}(Z) = (s+1)/(N+1) · P_N (Z ⊗ I^{⊗(N−s)}) P_N`, and
`π_s = C(N+1,s+1)(2η)^{s+1}(1−η)^{N−s} / ((1+η)^{N+1} − (1−η)^{N+1})`,
`p_N = m_N (ab)^{λ} (a^{N+1} − b^{N+1})/η`.

*Proof.* Products `|u⟩⟨v|^{⊗M}` span `L(Sym^M)` (polarization). With `g = ⟨v|u⟩` and
`A_uv := D_η(|u⟩⟨v|) = b g I + η|u⟩⟨v|`, `det A_uv = b²g² + bηg² = ab g²`, and `D_η^{⊗M}(|u⟩⟨v|^{⊗M}) = A_uv^{⊗M}`.
By Lemma 1 the output is block diagonal with Q_N-part `Ψ_N(|u⟩⟨v|^{⊗M}) = (ab)^λ g^{2λ} S_N(A_uv)`, extended
linearly. Since `L_{M→N}(|u⟩⟨v|^{⊗M}) = g^{M−N} |u⟩⟨v|^{⊗N}` and `P_N A^{⊗N} P_N = S_N(A)`,
`Ψ_N = (ab)^λ · P_N D_η^{⊗N}( L_{M→N}(·) ) P_N`. Expanding `D_η = η·id + b·tr(·)I` over subsets S of the N qubits,
`P_N D_η^{⊗N}(Y) P_N = Σ_s C(N,s) η^s b^{N−s} P_N (L_{N→s}(Y) ⊗ I^{⊗(N−s)}) P_N
 = Σ_s C(N+1,s+1) η^s b^{N−s} C_{s→N}(L_{N→s}(Y))` (permutations are absorbed by P_N; `C(N,s)(N+1)/(s+1) = C(N+1,s+1)`).
With `L_{N→s} L_{M→N} = L_{M→s}` and tr-preservation of `C, L`, `tr Ψ_N(X) = (ab)^λ q_N tr X`,
`q_N = Σ_s C(N+1,s+1) η^s b^{N−s} = ((η+b)^{N+1} − b^{N+1})/η = (a^{N+1} − b^{N+1})/η`. Normalizing gives Φ_N, π_s
(multiply numerator/denominator by `2^{N+1}`) and `p_N = m_N tr Ψ_N(X)`. ∎

**Corollary.** For `|Ψ⟩ = Σ_i √q_i |i⟩_R |φ_i⟩` with `φ_i ∈ Sym^M`, linearity gives
`(id_R ⊗ D^{⊗M})(Ψ) ≅ ⊕_N p_N (id ⊗ Φ_N)(Ψ) ⊗ I/m_N`; the multiplicity entropies `H(p) + Σ p_N log m_N` cancel in

## §2 Single-particle steps (Schwinger form)

Identify `Sym^n` with n bosons in two modes; Dicke `|n;x⟩ = |n−x, x⟩` (x = number of `|1⟩`s). For `ψ ∈ Sym^n`,
`P_{n+1}(|ψ⟩ ⊗ |i⟩) = (n+1)^{−1/2} a_i^† |ψ⟩` and `(⟨i| ⊗ I)|ψ⟩ = n^{−1/2} a_i|ψ⟩` (standard first↔second
quantization identities; checked on occupation basis states). Hence
`L_{n→n−1}(X) = tr_1 X = (1/n) Σ_i a_i X a_i^†`,
`C_{n→n+1}(Z) = (n+1)/(n+2) Σ_i P(Z⊗|i⟩⟨i|)P = (1/(n+2)) Σ_i a_i^† Z a_i`, and `C_{s→N} = C_{N−1→N} ∘ … ∘ C_{s→s+1}`
because `P_{n+2}(P_{n+1} ⊗ I) = P_{n+2}`. In the Dicke basis:
`[L(X)]_{xy} = (1/n)[√((n−x)(n−y)) X_{xy} + √((x+1)(y+1)) X_{x+1,y+1}]`,
`[C(Z)]_{xy} = (1/(n+2))[√((n+1−x)(n+1−y)) Z_{xy} + √(xy) Z_{x−1,y−1}]`.
Horner: with `Y_s = L_{M→s}(X)`, `Z_{smin} = π_{smin} Y_{smin}`, `Z_{s+1} = C_{s→s+1}(Z_s) + π_{s+1} Y_{s+1}` gives
`Z_N = Σ_{s≥smin} π_s C_{s→N}(Y_s)`. C never lowers x and L never raises it, so entries with `x, y ≤ D` (resp. the
input support) are computed exactly from entries in the same range: truncation is exact on the kept block.

## §3 Floating-point error model (double-double on nonnegative operands)

`u = 2^{−53}`; every binary64 op is correctly rounded. Standard model *with* gradual underflow:
`fl(x) = x(1+δ) + η`, `|δ| ≤ u`, `|η| ≤ 2^{−1075}`, `δη = 0` (IEEE 754; numpy float64 on arm64 does not flush
subnormals). Each DD primitive therefore has error `≤ ε·|exact| + A_op` with `A_op ≤ 2^{−1000}`: if every
intermediate of the primitive is ≥ 2^{−969} in magnitude, TwoSum/TwoProd/Sterbenz steps are exact and only the
`δ` parts remain; otherwise the failing sub-computation (e.g. a subnormal TwoProd error word, a Dekker split of a
subnormal `π·Y` product) only involves quantities below `2^{−1015}`, so its total absolute damage is `< 2^{−1000}`.
The relative statements below are for the `δ` parts (normal range).
Inputs: every complex amplitude vector is split exactly into ≤ 4 entrywise nonnegative real parts with phases
`1, −1, i, −i`; Φ_N is linear, so each operator `|c_i⟩⟨c_j|` is a phase-weighted sum of ≤ 16 nonnegative outer
products, each formed exactly by TwoProd (`dd.two_prod`). Every subsequent quantity in the recursion is a sum
and product of nonnegative numbers.
Primitive bounds (`δ` parts) for nonnegative DD operands `x = x_h + x_l`, `|x_l| ≤ u x_h` (normalized output of
quick_two_sum):
- `add`: `two_sum` exact; neglected/rounded terms: `fl(x_l + y_l)` (≤ u·u(x_h+y_h)), `fl(e + t)`
  (≤ u(|e|+|t|) ≤ 3u²(x_h+y_h)); final quick_two_sum exact (|e| ≪ s). Total ≤ 4.2 u² (x+y).
- `mul`: `two_prod` exact (Dekker split, no FMA); cross terms `fl(x_h y_l) + fl(x_l y_h)` rounded twice
  (≤ 4.1 u² x y), `fl(e + cross)` (≤ 3.1 u² x y), neglected `x_l y_l` (≤ u² x y). Total ≤ 8.3 u² x y.
- `sqrt_int(m)`, `recip_int(m)` (integers < 2^52): Newton correction from a correctly rounded seed with the
  residual computed exactly by TwoProd and Sterbenz: relative error ≤ 3.1 u².
We use the single constant `ε = 2^{−100} = 64 u²` for every primitive (a factor ≥ 7 slack).
Per loss step the longest chain is: coefficients (`√` twice, outer product: ≤ 2·3.1u² + ε), product with Y (ε),
add (ε), product with `1/n` (ε + 3.1u²): ≤ 5ε. Per add step (incl. `+ π_{s+1} Y_{s+1}`): ≤ 6ε plus the relative
representation error of `π_{s+1}` as a DD (≈ 1e−32 relative: a DD carries ~106 bits; the actual per-sector maximum
`max(pis_rel)` is computed in Arb and added to relE).
Since all terms are nonnegative, relative errors of summands combine by max and of factors by addition, so
after a chain of length L every computed entry `ẑ` satisfies `|ẑ − z| ≤ ((1+ε)^L − 1 + max δπ) z`; cert.py uses
`L = 10 · ((M − smin) + (N − smin)) + 20` (≥ 1.6× the derived count) and inflates by 1.01.
Underflow control: nonzero amplitudes must be ≥ 1e−100 (so all inputs ≥ 1e−200); after every step entries
below `2^{−900}` are set to 0. Intermediates (low words, TwoProd error words, `π·Y` products with `π` as small as
1e−40) CAN be subnormal; no normality is assumed. Absolute contributions: (i) a flushed perturbation R_t

< 2·10⁻²⁸⁶. Their sum is far

## §4 Truncation, tails, sector bounds

## §5 Entropy enclosure of a Hermitian PSD block A (tr A ≤ 1)

V = binary64 eigenvectors of the midpoint (exact dyadic matrix). In Arb: `W = V*AV`, `G = V*V`,
`δ ≥ ‖G − I‖_F ≥ ‖G − I‖_2` (require δ < 1e−6). Ostrowski: `λ_k(W) = θ_k λ_k(A)`, `θ_k ∈ [1−δ, 1+δ]` (sorted).
Gershgorin for Hermitian W: every eigenvalue lies in `∪_i [W_ii − r_i, W_ii + r_i]`, `r_i ≥ Σ_{j≠i}|W_ij|`; a connected
component of k discs contains exactly k eigenvalues (continuity of eigenvalues along `diag W + t(W − diag W)`).
Dividing by θ (outward) gives intervals for A's eigenvalues, clipped to [0,1]; on each component the k
eigenvalues contribute to `S = Σ h(λ)` between `k·min h` and `k·max h` over the interval (h concave, increasing on
[0,1/e], decreasing on [1/e,1], max `log₂e/e`). Endpoint values of h are Arb enclosures; all conversions to
binary64 are rounded outward (`nextafter`).
Lowest-cluster refinement (code versions after the M=2000 p=1/5 run; the snapshot in

`m/k ≤ 1/e`. Only the upper entropy bound uses this; the lower bound for that cluster stays `k·min h ≥ 0`.

**Normalization and weights.** The certified state is `φ_i = a_i/‖a_i‖` for the dyadic witness vectors `a_i` exactly

## §6 What a certificate is (verification protocol, v3)

A run writes one JSON record per sector carrying `witness_sha256`, `cert_py_sha256`, `dd_py_sha256`, `M`, `p`,
`D_param`, `ptail`, `pitail` and the rigorous sector bounds. `combine.py` rejects (with a named reason) records from

field bitwise. Acceptance requires replay of every sector (a full rerun) or an independent recomputation.

import numpy as np
import flint
from flint import arb, arb_mat, acb, acb_mat

import dd as DDm
from dd import DD

PREC = 160
flint.ctx.prec = PREC
EPS = Fraction(1, 2 ** 100)   # per-operation relative error constant of dd.py on nonnegative operands
STEP_OPS = 10                 # error-chain length per loss/add step (PROOFS §3 shows <= 6)
FLUSH = 2.0 ** -900           # nonzero values below are set to 0 (absolute damage bounded in PROOFS §3/_v2 A3)
ABS_ENTRY = 1e-250            # absolute per-entry budget: flushes + underflow (PROOFS §3, PROOFS_v2 A3)
LOG2 = arb(2).log()
INV_E_LO, INV_E_HI = 0.367879, 0.367880
CODE_SHA256 = hashlib.sha256(open(__file__, "rb").read()).hexdigest()
DD_SHA256 = hashlib.sha256(open(DDm.__file__, "rb").read()).hexdigest()


def A(x) -> arb:
    if isinstance(x, Fraction):
        return arb(x.numerator) / arb(x.denominator)
    if isinstance(x, (int, float)):
        return arb(x)
    if isinstance(x, arb):
        return x
    raise TypeError(type(x))


def up(x) -> float:
    return float(np.nextafter(float(x.upper()), np.inf))


def lo(x) -> float:
    return float(np.nextafter(float(x.lower()), -np.inf))


def h_point(x: float) -> arb:
    if x <= 0.0:
        return arb(0)
    X = arb(x)
    return -X * X.log() / LOG2


def h_range(a: float, b: float):
    """[min, max] of h(x) = -x log2 x over x in [a, b] intersected with [0, 1] (floats, outward)."""
    a = min(max(a, 0.0), 1.0)
    b = min(max(b, a), 1.0)
    ha, hb = h_point(a), h_point(b)
    hmin = max(min(lo(ha), lo(hb)), 0.0)
    if b <= INV_E_LO:
        hmax = up(hb)
    elif a >= INV_E_HI:
        hmax = up(ha)
    else:
        hmax = up(1 / (arb(1).exp() * LOG2))
    return hmin, hmax


def h2_upper(x: float) -> float:
    """upper bound of binary entropy h2(x) for 0 <= x <= 1/2."""
    if x <= 0:
        return 0.0
    X = arb(x)
    return up((-X * X.log() - (1 - X) * (1 - X).log()) / LOG2)


# ----------------------------------------------------------------------------------------------- witness
def parse_witness(w):
    M = int(w["M"])
    p = Fraction(w["p"])
    eta = 1 - Fraction(4, 3) * p
    qs = [Fraction(x) for x in w["q"]]
    assert sum(qs) == 1 and all(q > 0 for q in qs)
    amps = []
    for row in w["amps"]:
        if row and isinstance(row[0], list):
            amps.append(np.array([complex(float.fromhex(a), float.fromhex(b)) for a, b in row]))
        else:
            amps.append(np.array([float.fromhex(a) for a in row]))
    return M, p, eta, qs, amps, w.get("k"), w.get("residues"), int(w["D"])


def positive_parts(c: np.ndarray):
    """exact split c = sum_t phase_t v_t, v_t >= 0, phases in {1,-1,1j,-1j}."""
    re = np.real(c).astype(np.float64)
    im = np.imag(c).astype(np.float64) if np.iscomplexobj(c) else np.zeros_like(re)
    out = []
    for ph, v in ((1, np.maximum(re, 0)), (-1, np.maximum(-re, 0)), (1j, np.maximum(im, 0)),
                  (-1j, np.maximum(-im, 0))):
        if np.any(v > 0):
            out.append((ph, v))
    return out


# ----------------------------------------------------------------------------------------------- probabilities
def sector_probs_arb(M: int, eta: Fraction):
    a, b = (1 + eta) / 2, (1 - eta) / 2
    Aa, Ab, Ae = A(a), A(b), A(eta)
    out = {}
    for N in range(M % 2, M + 1, 2):
        lam2 = (M - N) // 2
        m = math.comb(M, lam2) - (math.comb(M, lam2 - 1) if lam2 >= 1 else 0)
        out[N] = arb(m) * (Aa * Ab) ** lam2 * (Aa ** (N + 1) - Ab ** (N + 1)) / Ae
    return out


def pi_arb(N: int, eta: Fraction):
    Ae = A(eta)
    two_e, one_m = 2 * Ae, 1 - Ae
    den = (1 + Ae) ** (N + 1) - (1 - Ae) ** (N + 1)
    res = []
    pa, pb = two_e, one_m ** N
    inv = 1 / one_m
    for s in range(N + 1):
        res.append(arb(math.comb(N + 1, s + 1)) * pa * pb / den)
        pa *= two_e
        pb *= inv
    return res


def arb_to_dd(x: arb):
    m = x.mid()
    hi = float(m)
    lo_ = float(m - arb(hi))
    err = abs(x - (arb(hi) + arb(lo_))) + x.rad()
    return DD(np.array(hi), np.array(lo_)), (up(err / x) if lo(x) > 0 else float("inf"))


# ----------------------------------------------------------------------------------------------- DD recursion
def _flush(Z: DD) -> DD:
    small = (Z.hi < FLUSH) & (Z.hi != 0)
    if np.any(small):
        Z.hi[small] = 0.0
        Z.lo[small] = 0.0
    return Z


def _scal(Z: DD, c: DD) -> DD:
    return DDm.mul(Z, DD(np.broadcast_to(c.hi, Z.shape), np.broadcast_to(c.lo, Z.shape)))


def loss_step_dd(Y: DD, n: int) -> DD:
    """[L_{n->n-1} Y]_xy = (1/n)[sqrt((n-x)(n-y)) Y_xy + sqrt((x+1)(y+1)) Y_{x+1,y+1}] (PROOFS §2)."""
    d = Y.shape[0]
    dn = min(d, n)
    a = DDm.sqrt_int(n - np.arange(dn, dtype=np.float64))
    out = DDm.mul(DDm.outer(a, a), Y[:dn, :dn])
    m = min(dn, d - 1)
    if m > 0:
        b = DDm.sqrt_int(np.arange(1, m + 1, dtype=np.float64))
        t2 = DDm.mul(DDm.outer(b, b), Y[1:m + 1, 1:m + 1])
        s = DDm.add(out[:m, :m], t2)
        out.hi[:m, :m] = s.hi
        out.lo[:m, :m] = s.lo
    return _flush(_scal(out, DDm.recip_int(np.array(float(n)))))


def add_step_dd(Z: DD, n: int, Dmax: int) -> DD:
    """[C_{n->n+1} Z]_xy = (1/(n+2))[sqrt((n+1-x)(n+1-y)) Z_xy + sqrt(xy) Z_{x-1,y-1}], x,y <= Dmax."""
    d = Z.shape[0]
    dn = min(d + 1, n + 2, Dmax + 1)
    out = DD(np.zeros((dn, dn)), np.zeros((dn, dn)))
    m0 = min(d, dn)
    a = DDm.sqrt_int(n + 1 - np.arange(m0, dtype=np.float64))
    t1 = DDm.mul(DDm.outer(a, a), Z[:m0, :m0])
    out.hi[:m0, :m0] = t1.hi
    out.lo[:m0, :m0] = t1.lo
    m1 = min(d, dn - 1)
    if m1 > 0:
        b = DDm.sqrt_int(np.arange(1, m1 + 1, dtype=np.float64))
        t2 = DDm.mul(DDm.outer(b, b), Z[:m1, :m1])
        s = DDm.add(out[1:m1 + 1, 1:m1 + 1], t2)
        out.hi[1:m1 + 1, 1:m1 + 1] = s.hi
        out.lo[1:m1 + 1, 1:m1 + 1] = s.lo
    return _flush(_scal(out, DDm.recip_int(np.array(float(n + 2)))))


def axpy_dd(Z: DD, pi: DD, Y: DD) -> DD:
    m = min(Y.shape[0], Z.shape[0])
    t = _scal(Y[:m, :m], pi)
    s = DDm.add(Z[:m, :m], t)
    Z.hi[:m, :m] = s.hi
    Z.lo[:m, :m] = s.lo
    return Z


STRIDE = 20   # checkpoint spacing of the loss chain (memory ~ (M-smin)/STRIDE + STRIDE matrices per chain)


class LossChain:
    """Y_s = L_{M->s}(X) with checkpoints at s = M, at multiples of STRIDE and at the lowest level reached.

    The same deterministic loss steps are replayed from a checkpoint, so replayed values are bitwise identical
    to a single straight descent (error model unchanged)."""

    def __init__(self, X: DD, M: int):
        self.ck = {M: X}
        self.low = M

    def extend_to(self, s: int):
        Y, t = self.ck[self.low], self.low
        while t > s:
            Y = loss_step_dd(Y, t)
            t -= 1
            if t % STRIDE == 0 or t == s:
                self.ck[t] = Y
        self.low = min(self.low, s)

    def segment(self, lo_: int, hi_: int):
        """{s: Y_s} for lo_ <= s <= hi_ (requires lo_ >= self.low)."""
        if lo_ < self.low:
            self.extend_to(lo_)
        start = min(l for l in self.ck if l >= hi_)
        Y, t = self.ck[start], start
        out = {}
        if lo_ <= t <= hi_:
            out[t] = Y
        while t > lo_:
            Y = loss_step_dd(Y, t)
            t -= 1
            if t <= hi_:
                out[t] = Y
        return out

    def drop_above(self, top: int):
        """keep the smallest checkpoint >= top and everything below it."""
        keep = min(l for l in self.ck if l >= top)
        for l in [l for l in self.ck if l > keep]:
            del self.ck[l]


def sector_output_dd(chain: LossChain, N: int, smin: int, pis_dd, D: int) -> DD:
    """Z = sum_{s=smin}^{N} pi_s C_{s->N}(Y_s), entries x,y <= D (Horner, PROOFS §2).

    Y_s are replayed in checkpoint-aligned segments [k*STRIDE, (k+1)*STRIDE-1] so each is computed once."""
    chain.extend_to(smin)
    Z = None
    s = smin
    while s <= N:
        seg_hi = min((s // STRIDE + 1) * STRIDE - 1, N)
        Ys = chain.segment(s, seg_hi)
        for t in range(s, seg_hi + 1):
            Y = Ys[t]
            if Z is None:
                m = min(Y.shape[0], D + 1)
                Z = _scal(Y[:m, :m], pis_dd[t])
                Z = DD(np.ascontiguousarray(Z.hi), np.ascontiguousarray(Z.lo))
            else:
                Z = add_step_dd(Z, t - 1, D)
                Z = axpy_dd(Z, pis_dd[t], Y)
        s = seg_hi + 1
    return Z


# ----------------------------------------------------------------------------------------------- entropy
def entropy_enclosure(entries, n: int, complex_: bool, mid: np.ndarray):
    """[lo, hi] for S(A) (bits); A Hermitian PSD, tr A <= 1, entries = nested lists of arb/acb (PROOFS §5)."""
    if n == 0:
        return 0.0, 0.0, {"n": 0}
    Am = acb_mat(entries) if complex_ else arb_mat(entries)
    _, V = np.linalg.eigh(mid)
    if complex_:
        Va = acb_mat([[acb(float(V[i, j].real), float(V[i, j].imag)) for j in range(n)] for i in range(n)])
        Vh = Va.transpose().conjugate()
    else:
        Va = arb_mat(V.tolist())
        Vh = Va.transpose()
    W = Vh * Am * Va
    G = Vh * Va
    d2 = arb(0)
    for i in range(n):
        for j in range(n):
            g = G[i, j] - 1 if i == j else G[i, j]
            d2 += abs(g) ** 2
    delta = up(d2.sqrt())
    if not delta < 1e-6:
        raise RuntimeError(f"Gram defect too large: {delta}")
    lows, highs = [], []
    for i in range(n):
        rsum = arb(0)
        for j in range(n):
            if j != i:
                rsum += abs(W[i, j])
        c = W[i, i].real if complex_ else W[i, i]
        lows.append(lo(c - rsum))
        highs.append(up(c + rsum))
    order = sorted(range(n), key=lambda i: lows[i])
    comps = []
    cur, cur_lo, cur_hi = [order[0]], lows[order[0]], highs[order[0]]
    for i in order[1:]:
        if lows[i] <= cur_hi:
            cur.append(i)
            cur_hi = max(cur_hi, highs[i])
        else:
            comps.append((cur, cur_lo, cur_hi))
            cur, cur_lo, cur_hi = [i], lows[i], highs[i]
    comps.append((cur, cur_lo, cur_hi))
    one_m, one_p = arb(1) - arb(delta), arb(1) + arb(delta)
    S_lo, S_hi = arb(0), arb(0)
    worst = 0.0
    for ci, (idx, a_, b_) in enumerate(comps):
        kc = len(idx)
        a_A = lo(arb(a_) / (one_p if a_ >= 0 else one_m))
        b_A = up(arb(b_) / (one_m if b_ >= 0 else one_p))
        hmin, hmax = h_range(a_A, b_A)
        if ci == 0 and kc > 1:
            # Lowest cluster = the kc smallest eigenvalues of W. Ky Fan: their sum <= tr of any kc-dim
            # compression, e.g. sum_{i in cluster} W_ii.  Hence sum of the kc smallest eigenvalues of A
            # <= (sum W_ii + kc*max(-a_,0)) / (1-delta); with each in [0, 1], concavity gives
            # sum h <= kc * h(mass/kc) whenever mass/kc <= 1/e (PROOFS §5).
            tr = arb(0)
            for i in idx:
                tr += (W[i, i].real if complex_ else W[i, i])
            mass = up((tr + kc * arb(max(-a_, 0.0))) / one_m)
            x = float(np.nextafter(max(mass, 0.0) / kc, np.inf))   # rounded up; h increasing on [0, 1/e]
            if x <= INV_E_LO:
                hmax = min(hmax, up(h_point(x)))
        S_lo += kc * arb(hmin)
        S_hi += kc * arb(hmax)
        worst = max(worst, kc * (hmax - hmin))
    return lo(S_lo), up(S_hi), {"n": n, "delta": delta, "components": len(comps), "worst": worst}


# ----------------------------------------------------------------------------------------------- sector
def operator_arb(parts, relE: float, idx_a, idx_b, scale: arb, complex_: bool):
    """Exact-midpoint ball entries for sum_t phase_t * Z_t restricted to (idx_a x idx_b), times scale."""
    na, nb = len(idx_a), len(idx_b)
    rad = np.zeros((na, nb))
    for _, Z in parts:
        rad += Z.hi[np.ix_(idx_a, idx_b)]
    # rad >= relE * sum_t value_t (value_t <= hi_t (1 + 2^-52)) + ABS_ENTRY (PROOFS §3)
    rad = rad * (relE * (1 + 1e-6)) + ABS_ENTRY
    rows = []
    for a in range(na):
        row = []
        for b in range(nb):
            if complex_:
                re, im = arb(0), arb(0)
                for ph, Z in parts:
                    v = arb(float(Z.hi[idx_a[a], idx_b[b]])) + arb(float(Z.lo[idx_a[a], idx_b[b]]))
                    re += v * ph.real
                    im += v * ph.imag
                rr = float(rad[a, b])
                row.append(acb(re + arb(0, rr), im + arb(0, rr)) * scale)
            else:
                v = arb(0)
                for ph, Z in parts:
                    v += (arb(float(Z.hi[idx_a[a], idx_b[b]])) + arb(float(Z.lo[idx_a[a], idx_b[b]]))) * int(np.real(ph))
                row.append((v + arb(0, float(rad[a, b]))) * scale)
        rows.append(row)
    return rows


def run_sector(N, M, chains, keys, qs, norms2, k, residues, D, smin, pis, pis_dd, pis_rel, complex_, Srho_hi):
    t0 = time.time()
    r = len(qs)
    outs = {}
    for key in keys:
        outs[key] = [(ph, sector_output_dd(ch, N, smin, pis_dd, D)) for ph, ch in chains[key]]
    nsteps = (M - smin) + (N - smin)
    L = STEP_OPS * nsteps + 20
    relE = up((1 + A(EPS)) ** L - 1) * 1.01 + 1.01 * max(pis_rel)
    dB = outs[keys[0]][0][1].shape[0]
    Dm = dB - 1
    if k is None and Dm < N:
        raise ValueError("non-modular inputs require D >= N (no truncation)")
    pi_mass = arb(0)
    for s in range(smin, N + 1):
        pi_mass += pis[s]
    eps_tail = max(up(1 - pi_mass), 0.0)
    inv_mass = 1 / pi_mass
    xs = np.arange(dB)
    sc_B = [A(qs[i]) / norms2[i] * inv_mass for i in range(r)]
    sc_RB = {(i, j): (A(qs[i]) * A(qs[j]) / (norms2[i] * norms2[j])).sqrt() * inv_mass
             for i in range(r) for j in range(r)}
    # truncated traces -> flag weights w_i (exact-midpoint arb sums)
    ws = []
    for i in range(r):
        parts = outs[(i, i)]
        tr = arb(0)
        rad_tr = 0.0
        for ph, Z in parts:
            for x in range(dB):
                v = arb(float(Z.hi[x, x])) + arb(float(Z.lo[x, x]))
                tr += v * (int(np.real(ph)) if not complex_ else ph.real)
                rad_tr += float(Z.hi[x, x])
        tr = tr + arb(0, rad_tr * relE * (1 + 1e-6) + dB * ABS_ENTRY)
        ws.append(1 - tr / norms2[i] * inv_mass)
    if Dm >= N:   # no truncation: T_D is the identity, the flag carries exactly zero weight (PROOFS §4)
        ws = [arb(0) for _ in range(r)]
    if k is None:
        blocks_B = [xs]
        blocks_RB = [[xs for _ in range(r)]]
    else:
        blocks_B = [np.nonzero(xs % k == c)[0] for c in range(k)]
        blocks_RB = [[np.nonzero(xs % k == (c + residues[i]) % k)[0] for i in range(r)] for c in range(k)]
    SB = [arb(0), arb(0)]
    SRB = [arb(0), arb(0)]
    info = []
    for ix in blocks_B:
        n = len(ix)
        entries = None
        mid = np.zeros((n, n), dtype=np.complex128 if complex_ else np.float64)
        for i in range(r):
            blk = operator_arb(outs[(i, i)], relE, ix, ix, sc_B[i], complex_)
            entries = blk if entries is None else [[entries[a][b] + blk[a][b] for b in range(n)] for a in range(n)]
            for ph, Z in outs[(i, i)]:
                mid += (ph if complex_ else np.real(ph)) * (Z.hi + Z.lo)[np.ix_(ix, ix)] * float(sc_B[i].mid())
        l_, h_, inf = entropy_enclosure(entries, n, complex_, mid)
        SB[0] += arb(l_)
        SB[1] += arb(h_)
        info.append(("B", inf))
    for ids in blocks_RB:
        sizes = [len(v) for v in ids]
        offs = np.concatenate([[0], np.cumsum(sizes)]).astype(int)
        nn = int(offs[-1])
        entries = [[None] * nn for _ in range(nn)]
        mid = np.zeros((nn, nn), dtype=np.complex128 if complex_ else np.float64)
        for i in range(r):
            for j in range(r):
                if i <= j:
                    blk = operator_arb(outs[(i, j)], relE, ids[i], ids[j], sc_RB[(i, j)], complex_)
                    for ph, Z in outs[(i, j)]:
                        mid[offs[i]:offs[i + 1], offs[j]:offs[j + 1]] += (ph if complex_ else np.real(ph)) * \
                            (Z.hi + Z.lo)[np.ix_(ids[i], ids[j])] * float(sc_RB[(i, j)].mid())
                else:
                    blk_t = operator_arb(outs[(j, i)], relE, ids[j], ids[i], sc_RB[(i, j)], complex_)
                    blk = [[(blk_t[b][a].conjugate() if complex_ else blk_t[b][a]) for b in range(sizes[j])]
                           for a in range(sizes[i])]
                    mid[offs[i]:offs[i + 1], offs[j]:offs[j + 1]] = np.conj(mid[offs[j]:offs[j + 1], offs[i]:offs[i + 1]]).T
                for a in range(sizes[i]):
                    for b in range(sizes[j]):
                        entries[offs[i] + a][offs[j] + b] = blk[a][b]
        l_, h_, inf = entropy_enclosure(entries, nn, complex_, mid)
        SRB[0] += arb(l_)
        SRB[1] += arb(h_)
        info.append(("RB", inf))
    # one flag (PROOFS §4): modular inputs => RB flag block diag(q_i w_i)
    w_lo = [max(lo(w), 0.0) for w in ws]
    w_hi = [max(up(w), 0.0) for w in ws]
    fB = h_range(lo(sum((A(qs[i]) * arb(w_lo[i]) for i in range(r)), arb(0))),
                 up(sum((A(qs[i]) * arb(w_hi[i]) for i in range(r)), arb(0))))
    fRB = [h_range(lo(A(qs[i]) * arb(w_lo[i])), up(A(qs[i]) * arb(w_hi[i]))) for i in range(r)]
    if k is None and Dm < N:
        raise ValueError("non-modular inputs require D >= N")
    ic_lo = (SB[0] + arb(fB[0])) - (SRB[1] + sum(arb(f[1]) for f in fRB))
    ic_hi = (SB[1] + arb(fB[1])) - (SRB[0] + sum(arb(f[0]) for f in fRB))
    w_tot = up(sum((A(qs[i]) * arb(w_hi[i]) for i in range(r)), arb(0)))
    # ---- lower bound for I_c(rho, Phi_N)  (PROOFS §4): DPI, then pi-tail almost-convexity
    e = eps_tail
    h2e = h2_upper(e) if e > 0 else 0.0
    icl = lo(ic_lo)
    lowN = ((1 - arb(e)) * arb(icl) if icl >= 0 else arb(icl)) - arb(e) * arb(Srho_hi) - arb(h2e)
    # ---- upper bound: pinching + AFW (needs small w), flag correction, pi-tail
    icu = up(ic_hi) + sum(f[1] for f in fRB)
    sw = math.sqrt(w_tot) * (1 + 1e-12)
    afw = 0.0
    if sw > 0:
        afw = w_tot * math.log2(r) + 2 * sw * math.log2(r) + (1 + sw) * h2_upper(min(sw / (1 + sw), 0.5))
        afw *= 1 + 1e-12
    upI = arb(icu) + arb(afw)
    upN = ((1 - arb(e)) * upI if lo(upI) < 0 else upI) + arb(e) * arb(Srho_hi) + arb(h2e)
    return {"N": N, "lo": lo(lowN), "hi": up(upN), "ic_trunc": [lo(ic_lo), up(ic_hi)], "eps_tail": e,
            "w_tail": w_tot, "relE": relE, "smin": smin, "nsteps": nsteps, "D": Dm,
            "secs": round(time.time() - t0, 2), "blocks": info}


def certify(witness, sectors_only=None, ptail=1e-30, pitail=1e-40, verbose=True, log=None):
    M, p, eta, qs, amps, k, residues, D = parse_witness(witness)
    r = len(qs)
    complex_ = any(np.iscomplexobj(c) and np.any(np.imag(c) != 0) for c in amps)
    K = max(len(c) for c in amps) - 1
    amps = [np.pad(c, (0, K + 1 - len(c))) for c in amps]
    for c in amps:
        nz = np.abs(c[c != 0])
        if nz.size and nz.min() < 1e-100:
            raise ValueError("witness amplitudes must be 0 or >= 1e-100 in modulus")
    assert M + D < 10 ** 6 and D < 10 ** 4
    norms2 = []
    for c in amps:
        s = arb(0)
        for z in c:
            if z != 0:
                s += arb(float(np.real(z))) ** 2 + arb(float(np.imag(z))) ** 2
        norms2.append(s)
    orth = all(np.vdot(amps[i], amps[j]) == 0 for i in range(r) for j in range(i + 1, r))
    if orth:   # rho = sum q_i |c_i><c_i| with orthonormal c_i: S(rho) = H(q)
        Srho = sum((-A(q) * A(q).log() / LOG2 for q in qs), arb(0))

            sel.append(n)
        else:
            rest += pN[n]

        # same phase only when their supports are disjoint (then the entrywise sum is exact); otherwise it
        # gets its own chain. Real signed inputs: (+,+)&(-,-) merge, (+,-)&(-,+) merge -> 2 chains.
        groups = []
        for ph_a, va in parts[i]:
            for ph_b, vb in parts[j]:

                Xh, Xl = DDm.two_prod(np.outer(va, np.ones(K + 1)), np.outer(np.ones(K + 1), vb))
                for g in groups:

                        g[1] = DD(g[1].hi + Xh, g[1].lo + Xl)   # disjoint supports: exact
                        break
                else:
                    groups.append([ph, DD(Xh, Xl)])
        chains[(i, j)] = [((ph.real if (ph.imag == 0 and not complex_) else ph), LossChain(G, M))
                          for ph, G in groups]

            rels.append(rel)
        res = run_sector(N, M, chains, keys, qs, norms2, k, residues, D, smin, pis, pis_dd, rels, complex_, Srho_hi)
        res["pN"] = float(pN[N].mid())
        tot_lo += pN[N] * arb(res["lo"])
        tot_hi += pN[N] * arb(res["hi"])
        for lst in chains.values():
            for _, ch in lst:
                ch.drop_above(N - 2)
        results.append(res)
        if verbose:
            print(f"N={N} pN={res['pN']:.3e} Ic_N in [{res['lo']:+.9e},{res['hi']:+.9e}] smin={smin} "
                  f"w={res['w_tail']:.1e} eps={res['eps_tail']:.1e} relE={res['relE']:.1e} t={res['secs']}s",
                  flush=True)

            rec = {k_: v for k_, v in res.items() if k_ != "blocks"}
            rec.update({"witness_sha256": witness_sha256(witness), "cert_py_sha256": CODE_SHA256,

            log.flush()

"""Vectorized double-double (DD) arithmetic on numpy float64 arrays, IEEE binary64 round-to-nearest.

A DD number is a pair (hi, lo) of float64 arrays representing hi + lo.  Only error-free transformations
(TwoSum, Dekker split/TwoProd) and correctly rounded +,-,*,/ are used, so the code is deterministic and
platform independent (numpy float64 ops are IEEE correctly rounded; no FMA is used anywhere).

Rigorous error model used by cert.py (u = 2^-53, all magnitudes far from overflow/underflow; cert.py asserts
the exponent range at runtime):
  * add(a, b)  : |res - (a+b)| <= EPS_ADD * (|a| + |b|)
  * mul(a, b)  : |res - a*b|   <= EPS_MUL * |a| * |b|
  * mul_d(a, d): |res - a*d|   <= EPS_MUL * |a| * |d|        (d a float64)
  * Inputs carry their own absolute error bounds; cert.py propagates bounds with a separate float64
    magnitude recursion inflated by safety factors (see cert.py).
Derivation sketch (proved in review/PROOFS.md): TwoSum and TwoProd are exact; for add, the neglected
rounding errors are fl(a.lo+b.lo) (<= u|a.lo+b.lo| <= u^2(|a|+|b|)(1+u)) and fl(e + t) (<= u(|e|+|t|) <=
u(u+u^2)(|a|+|b|)*2), and the final quick_two_sum is exact when |s| >= |e|, giving < 4u^2(|a|+|b|).
For mul, neglected terms are a.lo*b.lo (<= u^2|ab|(1+u)^2), and roundings of the two cross products and of
two sums, each <= u * (2u + u^2)|ab|(1+u)^2, giving < 8u^2|a||b|.  We use EPS_ADD = EPS_MUL = 2^-100
(~ 7.9e-31 = 64.5 u^2), a factor > 8 above the derived constants.
"""
from __future__ import annotations

import numpy as np

U = 2.0 ** -53
EPS_ADD = 2.0 ** -100
EPS_MUL = 2.0 ** -100
_SPLIT = 134217729.0  # 2^27 + 1


def two_sum(a, b):
    s = a + b
    bb = s - a
    e = (a - (s - bb)) + (b - bb)
    return s, e


def quick_two_sum(a, b):
    s = a + b
    e = b - (s - a)
    return s, e


def split(a):
    t = _SPLIT * a
    hi = t - (t - a)
    lo = a - hi
    return hi, lo


def two_prod(a, b):
    p = a * b
    ah, al = split(a)
    bh, bl = split(b)
    e = ((ah * bh - p) + ah * bl + al * bh) + al * bl
    return p, e


class DD:
    __slots__ = ("hi", "lo")

    def __init__(self, hi, lo=None):
        self.hi = np.asarray(hi, dtype=np.float64)
        self.lo = np.zeros_like(self.hi) if lo is None else np.asarray(lo, dtype=np.float64)

    def copy(self):
        return DD(self.hi.copy(), self.lo.copy())

    def __getitem__(self, idx):
        return DD(self.hi[idx], self.lo[idx])

    def __setitem__(self, idx, val):
        self.hi[idx] = val.hi
        self.lo[idx] = val.lo

    @property
    def shape(self):
        return self.hi.shape

    def to_float(self):
        return self.hi + self.lo


def add(a: DD, b: DD) -> DD:
    s, e = two_sum(a.hi, b.hi)
    t = a.lo + b.lo
    e = e + t
    hi, lo = quick_two_sum(s, e)
    return DD(hi, lo)


def mul(a: DD, b: DD) -> DD:
    p, e = two_prod(a.hi, b.hi)
    e = e + (a.hi * b.lo + a.lo * b.hi)
    hi, lo = quick_two_sum(p, e)
    return DD(hi, lo)


def mul_d(a: DD, d) -> DD:
    """DD times float64 (array or scalar)."""
    d = np.asarray(d, dtype=np.float64)
    p, e = two_prod(a.hi, d)
    e = e + a.lo * d
    hi, lo = quick_two_sum(p, e)
    return DD(hi, lo)


def outer(a: DD, b: DD) -> DD:
    """outer product of two DD vectors (one DD multiplication per entry)."""
    A = DD(np.broadcast_to(a.hi[:, None], (a.hi.shape[0], b.hi.shape[0])),
           np.broadcast_to(a.lo[:, None], (a.hi.shape[0], b.hi.shape[0])))
    B = DD(np.broadcast_to(b.hi[None, :], (a.hi.shape[0], b.hi.shape[0])),
           np.broadcast_to(b.lo[None, :], (a.hi.shape[0], b.hi.shape[0])))
    return mul(A, B)


def sqrt_int(m) -> DD:
    """DD enclosure-quality sqrt of nonnegative integers m < 2^52 (exactly representable).

    s = fl(sqrt(m)); r = m - s^2 computed exactly via two_prod; correction c = r/(2s).
    Relative error <= 3u^2 (Newton step from a correctly rounded seed); m = 0 -> 0.
    """
    m = np.asarray(m, dtype=np.float64)
    s = np.sqrt(m)
    p, e = two_prod(s, s)
    r = (m - p) - e  # exact: m - p is exact (Sterbenz, p within 1 ulp of m); then one rounding
    with np.errstate(divide="ignore", invalid="ignore"):
        c = np.where(s > 0, r / (2.0 * s), 0.0)
    hi, lo = quick_two_sum(s, c)
    return DD(hi, lo)


def recip_int(m) -> DD:
    """DD approximation of 1/m for positive integers m < 2^52; relative error <= 3u^2."""
    m = np.asarray(m, dtype=np.float64)
    x = 1.0 / m
    p, e = two_prod(m, x)
    r = (1.0 - p) - e
    c = r * x
    hi, lo = quick_two_sum(x, c)
    return DD(hi, lo)

"""Combine per-sector records of cert.py into the global enclosure, with discriminating rejections (v3).

python combine.py WITNESS.json PART*.sectors.jsonl --ptail 1e-13 --pitail 1e-40 --out total.json [--allow-missing]

LIMIT: records are replayable evidence, not proof. combine.py checks provenance, parameters, coverage and
interval sanity, but it cannot detect a record whose numbers were altered consistently; replay.py recomputes
sectors and compares them bitwise. A certificate is accepted only after replay of every sector (full rerun) or
an independent recomputation.

Rejections raise Reject(reason) with reason in:
  witness_hash, no_provenance, cert_hash, dd_hash, param_mismatch, duplicate, order, nonfinite,
  unexpected_sector, missing

import argparse
import json

import numpy as np
from flint import arb

import cert
from cert import A, LOG2, lo, parse_witness, sector_probs_arb, up, witness_sha256


class Reject(Exception):
    def __init__(self, reason, detail=""):
        super().__init__(f"REJECT {reason}: {detail}")
        self.reason = reason


def combine(w, parts, ptail, pitail, allow_missing=False, expect_cert=None, expect_dd=None):

    expect_dd = expect_dd or cert.DD_SHA256

    Srho_hi = up(Srho)

    selset = set(sel)

    wsha = witness_sha256(w)
    got = {}
    for f in parts:
        for line in open(f):
            if not line.strip():
                continue
            rec = json.loads(line)
            N = rec.get("N")
            for key in ("witness_sha256", "cert_py_sha256", "dd_py_sha256", "M", "p", "D_param", "ptail", "pitail"):
                if key not in rec:
                    raise Reject("no_provenance", f"sector {N} in {f} lacks {key}")
            if rec["witness_sha256"] != wsha:
                raise Reject("witness_hash", f"sector {N} in {f}")
            if rec["cert_py_sha256"] != expect_cert:
                raise Reject("cert_hash", f"sector {N}: {rec['cert_py_sha256'][:12]} != {expect_cert[:12]}")
            if rec["dd_py_sha256"] != expect_dd:
                raise Reject("dd_hash", f"sector {N}")
            if (rec["M"], rec["p"], rec["D_param"], rec["ptail"], rec["pitail"]) != (M, str(p), D, ptail, pitail):
                raise Reject("param_mismatch", f"sector {N}: {(rec['M'], rec['p'], rec['D_param'], rec['ptail'], rec['pitail'])}")
            vals = [rec["lo"], rec["hi"], *rec["ic_trunc"], rec["eps_tail"], rec["w_tail"], rec["relE"]]
            if not all(isinstance(v, (int, float)) and math.isfinite(v) for v in vals):
                raise Reject("nonfinite", f"sector {N}")
            if rec["lo"] > rec["hi"] or rec["ic_trunc"][0] > rec["ic_trunc"][1]:
                raise Reject("order", f"sector {N}: lo {rec['lo']} > hi {rec['hi']}")
            if N not in selset:
                raise Reject("unexpected_sector", f"sector {N} not in the ptail-selected set")
            if N in got:
                raise Reject("duplicate", f"sector {N}")
            got[N] = rec
    missing = [n for n in sel if n not in got]
    if missing and not allow_missing:
        raise Reject("missing", f"{len(missing)} selected sectors absent, e.g. {missing[:5]}")
    tot_lo, tot_hi = arb(0), arb(0)
    for n in sel:
        if n in got:
            tot_lo += pN[n] * arb(got[n]["lo"])
            tot_hi += pN[n] * arb(got[n]["hi"])
        else:   # explicit honest bound for an omitted sector: -S(rho) <= I_c(Phi_N) <= S(rho)
            tot_lo -= pN[n] * arb(Srho_hi)
            tot_hi += pN[n] * arb(Srho_hi)
    tot_lo -= rest * arb(Srho_hi)
    tot_hi += rest * arb(Srho_hi)
    omitted_mass = up(sum((pN[n] for n in missing), arb(0)))
    return {"witness_sha256": wsha, "cert_py_sha256": expect_cert, "dd_py_sha256": expect_dd,
            "M": M, "p": str(p), "eta": str(eta), "D": D, "ptail": ptail, "pitail": pitail,
            "lower": lo(tot_lo), "upper": up(tot_hi), "selected_sectors": len(sel), "computed": len(got),
            "missing": missing, "omitted_mass_hi": omitted_mass, "rest_mass_hi": up(rest), "Srho_hi": Srho_hi,
            "max_relE": max((g["relE"] for g in got.values()), default=None),
            "max_w_tail": max((g["w_tail"] for g in got.values()), default=None),
            "max_eps_tail": max((g["eps_tail"] for g in got.values()), default=None),
            "classification": "POS" if lo(tot_lo) > 0 else ("NEG" if up(tot_hi) < 0 else "UNDECIDED"),
            "note": "records are replayable evidence; acceptance requires replay.py on every sector or an independent recomputation"}
