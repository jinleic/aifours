Write an independent Python3 STANDARD-LIBRARY verifier for a certificate of a point-cyclic resolution of a cyclic 2-(v,4,1) design, from ONLY the definitions and format below. Do not use tools. Return exactly one fenced Python code block and nothing else. No asserts (checks must survive python -O), no writes, network or subprocess. Read the input bytes exactly once; verify the expected SHA-256 before parsing. CLI: checker.py EXPECTED_V FILE EXPECTED_SHA256. Print one JSON object; exit 0 iff valid; on invalid input print a precise invariant-specific reason and exit 1.
Definitions (Topalova–Zhelezova 2026). Points V = Z_v = {0..v-1}. A 2-(v,4,1) design is a collection of 4-subsets (blocks) of V such that every 2-subset of V lies in exactly one block; it then has v(v-1)/12 blocks. A parallel class is a set of blocks partitioning V (v/4 blocks). A resolution is a partition of the collection of blocks into parallel classes ((v-1)/3 classes). An automorphism of the design is a permutation of V mapping the block collection onto itself; an automorphism of the resolution is a design automorphism mapping every parallel class onto a parallel class. A resolution is point-cyclic if it has an automorphism permuting the points in one cycle. The certificate claims that the map s(x) = x+1 mod v is such an automorphism: verify that the block collection is invariant under s, and that for every class C, s(C) = {s(B) : B in C} is again one of the listed classes. Also report the orbit lengths of the classes under s (as a sorted list) and the number of block orbits under s with their lengths.
Format (text, ASCII only, LF line endings, final LF, no comments, no blank lines, no trailing whitespace, no CR, no leading zeros, single spaces): first line 'POINT-CYCLIC-RESOLUTION v 4 c b' with c=(v-1)/3 and b=v/4 (reject any other values, including v not equal to EXPECTED_V or v not congruent to 4 mod 12); then exactly c*b lines 'j p1 p2 p3 p4' where j is the class index, the class indices are nondecreasing and run 0,0,...,1,1,...,c-1 with exactly b lines per class, and p1<p2<p3<p4 are points of V. No other lines.
Check everything directly: block count, distinct blocks, every 2-subset of V covered exactly once (compare against the full set of C(v,2) pairs), every class a partition of V, every block in exactly one class, invariance of the block collection under s, and s mapping each class onto a listed class (as sets of blocks). Report counts (blocks, pairs covered, classes, blocks per class, class-orbit lengths, block-orbit lengths).
