0211| **Lemma A.** Let X be an m×m Metzler matrix (m ≥ 2) and λ a non-real eigenvalue. Then
0212| |Im λ| ≤ (s(X) − Re λ) cot(π/m).
0213| 
0214| *Irreducible case.* μ := s(X); Perron–Frobenius gives r > 0 with Xr = μr, and Re λ < μ for every eigenvalue λ ≠ μ
0215| (primitivity of X + κI). Q := diag(r)⁻¹(X − μI)diag(r) is Metzler with Q𝟙 = 0; z := λ − μ is an eigenvalue of Q
0216| with eigenvector w ∈ ℂ^m; after conjugating if necessary z = −x + iy, x > 0, y > 0; z = |z|e^{i(π−φ)} with
0217| φ := arctan(y/x) ∈ (0, π/2). For r ≥ 0, e^{Qr} is stochastic and e^{Qr}w = e^{zr}w, so with
0218| K := conv{w₁, …, w_m} ⊂ ℂ ≅ ℝ² (multiplication by e^{zr} is ℝ-linear) e^{zr}K ⊆ K.
0219| 1. 0 ∈ K (closed; e^{zr}w_i → 0). K is not in a line L: else 0 ∈ L and for w_i ≠ 0 the arguments arg w_i + yr of
0220|    e^{zr}w_i ∈ L would stay in {ϑ, ϑ + π} mod 2π.
0221| 2. 0 ∈ int K: else a unit ν has Re(ν̄w) ≥ 0 on K; a vertex v ≠ 0 exists, and for r with arg(e^{zr}v) = arg(−ν),
0222|    Re(ν̄e^{zr}v) < 0.
0223| 3. K is a convex polygon with vertices v₁, …, v_p (counter-clockwise, 3 ≤ p ≤ m, v_k ≠ 0); ω_k ∈ (0, π) is the
0224|    angle at 0 of Δ_k = (0, v_k, v_{k+1}) (indices mod p), Σω_k = 2π; ε_k is its angle at v_k, so its angle at v_{k+1}
0225|    is π − ω_k − ε_k.
0226| 4. K ⊆ v_k + C_k, C_k := cone(v_{k+1} − v_k, v_{k−1} − v_k) (closed, angular width < π, containing −v_k in its
0227|    interior). e^{zr}v_k ∈ K gives zv_k ∈ C_k. Rotating so that v_k > 0: −v_k has direction π, v_{k+1} − v_k has
0228|    direction π − ε_k (upper half plane, since arg(v_{k+1}/v_k) = ω_k ∈ (0, π)), v_{k−1} − v_k points into the lower
0229|    half plane, and zv_k has direction π − φ. Hence φ ≤ ε_k for all k.
0230| 5. Law of sines in Δ_k: |v_{k+1}|/|v_k| = sin ε_k / sin(ω_k + ε_k) =: g_k(ε_k); the product over k is 1.
0231|    (log g_k)′ = cot ε − cot(ω_k + ε) > 0 on (0, π − ω_k), and φ ≤ ε_k < π − ω_k, so 1 ≥ Π_k g_k(φ):
0232|    sin^pφ ≤ Π_k sin(ω_k + φ), all ω_k + φ ∈ (0, π).
0233| 6. log sin is concave on (0, π): sin φ ≤ sin(φ + 2π/p) with φ + 2π/p ∈ (0, π). For 0 < u < v < π, sin u ≤ sin v
0234|    ⇔ u + v ≤ π; so 2φ + 2π/p ≤ π, i.e. y/x = tan φ ≤ cot(π/p) ≤ cot(π/m).

0029| ## 1. Exact question (contract `exact_statement`; not the book's general question)
0030| 
0031| For all real a > c > 0, b > 0, let F(s) = c(a²+b²)/[(s+c)((s+a)²+b²)]. A PH representation of order n is
0032| (α, T): α ≥ 0 row vector with α1 = 1; T real n×n Metzler, T1 ≤ 0, Hurwitz; F(s) = α(sI−T)⁻¹(−T1).
0033| Claim to settle: the minimum order equals n* = min{n ≥ 3 : b ≤ (a−c)cot(π/n)} (upper band endpoints included,
0034| lower endpoints use the smaller n). Negative alternative: explicit (a,b,c) with a proof that **no** PH
0035| representation of order n* exists, over all topologies.
0036|
