160: ## 6. Lemma SPLIT (new)
161: 
162: **Lemma SPLIT.**  Let C be a nonempty set of cheap runs with C != [k], and let E be the set of empty runs in C (all of them
163: empty defects).  Then there are U*, V* with U* u V* = C, U* n V* = E,
164:    min(c(U*), c(V*)) >= floor((|C| + |E|)/2),   BH(U*) + BH(V*) = BH(C) + BH(E) <= BH(C) - 2|E|.
165: Proof.  C' := C \ E.  A C'-block is a maximal set of cyclically consecutive runs of C'; no C'-block is the whole cycle.  An
166: E-block is a maximal set of consecutive runs of E; m(E) := number of E-blocks; each E-block has at most two outer neighbours
167: (the runs just outside it), which are not in E.  For each C'-block beta = (t_1, ..., t_L) put its two classes
168: {t_1, t_3, ...} and {t_2, t_4, ...}; choosing an orientation per block sends one class to U', the other to V'.  U' and V' are
169: independent (runs of one class of a block are not adjacent; different C'-blocks are separated by a run outside C').  Let
170: a(U') := number of pairs (b, t), b an E-block, t in U' an outer neighbour of b; similarly a(V'); a(U') + a(V') <= 2 m(E).
171: Put U* := U' u E, V* := V' u E.  The U'-runs are pairwise non-adjacent and so are the E-blocks; the adjacency graph between
172: U'-runs and E-blocks is a disjoint union of paths (no cycle, as U* != [k]), so m(U*) = |U'| + m(E) - a(U') and
173:    c(U*) = W(U') + phi(E) + m(E) - a(U') >= (|U'| - a(U')) + |E| + m(E)
174: (cheap runs have w >= 1, empty defects phi >= 1); likewise for V*.  For a C'-block with L runs whose end runs t_1, t_L have
