31: ## Theorem
32: 
33: Let G be any group. Let a_1G_1, …, a_5G_5 be pairwise disjoint left cosets of subgroups of finite index. Then gcd([G:G_i], [G:G_j]) ≥ 5 for some i < j.
34: 
35: ## 1. R0: reduction to finite groups
36: 
37: core_G(G_i) is the kernel of the action of G on G/G_i, so its index is at most [G:G_i]!. Hence N = ∩_i core_G(G_i) is a normal subgroup of finite index contained in every G_i.
38: 
39: Each coset a_iG_i is the full preimage of its image in G/N. So indices, intersection indices and disjointness all pass to the finite group G/N.
40: 
41: ## 2. R1: reduction to Core(5), with a self-contained proof of M-S Prop 4.5
42: 
43: **Core(5)** says: no finite group G has subgroups U_1, …, U_5 with [G:U_i] = 4r_i, the r_i pairwise coprime, and pairwise disjoint cosets g_iU_i.
44: 
45: **(Sun(5) ⇒ Core(5)).** A Core(5) configuration has every pairwise gcd equal to 4 < 5.
46: 
47: **(Core(5) ⇒ Sun(5)), group by group.** Let n_i = [G:G_i], and assume five disjoint cosets in G have all pairwise gcds ≤ 4.
48: 
49: 1. **Each gcd is 2, 3 or 4.** By L0.2 and L0.6 no gcd equals 1, so each lies in {2, 3, 4}.
50: 2. **All divisible by 3, or all even.** If some n_i is odd, every gcd with it is odd and so equals 3. Then 3 divides all five indices.
51: 3. **All divisible by 3.** Every gcd is then 3 < 4. Any four of the cosets contradict Zhu Theorem 1.1 at k = 4.
52: 4. **All even.** Write n_i = 2^{e_i}m_i with m_i odd. Then the m_i are pairwise coprime, every e_i ≥ 1, and at most one e_i ≥ 3.
53:    - **Two indices with e = 1.** With any third index they have all pairwise gcds equal to 2 < 3, contradicting Zhu Theorem 1.1 at k = 3.
54:    - **Exactly one index with e = 1.** We get (2r_1, 4r_2, 4r_3, 4r_4) with r_1 odd and the r's pairwise coprime. This is excluded by Proposition 4.5 below.
55:    - **Otherwise.** n_i = 4r_i with r_i = 2^{e_i−2}m_i pairwise coprime: a Core(5) configuration *in the same group G* with the same subgroups.
56: 
57: **Proposition 4.5 (M-S, Beitr. Algebra Geom. 60 (2019); proof patched per F-2 and F-8).**
58: 
59: *Statement.* Let r_1, …, r_4 be pairwise coprime with r_1 odd. Then no group has subgroups with indices [G:U_1] = 2r_1 and [G:U_i] = 4r_i (i = 2, 3, 4) and pairwise disjoint cosets g_iU_i.
60: 
61: *Proof.* By R0 we may take G finite. All sizes below are in units of |G|, and α(i,j) := [G:U_i∩U_j] / lcm(n_i, n_j).
62: 
63: - **(a) α(1,i) = 1 and |U_1U_i| = 1/2 for i ≥ 2.** gcd(2r_1, 4r_i) = 2, so α ≤ 1 by L0.3.
64: - **(b) α(i,j) ≠ 2 for i, j ≥ 2.** Suppose α(2,3) = 2, so [G:U_2∩U_3] = 8r_2r_3.
65:   - T = [G:U_1∩U_2∩U_3] is divisible by 2r_1 and by 8r_2r_3, hence by 8r_1r_2r_3.
66:   - So |U_1(U_2∩U_3)| = T/(2r_1·8r_2r_3) ≥ 1/2 = |U_1U_2| = |U_1U_3|. Hence U_1U_2 = U_1(U_2∩U_3) = U_1U_3.
67:   - Apply Lemma K (rules-v1 L3) at vertex 2 with S = {1, 3}. The pair condition U_1U_2 ⊆ U_1U_3 holds. So we would need |U_1U_2| + |U_3U_2| < 1, but the sum is 1/2 + 1/2 = 1. Contradiction.
68: - **(c) If α(2,3) = 3, then 3 | r_1 and |U_2U_1 ∩ U_2U_3| = 1/4. (F-2 patch.)**
69:   - T = [G:U_1∩U_2∩U_3] is divisible by lcm(2r_1, 4r_2, 4r_3) = 4r_1r_2r_3. Write T = 4r_1r_2r_3τ.
70:   - [G:U_2∩U_3] = 12r_2r_3 divides T, so 3 | r_1τ.
71:   - [G:U_1∩U_3] = 4r_1r_3 by (a). So |U_2(U_1∩U_3)| = T / (4r_2·4r_1r_3) = τ/4 ≤ |U_2U_1| = 1/2. Hence τ ≤ 2, so 3 ∤ τ, and therefore 3 | r_1.
72:   - U_2U_1 ∩ U_2U_3 contains U_2(U_1∩U_3), so its size is ≥ τ/4 ≥ 1/4. By L0.5 and L0.4 it is a union of (U_2, U_1∩U_3)-double cosets, each of size a multiple of 1/gcd(4r_2, 4r_1r_3) = 1/4.
73:   - Its size is not 1/2 = |U_2U_1|. Otherwise U_2U_1 ⊆ U_2U_3, and Lemma K at vertex 1 with S = {2, 3} would give |U_2U_1| + |U_3U_1| = 1, a contradiction. Hence the size is exactly 1/4.
74: - **(d) Not all of α(2,3), α(2,4), α(3,4) equal 1.** Suppose they all do.
75:   - The triangle {2, 3, 4} has τ ≤ 1 (rules-v1 T2), so τ = 1. Then |U_2(U_4∩U_3)| = 1/4 = |U_2U_4|, which gives U_2U_4 ⊆ U_2U_3.
76:   - In the triangle {1, 2, 4}, T is a multiple of 4r_1r_2r_4. So |U_1(U_4∩U_2)| = T/(2r_1·4r_2r_4) ≥ 1/2 = |U_1U_4|, which gives U_1U_4 ⊆ U_1U_2. Likewise U_1U_4 ⊆ U_1U_3.
77:   - So every pair in S = {1, 2, 3} satisfies the pair condition of Lemma K at vertex 4, in the form "U_iU_4 ⊆ U_iU_j".
78:   - Lemma K then requires 1/2 + 1/4 + 1/4 < 1, which fails.
79: - **(e) Choosing labels.** By (b) and (d), some α(i,j) with i, j ≥ 2 equals 3; relabel so that α(2,3) = 3. By (c), 3 | r_1.
80:   - α(2,4) and α(3,4) cannot both be 1. Otherwise the triangle {2, 3, 4} has τ ≤ α(2,4)α(3,4) = 1, and then 12r_2r_3 | 4r_2r_3r_4 gives 3 | r_4. That contradicts 3 | r_1.
81:   - So, after swapping 2 and 3 if necessary, α(2,4) = 3.
82: - **(f) α(3,4) = 3.** Suppose α(3,4) = 1.
83:   - In the triangle {2, 3, 4}, write T = 4r_2r_3r_4τ. Then 12r_2r_3 | T and 12r_2r_4 | T. Since 3 ∤ r_3r_4 (because 3 | r_1), we get 3 | τ.
84:   - So |U_3(U_2∩U_4)| = τ/(4·3) ≥ 1/4 = |U_3U_4|, which gives U_3U_4 ⊆ U_3U_2.
85:   - Lemma K at vertex 4 with S = {2, 3} then requires 3/4 + 1/4 < 1, which fails.
86: - **(g) Final count.** Now α(1,i) = 1, α(i,j) = 3 for all i, j ∈ {2, 3, 4}, and 3 | r_1.
87:   - By (c), applied to the pairs (2,3) and (2,4): |U_2U_1 ∪ U_2U_j| = 1/2 + 3/4 − 1/4 = 1 for j = 3, 4.
88:   - |U_2U_3 ∩ U_2U_4| is a multiple of 1/gcd(4r_2, 12r_3r_4) = 1/4, using 3 ∤ r_2. This is F-8: only the multiple of 1/4 is used.
89:   - That size is at least 3/4 + 3/4 − 1 = 1/2. It is not 3/4: otherwise U_2U_3 = U_2U_4, and Lemma K at vertex 3 with S = {2, 4} would give 3/4 + 3/4 < 1. So the size is 1/2, and U_2U_3 ∪ U_2U_4 = G.
90:   - By M-S Lemma 3.1, applied with R = U_2U_1, S = U_2U_3, T = U_2U_4 (all pairwise unions are G):
91:     |R ∩ S ∩ T| = |R| − |G∖S| − |G∖T| = 1/2 − 1/4 − 1/4 = 0.
92:   - But U_2 ⊆ R ∩ S ∩ T, a contradiction. ∎
93: 
94:   *Proof of M-S Lemma 3.1 as used.* G∖S and G∖T are disjoint subsets of R, so R ∩ S ∩ T = R ∖ ((G∖S) ⊔ (G∖T)).

143: ## 5. Lemma R and the refutation of S-D
144: 
145: S-D is the pattern:
146: - α01 = α02 = 1, α03 = α04 = 2, and the other six α equal 3;
147: - E2 = 1, E3 = 0, and r_2, r_3, r_4 coprime to 6.
148: 
149: **Lemma R (right-coset fibres over a vertex subgroup) [NEW].**
150: 
151: *Setting.* Fix a vertex v and normalise g_v = 1. For j ≠ v put D_j = U_vg_jU_j and d_j = |D_j|/|U_j|. In Core(5), |D_j| = q_j|G|/4 with q_j a positive integer, so d_j = q_jr_j.
152: 
153: *Statements.*
154: - **(R1)** D_j ∩ U_vU_j = ∅.
155: - **(R2)** |D_j| is a positive multiple of |G|/gcd(n_v, n_j). In Core(5), 1 ≤ q_j ≤ 4 − α_vj.
156: - **(R3)** Every right coset U_vy ⊆ D_j meets g_jU_j. The piece g_jU_j ∩ U_vy is a right coset of a subgroup of index d_j in U_v.
157: - **(R5)** If j ≠ k and D_j ∩ D_k ≠ ∅, then gcd(d_j, d_k) ≥ 2.
158: 
159: *Proofs.* As in proof-v2. (R5) applies the k = 2 case directly to the two pieces of j and k inside one right coset C ⊆ D_j ∩ D_k (F-1).
160: 
161: **Refutation of S-D.** Take v = 2 and the sets X_j = U_2U_j.
162: 
163: 1. For j ∈ {1, 3, 4}, Y_j = G ∖ X_j has size |G|/4. Hence D_j = Y_j, q_j = 1 and d_j = r_j.
164: 2. The sets Y_1, Y_3, Y_4 are pairwise disjoint, by (R5) and coprimality of the r_j.
165: 3. τ_012 = 1 and τ_023 = τ_024 = 2. So by (T3), X_0 ⊆ X_1 ∩ X_3 ∩ X_4.
166: 4. Therefore G ∖ X_0 = Y_1 ⊔ Y_3 ⊔ Y_4.
167: 5. D_0 ⊆ G ∖ X_0, with d_0 = q_0r_0 and q_0 ∈ {1, 2, 3}. So D_0 meets some Y_j, and (R5) gives gcd(q_0, r_j) ≥ 2.
168:    - This is impossible for j = 3, 4.
169:    - So D_0 ⊆ Y_1, which forces q_0 = 1 by size. But then gcd(1, r_1) = 1, a contradiction. (proof-v2's route through q_0 = 2 is also valid.) ∎

9: ## Theorem
10: 
11: Let G be any group. Let a_1G_1, …, a_5G_5 be pairwise disjoint left cosets of subgroups of finite index. Then gcd([G:G_i], [G:G_j]) ≥ 5 for some i < j.

13: ## Proof structure
14: 
15: 1. **R0** (README §2): we may assume G is finite.
16: 2. **R1** (README §2): it suffices to prove **Core(5)**. Core(5) asserts that no finite group has subgroups U_1, …, U_5 with [G:U_i] = 4r_i, the r_i pairwise coprime, and pairwise disjoint cosets g_iU_i.
17:    - R1 uses M-S Props 4.2, 4.3 and 4.5 (Beitr. Algebra Geom. 60 (2019)). Zhu Theorems 2.2 and 3.1 supply Props 4.2 and 4.3 independently.
18: 3. Suppose Core(5) fails. Choose a counterexample with |G| minimal among finite groups containing five pairwise disjoint cosets with all pairwise index-gcds ≤ 4. 31: ## Lemma R: right-coset fibres over a vertex subgroup [NEW, unreviewed]
32: 
33: **Setting.** Harmonic configuration (rules-v1 §0). Fix a vertex v, and translate so that g_v = 1. For j ≠ v put D_j = U_v g_j U_j, a (U_v, U_j)-double coset, and d_j = |D_j| / |U_j|.
34: 
35: **Statement.**
36: - **(R1)** D_j ∩ U_vU_j = ∅. So D_j ⊆ G ∖ U_vU_j.
37: - **(R2)** |D_j| is a positive multiple of |G| / gcd(n_v, n_j).
38: - **(R3)** Every right coset U_vy contained in D_j meets g_jU_j. If w ∈ g_jU_j ∩ U_vy, then g_jU_j ∩ U_vy = (U_v ∩ wU_jw⁻¹)w, and [U_v : U_v ∩ wU_jw⁻¹] = d_j.
39: - **(R4)** Let C = U_vy be a right coset, and let S_C = {j ≠ v : C ⊆ D_j}. If |S_C| = s ≥ 2, then gcd(d_j, d_k) ≥ s for some j ≠ k in S_C.
40: - **(R5)** If D_j ∩ D_k ≠ ∅ (j ≠ k), then D_j ∩ D_k contains a whole right coset U_vy. Hence gcd(d_j, d_k) ≥ 2.
41: 
42: **Proof.**
43: - **(R1)** By L0.2, disjointness of g_vU_v = U_v and g_jU_j gives g_j ∉ U_vU_j. Now U_vU_j = U_v·1·U_j is the double coset of 1. Distinct double cosets are disjoint, so D_j ∩ U_vU_j = ∅.
44: - **(R2)** This is L0.4.
45: - **(R3)** Take U_vy ⊆ D_j.
46:   - Write y = c g_j u with c ∈ U_v and u ∈ U_j. Then U_vy = U_v g_j u contains g_ju ∈ g_jU_j.
47:   - For w ∈ g_jU_j ∩ U_vy we have g_jU_j = wU_j and U_vy = U_vw. Then x ∈ wU_j ∩ U_vw ⟺ xw⁻¹ ∈ wU_jw⁻¹ ∩ U_v.
48:   - The index is [U_v : U_v ∩ wU_jw⁻¹] = |U_v · wU_jw⁻¹| / |wU_jw⁻¹| = |U_vwU_j| / |U_j| = |D_j| / |U_j|, since w ∈ D_j.
49: - **(R4)** Fix w_0 ∈ C. By (R3), for each j ∈ S_C the piece g_jU_j ∩ C is a right coset (U_v ∩ w_jU_jw_j⁻¹)w_j with w_j ∈ C.
50:   - Right-multiplying by w_0⁻¹ gives right cosets A_j c_j of subgroups A_j ≤ U_v with [U_v : A_j] = d_j, where c_j = w_jw_0⁻¹ ∈ U_v.
51:   - These cosets are pairwise disjoint, because the g_jU_j are. Inversion turns them into the pairwise disjoint left cosets c_j⁻¹A_j of U_v.
52:   - So (d_j)_{j∈S_C} is U_v-harmonic. Sun's statement for k = s holds in U_v: by L0.6 for s = 2, Zhu for s = 3, 4. Here s ≤ 4 automatically, since S_C ⊆ the other vertices.
53: - **(R5)** D_j and D_k are both left U_v-invariant, so their intersection is too. A non-empty left U_v-invariant set contains a full right coset U_vy. Apply (R4) with s ≥ 2. ∎
54: 
55: **Core(5) form.** By (R2), |D_j| = s_j |G|/4 with s_j a positive integer. By (R1), s_j ≤ 4 − α_vj. Then d_j = s_j |G|/4 ÷ (|G|/(4r_j)) = s_j r_j.

57: ## Refutation of S-D
58: 
59: Assume a Core(5) configuration with pattern S-D. Take v = 2, translate so that g_2 = 1, and put X_j = U_2U_j for j ∈ {0, 1, 3, 4}.

16: ## 0. Setting and notation
17: 
18: **Harmonic configuration.** G is a finite group. U_1, ..., U_k ≤ G are subgroups with n_i = [G:U_i], and g_1, ..., g_k ∈ G are elements such that the cosets g_iU_i are pairwise disjoint. Finiteness of G is justified by R0 in the README.
19: 
20: **Pairwise data.** For each pair i ≠ j put
21: - g_ij = gcd(n_i, n_j);
22: - I_ij = [G : U_i ∩ U_j];
23: - α_ij = I_ij / lcm(n_i, n_j). This is an integer, because n_i and n_j both divide I_ij.
24: 
25: **The Core(5) setting.**
26: - k = 5 and n_i = 4 r_i, where the r_i are pairwise coprime positive integers.
27: - E2 is the unique vertex with r_i even, if there is one. E3 is the unique vertex with 3 | r_i, if there is one. E2 = E3 is allowed.
28: - Consequently g_ij = 4, lcm(n_i, n_j) = 4 r_i r_j and I_ij = 4 r_i r_j α_ij.
29: 
30: **Minimal counterexample (used in F2).** Suppose Core(5) fails. Fix a counterexample in a group G of minimal order among all finite groups that contain five pairwise disjoint cosets of subgroups whose pairwise index-gcds are all ≤ 4. Then every proper subgroup of G satisfies Sun's statement for k = 5.

36: **L0.2 [PUB, M-S Lemma 3.2(3)].** gU ∩ hV = ∅ if and only if g⁻¹h ∉ UV.

40: **L0.3.** In a harmonic configuration, |U_iU_j| = α_ij |G| / g_ij and 1 ≤ α_ij ≤ g_ij − 1. In Core(5) this reads α_ij ∈ {1, 2, 3} and |U_iU_j| = α_ij |G| / 4.

42: *Proof.*
43: - By L0.1, |U_iU_j| = |G| I_ij / (n_i n_j) = |G| lcm(n_i, n_j) α_ij / (n_i n_j) = α_ij |G| / g_ij.

46: **L0.4 [PUB, M-S Lemma 3.4(1)].** For subgroups A, B and any x ∈ G, |AxB| is a multiple of |G| / gcd([G:A], [G:B]).

48: *Proof.*

50: - [G : A ∩ xBx⁻¹] is a multiple of lcm([G:A], [G:B]).
51: - Substituting gives |AxB| = (integer) · |G| / gcd([G:A], [G:B]).

70: ## L1. Triangle lemma T [NEW form; subsumes M-S Lemma 3.10(a),(c) and Zhu (3.1), (3.4)]
71: 
72: Fix distinct vertices a, b, c. Put L = lcm(n_a, n_b, n_c) and T = [G : U_a∩U_b∩U_c].
73: 
74: **Statement.** L divides T. The quotient τ = T/L is a positive integer satisfying:
75: 
76: - **(T1)** I_xy divides L·τ for each pair {x, y} ⊆ {a, b, c}.
77: - **(T3)** For every labelling {x, y, z} = {a, b, c}:
78:   |U_y(U_x∩U_z)| = |G| · L · τ / (n_y · I_xz).
79: - **(T2)** For every labelling, |U_y(U_x∩U_z)| ≤ min(|U_yU_x|, |U_yU_z|).
80: 
81: *Proof.*
82: - The triple intersection lies in each U_x and in each U_x∩U_y. Hence every n_x divides T, so L | T. Likewise every I_xy divides T = Lτ, which is (T1).
83: - (T3) is L0.1 applied with |U_y| = |G|/n_y, |U_x∩U_z| = |G|/I_xz and |U_x∩U_y∩U_z| = |G|/T.
84: - (T2) holds because U_y(U_x∩U_z) ⊆ U_yU_x ∩ U_yU_z.
85: 
86: **Definitions.**
87: - τ_min is the least positive τ satisfying (T1). The set of solutions of (T1) is exactly the set of multiples of τ_min, since I_xy | Lτ ⟺ (I_xy / gcd(I_xy, L)) | τ.
88: - τ_max is the largest τ satisfying (T2) at all three apexes.
89: 
90: **T-kill.** If τ_min > τ_max, no harmonic configuration has these data.
91: 
92: **Core(5) form.**
93: - L = 4 r_a r_b r_c.
94: - (T1) ⟺ α_xy | r_z τ.
95: - (T3) reads |U_y(U_x∩U_z)| = τ |G| / (4 α_xz).
96: - (T2) ⟺ τ ≤ α_xy α_xz and τ ≤ α_yz α_xz.
97: 
98: So τ_max is the smallest product of two of the three α's. Also τ_min = lcm over the edges xy of α_xy / gcd(α_xy, r_z). Here gcd(α, r_z) = α exactly when α = 2 and z = E2, or α = 3 and z = E3; otherwise it is 1.

110: ## L3. Lemma K [NEW generalisation of M-S Lemma 3.5; subsumes Cor 3.6, Prop 3.8, Cor 3.9, Lemma 3.10(b), Cor 3.11]
111: 
112: **Statement.** Let v be a vertex and S a set of other vertices. Suppose that for every pair {i, j} ⊆ S,
113: 
114:   U_vU_i ⊆ U_jU_i   or   U_vU_j ⊆ U_iU_j.
115: 
116: Then Σ_{i∈S} |U_iU_v| ≤ |G| − |U_v| < |G|, that is, Σ_{i∈S} α_iv / g_iv < 1. In Core(5) this reads Σ_{i∈S} α_iv ≤ 3.
117: 
118: *Proof.*
119: 1. **The sets g_iU_iU_v (i ∈ S) are pairwise disjoint.** Suppose g_iu_iu = g_ju_ju' with u, u' ∈ U_v.
120:    - Then g_j⁻¹g_i = u_j u' u⁻¹ u_i⁻¹ ∈ U_jU_vU_i.
121:    - If U_vU_i ⊆ U_jU_i, then U_jU_vU_i ⊆ U_jU_i. This contradicts L0.2 for the disjoint pair g_jU_j, g_iU_i.
122:    - If instead U_vU_j ⊆ U_iU_j, then g_i⁻¹g_j ∈ U_iU_vU_j ⊆ U_iU_j, the same contradiction.
123: 2. **None of these sets meets g_vU_v.** Each g_iU_iU_v is right U_v-invariant. If it met g_vU_v it would contain g_v, say g_v = g_iu_iu. Then g_vu⁻¹ = g_iu_i lies in g_vU_v ∩ g_iU_i, which is empty.
124: 3. **Counting.** Summing the sizes |g_iU_iU_v| = |U_iU_v| = α_iv |G| / g_iv gives the claim.
125: 
126: **K1 (links).** The pair condition for {i, j} at v holds if |U_i(U_v∩U_j)| = |U_iU_v|, or if |U_j(U_v∩U_i)| = |U_jU_v|.
127: - By L2, the first equality gives U_vU_i ⊆ U_jU_i, and the second gives U_vU_j ⊆ U_iU_j.
128: - Core(5) form: τ_{ivj} = α_iv α_vj, where the product is of the two α's at v.

130: **K2.** If U_vU_j ⊆ U_vU_k (v, j, k distinct), then α_vj / g_vj + α_kj / g_kj < 1. In Core(5): α_vj + α_kj ≤ 3.
131: 
132: *Proof of K2.* Apply L3 at vertex j with S = {v, k}. Its pair condition requires U_jU_v ⊆ U_kU_v, which is the inverse of the hypothesis.

142: ## L4. Vertex count P [NEW form; subsumes the Lemma 3.1 counts in M-S Props 4.3/4.5 and screen N1]
143: 
144: Fix a vertex v. For each other vertex j put X_j = U_vU_j and Y_j = G ∖ X_j.
145: 
146: **Statement.**
147: - **(P1)** |X_j| = α_vj |G| / g_vj, and U_v ⊆ X_j.
148: - **(P2)** |X_j ∩ X_k| is a multiple of u_vjk = |G| / gcd(n_v, I_jk). In Core(5), u_vjk = |G| / (4 gcd(r_v, α_jk)).
149: - **(P3)** |X_j ∩ X_k| ≥ max(|U_v(U_j∩U_k)|, |X_j| + |X_k| − |G|). The first term is given by (T3).
150: - **(P4)** If |X_j ∩ X_k| = |X_j|, then X_j ⊆ X_k, so K2 must hold for that containment.
151: - **(P5)** For every set S of other vertices:
152:   Σ_{j∈S} |Y_j| − Σ_{j<k in S} |Y_j ∩ Y_k| < |G|,
153:   where |Y_j ∩ Y_k| = |G| − |X_j| − |X_k| + |X_j ∩ X_k|.

155: *Proof.*
156: - (P2): by L0.5, X_j ∩ X_k is a union of (U_v, U_j∩U_k)-double cosets. By L0.4, each has size a multiple of |G| / gcd(n_v, I_jk). In Core(5), gcd(4r_v, 4r_jr_kα_jk) = 4 gcd(r_v, α_jk), because gcd(r_v, r_jr_k) = 1.
157: - (P3): U_v(U_j∩U_k) ⊆ X_j ∩ X_k, and inclusion–exclusion gives the second bound.
158: - (P4): immediate from K2.
159: - (P5): this is the Bonferroni inequality. Also ∪_j Y_j ⊆ G ∖ U_v, which is a proper subset of G.

161: **How the engine uses P (sound).** For each pair {j, k}:
162: - hi_jk is the largest multiple of u that is ≤ min(|X_j|, |X_k|). It is lowered by one unit u when equality would force a containment that K2 forbids. If |X_j| = |X_k|, equality would force X_j = X_k, and then both K2 conditions must hold.
163: - lo_jk is (P3) rounded up to a multiple of u.
164: - If lo_jk > hi_jk the pattern is killed: **P-pair**.
165: - Otherwise the left side of (P5) is non-increasing in each |X_j ∩ X_k|. If (P5) already fails with every |X_j ∩ X_k| set to hi_jk, it fails for the true values, and the pattern is killed: **P-Bonferroni**.

167: ## L5. N2: all ten α = 2 is impossible in Core(5) [NEW, unreviewed]
168: 
169: *Proof.*
170: 1. **Every triangle has τ = 2.** Each edge has α = 2, and at most one vertex is E2. So by (T1) τ is even, and by (T2) τ ≤ 4.
171:    - If τ = 4, then (T2) holds with equality at every apex. So every vertex is linked for the other two (K1), and L3 at any vertex of the triangle gives 2 + 2 ≤ 3, which is false.
172:    - Hence τ = 2. Therefore [G : U_a∩U_b∩U_c] = 8 r_a r_b r_c for every triangle.
173: 2. **Fix a vertex v with r_v odd.** One exists, since at most one r is even. For the other vertices j put X_j = U_vU_j; then |X_j| = |G|/2.
174: 3. **Pairwise intersections.** For other vertices j ≠ k put Z_jk = U_v(U_j∩U_k).
175:    - By (T3), |Z_jk| = 2|G| / (4·2) = |G|/4, and Z_jk ⊆ X_j ∩ X_k.
176:    - By (P2), |X_j ∩ X_k| is a multiple of |G| / (4 gcd(r_v, 2)) = |G|/4.
177:    - |X_j ∩ X_k| ≠ |G|/2: otherwise X_j = X_k, and K2 would give 2 + 2 ≤ 3.
178:    - Hence X_j ∩ X_k = Z_jk.
179: 4. **The three Z's of a triple coincide.** Take distinct other vertices j, k, l and put W = U_j∩U_k∩U_l, so [G:W] = 8 r_j r_k r_l.
180:    - Q = [G : U_v ∩ W] is divisible by the three triangle indices 8 r_v r_j r_k, 8 r_v r_j r_l and 8 r_v r_k r_l. By coprimality, Q is divisible by 8 r_v r_j r_k r_l.

182:    - But U_vW ⊆ Z_jk ∩ Z_jl ∩ Z_kl, and each Z has size |G|/4. Hence Z_jk = Z_jl = Z_kl = U_vW.
183: 5. **Contradiction.** The six sets Z among the four other vertices are therefore all one set Z with |Z| = |G|/4.
184:    - The four sets X_j ∖ Z are pairwise disjoint, each of size |G|/4.
185:    - So |∪_j X_j| = 4·|G|/4 + |G|/4 = 5|G|/4 > |G|, a contradiction.

221: ## L8. Soundness of the engine's evaluation points [NEW]
222: 
223: **(M1) Evaluating at τ = τ_min is enough.** Every admissible τ is a multiple of τ_min, so τ ≥ τ_min. Every rule the engine uses is upward closed in each triangle's τ:
