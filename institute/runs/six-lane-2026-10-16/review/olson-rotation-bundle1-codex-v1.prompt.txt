28: signed sum (copies and lights have absolute weight 1, h has 3) and gives an even count in [s0, s1]:

30:  i = 1 (O1) copy -> an unused X-light (0); (O2) drop the copy and a used Y'-light (-2); (O3) copy and two used X-lights

27: ## 2. Proof
28: 
29: GRX facts for this representation (all blocks odd): for a pattern z with plus-set P, Phi = Phi(z) <= k,
30: delta = k - Phi, C_max = F - k + Phi = 2H + Phi = 2p - 2 + Phi (kappa = 0), so the admissible rotation counts are the
31: even m with 2 - Phi <= m <= 2p - Phi; and R = N - F = N - (2p - 2 + k) <= 2p - k <= 2p - Phi.
32: Step 0 (W <= 2p-1).  If W >= 2p, (FULL) gives a sub-multiset of weight exactly 2p: its value sum is 2p c = 0 mod p,
33: its size is even (odd weights, even total) and at least 2, and at most R < 2p; it is a zero-sum of length in [2, 2p],
34: i.e. a solution for the all-plus pattern (Phi = 0, C = 2p - m in [0, 2p-2] = [Phi, C_max]): w would not avoid.
35: Step 1 (the expanded word).  Let u be w with every rotation x replaced, in place, by a_x copies of rho_c.  u has the
36: same blocks, nonempty runs and all rotations equal to rho_c, so u is an RGR word; its length is N + E.
37: Step 2 (u avoids).  u and w use the same representation, so Phi, C_max and T(z) agree for every pattern z.  Suppose u
38: has an identity 2p-subword with pattern z (plus-set P), C reflections and m = 2p - C rotations: q copies of rho_c
39: from runs in P and q' from runs not in P, q + q' = m, and (q - q') c = T(z) mod p.  Here 0 <= q <= W_P and
40: 0 <= q' <= W_(not P), where W_P is the total weight of the rotations of w in runs of P.
41:  If Phi = 0 then P is all runs (z_1 = +), q' = 0, T(z) = 0, so q = 0 mod p with q even and 2 <= q <= W <= 2p-1:
42:  impossible.  So Phi >= 2.
43:  Let t = q - q'.  The integer t + W_(not P) lies in [0, W]; by (FULL) choose a sub-multiset S of the rotations of w
44:  with weight exactly t + W_(not P).  Select in w the rotations U := S cap (runs of P) and V := (runs not in P) minus S.
45:  Their signed sum in pattern z is (sum_U a - sum_V a) c = (weight(S) - W_(not P)) c = t c = T(z) mod p.
46:  Their number m_w = |U| + |V| satisfies m_w = sum_U a + sum_V a = t (mod 2), and t = q + q' - 2q' = m = 0 (mod 2);
47:  0 <= m_w <= R <= 2p - Phi; and m_w >= 0 >= 2 - Phi.  So C_w := 2p - m_w is even with Phi <= C_w <= C_max, and by
48:  GRX (realisability) w has an identity 2p-subword with pattern z: contradiction.  Hence u avoids.
49: Step 3 (an RGR witness of EXACT length 4p-1).  Call the a_x - 1 copies of rho_c that replace a rotation x beyond its
50: first copy the ADDED copies; there are exactly E of them.  Suppose N + E >= 4p-1 and put d := N + E - (4p-1); since
51: N <= 4p-2, 0 <= d <= E - 1 <= E.  Delete any d ADDED copies from u and nothing else.  No reflection is deleted, so every
52: block keeps its letters, value and position; every run keeps at least the first copy of each of its original rotations,
53: so every run stays nonempty and no two blocks become adjacent (no merging); all rotations are still rho_c.  The result
54: u' is therefore an RGR word (constant maximal cyclic reflection runs, rotations in {rho_c}) of length exactly
55: N + E - d = 4p-1.  It is a subword of u (increasing index sets of u' are increasing index sets of u with the same
56: letters), so it has no identity 2p-subword because u has none (Step 2).  This contradicts RGR-LONG(p).  So
57: N + E <= 4p-2.  []

62: (the number of rotations equal to rho_c) is at least a_max - 1.  It is a GLOBAL condition: no assumption on which run
63: contains which rotation (the "thin heavy" obstruction of Theorem EXP, proof-EXP-v2.md, does not arise here).
