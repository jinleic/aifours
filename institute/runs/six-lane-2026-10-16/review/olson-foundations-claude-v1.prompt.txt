L2: 
L3: Status: written proof (lane MathOlson, 2026-10-16), mechanism checked by brute
L4: force (`code/verify_marked.py`, `code/verify_theoremP.py`); NOT yet independently
L5: reviewed.  This is a theorem about a CLASS OF WORDS in D_{2p}; it does not

L8: ## Setting and conventions
L9: 
L10: p is an odd prime. D_{2p} = {(v, e) : v in Z_p, e in {+1,-1}} with
L11: (v, e)(v', e') = (v + e v', e e')  (rotations (x,+1), reflections (y,-1)).
L12: For a word w = w_1 ... w_N and indices i_1 < ... < i_k the ordered product is
L13: w_{i_1} w_{i_2} ... w_{i_k}.  An identity k-subword is such an index set with
L14: product (0, +1).  Cyclic rotation of w preserves the existence of identity
L15: k-subwords (a product U V becomes V U = U^{-1} (U V) U).
L16: 
L17: Let w contain F >= 1 reflections.  Rotate w cyclically so that it ENDS with a
L18: reflection:
L19:     w = X_1 f_1 X_2 f_2 ... X_F f_F,
L20: where f_t = (y_t, -1) are the reflections and X_t (t = 1..F) is the block of
L21: rotations strictly between f_{t-1} and f_t (X_1 = rotations before f_1); n_t =
L22: |X_t|.  ("Gap t" = X_t; cyclically these are exactly the gaps between
L23: consecutive reflections.)
L24: 
L25: ## Theorem P
L26: 
L27: If N = |w| <= 4p - 1 and  F + sum_{t=1}^{F} floor(n_t / 2) >= 3p - 1,  then w
L28: has an identity 2p-subword.
L29: 
L30: ## Proof
L31: 
L32: **Step 1 (parametrisation).** In each gap X_t list the rotations in index order
L33: and group them into floor(n_t/2) consecutive PAIRS pi = (i, i'); if n_t is odd
L34: the last rotation of X_t is a SINGLETON.  Introduce Boolean parameters
L35:   u_2, ..., u_F  (gap colours; set u_1 := 0 and u_{F+1} := u_1 = 0),
L36:   m_pi  for each pair pi  (pair marks).
L37: Number of parameters:  M = (F - 1) + sum_t floor(n_t/2) >= 3p - 2.
L38: 
L39: To a parameter point (u, m) assign the selection S(u, m):
L40: * reflection f_t is selected iff u_t != u_{t+1}  (t = 1..F);
L41: * both rotations of pair pi in gap t are selected iff m_pi XOR u_t = 1,
L42:   otherwise neither;
L43: * singletons are never selected.
L44: 
L45: **Step 2 (injectivity; the empty selection).** The selection determines the
L46: parameters: going left to right, u_1 = 0 and u_{t+1} = u_t XOR [f_t selected]
L47: determine all u_t; then m_pi = [pi selected] XOR u_t.  Hence the map
L48: (u, m) -> S(u, m) is injective, and S(u, m) is EMPTY iff (u, m) = 0: an empty
L49: selection selects no reflection, so all u_t = u_1 = 0, and no pair, so all
L50: m_pi = u_t = 0.
L51: 
L52: **Step 3 (size).** |S(u,m)| = #{t : u_t != u_{t+1}} + 2 #{pi : m_pi XOR u_{t(pi)} = 1}.
L53: The first term is the number of colour changes around the cycle 1..F, 1, hence
L54: even.  So |S| is always EVEN, and |S| <= N <= 4p - 1.
L55: 
L56: **Step 4 (signs and the product).** Let S = S(u,m).  For an element of S lying
L57: in gap t or equal to f_t, the number of selected reflections strictly before
L58: it is #{s < t : u_s != u_{s+1}}, which has the parity of [u_t != u_1] = u_t.
L59: So in the ordered product every selected rotation x in gap t is multiplied by
L60: c_t := (-1)^{u_t}, and a selected reflection f_t contributes c_t y_t to the
L61: rotation coordinate.  The number of selected reflections is even (Step 3), so
L62: the product is (V, +1) with
L63:   V = sum_{t : u_t != u_{t+1}} c_t y_t + sum_{pairs pi selected} c_{t(pi)} x_pi,
L64: where x_pi = x_i + x_i'.  Using (c_t - c_{t+1})/2 = u_{t+1} - u_t (which is
L65: 0 when u_t = u_{t+1} and c_t when they differ) and summation by parts with
L66: u_1 = u_{F+1} = 0,
L67:   sum_{t=1}^{F} (u_{t+1} - u_t) y_t = sum_{t=2}^{F} u_t (y_{t-1} - y_t).
L68: For pairs: a selected pair (m XOR u_t = 1) contributes c_t x_pi; one checks
L69: c_t x_pi [m XOR u_t] = x_pi m - x_pi u_t for both u_t = 0, 1.  Therefore, in Z_p,
L70:   V(u, m) = sum_{t=2}^{F} beta_t u_t + sum_pi x_pi m_pi,
L71:   beta_t = y_{t-1} - y_t - sum_{pi in gap t} x_pi.
L72: V is a polynomial of degree 1 in the parameters (over F_p), and S(u,m) is an
L73: identity subword iff V(u, m) = 0 in Z_p.
L74: 
L75: **Step 5 (Chevalley–Warning on the Boolean box).** Write the size as the
L76: integer polynomial
L77:   Z(u, m) = sum_{t=1}^{F} (u_t + u_{t+1} - 2 u_t u_{t+1}) + 2 sum_pi (m_pi + u_{t(pi)} - 2 m_pi u_{t(pi)}),
L78: which agrees with |S(u, m)| on {0,1}^M and has degree 2.  Over F_p put
L79:   Q = (1 - V^{p-1}) (1 - Z^{p-1}),   deg Q <= 3(p - 1) < M.
L80: On {0,1}^M, Q(x) = 1 if V(x) = 0 and Z(x) = 0 in F_p, and Q(x) = 0 otherwise
L81: (Fermat).  Box lemma: for any polynomial Q over F_p of degree < M,
L82:   sum_{x in {0,1}^M} (-1)^{|x|} Q(x) = 0.
L83: (Proof: suffices for monomials; a monomial of degree < M omits some variable
L84: x_j, and the involution flipping coordinate j pairs points with opposite signs
L85: and equal values.)  Hence
L86:   sum_{x : V(x) = 0, Z(x) = 0 mod p} (-1)^{|x|} = 0 in F_p.
L87: The point x = 0 contributes +1, so there is a parameter point x != 0 with
L88: V(x) = 0 and |S(x)| = Z(x) = 0 mod p.
L89: 
L90: **Step 6 (conclusion).** By Step 2, S(x) is nonempty; by Step 3 its size is
L91: even and at most 4p - 1; being divisible by p (odd), the size is a positive
L92: even multiple of p below 4p, i.e. exactly 2p.  By Step 4 its ordered product is
L93: the identity.  QED.

L80: (ii) B <= kappa; (iii) o_F >= 2 kappa - B + 1 >= kappa + 1 >= 1, in particular (V) holds; (iv) if B <= kappa - 1, o_F >= kappa + 2.

L84: solvable.  Hence B = min(A, B) <= kappa.  (iii) By (1.1) and (i), 2p - o_F + 2 kappa = A + B <= 2p - 1 + B, so
L85: o_F >= 2 kappa - B + 1 >= kappa + 1 by (ii), and kappa >= B >= 0.  (iv) 2 kappa - B + 1 >= kappa + 2 iff B <= kappa - 1.  []
