9: ## 1. Statement (exact scope)
10: 
11: o_F(w) is the number of blocks of ODD length in the maximal cyclic constant-block decomposition of w.  That decomposition cuts
12: every maximal cyclic reflection run at every change of letter; see proof-K0star-r2.md L22-25.  In it an empty rotation run
13: always lies between blocks of different values (L25).
14: **Corollary REFL-few-odd.**  Let p >= 5 be prime, and let w0 be a word of length 4p - 2 over D_(2p) such that
15:  (i)   all rotation letters of w0 lie in one set {rho_x, rho_-x}, x != 0;
16:  (ii)  w0 is an avoider, i.e. it has no identity 2p-subword in increasing index order;
17:  (iii) o_F(w0) <= p.
18: Then every maximal cyclic reflection run of w0 is constant.
19: * Nothing else is assumed of w0.  In particular there is no INV* hypothesis, no RGR hypothesis, and no condition on kappa, A, B,
20:   k, run lengths, block lengths or reflection values.
21: * Relative to REFL(p) (README.md L17-19: "every avoider w of length 4p-2 over D_(2p) whose rotation letters all lie in one set
22:   {rho_x, rho_-x}, x != 0, has every maximal CYCLIC reflection run constant"), the only restriction is (iii).
23: * Words without reflections are vacuous.  Words without rotations are handled at the start of the proof of Theorem RED
24:   (RED-r2 L136, by Lemma AR), exactly as there.
25: Remark (sub-blocks).  Suppose a word is given by any cyclic constant-block representation, in which adjacent blocks may have equal
26: values across empty runs.  Then its o_F is at most the number of odd blocks of that representation.  Passing to the maximal
27: decomposition fuses equal-valued blocks across empty runs: odd + odd -> even and odd + even -> odd, so the odd count never rises.

53: Suppose w0 violates the conclusion.  The proof of Theorem RED (RED-r2 L136-164) normalises x = 1 and A >= B; neither step changes

58: Given MON, the terminal word has k <= o_F(w0) <= p, which the small-k verdict excludes: a contradiction.
59: Proof of MON.  Throughout, an empty run of the maximal decomposition lies only between blocks of different values.
60: * P1 (FUS; K0star-r2 L84-97).  An even block E is recoloured to the value u of a block X adjacent to it across an empty run.
61:   X and E fuse, and the result has the parity of X.  If the run on E's other side is empty and the block Y there also has value u,
62:   X, E and Y all fuse (a "double fusion", L95-97), and the new block has the parity of |X| + |Y|.  Before the move the three blocks
63:   contribute the odd ones among X and Y.  After it, the merged block is odd iff exactly one of X, Y is odd.  So o_F drops by 2 or
64:   is unchanged.
65: * P2 (PM0; K0star-r2 L107-110).  Two nonempty runs R_j, R_(j+1) are merged and the even block S_j is appended to S_(j+1).
66:   S_(j+1) keeps its parity, S_j (even) disappears, and the merged run is nonempty, so nothing fuses.  o_F is unchanged.
67: * P3 (TR-fill; K0star-r2 L104-106, RED-r2 L142-143).  One rho_1 rho_-1 pair moves from a run with r >= 3, which stays nonempty,
68:   into an empty run.  No block changes, and none splits, since the filled run lay between different values.  o_F is unchanged.
69: * P4 (M0'; RED-r2 L144-147).  The two letters of a (1,1)-run are deleted, and sigma_y sigma_y is inserted into a block, which keeps
70:   that block's parity.  The neighbours of the new empty run fuse if they have equal values: odd + odd -> even, odd + even -> odd,
71:   even + even -> even.  So o_F drops by 2 or is unchanged.  []

131: 
132: Define RES_<(p): G-words of length 4p - 2 (rotations rho_1, rho_-1; normalised A >= B) with at least one (genuine) empty run,

135: avoider in RES_<(p) violates REFL(p).  Hence REFL(p) <=> RES_<(p) contains no avoider with kappa >= 2.

9: p odd prime, conventions of olson/proof-dihedral-partial.md Sec. 0.  Let w have F >= 1 reflections.  Read w

23: 
24: A selection with an even number of reflections is given by (i) z_i := (-1)^(number of selected reflections
25: cyclically before R_i, counted from a fixed cut point at the end of S_k), (ii) c_i := number of selected letters of
26: S_i, with c_i = f_i (mod 2) [the parity of selected reflections in S_i is exactly what changes the zone sign between
27: R_i and R_(i+1)], (iii) any sub-multiset of each X_i.  Conversely each such datum with 0 <= c_i <= l_i is realised
28: (choose any c_i letters of the constant block S_i; any chosen rotations).  Because S_i is constant, its c_i selected
29: letters multiply to sigma_(y_i) (c_i odd) or 1 (c_i even); so the ordered product, read from the cut, is
30:     rho_V,  V = sum_i z_i (sum of chosen values in X_i) + sum_{i : f_i = 1} z_i y_i      (mod p),
31: by induction along the word (a rotation rho_x in a zone of sign z contributes z x; a reflection sigma_y entered in
32: a zone of sign z contributes z y and flips the zone sign; the even total makes the product a rotation).
33: Summation by parts: sum_{f_i=1} z_i y_i = sum_i y_i (z_i - z_(i+1))/2 = sum_i z_i (y_i - y_(i-1))/2 = -(sum_i z_i theta_i)/2,
