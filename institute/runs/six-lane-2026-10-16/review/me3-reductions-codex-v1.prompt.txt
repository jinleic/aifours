18: ## 0. Conventions and imports
19: 
20: **0.1 Exponential polynomials.** An *exponential polynomial* (e.p.) is f(t) = Σ_{λ∈Λ} p_λ(t) e^{λt} with Λ ⊂ ℂ
21: finite and p_λ ∈ ℂ[t]∖{0}. Λ is the set of *contributing exponents*, ord f := Σ_λ (deg p_λ + 1) is the *order*, and
22: E(f) := {λ with multiplicity deg p_λ + 1} is the *exponent multiset*. By (I1) the representation is unique. Hence a
23: real-valued e.p. has Λ = Λ̄ and p_{λ̄} = conj(p_λ).
24: 
25: **0.2 Moments.** Densities live on [0, ∞): for measurable f ≥ 0 on [0, ∞), f ≢ 0, with ∫_0^∞ (1 + t²) f < ∞, put
26: m_k := ∫_0^∞ t^k f(t) dt (k = 0, 1, 2), SCV(f) := m0 m2 / m1² − 1, and S(f) := SCV/(1 + SCV) = 1 − m1²/(m0 m2).
27: Here m0, m1 > 0 and SCV ≥ 0 (Cauchy–Schwarz m1² ≤ m0 m2). An e.p. defined on ℝ is restricted to [0, ∞) for moments.

29: **0.3 Imports (ordinary background only).**
30: * (I1) The functions t^k e^{λt} (distinct pairs (k, λ)) are linearly independent over ℂ on every interval of positive
31:   length. A nonzero e.p. is an entire function, so its real zeros are isolated and have finite multiplicity.
32: * (I2) Jordan/spectral form of e^{At}; Cayley–Hamilton; existence and uniqueness for linear constant-coefficient ODE
33:   initial value problems; companion matrices.
34: * (I3) Rolle's theorem.
35: * (I4) Hermite–Genocchi formula, including coincident (confluent) nodes. For ϕ ∈ C²(ℝ) and nodes x1 ≤ x2 ≤ x3,

37:   u1 := 1 − u2 − u3. The (confluent) divided difference ϕ[x1,x2,x3] is a linear combination, with coefficients
38:   depending only on the nodes, of the values ϕ^{(j)}(x_i), j < multiplicity of x_i.

40:   in ℝ^n is a finite convex combination of extreme points.

47: ## 1. L1 — structure of ME(≤3)
48: 
49: **Lemma 1.1 (decay).** If an e.p. G satisfies G(t) → 0 as t → +∞, then every contributing exponent of G has negative
50: real part.
51: 
52: *Proof.* Let G ≢ 0, σ := max_{λ∈Λ} Re λ, d := max{deg p_λ : Re λ = σ}, Λ* := {λ : Re λ = σ, deg p_λ = d}, and let
53: c_λ ≠ 0 be the leading coefficient of p_λ. For t ≥ 1, t^{−d} e^{−σt} G(t) = T(t) + ε(t), where
54: T(t) := Σ_{λ∈Λ*} c_λ e^{i(Im λ)t} and ε(t) → 0. Each remaining term has either a lower polynomial degree or a smaller
55: real part. The numbers Im λ (λ ∈ Λ*) are distinct, so by (I8)
56: (1/L)∫_0^L |T|² = Σ|c_λ|² + Σ_{λ≠λ'} c_λ conj(c_{λ'}) (1/L)∫_0^L e^{i(Im λ − Im λ')t} dt → Σ|c_λ|² > 0.
57: If σ ≥ 0, then |t^{−d} e^{−σt} G(t)| ≤ |G(t)| → 0 for t ≥ 1. This forces T(t) → 0, hence (1/L)∫_0^L |T|² → 0, a
58: contradiction. So σ < 0. ∎
59: 
60: **Lemma 1.2 (dominant real exponent).** Let f ≢ 0 be a real-valued e.p. with f(t) ≥ 0 for all t ≥ t0. Then
61: σ := max Re λ over the contributing exponents is itself a contributing exponent (in particular real). Consequently, a
62: contributing non-real λ forces a contributing real λ0 ≥ Re λ. The case λ0 = Re λ is allowed: it is D1.
63: 
64: *Proof.* Suppose σ ∉ Λ. Define d, Λ*, c_λ, T, ε as in 1.1. Every λ ∈ Λ* is now non-real and Λ* = conj(Λ*), so T is
65: real-valued. T has no zero frequency, so the mean M(T) := lim (1/L)∫_0^L T is 0. Also M(T²) = Σ_{Λ*} |c_λ|² > 0.
66: For t ≥ max(t0, 1) we have t^{−d} e^{−σt} f(t) ≥ 0, so T ≥ −ε and T⁻ := max(−T, 0) ≤ |ε| → 0. Hence M(T⁻) = 0. Then
67: |T| = T + 2T⁻ gives M(|T|) = 0, and T² ≤ ‖T‖_∞ |T| gives M(T²) = 0, a contradiction. ∎

69: **Theorem L1(a) (structure).** Let X be continuous with an ME representation (α, A) of order n ≤ 3 (HSTZ Def. 1–2):
70: F(t) = Pr(X < t) = 1 − α e^{At} 𝟙 for t ≥ 0, with α real 1×n and A real n×n. Put G(t) := α e^{At} 𝟙 and
71: f(t) := −α A e^{At} 𝟙. Then:
72: 1. α𝟙 = 1, and G(t) = Pr(X ≥ t) for t ≥ 0.
73: 2. G is a real e.p. with ord G ≤ n. Its contributing exponents are eigenvalues of A, all with Re < 0.
74: 3. f = −G' is a density of X: f ≥ 0 on [0, ∞), ∫_0^∞ f = 1, E(f) = E(G), ord f ≤ 3, all moments finite.
75: 4. If f has a contributing non-real exponent, then E(f) = {λ0, λ, λ̄} with λ0 real, λ0 ≥ Re λ, all simple.
76: 
77: *Proof.* (1) F(0) = Pr(X < 0) = 0 gives α𝟙 = 1, and G = 1 − F.
78: (2) By (I2), e^{At} = Σ_{λ∈spec A} e^{λt} Σ_{k<N_λ} (t^k/k!)(A − λ)^k P_λ, where P_λ are the spectral projectors and
79: N_λ the algebraic multiplicities. So G = Σ e^{λt} q_λ with deg q_λ ≤ N_λ − 1, and dropping the zero q_λ gives
80: ord G ≤ Σ N_λ = n. G(t) = Pr(X ≥ t) → 0 (X is a.s. finite), so Lemma 1.1 applies.
81: (3) d/dt e^{At} = A e^{At}, so f = −G'. F = 1 − G is C¹ on [0, ∞) and nondecreasing with F(0) = 0. So
82: F(t) = ∫_0^t f, f = F' ≥ 0 (one-sided at 0), and ∫_0^∞ f = lim F = 1. Every contributing λ satisfies λ ≠ 0, and
83: (q e^{λt})' = (q' + λq) e^{λt} with deg(q' + λq) = deg q; hence E(f) = E(G). Moments are finite by exponential decay.
84: (4) Lemma 1.2 gives a real contributing λ0 ≥ Re λ. λ̄ also contributes because f is real, so ord f ≤ 3 forces
85: E(f) = {λ0, λ, λ̄} with all multiplicities 1. ∎

87: **Theorem L1(b) (converse).** Let f be a real e.p. whose contributing exponents all have Re < 0, with ord f = N ≤ 3,
88: f ≥ 0 on [0, ∞) and ∫_0^∞ f = 1. Then f is the density of a continuous X ∈ ME(N) ⊆ ME(3), with an explicit real
89: representation of order N, and f = −α A e^{At} 𝟙.

91: *Proof.* Put G(t) := ∫_t^∞ f. For Re λ < 0, ∫_t^∞ p(s) e^{λs} ds = q(t) e^{λt} with
92: q = −Σ_{j=0}^{deg p} (−1)^j λ^{−j−1} p^{(j)}, and deg q = deg p. So G is a real e.p. with E(G) = E(f) and G(0) = 1.
93: Let χ(s) := Π_{λ∈Λ} (s − λ)^{m_λ} with m_λ := deg p_λ + 1. χ is real, monic and of degree N, and χ(D)G = 0. Put
94: x(t) := (G, G', …, G^{(N−1)})ᵀ. Then x' = Cx with C the companion matrix of χ, so
95: G(t) = e1ᵀ e^{Ct} x(0) = x(0)ᵀ e^{Cᵀt} e1. Let S := [𝟙, e2, …, eN] (det S = 1, S e1 = 𝟙), A := S Cᵀ S^{−1} and
96: α := x(0)ᵀ S^{−1}. Then α e^{At} 𝟙 = x(0)ᵀ e^{Cᵀt} S^{−1} 𝟙 = x(0)ᵀ e^{Cᵀt} e1 = G(t). If X has density f, then
97: Pr(X < t) = 1 − G(t) = 1 − α e^{At} 𝟙 for t ≥ 0, and −α A e^{At} 𝟙 = −G' = f. ∎

117: ## 2. L2 — cones, ratio form, mixtures, extreme rays, bookkeeping
118: 
119: **Definitions.** An *admissible* multiset E is a conjugation-closed multiset in {Re < 0} with |E| ≤ 3. V_E is the real
120: vector space of real e.p. whose exponent multiset is contained in E, together with 0. It has dim V_E = |E|, with basis
121: t^k e^{λt} (λ real, k < mult λ) and e^{(Re λ)t} cos((Im λ)t), e^{(Re λ)t} sin((Im λ)t) for a non-real pair (whose
122: multiplicity is 1 when |E| ≤ 3). K_E := {f ∈ V_E : f(t) ≥ 0 ∀ t ≥ 0} and B_E := {f ∈ K_E : ∫_0^∞ f = 1}.
123: By L1(a)–(b), the densities of continuous ME(≤3) laws are exactly ∪_E B_E over admissible E.
124: 
125: **Lemma 2.1 (cone).** K_E is a closed, convex, pointed cone. ℓ(f) := ∫_0^∞ f and m1(f) are > 0 on K_E∖{0}, and B_E is
126: compact and convex.
127: 
128: *Proof.* Each evaluation f ↦ f(t) is a linear functional on the finite-dimensional V_E, so K_E is an intersection of
129: closed half-spaces. If ±f ∈ K_E then f = 0 on [0, ∞), so f = 0 by (I1). For f ∈ K_E∖{0}, f ≥ 0 is continuous and
130: ≢ 0 on [0, ∞) by (I1), so ℓ(f) > 0 and m1(f) > 0. Fix a norm. ℓ is continuous and positive on the compact set
131: K_E ∩ {‖f‖ = 1}, so ℓ ≥ c > 0 there. Hence B_E ⊆ {‖f‖ ≤ 1/c}, which is closed and bounded. ∎
132: 
133: **Lemma 2.2 (ratio form).** For f as in 0.2, S(f) = min_{θ>0} R_θ(f), where
134: R_θ(f) := ∫_0^∞ (t − θ)² f / (θ² ∫_0^∞ f). The minimum is attained at θ = m2/m1.
135: 
136: *Proof.* With x := 1/θ > 0, R_θ = 1 − 2(m1/m0)x + (m2/m0)x². This is minimized at x = m1/m2 > 0, with value
137: 1 − m1²/(m0 m2) = S(f). ∎
138: 
139: **Lemma 2.3 (mixtures).** Let ν be a finite positive measure on M with ν(M) > 0, and g : M × [0, ∞) → [0, ∞)
140: measurable. Assume each g_μ := g(μ, ·) satisfies 0.2, ∫_M ∫_0^∞ (1 + t²) g_μ dt dν < ∞, and SCV(g_μ) ≥ c ≥ 0 for
141: ν-a.e. μ. Then f := ∫_M g_μ dν(μ) satisfies SCV(f) ≥ c. In particular, SCV(f1 + … + fk) ≥ min_i SCV(f_i) for
142: nonnegative f_i ≢ 0 satisfying 0.2.
143: 
144: *Proof.* x ↦ x/(1 + x) is increasing, so S(g_μ) ≥ c' := c/(1 + c). Fix θ > 0. By 2.2,
145: ∫(t − θ)² g_μ ≥ c' θ² ∫ g_μ for a.e. μ. Integrate over ν (Tonelli) to get ∫(t − θ)² f ≥ c' θ² ∫ f, i.e. R_θ(f) ≥ c'.
146: f satisfies 0.2, since ∫ f = ∫∫ g_μ > 0. Minimizing over θ gives S(f) ≥ c', i.e. SCV(f) ≥ c. ∎
147: 
148: **Lemma 2.4 (extreme rays).** Let E be admissible with K_E ≠ {0}.
149: 1. min_{K_E∖0} SCV exists.
150: 2. Every f ∈ K_E∖0 has finitely many f_i on extreme rays of K_E with SCV(f) ≥ min_i SCV(f_i).
151: 3. The minimum in (1) is attained on an extreme ray.
152: 
153: Hence inf_{K_E∖0} SCV = inf over the extreme rays of K_E.
154: 
155: *Proof.* SCV is scale-invariant and continuous on K_E∖0: the m_k are linear on V_E, and m0, m1 > 0 there. So it
156: attains its minimum on the compact B_E (2.1, I6). Extreme points of B_E lie on extreme rays: if e = x + y with
157: x, y ∈ K_E∖0, then e = ℓ(x)·x/ℓ(x) + ℓ(y)·y/ℓ(y) with ℓ(x) + ℓ(y) = 1, so x/ℓ(x) = y/ℓ(y) = e. By (I5),
158: f/ℓ(f) = Σ c_i e_i with e_i extreme in B_E and c_i > 0; apply 2.3. Applying (2) to a minimizer gives (3). ∎
159: 
160: **Lemma 2.5 (bookkeeping; correction of the outline).** If E ⊆ E' (both admissible), then V_E ⊆ V_{E'} and
161: K_E = K_{E'} ∩ V_E ⊆ K_{E'}. Hence inf_{K_{E'}∖0} SCV ≤ inf_{K_E∖0} SCV. Every real admissible E with |E| ≤ 2 lies in
162: a real admissible E' with |E'| = 3: add real negative numbers outside E, or repeat one.
163: **K_E need not be a face of K_{E'}.** Counterexample: E = {−1} and E' = {−1, −2, −3}. Then x := e^{−t} − e^{−3t} and
164: y := e^{−t} + e^{−3t} lie in K_{E'} (e^{−t} ≥ e^{−3t} on [0, ∞)), and x + y = 2e^{−t} ∈ K_E, but x, y ∉ V_E. Only the
165: inclusion is used below. K_E *is* a face when E' ∖ E is the asymptotically dominant basis element (Lemma 3.2).
166: 
167: **Corollary 2.6 (assembly).** Define three infima of SCV:
168: * I_R over K_E∖0 with E real admissible;
169: * I_1 over the D1 cones K_{{−1, −1±iω}}, ω > 0;
170: * I_2 over the D2 cones K_{{−1, −(1+δ)±iω}}, δ, ω > 0.
171: 
172: Then inf{SCV(X) : X ∈ ME(≤3) continuous} = min(I_R, I_1, I_2), and each of the three infima is an infimum over the
173: extreme rays of the respective cones.
174: 
175: *Proof.* A density f lies in B_{E(f)}. E(f) is of type R or D, and SCV is invariant under the time change (normal
176: forms). Type R with |E(f)| < 3 is padded (2.5). Conversely, every nonzero cone element, normalized, is an ME(≤3)
177: density (L1(b)). A complex E whose pair is not dominated by the real exponent has K_E = K_{{λ0}} by Lemma 1.2, which is
178: contained in the real case. Finally apply 2.4. ∎

182: ## 3. L3 — real exponents (cases A, B, C)
183: 
184: **Setting.** E is a real admissible multiset with |E| = 3, written with positive *rates*. The basis φ1, φ2, φ3 is
185: ordered by decreasing dominance at +∞:
186: * (A) E = {−λ1, −λ2, −λ3}, 0 < λ1 < λ2 < λ3: φ1 = e^{−λ1t}, φ2 = e^{−λ2t}, φ3 = e^{−λ3t}.
187: * (B1) E = {−λ, −λ, −μ}, 0 < λ < μ: φ1 = t e^{−λt}, φ2 = e^{−λt}, φ3 = e^{−μt}.
188: * (B2) E = {−λ, −μ, −μ}, 0 < λ < μ: φ1 = e^{−λt}, φ2 = t e^{−μt}, φ3 = e^{−μt}.
189: * (C) E = {−λ, −λ, −λ}: φ1 = t² e^{−λt}, φ2 = t e^{−λt}, φ3 = e^{−λt}.

191: For f = a1φ1 + a2φ2 + a3φ3 put a1(f) := a1. Let λ_* be the smallest rate, m_* its multiplicity, and
192: ψ(t) := (1 + t)^{m_*−1} e^{−λ_* t} > 0. Two facts follow by inspection of each type: (F1) sup_{t≥0} |g|/ψ < ∞ for
193: every g ∈ V_E; (F2) f(t)/ψ(t) → a1(f) as t → ∞.

195: **Lemma 3.1 (zero count; Chebyshev property).** Let E be any real multiset of size N ≥ 1. Every nonzero g ∈ V_E has at
196: most N − 1 real zeros counted with multiplicity.
197: 
198: *Proof.* Induction on N; N = 1 is trivial. Write g = Σ_{i=1}^r p_i(t) e^{κ_i t} with κ_i the distinct elements of E,
199: multiplicities m_i and deg p_i ≤ m_i − 1 (some p_i may be 0). If at most one p_i ≠ 0, then g = p_i e^{κ_i t} has
200: ≤ m_i − 1 ≤ N − 1 zeros. Otherwise let p_j ≠ 0 for some j ≥ 2. Put h := e^{−κ1 t} g; it has the same zeros with the
201: same multiplicities. Then h^{(m1)} = Σ_{i≥2} p̃_i e^{(κ_i−κ1)t} with deg p̃_i = deg p_i, because κ_i − κ1 ≠ 0 and
202: (D + c) preserves degree for c ≠ 0. So h^{(m1)} ≠ 0 lies in a real e.p. space of size N − m1 and, by induction, has
203: ≤ N − m1 − 1 zeros. Rolle with multiplicities (I3) says: if h has zeros x1 < … < xs of multiplicities k_j with
204: Σ k_j = Z, then h' has a zero of multiplicity ≥ k_j − 1 at each x_j and a zero in each (x_j, x_{j+1}), so ≥ Z − 1
205: zeros. If h had ≥ N zeros (choose finitely many), h^{(m1)} would have ≥ N − m1 zeros, a contradiction. ∎

207: **Lemma 3.2 (dominant coefficient; face).** a1(f) ≥ 0 for f ∈ K_E. K' := K_E ∩ {a1 = 0} is an exposed face of K_E.
208: It is the nonnegative cone of V' := span(φ2, φ3) = V_{E''} for a real multiset E'' of size 2:
209: * (A) {e^{−λ2t}, e^{−λ3t}};
210: * (B1) {e^{−λt}, e^{−μt}};
211: * (B2) {t e^{−μt}, e^{−μt}};
212: * (C) {t e^{−λt}, e^{−λt}}.
213: 
214: The extreme rays of K_E inside K' are exactly the extreme rays of K'.
215: 
216: *Proof.* By (F2), a1(f) = lim f/ψ ≥ 0. If x + y ∈ K' with x, y ∈ K_E, then a1(x) + a1(y) = 0 with both ≥ 0, so
217: x, y ∈ K'. An extreme ray of K' is therefore extreme in K_E, and conversely. ∎

219: **Lemma 3.3 (face rays).**
220: 1. For 0 < κ1 < κ2, a e^{−κ1t} + b e^{−κ2t} ≥ 0 on [0, ∞) iff a ≥ 0 and a + b ≥ 0. The extreme rays are e^{−κ2t} and
221:    e^{−κ1t} − e^{−κ2t}.
222: 2. For κ > 0, (a + bt) e^{−κt} ≥ 0 on [0, ∞) iff a, b ≥ 0. The extreme rays are e^{−κt} and t e^{−κt}.
223: 3. SCV(e^{−κt}) = 1, SCV(t e^{−κt}) = 1/2, and SCV(e^{−κ1t} − e^{−κ2t}) = (κ1² + κ2²)/(κ1 + κ2)² ∈ [1/2, 1). So every
224:    face ray has SCV ≥ 1/2.
225: 
226: *Proof.* (1) e^{κ1t} f = a + b x, where x = e^{−(κ2−κ1)t} ranges over (0, 1]. An affine function is ≥ 0 on (0, 1] iff
227: it is ≥ 0 as x → 0+ and at x = 1. The planar cone {a ≥ 0, a + b ≥ 0} has extreme rays (0, 1) and (1, −1).
228: (2) t = 0 gives a ≥ 0 and t → ∞ gives b ≥ 0; the converse is clear.
229: (3) m_k(e^{−κt}) = k!/κ^{k+1}, m_k(t e^{−κt}) = (k+1)!/κ^{k+2} and m_k(e^{−κ1t} − e^{−κ2t}) = k!(κ1^{−k−1} − κ2^{−k−1}).
230: For the last, m0m2/m1² = 2(κ1² + κ1κ2 + κ2²)/(κ1 + κ2)². Finally 2(κ1² + κ2²) ≥ (κ1 + κ2)². ∎

232: **Lemma 3.4 (double-zero rays; Hermite–Genocchi).** Let (λ1, λ2, λ3) list the rates of E with multiplicity. For τ ∈ ℝ
233: define F_τ(t) := (t − τ)² ∫_Σ e^{−(t−τ)(u1λ1 + u2λ2 + u3λ3)} du2 du3. Then:

236: 2. F_τ > 0 on ℝ∖{τ}, F_τ(τ) = F_τ'(τ) = 0 and F_τ''(τ) = 1.
237: 3. Every g ∈ V_E with g(τ) = g'(τ) = 0 is a real multiple of F_τ.
238: 4. a1(F_τ) > 0.

241: *Proof.*

251:    (t ↦ t/μ_u), SCV(g_u) = SCV((t − μ_uτ)² e^{−t}) ≥ Δ3. The integrability in 2.3 holds because the integrand is
