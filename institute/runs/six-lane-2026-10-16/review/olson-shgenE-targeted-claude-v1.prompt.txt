57: ## 2. Lemma Ua (eta = 1: the expanded word is solvable)

60: Proof.  Suppose neither does.  All rotations of u° lie in {rho_c, rho_-c}: u° is an RGR word of length 4p-2 with
61: F, R >= 1, all blocks odd, runs nonempty and kappa(u°) >= 1.  Replace c by -c if needed so that the majority count A°
62: of u° is >= its minority count B°.
63:  - A° >= 2p: the trivial cut (2p equal rotations) solves u°.
64:  - B° >= kappa(u°) + 1: (rho_c rho_-c)^(kappa(u°)+1) has value sum 0 and size 2kappa(u°) + 2 <= 2p; (ZP) fails for u°.
65:  - 1 <= B° <= kappa(u°) - 1: Corollary B'(b) solves u°.  B° = 0: the C1 composition solves u°.
66:  - B° = kappa(u°) >= 1: (V) for u° gives kappa(u°) <= k-1.  If k >= p+1, KBH solves u°.  If k <= p, KB solves u°
67:    unless its capped case arises.  All blocks are odd, so the OR-segments are the single runs; a capped segment G has
68:    A°_G - B°_G >= 2p-1, hence (A° <= 2p-1, else the first bullet applies) A°_G = A° = 2p-1 and B°_G = 0: G holds every majority letter and every other run holds
69:    only minority letters, kappa(u°) of them in total.

71:      G contain kappa(u°) - a + 1 rotations of w: k - 1 <= kappa(u°) - a + 1 <= k - a, impossible (a >= 3).
72:    * If the copies have the majority value, w has 2p-1-a majority lights and kappa(u°) = kappa + (a-1)/2 >= kappa + 1

74:      (rho_c rho_-c)^(kappa+1) violates (ZP) for w (size 2kappa + 2 <= 2p): w is solvable, contrary to assumption.
75:    So the capped case does not arise and KB solves u°.

117: Suppose w avoids; (H) gives H >= (a-1)/2 for every heavy.  Induction on eta.

44: Let D be a zero-sum-free SET of d >= 3 distinct odd elements with |A(D)| <= 2p-2.  Then some x in D has
