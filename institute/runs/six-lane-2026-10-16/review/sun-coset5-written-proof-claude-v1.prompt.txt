70: ## L1. Triangle lemma T [NEW form; subsumes M-S Lemma 3.10(a),(c) and Zhu (3.1), (3.4)]

27: **R0. Reduction to finite groups.** This is standard; Menon §2 gives the same argument.
28: - Put N = ∩_i core_G(G_i). It is a normal subgroup of finite index, contained in every G_i.
29: - Each coset a_iG_i is the full preimage of its image in G/N.

33: **R1. Reduction to Core(5).** Sun at k = 5 in all groups is equivalent to the following statement, which is correct as stated in the screen.
34: 
35: > **Core(5).** No finite group G has subgroups U_1, …, U_5 with [G:U_i] = 4r_i, the r_i pairwise coprime, and with pairwise disjoint cosets g_iU_i.
36: 
37: *Proof.*
38: - (⇐) Core(5) is a special case of the target. In such a configuration every pairwise gcd equals 4, which is less than 5.
39: - (⇒) Suppose five disjoint cosets have all pairwise gcds ≤ 4. Write n_i = [G:G_i].
40:   1. **Each gcd is 2, 3 or 4.** By L0.6 no pair is coprime. So each pairwise gcd lies in {2, 3, 4}, and 6 divides none of them.
41:   2. **All n_i are divisible by 3, or all are even.** If some n_i is odd, it shares the factor 3 with every n_j, so 3 divides all five.
42:   3. **The case where 3 divides every n_i.** Then every gcd equals 3. Writing n_i = 3r_i, the r_i are pairwise coprime. Four of them contradict M-S Prop 4.3, which is also Zhu Theorem 3.1.
43:   4. **The case where every n_i is even.** Write n_i = 2^{e_i} m_i with m_i odd. From gcd ∈ {2, 4} we get: the m_i are pairwise coprime, every e_i ≥ 1, and min(e_i, e_j) ≤ 2. So at most one e_i is ≥ 3.
44:      - If two indices have e = 1, then together with any third index they form (2r, 2r', 2r'') with pairwise coprime r's. This contradicts M-S Prop 4.2, which is also Zhu Theorem 2.2.
45:      - If exactly one index has e = 1, say n_1 = 2m_1, take any three of the others. They are 4r_j with r_j = 2^{e_j−2} m_j, pairwise coprime because at most one e_j ≥ 3. With r_1 = m_1 odd, this contradicts M-S Prop 4.5.
46:      - Otherwise every e_i ≥ 2, so n_i = 4r_i with r_i = 2^{e_i−2} m_i pairwise coprime. That is a Core(5) configuration. ∎
