88: ## 0. Conventions and imports
89: 
90: **0.1 Exponential polynomials.** An *exponential polynomial* (e.p.) is f(t) = Σ_{λ∈Λ} p_λ(t) e^{λt} with Λ ⊂ ℂ
91: finite and p_λ ∈ ℂ[t]∖{0}. Λ is the set of *contributing exponents*, ord f := Σ_λ (deg p_λ + 1) is the *order*, and
92: E(f) := {λ with multiplicity deg p_λ + 1} is the *exponent multiset*. By (I1) the representation is unique. Hence a
93: real-valued e.p. has Λ = Λ̄ and p_{λ̄} = conj(p_λ).
94: 
95: **0.2 Moments.** Densities live on [0, ∞). Take a measurable f ≥ 0 on [0, ∞) with **0 < ∫_0^∞ f** and
96: ∫_0^∞ (1 + t²) f < ∞ (positive mass, i.e. f ≠ 0 in L¹; pointwise f ≢ 0 is NOT enough, e.g. f = 𝟙_{{0}}), and put
97: m_k := ∫_0^∞ t^k f(t) dt (k = 0, 1, 2), SCV(f) := m0 m2 / m1² − 1, and S(f) := SCV/(1 + SCV) = 1 − m1²/(m0 m2).
98: Here m0 > 0, and m1 > 0 because {f > 0} has positive measure while {0} is null. SCV ≥ 0 by Cauchy–Schwarz
99: (m1² ≤ m0 m2). An e.p. defined on ℝ is restricted to [0, ∞) for moments.
100: For a continuous f on an interval (in particular an e.p.), "f ≢ 0" (not identically 0) is equivalent to "f not a.e. 0";
101: every later use of "≢ 0" concerns continuous functions [v4 MINOR-6(ii)].

104: * (I1) The functions t^k e^{λt} (distinct pairs (k, λ)) are linearly independent over ℂ on every interval of positive
105:   length. A nonzero e.p. is an entire function, so its real zeros are isolated and have finite multiplicity.
106: * (I2) Jordan/spectral form of e^{At}; Cayley–Hamilton; existence and uniqueness for linear constant-coefficient ODE
107:   initial value problems; companion matrices.
108: * (I3) Rolle's theorem.
109: * (I4) Hermite–Genocchi formula, including coincident (confluent) nodes. For ϕ ∈ C²(ℝ) and nodes x1 ≤ x2 ≤ x3,
110:   ϕ[x1,x2,x3] = ∫_Σ ϕ''(u1x1 + u2x2 + u3x3) du2 du3, where Σ := {(u2,u3) : u2, u3 ≥ 0, u2 + u3 ≤ 1} and

123: **Lemma 1.1 (decay).** If an e.p. G satisfies G(t) → 0 as t → +∞, then every contributing exponent of G has negative
124: real part.
125: 
126: *Proof.* Let G ≢ 0, σ := max_{λ∈Λ} Re λ, d := max{deg p_λ : Re λ = σ}, Λ* := {λ : Re λ = σ, deg p_λ = d}, and let
127: c_λ ≠ 0 be the leading coefficient of p_λ. For t ≥ 1, t^{−d} e^{−σt} G(t) = T(t) + ε(t), where
128: T(t) := Σ_{λ∈Λ*} c_λ e^{i(Im λ)t} and ε(t) → 0. Each remaining term has either a lower polynomial degree or a smaller
129: real part. The numbers Im λ (λ ∈ Λ*) are distinct, so by (I8)
130: (1/L)∫_0^L |T|² = Σ|c_λ|² + Σ_{λ≠λ'} c_λ conj(c_{λ'}) (1/L)∫_0^L e^{i(Im λ − Im λ')t} dt → Σ|c_λ|² > 0.
131: If σ ≥ 0, then |t^{−d} e^{−σt} G(t)| ≤ |G(t)| → 0 for t ≥ 1. This forces T(t) → 0, hence (1/L)∫_0^L |T|² → 0, a
132: contradiction. So σ < 0. ∎
133: 
134: **Lemma 1.2 (dominant real exponent).** Let f ≢ 0 be a real-valued e.p. with f(t) ≥ 0 for all t ≥ t0. Then
135: σ := max Re λ over the contributing exponents is itself a contributing exponent (in particular real). Consequently, a
136: contributing non-real λ forces a contributing real λ0 ≥ Re λ. The case λ0 = Re λ is allowed: it is D1.
137: 
138: *Proof.* Suppose σ ∉ Λ. Define d, Λ*, c_λ, T, ε as in 1.1. Every λ ∈ Λ* is now non-real and Λ* = conj(Λ*), so T is
139: real-valued. T has no zero frequency, so the mean M(T) := lim (1/L)∫_0^L T is 0. Also M(T²) = Σ_{Λ*} |c_λ|² > 0.
140: For t ≥ max(t0, 1) we have t^{−d} e^{−σt} f(t) ≥ 0, so T ≥ −ε and T⁻ := max(−T, 0) ≤ |ε| → 0. Hence M(T⁻) = 0. Then
141: |T| = T + 2T⁻ gives M(|T|) = 0, and T² ≤ ‖T‖_∞ |T| gives M(T²) = 0, a contradiction. ∎

143: **Theorem L1(a) (structure).** Let X be continuous with an ME representation (α, A) of order n ≤ 3 (HSTZ Def. 1–2):
144: F(t) = Pr(X < t) = 1 − α e^{At} 𝟙 for t ≥ 0, with α real 1×n and A real n×n. Put G(t) := α e^{At} 𝟙 and
145: f(t) := −α A e^{At} 𝟙. Then:
146: 1. α𝟙 = 1, and G(t) = Pr(X ≥ t) for t ≥ 0.
147: 2. G is a real e.p. with ord G ≤ n. Its contributing exponents are eigenvalues of A, all with Re < 0.
148: 3. f = −G' is a density of X: f ≥ 0 on [0, ∞), ∫_0^∞ f = 1, E(f) = E(G), ord f ≤ 3, all moments finite.
149: 4. If f has a contributing non-real exponent, then E(f) = {λ0, λ, λ̄} with λ0 real, λ0 ≥ Re λ, all simple.
150: 
151: *Proof.* (1) F(0) = Pr(X < 0) = 0 gives α𝟙 = 1, and G = 1 − F.
152: (2) By (I2), e^{At} = Σ_{λ∈spec A} e^{λt} Σ_{k<N_λ} (t^k/k!)(A − λ)^k P_λ, where P_λ are the spectral projectors and
153: N_λ the algebraic multiplicities. So G = Σ e^{λt} q_λ with deg q_λ ≤ N_λ − 1, and dropping the zero q_λ gives
154: ord G ≤ Σ N_λ = n. G(t) = Pr(X ≥ t) → 0 (X is a.s. finite), so Lemma 1.1 applies.
155: (3) d/dt e^{At} = A e^{At}, so f = −G'. F = 1 − G is C¹ on [0, ∞) and nondecreasing with F(0) = 0. So
156: F(t) = ∫_0^t f, f = F' ≥ 0 (one-sided at 0), and ∫_0^∞ f = lim F = 1. Every contributing λ satisfies λ ≠ 0, and
157: (q e^{λt})' = (q' + λq) e^{λt} with deg(q' + λq) = deg q; hence E(f) = E(G). Moments are finite by exponential decay.
158: (4) Lemma 1.2 gives a real contributing λ0 ≥ Re λ. λ̄ also contributes because f is real, so ord f ≤ 3 forces
159: E(f) = {λ0, λ, λ̄} with all multiplicities 1. ∎

194: ## 2. L2 — cones, ratio form, mixtures, extreme rays, bookkeeping
195: 
196: **Definitions.** An *admissible* multiset E is a conjugation-closed multiset in {Re < 0} with |E| ≤ 3. V_E is the real
197: vector space of real e.p. whose exponent multiset is contained in E, together with 0. It has dim V_E = |E|, with basis
198: t^k e^{λt} (λ real, k < mult λ) and e^{(Re λ)t} cos((Im λ)t), e^{(Re λ)t} sin((Im λ)t) for a non-real pair (whose
199: multiplicity is 1 when |E| ≤ 3). K_E := {f ∈ V_E : f(t) ≥ 0 ∀ t ≥ 0} and B_E := {f ∈ K_E : ∫_0^∞ f = 1}.
200: By L1(a)–(b), the densities of continuous ME(≤3) laws are exactly ∪_E B_E over admissible E.
201: 
202: **Lemma 2.1 (cone).** K_E is a closed, convex, pointed cone. ℓ(f) := ∫_0^∞ f and m1(f) are > 0 on K_E∖{0}, and B_E is
203: compact and convex.
204: 
205: *Proof.* Each evaluation f ↦ f(t) is a linear functional on the finite-dimensional V_E, so K_E is an intersection of
206: closed half-spaces. If ±f ∈ K_E then f = 0 on [0, ∞), so f = 0 by (I1). For f ∈ K_E∖{0}, f ≥ 0 is continuous and
207: ≢ 0 on [0, ∞) by (I1), so ℓ(f) > 0 and m1(f) > 0. Fix a norm. ℓ is continuous and positive on the compact set
208: K_E ∩ {‖f‖ = 1}, so ℓ ≥ c > 0 there. Hence B_E ⊆ {‖f‖ ≤ 1/c}, which is closed and bounded. ∎
209: 
210: **Lemma 2.2 (ratio form).** For f as in 0.2, S(f) = min_{θ>0} R_θ(f), where
211: R_θ(f) := ∫_0^∞ (t − θ)² f / (θ² ∫_0^∞ f). The minimum is attained at θ = m2/m1.
212: 
213: *Proof.* With x := 1/θ > 0, R_θ = 1 − 2(m1/m0)x + (m2/m0)x². This is minimized at x = m1/m2 > 0, with value
214: 1 − m1²/(m0 m2) = S(f). ∎
215: 
216: **Lemma 2.3 (mixtures).** Let ν be a finite positive measure on M with ν(M) > 0, and g : M × [0, ∞) → [0, ∞)
217: measurable. Assume each g_μ := g(μ, ·) satisfies 0.2 (in particular 0 < ∫ g_μ), ∫_M ∫_0^∞ (1 + t²) g_μ dt dν < ∞,
218: and SCV(g_μ) ≥ c ≥ 0 for ν-a.e. μ. Then f := ∫_M g_μ dν(μ) satisfies 0.2 and SCV(f) ≥ c. In particular,
219: SCV(f1 + … + fk) ≥ min_i SCV(f_i) whenever every f_i satisfies 0.2 (positive mass).

282: **Lemma 3.1 (zero count; Chebyshev property).** Let E be any real multiset of size N ≥ 1. Every nonzero g ∈ V_E has at
283: most N − 1 real zeros counted with multiplicity.
284: 
285: *Proof.* Induction on N; N = 1 is trivial. Write g = Σ_{i=1}^r p_i(t) e^{κ_i t} with κ_i the distinct elements of E,
286: multiplicities n_i and deg p_i ≤ n_i − 1 (some p_i may be 0). If at most one p_i ≠ 0, then g = p_i e^{κ_i t} has
287: ≤ n_i − 1 ≤ N − 1 zeros. Otherwise let p_j ≠ 0 for some j ≥ 2. Put h := e^{−κ1 t} g; it has the same zeros with the
288: same multiplicities. Then h^{(n1)} = Σ_{i≥2} p̃_i e^{(κ_i−κ1)t} with deg p̃_i = deg p_i, because κ_i − κ1 ≠ 0 and
289: (D + c) preserves degree for c ≠ 0. So h^{(n1)} ≠ 0 lies in a real e.p. space of size N − n1 and, by induction, has
290: ≤ N − n1 − 1 zeros. Rolle with multiplicities (I3) says: if h has zeros x1 < … < xs of multiplicities k_j with
291: Σ k_j = Z, then h' has a zero of multiplicity ≥ k_j − 1 at each x_j and a zero in each (x_j, x_{j+1}), so ≥ Z − 1
292: zeros. If h had ≥ N zeros (choose finitely many), h^{(n1)} would have ≥ N − n1 zeros, a contradiction. ∎

307: **Lemma 3.3 (face rays).**
308: 1. For 0 < κ1 < κ2, a e^{−κ1t} + b e^{−κ2t} ≥ 0 on [0, ∞) iff a ≥ 0 and a + b ≥ 0. The extreme rays are e^{−κ2t} and
309:    e^{−κ1t} − e^{−κ2t}.

311: 3. SCV(e^{−κt}) = 1, SCV(t e^{−κt}) = 1/2, and SCV(e^{−κ1t} − e^{−κ2t}) = (κ1² + κ2²)/(κ1 + κ2)² ∈ [1/2, 1). So every
312:    face ray has SCV ≥ 1/2.

314: *Proof.* (1) e^{κ1t} f = a + b x, where x = e^{−(κ2−κ1)t} ranges over (0, 1]. An affine function is ≥ 0 on (0, 1] iff
315: it is ≥ 0 as x → 0+ and at x = 1. The planar cone {a ≥ 0, a + b ≥ 0} has extreme rays (0, 1) and (1, −1).
316: (2) t = 0 gives a ≥ 0 and t → ∞ gives b ≥ 0; the converse is clear.

662: h_τ'(t) = ((ω² + δ²)/ω) e^{−δ(t−τ)} sin ω(t − τ), so h_τ(τ) = h_τ'(τ) = 0. The set {g ∈ V : g(τ) = g'(τ) = 0} is
663: the line spanned by e^{−t}h_τ.
664: *Proof.* Write g = e^{−t}G; then g(τ) = g'(τ) = 0 iff G(τ) = G'(τ) = 0.
665: G' = e^{−δt}[(−δb + ωc) cos ωt + (−ωb − δc) sin ωt]. The map (b, c) ↦ (−δb + ωc, −ωb − δc) has determinant
666: δ² + ω² > 0, so G'(τ) = 0 is one nontrivial linear condition on (b, c), and G(τ) = 0 then fixes a. The formula for
667: h_τ' and the span membership are direct computations (`ctl-e-v1` e0, exact sympy). ∎

669: **Lemma 6.3 (extreme rays).** The extreme rays of K are exactly the rays of e^{−t}h_τ for the *feasible* τ ≥ 0, i.e.
670: those with h_τ ≥ 0 on [0, ∞).
671: *Proof.* Let f = e^{−t}H ∈ K∖0, so a > 0. The following cases are exhaustive.
672: * (a) H > 0 on [0, ∞). Since H → a > 0, inf H > 0, while |G| ≤ M for every g = e^{−t}G ∈ V. So f ± εg ∈ K and f is
673:   interior, not extreme.
674: * (b) H(0) = 0, H'(0) > 0 and H > 0 on (0, ∞). Then H ≥ c·t/(1 + t) with c > 0. Choose g ∉ span f with G(0) = 0;
675:   then |G| ≤ M t/(1 + t). So f is not extreme. *This is the outline's "boundary τ = 0 needs h'(0) = 0".*
676: * (c) H(0) = H'(0) = 0. Then f is a positive multiple of e^{−t}h_0 (6.2).
677: * (d) H(τ) = 0 for some τ > 0. Then H'(τ) = 0 (interior minimum), so f is a positive multiple of e^{−t}h_τ.

679: H(0) = 0 forces H'(0) ≥ 0. In (c) and (d), extremality follows exactly as in 3.5: if f = x + y with x, y ∈ K, then

683: is the unique solution in (π, 2π) of g_r(u) = 1. Equivalently, for τ < 2π/ω, feasibility ⟺ h_τ(0) ≥ 0.
684: *Proof.* First, h_τ(0) = 1 − e^{δτ}(cos ωτ − r sin ωτ) = 1 − g_r(φ), since δτ = rφ.

687: on (θ1, 2π].

692: * If τ < 2π/ω: on s ∈ (−π/ω, 0), h_τ decreases to h_τ(τ) = 0, so h_τ > 0 there. On s ∈ (−2π/ω, −π/ω], h_τ is
