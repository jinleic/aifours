85: Spec(sigma_u^(l'+l)) subset of Spec(sigma_v^(l') sigma_u^l).  [r2 fix 1: r1 printed sigma_v^(l'+l) in the second inclusion, which is
86: false (l = 1, l' = 2, u != v: size 3 forces sigma_u, not sigma_v).]  In both forms the EVEN block sigma_v^(l') is recoloured with the
87: value u of its neighbour, on either side.
88: Proof (first form).  Spec(sigma_u^(l+l')) = {(c, sigma_u^c) : 0 <= c <= l + l'} (sigma_u^c = 1 for even c, sigma_u for odd c).
89: c <= l: c letters sigma_u.  c > l, c - l even: all l letters sigma_u and c - l letters sigma_v (even number): product sigma_u^l =
90: sigma_u^c.  c > l, c - l odd: then c - l <= l' - 1, take l - 1 letters sigma_u and c - l + 1 <= l' letters sigma_v.  Second form
91: [r2 fix 1]: the same counts, with the even number (c - l or c - l + 1) of letters sigma_v taken FIRST and then l or l - 1 letters

116: ## 3. Lemma BC' (block chain with the genuineness boost)
117: 
118: For a proper pattern Q of an avoider put lambda'(Q) := lambda(Q) + [lambda(Q) = 0 and u_Q != 0 (mod p)].
119: **Lemma BC'.**  Let w be an avoider (any length; windows of Lemma H0).  Let (P_1, ..., P_s), s >= 2, be an ordered partition of
120: [k] into nonempty proper patterns, Q_t := P_1 u ... u P_t.  If
121:  (a) lambda'(P_1) + ... + lambda'(P_s) >= p + 1;
122:  (b) for 2 <= t <= s - 1, with X = Q_(t-1), Y = P_t, Z = Q_t^c:  lambda'(X u Y) + lambda'(Y u Z) + lambda'(Z u X) >= p + 1 and
123:      lambda'(X) + lambda'(Y) + lambda'(Z) >= 1;
124:  (c) lambda'(P_s) + lambda'(P_s^c) >= 1,
125: then w has an identity 2p-subword (contradiction).
126: Proof.  (*) For every proper Q, u_Q is congruent to no element of I'(Q) := [1 - lambda'(Q^c), lambda'(Q) - 1].  Indeed I'(Q) = I(Q)
127: if no boost occurs; if exactly one of lambda(Q), lambda(Q^c) is 0 and boosted, I'(Q) = I(Q) u {0} or is empty; if both are 0 and
128: boosted, I'(Q) = {0}; and u_Q avoids I(Q) (Lemma H0) and 0 (the boost condition; u_(Q^c) = -u_Q).  Hence |I'(Q)| <= p - 1,
129: i.e. lambda'(Q) + lambda'(Q^c) <= p.  From here the proof of Lemma BC (inverse-parity/proof-PAR-K0.md L67-87) is repeated
130: verbatim with lambda' in place of lambda; it uses only (*) and arithmetic:
131: Claim: if y = u_Q (mod p) and 1 - l' <= y <= p + l - 1 (l = lambda'(Q), l' = lambda'(Q^c)) then l <= y <= p - l' (the ranges
132: [1 - l', l - 1] and [p + 1 - l', p + l - 1] consist of integers congruent to elements of I'(Q); as l + l' <= p the three ranges
133: [1 - l', l - 1], [l, p - l'], [p + 1 - l', p + l - 1] tile [1 - l', p + l - 1]; if l + l' <= 1 the outer ones are empty and
134: [1 - l', p + l - 1] lies in [l, p - l']).  Choose v_t = u_(P_t) (mod p) in [lambda'(P_t), p - lambda'(P_t^c)] (by the claim if
135: l + l' >= 1, since [1 - l', p + l - 1] then has >= p integers; directly if l + l' <= 0).  V_t := v_1 + ... + v_t = u_(Q_t).
136: Induction: V_t in [lambda'(Q_t), p - lambda'(Q_t^c)] for t <= s - 1: V_t lies in [lambda'(X) + lambda'(Y),
137: 2p - lambda'(Y u Z) - lambda'(Z u X)], which by (b) lies in [1 - lambda'(Z), p + lambda'(X u Y) - 1], and the claim for Q_t = X u Y
138: (complement Z) applies.  Finally V_s = 0 (mod p), V_s >= p + 1 by (a), V_s <= (p - lambda'(P_s)) + (p - lambda'(P_s^c)) <= 2p - 1
139: by (c).  []

141: **Lemma CH (conditions (b), (c) for a family of interval partitions, B = kappa = 0).**  Let w be an avoider of length 4p - 2 with
142: B = kappa = 0 and R >= p, and let P_1, ..., P_s (s >= 2) be consecutive cyclic intervals in cyclic order partitioning [k], such
143: that every part either has R_P >= 1 or is a single genuine empty run with beta <= 1, and at most one part has R_P = 0.  Then (b)
144: and (c) of Lemma BC' hold.
145: Proof.  For a cyclic interval Q (m = 1), B = kappa = 0 and R_Q <= R <= 2p - 1 give lambda(Q) = min(p, R_Q + 1 - beta,
146: floor(R_Q/2) + 1) = floor(R_Q/2) + 1 - def(Q), def(Q) := max(0, beta(Q) - ceil(R_Q/2)).  Every union U of parts that contains
147: >= 2 parts has R_U >= 1, so def(U) <= 1, and lambda'(U) >= lambda(U) >= 0; a single part has lambda' >= 0 too (R_P >= 1, or
148: R_P = 0 with beta <= 1: lambda = 1 - beta, boosted to 1 when it is 0 since the part is a genuine empty run).  (b) lower: X, Y, Z
149: are unions of parts with R_X + R_Y + R_Z = R >= 5, the largest has R_Q >= 2 and lambda >= 1.  (b) upper: the three unions
150: contain >= 2 parts each; their R-values sum to 2R, at most two are odd, so the floors sum to >= R - 1; two unions with def = 1
151: would both have R_U <= 2 and would cover the cycle (X u Y and Y u Z do), so R <= 4: impossible.  Hence the sum is
152: >= R - 1 + 3 - 1 >= p + 1.  (c): one of P_s, P_s^c has R_Q >= 3 (R >= 5), so def = 0 and lambda >= 2; the other has lambda' >= 0.  []

154: ## 4. Theorem K0*
155: 
156: **Theorem K0*.**  Let p >= 5 be prime and w a word of length 4p - 2 over D_(2p) whose rotation letters all lie in one set
157: {rho_x, rho_-x}, x != 0.  If w is an avoider with kappa(w) = 0 (i.e. its maximal constant reflection blocks contain p - 1 disjoint
158: same-letter pairs), then every maximal cyclic reflection run of w is constant.  Equivalently REFL(p) holds for avoiders with
159: kappa = 0.  (Uses only Theorem P, Davenport-alpha, EGZ/Lemma AR and the elementary lemmas above; no RGR theorem is imported.)
160: 
161: Proof.  Normalise x = 1.  If F = 0 there is nothing to prove; if R = 0, Lemma AR.  So w is a G-word with F, R >= 1; suppose it has
162: g >= 1 genuine empty runs and avoids.  By (Z0) and kappa = 0: B = 0 (all rotations rho_1), R = 2p - o_F, 1 <= o_F.
163: 
164: Step 1 (FUS process).  While some genuine empty run is adjacent to an even block, apply a FUS step there.  Each step preserves
165: avoidance, the length, every rotation, and lowers g by >= 1.  It never performs an odd-odd double fusion: that would give an
166: avoider with kappa = -1, contradicting (Pairs).  So kappa stays 0 and B stays 0.  Let w_end be the final word.
167: Step 2 (w_end has no empty run).  Otherwise every empty run of w_end lies between two odd blocks, and no even block of w_end is
168: adjacent to an empty run.  Apply PM0 across every even block (both neighbouring runs are nonempty): each step preserves avoidance
169: and kappa = 0, keeps every empty run and the odd parity of its neighbours, and creates no even block next to an empty run.  The
170: resulting avoider has e_F = 0 and e_R >= g >= 1 > e_F + 2 kappa, contradicting (P0).
171: Step 3 (the last step).  Hence the process ends with an RGR word and its last step w' -> w_end removed every empty run of the
172: avoider w' (kappa(w') = 0, B = 0, g(w') >= 1).  A FUS step at an empty run R_t recolours an even neighbour, which then fuses with
173: the block on its other side only through a second empty run; so either
174:  (C1) g(w') = 1: one empty run R_t, and at least one of S_(t-1), S_t is even; or
175:  (C2) g(w') = 2: S_(t-1) = sigma_u^a, R_t empty, S_t = sigma_v^b with b even, R_(t+1) empty, S_(t+1) = sigma_u^c, u != v, and
176:       a, c not both odd (kappa = 0).
177: Step 4 (normalisation).  Apply PM0 across every even block of w' whose two neighbouring runs are nonempty.  This keeps
178: avoidance, kappa = 0, B = 0, the empty runs, their neighbouring blocks' values and parities.  Call the result w'' (still k, o_F,
179: e_F, e_R, R, r_i for its own decomposition).  Now every even block of w'' is adjacent to an empty run, so its even blocks lie in
180: {S_(t-1), S_t} (C1) or {S_(t-1), S_t, S_(t+1)} (C2).  By (P0) and (Par), e_R <= e_F and e_R = e_F (mod 2), and e_R >= g.  Also
181: o_F <= p: the k - g nonempty runs give k - g <= R = 2p - o_F, and k - g = o_F + e_F - g >= o_F as e_F >= e_R >= g; so R >= p >= 5.
182: Step 5 (cases and partitions).  For a cyclic interval Q, lambda(Q) = floor(R_Q/2) + 1 - def(Q) as in Lemma CH.  Single runs are
183: written {i}.
184:  C1a: exactly one of S_(t-1), S_t is even.  Then e_F = 1, e_R = 1: R_t is the only even run and every nonempty run is odd;
185:    k = o_F + 1.  Parts: all single runs in cyclic order.  {t}: beta = 1, R = 0, lambda = 0, u_t = theta_t/2 != 0, lambda' = 1.
186:    The other run next to the even block has beta = 1 and lambda = (r + 1)/2; every other run has beta = 0 and lambda = (r + 1)/2.
187:    Sum = 1 + (R + k - 1)/2 = 1 + (2p - o_F + o_F)/2 = p + 1.
188:  C1b: both S_(t-1), S_t even.  Then e_F = 2, e_R = 2: R_t and exactly one nonempty even run.  k = o_F + 2 >= 3, so S_(t-2) and
189:    S_(t+1) are odd.  Parts: {t, t+1} (boundaries S_(t-1) even, S_(t+1) odd; R = r_(t+1) >= 1) and all other single runs ({t-1} has
190:    beta = 1, R >= 1).  Every part has lambda = floor(R_P/2) + 1, and the sum is
191:    sum_(i != t) (floor(r_i/2) + 1) = (R + (k - 1) + 1)/2 = (2p - o_F + o_F + 2)/2 = p + 1.
192:  C2a: exactly one of a, c even, say a odd and c even (the case a even, c odd is the mirror image below).  Then e_F = 2 (S_t,
193:    S_(t+1)), e_R = 2 (the two empty runs), every nonempty run odd, k = o_F + 2 >= 3, S_(t+2) odd (it is S_(t-1) if k = 3).
194:    Parts: {t} (boundaries S_(t-1) odd, S_t even: beta = 1, lambda = 0, u_t = (u - v)/2 != 0, lambda' = 1), {t+1, t+2} (boundaries
195:    S_t even, S_(t+2) odd; R = r_(t+2) >= 1, lambda = (r_(t+2) + 1)/2), all other single runs (beta = 0).  Sum =
196:    1 + sum_(i notin {t, t+1}) (r_i + 1)/2 = 1 + (R + k - 2)/2 = p + 1.
197:    Mirror (a even, c odd): parts {t+1} (boundaries S_t even, S_(t+1) odd, u_(t+1) = (v - u)/2 != 0, lambda' = 1), {t-1, t}
198:    (boundaries S_(t-2) odd, S_t even; R = r_(t-1) >= 1), all other single runs; the same sum p + 1.
199:  C2b: a, c both even.  Then e_F = 3, e_R = 3 (the two empty runs and exactly one nonempty even run), k = o_F + 3 >= 4, so S_(t-2)
200:    and S_(t+2) are odd.  Parts: {t-1, t} (boundaries S_(t-2) odd, S_t even; R = r_(t-1) >= 1), {t+1, t+2} (boundaries S_t even,
201:    S_(t+2) odd; R = r_(t+2) >= 1), all other single runs (beta = 0).  Sum = sum over the nonempty runs of (floor(r_i/2) + 1) =
202:    (R + (k - 2) + 1)/2 = (2p - o_F + o_F + 2)/2 = p + 1.
203: In every case the parts are consecutive cyclic intervals in cyclic order, each has R_P >= 1 or is a single genuine empty run with
204: beta = 1, and at most one part has R_P = 0.  So (a) holds, Lemma CH gives (b), (c), and Lemma BC' shows that w'' has an identity
205: 2p-subword, contradicting its avoidance.  []
