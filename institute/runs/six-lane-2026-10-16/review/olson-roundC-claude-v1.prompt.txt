23: block's parity (change +-1).  Deleting a block of length 1 removes one odd block; its two runs merge, and if the merged

28: reflection runs are constant.  Then w is RGR: two rotation letters of w whose values are not in one pair {c, -c} with
29: c != 0 (or a letter rho_0) survive together in some w' (delete any third letter; 4p - 1 >= 3), and two adjacent
30: reflections of different values survive, still adjacent, in the subword obtained by deleting a letter away from them.

16: ## 0. Lemma INC
17: 
18: Let p >= 5 be prime and Y a zero-sum-free sequence of odd elements of Z_(2p) of length L = 2p-1-e, 0 <= e <= 3.  Then Y = g^L
19: with g a generator, or e >= 2 and Y = g^(L-1)(3g).
20: Proof.  For an ordering y_1..y_L let A_0 = {0}, A_t = A_(t-1) u (A_(t-1) + y_t), delta_t = |A_t| - |A_(t-1)|.
21: (a) delta_t >= 1: else A_(t-1) + y_t lies in A_(t-1), so A_(t-1) contains 0, y_t, 2y_t, ..., hence -y_t, which is 0 or a
22:     subsequence sum of y_1..y_(t-1): a zero-sum.  As |A_L| <= 2p, sum (delta_t - 1) <= 2p-1-L = e <= 3 ("extras").
23: (b) At most two distinct values: put three distinct values a, b, c first.  A_2 = {0, a, b, a+b} (a+b even, nonzero);
24:     A_2 + c = {c, a+c, b+c, a+b+c} is disjoint from A_2 (c != a, b; a+b+c = a or b gives a zero-sum pair; a+c, b+c are even,
25:     nonzero, and a+c = a+b iff c = b, b+c = a+b iff c = a).  Deltas 1, 2, 4: extras 4 > 3.
26: (c) Y = a^m b^n, m >= n >= 1.  L >= 6 gives m >= 3; a = (1,0) would make a a a zero-sum, so a is a generator; b = d a with
27:     d odd, 3 <= d <= 2p-1.  Order a^m first: A = {0, a, ..., m a}, deltas 1.  First b:
28:     - if 2p-d <= m, b a^(2p-d) is a zero-sum;
29:     - if d <= m: m+d >= 2p would give the previous case, so A + b = {d a, ..., (m+d) a} adds d new sums, extras d-1 <= 3,
30:       d = 3;
31:     - otherwise b + i a = j a (0 <= i, j <= m) is impossible, A + b is disjoint from A, and extras >= m >= 4 > 3
32:       (for p >= 7, m >= ceil(L/2) >= p-2 >= 5; for p = 5 and e <= 2, L >= 7 and m >= 4) unless p = 5, e = 3,
33:       m = n = 3.  In that case m < d < 2p - m = 7 forces d = 5, i.e. b = 5a = (1,0), and b b is a zero-sum (n = 3):
34:       impossible.
35:     So b = 3a.  If n >= 2: when m+6 >= 2p, the subsequence b b a^(2p-6) is a zero-sum (2p-6 >= 0 and 2p-6 <= m); so
36:     m+6 < 2p, A = {0, ..., (m+3) a} after the first b, and the second b adds the three new sums (m+4)a, (m+5)a, (m+6)a:
37:     extras >= 2 + 2 > 3.  Hence n = 1, Y = a^(L-1)(3a), extras 2 <= e.  []
