182: ### Lemma A
183: Let d ≥ 1, n ≥ 1 with 5 | n and dn even, and M ∈ M ∩ (5/n)Z^{5×5} with support supp M := {u : m_u > 0}. For every
184: μ ∈ R^{supp M},
185:   |T(M)|/|P_{n,d}| ≤ P_d(n)·exp(n·V_μ(M)),
186: where
187:   V_μ(M) := ((d−1)/5) Σ_u m_u log m_u + (1−d) log 5 + (d/2) log d + Σ_{e = {u,v} ⊆ supp M, u ~ v} e^{μ_u + μ_v − 1}
188:            − (d/5) Σ_{u ∈ supp M} μ_u m_u
189: and P_d(n) := e^{26}(dn + 1)^{25/2} (dn/2 + 1)^{401/2}. P_d(n) depends on neither M nor μ.
190: 
191: *Proof.* Each bound is applied to the exact count.
192: 1. *Colourings.* By the multinomial bound, n!/Π_u n_u! ≤ Π_{u ∈ supp M} (n/n_u)^{n_u} = exp(n H_5(M)), where
193:    H_5(M) := −Σ_u (m_u/5) log(m_u/5). Empty cells contribute 0! = 1 and 0⁰ = 1.
194: 2. *Points of each cell.* For u ∈ supp M, (d n_u)! ≤ e√(dn_u + 1)(dn_u/e)^{dn_u} ≤ e√(dn + 1)(dn_u/e)^{dn_u}. For
195:    u ∉ supp M, (d n_u)! = 0! = 1 = (0/e)⁰. There are 25 cells, so
196:    Π_u (d n_u)! ≤ e^{25}(dn + 1)^{25/2} Π_{u ∈ supp M} (dn_u/e)^{dn_u}.
197: 3. *Edge factorials.* For every b ∈ B(M, n) and every e, 1/b_e! ≤ (e/b_e)^{b_e} (lower Stirling bound; b_e = 0 gives
198:    1 ≤ 1). Summing (3.3) over u gives Σ_e b_e = dn/2, so Π_e 1/b_e! ≤ e^{dn/2} exp(−Σ_e b_e log b_e).
199: 4. *Number of tuples.* Each b_e lies in {0, …, dn/2}, so |B(M, n)| ≤ (dn/2 + 1)^{200}.
200: 5. *Pairings.* 1/|P_{n,d}| = (dn/2)! 2^{dn/2}/(dn)! ≤ e√(dn/2 + 1)(dn/(2e))^{dn/2} 2^{dn/2}/(dn/e)^{dn}
201:    = e√(dn/2 + 1)·(dn/e)^{−dn/2}.
202: 6. *Empty cells in B(M, n).* If u ∉ supp M then (3.3) forces b_e = 0 for every e ∋ u. Such edges contribute
203:    b_e log b_e = 0, so only edges e ⊆ supp M remain.
204: 7. *Pointwise weak duality.* Fix b ∈ B(M, n) and write b_e = nβ_e. Then
205:    −Σ_e b_e log b_e = −n Σ_e β_e log β_e − (dn/2) log n.
206:    The constraints read Σ_{v ~ u} β_{uv} = d m_u/5 for u ∈ supp M. For any μ ∈ R^{supp M}, with all sums over
207:    e = {u, v} ⊆ supp M and u ∈ supp M,
208:      −Σ_e β_e log β_e = Σ_e [−β_e log β_e + β_e(μ_u + μ_v)] − Σ_u μ_u Σ_{v~u} β_{uv}
209:                       ≤ Σ_e e^{μ_u+μ_v−1} − (d/5) Σ_u μ_u m_u.
210:    The equality holds because each edge contributes β_e to both endpoint constraints. The inequality is (I8)
211:    applied to each term with θ = μ_u + μ_v. No strong duality and no exact inner optimum is needed.
212: 8. *Collecting exponents.* Multiply items 1–5 and substitute item 7 for every b. Since Σ_u d n_u = dn and
213:    Σ_e b_e = dn/2, the factors (dn_u/e)^{dn_u}, e^{dn/2}, n^{−dn/2} and (dn/e)^{−dn/2} give exactly
214:      n[Σ_u (d m_u/5) log(d m_u/5) − (d/2) log d] + dn log n − dn + dn/2 − (dn/2) log n − (dn/2) log n + dn/2.
215:    The n log n terms and the linear terms cancel. Using Σ_u m_u = 5,
216:      H_5(M) + Σ_u (d m_u/5) log(d m_u/5) − (d/2) log d = ((d−1)/5) Σ_u m_u log m_u + (1−d) log 5 + (d/2) log d

264: ### Lemma 3.1 (row reduction at k = 5)
265: Let (f_pq) be any 5×5 array of non-negative reals, with row sums R_p, column sums C_q, total Σf and
266: E(f) := Σ_{unordered allowed} f_u f_v. Then
267:   2E(f) = (Σf)² − Σ_p R_p² − Σ_q C_q² + Σ f_pq²,
268: and
269:   E(f) ≤ Σ_p ((3/2)R_p² + Q_p/2),   Q_p := Σ_q f_pq².
270: 
271: *Proof.* The first identity is inclusion–exclusion over the pairs with p = r or q = s (verifier B, symbolic in the
272: 25 entries). For the second, an exact identity (verifier B) gives
273:   3Σ_p R_p² + Σ f² − 2E(f) = [Σ_q C_q² − (Σf)²/5] + (4/5)[5Σ_p R_p² − (Σ_p R_p)²].
274: Both brackets are ≥ 0 by Cauchy–Schwarz over the five columns and the five rows. ∎
275: 
276: If M ∈ S_5 and f = m^{11/12}, then row p contributes (3/2)R_p² + Q_p/2 = F(r_p), where r_p is the p-th row of M.
277: Hence E(M) ≤ Σ_p F(r_p).

279: ### Lemma 3.2 (row inequality on Δ_5)
280: For every r ∈ Δ_5, F(r) ≤ F(u_*) − κ|r − u_*|², where F(u_*) = 8·5^{−5/6} = 40·5^{−11/6}.
281: 
282: **Proof (analytic, by hypercontractivity). This is the proof on which Theorem C rests.**
283: 1. *The chain.* Let X = {1, …, 5} with the uniform measure π, and K(x, y) := π(y). K is irreducible, and reversible
284:    because π(x)K(x, y) = π(x)π(y). K is the projection g ↦ Eg, so (I − K)² = I − K and
285:    H_t = exp(−t(I − K)) = K + e^{−t}(I − K) (I7). Thus H_t g = T_ρ g := Eg + ρ(g − Eg) with ρ = e^{−t}.
286: 2. *Normalisation.* D–SC Theorem A.1 with |X| = 5 gives α = (1 − 2/5)/log 4 = 3/(5 log 4) (verifier B). By
287:    Theorem 3.5(ii) with q = 12, ‖H_t‖_{2→12} ≤ 1 whenever e^{4αt} ≥ 11, i.e. t ≥ t_0 := (5/12)(log 4)(log 11).
288: 3. *Duality.* H_t is self-adjoint on L²(π). By Hölder with exponents 12/11 and 12, for every g:
289:    ‖H_t g‖₂ = sup_{‖h‖₂ ≤ 1} ⟨g, H_t h⟩_π ≤ ‖g‖_{12/11} sup_{‖h‖₂ ≤ 1} ‖H_t h‖₁₂ ≤ ‖g‖_{12/11}
290:    for t ≥ t_0. Equivalently, ‖T_ρ g‖₂ ≤ ‖g‖_{12/11} for 0 ≤ ρ ≤ a := e^{−t_0} = 11^{−5 log 4/12}.
291: 4. *ρ = 1/4 is admissible, strictly.* 1/4 < a ⟺ log 4 > (5/12)(log 4)(log 11) ⟺ log 11 < 12/5 ⟺ 11⁵ < e¹².
292:    Exact proof: e¹² = Σ_j 12^j/j! > Σ_{j=0}^{21} 12^j/j! = 161767.65… > 161051 = 11⁵, since every omitted term is
293:    positive and the partial sum is computed in exact rational arithmetic (verifier B; 22 terms is the minimum
294:    needed). The arb enclosure is a = 0.250304119353463942637… > 1/4, and the margin is
295:    12/5 − log 11 = 0.0021047272016294559… (verifier B).
296: 5. *Identification.* Put g_j := r_j^{11/12}.
297:    - (3/2)S(r)² + Q(r)/2 = 40‖T_{1/4} g‖₂² (verifier B).
298:    - ‖g‖²_{12/11} = ((1/5)Σ r_j)^{11/6} = 5^{−11/6} (verifier B), and 40·5^{−11/6} = F(u_*).
299: 6. *Decay.* ‖T_ρ g‖₂² = (Eg)² + ρ² Var_π g (verifier B). So
300:    F(r) = 40[(Eg)² + Var_π g/16] = 40[‖T_a g‖₂² − (a² − 1/16) Var_π g] ≤ F(u_*) − 40(a² − 1/16) Var_π g.
301: 7. *Variance comparison.* By the mean value theorem, |s^{11/12} − t^{11/12}| ≥ (11/12)|s − t| for s, t ∈ [0, 1],
302:    including s = 0, because the derivative (11/12)ξ^{−1/12} ≥ 11/12 for ξ ∈ (0, 1]. Writing
303:    Var_π g = (1/50) Σ_{i,j} (g_i − g_j)² (verifier B), this gives Var_π g ≥ (121/144) Var_π r = (121/144)|r − u_*|²/5.
304: 8. *Conclusion.* F(r) ≤ F(u_*) − 40·(121/720)(a² − 1/16)|r − u_*|² = F(u_*) − κ|r − u_*|². ∎
