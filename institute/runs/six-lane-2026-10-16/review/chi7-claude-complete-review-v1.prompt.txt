85: ## 2. The sharpened Achlioptas–Naor inequality at k = 4 and the replacement for KPW (3.15)
86: 
87: ### Lemma 2.1 (per-row inequality)
88: For every p ∈ Δ_4,
89:   D(p‖U) ≥ (3/2)·log 3·(Σ_i p_i² − 1/4),
90: with equality iff p = U or p is a permutation of (3/4, 1/12, 1/12, 1/12).
91: 
92: *Proof.* Let F(p) := D(p‖U) − (3/2) log 3 (Σp_i² − 1/4). F is continuous on the compact set Δ_4 and F(U) = 0.
93: 
94: (a) *No minimiser on the boundary.* Suppose p_j = 0 and p_i > 0. For 0 < ε ≤ p_i/2, move ε from i to j and call
95: the result p′. Then:
96: - F(p′) − F(p) = ε log(4ε) + [(p_i − ε) log(4(p_i − ε)) − p_i log(4p_i)] − (3/2) log 3 [ε² + (p_i − ε)² − p_i²].
97: - By the mean value theorem the middle bracket has absolute value at most ε(|log(2p_i)| + |log(4p_i)| + 1).
98: - The last term is O(ε).
99: - So F(p′) − F(p) ≤ ε(log(4ε) + K) < 0 for small ε.
100: Hence every minimiser lies in the relative interior.
101: 
102: (b) *Minimisers take at most two values.* At an interior minimiser, Lagrange multipliers give
103: ψ(p_j) := log(4p_j) + 1 − 3 log 3·p_j = λ for all j. Since ψ″(u) = −1/u² < 0, ψ is strictly concave and takes
104: each value at most twice. So up to permutation p = (a, …, a, b, …, b) with m copies of a, 1 ≤ m ≤ 3 (m = 0 is
105: the uniform case). This leaves two one-parameter families:
106: - m = 1 or 3: (x, y, y, y) with y = (1 − x)/3 and x ∈ [0, 1];
107: - m = 2: (x, x, y, y) with y = 1/2 − x and x ∈ [0, 1/2].
108: 
109: (c) *Family (x, y, y, y).* Put x = (1 + 3v)/4, so y = (1 − v)/4 and v ∈ [−1/3, 1]. Then:
110: - D = [(1+3v) log(1+3v) + 3(1−v) log(1−v)]/4;
111: - Σp² − 1/4 = (4x − 1)²/12 = 3v²/4;
112: - so 4F = G(v) := (1+3v) log(1+3v) + 3(1−v) log(1−v) − (9/2) log 3·v².
113: 
114: Derivatives:
115: - G′(v) = 3L(v), where L(v) := log((1+3v)/(1−v)) − 3v log 3;
116: - L′(v) = q(v) − 3 log 3, where q(v) := 3/(1+3v) + 1/(1−v).
117: 
118: q is strictly convex on (−1/3, 1), since q″ = 54/(1+3v)³ + 2/(1−v)³ > 0. Also q(0) = q(2/3) = 4 and q(1/3) = 3.
119: Since 3 < 3 log 3 < 4, which is the exact fact 1 < log 3 < 4/3 (verified in §7, item A1), L′ has exactly two
120: zeros, v_1 ∈ (0, 1/3) and v_2 ∈ (1/3, 2/3). L′ > 0 on (−1/3, v_1) ∪ (v_2, 1) and L′ < 0 on (v_1, v_2).
121: 
122: Also L(0) = 0 and L(2/3) = log 9 − 2 log 3 = 0. It follows that:
123: - L < 0 on (−1/3, 0) and L > 0 on (0, v_1];
124: - L is strictly decreasing on [v_1, v_2] with L(v_1) > 0 > L(v_2), so it has a unique zero v* there;
125: - L < 0 on [v_2, 2/3) and L > 0 on (2/3, 1).
126: 
127: So G is strictly decreasing on [−1/3, 0], increasing on [0, v*], decreasing on [v*, 2/3] and increasing on
128: [2/3, 1], using continuity at the endpoints. Since G(0) = 0 and G(2/3) = 3 log 3 − log 3 − 2 log 3 = 0, we get
129: G ≥ 0, with equality only at v ∈ {0, 2/3}, i.e. p = U or p = (3/4, 1/12, 1/12, 1/12).
130: 
131: (d) *Family (x, x, y, y).* Put u = 4x − 1 ∈ [−1, 1]. Then:
132: - D = [(1+u) log(1+u) + (1−u) log(1−u)]/2 and Σp² − 1/4 = u²/4;
133: - r(u) := D − u²/2 is even with r(0) = 0, and r′(u) = atanh(u) − u ≥ 0 on [0, 1);
134: - so D ≥ u²/2 ≥ (3/8) log 3·u², because (3/8) log 3 < 1/2 ⟺ log 3 < 4/3.
135: Hence F ≥ 0 on this family, with equality only at u = 0.
136: 
137: (e) By (a) and (b), min F is attained in one of the two families, so min F = 0. Any zero of F is a minimiser,
138: hence lies in a family, hence is one of the stated equality points. ∎

140: ### Theorem 2.2 (AN Theorem 7 at k = 4 with the sharper constant)
141: For every A ∈ S_4 and every real c ≥ 0,
142:   g_c(J) − g_c(A) ≥ ((3/8) log 3 − c/9)·Σ_{ij}(a_ij − 1/4)².
143: In particular g_c(J) ≥ g_c(A) for all A ∈ S_4 whenever c ≤ c* := (27/8) log 3 = (k−1)³ log(k−1)/(k(k−2)) at
144: k = 4. AN state their Theorem 7 only for c ≤ c_{k−1} = 3 log 3.
145: 
146: *Proof.* For a row a_i ∈ Δ_4, Σ_j a_ij log a_ij = D(a_i‖U) − log 4, so H(A) = log 4 − (1/4)Σ_i D(a_i‖U) and
147: H(J) = log 4. Also E(A) − E(J) = log((1/2 + ρ_A/16)/(9/16)) = log(1 + (ρ_A − 1)/9) ≤ (ρ_A − 1)/9. Hence
148:   g_c(J) − g_c(A) = (1/4)Σ_i D(a_i‖U) − c(E(A) − E(J))
149:                   ≥ (1/4)(3/2) log 3·Σ_i(Σ_j a_ij² − 1/4) − c(ρ_A − 1)/9
150:                   = ((3/8) log 3 − c/9)(ρ_A − 1),
151: by Lemma 2.1 applied row by row. Finally ρ_A − 1 = Σ(a_ij − 1/4)². ∎

265: ### Lemma 5.1 (exact count)
266: Let N = dn be even. Colour the n cells with class sizes n_1, n_2, n_3 and put s_i = d n_i. The number of perfect
267: matchings of the N points with no pair inside a colour class is
268: - M(s) = s_1! s_2! s_3!/(b_12! b_13! b_23!), if all b_ij := (s_i + s_j − s_k)/2 ({i,j,k} = {1,2,3}) are
269:   non-negative integers;
270: - M(s) = 0 otherwise.
271: 
272: *Proof.* Such a matching has b_ij pairs between classes i and j, and s_i = b_ij + b_ik, which forces the stated
273: b_ij. Choose, in each class i, which b_ij of its points go to class j: s_i!/(b_ij! b_ik!) ways. Then match
274: across each pair of classes: b_ij! ways. ∎

276: ### Lemma 5.2 (exponential bound)
277: Let x_i = n_i/n, and let P := {x ∈ R³ : Σx_k = 1, 0 ≤ x_k ≤ 1/2}. Define
278:   w_d(a) := (d−1) a log a − d (1/2 − a) log(1/2 − a),   Φ_d(x) := Σ_k w_d(x_k).
279: Then the expected number Z_3 of proper 3-colourings of P_{n,d} satisfies
280:   E Z_3 ≤ e⁴ (n+1)² (dn+1)² · exp(n · max_P Φ_d).

282: *Proof.*

287:   e⁴ (N+1)² · exp(N[Σ x_k log x_k − Σ_k (1/2 − x_k) log(1/2 − x_k)]). All the linear terms cancel because
288:   Σ s_i = N and Σ b_ij = N/2.
