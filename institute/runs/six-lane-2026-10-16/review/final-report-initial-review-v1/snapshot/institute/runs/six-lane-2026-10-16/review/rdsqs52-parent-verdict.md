# RDSQS(52): parent verdict

## Result

The pinned certificate gives an explicit **RDSQS(52)**: a Steiner quadruple system on 52 points whose derived Steiner triple system is resolvable at every one of the 52 points.

- Certificate: [rdsqs52_z52_m23.txt](rdsqs52-parent-inputs-v1/rdsqs52_z52_m23.txt), SHA-256 `7ae0a828b5af08b4bd9b423564981d85e3703886553638024fdc812f564989a6`.
- It contains all 5,525 quadruples. Every one of the 22,100 three-subsets lies in exactly one block.
- At each point x, the certificate gives an explicit resolution of the 425 derived triples into 25 parallel classes of 17 triples.
- The block set is invariant under the affine group generated by `y ↦ y+1` and `y ↦ 23y` (order 312). Every listed resolution is a translate of the resolution at 0.

Primary target: Tan–Zhou, arXiv:2503.11934v1 §4(1), PDF p.19:
> “Find more examples of mcDSQS(v)s, for example, an mcDSQS(38) and an RDSQS(52) (the smallest unknown mcDSQS(6n + 2)s and the smallest unknown RDSQS(6n + 4)s, respectively).”

The parent read the definition: “We use the notation RDSQS(v) to denote an SQS(v) with resolvable derived designs” (same paper, lines 78–82). The frozen contract requires one SQS with explicit resolutions at every point ([contract](../screening/math-1-rdsqs52-contract.json)).

## Priority, consequences and significance

A bounded priority audit ([report](rdsqs52-priority-audit.md)) found no earlier construction or impossibility proof. It read the 2025 arXiv and journal metadata, the Tan–Zhou tilings paper, Liu–Lei, Shi–Xia–Krotov, and the reachable Yuan–Kang/Xu–Ji abstracts and citations. Inaccessible bodies remain the main access hole. A search miss is not novelty.

Consequences the audit traced to primary statements:
- **Overlarge set.** An RDSQS(v+1) gives an overlarge set of Kirkman triple systems OLKTS(v). Each triple T of the point set is contained in exactly one block B, so it occurs in exactly one derived design, at x = B∖T. Hence this certificate gives an **OLKTS(51)**. Tan–Zhou arXiv:2512.22754v1, Theorem 2.8(2), lists 51 among the exceptions to its stated OLKTS family. That theorem is not a complete status list, so this is not presented as a separately stated open problem.
- **Diameter-perfect codes.** Tan–Zhou Corollary 1.4(2) states: “For n ≡ 4 (mod 6), if there exists an RDSQS(n), then q′₀(3,4,n) = n/2.” The certificate therefore gives the paper's minimum alphabet value **q′₀(3,4,52) = 26** for the defined diameter-perfect constant-weight code problem.
- **No LKTS gain.** LKTS(51) is already known, so this result gives no new LKTS order through the usual tripling theorem.

Significance: a modest-to-specialist finite construction that settles the smallest order explicitly named unknown in a 2025 RDSQS paper. It contributes evidence for the Shi–Xia–Krotov conjecture, but does not prove that conjecture.
