33: a = b = 0.  Then |A + B| >= |A| + |B| - 1.

42: ## 2. Lemma GROW
43: 
44: Let D be a zero-sum-free SET of d >= 3 distinct odd elements with |A(D)| <= 2p-2.  Then some x in D has
45: |A(D)| >= |A(D - x)| + 2.
46: Proof.  Otherwise, by INC (a), |A(D)| = |A(D - x)| + 1 for every x in D.  At most one element is (1,0); take distinct
47: generators x, y in D.  For a generator x and a set B with 0 < |B| < 2p, |(B + x) - B| is the number of maximal x-arcs of
48: B on the cycle 0, x, 2x, ..., (2p-1)x.  As A(D) = B u (B + x) with B := A(D - x), B is ONE x-arc {u, u+x, ..., u+jx}
49: containing 0.  If 0 = u + ix with i >= 1, then -x = u + (i-1)x lies in B, i.e. -x is a nonempty subset sum of D - x,
50: and with x it gives a zero-sum: impossible.  So u = 0 and A(D) = {0, x, ..., Jx}, J := |A(D)| - 1.  Likewise
51: A(D) = {0, y, ..., Jy}.  Write y = r x.  Then the index arc I := {0, 1, ..., J} of Z_(2p) equals {0, r, 2r, ..., Jr},
52: so |I n (I + r)| >= J = |I| - 1.  For an arc of length l, 2 <= l <= 2p-2, and r' in [1, 2p-1] the residue of r,
53: |I n (I + r')| = max(0, l - r') + max(0, l - 2p + r'); if both terms are positive the sum is 2l - 2p <= l - 2,
54: otherwise it is >= l - 1 only for r' = 1 or r' = 2p-1.  So y = x (not distinct) or y = -x (zero-sum x y).  []

61: ## 3. Lemma MULT
62: 
63: Let Y' be a zero-sum-free sequence of odd elements of length L, e := 2p - 1 - L, m its largest multiplicity, attained
64: by the value g.
65:  (i)   (layers) m >= L - e = 2p - 1 - 2e.
66:  (ii)  If m >= max(2, e + 1) then g is a generator and Y' = g^m (d_1 g) ... (d_q g) with odd integers d_j >= 3 and
67:        sum_j (d_j - 1) <= e; in particular q <= e/2.
68:  (iii) If 2p >= 3e + 2 then m >= max(2, e + 1).
69: Proof.  (i) Let D_j (1 <= j <= m) be the set of values of multiplicity >= j; Y' is the disjoint union of the D_j and
70: sum_j |D_j| = L.  Put T_j := A(D_1) + ... + A(D_j) (sumset); T_m lies in A(Y').  If a + b = 0 with a in T_(j-1) and
71: b in A(D_j), the realising subsequences are disjoint and together sum to 0, so both are empty and a = b = 0.  SCHERK
72: gives |T_j| >= |T_(j-1)| + |A(D_j)| - 1, hence |A(Y')| - 1 >= sum_j (|A(D_j)| - 1), i.e.
73: extras(Y') >= sum_j extras(D_j) >= sum_j (|D_j| - 1) = L - m (Corollary SET).  With extras(Y') <= e: m >= L - e.
74: (ii) g = (1,0) would make g g a zero-sum, so m <= 1; hence g is a generator.  Put g^m first: A = {0, g, ..., mg}
75: (m+1 distinct elements, no zero-sum).  Add the other terms in any order; before each addition A = {0, g, ..., Mg} with
76: M >= m.  The next term is b = d g with d odd in [3, 2p-1].  If d + M >= 2p, then (2p - d)g, with
77: 1 <= 2p - d <= M, is a nonempty subset sum of earlier terms and with b gives a zero-sum: impossible.  So d + M <= 2p - 1
78: and A + b = {dg, ..., (d+M)g} without wrap-around.  If d >= M + 2 all M + 1 of these are new: extras >= M >= m > e,
79: impossible.  So d <= M + 1, exactly d sums (M+1)g, ..., (M+d)g are new (extras d - 1), and A becomes {0, ..., (M+d)g}.
80: Summing, sum_j (d_j - 1) <= e.
81: (iii) By (i), m >= 2p - 1 - 2e >= e + 1; for e >= 1, 2p - 1 - 2e >= e + 1 >= 2, and for e = 0, m = L = 2p - 1 >= 2.  []

94: ## 5. Lemma WT (weight bounds)

28: ## 0. Representation
29: 
30: Split every maximal cyclic reflection run of an avoider w into its maximal constant sub-blocks; consecutive sub-blocks
31: of one run are separated by EMPTY rotation runs and have different values.  o := the number of odd sub-blocks.
32: Normal form: F >= 1, since F = 0 would leave R = 4p-2 >= 3p-1 rotations and EGZ (twice) would give an identity
33: 2p-subword.  Apply PM* across every even sub-block (it allows empty runs); whenever two blocks of the same value become
34: separated by an empty run, read them as one block (its length is the sum of theirs, so it is odd exactly when exactly
35: one of them is odd) and apply PM* again if it is even; each such step lowers the number of odd blocks by 2 or leaves it
36: unchanged (e.g. A | E1 | E2 with A odd, E1, E2 even and E2 of A's value: PM* across E1 lets A and E2 fuse into one
37: odd block), so k <= o and k = o (mod 2).  The process ends with an avoider w^ of the same length and rotation multiset, given EITHER by a cyclic
38: representation with 1 <= k <= o blocks, all odd, in which every EMPTY run separates two blocks of DIFFERENT values,
39: OR (no odd block left, possibly after an equal-valued merge) by ONE EVEN block.  The even-block case is impossible:
40: accepted Proposition K1 forces F = 2p-1, which is odd (equivalently, Davenport-alpha with H = F/2 and F >= 2 gives
41: R + F/2 <= 3p-2, i.e. F/2 >= p, and 2p reflections of that block form an identity 2p-subword).  If k = 1, Proposition
42: K1 makes all rotations equal.  So let k >= 2.  As before H = (F - k)/2, kappa = p - 1 - H, R = 2p + 2kappa - k, and Lemma DAV
43: (boundary gaps are never in I; the frame is a boundary gap) gives kappa <= k - 1; GRX gives (ZP).

73: 
74: **Theorem ROT-FEW-E.**  Let p >= 5 be prime, assume Theorem SHgen and REFL(p), and let w be an avoider of length
75: 4p-2 over D_(2p) with o odd maximal constant reflection sub-blocks, 5o <= 2p + 4.  Then all rotation letters of w lie
76: in one {rho_c, rho_-c}, c != 0; and, by REFL(p), every maximal reflection run of w is constant, so w is RGR.

80: rotations lie in {rho_c, rho_-c}.  Otherwise Step 5's inequalities give (H) and (K), and Lemma SHgen-E gives w^ an
81: identity 2p-subword, contradicting PM*.  The rotation multiset of w is that of w^.  The last sentence is REFL(p)
82: applied to w (o_F(w) = o).  REFL is used only on words of length 4p-2 with all rotations in one nonzero pair and
83: with o_F = k (u°(h)) or o_F = o (w).  In Lemma SHgen-E's generality (K) would allow k up to 2p - 5 > p (p >= 7), but every

20: ## Statement
21: 
22: **Corollary OLSON-FEW.**  Let p >= 5 be prime and w a word of length 4p-1 over D_(2p).
23:  (a) If o_F(w) <= 3, or p >= 7 and o_F(w) <= 4, then w has an identity 2p-subword (conditional on REFL-few-odd only).
24:  (b) If 5 o_F(w) <= 2p + 4, then w has an identity 2p-subword (conditional on REFL-few-odd and SHgen).
25: 
26: ## Proof
27: 
28: Suppose w has no identity 2p-subword; every subword then avoids.  Let B denote the bound on o_F in (a) or (b); by
29: Corollary INV*-FEW every avoider of length 4p-2 with o_F <= B is RGR (rotations in one {rho_c, rho_-c}, c != 0, every
30: maximal cyclic reflection run constant).
31: Case 1: R <= 2.  Then F >= 4p - 3.  If R = 0 and all reflections are equal, any 2p of them multiply to
32: sigma_y^(2p) = 1.  Otherwise read w in the cyclic frame that starts at a rotation letter (R >= 1) or at a change of
33: reflection value (R = 0); no block wraps around this frame, so the blocks contain (F - o_F(w))/2 >= p disjoint equal
34: pairs sigma_y sigma_y adjacent in the framed word (o_F(w) <= B <= 2p - 3), and p of them form an identity 2p-subword
35: of the framed word.  A cyclic shift changes the product of a selection only by conjugation, so this selection is an
36: identity 2p-subword of w as well (conjugating back as in R/olson-runs-parent-verdict-v1.md L49): contradiction.
37: Case 2: some odd block has length >= 3.  Deleting one of its letters gives a word w' of length 4p-2 with
38: o_F(w') = o_F(w) - 1 (that block becomes even; nothing else changes).  w' is RGR.  w has the same rotations as w', and
39: its reflection runs differ from those of w' only by one more copy of a letter inside a constant block, so w is RGR.
40: Case 3: R >= 3 (the argument does not use that Case 2 fails; Case 3 alone covers every R >= 3, and Case 2 is the
41: shorter argument when it applies).  Delete two different rotation letters x1, x2: w_i := w - x_i has
42: o_F(w_i) <= o_F(w) (deleting a rotation never raises o_F: if its run becomes empty the two neighbouring blocks keep
43: their identity or fuse, and fusing never increases the number of odd blocks).  Both w_i are RGR.  A third rotation
44: lies in both, so their pairs {c_1, -c_1}, {c_2, -c_2} coincide and every rotation of w lies in it; deleting a rotation
45: only creates new adjacencies between reflections, so two adjacent reflections of different values in w would stay
46: adjacent in w_1.  Hence w is RGR.
47: In Cases 2 and 3, RGR-LONG(p) gives w an identity 2p-subword: contradiction.  []
