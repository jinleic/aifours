112: By induction u° is solvable; Lemma FLEXa forbids it.  []

24: ## 1. Lemma SCHERK
25: 
26: Let A, B be finite subsets of an abelian group with 0 in A n B such that a + b = 0 (a in A, b in B) only for
27: a = b = 0.  Then |A + B| >= |A| + |B| - 1.
28: Proof.  Induction on |B|; |B| = 1 is clear.  Let |B| >= 2.  Some e in A has e + B not inside A: otherwise A + b = A
29: for every b in B, so -b in A, and (-b) + b = 0 with b != 0 in B is forbidden.  Put A' := A u (e + B),
30: B' := B n (A - e).  Then 0 in A' n B' (e in A), |B'| < |B| (some b in B has e + b outside A), |A'| + |B'| = |A| + |B|
31: (|A'| = |A| + |B| - |A n (e+B)| and |B'| = |(e+B) n A|), and A' + B' lies in A + B (for b' in B', e + b' is in A, so
32: (e + b) + b' = b + (e + b')).  If x + y = 0 with x in A', y in B': for x in A, y in B gives x = y = 0; for x = e + b
33: outside A, b + (e + y) = 0 with b in B, e + y in A forces b = 0, so x = e in A, a contradiction.  By induction
34: |A + B| >= |A' + B'| >= |A'| + |B'| - 1 = |A| + |B| - 1.  []

36: ## 2. Lemma GROW
37: 
38: Let D be a zero-sum-free SET of d >= 3 distinct odd elements with |A(D)| <= 2p-2.  Then some x in D has
39: |A(D)| >= |A(D - x)| + 2.
40: Proof.  Otherwise, by INC (a), |A(D)| = |A(D - x)| + 1 for every x in D.  At most one element is (1,0); take distinct
41: generators x, y in D.  For a generator x and a set B with 0 < |B| < 2p, |(B + x) - B| is the number of maximal x-arcs of
42: B on the cycle 0, x, 2x, ..., (2p-1)x.  As A(D) = B u (B + x) with B := A(D - x), B is ONE x-arc {u, u+x, ..., u+jx}
43: containing 0.  If 0 = u + ix with i >= 1, then -x = u + (i-1)x lies in B, i.e. -x is a nonempty subset sum of D - x,
44: and with x it gives a zero-sum: impossible.  So u = 0 and A(D) = {0, x, ..., Jx}, J := |A(D)| - 1.  Likewise
45: A(D) = {0, y, ..., Jy}.  Write y = r x.  Then the index arc I := {0, 1, ..., J} of Z_(2p) equals {0, r, 2r, ..., Jr},
46: so |I n (I + r)| >= J = |I| - 1.  For an arc of length l, 2 <= l <= 2p-2, and r' in [1, 2p-1] the residue of r,
47: |I n (I + r')| = max(0, l - r') + max(0, l - 2p + r'); if both terms are positive the sum is 2l - 2p <= l - 2,
48: otherwise it is >= l - 1 only for r' = 1 or r' = 2p-1.  So y = x (not distinct) or y = -x (zero-sum x y).  []
49: Corollary SET.  A zero-sum-free set D of d odd elements has |A(D)| >= 2d, i.e. extras(D) >= d - 1.
50: Proof.  d = 1: |A| = 2.  d = 2: A = {0, x, y, x+y}, four distinct elements (x != y, x + y != 0).  d >= 3: if
51: |A(D)| >= 2p - 1, then, as D holds at most one of x, -x for each odd x and (1,0) at most once, d <= (p+1)/2 and
52: |A(D)| >= 2p - 1 >= 2d + 2; otherwise remove, by GROW, one element at a time lowering |A| by >= 2 until three remain
53: and use INC (b): |A(D)| >= 8 + 2(d-3) = 2d + 2.  []

55: ## 3. Lemma MULT
56: 
57: Let Y' be a zero-sum-free sequence of odd elements of length L, e := 2p - 1 - L, m its largest multiplicity, attained
58: by the value g.
59:  (i)   (layers) m >= L - e = 2p - 1 - 2e.
60:  (ii)  If m >= max(2, e + 1) then g is a generator and Y' = g^m (d_1 g) ... (d_q g) with odd integers d_j >= 3 and
61:        sum_j (d_j - 1) <= e; in particular q <= e/2.
62:  (iii) If 2p >= 3e + 2 then m >= max(2, e + 1).
63: Proof.  (i) Let D_j (1 <= j <= m) be the set of values of multiplicity >= j; Y' is the disjoint union of the D_j and
64: sum_j |D_j| = L.  Put T_j := A(D_1) + ... + A(D_j) (sumset); T_m lies in A(Y').  If a + b = 0 with a in T_(j-1) and
65: b in A(D_j), the realising subsequences are disjoint and together sum to 0, so both are empty and a = b = 0.  SCHERK
66: gives |T_j| >= |T_(j-1)| + |A(D_j)| - 1, hence |A(Y')| - 1 >= sum_j (|A(D_j)| - 1), i.e.
67: extras(Y') >= sum_j extras(D_j) >= sum_j (|D_j| - 1) = L - m (Corollary SET).  With extras(Y') <= e: m >= L - e.
68: (ii) g = (1,0) would make g g a zero-sum, so m <= 1; hence g is a generator.  Put g^m first: A = {0, g, ..., mg}
69: (m+1 distinct elements, no zero-sum).  Add the other terms in any order; before each addition A = {0, g, ..., Mg} with
70: M >= m and M <= 2p - 2.  The next term is b = d g with d odd in [3, 2p-1].  If d + M >= 2p, then (2p - d)g, with
71: 1 <= 2p - d <= M, is a nonempty subset sum of earlier terms and with b gives a zero-sum: impossible.  So d + M <= 2p - 1
72: and A + b = {dg, ..., (d+M)g} without wrap-around.  If d >= M + 2 all M + 1 of these are new: extras >= M >= m > e,

29: ## 2. Setting and the interval windows
30: 
31: Runs and notation as in ../proof-RUNS.md Sec. 0: rotation runs R_1, ..., R_k, reflection run S_j
32: between R_j and R_{j+1}, a_t, b_t, d_t = a_t - b_t, H = sum floor(l_j/2), o = o_F the number of odd
33: l_j, phi_t = (y_{t-1} - y_t)/2.  Lemma HW: w avoids iff phi(P) := sum_{t in P} phi_t is not in
34: I(P) = [-g_P(E-), g_P(E+)] (mod p) for every proper pattern P, where g_P(E) = min(p - m,
35: E + m + h(P) - p, floor(E/2)), m = m(P) the number of cyclic blocks of P, h(P) = H - beta(P),
36: beta(P) the number of even boundary reflection runs, E+ = sum_P a + sum_{P^c} b, E- = R - E+.
37: We only use: if phi(P) is in I(P) (mod p) for ONE proper P, then w has an identity 2p-subword.

39: **Segments.**  Let O = {j : l_j odd}, |O| = o >= p+1.  The segments G_1, ..., G_o are the maximal
40: sets of rotation runs strictly between cyclically consecutive odd reflection runs (each is a
41: nonempty cyclic interval of runs; they partition [k] in cyclic order).  For a segment G put
42: d_G = A_G - B_G.  A union Q of c consecutive segments, 1 <= c <= o-1, is a proper cyclic interval
43: of runs whose two boundary reflection runs are odd, so m(Q) = 1, beta(Q) = 0, h(Q) = H, and
44: E+(Q) = A_Q + B - B_Q = D_Q + B with D_Q := sum_{G in Q} d_G.  With H = p - 1 - kappa = p - 1 - B:
45:    U_Q := g_Q(E+) = min(p - 1, D_Q, floor((D_Q + B)/2)),
46:    L_Q := g_Q(E-) = min(p - 1, D - D_Q, floor((D - D_Q + B)/2)),       D := A - B,
47: since E+ + 1 + H - p = D_Q and E- = R - D_Q - B = (D - D_Q) + B.  (This is the observation behind
48: OlsonParity's Lemma OR; no merged word is needed below.)

50: ## 3. Lemma ZS (zero-sum interval certificate)
51: 
52: **Lemma ZS.**  Let w be any RGR word, G_1, ..., G_o its segments with o >= p+1, and fix p
53: cyclically consecutive segments W = (G_{s+1}, ..., G_{s+p}).  For 0 <= i < j <= p let
54: Q_{ij} = G_{s+i+1} u ... u G_{s+j}.  If integers tau_1, ..., tau_p satisfy
55:    tau_{i+1} + ... + tau_j  in  [-L_{Q_ij}, U_{Q_ij}]      for all 0 <= i < j <= p
56: (with U, L the windows of Q_ij in w), then w has an identity 2p-subword.
57: Proof.  Put S_0 = 0 and S_j = sum_{i=1}^{j} (phi(G_{s+i}) - tau_i) mod p, j = 0..p.  These are
58: p+1 residues mod p, so S_i = S_j for some i < j.  Then phi(Q_ij) = tau_{i+1} + ... + tau_j
59: (mod p) lies in I(Q_ij), and Q_ij is a proper pattern (it misses at least o - p >= 1 segments,
60: hence at least one run).  Lemma HW.  []

62: ## 4. Proof of Theorem KBH
63: 
64: **Step 0 (parameters).**  If A >= 2p, the subword rho_1^{2p} is an identity 2p-subword; so
65: assume A <= 2p - 1.  F = o + 2H and R = 4p - 2 - F = 2p - o + 2B, hence
66:    D = A - B = R - 2B = 2p - o,   1 <= D <= p - 1,
67: since p+1 <= o <= k and 2k <= R + F = 4p - 2 give o <= 2p - 1.  Also B = kappa <= p - 1 (H >= 0).
68: If B = 0 then R = 2p - o <= p - 1 < p + 1 <= o <= k <= R, impossible; so B >= 1.
69: Positive and negative parts: P_G := max(0, d_G) <= A_G and N_G := max(0, -d_G) <= B_G, so for any
70: set Q of segments D_Q = P_Q - N_Q, N_Q <= B, and for pairwise disjoint Q_1, ..., Q_r:
71: sum_r P_{Q_r} <= A <= 2p - 1.
72: 
73: **Step 1 (the constraints in theta-coordinates).**  Fix ANY window W (s arbitrary) and write
74: tau_i = d_{G_{s+i}} - theta_i, theta(Q_ij) := theta_{i+1} + ... + theta_j.  By Sec. 2,
75: tau(Q) in [-L_Q, U_Q] is equivalent to
76:    lo(Q) <= theta(Q) <= hi(Q),
77:    lo(Q) := D_Q - U_Q = max(0, ceil((D_Q - B)/2), D_Q - p + 1),
78:    hi(Q) := D_Q + L_Q = min(D, floor((D + D_Q + B)/2), D_Q + p - 1).
79: The function x -> lo(x) := max(0, ceil((x - B)/2), x - p + 1) is nondecreasing, satisfies
80: lo(x + c) - lo(x) <= c for c >= 0 (each of the three terms does), lo(x) = 0 for x <= B
81: (as B <= p - 1), and lo(x) <= x for x >= 0.
82: 
83: **Step 2 (greedy theta).**  For j = 1, ..., p define
84:    theta_j := max(0, max_{0 <= i < j} [ lo(Q_ij) - theta(Q_{i,j-1}) ]),   theta(Q_{j-1,j-1}) := 0.
85: By induction on j, theta(Q_ij) >= lo(Q_ij) for all 0 <= i < j <= p.
86: (2a) 0 <= theta_j <= P_{G_{s+j}}.  For i = j-1 the bracket is lo(d) with d = d_{G_{s+j}}, which is
87: 0 if d <= 0 and <= d if d > 0.  For i < j-1, by induction theta(Q_{i,j-1}) >= lo(Q_{i,j-1}), so
88: the bracket is <= lo(D_{Q_{i,j-1}} + d) - lo(D_{Q_{i,j-1}}) <= max(0, d).
89: (2b) theta(W) := theta_1 + ... + theta_p <= D.  Let J = {j : theta_j > 0}; if J is empty we are
90: done.  Otherwise let j_1 = max J and i_1 a maximiser in the definition of theta_{j_1}; then
91: theta(Q_{i_1 j_1}) = lo(Q_{i_1 j_1}) ("tight").  Recursively let j_{r+1} = max(J n [1, i_r]) and
92: i_{r+1} a maximiser for it, as long as J n [1, i_r] is nonempty.  The intervals
93: Q_r := Q_{i_r j_r} are pairwise disjoint, every element of J lies in one of them, so
94: theta(W) = sum_r theta(Q_r) = sum_r lo(Q_r), and lo(Q_r) >= theta_{j_r} > 0 forces
95: D_{Q_r} >= B + 1 (lo(x) > 0 needs x > B or x >= p > B).
96:  * One interval: D_Q <= P_Q <= A = D + B, so ceil((D_Q - B)/2) <= ceil(D/2) <= D and
97:    D_Q - p + 1 <= D + B - p + 1 <= D; hence lo(Q_1) <= D.
98:  * r >= 2 intervals: sum_r D_{Q_r} <= sum_r P_{Q_r} <= A <= 2p - 1 and every D_{Q_r} >= B + 1, so
99:    every D_{Q_r} <= 2p - 2 - B, and then D_{Q_r} - p + 1 <= (D_{Q_r} - B)/2; thus
100:    lo(Q_r) = ceil((D_{Q_r} - B)/2) <= (D_{Q_r} - B + 1)/2 and
101:    sum_r lo(Q_r) <= (A - r(B - 1))/2 <= (A - 2(B - 1))/2 = (D - B + 2)/2 <= D
102:    (B >= 1 and D + B >= 2).
103: (2c) Upper bounds.  For every subinterval Q of W: theta(Q) <= min(D, P_Q) by (2a), (2b) and
104: theta >= 0.  Hence theta(Q) <= D; 2 theta(Q) <= D + P_Q <= D + P_Q + (B - N_Q) = D + D_Q + B; and
105: theta(Q) <= P_Q <= P_Q - N_Q + p - 1 = D_Q + p - 1 (N_Q <= B <= p - 1).  So theta(Q) <= hi(Q).
106: 
107: **Step 3.**  By Steps 1-2, tau_i := d_{G_{s+i}} - theta_i satisfies the hypothesis of Lemma ZS
108: for the window W, so w has an identity 2p-subword.  []
