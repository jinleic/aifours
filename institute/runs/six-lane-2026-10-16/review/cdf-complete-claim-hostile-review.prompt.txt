  - It follows that translates are pairwise distinct, since two equal translates would share a pair. That gives v(v−1)/20 blocks covering v(v−1)/2 pairs, each exactly once.
- **Stabilisers.** If B+t = B, then B is a union of ⟨t⟩-cosets. So |⟨t⟩| divides both 5 and v, and gcd(5, v) = 1 forces t = 0.

import Mathlib.Data.Fintype.Prod

/-!
# Cyclic `(v, 5, 1)` difference families: the target statement

This module imports no certificate data and fixes the meaning of the kernel-checked roots.

* Residues modulo `v` are the elements of `Fin v`.  For `a b : Fin v`, `a - b` is the core
  `Fin.sub`, i.e. subtraction modulo `v`: its value is `(v - b + a) % v`
  (`CdfKernel.Facts` proves `a - b = d ↔ d ≡ a - b [ZMOD v]`).
* A family of `n` base blocks is a map `B : Fin n → Fin 5 → Fin v`; base block `i` lists the
  five residues `B i 0, ..., B i 4`.
* `Cdf.diffs B` is the multiset of ordered differences `B i j - B i k` over every base block `i`
  and every ordered pair `(j, k)` of distinct positions.  When the five residues of each block
  are distinct, these are exactly the ordered differences `a - b` of distinct elements `a, b` of
  each block, each block contributing `5 * 4 = 20` of them.
* `Cdf.IsCDF B`: each base block consists of five distinct residues, and `Cdf.diffs B` contains
  every nonzero residue exactly once and the residue `0` never.
* `Cdf.Target v`: a cyclic `(v, 5, 1)` difference family exists (with some number of blocks).
-/

namespace Cdf

/-- The multiset of ordered differences `B i j - B i k` (subtraction in `Fin v`, i.e. modulo
`v`) over all base blocks `i` and all ordered pairs `(j, k)` of distinct positions `j ≠ k`. -/
def diffs {v n : ℕ} (B : Fin n → Fin 5 → Fin v) : Multiset (Fin v) :=
  ((Finset.univ : Finset (Fin n × Fin 5 × Fin 5)).filter fun t => t.2.1 ≠ t.2.2).val.map
    fun t => B t.1 t.2.1 - B t.1 t.2.2

/-- `B` is a cyclic `(v, 5, 1)` difference family: every base block consists of five distinct
residues modulo `v`, every nonzero residue occurs exactly once in the multiset of ordered
differences, and the residue `0` never occurs in it. -/
def IsCDF {v n : ℕ} (B : Fin n → Fin 5 → Fin v) : Prop :=
  (∀ i : Fin n, Function.Injective (B i)) ∧
    (∀ d : Fin v, d.val ≠ 0 → (diffs B).count d = 1) ∧
    (∀ d : Fin v, d.val = 0 → (diffs B).count d = 0)

/-- A cyclic `(v, 5, 1)` difference family exists. -/
def Target (v : ℕ) : Prop :=
  ∃ n : ℕ, ∃ B : Fin n → Fin 5 → Fin v, IsCDF B

end Cdf

/-!
# A generic kernel-checkable certificate for cyclic `(v, 5, 1)` difference families

Raw certificate data is a list of raw blocks, each a list of natural numbers.  `blockOf v hv n d`
is the family of `n` base blocks whose entry `j` of block `i` is the residue of `rawAt d i j`
modulo `v`.

The Boolean side uses only `Nat` arithmetic, list recursion and bitwise `|||` on `Nat`, which
the Lean kernel evaluates on literals (with GMP).  `coverMask v n d` sets bit `x` for every
ordered difference `x` of the first `n` raw blocks (computed as `Fin.sub` computes it), and
`fullMask v` is the mask of bits `1, ..., v - 1`.

`isCDF_of_check` is the data-independent soundness theorem: from

* `20 * n + 1 = v` (a numeral identity), and
* `coverMask v n d = fullMask v` (one kernel evaluation),

it concludes the target property `Cdf.IsCDF (blockOf v hv n d)`.  The mask equality says that
the set of ordered differences is exactly the set of nonzero residues; that each nonzero residue
is hit only once then follows by counting (`20 * n` ordered differences, `v - 1` nonzero
residues), and distinctness of block entries follows from `0` never being a difference.
-/

namespace Cdf.Kernel

/-! ## Raw data and the semantic blocks it names -/

/-- Raw entry `j` of raw block `i` (`0` outside the data). -/
def rawAt (d : List (List ℕ)) (i j : ℕ) : ℕ := (d.getD i []).getD j 0

/-- The family of `n` base blocks named by raw data `d`: entry `j` of block `i` is the residue
of `rawAt d i j` modulo `v`. -/
def blockOf (v : ℕ) (hv : 0 < v) (n : ℕ) (d : List (List ℕ)) (i : Fin n) (j : Fin 5) : Fin v :=
  ⟨rawAt d i j % v, Nat.mod_lt _ hv⟩

/-! ## The Boolean checker -/

/-- The 20 ordered pairs `(j, k)` of distinct positions `j, k < 5`. -/
def posPairs : List (ℕ × ℕ) :=
  [(0, 1), (0, 2), (0, 3), (0, 4), (1, 0), (1, 2), (1, 3), (1, 4), (2, 0), (2, 1),
   (2, 3), (2, 4), (3, 0), (3, 1), (3, 2), (3, 4), (4, 0), (4, 1), (4, 2), (4, 3)]

/-- The value of `a - b` in `Fin v` for `a, b < v`, written exactly as `Fin.sub` computes it. -/
def dnat (v a b : ℕ) : ℕ := (v - b + a) % v

/-- The ordered differences of the first `n` raw blocks, block by block. -/
def diffList (v n : ℕ) (d : List (List ℕ)) : List ℕ :=
  (List.range n).flatMap fun i =>
    posPairs.map fun p => dnat v (rawAt d i p.1 % v) (rawAt d i p.2 % v)

/-- Bitwise union of a list of naturals. -/
def orAll (l : List ℕ) : ℕ := l.foldl (· ||| ·) 0

/-- Bit `x` for every ordered difference `x` of the first `n` raw blocks. -/
def coverMask (v n : ℕ) (d : List (List ℕ)) : ℕ := orAll ((diffList v n d).map (2 ^ ·))

/-- Bits `1, ..., v - 1`: one bit per nonzero residue modulo `v`. -/
def fullMask (v : ℕ) : ℕ := orAll (((List.range v).filter (· != 0)).map (2 ^ ·))

  induction l generalizing a with
  | nil => simp
  | cons m l ih =>
    rw [List.foldl_cons, ih, Nat.testBit_or, Bool.or_eq_true]
    simp only [List.mem_cons, exists_eq_or_imp]

  have hd : (d : ℕ) < v := d.isLt

    Int.emod_eq_of_lt (Int.natCast_nonneg _) (by exact_mod_cast hd)]
  have key : (((a : ℕ) : ℤ) - ((b : ℕ) : ℤ)) % (v : ℤ) = (((v - b + a) % v : ℕ) : ℤ) := by
    rw [Int.natCast_emod, Nat.cast_add, Nat.cast_sub hb.le,

  · intro h

  · intro h

# Semantic bridge for the CDF kernel roots

Each item below is marked **[kernel]** if a Lean theorem in this directory proves it, or **[written]** if it is an argument in this note that no kernel has checked.

## 1. The formal target

`CdfKernel/Target.lean` imports only `Mathlib.Data.Fintype.Prod` and no certificate data. **[kernel]**

- Residues mod v are the elements of `Fin v`. `a - b` is core `Fin.sub`, whose value is `(v - b + a) % v`. The audit's `pp.explicit` print shows that the instance is `Fin.instSub`.
- `Cdf.diffs B` is the multiset of `B i j - B i k` over all `(i, j, k) : Fin n × Fin 5 × Fin 5` with `j ≠ k`.
- `Cdf.IsCDF B` is the conjunction of three conditions:
  - every `B i` is injective;
  - `count d (diffs B) = 1` whenever `d.val ≠ 0`;
  - `count d (diffs B) = 0` whenever `d.val = 0`.
- `Cdf.Target v` is `∃ n, ∃ B : Fin n → Fin 5 → Fin v, Cdf.IsCDF B`.

The roots are `Cdf.Kernel.exists_cdf{v} : ∃ B : Fin n → Fin 5 → Fin v, Cdf.IsCDF B` for (v, n) = (321, 16), (501, 25), (621, 31), (681, 34), (801, 40) and (901, 45). The audits `Cdf.Audit.target{v} : Cdf.Target v` derive the target statement from them. **[kernel]**

Sanity facts proved from the definition alone in `CdfKernel/Facts.lean` **[kernel]**:

- `Cdf.sub_eq_iff_modEq`: `a - b = d ↔ d ≡ a - b [ZMOD v]`, with integer casts of the values. So `Fin v` with `-` is ℤ/vℤ.
- `Cdf.IsCDF.existsUnique`: every nonzero residue equals `B i j - B i k` for exactly one triple `(i, j, k)` with `j ≠ k`.
- `Cdf.IsCDF.card_eq`: `20 * n = v - 1`, so the number of blocks is forced to be (v − 1)/20.

## 2. Identification with the literature notion **[written]**

A cyclic (v, k, 1) difference family is a collection {B_1, …, B_t} of k-subsets of ℤ_v such that every nonzero element of ℤ_v occurs exactly once among the differences x − y (x, y ∈ B_i, x ≠ y, 1 ≤ i ≤ t). This is the standard definition used by Abel–Costa–Finizio (2004) and in the later status papers.

- **ℤ_v.** `Fin v` with `Fin.sub` is ℤ_v, by the kernel lemma above.
- **k-subsets.** A k-subset is the same as an injective 5-tuple listing it. Choosing an order does not change the multiset of differences, because the index set contains every ordered pair of distinct positions.
- **Ordered pairs.** For an injective tuple, ordered pairs of distinct positions correspond bijectively to ordered pairs of distinct elements. Hence `diffs B` is exactly the literature's list of differences, counted with multiplicity.
- **"Exactly once".** This is `count = 1` for each nonzero residue. The residue 0 never occurs. That already follows from injectivity, and the definition also states it explicitly.

## 3. CDF ⇒ strictly cyclic S(2, 5, v)

The development has blocks `devBlock B (i, s) = {B i j + s}`.

`Cdf.IsCDF.steiner : IsCDF B → IsStrictlyCyclicSteiner B` proves four properties **[kernel]**:

1. every block has 5 points;
2. any two distinct points lie in the blocks of exactly one index (i, s);
3. the indexing is injective, so there are n·v distinct blocks;
4. translation by t maps block (i, s) to block (i, s + t).

Properties 1–3 give an S(2, 5, v) on ℤ_v. Property 4 with t = 1 makes x ↦ x + 1 an automorphism of order v. By property 3, each of the n block orbits {(i, s + t)} has full length v, which is the meaning of "strictly cyclic". **[written]**

Only the direction CDF ⇒ design is formalized. Existence needs nothing more.

## 4. CDF ⇒ perfect (v, 5, 1) optical orthogonal code

`Cdf.IsCDF.ooc : IsCDF B → IsPerfectOOC B` proves three properties **[kernel]**:

1. each codeword `devBlock B (i, 0) = {B i 0, …, B i 4}` has weight 5;
2. `|C_i ∩ (C_{i'} + τ)| ≤ 1` for every (i, i', τ) except i = i' with τ = 0;
3. `20 * n = v − 1`.

For 0/1 sequences of length v, the periodic correlation at shift τ is |C_i ∩ (C_{i'} + τ)|. The theorem quantifies over all τ, so the sign convention of the shift does not matter. "Perfect" means the Johnson bound ⌊(v − 1)/(k(k − 1))⌋ = (v − 1)/20 is attained. Baicheva–Topalova (*Axioms* 15(1):35, 2026, p.2, per the parent's excerpt `cdf-latest-primary-excerpt.txt`) call these perfect (v, k, 1) CPCW codes, and state that they are equivalent both to strictly cyclic 2-(v, k, 1) designs and to cyclic (v, k, 1) difference families. **[written]**

`CdfKernel/Bridge.lean` applies `Cdf.bridge_of_target` to the six audited roots: `Cdf.Bridge.bridge{v} : ∃ n B, IsCDF B ∧ IsStrictlyCyclicSteiner B ∧ IsPerfectOOC B`. **[kernel]**

## 5. Not covered by the kernel

- **Reading the target.** Whether `Target.lean`, `Facts.lean`, `IsStrictlyCyclicSteiner` and `IsPerfectOOC` match the literature definitions rests on sections 2–4 of this note.
- **Raw-to-literal binding.** `gen_lean.py` regenerates the literals byte-identically, and an independent regex reader in `replay.py` compares them with the raw files. Both run in Python, not in Lean.
- **Kernel independence.** `lean` and `leanchecker --fresh` belong to one Lean 4.34.1 toolchain. This is not Comparator and not a second, independent kernel. `decide +kernel` relies on the kernel's GMP-accelerated `Nat` literal arithmetic, which is part of that trusted kernel.
- **Priority, open status and significance.** These are separate parent audits (`cdf-k5-parent-verdict.md`, `cdf-k5-priority-audit.md`) and are unaffected by this work.

# Cyclic (v,5,1) difference families: priority audit (read-only scout, 2026-10-16 PT)

Preserved verbatim. A search miss is not novelty.

I found no earlier construction or announced construction of a cyclic (v,5,1) difference family for any of v ∈ {321, 501, 621, 681, 801, 901}, and no nonexistence proof for any of them. The search was bounded and several sources were unreachable, so this is not a proof of novelty.

The latest primary sources still list all six as possible exceptions. The newest is Baicheva–Topalova, *Axioms*, 1 January 2026; two later papers by the same group (May and September 2026) neither restate nor touch these orders. For 501 there is one earlier claim. The 1996 CRC Handbook listed 501, 681 and 801 as known, and Abel–Costa–Finizio (2004) later said that listing was incorrect. Abel wrote both.

I edited no files and ran no solvers or model CLIs.

### Per-v status
The three names are the same object here. Since 5 ∤ v, every cyclic S(2,5,v) is strictly cyclic, and a perfect (v,5,1) OOC is the same thing as a cyclic difference family.

- **Known weight-5 OOC families can't reach these lengths.** This is my own arithmetic from the families listed in *Axioms* 15(1):35 §1.2 and arXiv:1911.07189v2 Thm 7.1.
