Write an independent Python3 STANDARD-LIBRARY verifier for an mcDSQS(v) certificate, from ONLY the definitions and format below. Do not use tools. Return exactly one fenced Python code block and nothing else. No asserts (checks must survive python -O), no writes, network or subprocess. Read the input bytes exactly once; verify the expected SHA-256 before parsing. CLI: checker.py EXPECTED_V FILE EXPECTED_SHA256. Print one JSON object; exit 0 iff valid; on invalid input print a precise invariant-specific reason and exit 1.
Definitions (Tan–Zhou 2025). A Steiner quadruple system SQS(v) is a set of 4-subsets (blocks) of V={0..v-1} such that every 3-subset of V lies in exactly one block. For x in V the derived design at x is {B\{x} : x in B in blocks}, a Steiner triple system on V\{x} with D=(v-1)(v-2)/6 triples. A partial parallel class (PPC) is a set of pairwise disjoint triples. An r-colouring of a triple system is a partition of its triples into r colour classes, each a PPC. An mcDSQS(v) is an SQS(v) whose derived design at EVERY point admits an r-colouring with r equal to the minimum chromatic index over all STS(v-1). This verifier must establish minimality itself: every PPC on v-1 points has at most M=floor((v-1)/3) triples, so every STS(v-1) needs at least L=ceil(D/M) colours; the certificate is valid only if r = L and every derived design is explicitly r-coloured.
Format (text, LF line endings, final LF; lines starting with '#' are comments anywhere and may contain any UTF-8; all other lines ASCII): first data line 'MCDSQS v'; next 'COLOURS r'; next 'BLOCKS'; then exactly v(v-1)(v-2)/24 lines of 4 distinct canonical decimal points separated by single spaces; then for x=0..v-1 in order: a line 'POINT x', and for j=0..r-1 in order a line 'CLASS j' followed by one or more lines of 3 distinct canonical decimal points (a class ends at the next CLASS or POINT line or end of file). No other lines; reject trailing whitespace, blank data lines, CR, leading zeros, empty classes.
Check everything directly: block count, distinct blocks, every 3-subset covered exactly once (compare with the full set of C(v,3) triples), r = L as defined above, every class triple is a derived triple at x and excludes x, triples within a class pairwise disjoint, each derived triple appears in exactly one class at x, and all v points are coloured. Report counts (blocks, triples covered, points coloured, r, L, and the multiset of class sizes per point).
