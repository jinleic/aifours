40: ## 1. Lemma S1 (d)
41: 
42: **Lemma S1 (d).**  Let p >= 11 be prime and kappa = (p + 3)/2, so that 2kappa = p + 3.  Let Y be a sequence of odd
43: elements of Z_(2p) with
44:   (ZP) no zero-sum subsequence of length in [2kappa + 2, 2p] = [p + 5, 2p].
45: Then (S1) holds: every zero-sum subsequence of Y has length <= p + 3.
46: 
47: Proof.  Suppose not.  Let T be a zero-sum subsequence of Y with |T| >= p + 5 and |T| least, and N := |T|.
48: 
49: (1) Lengths.
50: - N is even and not in [p + 5, 2p], so N >= 2p + 2.
51: - By (D), T minus one term (length >= 2p + 1) contains a nonempty zero-sum.  So T has a nonempty proper zero-sum
52:   subsequence.
53: - Let T' be any nonempty proper zero-sum subsequence.  T' and T - T' are nonempty zero-sums shorter than T, so by
54:   minimality neither has length >= p + 5.  Being even, both have length <= p + 3.
55: - Hence N <= 2p + 6, and every nonempty proper zero-sum subsequence of T has length in [N - p - 3, p + 3].
56: 
57: (2) Half-sums.  EGZ applied to any 2p - 1 terms of T gives a half-sum T_1 <= T with |T_1| = p.  Put M := T - T_1.
58: Then |M| = N - p >= p + 2, x(M) = 0, and |M| is odd.
59: - Claim A.  Let V <= M with 1 <= |V| <= p and x(V) = 0.  Then either |V| is even and |V| >= N - p - 3, or |V| is odd
60:   and |V| <= 3.
61:   - If |V| is even, V is a nonempty proper zero-sum (|V| <= p < N), and (1) applies.
62:   - If |V| is odd, T_1 V is a zero-sum of length p + |V| <= 2p < N, nonempty and proper.  So p + |V| <= p + 3.
63: - Claim B.  M contains no two disjoint subsequences V_1, V_2 of odd length <= 3 with x(V_i) = 0.
64:   - Otherwise V_1 V_2 is a nonempty proper zero-sum of length <= 6.
65:   - But by (1) its length would be >= N - p - 3 >= p - 1 >= 10.
66: 
67: (3) N = 2p + 2.
68: - Suppose N >= 2p + 4.  Then an even V as in Claim A would need |V| >= p + 1 > p, so every V there is odd with
69:   |V| <= 3.
70: - Davenport (on p terms of M; |M| >= p + 4) gives such a V_1.
71: - M - V_1 has >= p + 1 terms, so Davenport gives a second one, V_2, disjoint from V_1, contrary to Claim B.
72: - Hence N = 2p + 2 and |M| = p + 2.  Every nonempty proper zero-sum subsequence of T has length p - 1, p + 1 or p + 3.
73: 
74: (4) T has no term equal to (1, 0).  Suppose u = (1, 0) is a term.
75: - Take T_1 by EGZ among the 2p + 1 other terms.  Then u lies in M.  M - {u} has p + 1 terms, so Davenport gives
76:   V <= M - {u} with x(V) = 0 and 1 <= |V| <= p.
77: - If |V| is odd, then {u} and V are disjoint, both of odd length <= 3 with x-sum 0 (Claim A), contrary to Claim B.
78: - If |V| is even, then |V| = p - 1 (Claim A).  The two remaining terms of M - {u} - V have x-sum 0, so they form a
79:   zero-sum of length 2 < p - 1, contrary to (3).
80: 
81: (5) M = C V, where |C| = 3, x(C) = 0, and V is a zero-sum of length p - 1 with no nonempty proper subsequence of x-sum 0.
82: - Davenport gives V_0 <= M with x(V_0) = 0 and 1 <= |V_0| <= p.
83:   - If |V_0| is odd, then |V_0| <= 3 (Claim A), and |V_0| != 1 by (4), since a single term of x-sum 0 is (1, 0).  So
84:     |V_0| = 3; put C := V_0.
85:   - If |V_0| is even, then |V_0| = p - 1 (Claim A); put C := M - V_0.
86: - Put V := M - C.  Then |V| = p - 1 is even and x(V) = 0, so V is a zero-sum.
87: - Suppose V had a nonempty proper subsequence V'' with x(V'') = 0.
88:   - If |V''| is even, V'' is a zero-sum of length < p - 1, contrary to (3).
89:   - If |V''| is odd, V'' and V - V'' are disjoint subsequences of M of odd length <= p with x-sum 0.  By Claim A both
90:     have length <= 3, so |V| <= 6 < p - 1: a contradiction.
91: - So the x-values of V form a minimal zero-sum sequence over Z_p of length p - 1.
92: 
93: (6) Index 1.  By the Savchev-Chen / Yuan theorem (C_p, length p - 1 >= floor(p/2) + 2), there are h in Z_p \ {0} and
94: positive integers x_1, ..., x_(p-1) such that the x-values of V are x_1 h, ..., x_(p-1) h and x_1 + ... + x_(p-1) = p.
95: - p - 1 positive integers with sum p consist of one 2 and p - 2 ones.
96: - Put h^ := (1, h), and let y be the term of V with x-value 2h.  Then V = h^^(p-2) y.
97: - So t, the multiplicity of h^ in T, satisfies t >= p - 2.
98:

100: By (4), c != 0, and c != 1 since z != h^.
101: - c even.  Put beta := p - c.  It is odd with 1 <= beta <= p - 2 <= t.
102:   - The subsequence h^^beta z has x-sum (beta + c) h = 0 and even length beta + 1 <= p - 1 < N, so it is a nonempty
103:     proper zero-sum.
104:   - By (3), beta + 1 = p - 1, so c = 2.
105: - c odd, c >= 3.  Put j := p - 2 - c.  Then 0 <= j <= p - 5 <= t, and z != y (different x-values).
106:   - The subsequence h^^j y z has x-sum (j + 2 + c) h = 0.
107:   - Its length is j + 2 = p - c, which is even (p and c are odd) and <= p - 3.
108:   - So it is a nonempty proper zero-sum shorter than p - 1, contrary to (3).
109: - Hence T consists of t copies of h^ and u copies of y = (1, 2h), with t + u = 2p + 2.

112: - x(T) = (t + 2u) h = 0, so t + 2u = 0 (mod p).  With t = 2p + 2 - u this gives u + 2 = 0 (mod p), so u is p - 2 or
113:   2p - 2.
114: - u = 2p - 2 would give t = 4 < p - 2.  So u = p - 2 and t = p + 4.
115: - Then h^^(p-6) y^3 (p - 6 <= t, 3 <= u) has x-sum (p - 6 + 6) h = 0 and even length p - 3 < p - 1.  It is a nonempty
116:   proper zero-sum, contrary to (3).  []

222:   with |b| <= p - 2, it is the SHgen weight b_x of rho_x relative to c (proof-SHgen-v3.md L39-41).  x = 0 would need
223:   b = p (b_0 := p), which is excluded.  So the lights are the rotations with b = +-1, and E and N are those of Lemma
224:   ZX, with E + N <= k - 1.

27: **Lemma S1 (c).**  Let p >= 5 be prime, kappa = (p + 1)/2, and let Y be a sequence of odd elements of Z_(2p) with
28:   (ZP) no zero-sum subsequence of length in [2kappa + 2, 2p] = [p + 3, 2p].

31: Proof.  Suppose not.  Let T be a zero-sum subsequence of Y with |T| >= p + 3, of least possible length, and N := |T|.
32: (i) N = 2p + 2, and every nonempty proper zero-sum subsequence T' of T has |T'| = p + 1.
33: - N is even and not in [p + 3, 2p] by (ZP), so N >= 2p + 2.
34: - T minus one term has length N - 1 >= 2p + 1, so by (D) it contains a nonempty zero-sum.  Hence T has a nonempty
35:   proper zero-sum subsequence.
36: - Let T' be any nonempty proper zero-sum subsequence.  Then T' and T - T' are nonempty zero-sums shorter than T.  By
37:   the minimality of N, each has length <= p + 1.  So N <= 2p + 2, hence N = 2p + 2, and |T'| = N - |T - T'| >= p + 1,
38:   hence |T'| = p + 1.

40: s(T_1) = (1, 0).  Put M := T - T_1.  Then |M| = p + 2 and s(M) = -(1, 0) = (1, 0).
41: (iii) Let V <= M be nonempty with x-sum 0 and |V| <= p.  Then V is a single term equal to (1, 0).
42: - If |V| is even, V is a nonempty zero-sum.  It is proper, since |V| <= p < N, so |V| = p + 1 by (i).  But
43:   |V| <= p, a contradiction.

45:   nonempty, and proper because p + |V| <= 2p < N.  By (i), p + |V| = p + 1.  So V is one term with x = 0, i.e. (1, 0).

22: **Corollary OLSON-FEW.**  Let p >= 5 be prime and w a word of length 4p-1 over D_(2p).
23:  (a) If o_F(w) <= 3, or p >= 7 and o_F(w) <= 4, then w has an identity 2p-subword (conditional on REFL-few-odd only).
24:  (b) If 5 o_F(w) <= 2p + 4, then w has an identity 2p-subword (conditional on REFL-few-odd and SHgen).

26: ## Proof
27: 
28: Suppose w has no identity 2p-subword; every subword then avoids.  Let B denote the bound on o_F in (a) or (b); by
29: Corollary INV*-FEW every avoider of length 4p-2 with o_F <= B is RGR (rotations in one {rho_c, rho_-c}, c != 0, every
30: maximal cyclic reflection run constant).
31: Case 1: R <= 2.  Then F >= 4p - 3.  If R = 0 and all reflections are equal, any 2p of them multiply to
32: sigma_y^(2p) = 1.  Otherwise read w in the cyclic frame that starts at a rotation letter (R >= 1) or at a change of
33: reflection value (R = 0); no block wraps around this frame, so the blocks contain (F - o_F(w))/2 >= p disjoint equal
34: pairs sigma_y sigma_y adjacent in the framed word (o_F(w) <= B <= 2p - 3), and p of them form an identity 2p-subword
35: of the framed word.  A cyclic shift changes the product of a selection only by conjugation, so this selection is an
36: identity 2p-subword of w as well (conjugating back as in R/olson-runs-parent-verdict-v1.md L49): contradiction.
37: Case 2: some odd block has length >= 3.  Deleting one of its letters gives a word w' of length 4p-2 with
38: o_F(w') = o_F(w) - 1 (that block becomes even; nothing else changes).  w' is RGR.  w has the same rotations as w', and
39: its reflection runs differ from those of w' only by one more copy of a letter inside a constant block, so w is RGR.
40: Case 3: R >= 3 (the argument does not use that Case 2 fails; Case 3 alone covers every R >= 3, and Case 2 is the
41: shorter argument when it applies).  Delete two different rotation letters x1, x2: w_i := w - x_i has
42: o_F(w_i) <= o_F(w) (deleting a rotation never raises o_F: if its run becomes empty the two neighbouring blocks keep
43: their identity or fuse, and fusing never increases the number of odd blocks).  Both w_i are RGR.  A third rotation
44: lies in both, so their pairs {c_1, -c_1}, {c_2, -c_2} coincide and every rotation of w lies in it; deleting a rotation
45: only creates new adjacencies between reflections, so two adjacent reflections of different values in w would stay
46: adjacent in w_1.  Hence w is RGR.
