35:   g(p,q) = 1. When p and q are collinear, G1 then forbids the count 1.

38:   Hence:
39:   - every r ∈ ℓ1∖ℓ2 has a neighbour on ℓ2∖ℓ1;

1: #!/usr/bin/env python3
2: """gram_enc.py: frame-free Gram-support CNF for sets of mutually orthogonal QLS(7). Lane moqls7-maximum.
3: 
4: Unknowns: for each quantum square a and each pair of cells p != q, g[a,p,q] <=> <psi_a,p, psi_a,q> != 0.
5: Lines: rows and columns (ONB lines of every square) plus, with --net-L, the symbol lines of a FIXED classical square L
6: (ONB lines of every quantum square by (C1)). Necessary conditions (review/GRAM-ENCODING.md):
7:   G1 collinear cells are orthogonal: g = 0 on every line;
8:   G2 frame consistency: for every line l and cells p, q off l, expanding in the ONB of l gives
9:      G_pq = sum_{r in l} conj(G_rp) G_rq, so #{r in l : g(p,r) and g(q,r)} = 0 forces g(p,q) = 0 and = 1 forces
10:      g(p,q) = 1;
11:   G3 the transition matrix between two lines is unitary: every point of one line off the other has a neighbour on it;
12:      a point with exactly one neighbour q on the other line is q's only neighbour on its own line;
13:   G5 product-vector orthogonality of squares a != b is exactly g_a(p,q) g_b(p,q) = 0 for all p != q;
14:      orthogonality to the classical L is exactly G1 on the L lines;
15:   G4 (--heavy) minimal-counterexample reduction (review/K1-THEOREM.r1.md section 8 plus Lemma 10 in an arbitrary
16:      basis): every quantum square has, for every one of its ONB lines l, a point with >= 3 neighbours on l.
17: Symmetry (--sym, K3 only): square 1 is heavy in the frame of row 0 at cell (1,0) with neighbours (0,1),(0,2),(0,3)
18: (row and column permutations preserve all conditions).

22: import itertools
23: import json
24: 
25: P = 7
26: CELLS = [(i, j) for i in range(P) for j in range(P)]
27: 
28: 
29: class CNF:
30:     def __init__(self):
31:         self.nv = 0
32:         self.cl = []
33: 
34:     def new(self):
35:         self.nv += 1
36:         return self.nv
37: 
38:     def add(self, c):
39:         self.cl.append(list(c))
40: 
41:     def text(self):
42:         return "p cnf %d %d\n" % (self.nv, len(self.cl)) + "".join(" ".join(map(str, c)) + " 0\n" for c in self.cl)
43:

45: def at_least(F, lits, t, guard=None):
46:     n = len(lits)
47:     if t > n:
48:         F.add([-guard] if guard else [])
49:         return
50:     for sub in itertools.combinations(lits, n - t + 1):
51:         F.add(([-guard] if guard else []) + list(sub))
52: 
53: 
54: def build(nsq=3, L=None, heavy=False, sym=False, fix=None):
55:     lines = [[(i, j) for j in range(P)] for i in range(P)] + [[(i, j) for i in range(P)] for j in range(P)]
56:     if L is not None:
57:         lines += [[c for c in CELLS if L[c[0]][c[1]] == s] for s in range(P)]
58:     collinear = set()
59:     for l in lines:
60:         for p, q in itertools.combinations(l, 2):
61:             collinear.add((p, q))
62:             collinear.add((q, p))
63:     F = CNF()
64:     squares = list(range(1, nsq + 1))
65:     g = {}
66:     for a in squares:
67:         for p, q in itertools.combinations(CELLS, 2):
68:             if (p, q) not in collinear:
69:                 v = F.new()
70:                 g[(a, p, q)] = v
71:                 g[(a, q, p)] = v
72:     def G(a, p, q):
73:         return g.get((a, p, q))          # None means constant false (collinear)
74:     h = {}

83: 2     Preliminaries
84: 2.1    Latin squares
85: A Latin square of order n is an n × n matrix containing elements of a set of size n such that each row and
86: each column contains every element exactly once. Two Latin squares A = (aij )1≤i,j≤n and B = (bij )1≤i,j≤n
87: are orthogonal if all n2 tuples (aij , bij ) are different. A set of t mutually orthogonal Latin squares of order
88: n, abbreviated t MOLS(n), is a set of t Latin squares of order n that are pairwise orthogonal.
89: 
90: 2.2    Quantum Latin squares
91: A quantum Latin square of order n is an n × n matrix over Cn such that each row and each column forms
92: an orthonormal basis of Cn . Two quantum Latin squares are isotopic if they can be obtained from one
93: another by
94:  (i) multiplying each entry by a phase factor,
95:  (ii) permuting rows and columns, and
96: (iii) applying a unitary transformation on all entries.
97: A quantum Latin square is classical or not genuinely quantum if, up to isotopy, all entries are contained
98: in {|1⟩ , . . . , |n⟩}, a fixed orthonormal basis. This property is independent of the chosen basis by item (iii)
99: in the definition of isotopy.
100: 
101: 2.3    Mutually orthogonal quantum Latin squares (MOQLS)
102: Two quantum Latin squares (ψij )1≤i,j≤n and (ϕij )1≤i,j≤n are orthogonal if

106: denoted t MOQLS(n), is a set of t quantum Latin squares of order n such that any two of them are
107: orthogonal. Two sets of t MOQLS(n) are isotopic if they can be obtained from one another by

118: 2.4    Patterns of quantum Latin squares
119: The pattern of a matrix is the binary matrix that is obtained from it by replacing each nonzero entry by
120: a one. A unitary pattern is a pattern of a unitary matrix. Similarly, the pattern of a vector is the vector
121: obtained from it by replacing each nonzero entry by a one. The support of a vector is the set of coordinates
122: where it is nonzero. The weight of a vector is the size of its support, that is, the number of ones in its
123: pattern. The pattern of a quantum Latin square is the matrix that is obtained from it by replacing each
124: entry by its pattern. For example:
