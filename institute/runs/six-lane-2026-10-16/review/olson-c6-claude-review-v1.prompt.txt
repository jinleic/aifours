217: ## 6. Proposition AB: anti-heavy intervals are exactly what breaks (H) in the T1 classes

219: **Proposition AB.**  Let w be any all-single-letter word (any prime p, kB >= 1, B, positions).  If some interval Q (one cyclic block of
220: consecutive runs) has D_Q <= -4 when kB is odd, or D_Q <= -5 when kB is even, then Q is not certified by plain singleton extension
221: (Lemma L, singleton ranges [lambda({t}), U({t})]); in particular w fails (H).
222: Proof.  |Q| >= 4 and Q != [k] (D = p + kB - B > 0).  A certification of Q ends with a step Q = Q' u {t}, t in Q, Q' certified; its
223: condition (B) reads lambda(Q) + lambda(Q'^c) + lambda({t}^c) >= p + 1.  Put f := -D_Q >= 1, N := p + kB, d := d_t.  Taking one term of
224: each minimum: lambda(Q) <= D_Q + 1 - kB (m(Q) = 1), lambda(Q'^c) <= floor((N + f + d)/2) + 1 (D_(Q'^c) = D - D_Q + d), lambda({t}^c) <=
225: floor((N - d)/2) + 1.  So (B) needs floor((N + f + d)/2) + floor((N - d)/2) >= N + f - 2.  The left side is (2N + f - e)/2 where e is the
226: number of odd numbers among N + f + d, N - d: for N even (kB odd) e = 1 + [f even], for N odd (kB even) e = [f odd].  Hence (B) needs
227: f <= 3 - [f even] (N even), i.e. f <= 3, resp. f <= 4 - [f odd] (N odd), i.e. f <= 4.  For f >= 4 (kB odd), resp. f >= 5 (kB even), no

9: RGR word of length N = 4p-2, x = 1, cyclic runs R_1 S_1 ... R_k S_k (S_j between R_j
10: and R_{j+1}); a_t, b_t, r_t = a_t + b_t, d_t = a_t - b_t; l_j; A, B, R = A + B, F, D = A - B;
11: o_F, o_R odd reflection / rotation runs, e_F = k - o_F, e_R = k - o_R; H = (F - o_F)/2;
12: kappa := p - 1 - H = (R + o_F - 2p)/2 (an integer: F + R even, F = o_F mod 2).
13: For a set Q of rotation runs ("pattern"; proper means Q != empty, [k]): u_Q :=
14: 2^{-1} sum_{t in Q} theta_t in Z_p (theta_t = y_{t-1} - y_t), additive, u_{[k]} = 0;
15: D_Q = sum_Q d_t; m(Q) = number of maximal cyclic blocks of Q; the 2m(Q) reflection runs
16: S_j with exactly one of R_j, R_{j+1} in Q are the boundary runs of Q, beta(Q) of them even.
17: 
18: **Lemma H (half windows).**  For every proper pattern Q put
19:   lambda(Q) := min( p - m(Q) + 1,  D_Q + B - kappa + m(Q) - beta(Q),  floor((D_Q + B)/2) + 1 ),
20:   I(Q) := [1 - lambda(Q^c), lambda(Q) - 1]  (an integer interval, possibly empty).
21: Then the word has no identity 2p-subword iff u_Q notin I(Q) (mod p) for every proper Q
22: and 0 notin I(empty) (mod p), where I(empty) := [-min(p, A - kappa - 1, floor(A/2)),
23: min(p, B - kappa - 1, floor(B/2))].  If A, B <= 2p - 1, the last condition is equivalent to
24: min(A, B) <= kappa.  [Correction 2026-10-17T07:39 PDT, after the Codex review
25: review/olson-kbh-codex-review-v1.note.md: the earlier statement replaced the empty/full
26: condition by min(A, B) <= kappa without the bound A, B <= 2p - 1, which is false, e.g.
27: p = 5, w = rho_1^10 sigma_0^8 (k = 1, H = 4, kappa = B = 0, no proper patterns) satisfies it
28: but rho_1^10 = 1.]  Every avoider has A, B <= 2p - 1 (2p letters rho_1, resp. rho_{-1}, form
29: an identity 2p-subword), so for avoiders the zero condition min(A, B) <= kappa is necessary;
30: Lemma OR (proof-PAR-Kplus-partial.md Sec. 1) and Lemma M0 do not increase A or B, so the bound
31: persists under those reductions.  All uses in this directory are of this necessary direction.
32: Proof.  Lemma WAS: avoid iff 2u_P notin Ach(z_P) (mod p) for every P subset [k]
33: (z_i = +1 iff i in P), Ach(z) = the even integers in [lo, hi] (../proof-GR.md Sec. 2).
34: Since 2 is invertible mod p this is u_P notin Z cap [lo/2, hi/2]; with c = C_max/2,
35: hi/2 rounded down is min(p - Phi/2, E+ + c - p, floor(E+/2)) and lo/2 rounded up is
36: -min(p - Phi/2, E- + c - p, floor(E-/2)) (C_max and Phi are even).  For a proper P with
37: Phi = 2m boundaries, beta of them even: delta = beta + (o_F - (2m - beta)), so
38: c = H + m - beta = p - 1 - kappa + m - beta; E+ = A_P + B_{P^c} = D_P + B; P^c has the
39: same boundaries and E+(P^c) = E-(P).  This gives hi/2 = lambda(P) - 1 and
40: lo/2 = 1 - lambda(P^c).  For P = empty (z = -1, Phi = 0, c = H, E+ = B, E- = A) the
41: half window is I(empty) as displayed (P = [k] gives its negative).  Its end points lie in
42: [-p, p]; the end -p (resp. p) occurs only if floor(A/2) >= p, i.e. A >= 2p (resp. B >= 2p).
43: So for A, B <= 2p - 1 the only multiple of p it can contain is 0, which it contains iff
44: A, B >= kappa + 1.  []

55: ## 2. Block-chain lemma (value-independent certificate; no winding hypothesis)
56: 
57: **Lemma BC.**  Let w be an avoider (RGR, length 4p-2, F, R >= 1).  Let (P_1, ..., P_s),
58: s >= 2, be an ordered partition of [k] into nonempty proper patterns, Q_t := P_1 u ... u P_t.
59: Suppose
60:  (a) lambda(P_1) + ... + lambda(P_s) >= p + 1;
61:  (b) for 2 <= t <= s-1, with X = Q_{t-1}, Y = P_t, Z = Q_t^c:
62:      lambda(X u Y) + lambda(Y u Z) + lambda(Z u X) >= p + 1   and
63:      lambda(X) + lambda(Y) + lambda(Z) >= 1;
64:  (c) lambda(P_s) + lambda(P_s^c) >= 1.
65: Then w has an identity 2p-subword (contradiction).
66: 
67: Proof.  As w avoids, for every proper Q the residue u_Q is not that of any element of
68: I(Q); in particular |I(Q)| <= p - 1, i.e. lambda(Q) + lambda(Q^c) <= p.
69: Claim: if y is an integer, y = u_Q (mod p) and 1 - lambda(Q^c) <= y <= p + lambda(Q) - 1,
70: then lambda(Q) <= y <= p - lambda(Q^c).  Indeed, write l = lambda(Q), l' = lambda(Q^c); the
71: integers [1 - l', l - 1] and [p + 1 - l', p + l - 1] are congruent to elements of I(Q), so y
72: avoids them; as l + l' <= p, the three ranges [1 - l', l - 1], [l, p - l'],
73: [p + 1 - l', p + l - 1] tile [1 - l', p + l - 1] in this order (when l + l' <= 1 the outer
74: ranges are empty and [1 - l', p + l - 1] is contained in [l, p - l']).
75: For each t choose an integer v_t = u_{P_t} (mod p) in [lambda(P_t), p - lambda(P_t^c)]
76: (possible: if l + l' >= 1 the interval [1 - l', p + l - 1] has >= p integers and contains a
77: representative, which lies in [l, p - l'] by the claim; if l + l' <= 0 the interval
78: [l, p - l'] itself has >= p + 1 integers).  Put V_t = v_1 + ... + v_t = u_{Q_t} (mod p).
79: Induction: V_t in [lambda(Q_t), p - lambda(Q_t^c)] for 1 <= t <= s-1.  For t = 1 this is
80: the choice of v_1.  For 2 <= t <= s-1, V_t = V_{t-1} + v_t lies in
81: [lambda(Q_{t-1}) + lambda(P_t), 2p - lambda(Q_{t-1}^c) - lambda(P_t^c)], and with
82: X, Y, Z as in (b) (Q_{t-1}^c = Y u Z, P_t^c = Z u X, Q_t = X u Y, Q_t^c = Z) condition (b)
83: says exactly that this range lies in [1 - lambda(Q_t^c), p + lambda(Q_t) - 1]; the claim
84: gives the induction step.  Finally V_s = u_{[k]} = 0 (mod p), V_s = sum v_t >= sum
85: lambda(P_t) >= p + 1 by (a), and V_s = V_{s-1} + v_s <= (p - lambda(P_s)) +
86: (p - lambda(P_s^c)) <= 2p - 1 by (c) (Q_{s-1}^c = P_s).  No multiple of p lies in
87: [p + 1, 2p - 1].  []
