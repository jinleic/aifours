160: ### Lemma A
161: Let d ≥ 1, n ≥ 1 with 4 | n and dn even, and M ∈ M ∩ (4/n)Z^{4×4} with support S := {u : m_u > 0}. For every
162: μ ∈ R^S,
163:   |T(M)|/|P_{n,d}| ≤ P_d(n)·exp(n·V_μ(M)),
164: where
165:   V_μ(M) := ((d−1)/4) Σ_u m_u log m_u + (1−d) log 4 + (d/2) log d + Σ_{e = {u,v} ⊆ S, u ~ v} e^{μ_u + μ_v − 1}
166:            − (d/4) Σ_{u∈S} μ_u m_u
167: and P_d(n) := e^{17}(dn + 1)^8 (dn/2 + 1)^{145/2}. P_d(n) depends on neither M nor μ.
168: 
169: *Proof.* Each bound is applied to the exact count.
170: 1. *Colourings.* By the multinomial bound, n!/Π_u n_u! ≤ Π_{u∈S} (n/n_u)^{n_u} = exp(n H_4(M)), where
171:    H_4(M) := −Σ_u (m_u/4) log(m_u/4). Empty cells contribute 0! = 1 and 0⁰ = 1.
172: 2. *Points of each cell.* For u ∈ S, (d n_u)! ≤ e√(dn_u + 1)(dn_u/e)^{dn_u} ≤ e√(dn + 1)(dn_u/e)^{dn_u}. For u ∉ S,
173:    (d n_u)! = 0! = 1 = (0/e)⁰. There are at most 16 cells, so Π_u (d n_u)! ≤ e^{16}(dn + 1)^8 Π_{u∈S} (dn_u/e)^{dn_u}.
174: 3. *Edge factorials.* For every b ∈ B(M, n) and every e, 1/b_e! ≤ (e/b_e)^{b_e} (lower Stirling bound; b_e = 0 gives
175:    1 ≤ 1). Summing (3.3) over u gives Σ_e b_e = dn/2, so Π_e 1/b_e! ≤ e^{dn/2} exp(−Σ_e b_e log b_e).
176: 4. *Number of tuples.* Each b_e lies in {0, …, dn/2}, so |B(M, n)| ≤ (dn/2 + 1)^{72}.
177: 5. *Pairings.* 1/|P_{n,d}| = (dn/2)! 2^{dn/2}/(dn)! ≤ e√(dn/2 + 1)(dn/(2e))^{dn/2} 2^{dn/2}/(dn/e)^{dn}
178:    = e√(dn/2 + 1)·(dn/e)^{−dn/2}.
179: 6. *Empty cells in B(M, n).* If u ∉ S then (3.3) forces b_e = 0 for every e ∋ u. Such edges contribute
180:    b_e log b_e = 0, so only edges e ⊆ S remain.
181: 7. *Pointwise weak duality.* Fix b ∈ B(M, n) and write b_e = nβ_e. Then
182:    −Σ_e b_e log b_e = −n Σ_e β_e log β_e − (dn/2) log n.
183:    The constraints read Σ_{v ~ u} β_{uv} = d m_u/4 for u ∈ S. For any μ ∈ R^S,
184:      −Σ_{e⊆S} β_e log β_e = Σ_{e={u,v}⊆S} [−β_e log β_e + β_e(μ_u + μ_v)] − Σ_{u∈S} μ_u Σ_{v~u} β_{uv}
185:                           ≤ Σ_{e⊆S} e^{μ_u+μ_v−1} − (d/4) Σ_{u∈S} μ_u m_u.
186:    The equality holds because each edge contributes β_e to both endpoint constraints. The inequality is (I8)
187:    applied to each term with θ = μ_u + μ_v. No strong duality and no exact inner optimum is needed.
188: 8. *Collecting exponents.* Multiply items 1–5 and substitute item 7 for every b. Since Σ_u d n_u = dn and
189:    Σ_e b_e = dn/2, the factors (dn_u/e)^{dn_u}, e^{dn/2}, n^{−dn/2} and (dn/e)^{−dn/2} give exactly
190:      n[Σ_u (d m_u/4) log(d m_u/4) − (d/2) log d] + dn log n − dn + dn/2 − (dn/2) log n − (dn/2) log n + dn/2.
191:    The n log n terms and the linear terms cancel. Using Σ_u m_u = 4,
192:      H_4(M) + Σ_u (d m_u/4) log(d m_u/4) − (d/2) log d = ((d−1)/4) Σ_u m_u log m_u + (1−d) log 4 + (d/2) log d
193:    (verifier item B "Lemma A exponent").
194: 9. *Polynomial factor.* The non-exponential factors are e^{16}(dn+1)^8, (dn/2+1)^{72} and e√(dn/2+1), whose product
195:    is P_d(n). ∎

197: ### Proposition B (closed form at d = 8)
198: For every M ∈ M ∩ (4/n)Z^{4×4},
199:   |T(M)|/|P_{n,8}| ≤ P_8(n)·e^{n U(M)},   U(M) = −10 log 2 + 4 log E(M),   P_8(n) = e^{17}(8n+1)^8(4n+1)^{145/2}.
200: Moreover E(M) ≥ (8 + ‖M‖_F²)/2 ≥ 9/2 > 0 on M, and U(J) = 2 log 4 + 8 log(3/4) = 8 log 3 − 12 log 2, which is the
201: exponent of (EY)².
202: 
203: *Proof.*
204: - Take μ_u := c + (7/8) log m_u for u ∈ S, with c real.
205: - Since (d−1)/4 = (d/4)(7/8) = 7/4, the entropy terms cancel, and Σ_{u∈S} m_u = 4. Also
206:   Σ_{e⊆S} e^{2c−1}(m_u m_v)^{7/8} = e^{2c−1} E(M), where pairs touching an empty cell contribute 0 to E anyway. So
207:   V_μ(M) = −7 log 4 + 4 log 8 + e^{2c−1} E(M) − 8c.
208: - This is strictly convex in c and minimal at e^{2c−1} = 4/E(M), with value −10 log 2 + 4 log E(M) (verifier items
209:   B "Prop B"). The choice requires E(M) > 0.
210: - *Lower bound on E.* m^{7/8} ≥ m on [0, 1], so E(M) ≥ Σ_{allowed} m_u m_v. For doubly stochastic M this equals

218: ### Lemma 3.1 (row reduction)

221:   2E(f) = (Σf)² − Σ_p R_p² − Σ_q C_q² + Σ f_pq²,

223:   E(f) ≤ Σ_p (R_p² + Q_p/2),   Q_p := Σ_q f_pq².

226: second, an exact identity (verifier item "row-reduction certificate") gives

228: Both brackets are ≥ 0 by Cauchy–Schwarz over the four columns and the four rows. ∎

236: **Proof 1 (hypercontractivity).**
237: 1. *The chain.* Let X = {1, 2, 3, 4} with the uniform measure π, and K(x, y) := π(y). K is irreducible, and
238:    reversible because π(x)K(x, y) = π(x)π(y). K is the projection g ↦ Eg, so (I − K)² = I − K and
239:    H_t = exp(−t(I − K)) = K + e^{−t}(I − K) (I7). Thus H_t g = T_ρ g := Eg + ρ(g − Eg) with ρ = e^{−t}.

241:    By Theorem 3.5(ii) with q = 8, ‖H_t‖_{2→8} ≤ 1 whenever e^{4αt} ≥ 7, i.e. t ≥ t_0 := (log 3)(log 7)/2.
242: 3. *Duality.* H_t is self-adjoint on L²(π). By Hölder with exponents 8/7 and 8, for every g:
243:    ‖H_t g‖₂ = sup_{‖h‖₂ ≤ 1} ⟨g, H_t h⟩_π ≤ ‖g‖_{8/7} sup_{‖h‖₂ ≤ 1} ‖H_t h‖₈ ≤ ‖g‖_{8/7}
244:    for t ≥ t_0. Equivalently, ‖T_ρ g‖₂ ≤ ‖g‖_{8/7} for 0 ≤ ρ ≤ a := e^{−t_0} = 7^{−(log 3)/2}.
245: 4. *ρ = 1/3 is admissible.* 1/3 ≤ a ⟺ log 3 ≥ (log 3)(log 7)/2 ⟺ log 7 ≤ 2 ⟺ 7 ≤ e². This holds because
246:    e² = Σ_j 2^j/j! > Σ_{j≤5} 2^j/j! = 109/15 > 7 (exact; verifier B). The enclosure is
247:    a = 0.343385896618341840676… > 1/3.

251: 6. *Decay.* ‖T_ρ g‖₂² = (Eg)² + ρ² Var_π g (verifier item). So

253: 7. *Variance comparison.* By the mean value theorem, |s^{7/8} − t^{7/8}| ≥ (7/8)|s − t| for s, t ∈ [0, 1],
254:    including s = 0, because the derivative (7/8)ξ^{−1/8} ≥ 7/8 for ξ ∈ (0, 1]. Writing
255:    Var_π g = (1/32) Σ_{i,j} (g_i − g_j)², this gives Var_π g ≥ (49/64) Var_π r = (49/64)|r − U|²/4.

23:                                                        In this work we show that, for any fixed d, random d-regular graphs asymptotically
24:                                                    almost surely can be coloured with k colours, where k is the smallest integer satisfying
25:                                                    d < 2(k − 1) log(k − 1). From previous lower bounds due to Molloy and Reed, this estab-
26:                                                    lishes the chromatic number to be asymptotically almost surely k − 1 or k. If moreover

30:                                                    applies the small subgraph conditioning method to the number of balanced k-colourings,
31:                                                    where a colouring is balanced if the number of vertices of each colour is equal.

440: def psi_exact(m, d, tol=1e-13, maxit=200):
441:     """Exact inner optimum via the concave dual (float; Newton with backtracking)."""
442:     mv = m.reshape(-1)
443:     S = np.where(mv > 1e-15)[0]
444:     A = ADJ[np.ix_(S, S)]
445:     cc = d * mv[S]
446:     lam = np.log(np.sqrt(cc / np.maximum(A.sum(axis=1), 1e-300)))
447:     for _ in range(maxit):
448:         x = np.exp(lam)
449:         Ax = A @ x
450:         grad = cc - x * Ax
451:         if np.max(np.abs(grad)) < tol:
452:             break
453:         H = -(np.diag(x * Ax) + (x[:, None] * A * x[None, :]))
454:         step = np.linalg.solve(H, -grad)
455:         g0 = cc @ lam - 0.5 * x @ Ax
456:         t = 1.0
457:         while t > 1e-12:
458:             ln_ = lam + t * step
459:             xn = np.exp(ln_)
460:             if cc @ ln_ - 0.5 * xn @ (A @ xn) >= g0 - 1e-15:
461:                 break
462:             t *= 0.5
463:         lam = lam + t * step
464:     ent = sum(v * math.log(v) for v in mv if v > 0)
465:     inner = float(np.sum(d * mv[S] * lam))
466:     return (1 - d / 2) * math.log(4) + (d / 2) * math.log(d) + (d - 1) / 4 * ent - inner / 4
