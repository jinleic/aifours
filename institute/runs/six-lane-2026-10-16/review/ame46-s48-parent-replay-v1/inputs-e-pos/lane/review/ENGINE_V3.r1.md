## 3. Lemma 19 (officer-placement relaxation; validity)

Notation and facts F1–F4 as in `review/SUPPORT_LOWER48.r1.md` §1. Let ψ be an AME(4,6) state whose deficit profile is
in normal form, and let T be its officer set. Then:
- **(C1)** every line (b, c) of a pair (j, k) with (b, c) ∉ V_j × V_k holds exactly one officer;
- **(C2)** every line (a, b) ∈ V_j × V_k holds at most one officer;
- **(C3)** for i ≠ j and a ∈ V_i, exactly |V_j| − d_{i,a} of the lines (a, b), b ∈ V_j, hold an officer.

*Proof.*
- **(C1).** Every point of N lies in Π V_i (F3), so such a line contains no point of N. By F2 it holds exactly one
  officer.
- **(C2).** L42-3.
- **(C3).** Of these |V_j| lines, exactly d_{i,a} meet N (F3) and hold no officer (F1). Each of the others holds
  exactly one officer (F2). ∎

`code/profile_officer_cnf.py` encodes these constraints:
- one variable per point of [6]⁴;
- for C1, an at-least-one clause plus `CNF.at_most_k(·, 1)`;
- for C2, `at_most_k(·, 1)`;
- for C3, one indicator per line (a, b) with v ↔ OR(points of the line), then `at_most_k` on the indicators and on
  their negations, giving exactly |V_j| − d_{i,a}.

The indicator of T, together with the auxiliary values the sequential-counter encoding assigns to it, satisfies the
CNF. So UNSAT means no AME state has this profile, for every e. The encoding uses the same `ame_e0_cnf.CNF` helpers
as the frozen engine.

## 4. Completeness of the enumeration (argument independent of syntactic CNF symmetry)

This replaces the "each generator is a symmetry of the CNF" wording of `review/ENGINE_V2_GUARD.r1.md` §3 and
`review/SUPPORT_LOWER48.r1.md` §3. The parent noted that an arbitrary point permutation need not lift to a literal
automorphism of the ordered sequential-counter auxiliaries. The argument below needs no such symmetry.
- Let N be the non-classical part of the support of a genuine AME state whose profile is in normal form.
- Let N be the support's non-classical part of a genuine AME state, with profile in normal form.
- H is generated by Γ: value transpositions inside a d-class, and transpositions of equal-part coordinates. Each
  element of H acts as a local permutation or a party permutation. It maps the AME state to an AME state with the
  same normal-form profile and non-classical part g(N). So the H-orbit of N consists of genuine supports.
- Let N* be the lexicographically least element of this orbit, in the shared point order (`itertools.product` order
  of Π V_i). N* is genuine, so it satisfies the base CNF with suitable auxiliaries, by the necessary-constraint
  extension of LOWER46 r1 §3 step 2.
- N* ≤_lex g(N*) for every g ∈ H, in particular for every g ∈ Γ. So N* satisfies the lex-leader constraints, with
  the chain auxiliaries set to "prefixes agree".
- If the final CNF (base ∧ Lex_Γ ∧ blocking clauses of all found solutions) is certified UNSAT, then N* is a found
  solution. Every found solution is excluded by an exact check, which shows it is not a genuine support. That
  contradicts the genuineness of N*.
- Hence no genuine support has this profile, (t, e). Neither H-invariance of the CNF's solution set nor H-invariance
  of the checks is needed.
