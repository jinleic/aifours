68: ## 2. rules-k6-v3 L10 (XE)
69: 
70: **Statement.** Let v, j, k be distinct, and suppose U_vU_j = U_vU_k. Then:
71: - α_jk = 1;
72: - W := U_jU_k is a subgroup of index 5;
73: - [U_v : U_v∩W] = α_vj.

75: **Proof.**
76: 1. **X absorbs W.** X := U_vU_j satisfies XU_j = X, and since X = U_vU_k, also XU_k = X. Hence XW = X for W := ⟨U_j, U_k⟩.
77: 2. **X = U_vW.** Because 1 ∈ X, we have U_v ⊆ X, so U_vW ⊆ XW = X. Conversely, X = U_vU_j ⊆ U_vW.
78: 3. **W ≠ G.** μ(X) = α_vj/5 ≤ 4/5 < 1.
79: 4. **Index 5.** U_j ≤ W and U_k ≤ W, so [G:W] divides [G:U_j] = 5r_j and [G:U_k] = 5r_k. Hence it divides gcd(5r_j, 5r_k) = 5, and since W ≠ G, [G:W] = 5.
80: 5. **α_jk = 1.** U_jU_k ⊆ W, so α_jk/5 = μ(U_jU_k) ≤ μ(W) = 1/5. Hence α_jk = 1 and μ(U_jU_k) = μ(W), so U_jU_k = W.
81: 6. **The index of U_v∩W.** μ(U_vW) = [U_v : U_v∩W]·μ(W), by the product formula. Since μ(U_vW) = μ(X) = α_vj/5, we get [U_v : U_v∩W] = α_vj. ∎
82: 
83: **Corollary.** If α_jk ≥ 2, then U_vU_j ≠ U_vU_k for every vertex v.
84: 
85: ## 3. rules-k6-v3 L11 (N2-6)
86: 
87: **Hypotheses.** Let v be a vertex such that:
88: - (i) v ≠ E2, so r_v is odd;
89: - (ii) α_vj = 2 for all j ≠ v;
90: - (iii) α_jk ∈ {2, 4} for all distinct j, k ≠ v;
91: - (iv) for every triple {j,k,l} ⊆ V∖{v}, gcd(r_v, τ_jkl) = 1.
92: 
93: Condition (iv) holds automatically if v ≠ E3, because every prime factor of τ is 2 or 3. If v = E3, it holds when 3 ∤ τ_jkl for every triple. A sufficient test for that: for each triple, either 3 | τ_min(jkl) — impossible here, since τ_min is a product of 2-powers when all α ∈ {2,4} — or τ_max(jkl) < 3τ_min(jkl). The second suffices because τ is a multiple of τ_min that is at most τ_max.
94: 
95: **Conclusion.** No configuration with these data exists.
96: 
97: **Proof.** Translate so that g_v = 1, and put X_j = U_vU_j for j ≠ v. Then μ(X_j) = 2/5, and U_v ⊆ X_j.
98: 
99: **Step 1: μ(X_j∩X_k) = 1/5 for all j ≠ k.**
100: - (T1) for the edge jk, whose opposite vertex is v, gives α_jk | r_vτ_vjk. Since r_v is odd and α_jk ∈ {2, 4}, this gives α_jk | τ_vjk, so τ_vjk ≥ α_jk.
101: - By (T3) at apex v, Z_jk := U_v(U_j∩U_k) has μ(Z_jk) = τ_vjk/(5α_jk) ≥ 1/5. Also Z_jk ⊆ X_j∩X_k.
102: - By L0.5, X_j∩X_k is a union of (U_v, U_j∩U_k)-double cosets. By L0.4 each has μ a multiple of 1/gcd(5r_v, 5r_jr_kα_jk) = 1/(5·gcd(r_v, α_jk)) = 1/5, since r_v is odd and α_jk ∈ {2, 4}.
103: - By the XE corollary, X_j ≠ X_k. As both have measure 2/5, this gives μ(X_j∩X_k) < 2/5.
104: - Hence μ(X_j∩X_k) = 1/5, and so Z_jk = X_j∩X_k with μ(Z_jk) = 1/5.
105: 
106: **Step 2: the three Z's of a triple coincide.** Fix a triple j, k, l of vertices other than v, and put W := U_j∩U_k∩U_l.
107: - Index of W: [G:W] = 5r_jr_kr_lτ_jkl, using the definition of τ.
108: - Put Q := [G : U_v∩W]. Then Q is a multiple of [G:W] = 5r_jr_k·(r_lτ_jkl) and of T_vjk = 5r_jr_k·(r_vτ_vjk). So it is a multiple of 5r_jr_k·lcm(r_lτ_jkl, r_vτ_vjk).
109: - **The coprimality step.** The lcm is a multiple of lcm(r_lτ_jkl, r_v). This equals r_lτ_jkl·r_v, because gcd(r_v, r_lτ_jkl) = gcd(r_v, τ_jkl) = 1. Here gcd(r_v, r_l) = 1, and gcd(r_v, τ_jkl) = 1 by (iv).
110: - Hence Q ≥ 5r_jr_kr_lτ_jkl·r_v = r_v[G:W].
111: - By the product formula, μ(U_vW) = Q/(5r_v·[G:W]) ≥ 1/5.
112: - U_vW ⊆ Z_jk ∩ Z_jl ∩ Z_kl, and each Z has measure 1/5. Hence Z_jk = Z_jl = Z_kl = U_vW.
113: 
114: **Step 3: contradiction.**
115: - Take any two pairs of vertices from V∖{v}. Two pairs that share a vertex lie in a common triple, and two disjoint pairs {j,k}, {l,m} are linked through {j,l}. So all ten sets Z coincide; call the common set Z, with μ(Z) = 1/5.
116: - For j ≠ k, X_j∩X_k = Z. So the five sets X_j∖Z are pairwise disjoint, each of measure 1/5.
117: - Hence μ(∪_j X_j) = μ(Z) + 5·(1/5) = 6/5 > 1, a contradiction. ∎
118: 
119: The markers E3 (when v ≠ E3) and E5 play no role in this proof. If E2 is a neighbour j, nothing changes either: only r_v is involved in the granularity, and only gcd(r_v, ·) enters Step 2.

121: ## 4. rules-k6-v3 L12 (RPLP)
122: 
123: **Setting.** Fix v and translate so that g_v = 1. Write N for the five vertices other than v. For j ∈ N put X_j = U_vU_j, Y_j = G∖X_j and D_j = U_vg_jU_j.
124: 
125: **Facts, by rules-k6-v1 L7 (R1–R3, proved in sun-coset5 proof-v4 §5, which uses only pairwise disjointness and holds verbatim for six cosets):**
126: - D_j ⊆ Y_j.
127: - μ(D_j) = q_j/5 with an integer q_j satisfying 1 ≤ q_j ≤ 5 − α_vj.
128: - d_j = q_jr_j.
129: 
130: Each admissible vector q ∈ ∏_j {1, …, 5 − α_vj} is treated separately. The true configuration has exactly one such q, and it is not known which. So the argument must hold for every q.
131: 
132: **Types.**

134: - For a right coset C, its type is (A_C, S_C), where A_C = {j : C ⊆ Y_j} and S_C = {j : C ⊆ D_j}. Since D_j ⊆ Y_j, S_C ⊆ A_C. By L9(b), S_C is hereditary-allowed whenever |S_C| ≥ 2.

136: - The cosets with A_C = ∅ are exactly those in ∩_j X_j, and U_v is one of them.

138: **Forced containments.** Suppose τ_min(v,w,j) ≥ α_vwα_wj.
139: - (T2) at apex w gives τ ≤ α_vwα_wj, so τ = α_vwα_wj.
140: - (T3) at apex v gives μ(U_v(U_w∩U_j)) = τ/(5α_wj) = α_vw/5 = μ(X_w).
141: - Hence X_w = U_v(U_w∩U_j) ⊆ X_j, that is, Y_j ⊆ Y_w.
142: - So every type with j ∈ A and w ∉ A has x = 0. The engine omits those columns, which is valid.
143: 
144: **Constraints satisfied by x.**
145: - **(E1_j)** Σ_{(A,S): j∈S} x(A,S) = μ(D_j) = q_j/5.
146: - **(E2_j)** Σ_{(A,S): j∈A} x(A,S) = μ(Y_j) = (5 − α_vj)/5.
147: - **(B_jk)** ylo_jk ≤ Σ_{(A,S): j,k∈A} x(A,S) = μ(Y_j∩Y_k) ≤ yhi_jk.
148:   - μ(Y_j∩Y_k) = 1 − μ(X_j) − μ(X_k) + μ(X_j∩X_k).
149:   - lo_jk ≤ μ(X_j∩X_k) ≤ hi_jk, by rules-k6-v1 L4. Those bounds hold for every admissible τ (M1) and every instance (M2).
150: - **(TOT)** Σ x(A,S) = μ(∪_j Y_j) ≤ 1 − μ(U_v) < 1.
151: 
152: **The LP and its dual.** Let OPT(q) be the minimum of Σ x over all x ≥ 0 on allowed columns that satisfy E1, E2 and B. The true x is feasible, so OPT(q) ≤ μ(∪_j Y_j) < 1. If the system is infeasible, there is a contradiction straight away.
153: 
154: Let a_j, b_j be free rationals and u_jk, l_jk ≥ 0. Suppose that for every allowed column (A,S),
155: - Σ_{j∈S} a_j + Σ_{j∈A} b_j − Σ_{j<k, j,k∈A} u_jk + Σ_{j<k, j,k∈A} l_jk ≤ 1. ……(★)
156: 
157: **Weak duality.** For any feasible x:
158: - Σ x ≥ Σ_{(A,S)} x(A,S)·[Σ_{j∈S} a_j + Σ_{j∈A} b_j − Σ_{j,k∈A} u_jk + Σ_{j,k∈A} l_jk], using (★) and x ≥ 0.
159: - Regrouping the right side by constraint gives Σ_j a_j·(q_j/5) + Σ_j b_j·(5 − α_vj)/5 − Σ u_jk·μ(Y_j∩Y_k) + Σ l_jk·μ(Y_j∩Y_k).
160: - Since u_jk ≥ 0 and l_jk ≥ 0, this is ≥ Σ_j a_jq_j/5 + Σ_j b_j(5 − α_vj)/5 − Σ u_jk·yhi_jk + Σ l_jk·ylo_jk =: Obj.
161: 
162: So if Obj ≥ 1, then Σ x ≥ 1 for every feasible x, contradicting (TOT).
163: 
164: **Farkas case.** If the primal system has no solution, a dual direction exists with (★) holding with right-hand side 0 and positive objective. Scaling it so that Obj = 1 satisfies (★) with right-hand side 0 ≤ 1. So the same check (★) together with Obj ≥ 1 certifies this case as well.
165: 
166: **Exactness.** All entries are rationals: q_j/5, (5 − α_vj)/5, lo, hi, and the dual entries. The certificate is checked in exact rational arithmetic.
167: 
168: **Conclusion.** If, for **every** admissible q at v, there is either
169: - an RLP certificate (rules-k6-v1 L7 dual y with value ≥ 1), or
170: - a vector (a, b, u, l) satisfying (★) on all allowed columns with Obj ≥ 1,
171: 
172: then vertex v admits no configuration, so the pattern is impossible. ∎
173: 
174: The hereditary-allowed test is applied with maxgcd. That is exact, or at least safe, as shown in §1.

120:   - if x_j < x_k, barred unless α_vj + α_kj ≤ 4;
121:   - if x_k < x_j, barred unless α_vk + α_jk ≤ 4;
122:   - if x_j = x_k, barred unless both inequalities hold.

125: 
126: **PB:** every pair of N has lo ≤ hi (otherwise a Ppair would apply), and
127:   Σ_{j∈S}(1 − x_j) − Σ_{{j,k}⊆S}(1 − x_j − x_k + hi_jk) ≥ 1.

41: ## L1. Triangle lemma T [GEN; rules-v1 L1]
42: 
43: For distinct a, b, c put L = lcm(n_a, n_b, n_c) and T = [G : U_a∩U_b∩U_c]. Then L | T, and τ = T/L satisfies:
44:

46: - **(T3)** |U_y(U_x∩U_z)| = |G| L τ / (n_y I_xz).
47: - **(T2)** |U_y(U_x∩U_z)| ≤ min(|U_yU_x|, |U_yU_z|).

49: **Core5(6) form.**
50: - L = 5r_ar_br_c, because the r's are pairwise coprime.
51: - (T1) is equivalent to α_xy | r_zτ.
52: - (T3) reads |U_y(U_x∩U_z)| = τ|G| / (5α_xz).
53: - (T2) is equivalent to τ ≤ α_xyα_xz and τ ≤ α_yzα_xz.
54: - So τ_max is the smallest, over the three vertices, of the product of the two α's at that vertex.
55: - τ_min is the lcm over the three edges of α_e / gcd(α_e, r_opp), where r_opp is the r of the vertex opposite the edge. The table below lists gcd(α, r_z) by E2/E3 status alone; a prime p ≥ 5 never divides α ≤ 4.

58: |---|---|
59: | 1 | 1 |

62: | 4 | 4 if z = E2 with c2 = 2; 2 if z = E2 with c2 = 1; else 1 |

74: ## L3. Lemma K [GEN; rules-v1 L3]
75: 
76: **Statement.** Let v be a vertex and S a set of other vertices such that, for every pair {i, j} ⊆ S, U_vU_i ⊆ U_jU_i or U_vU_j ⊆ U_iU_j. Then Σ_{i∈S} |U_iU_v| ≤ |G| − |U_v|. In Core5(6) this reads Σ_{i∈S} α_iv ≤ 4.

116: ## L6. H5: index-5 subgroups from α = 1 edges [NEW]
117: 
118: **Statement.** In Core5(6), suppose α_ab = 1 and V := {v ∉ {a, b} : α_va = α_vb} ≠ ∅. Then:
119: - H := U_aU_b is a subgroup of index 5;
120: - U_a ⊆ H and U_b ⊆ H;
121: - for every v ∈ V, t_v = [U_v : U_v∩H] = α_va. In particular U_v ⊆ H when α_va = 1.
122: 
123: This covers M-S Lemma 3.7 with a = 5, which is the case α_va = 1.
124: 
125: **Proof.** Fix v ∈ V and put c = α_va = α_vb ∈ {1, 2, 3, 4}. Work in the triangle {v, a, b}.
126: 1. **The bound τ ≤ c.** The vertex products are c at a, c at b and c² at v, so (T2) gives τ ≤ c.
127: 2. **c divides τ.** Suppose c ≥ 2. By (T1), c | r_b τ and c | r_a τ, using the edges va and vb.
128:    - If c is prime (2 or 3): r_a and r_b are coprime, so c fails to divide at least one of them. Hence c | τ.
129:    - If c = 4: one of r_a, r_b is odd, and that one forces 4 | τ.
130:    - So τ = c. For c = 1 the bound already gives τ = 1.
131: 3. **U_vU_a = U_vU_b.** By (T3) with apex v, |U_v(U_a∩U_b)| = τ/(5α_ab) = c/5 = |U_vU_a| = |U_vU_b|. Since U_v(U_a∩U_b) lies inside both, U_vU_a = U_v(U_a∩U_b) = U_vU_b. Call this set X.
132: 4. **X = U_vW for W = ⟨U_a, U_b⟩.** X is right-invariant under U_a and under U_b, hence under W. So U_vW ⊆ X ⊆ U_vW.
133: 5. **W has index 5.** |X| = c/5 < 1, so W ≠ G. Also [G:W] divides gcd(5r_a, 5r_b) = 5, since U_a ≤ W. Hence [G:W] = 5.
134: 6. **W = U_aU_b.** U_aU_b ⊆ W and |U_aU_b| = 1/5 = |W|.
135: 7. **t_v = c.** |U_vW| = t_v|W| = t_v/5, and |U_vW| = |X| = c/5.

139: ## L7. Lemma R in LP form [NEW]
140: 
141: **Setting.** A harmonic configuration (pairwise disjoint cosets). Fix a vertex v and translate so that g_v = 1. For j ≠ v put D_j = U_vg_jU_j and d_j = |D_j|/|U_j|.
142: 
143: **The fibre facts (R1)–(R5′).** These are proved in sun-coset5 proof-v4 §5; the proofs use only disjointness and L0.
144: - **(R1)** D_j ∩ U_vU_j = ∅.
145: - **(R2)** |D_j| is a positive multiple of |G|/gcd(n_v, n_j).
146: - **(R3)** Every right coset U_vy ⊆ D_j meets g_jU_j, in a right coset of a subgroup of U_v of index d_j.
147: - **(R5′)** If D_j ∩ D_k ≠ ∅, then gcd(d_j, d_k) ≥ 2.
148: 
149: **A strengthening (R4′).** Let C be a right U_v-coset and S_C = {j : C ⊆ D_j}. If |S_C| = s ≥ 2, then:
150: - every pair in S_C has gcd ≥ 2;
151: - some pair in S_C has gcd ≥ s.
152: 
153: *Proof of (R4′).* The pieces in C, right-translated into U_v and then inverted, are pairwise disjoint left cosets in U_v. Apply Sun(s) in U_v (s ≤ 5, using the inputs of §0) to all of them. For the "every pair" part, apply L0.6 to each pair.
154: 
155: **Core5(6) form.**
156: - |D_j| = q_j|G|/5 with 1 ≤ q_j ≤ 5 − α_vj, so d_j = q_jr_j.
157: - The common primes of d_j and d_k lie in {2, 3}: q ≤ 4, and no two r's share a prime. In particular E5 is irrelevant here.
158: 
159: **LP statement.**
160: - **Measure.** For each non-empty S, let μ(S) be the total size of the right U_v-cosets C with S_C = S.
161: - **Coverage.** Σ_{S∋j} μ(S) = |D_j| = q_j/5.
162: - **Total.** Σ_S μ(S) ≤ 1 − |U_v| < 1. Here U_v·1 lies in no D_j, by (R1).
163: - **Support.** μ(S) > 0 only for **allowed** S: either |S| = 1, or every pair in S has maxgcd ≥ 2 and some pair has maxgcd ≥ |S|. "maxgcd" is the largest value of gcd(q_jr_j, q_kr_k) over all r with the given special statuses.
164: - **Lower bound.** Let LPmin(q) be the minimum of Σ_S μ(S) over μ ≥ 0 on allowed S with Σ_{S∋j} μ(S) ≥ q_j/5. This relaxes the true coverage equalities, so LPmin(q) is at most the true total.
165: 
166: **RLP kill.** If LPmin(q) ≥ 1 for every admissible vector q, i.e. every q with 1 ≤ q_j ≤ 5 − α_vj, then vertex v is impossible.
167: 
168: **Evaluation of LPmin.** By LP duality,
169:   LPmin = max Σ_j (q_j/5) y_j subject to Σ_{j∈S} y_j ≤ 1 for every maximal allowed S, and y ≥ 0.
170: - Maximal sets suffice: every non-maximal allowed set lies inside an allowed superset, and y ≥ 0 makes its constraint redundant.
171: - The engine solves this packing LP by exact rational simplex with Bland's rule.
172: 
173: **Soundness of maxgcd.** Using maxgcd only enlarges the allowed family, which lowers LPmin. Hence a kill computed with maxgcd is a kill for every instance.

175: ## L8. Evaluation points, representatives and E5 [NEW]
176: 
177: **(M1) τ_min suffices.** Every admissible τ is a multiple of τ_min. The rules T, K, P and RLP are upward closed in τ:
178: - a K1 link at τ_min forces τ = τ_min;
179: - the (P3) lower bounds increase with τ;
180: - RLP and F do not read τ.
181: 
182: So a kill at τ_min is a kill for every admissible τ.
183: 
184: **(M2) Representatives suffice.** A pattern quantifies over all pairwise coprime r with given statuses: the E2 vertex and its class, the E3 vertex, and the E5 vertex.
185: - **How r enters each rule.** T, K, P and the support of RLP depend on r only through these statuses. For E2 the class matters for α = 4, and for maxgcd the 2-adic part of q_jr_j is v₂(q_j) + v₂(r_j). In the RLP maxgcd, E2 of class 2 contributes an unbounded v₂.
186: - **F rules.** gcd(λ_l, λ_l') involves only the primes 2, 3 and 5:
187:   - t ≤ 5 and m = 5, and the r's are coprime;
188:   - a class-1 E2 contributes v₂ = 1 exactly;
189:   - class-2 E2, E3 and E5 contribute exponents larger than any t-part. The representative exponents 2⁴, 3⁴ and 5⁴ dominate.
190:   - Because the kill condition is monotone in the gcds, a kill at the representative is a kill for every instance.
191: 
192: **E5.** E5 affects only the F rules: no α and no q is divisible by 5, and only one r is divisible by 5. **Every F certificate must refute every E5 placement, including "no E5".** The engine checks all seven placements.

194: ## Certificates and the order of rules
195: 
196: **Enumeration.**
197: - There are 8 special-placement types up to S6.
198: - For each type, backtracking runs over the 15 edges, with α ∈ {1, 2, 3, 4}.
199: - A partial labelling is pruned as soon as a completed triangle is T-forbidden. Its certificate is the triangle-local record: the vertices, the three α's and the statuses.
200: - Every complete T-consistent labelling (a "leaf") is tested in this order: K, RLP, P (P-pair, then PB), FH5.
201: 
202: **FH5.**
203: - For each 1-edge (a, b) with V ≠ ∅, use H5 with m = 5.
204: - Vertices fixed inside H: a, b and every v ∈ V with α_va = 1.
205: - Forced values: t_v = α_va for the other v ∈ V.
206: - Free vertices: t_l ranges over 1..5. Every met-coset set M_l with |M_l| = t_l is enumerated, and a's coset is fixed to label 0.
207: - An assignment is rejected iff (F3) fails at a vertex with t = 1, or (F2) fails in some coset.
208: - The certificate requires every assignment to be rejected for **every** E5 placement.
209: 
210: **Output.**
211: - Each leaf yields one certificate or the label SURVIVE.
212: - Leaves are deduplicated into orbits by a canonical form under the stabiliser of the special placement.
213: - **Controls** record observations only and do not gate the run. They are:

37: ## Theorem
38: 
39: Let G be any group. Let a_1G_1, …, a_5G_5 be pairwise disjoint left cosets of subgroups of finite index. Then gcd([G:G_i], [G:G_j]) ≥ 5 for some i < j.
40: 
41: ## 1. R0: reduction to finite groups
42: 
43: core_G(G_i) is the kernel of the action of G on G/G_i, so its index is at most [G:G_i]!. Hence N = ∩_i core_G(G_i) is a normal subgroup of finite index contained in every G_i.
44: 
45: Each coset a_iG_i is the full preimage of its image in G/N. So indices, intersection indices and disjointness all pass to the finite group G/N.
46: 
47: ## 2. R1: reduction to Core(5), and a proof of M-S Prop 4.5
48: 
49: **Core(5).** No finite group G has subgroups U_1, …, U_5 with [G:U_i] = 4r_i, the r_i pairwise coprime, and pairwise disjoint cosets g_iU_i.
50: 
51: **The Sun(5) ⇒ Core(5) direction.** A Core(5) configuration has every pairwise gcd equal to 4 < 5.
52: 
53: **The Core(5) ⇒ Sun(5) direction, group by group.** Let n_i = [G:G_i], and assume five disjoint cosets in G have all pairwise gcds ≤ 4.
54: 
55: 1. **Each gcd is 2, 3 or 4.** By L0.2 and L0.6 no gcd equals 1, so each lies in {2, 3, 4}.
56: 2. **All divisible by 3, or all even.** If some n_i is odd, every gcd with it is odd and so equals 3. Then 3 divides all five indices.
57: 3. **All divisible by 3.** Every gcd is then 3 < 4. Any four of the cosets contradict Zhu Theorem 1.1 at k = 4.
58: 4. **All even.** Write n_i = 2^{e_i}m_i with m_i odd. Then the m_i are pairwise coprime, every e_i ≥ 1, and at most one e_i ≥ 3.
59:    - **Two indices with e = 1.** With any third index they have all pairwise gcds equal to 2 < 3, contradicting Zhu Theorem 1.1 at k = 3.
60:    - **Exactly one index with e = 1.** We get (2r_1, 4r_2, 4r_3, 4r_4) with r_1 odd and the r's pairwise coprime. This is excluded by Proposition 4.5 below.
61:    - **Otherwise.** n_i = 4r_i with r_i = 2^{e_i−2}m_i pairwise coprime: a Core(5) configuration in the same group G, with the same subgroups.
62: 
63: **Proposition 4.5 (M-S, Beitr. Algebra Geom. 60 (2019); proof patched per F-2 and F-8).**
64: 
65: *Status of this proof.* It is self-contained modulo rules-v1 L0.3–L0.5 and L1–L3. "Harmonic" means: there exist g_i such that the cosets g_iU_i are pairwise disjoint (F-9).

67: *Statement.* Let r_1, …, r_4 be pairwise coprime with r_1 odd. Then no group has subgroups with indices [G:U_1] = 2r_1 and [G:U_i] = 4r_i (i = 2, 3, 4) and pairwise disjoint cosets g_iU_i.
68: 
69: *Proof.* By R0 we may take G finite. Sizes are in units of |G|, and α(i,j) := [G:U_i∩U_j] / lcm(n_i, n_j). Lemma K (rules-v1 L3) at a vertex v with set S requires: for each pair {i, j} ⊆ S, either U_vU_i ⊆ U_jU_i or U_vU_j ⊆ U_iU_j. Its conclusion is Σ_{i∈S} |U_iU_v| < 1.
70: 
71: - **(a) α(1,i) = 1 and |U_1U_i| = 1/2 for i ≥ 2.** gcd(2r_1, 4r_i) = 2, since r_1 is odd and coprime to r_i. So α ≤ 1 by L0.3.
72: - **(b) α(i,j) ≠ 2 for i, j ≥ 2.** Suppose α(2,3) = 2, so [G:U_2∩U_3] = 8r_2r_3.
73:   - T = [G:U_1∩U_2∩U_3] is divisible by 2r_1 and by 8r_2r_3, hence by 8r_1r_2r_3.
74:   - So |U_1(U_2∩U_3)| = T/(2r_1·8r_2r_3) ≥ 1/2 = |U_1U_2| = |U_1U_3|. Hence U_1U_2 = U_1(U_2∩U_3) = U_1U_3.
75:   - **Inverting** gives U_2U_1 = U_3U_1. In particular U_2U_1 ⊆ U_3U_1, which is L3's first alternative at v = 2 for the pair {1, 3}. This is K2 with (v, j, k) = (1, 2, 3).
76:   - Lemma K at v = 2 with S = {1, 3} then requires |U_1U_2| + |U_3U_2| < 1, but the sum is 1/2 + 1/2 = 1. Contradiction.
77: - **(c) If α(2,3) = 3, then 3 | r_1 and |U_2U_1 ∩ U_2U_3| = 1/4.** (F-2 patch.)
78:   - T = [G:U_1∩U_2∩U_3] is divisible by lcm(2r_1, 4r_2, 4r_3) = 4r_1r_2r_3. Write T = 4r_1r_2r_3τ.
79:   - [G:U_2∩U_3] = 12r_2r_3 divides T, so 3 | r_1τ.
80:   - [G:U_1∩U_3] = 4r_1r_3 by (a). So |U_2(U_1∩U_3)| = T/(4r_2·4r_1r_3) = τ/4 ≤ |U_2U_1| = 1/2. Hence τ ≤ 2, so 3 ∤ τ, and therefore 3 | r_1.
81:   - U_2U_1 ∩ U_2U_3 contains U_2(U_1∩U_3), so its size is ≥ τ/4 ≥ 1/4. By L0.5 and L0.4 it is a union of (U_2, U_1∩U_3)-double cosets, each of size a multiple of 1/gcd(4r_2, 4r_1r_3) = 1/4.
82:   - Its size is not 1/2. Otherwise U_2U_1 ⊆ U_2U_3. **Inverting** gives U_1U_2 ⊆ U_3U_2, which is L3's first alternative at v = 1 for the pair {2, 3} (K2 with (v, j, k) = (2, 1, 3)). Lemma K at v = 1 with S = {2, 3} would then give |U_2U_1| + |U_3U_1| = 1, a contradiction. Hence the size is exactly 1/4.
83: - **(d) Not all of α(2,3), α(2,4), α(3,4) equal 1.** Suppose they all do.
84:   - In the triangle {2, 3, 4}, (T2) gives τ ≤ 1, so τ = 1. Then |U_2(U_4∩U_3)| = 1/4 = |U_2U_4| (T3), so U_2U_4 ⊆ U_2U_3. **Inverting** gives U_4U_2 ⊆ U_3U_2. Likewise U_4U_3 ⊆ U_2U_3.
85:   - In the triangle {1, 2, 4}, T is a multiple of lcm(2r_1, 4r_2, 4r_4) = 4r_1r_2r_4. So |U_1(U_4∩U_2)| = T/(2r_1·4r_2r_4) ≥ 1/2 = |U_1U_4|, giving U_1U_4 ⊆ U_1U_2. **Inverting** gives U_4U_1 ⊆ U_2U_1. Likewise U_4U_1 ⊆ U_3U_1.
86:   - So for every pair {i, j} ⊆ S = {1, 2, 3}, the inclusion U_4U_i ⊆ U_jU_i holds for at least one ordering of the pair. That is L3's pair condition at v = 4.
87:   - Lemma K requires 1/2 + 1/4 + 1/4 < 1, which fails.
88: - **(e) Choosing labels.** By (b) and (d), together with α ≤ 3 from L0.3, some α(i,j) with i, j ≥ 2 equals 3. Relabel so that α(2,3) = 3. By (c), 3 | r_1.
89:   - α(2,4) and α(3,4) cannot both be 1. Otherwise the triangle {2, 3, 4} has τ ≤ α(2,4)α(3,4) = 1, and then 12r_2r_3 | T = 4r_2r_3r_4 gives 3 | r_4. That contradicts 3 | r_1.
90:   - By (b) neither of them equals 2. So, after swapping 2 and 3 if necessary, α(2,4) = 3.
91: - **(f) α(3,4) = 3.** By (b), α(3,4) ≠ 2. Suppose α(3,4) = 1.
92:   - In the triangle {2, 3, 4}, write T = 4r_2r_3r_4τ. Then 12r_2r_3 | T and 12r_2r_4 | T. Since 3 ∤ r_3r_4 (because 3 | r_1), we get 3 | τ.
93:   - So |U_3(U_2∩U_4)| = τ/(4·3) ≥ 1/4 = |U_3U_4|, giving U_3U_4 ⊆ U_3U_2. **Inverting** gives U_4U_3 ⊆ U_2U_3, which is L3's second alternative at v = 4 for the pair {2, 3} (K2 with (v, j, k) = (3, 4, 2)).
94:   - Lemma K at v = 4 with S = {2, 3} requires 3/4 + 1/4 < 1, which fails.
95: - **(g) Final count.** Now α(1,i) = 1 and α(i,j) = 3 for all i, j ∈ {2, 3, 4}, and 3 | r_1.
96:   - By (c), applied to the pairs (2,3) and (2,4): |U_2U_1 ∪ U_2U_j| = 1/2 + 3/4 − 1/4 = 1 for j = 3, 4.
97:   - |U_2U_3 ∩ U_2U_4| is a multiple of 1/gcd(4r_2, 12r_3r_4) = 1/4 (by L0.5 + L0.4, using 3 ∤ r_2). This is F-8.
98:   - That size is at least 3/4 + 3/4 − 1 = 1/2. It is not 3/4: otherwise U_2U_3 = U_2U_4, and K2 with (v, j, k) = (2, 3, 4) — that is, Lemma K at v = 3 with S = {2, 4}, using the inverse U_3U_2 ⊆ U_4U_2 — would give 3/4 + 3/4 < 1. So the size is 1/2, and U_2U_3 ∪ U_2U_4 = G.
99:   - Put 𝒜 = U_2U_1, ℬ = U_2U_3, 𝒞 = U_2U_4. All three pairwise unions are G. So G∖ℬ and G∖𝒞 are disjoint subsets of 𝒜, and 𝒜 ∩ ℬ ∩ 𝒞 = 𝒜 ∖ ((G∖ℬ) ⊔ (G∖𝒞)) (M-S Lemma 3.1, re-proved here). Hence
100:     |𝒜 ∩ ℬ ∩ 𝒞| = 1/2 − 1/4 − 1/4 = 0.
101:   - But U_2 ⊆ 𝒜 ∩ ℬ ∩ 𝒞, a contradiction. ∎

170: ## 5. Lemma R: right-coset fibres over a vertex subgroup [NEW]
171: 
172: **Setting.** G is finite. U_1, …, U_5 ≤ G have indices n_i. **Assume the cosets g_1U_1, …, g_5U_5 are pairwise disjoint (F-9).** Fix a vertex v and left-translate the whole configuration so that g_v = 1; disjointness is preserved. For j ≠ v put D_j := U_v g_j U_j, a (U_v, U_j)-double coset, and d_j := |D_j|/|U_j|.
173: 
174: **Statement.**
175: - **(R1)** D_j ∩ U_vU_j = ∅.
176: - **(R2)** |D_j| is a positive multiple of |G|/gcd(n_v, n_j).
177: - **(R3)** Every right coset U_vy contained in D_j meets g_jU_j. If w ∈ g_jU_j ∩ U_vy, then g_jU_j ∩ U_vy = (U_v ∩ wU_jw⁻¹)w, and [U_v : U_v ∩ wU_jw⁻¹] = d_j.
178: - **(R5′)** If j ≠ k and D_j ∩ D_k ≠ ∅, then gcd(d_j, d_k) ≥ 2.
179: - (R4) from earlier versions is deleted, since it is unused.
180: 
181: **Proof of (R1).** Since g_vU_v = U_v and g_jU_j are disjoint, L0.2 gives g_j ∉ U_vU_j. Now U_vU_j = U_v·1·U_j is the double coset of 1, and D_j is the double coset of g_j. Distinct double cosets are disjoint, so D_j ∩ U_vU_j = ∅.
182: 
183: **Proof of (R2).** By L0.4, |U_v g_j U_j| is a multiple of |G|/gcd([G:U_v], [G:U_j]). It is positive because g_j ∈ D_j.
184: 
185: **Proof of (R3).**
186: - Let U_vy ⊆ D_j. Then y = c g_j u with c ∈ U_v and u ∈ U_j. So U_vy = U_v g_j u contains g_ju, which lies in g_jU_j.
187: - For w ∈ g_jU_j ∩ U_vy we have g_jU_j = wU_j and U_vy = U_vw. Then x ∈ wU_j ∩ U_vw ⟺ xw⁻¹ ∈ wU_jw⁻¹ and xw⁻¹ ∈ U_v. So g_jU_j ∩ U_vy = (U_v ∩ wU_jw⁻¹)w.
188: - For the index: [U_v : U_v ∩ wU_jw⁻¹] = |U_v · wU_jw⁻¹| / |wU_jw⁻¹|. Right multiplication by w preserves size, so |U_v · wU_jw⁻¹| = |U_vwU_j|. Since w ∈ D_j, U_vwU_j = D_j. Hence the index is |D_j|/|U_j| = d_j.
189: 
190: **Proof of (R5′).**
191: - D_j and D_k are both left U_v-invariant, so D_j ∩ D_k is too. Being non-empty, it contains a whole right coset C = U_vy.
192: - By (R3), choose w_j ∈ g_jU_j ∩ C and w_k ∈ g_kU_k ∩ C. The two pieces are P_j = g_jU_j ∩ C = A w_j and P_k = g_kU_k ∩ C = B w_k, where A = U_v ∩ w_jU_jw_j⁻¹ and B = U_v ∩ w_kU_kw_k⁻¹. Their indices in U_v are d_j and d_k.
193: - P_j ∩ P_k = ∅, because g_jU_j ∩ g_kU_k = ∅.
194: - **Right-translate into U_v.** Multiply both pieces on the right by w_j⁻¹. This gives A and Bc, where c = w_kw_j⁻¹ lies in U_v because w_j and w_k lie in the same right coset C. So A and Bc are disjoint subsets of U_v.
195: - **Invert.** A⁻¹ = A and (Bc)⁻¹ = c⁻¹B. These are disjoint left cosets in U_v of subgroups of indices d_j and d_k.
196: - **Apply k = 2 (L0.6) in U_v.** If gcd(d_j, d_k) = 1, then AB = U_v, so c⁻¹ ∈ AB, i.e. c⁻¹ = ab with a ∈ A and b ∈ B. Then a = c⁻¹b⁻¹ ∈ A ∩ c⁻¹B, a contradiction.
197: - Hence gcd(d_j, d_k) ≥ 2. ∎
198: 
199: **Core(5) form.** In Core(5), gcd(n_v, n_j) = 4. So |D_j| = q_j |G|/4 with q_j a positive integer. By (R1), D_j ⊆ G ∖ U_vU_j, which has size (4 − α_vj)|G|/4, so 1 ≤ q_j ≤ 4 − α_vj. Then d_j = q_j|G|/4 ÷ (|G|/(4r_j)) = q_jr_j.

201: ## 6. Refutation of the pattern S-D
202: 
203: **S-D:**
204: - α01 = α02 = 1, α03 = α04 = 2, and α12 = α13 = α14 = α23 = α24 = α34 = 3;
205: - E2 = 1, so r_1 is even and 3 ∤ r_1;
206: - E3 = 0, so 3 | r_0 and r_0 is odd;
207: - r_2, r_3, r_4 are coprime to 6.
208: 
209: Assume a Core(5) configuration with this pattern. Take v = 2, translate so that g_2 = 1, and put X_j = U_2U_j for j ∈ {0, 1, 3, 4}.
210: 
211: **Step 1: sizes, and D_j = Y_j for j ∈ {1, 3, 4}.**
212: - By L0.3, |X_0| = α_20|G|/4 = |G|/4 and |X_1| = |X_3| = |X_4| = 3|G|/4.
213: - For j ∈ {1, 3, 4} put Y_j = G ∖ X_j, so |Y_j| = |G|/4.
214: - By (R1), D_j ⊆ Y_j. By (R2), |D_j| is a positive multiple of |G|/4.
215: - Hence D_j = Y_j, q_j = 1 and d_j = r_j.
216: 
217: **Step 2: Y_1, Y_3, Y_4 are pairwise disjoint.** If Y_j ∩ Y_k ≠ ∅ for distinct j, k ∈ {1, 3, 4}, then D_j ∩ D_k ≠ ∅. By (R5′), gcd(r_j, r_k) ≥ 2, contradicting coprimality.
218: 
219: **Step 3: X_0 ⊆ X_1 ∩ X_3 ∩ X_4.** Use rules-v1 L1 in the triangles {0, 1, 2}, {0, 2, 3} and {0, 2, 4}.
220: - In {0, 1, 2}: by (T2), τ ≤ α01·α02 = 1, so τ_012 = 1.
221: - In {0, 2, 3}: (T1) gives α03 = 2 | r_2 τ, and r_2 is odd, so τ is even. (T2) gives τ ≤ α02·α03 = 2. Hence τ_023 = 2. The same argument gives τ_024 = 2.
222: - By (T3) with apex 2:
223:   - |U_2(U_0∩U_1)| = τ_012|G|/(4α01) = |G|/4;
224:   - |U_2(U_0∩U_3)| = τ_023|G|/(4α03) = 2|G|/8 = |G|/4;
225:   - |U_2(U_0∩U_4)| = |G|/4.
226: - Each of these sets lies inside X_0 = U_2U_0, which has size |G|/4. So X_0 = U_2(U_0∩U_j) ⊆ U_2U_j = X_j for j = 1, 3, 4.
227: 
228: **Step 4: G ∖ X_0 = Y_1 ⊔ Y_3 ⊔ Y_4.**
229: - By Step 3, X_0 ∩ Y_j = ∅ for j = 1, 3, 4.
230: - By Step 2, |Y_1 ⊔ Y_3 ⊔ Y_4| = 3|G|/4 = |G ∖ X_0|.
231: 
232: **Step 5: the coset g_0U_0.**
233: - **Location.** By (R1), D_0 ⊆ G ∖ X_0. By (R2), |D_0| = q_0|G|/4 with q_0 ∈ {1, 2, 3}, and d_0 = q_0r_0.
234: - **D_0 meets some Y_j.** D_0 is non-empty, so by Step 4 it meets some Y_j = D_j with j ∈ {1, 3, 4}.
235: - **Gcd condition.** (R5′) gives gcd(q_0r_0, r_j) ≥ 2. Since gcd(r_0, r_j) = 1, gcd(q_0r_0, r_j) = gcd(q_0, r_j).
236:   - For j = 3, 4 the number r_j is coprime to 6, so gcd(q_0, r_j) = 1 for q_0 ∈ {1, 2, 3}. This is impossible.
237:   - So D_0 does not meet Y_3 or Y_4, and therefore D_0 ⊆ Y_1.
238: - **Contradiction (q_0 = 1 route).** Because |Y_1| = |G|/4, D_0 ⊆ Y_1 forces q_0 = 1. Then gcd(q_0, r_1) = gcd(1, r_1) = 1, which contradicts (R5′) for the pair {0, 1}.
239: - **Equivalent route (proof-v1).** gcd(q_0, r_1) ≥ 2 with r_1 even and 3 ∤ r_1 forces q_0 = 2, and then |D_0| = |G|/2 > |Y_1|.
240: 
241: So no configuration has the pattern S-D. ∎

18: **Harmonic configuration.** G is a finite group. U_1, ..., U_k ≤ G are subgroups with n_i = [G:U_i], and g_1, ..., g_k ∈ G are elements such that the cosets g_iU_i are pairwise disjoint. Finiteness of G is justified by R0 in the README.
19: 
20: **Pairwise data.** For each pair i ≠ j put
21: - g_ij = gcd(n_i, n_j);
22: - I_ij = [G : U_i ∩ U_j];
23: - α_ij = I_ij / lcm(n_i, n_j). This is an integer, because n_i and n_j both divide I_ij.
24: 
25: **The Core(5) setting.**
26: - k = 5 and n_i = 4 r_i, where the r_i are pairwise coprime positive integers.
27: - E2 is the unique vertex with r_i even, if there is one. E3 is the unique vertex with 3 | r_i, if there is one. E2 = E3 is allowed.
28: - Consequently g_ij = 4, lcm(n_i, n_j) = 4 r_i r_j and I_ij = 4 r_i r_j α_ij.
29: 
30: **Minimal counterexample (used in F2).** Suppose Core(5) fails. Fix a counterexample in a group G of minimal order among all finite groups that contain five pairwise disjoint cosets of subgroups whose pairwise index-gcds are all ≤ 4. Then every proper subgroup of G satisfies Sun's statement for k = 5.
31: 
32: ## L0. Basic facts
33: 
34: **L0.1 [standard] Product formula.** For subgroups X, Y: |XY| = |X||Y| / |X ∩ Y|.
35: 
36: **L0.2 [PUB, M-S Lemma 3.2(3)].** gU ∩ hV = ∅ if and only if g⁻¹h ∉ UV.
37: 
38: *Proof.* gu = hv holds if and only if g⁻¹h = u v⁻¹ ∈ UV.
39: 
40: **L0.3.** In a harmonic configuration, |U_iU_j| = α_ij |G| / g_ij and 1 ≤ α_ij ≤ g_ij − 1. In Core(5) this reads α_ij ∈ {1, 2, 3} and |U_iU_j| = α_ij |G| / 4.
41: 
42: *Proof.*
43: - By L0.1, |U_iU_j| = |G| I_ij / (n_i n_j) = |G| lcm(n_i, n_j) α_ij / (n_i n_j) = α_ij |G| / g_ij.
44: - By L0.2 and disjointness, g_i⁻¹g_j ∉ U_iU_j. So U_iU_j ≠ G, which gives α_ij < g_ij.
45: 
46: **L0.4 [PUB, M-S Lemma 3.4(1)].** For subgroups A, B and any x ∈ G, |AxB| is a multiple of |G| / gcd([G:A], [G:B]).
47: 
48: *Proof.*
49: - |AxB| = |A||B| / |A ∩ xBx⁻¹| = |G| [G : A ∩ xBx⁻¹] / ([G:A][G:B]).
50: - [G : A ∩ xBx⁻¹] is a multiple of lcm([G:A], [G:B]).
51: - Substituting gives |AxB| = (integer) · |G| / gcd([G:A], [G:B]).
52: 
53: **L0.5 [PUB, mirror of M-S Lemma 3.4(2)].** For subgroups A, B, C, the set AB ∩ AC is a union of (A, B∩C)-double cosets.
54: 
55: *Proof.* Let x = ab = a'c, with y ∈ A and w ∈ B∩C. Then yxw = (ya)(bw) = (ya')(cw), which lies in AB ∩ AC.
56: 
57: **L0.6 [PUB, Sun 2006 Lemma 2.1 / M-S Lemma 2.2].** If [G:A] and [G:B] are coprime, then AB = G, so every left coset of A meets every left coset of B.
58: 
59: **L0.7 [PUB] Sun's statement for k ≤ 4, in every group.**
60: - k = 2: Sun 2006 Remark 2.2 (equivalently L0.6).
61: - k = 3, 4: Zhu Theorem 1.1 (Thms 2.2 and 3.1). It is also a consequence of M-S Theorem B.
62: 
63: **L0.8 [PUB, M-S Props 4.2, 4.3, 4.5]. Index tuples that are G-harmonic for no group G.** Throughout, the r_i are pairwise coprime.
64: - **Prop 4.2:** (2r_1, 2r_2, 2r_3).
65: - **Prop 4.3:** (3r_1, ..., 3r_4).
66: - **Prop 4.5:** (2r_1, 4r_2, 4r_3, 4r_4) with r_1 odd.

70: ## L1. Triangle lemma T [NEW form; subsumes M-S Lemma 3.10(a),(c) and Zhu (3.1), (3.4)]
71: 
72: Fix distinct vertices a, b, c. Put L = lcm(n_a, n_b, n_c) and T = [G : U_a∩U_b∩U_c].
73: 
74: **Statement.** L divides T. The quotient τ = T/L is a positive integer satisfying:
75: 
76: - **(T1)** I_xy divides L·τ for each pair {x, y} ⊆ {a, b, c}.
77: - **(T3)** For every labelling {x, y, z} = {a, b, c}:
78:   |U_y(U_x∩U_z)| = |G| · L · τ / (n_y · I_xz).
79: - **(T2)** For every labelling, |U_y(U_x∩U_z)| ≤ min(|U_yU_x|, |U_yU_z|).
80: 
81: *Proof.*
82: - The triple intersection lies in each U_x and in each U_x∩U_y. Hence every n_x divides T, so L | T. Likewise every I_xy divides T = Lτ, which is (T1).
83: - (T3) is L0.1 applied with |U_y| = |G|/n_y, |U_x∩U_z| = |G|/I_xz and |U_x∩U_y∩U_z| = |G|/T.
84: - (T2) holds because U_y(U_x∩U_z) ⊆ U_yU_x ∩ U_yU_z.
85: 
86: **Definitions.**
87: - τ_min is the least positive τ satisfying (T1). The set of solutions of (T1) is exactly the set of multiples of τ_min, since I_xy | Lτ ⟺ (I_xy / gcd(I_xy, L)) | τ.
88: - τ_max is the largest τ satisfying (T2) at all three apexes.
89: 
90: **T-kill.** If τ_min > τ_max, no harmonic configuration has these data.
91: 
92: **Core(5) form.**
93: - L = 4 r_a r_b r_c.
94: - (T1) ⟺ α_xy | r_z τ.
95: - (T3) reads |U_y(U_x∩U_z)| = τ |G| / (4 α_xz).
96: - (T2) ⟺ τ ≤ α_xy α_xz and τ ≤ α_yz α_xz.
97: 
98: So τ_max is the smallest product of two of the three α's. Also τ_min = lcm over the edges xy of α_xy / gcd(α_xy, r_z). Here gcd(α, r_z) = α exactly when α = 2 and z = E2, or α = 3 and z = E3; otherwise it is 1.

100: ## L2. Linking [NEW form of the step used in M-S 3.7, 3.8, 3.10(b)]
101: 
102: **Statement.** If |U_y(U_x∩U_z)| = |U_yU_x|, then U_yU_x ⊆ U_yU_z, and also U_xU_y ⊆ U_zU_y.
103: 
104: *Proof.*
105: - U_y(U_x∩U_z) is contained in U_yU_x and has the same size, so the two sets are equal. It is also contained in U_yU_z.
106: - Taking inverses of U_yU_x ⊆ U_yU_z gives U_xU_y ⊆ U_zU_y.
107: 
108: **Core(5) form.** The hypothesis holds exactly when τ = α_xy α_xz, the product of the two α's at x.

110: ## L3. Lemma K [NEW generalisation of M-S Lemma 3.5; subsumes Cor 3.6, Prop 3.8, Cor 3.9, Lemma 3.10(b), Cor 3.11]
111: 
112: **Statement.** Let v be a vertex and S a set of other vertices. Suppose that for every pair {i, j} ⊆ S,
113: 
114:   U_vU_i ⊆ U_jU_i   or   U_vU_j ⊆ U_iU_j.
115: 
116: Then Σ_{i∈S} |U_iU_v| ≤ |G| − |U_v| < |G|, that is, Σ_{i∈S} α_iv / g_iv < 1. In Core(5) this reads Σ_{i∈S} α_iv ≤ 3.
117: 
118: *Proof.*
119: 1. **The sets g_iU_iU_v (i ∈ S) are pairwise disjoint.** Suppose g_iu_iu = g_ju_ju' with u, u' ∈ U_v.
120:    - Then g_j⁻¹g_i = u_j u' u⁻¹ u_i⁻¹ ∈ U_jU_vU_i.
121:    - If U_vU_i ⊆ U_jU_i, then U_jU_vU_i ⊆ U_jU_i. This contradicts L0.2 for the disjoint pair g_jU_j, g_iU_i.
122:    - If instead U_vU_j ⊆ U_iU_j, then g_i⁻¹g_j ∈ U_iU_vU_j ⊆ U_iU_j, the same contradiction.
123: 2. **None of these sets meets g_vU_v.** Each g_iU_iU_v is right U_v-invariant. If it met g_vU_v it would contain g_v, say g_v = g_iu_iu. Then g_vu⁻¹ = g_iu_i lies in g_vU_v ∩ g_iU_i, which is empty.
124: 3. **Counting.** Summing the sizes |g_iU_iU_v| = |U_iU_v| = α_iv |G| / g_iv gives the claim.
125: 
126: **K1 (links).** The pair condition for {i, j} at v holds if |U_i(U_v∩U_j)| = |U_iU_v|, or if |U_j(U_v∩U_i)| = |U_jU_v|.
127: - By L2, the first equality gives U_vU_i ⊆ U_jU_i, and the second gives U_vU_j ⊆ U_iU_j.
128: - Core(5) form: τ_{ivj} = α_iv α_vj, where the product is of the two α's at v.
129: 
130: **K2.** If U_vU_j ⊆ U_vU_k (v, j, k distinct), then α_vj / g_vj + α_kj / g_kj < 1. In Core(5): α_vj + α_kj ≤ 3.
131: 
132: *Proof of K2.* Apply L3 at vertex j with S = {v, k}. Its pair condition requires U_jU_v ⊆ U_kU_v, which is the inverse of the hypothesis.
133: 
134: **Corrections to M-S.**
135: - *M-S Cor 3.11.* The printed proof asserts "by Lemma 3.10a) gcd(r_v, α(U,W)) = 1". With α(U,W) = α(V,W) that step does not follow, because 3.10(a) becomes trivial. The statement is still true whenever α(U,W) is 1 or a prime:
136:   - since r_u and r_v are coprime, gcd(r_v, α) = 1 or gcd(r_u, α) = 1;
137:   - in the second case apply 3.10(b) with U and V swapped; the quantity |VU| + |UW| equals |UV| + |VW|.
138: 
139:   In this lane the statement is an instance of K1 + L3: τ ≤ τ_max forces a link at the vertex shared by the two equal edges. This settles the screen caveat.
140: - *M-S Lemma 4.4.* The first bullet is misprinted. It should read "α(U_2, U_3) ≠ 2", and that is what its proof shows.

142: ## L4. Vertex count P [NEW form; subsumes the Lemma 3.1 counts in M-S Props 4.3/4.5 and screen N1]
143: 
144: Fix a vertex v. For each other vertex j put X_j = U_vU_j and Y_j = G ∖ X_j.
145: 
146: **Statement.**
147: - **(P1)** |X_j| = α_vj |G| / g_vj, and U_v ⊆ X_j.
148: - **(P2)** |X_j ∩ X_k| is a multiple of u_vjk = |G| / gcd(n_v, I_jk). In Core(5), u_vjk = |G| / (4 gcd(r_v, α_jk)).
149: - **(P3)** |X_j ∩ X_k| ≥ max(|U_v(U_j∩U_k)|, |X_j| + |X_k| − |G|). The first term is given by (T3).
150: - **(P4)** If |X_j ∩ X_k| = |X_j|, then X_j ⊆ X_k, so K2 must hold for that containment.
151: - **(P5)** For every set S of other vertices:
152:   Σ_{j∈S} |Y_j| − Σ_{j<k in S} |Y_j ∩ Y_k| < |G|,
153:   where |Y_j ∩ Y_k| = |G| − |X_j| − |X_k| + |X_j ∩ X_k|.
154: 
155: *Proof.*
156: - (P2): by L0.5, X_j ∩ X_k is a union of (U_v, U_j∩U_k)-double cosets. By L0.4, each has size a multiple of |G| / gcd(n_v, I_jk). In Core(5), gcd(4r_v, 4r_jr_kα_jk) = 4 gcd(r_v, α_jk), because gcd(r_v, r_jr_k) = 1.
157: - (P3): U_v(U_j∩U_k) ⊆ X_j ∩ X_k, and inclusion–exclusion gives the second bound.
158: - (P4): immediate from K2.
159: - (P5): this is the Bonferroni inequality. Also ∪_j Y_j ⊆ G ∖ U_v, which is a proper subset of G.
160: 
161: **How the engine uses P (sound).** For each pair {j, k}:
162: - hi_jk is the largest multiple of u that is ≤ min(|X_j|, |X_k|). It is lowered by one unit u when equality would force a containment that K2 forbids. If |X_j| = |X_k|, equality would force X_j = X_k, and then both K2 conditions must hold.
163: - lo_jk is (P3) rounded up to a multiple of u.
164: - If lo_jk > hi_jk the pattern is killed: **P-pair**.
165: - Otherwise the left side of (P5) is non-increasing in each |X_j ∩ X_k|. If (P5) already fails with every |X_j ∩ X_k| set to hi_jk, it fails for the true values, and the pattern is killed: **P-Bonferroni**.

167: ## L5. N2: all ten α = 2 is impossible in Core(5) [NEW, unreviewed]
168: 
169: *Proof.*
170: 1. **Every triangle has τ = 2.** Each edge has α = 2, and at most one vertex is E2. So by (T1) τ is even, and by (T2) τ ≤ 4.
171:    - If τ = 4, then (T2) holds with equality at every apex. So every vertex is linked for the other two (K1), and L3 at any vertex of the triangle gives 2 + 2 ≤ 3, which is false.
172:    - Hence τ = 2. Therefore [G : U_a∩U_b∩U_c] = 8 r_a r_b r_c for every triangle.
173: 2. **Fix a vertex v with r_v odd.** One exists, since at most one r is even. For the other vertices j put X_j = U_vU_j; then |X_j| = |G|/2.
174: 3. **Pairwise intersections.** For other vertices j ≠ k put Z_jk = U_v(U_j∩U_k).
175:    - By (T3), |Z_jk| = 2|G| / (4·2) = |G|/4, and Z_jk ⊆ X_j ∩ X_k.
176:    - By (P2), |X_j ∩ X_k| is a multiple of |G| / (4 gcd(r_v, 2)) = |G|/4.
177:    - |X_j ∩ X_k| ≠ |G|/2: otherwise X_j = X_k, and K2 would give 2 + 2 ≤ 3.
178:    - Hence X_j ∩ X_k = Z_jk.
179: 4. **The three Z's of a triple coincide.** Take distinct other vertices j, k, l and put W = U_j∩U_k∩U_l, so [G:W] = 8 r_j r_k r_l.
180:    - Q = [G : U_v ∩ W] is divisible by the three triangle indices 8 r_v r_j r_k, 8 r_v r_j r_l and 8 r_v r_k r_l. By coprimality, Q is divisible by 8 r_v r_j r_k r_l.
181:    - So |U_vW| = |G| Q / (4 r_v · 8 r_j r_k r_l) ≥ |G|/4.
182:    - But U_vW ⊆ Z_jk ∩ Z_jl ∩ Z_kl, and each Z has size |G|/4. Hence Z_jk = Z_jl = Z_kl = U_vW.
183: 5. **Contradiction.** The six sets Z among the four other vertices are therefore all one set Z with |Z| = |G|/4.
184:    - The four sets X_j ∖ Z are pairwise disjoint, each of size |G|/4.
185:    - So |∪_j X_j| = 4·|G|/4 + |G|/4 = 5|G|/4 > |G|, a contradiction.

187: ## L6. Fibre lemma F [NEW form; the case of H1 below subsumes screen N3]
188: 
189: Let H ≤ G with [G:H] = m. For each vertex l put t_l = [U_l : U_l∩H] and λ_l = [H : U_l∩H].
190: 
191: **Statement.**
192: - **(F1)** n_l t_l = m λ_l and 1 ≤ t_l ≤ m. The coset g_lU_l meets exactly t_l left cosets of H.
193: - **(F2)** Fix a left coset C of H and z ∈ C, and let S_C = {l : g_lU_l ∩ C ≠ ∅}.
194:   - For each l ∈ S_C, the set z⁻¹(g_lU_l ∩ C) is a left coset in H of U_l∩H. These cosets are pairwise disjoint.
195:   - Hence, if |S_C| = s ≥ 2, then gcd(λ_l, λ_l') ≥ s for some l ≠ l' in S_C. This uses L0.7 for s ≤ 4, and for s = 5 the minimality of G (§0; H is proper).
196: - **(F3)** If U_i ⊆ H, then |U_iU_l| ≤ |HU_l| = t_l |G| / m, that is, α_il / g_il ≤ t_l / m. In particular, if U_i, U_j ⊆ H then α_ij / g_ij ≤ 1/m.
197: 
198: *Proof.*
199: - (F1): [G : U_l∩H] = n_l t_l = m λ_l. The set g_lU_lH is a union of |U_lH| / |H| = t_l left H-cosets. Also t_l ≤ m, since distinct cosets of U_l∩H in U_l lie in distinct cosets of H.
200: - (F2): take y ∈ g_lU_l ∩ C. Then g_lU_l = yU_l and C = yH, so g_lU_l ∩ C = y(U_l∩H). Since z⁻¹y ∈ H, z⁻¹y(U_l∩H) is a left coset in H. Disjointness is preserved by translation.
201: - (F3): U_iU_l ⊆ HU_l, and |HU_l| = |H||U_l| / |H∩U_l| = t_l |H|.

203: ## L7. Sources of a subgroup H
204: 
205: **H1 [PUB, M-S Lemma 3.7].** Suppose [G:U] = a r_u, [G:V] = a r_v, [G:W] = a r_w with r_u, r_v, r_w pairwise coprime, and α(U,V) = α(U,W) = α(V,W) = 1. Then UV = VU = UW = WU = VW = WV is a subgroup of index a. It contains U, V and W. In Core(5), a = 4.
206: 
207: **H2 [NEW, unreviewed].** In Core(5), suppose α_ab = 1, and let V2 be the non-empty set of vertices v with α_va = α_vb = 2. Put W = ⟨U_a, U_b⟩. Then one of the following holds:
208: - **(i)** [G:W] = 4, W = U_aU_b, and t_v = [U_v : U_v∩W] = 2 for every v ∈ V2;
209: - **(ii)** [G:W] = 2, and U_v ⊆ W for every v ∈ V2.
210: 
211: *Proof.* Fix v ∈ V2 and work in the triangle {v, a, b}.
212: 1. **τ = 2.** By (T2), τ ≤ min(2·2, 2·1, 2·1) = 2. By (T1), 2 | r_b τ and 2 | r_a τ. Since r_a and r_b are not both even, τ is even. So τ = 2.
213: 2. **U_vU_a = U_vU_b.** By (T3), |U_v(U_a∩U_b)| = 2|G| / (4·1) = |G|/2 = |U_vU_a| = |U_vU_b|. Hence U_vU_a = U_v(U_a∩U_b) = U_vU_b. Call this set X.
214: 3. **X = U_vW.** X is right-invariant under U_a and under U_b, hence under W. Since U_v ⊆ X, this gives U_vW ⊆ X. Conversely X = U_vU_a ⊆ U_vW. So X = U_vW, and |X| = |G|/2 shows W ≠ G.
215: 4. **[G:W] ∈ {2, 4}.** [G:W] divides gcd(4r_a, 4r_b) = 4.
216: 5. **Index 4.** U_aU_b ⊆ W, and |U_aU_b| = |G|/4 = |W|, so W = U_aU_b. Also |U_vW| = t_v |W| = |G|/2, so t_v = 2.
217: 6. **Index 2.** |U_vW| = |G|/2 = |W|, so U_v ⊆ W.
218: 
219: W does not depend on v, so the same alternative holds for all v ∈ V2.

221: ## L8. Soundness of the engine's evaluation points [NEW]
222: 
223: **(M1) Evaluating at τ = τ_min is enough.** Every admissible τ is a multiple of τ_min, so τ ≥ τ_min. Every rule the engine uses is upward closed in each triangle's τ:
224: - T-kill means τ_min > τ_max.
225: - A link (K1) at τ_min means (T2) holds with equality there. Then τ = τ_min is forced, because a larger τ would violate (T2). So the links present at τ_min are present for every admissible τ.
226: - The lower bounds in (P3) increase with τ. The values hi_jk and the K2 conditions do not depend on τ.
227: - F, H1, H2 and N2 do not use the program's τ.
228: 
229: So a kill at τ_min is a kill for every admissible τ.
230: 
231: **(M2) Representative values of r are enough.** A Core(5) pattern (α, E2, E3) quantifies over all pairwise coprime r. The engine instead fixes
232: 
233:   r_i = p_i · 16^[i=E2] · 81^[i=E3],   with distinct primes p_i ∈ {5, 7, 11, 13, 17}.
234: 
235: Every quantity it uses depends on r only through the following:
236: - g_ij = 4;
237: - whether α_xy | r_z, and gcd(r_v, α_jk). Both depend only on the E2/E3 status.
238: - In F, gcd(λ_l, λ_l') = 2^min(v_2) · 3^min(v_3).
239:   - No prime p ≥ 5 is common to the two, since the r's are coprime, t ≤ 4 and m ∈ {2, 4}.
240:   - With v_2(r_E2) = 4 ≥ 3 and v_3(r_E3) = 4 ≥ 2, each min equals the largest value over all instances.
241:   - The F-kill condition "no pair reaches s" is monotone, so a kill at the representative is a kill for every instance.

243: ## Engine rule order and certificates
244: 
245: **Order.** Rules are applied in the order T, K, P-pair, P-Bonferroni, N2, F-H1, F-H2. The certificate of a pattern is the first rule that fires, together with its witness:
246: - T: the triangle;
247: - K: the vertex and S;
248: - P: the vertex and the pair or S;
249: - N2: none;
250: - F: the source of H and the number of fibre assignments examined, all of which are refuted.
251: 
252: Patterns killed only through N2 or H2 are flagged, because those lemmas are [NEW] and unreviewed.
253: 
254: **F enumeration.**
255: - For each vertex l not known to lie inside H, the engine enumerates t_l ∈ {1, ..., m} and the set M_l of met cosets with |M_l| = t_l.
256: - Known inside vertices: the triangle for H1, and {a, b} for H2. For these t = 1, and they are placed in all possible cosets.
257: - Constraints:
258:   - (F3), with respect to every vertex that has t = 1;
259:   - t_v = 2 (case i) or t_v = 1 (case ii) for v ∈ V2 under H2;
260:   - (F2) in every coset, using the maximal possible gcds (M2).
