# LLM Coding Discipline

## Core Loop

Apply this skill as a process guardrail, not as a replacement for repository-specific instructions.

1. Define completion before editing.
   - Restate the concrete success criteria when the task is non-trivial, ambiguous, risky, or multi-step.
   - Convert vague asks into verifiable behavior. For example, "add validation" becomes the exact inputs rejected, user-visible result, and tests or smoke checks that prove it.
   - Ask only when the missing answer cannot be discovered locally and a reasonable assumption would be risky.
2. Read before writing.
   - Inspect the files, tests, imports, config, and nearby patterns that the change will touch.
   - Reuse existing project style, helper APIs, and dependency choices.
   - Search for similar implementations before adding new structure.
3. Plan only as much as the task needs.
   - For multi-step work, make an inspectable plan with evidence expectations.
   - For small clear fixes, proceed directly after reading enough context.
   - Keep explicit non-goals for risky, broad, or tempting cleanup work.
4. Make the smallest useful change.
   - Keep diffs proportional to the request.
   - Do not reformat, rename, reorganize, or upgrade unrelated code while passing through.
   - Be able to tie every changed line to the user request, a failing test, or a necessary local contract.
5. Verify with behavior.
   - Prefer reproducing a bug before fixing it.
   - Add or run tests that cover user-visible behavior, not just field assignments or happy-path construction.
   - If a behavior cannot be tested cheaply, run the strongest available smoke or static check and state the residual risk.
6. Review before reporting done.
   - Inspect the final diff for accidental broadening, style drift, dependency creep, secrets, and missing evidence.
   - Compare the result against the original success criteria.
   - Report what changed, why, what verified it, and any remaining risk.

## Debugging Rules

- Investigate instead of guessing.
- Read the complete error, stack trace, logs, request, response, and reproduction path before changing code.
- Change one causal thing at a time when isolating a failure.
- Do not hide unexpected nulls, missing fields, 500s, flakes, or race conditions with broad fallbacks until the cause is understood.
- When repeated fixes fail, stop and re-check the premise rather than layering more patches.

## Dependency Rules

- Treat each new dependency as permanent code outside local control.
- Before adding one, check whether the standard library, existing project dependencies, or local helpers already solve the problem.
- If a dependency is still warranted, make the reason visible in the implementation notes or final response.
- Verify lockfile or package-manager changes when dependency manifests are touched.

## Common Failure Modes

Stop and narrow the work if one of these appears:

- Kitchen Sink: a small task starts restructuring unrelated areas.
- Wrong Abstraction: abstraction appears before repeated real use or before the codebase pattern supports it.
- Optimistic Path: only happy-path behavior works while user input, network, server, empty-state, and permission failures are ignored.
- Runaway Refactor: one fix cascades through files without a clear requirement.
- Knowledge Hallucination: code uses an API, parameter, CLI flag, or library behavior not verified from local source or current docs.
- Format Fog: formatting churn makes the meaningful diff hard to review.

## Interaction With Other Local Workflow

- Follow higher-priority system, developer, workspace, and repo instructions first.
- Use the existing `humanize-workflow` skill for long-running, implementation-heavy, or review-sensitive work that needs explicit freeze-plan-iterate-audit loops.
- Use `$consult` only when the user asks for an external model or when a genuinely independent second opinion would materially reduce risk.
- Do not install hooks, run autonomous background loops, or change global Codex config as part of this skill.
- For live infra, production, cluster, GPU, or credential-sensitive work, keep this skill subordinate to the workspace ops routing and approval rules.

def a_bound(z, mu):
    """Enclose the specified a(z,mu), including the entire finite maximum."""
    powers = []

        for unused in range(2, 6):

        powers.append(row)
    phi = arb(0)

    for s, w in SPECTRA:
        term = arb(w)
        for k in range(4):
            if s[k]:

        phi += term

            if s[k]:
                moments[k] += s[k] * term

        raise Invalid("Phi is not certified finite and positive")

    if any(not (v.is_finite() and v > 0) for v in means):
        raise Invalid("a moment is not certified finite and positive")

def edges():

def hex_rational(text):

def root_simplex(facet):
    fi, fj = facet

def lower_decimal(value):

    value = value.lower()

def a_bound(z, mu):
    """Enclose the specified a(z,mu), including the entire finite maximum."""
    powers = []
    for q in mu:
        row = [arb(1), arb(q)]
        for unused in range(2, 6):

        powers.append(row)

    for s, w in SPECTRA:
        term = arb(w)
        for k in range(4):

        phi += term
        for k in range(4):
            if s[k]:
                moments[k] += s[k] * term
    if not (phi.is_finite() and phi > 0):
        raise Invalid("Phi is not certified finite and positive")
    means = [v / phi for v in moments]
    if any(not (v.is_finite() and v > 0) for v in means):
        raise Invalid("a moment is not certified finite and positive")
    g = [means[k].log() / 2 - arb(mu[k]).log() + z[k]
         for k in range(4)]
    # psi0 + z.m0 - g.m0 = log(Phi) exactly. No approximation
    # or assumed maximizer is used in this algebraic cancellation.

        @lru_cache(maxsize=65536)
        def entropy_term(n):
            b = arb(n)
            return b * b.log() * 3 / 2

        @lru_cache(maxsize=65536)
        def vertex_data(p):
            active, entropy = [], arb(0)
            for u, n in enumerate(class_values(p)):
                if n < 0:
                    raise Invalid("vertex outside Delta: negative class " + str(u))
                if n > 0:

            raise Invalid("nonfinite vertex margin")

def exact_phi_moments(mu):

def selftest(prec):
    checks = []

    def require(condition, name):
        if not condition:
            raise Invalid("selftest failed: " + name)
        checks.append(name)

            "simplified a agrees with the stated unsimplified formula")
    return {"verdict": "PASS", "selftest": True, "prec": prec,
            "checks": checks, "a_uniform": a.str(),

def spectra():
    result = []

def edges():
    used, result = set(), []
    for u in range(9):
        i, j = divmod(u, 3)

            if (v, kv) in used:

            result.append((u, k, v, kv))

def rational(text):

        raise Invalid("r0 must be a P/Q string")
    m = RATIONAL.fullmatch(text)

def hex_rational(text):
    """Parse the written binary rational, with no float conversion."""
    if not isinstance(text, str):
        raise Invalid("hexadecimal entry must be a string")
    m = HEX.fullmatch(text)
    if m is None:
        raise Invalid("invalid finite hexadecimal literal: " + repr(text)[:100])
    numerator = int(m[2] + m[3], 16)
    if m[1] == "-":
        numerator = -numerator
    exponent = int(m[4]) - 4 * len(m[3])
    if exponent >= 0:
        return Q(numerator << exponent)
    return Q(numerator, 1 << -exponent)

def root_simplex(facet):
    fi, fj = facet
    vertices = [CENTER]
    for sigma in permutations(range(3)):
        if sigma[fi] != fj:
            vertices.append(tuple(
                THIRD * int(truth) for truth in (
                    sigma[0] == 0, sigma[0] == 1,
                    sigma[1] == 0, sigma[1] == 1
                )

    if len(vertices) != 5:
        raise Invalid("root construction did not produce five vertices")
    return tuple(vertices)


def class_values(p):
    x1, x2, x3, x4 = p
    return (
        x1, x2, THIRD - x1 - x2,
        x3, x4, THIRD - x3 - x4,
        THIRD - x1 - x3, THIRD - x2 - x4,
        x1 + x2 + x3 + x4 - THIRD
    )


def lower_decimal(value):
    """Round an exact dyadic lower endpoint DOWN when printing decimal."""
    value = value.lower()
    if not value.is_finite():
        return None

        dc.prec = max(30, ctx.prec * 30103 // 100000)
        dc.rounding = ROUND_FLOOR
        return str(Decimal(m) / Decimal(1 << -e))


def a_bound(z, mu):
    """Enclose the specified a(z,mu), including the entire finite maximum."""
    powers = []
    for q in mu:
        row = [arb(1), arb(q)]
        for unused in range(2, 6):
            row.append(row[-1] * row[1])
        powers.append(row)
    phi = arb(0)
    moments = [arb(0) for unused in range(4)]
    for s, w in SPECTRA:
        term = arb(w)
        for k in range(4):
            if s[k]:
                term *= powers[k][s[k]]
        phi += term
        for k in range(4):
            if s[k]:
                moments[k] += s[k] * term
    if not (phi.is_finite() and phi > 0):
        raise Invalid("Phi is not certified finite and positive")
    means = [v / phi for v in moments]
    if any(not (v.is_finite() and v > 0) for v in means):
        raise Invalid("a moment is not certified finite and positive")
    g = [means[k].log() / 2 - arb(mu[k]).log() + z[k]
         for k in range(4)]
    # psi0 + z.m0 - g.m0 = log(Phi) exactly. No approximation
    # or assumed maximizer is used in this algebraic cancellation.
    maximum = None
    for s, unused in SPECTRA:
        score = arb(0)
        for k in range(4):
            if s[k]:
                score += s[k] * g[k]
        maximum = score if maximum is None else maximum.max(score)
    answer = phi.log() + maximum
    if not answer.is_finite():
        raise Invalid("nonfinite a(z,mu) enclosure")
    return answer
