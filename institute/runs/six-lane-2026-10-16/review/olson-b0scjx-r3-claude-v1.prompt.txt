65: ## 2. The c-function and Lemma SIGMA-2P
66: 
67: Singleton representatives: w_t := the representative of u_t in gap({t}); W(Q) := sum of w_t over t in Q, so W(Q) = u_Q (mod p).
68: c(Q) := the unique integer with W(Q) - c(Q) p in gap(Q); J := (sum_t w_t)/p - 1, an integer since sum_t u_t = 0.
69: **Lemma C1.**  (a) c({t}) = 0.  (b) c(Q) + c(Q^c) = J for every proper interval Q; in particular J = c([k] \ {t}) for every t.
70: (c) Let Q = Q1 u Q2 with Q1, Q2 nonempty consecutive sub-intervals, Q3 := Q^c, m_i := m_(Q_i) (m1 + m2 + m3 = R).
71:    (A') g(m1) + g(m2) + g(m3) >= -2 implies c(Q) >= c(Q1) + c(Q2);
72:    (B') g(m2 + m3) + g(m1 + m3) + g(m1 + m2) >= p - 2 implies c(Q) <= c(Q1) + c(Q2).
73: Proof.  (a) Definition.  (b) gap(Q^c) = [g(R - m_Q) + 1, p - g(m_Q) - 1] = p - gap(Q) (as sets) and W(Q) + W(Q^c) = (J + 1) p, so
74: W(Q) - (J - c(Q^c)) p = p - (W(Q^c) - c(Q^c) p) lies in gap(Q).  (c) Write U_i = g(m_i), L_i = g(R - m_i), U_Q = g(m1 + m2),
75: L_Q = g(m3).  X := W(Q) - (c(Q1) + c(Q2)) p lies in gap(Q1) + gap(Q2) = [U1 + U2 + 2, 2p - L1 - L2 - 2] and X = u_Q (mod p), so X
76: avoids I(Q) + pZ.  Under (A'), X >= -L_Q, hence X >= U_Q + 1; as W(Q) - c(Q) p <= p - L_Q - 1, (c(Q) - c(Q1) - c(Q2)) p >= U_Q + L_Q
77: + 2 - p > -p (U_Q + L_Q >= 0).  Under (B'), X <= p + U_Q (as L1 + L2 + U_Q >= p - 2), hence X <= p - L_Q - 1; as W(Q) - c(Q) p >=
78: U_Q + 1, (c(Q1) + c(Q2) - c(Q)) p >= U_Q + L_Q + 2 - p > -p.  []
79: **Lemma C2.**  (a) (A') holds for every split.  (b) (B') holds for every split whose three pair sums m1 + m2, m1 + m3, m2 + m3 are
80: all >= 2 Delta - 1.  (c) c(Q) >= 0 for every proper interval Q; hence 0 <= c(Q) <= J and J >= 0.
81: Proof.  (a) Call m small if m <= 2 kappa.  None small: sum >= (R - 3)/2 >= 0.  One small (m1): >= m1 - kappa + (R - m1 - 2)/2 >=
82: R/2 - 1 - kappa >= 0.  Two small (m1, m2): >= m1 + m2 - 2 kappa + (R - m1 - m2 - 1)/2 >= (R - 1)/2 - 2 kappa >= 0.  Three small:
83: = R - 3 kappa > 0.  (All by (H).)  (b) The pair sums s1, s2, s3 add up to 2R and any two add up to >= R >= 4 kappa + 1, so at most
84: one, say s, is <= 2 kappa.  If none is, (B') >= (2R - 3)/2, so (B') >= R - 1 >= p - 1.  If s <= 2 kappa, the other two s', s'' are
85: floor terms with s' + s'' = 2R - s, and floor(s'/2) + floor(s''/2) >= R - 1 - s/2 if s is even, = R - (s + 1)/2 if s is odd; so
86: (B') >= R - kappa - 1 + ceil(s/2), which is >= p - 2 iff ceil(s/2) >= Delta (as Delta = p + kappa - 1 - R), i.e. iff s >= 2 Delta - 1.
87: (c) Induction on |Q|: |Q| = 1 is C1(a); for |Q| >= 2 use any split, (a) and C1(c).  Then c(Q^c) >= 0 and C1(b).  []
88: **Lemma SIGMA-2P.**  Under (H) and (D), J = 0, i.e. sum_t w_t = p.
89: Proof.  If Delta <= 0, every pair sum is >= 0 >= 2 Delta - 1, so by C2(b) and C1(c) c(Q) <= c(Q1) + c(Q2) for every split; induction
90: gives c(Q) <= 0, so c = 0 on all proper intervals and J = c([k] \ {t}) = 0.  Otherwise let {s, s+1}, {t, t+1} be as in (D);
91: Q := the interval from s to t - 1 contains s, s + 1, and Q^c (from t to s - 1) contains t, t + 1 (the pairs are disjoint).  For
92: j = s + 1, ..., t - 1 split Q_j := [s, j] as Q_(j-1) u {j}.  The pair sums are m(Q_j) >= r_s + r_(s+1), m({j} u Q_j^c) >= m(Q^c) >=
93: r_t + r_(t+1) and m(Q_(j-1) u Q_j^c) >= m(Q^c); all are >= 2 Delta - 1.  By C2(b) and C1(c), c(Q_j) <= c(Q_(j-1)), so c(Q) <= c({s})
94: = 0 and c(Q) = 0 by C2(c).  Symmetrically (chain [t, j]) c(Q^c) = 0.  C1(b): J = c(Q) + c(Q^c) = 0.  []

156: **Theorem K0*.**  Let p >= 5 be prime and w a word of length 4p - 2 over D_(2p) whose rotation letters all lie in one set
157: {rho_x, rho_-x}, x != 0.  If w is an avoider with kappa(w) = 0 (i.e. its maximal constant reflection blocks contain p - 1 disjoint

159: kappa = 0.  (Uses only Theorem P, Davenport-alpha, EGZ/Lemma AR and the elementary lemmas above; no RGR theorem is imported.)

165: avoidance, the length, every rotation, and lowers g by >= 1.  It never performs an odd-odd double fusion: that would give an
