55: ## 2. Block-chain lemma (value-independent certificate; no winding hypothesis)
56: 
57: **Lemma BC.**  Let w be an avoider (RGR, length 4p-2, F, R >= 1).  Let (P_1, ..., P_s),
58: s >= 2, be an ordered partition of [k] into nonempty proper patterns, Q_t := P_1 u ... u P_t.
59: Suppose
60:  (a) lambda(P_1) + ... + lambda(P_s) >= p + 1;
61:  (b) for 2 <= t <= s-1, with X = Q_{t-1}, Y = P_t, Z = Q_t^c:
62:      lambda(X u Y) + lambda(Y u Z) + lambda(Z u X) >= p + 1   and
63:      lambda(X) + lambda(Y) + lambda(Z) >= 1;
64:  (c) lambda(P_s) + lambda(P_s^c) >= 1.
65: Then w has an identity 2p-subword (contradiction).
66: 
67: Proof.  As w avoids, for every proper Q the residue u_Q is not that of any element of
68: I(Q); in particular |I(Q)| <= p - 1, i.e. lambda(Q) + lambda(Q^c) <= p.
69: Claim: if y is an integer, y = u_Q (mod p) and 1 - lambda(Q^c) <= y <= p + lambda(Q) - 1,
70: then lambda(Q) <= y <= p - lambda(Q^c).  Indeed, write l = lambda(Q), l' = lambda(Q^c); the
71: integers [1 - l', l - 1] and [p + 1 - l', p + l - 1] are congruent to elements of I(Q), so y
72: avoids them; as l + l' <= p, the three ranges [1 - l', l - 1], [l, p - l'],
73: [p + 1 - l', p + l - 1] tile [1 - l', p + l - 1] in this order (when l + l' <= 1 the outer
74: ranges are empty and [1 - l', p + l - 1] is contained in [l, p - l']).
75: For each t choose an integer v_t = u_{P_t} (mod p) in [lambda(P_t), p - lambda(P_t^c)]
76: (possible: if l + l' >= 1 the interval [1 - l', p + l - 1] has >= p integers and contains a
77: representative, which lies in [l, p - l'] by the claim; if l + l' <= 0 the interval
78: [l, p - l'] itself has >= p + 1 integers).  Put V_t = v_1 + ... + v_t = u_{Q_t} (mod p).
79: Induction: V_t in [lambda(Q_t), p - lambda(Q_t^c)] for 1 <= t <= s-1.  For t = 1 this is
80: the choice of v_1.  For 2 <= t <= s-1, V_t = V_{t-1} + v_t lies in
81: [lambda(Q_{t-1}) + lambda(P_t), 2p - lambda(Q_{t-1}^c) - lambda(P_t^c)], and with
82: X, Y, Z as in (b) (Q_{t-1}^c = Y u Z, P_t^c = Z u X, Q_t = X u Y, Q_t^c = Z) condition (b)
83: says exactly that this range lies in [1 - lambda(Q_t^c), p + lambda(Q_t) - 1]; the claim
84: gives the induction step.  Finally V_s = u_{[k]} = 0 (mod p), V_s = sum v_t >= sum
85: lambda(P_t) >= p + 1 by (a), and V_s = V_{s-1} + v_s <= (p - lambda(P_s)) +
86: (p - lambda(P_s^c)) <= 2p - 1 by (c) (Q_{s-1}^c = P_s).  No multiple of p lies in
87: [p + 1, 2p - 1].  []
88: 
89: Remarks.  s = 2 is the full-window certificate (|I(P_1)| >= p).  s = 3 is the
90: "Cauchy-Davenport" certificate: (a) plus the first inequality of (b).

92: ## 3. Theorem K0
93: 
94: **Theorem K0.**  Let p >= 5 be prime and w in RGR_{4p-2}(p) with F, R >= 1, k <= p,
95: satisfying (P) and (V).  If kappa(w) = 0 and w has an even run, then w has an identity
96: 2p-subword.  In particular PAR(p) holds for every inherited avoider with kappa = 0.
97: 
98: Proof.  Suppose w avoids.  Normalise B <= A; the zero condition gives B <= kappa = 0, so
99: every rotation letter is rho_1: d_t = r_t >= 1, D = R, D_Q = R_Q := sum_{t in Q} r_t.
100: 
101: Step 1 (counting).  kappa = 0 means R = 2p - o_F.  (V) gives o_F >= 1, so R <= 2p - 1;
102: k <= p gives R >= p >= 5.  R = o_R (mod 2) and R = o_F (mod 2), so e_R = e_F (mod 2);
103: (P) gives o_R >= o_F, i.e. e_R <= e_F.  As w has an even run, e_F >= 1.
104: 
105: Step 2 (interval windows).  For a proper cyclic interval Q (m = 1) Lemma H gives
106: lambda(Q) = min(p, R_Q + 1 - beta(Q), floor(R_Q/2) + 1).  Since R_Q <= 2p - 1 the cap p
107: never binds, and R_Q + 1 - beta >= floor(R_Q/2) + 1 unless beta = 2 and R_Q <= 2; in that
108: case lambda(Q) = R_Q - 1 = floor(R_Q/2).  So
109:   lambda(Q) = floor(R_Q/2) + 1 - t_Q,   t_Q := [beta(Q) = 2 and R_Q <= 2],   lambda(Q) >= 0,
110: and lambda(Q) = 0 only if R_Q = 1 (and t_Q = 1).
111: 
112: Step 3 (the partition).  Cut the cycle at every odd reflection run.  This gives o_F
113: segments G (G = the rotation runs strictly between two cyclically consecutive odd
114: reflection runs; if o_F = 1 the single segment is all k runs); a segment with c_G rotation
115: runs contains c_G - 1 even reflection runs.  In every segment with c_G >= 2 cut also at its
116: first internal reflection run (right after its first rotation run).  The resulting parts
117: are cyclic intervals; each has at most one even boundary run, so t_P = 0 and
118: lambda(P) = floor(R_P/2) + 1.  The number of parts is s >= 2 (s >= o_F; if o_F = 1 then
119: e_F = k - 1 >= 1 and the segment is cut once more).  Writing n_e, n_o for the numbers of
120: parts with R_P even / odd,
121:   sum_P lambda(P) = (R + 2 n_e + n_o)/2 = p + (2 n_e + n_o - o_F)/2.
122: Score a segment by score(G) = sum over its parts of (2 if R_P even, 1 if odd).  Then
123: 2 n_e + n_o = sum_G score(G) and there are o_F segments, so condition (a) of Lemma BC is
124:   sum_G (score(G) - 1) >= 2.
125: A segment with c_G = 1 has score 1 + [r even].  A segment with c_G >= 2 has two parts,
126: score >= 2, and score = 3 when R_G is odd (its two parts then have opposite parities).
127: Since e_F >= 1 some segment has c_G >= 2 (contribution >= 1).  If a second segment
128: contributes, done.  Otherwise there is exactly one segment G0 with c_{G0} >= 2 and every
129: other segment is a single odd rotation run; then all even reflection runs and all even
130: rotation runs lie in G0, so e_F = c_{G0} - 1 and R_{G0} = c_{G0} - e_R = c_{G0} - e_F = 1
131: (mod 2) (Step 1).  So score(G0) = 3 and the sum is 2.  This proves (a).
132: 
133: Step 4 (conditions (b), (c) for the parts in cyclic order).  At step t the sets
134: X = Q_{t-1}, Y = P_t, Z = Q_t^c are nonempty cyclic intervals partitioning the cycle, and
135: X u Y, Y u Z, Z u X are proper cyclic intervals (complements of Z, X, Y).
136: Lower inequality: each lambda >= 0, and lambda(X) = lambda(Y) = lambda(Z) = 0 would force
137: R = 3 < 5.  Upper inequality: R_{XuY} + R_{YuZ} + R_{ZuX} = 2R is even, so at most two of
138: the three are odd, and
139:   lambda(XuY) + lambda(YuZ) + lambda(ZuX) >= (2R - 2)/2 + 3 - (t_{XuY} + t_{YuZ} + t_{ZuX}).
140: Two of the t's equal to 1 would give two of the unions R-value <= 2, and any two of the
141: unions cover the cycle, so R <= 4 < 5.  Hence the sum is >= R + 1 = 2p - o_F + 1 >= p + 1
142: (o_F <= k <= p).  (c): lambda(P_s), lambda(P_s^c) >= 0 and both 0 would force R = 2.
143: Lemma BC now gives the contradiction.  []

146: e_R <= e_F, k <= p in Step 4, kappa = 0 throughout.  (Pairs) is implied by kappa = 0;
147: (E), (D0) are not used.
