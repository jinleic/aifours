L37: ## 2. Lemma GEN (closed form of genericity)
L38: 
L39: **Lemma GEN.**  A proper pattern Q with y = D_Q and m = m(Q) is generic iff
L40:    |4m - (k + 2)| + |2y - D| <= E + 2 Delta0.
L41: Proof.  lambda(Q) equals its floor term iff (i) floor((y + B)/2) + 1 <= y + m - kB and (ii) floor((y + B)/2) + 1 <= p - m + 1;
L42: lambda(Q^c) equals its floor term iff (iii) floor((A - y)/2) + 1 <= A - kappa - y + m and (iv) floor((A - y)/2) + 1 <= p - m + 1.
L43: Write floor((y + B)/2) = (y + B - th)/2 with th := [y + B odd] and floor((A - y)/2) = (A - y - th')/2 with th' := [A - y odd].
L44: Doubling,
L45:    (i) 2m + y >= 2kB + B + 2 - th,  (ii) 2m + y <= 2p - B + th,  (iii) 2m - y >= 2kappa + 2 - A - th',  (iv) 2m - y <= 2p - A + th'.
L46: Now 2m + y == y == B + th (mod 2), and both bounds in (i), (ii) are == B + th as well; hence (i) is equivalent to
L47: 2m + y >= 2kB + B + 1 (for th = 1 this is the same bound; for th = 0 the value 2kB + B + 1 has the other parity) and (ii) to
L48: 2m + y <= 2p - B + 1.  In the same way 2m - y == A + th' (mod 2) and (iii), (iv) are equivalent to 2kappa + 1 - A <= 2m - y <=
L49: 2p - A + 1.  Both intervals have length 2(p - kappa); with
L50:    a1 := 2m + y - (p + kB + 1),     a2 := 2m - y - (p + kappa + 1 - A),
L51: Q is generic iff |a1| <= p - kappa and |a2| <= p - kappa.  Using (1.1): a1 + a2 = 4m - (2p + kB + kappa + 2 - A) = 4m - (k + 2)
L52: and a1 - a2 = 2y - (A - kappa + kB) = 2y - D.  Since max(|a1|, |a2|) = (|a1 + a2| + |a1 - a2|)/2 and 2(p - kappa) = E + 2 Delta0,

L35:
