# Smoke test and SOTA calibration — 2026-10-14

A live end-to-end run of the explorer with real Claude and Codex calls, on a scratch copy of the
explorer root (so no real `problems/` records were written). Quotas per stage were reduced to
identify 420 s, sota 900 s, attack 1200 s, replay 300 s, review 900 s and novelty 600 s. Executors
came from `DELEGATE_MODELS.json` (claude-opus-5-5 max, gpt-6.1-sol max).

## Measured costs (for setting quotas)

- identify: 152–268 s, about $0.73 notional each (Opus max).
- sota: 222–620 s, about 3M input tokens (about 92% cached) and about 17k output tokens.
- attack: 621–973 s, about 0.7M input tokens and about 33k output tokens.
- review: 452–608 s.
- novelty: 510 s.

The default quotas (`QUOTA` in `ri.py`: 600/1200/3600/600/1800/900 s) leave at least 2× headroom on
identify and sota. Claude's subscription windows read five-hour 0.56 and seven-day 0.67 during the
run. The runner stops claude stages at 0.9.

## Defects the smoke test exposed (all fixed, with regression tests)

- The frozen contract and the prompt hash were saved only after an attempt ended. A crash
  mid-attack would have lost the pre-registration. They are now saved before launch.
- Atomic writes created files with mkstemp's 0600 mode. They now use 0644.
- A requeued attack started from an empty directory, discarding certified code. It now continues
  from the previous epoch's deliverables, with the referee's feedback in its prompt.
